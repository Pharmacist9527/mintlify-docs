<span id="skills" />
## CLI、MCP、Skill 和插件各做什么

| 部件 | 作用 | 后续要做的事 |
|---|---|---|
| EvoLink CLI | 通过终端命令执行平台业务，媒体直连 API | [安装、登录与验证](/cn/cli/setup) |
| 远程 MCP | 通过 HTTP 与 OAuth 向宿主提供工具 | [选择 MCP 客户端](/cn/mcp/overview#选择您的助手) |
| 本地 MCP | 在本机以 stdio 运行工具进程 | [配置进程与平台 Key](/cn/mcp/other-clients#local-mcp) |
| Skill | 指导 Agent 查模型、确认费用、恢复和交付 | 安装到宿主可发现的位置，并让它确认读取 |
| 插件 | 按宿主能力打包接入配置与技能 | [插件步骤](/cn/mcp/plugins)，另核对登录和权限 |
| Markdown／llms.txt | 提供可读说明或文档索引 | 阅读对应正文，不能代替执行工具 |

安装 CLI 不会另外克隆 MCP 或插件仓库，也不自动注册原生 MCP。当前 CLI 随包带 evolink-cli 技能；MCP 插件仓库提供 evolink-mcp 工具说明。它们仍是分别维护的入口，不宣称已经共用同一个技能源。

## 技能包含什么

当前技能指导模型与参数查询、图片／视频／音频、参考上传、估价批准、预算检查、原请求恢复、任务等待、下载与原件交付。CLI 随包包含 SKILL.md 以及 capabilities、media-workflows、usage-and-budget 三份参考；详细安装目标、目录、加载验证和升级见[CLI 技能](/cn/cli/skills)。MCP 安装与宿主插件配置见[插件指南](/cn/mcp/plugins)。

目前没有独立爆款广告、UGC 成片、自动剪辑或预设技能库。模型示例和操作流程不保证传播效果。代码开发、任意文件编辑与网站搭建来自宿主能力，不能归入 EvoLink 工具。

## 给 Agent 的共同调用规则

```text
先确定本次使用 EvoLink CLI 还是原生 MCP，并确认实际连接。
查询账户可用模型和真实参数，按任务、素材、质量与预算给出推荐理由。
展示最终方案和本次预计费用，取得明确批准后只提交一次。
结果未知时沿原入口恢复原请求，不换身份或编号重发。
查询原 task_id，交付原件、已返回的实际费用及链接有效期。
说明缺少或不支持的能力，不编造模型、参数、工具、价格或退款。
不把估价预算说成最终扣费保证；未获要求不自动剪辑、修图或重做。
```

当前任务绑定一种入口。CLI 用命令与本地报价，MCP 用工具和原 client_request_id；调用方式分别查参考。技能文件存在不表示宿主已加载；能读技能也不表示工具已配置或允许执行。不要通过重复付费生成验证技能。

## Markdown 与 llms.txt 怎样使用

1. 先读[总览](/cn/cli-mcp/overview)并选择当前客户端和入口。
2. 阅读对应安装页、命令／工具参考和共用规则；模型 schema 以本次实际查询为准。
3. 页面支持的复制或 Markdown 导出可保存为 .md 后交给 Agent。文件中不放 Key、令牌或私人授权链接。
4. [llms.txt](https://docs.evolink.ai/llms.txt)是文档目录索引，用于找到正文；它不是 MCP 服务地址、CLI 安装脚本或登录接口。

| 资料 | 用途 |
|---|---|
| [CLI 参考](/cn/cli/reference)／[MCP 参考](/cn/mcp/tools) | 实际命令和工具参数、返回值及恢复 |
| [模型、费用与额度](/cn/cli-mcp/models-and-billing) | 推荐、估价状态、批准与预算边界 |
| [任务、素材与结果](/cn/cli-mcp/tasks-and-files) | 上传、有效期、未知恢复、下载和灰色预览 |
| [CLI 技能](/cn/cli/skills)／[MCP 插件](/cn/mcp/plugins) | 安装、宿主发现、个人修改和升级 |

## 更新资料之后还要验证什么

CLI 更新后同步随包技能，让宿主重新读取；插件或手工 MCP 配置变更后核对当前连接、OAuth 和工具权限。不要覆盖其他服务配置或个人修改。安装包、文档和工具版本可能不同，发现冲突时按实际已发布版本与返回 schema 核对，说明未确认的内容。
