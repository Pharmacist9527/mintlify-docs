EvoLink 让您在熟悉的 Agent 中生成图片、视频、音乐与语音，查询模型和费用、上传参考素材、跟踪任务并保存原件。先选择接入方式，再按对应指南完成安装和免费验证。

## 先选择接入方式

| 您在哪里使用 | 推荐入口 | 安装内容与登录方式 |
|---|---|---|
| Claude 聊天、ChatGPT | [远程 MCP](/cn/mcp/overview) | 添加服务连接，通过浏览器 OAuth 授权；无需安装 CLI |
| Codex、Claude Code、Cursor、OpenClaw、Hermes，且能执行终端命令 | [CLI](/cn/cli/setup) | 安装 CLI、登录账户、安装并加载技能 |
| 普通终端、SSH 或脚本 | [CLI](/cn/cli/setup) | 在实际执行环境安装；SSH 登录有独立回调步骤 |
| 希望使用原生 MCP 工具的终端 Agent | [对应 MCP 客户端页](/cn/mcp/overview#选择您的助手) | 按宿主配置并独立授权；可以直接选这一路 |
| 只支持本地 stdio 的 MCP 客户端 | [本地 MCP](/cn/mcp/other-clients#local-mcp) | 配置本地进程、Node.js 与个人 API Key |

Codex CLI 是您的 Agent 客户端，EvoLink CLI 是它调用的媒体工具。两者名字里都有 CLI，但安装的是不同产品。客户端卡片给出一种推荐入口；需要原生 MCP 时，各 CLI 客户端页也有对应链接。

## 安装后怎么确认成功

<Steps>
  <Step title="完成所选入口的安装与登录">
    CLI 按[安装与登录](/cn/cli/setup)执行五步；MCP 按自己的[客户端指南](/cn/mcp/overview#选择您的助手)配置和授权。浏览器登录由您完成，不把 Key 或令牌发到聊天中。
  </Step>
  <Step title="查询余额和模型，确认技能或工具可用">
    CLI 运行余额查询和 doctor，并让 Agent 确认读取技能；MCP 实际调用 check_balance 和 search_models。能看到文件、安装成功或列出工具都不等于调用成功。这些验证不提交付费媒体任务。
  </Step>
  <Step title="先看方案和预计费用，再确认首次生成">
    查询准确模型与参数，准备素材，展示方案及预计费用。您明确批准后只提交一次，保留任务编号，完成后保存原件。完整操作见[CLI 工作流](/cn/cli/workflows)与[MCP 工作流](/cn/mcp/overview#workflows)。
  </Step>
</Steps>

## 两种入口的关系

CLI 媒体业务走 `Agent／终端 → CLI → 平台 API`；原生 MCP 走 `Agent → 远程或本地 MCP → 平台 API`。CLI 媒体执行不依赖远程 MCP。账户登录使用 Passport；素材上传和原件下载另有文件地址。

CLI 和原生 MCP 的安装、登录会话和连接验证分别进行；同账户 OAuth 目前可以共享内部 Key 权限与额度。选择一种方式完成当前任务，提交结果未知时沿原入口恢复，不通过另一入口再生成。
