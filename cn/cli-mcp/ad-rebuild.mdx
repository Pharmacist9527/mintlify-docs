<span id="ad-rebuild" />
## 这个工作流做什么

把一条简短的参考广告、你的产品（如果有，再加上你的出镜人物）交给助手。助手会研究参考广告，用你的产品规划出同样的结构，准备关键帧图片，在一个视频任务里生成带声音的整条广告，对照计划检查，然后把结果交给你。

助手按 EvoLink 在登录后下发的分步规则执行，所以你不用写很长的提示词。在任何扣费发生之前，你只需要确认一个预估总价。

<span id="requirements" />
## 开始之前

| 你需要 | 说明 |
|---|---|
| 登录 EvoLink | 通过 [EvoLink 插件或远程 MCP](/cn/mcp/overview) 连接，或者安装 [EvoLink CLI](/cn/cli/setup) 并登录。这个工作流只提供给已登录的连接，只有 API Key 不能使用 |
| 能处理视频画面的助手 | 能运行命令的助手（例如 Claude Code、Codex 或 Cursor）在自己所在的机器上用 ffmpeg 和 ffprobe 从视频里抽帧。没有终端的助手（例如浏览器里的聊天窗口）改用 `make_frames` 来做，这是远程 MCP 提供给已登录连接的免费工具 |
| 足够的余额 | 估价会说明你的余额，以及你为 EvoLink MCP 设置的额度上限（如果设了），够不够这一次运行 |

<Note>
既不能运行命令、也没有 `make_frames` 工具的助手，做不了这个工作流里的抽帧工作。它会在产生任何费用之前告诉你。
</Note>

<span id="inputs" />
## 你要提供什么

| 输入 | 说明 |
|---|---|
| 参考视频 | MP4 或 MOV，**不超过 30 秒**。更长的话，助手会问你用哪一段 |
| 产品 | 一张或多张产品图片、一句话说明它的用途，以及你能确认的宣传点。参考广告里的宣传点不会照搬，除非你确认它们适用于你的产品 |
| 出镜人物（可选） | 你的出镜人物的照片。没有的话，广告需要人物时，助手会生成一个虚构的成年人。它不会照搬参考广告里的人 |
| 选项 | 语言、出镜说话还是旁白、音乐、时长（4 到 30 秒）、画面比例，以及分辨率：480p、720p、1080p 或 4K，也可以先出一个 480p 草稿。缺什么，助手会在一条消息里问清，并给出默认值；你没说分辨率时，它按 720p 估价，并在总价后面列出其他选项。如果你的助手能显示选项按钮，它会用按钮来问，你也随时可以自己输入回答 |

请使用你自己拥有或已获授权的素材。工作流保留参考广告的结构（开场钩子、节奏点、动作、镜头节奏），替换人物、产品、场景、文案和宣传点。

<span id="cost" />
## 一个预估总价，确认一次

在你确认之前，助手只做不花钱的事：检查登录和余额，读取参考视频的时长和画幅，数出镜头数，算出估价。然后给你看一个总价，例如：

```text
预估总价：约 $3.67（249.4 积分），一条 10 秒、720p、带声音的广告。
包含：分析参考视频、这条广告要用的图片、视频本身和最后的检查。
其他选项：480p、1080p 或 4K，或者先出一个 480p 草稿，以后再转成 1080p 或 4K
（每次转换单独报价、单独确认）。你选哪一个，我就改报那一个的总价。
每一步在执行时扣费；你中途停下的话，停下之前已经做完的步骤照常计费。
生成失败不扣费，每个失败的生成我最多重试两次。
要按 720p 开始，请回复“确认”。如果工作会超出这个总价，我会先问你。
```

- **总价就是预算**。确认以后，助手不会一步一步来问费用。只有当工作会超出总价时，它才回来找你。
- **其他选项也免费估价**。你选了别的分辨率或草稿，助手会改报那一个的总价；你仍然只确认一次。
- **包含什么**：分析参考视频、需要时的出镜人物图片、关键帧图片和修改其中几张的余量、一条带声音的视频，以及最后的检查。
- **不包含什么**：草稿的转换（单独报价、单独确认），以及已经完成一条视频之后，再生成一整条新的。如果成片没有达到计划，助手会说明哪里不对、重做一次要多少钱，然后等你决定。
- **余额不够时**，估价会说明差多少，并给出充值页面的链接。什么都不会开始。
- 价格按估价时你账户自己的价格计算；读不到时改用公开默认价格，估价里会写明。实际扣费以实际用量为准。估价 24 小时内有效。

交付时，助手会把实际扣费和预估总价放在一起告诉你；想看明细，可以让它按任务列出来。每一笔扣费都列在[控制台](https://evolink.ai/dashboard)的历史记录里，带模型和费用：图片和视频显示为生成任务，每次视频分析显示为一次 Gemini 模型调用。请用助手所用的同一个 EvoLink 账户登录查看。

<span id="steps" />
## 助手会做什么

| 步骤 | 做什么 | 是否计费 |
|---|---|---|
| 0. 检查和估价 | 参考视频的时长和画幅、镜头数、预估总价。你确认一次 | 否 |
| 1. 读参考视频 | 上传参考视频，分析它的镜头和声音，并把结果和抽出的画面对照 | 是 |
| 2. 写目标 | 逐个镜头写清什么要换、什么保留：人物、产品、场景、动作、台词、音乐 | 否 |
| 3. 规划整条广告 | 时间线、需要的关键帧图片，以及那一个视频任务 | 否 |
| 4. 制作关键帧图片 | 需要时先做出镜人物参考图，然后是每个镜头的第一帧和中间的状态。每张图检查通过后才进入下一步 | 是 |
| 5. 准备视频请求 | 全部关键帧图片，加上一份完整的画面和声音描述 | 否 |
| 6. 生成并检查 | 整条广告用一个视频任务生成，带人声、音乐和音效。生成结果会对照目标做分析 | 是 |
| 7. 交付 | 原始视频、关键帧总览图、简短的检查总结、重要的遗留问题，以及费用：预估总价和实际扣费。需要逐个镜头的结论，可以向助手要 | 否 |

确认以后，助手会一直做到交付。只有四种情况它会停下来：工作会超出总价；有只能由你决定的事（例如你的产品做不到某个动作）；成片需要重做一次；你选了草稿，草稿做好后，由你决定要不要转换。如果你想在生成视频之前先看关键帧图片，请在确认时说明。

<span id="draft" />
## 先出草稿

选草稿时，整条广告先按 480p 生成一次，按 480p 的价格计费，所以预估总价只包含这个草稿。助手会像检查成片一样检查草稿，并照同样的方式交付给你。

之后助手会问你：把草稿转成 1080p 还是 4K，或者就保留草稿。每次转换都是一个新任务：助手先告诉你价格，等你确认；转换单独扣费，不算在已确认的总价里。同一个草稿可以转换多次，例如先转 1080p，以后再转 4K；每次转换都要计费。

草稿在截止时间之前可以转换。助手会告诉你确切的截止时间，也就是查询任务时返回的 `draft_expires_at`。

<span id="start" />
## 开始一次复刻

1. 在助手里连接 EvoLink：安装 [EvoLink 插件](/cn/mcp/plugins)，或者按 [Claude Code](/cn/mcp/claude-code)、[Codex](/cn/mcp/codex)、[Cursor](/cn/mcp/cursor) 的说明添加远程 MCP，或者安装 [EvoLink CLI](/cn/cli/setup)。
2. 把参考视频和产品图片放在助手能读到的地方。
3. 用你自己的话提出要求，例如：

```text
用我的产品复刻这条广告。参考视频：./reference.mp4。产品：./product.png，一款玫瑰水保湿喷雾，能喷出细雾。英语，10 秒，720p，竖屏。
```

助手会取回工作流规则，做完不花钱的检查，然后带着预估总价回来找你。

<span id="limits" />
## 限制和预期

- **时长**：参考视频和成片都不超过 30 秒。
- **一个视频任务**：整条广告连同声音一次生成。工作流不会分镜头单独渲染，不会事后配音，也不会剪辑结果。
- **时间点是大致的**。视频模型把计划里的剪切时间当作参考。剪切点和动作可能早或晚一秒左右；交付时的检查会指出具体位置。
- **画面里的文字和标签**会在结果里检查，但仍然可能变形。
- **内容审核**：如果模型拒绝了素材，助手会告诉你，并请你换素材。它不会为了通过审核去改写请求。
- **频率限制**：一个账户每分钟、每天能发起的视频分析次数有限。提示信息会说明要等多久。
- **播放**：1080p 和 4K 视频是 10 位 HEVC 文件。有些播放器打不开；VLC 和 QuickTime 可以播放。

<span id="recovery" />
## 如果中途被打断

已经完成的步骤不会作废。后面出了问题，也不需要重新读参考视频，或者重新生成已经通过的图片。

| 发生了什么 | 助手怎么做 |
|---|---|
| 视频分析过程中连接断了 | 原样再发一次同一个请求。已经在进行的那次分析会被返回，只计费一次 |
| 服务繁忙 | 按提示信息说的时间等待，再试同一步，最多再试两次，然后告诉你 |
| 某个生成任务失败 | 这次不计费。助手在上面的次数限制内，用同样的输入重试 |
| 余额或额度上限不够 | 在下一笔扣费之前停下，说明已经完成了什么、还剩什么没做，等你充值或调高额度上限后继续 |
| 上传的文件或结果链接过期 | 上传的文件通常保留 72 小时，结果链接通常保留 24 小时。助手会用本地的副本重新上传 |

<span id="reference" />
## 工具和命令

这些由助手自己调用，你不需要亲自调用。

| 远程 MCP 工具 | CLI 命令 | 用途 | 是否计费 |
|---|---|---|---|
| get_media_workflow | `evolink workflow rules ad-rebuild` | 当前步骤的规则和运行编号（run ID） | 否 |
| get_media_workflow（带估价） | `evolink workflow estimate ad-rebuild --seconds 10 --keyframes 5` | 给计划中的这一次运行一个预估总价 | 否 |
| analyze_video | `evolink video analyze FILE_URL_OR_TASK_ID --run RUN_ID --step STEP --purpose PURPOSE` | 为工作流的某一步分析视频 | 是，按 token |
| get_video_analysis | `evolink video analysis ANALYSIS_ID` | 取回还在进行的分析 | 否 |
| generate_workflow_media | `evolink estimate --model MODEL --input-file FILE --run RUN_ID --step STEP`，然后 `evolink generate image\|video\|audio --quote ID --confirm` | 这一次运行里的一次付费生成，会和这一次运行记在一起 | 是，按模型的价格 |
| record_workflow_delivery | `evolink workflow deliver TASK_ID --run RUN_ID` | 记下交付的是哪一条已完成的视频 | 否 |
| make_frames | CLI 里没有：助手在自己的机器上用 ffmpeg | 给没有终端的助手抽帧、裁剪、做总览图和带编号的拼图 | 否 |

把一次生成和它所属的运行记在一起，只是一条方便以后查找的记录；不改变价格，也不改变结果。上传、单次生成的估价、生成和任务查询，用的是平常的 [MCP 工具](/cn/mcp/tools)和 [CLI 命令](/cn/cli/reference)。估价和扣费的关系见[模型、费用与额度](/cn/cli-mcp/models-and-billing)。
