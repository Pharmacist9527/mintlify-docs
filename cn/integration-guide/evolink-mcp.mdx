## 概述

EvoLink MCP 让 AI 助手直接调用 EvoLink 的模型：查有哪些模型和价格、先报价再生成图片、视频和音频、查任务进度和账户余额。

- **服务地址：** `https://mcp.evolink.ai/mcp`
- **不需要 API Key：** 第一次使用时在浏览器里登录 EvoLink 并点同意，助手就连上了。
- **按用量扣费：** 费用从您的 EvoLink 账户余额扣，价格和 API 相同，MCP 本身不收费。

## 支持的客户端

| 客户端 | 添加方式 |
|---|---|
| Claude（网页版、桌面版） | 设置里添加自定义连接器 |
| Claude Code | 一条命令 |
| Codex | 配置文件加两行，再登录 |
| Cursor | MCP 配置文件 |
| VS Code | MCP 配置文件 |

## 连接步骤

<Tabs>
  <Tab title="Claude（网页版 / 桌面版）">
    1. 打开 Claude 的 **设置 → 连接器**，点 **添加自定义连接器**。
    2. 名称填 `EvoLink`，地址填 `https://mcp.evolink.ai/mcp`，点 **添加**。
    3. 点 **连接**，在弹出的页面登录 EvoLink 并点同意。

    <Note>
    自定义连接器需要 Claude 的付费计划，以 Claude 官方说明为准。网页版里添加的连接器，桌面版也能用。
    </Note>
  </Tab>
  <Tab title="Claude Code">
    1. 在终端运行：

    ```bash
    claude mcp add --transport http evolink https://mcp.evolink.ai/mcp
    ```

    2. 在 Claude Code 里输入 `/mcp`，选 `evolink`，点 **Authenticate**。
    3. 浏览器会打开 EvoLink 登录页，登录后点同意，再回到 Claude Code。
  </Tab>
  <Tab title="Codex">
    1. 在 `~/.codex/config.toml` 里加上：

    ```toml
    [mcp_servers.evolink]
    url = "https://mcp.evolink.ai/mcp"
    ```

    2. 在终端运行：

    ```bash
    codex mcp login evolink
    ```

    3. 浏览器会打开 EvoLink 登录页，登录后点同意。
  </Tab>
  <Tab title="Cursor">
    1. 在 `~/.cursor/mcp.json` 里加上：

    ```json
    {
      "mcpServers": {
        "evolink": {
          "url": "https://mcp.evolink.ai/mcp"
        }
      }
    }
    ```

    2. 在 Cursor 的 MCP 设置里找到 `evolink`，按提示登录 EvoLink 并点同意。
  </Tab>
  <Tab title="VS Code">
    1. 在项目的 `.vscode/mcp.json` 里加上：

    ```json
    {
      "servers": {
        "evolink": {
          "type": "http",
          "url": "https://mcp.evolink.ai/mcp"
        }
      }
    }
    ```

    2. 启动 `evolink`，按提示登录 EvoLink 并点同意。
  </Tab>
</Tabs>

## 第一次连接：登录和同意

<Steps>
  <Step title="登录 EvoLink">
    浏览器打开 EvoLink 登录页。没有账号可以直接注册。
  </Step>
  <Step title="确认授权">
    同意页会写明是哪个助手（比如 Claude Code、Codex）在申请连接，申请的权限是 MCP。确认无误后点同意。
  </Step>
  <Step title="回到助手">
    浏览器提示可以回到助手，助手里显示已连接，就可以开始用了。
  </Step>
</Steps>

<Note>
同意页上，第三方助手会显示"未验证"，这是正常现象，不影响使用。
</Note>

## 能做什么

| 工具 | 用途 | 是否收费 |
|---|---|---|
| `search_models` | 按类型和关键词找图片、视频、音频模型 | 免费 |
| `get_model` | 查看某个模型的参数和价格 | 免费 |
| `estimate_cost` | 生成之前先报价 | 免费 |
| `generate_image` | 生成图片 | 按模型价格扣费 |
| `generate_video` | 生成视频 | 按模型价格扣费 |
| `generate_audio` | 生成音乐、歌曲或语音 | 按模型价格扣费 |
| `get_task` | 查询任务进度和结果 | 免费 |
| `list_tasks` | 查看最近的任务 | 免费 |
| `check_balance` | 查看账户余额和 MCP 已花费 | 免费 |

直接用自然语言说就行，比如"用 z-image-turbo 画一只红苹果"。助手会先报价，确认后再生成。视频和音频生成需要一些时间，助手会自动查询进度。

<Note>
通过登录连接时暂不支持上传本地文件。参考图片或视频请提供可公开访问的链接。
</Note>

## 费用和额度

- 费用从账户余额扣，价格和 API 相同。余额由 API、网页和 MCP 共用。
- 第一次连接后，控制台的 [API Keys](https://evolink.ai/dashboard/keys) 里会多一把名为 `EvoLink MCP (OAuth)` 的 Key。您账户下所有通过 MCP 连接的助手共用这把 Key。
- 在 API Keys 里给这把 Key 设总额度或当日额度，就能限制 MCP 的花费；停用这把 Key，所有助手的 MCP 就会暂停，不影响您其他的 Key。
- MCP 产生的任务、扣费和用量，在控制台照常显示，Key 名是 `EvoLink MCP (OAuth)`。

## 常见提示

助手遇到下面这些情况，会告诉您是哪一种、该怎么做：

| 提示（英文原文） | 含义 | 怎么做 |
|---|---|---|
| EvoLink MCP spending limit reached | MCP 总额度用完了，不是账户余额不足 | 在 API Keys 里调高 `EvoLink MCP (OAuth)` 的额度 |
| EvoLink MCP daily limit reached | MCP 当日额度用完了，零点重置 | 等重置，或调高当日额度 |
| Your EvoLink account balance is too low | 账户余额不足 | 到控制台充值 |
| EvoLink MCP is paused for this account | `EvoLink MCP (OAuth)` 被停用了 | 在 API Keys 里重新启用，不用重新连接 |
| This EvoLink connection was disconnected | 连接已断开或已过期 | 在助手里重新连接 EvoLink |

这几种情况都不会扣费。

## 断开连接

- **只断开一个助手：** Claude 在连接器设置里断开；Claude Code 运行 `claude mcp remove evolink`；Codex 运行 `codex mcp logout evolink`；Cursor、VS Code 删除配置里的 `evolink`。
- **暂停所有助手：** 在 [API Keys](https://evolink.ai/dashboard/keys) 里停用 `EvoLink MCP (OAuth)`，重新启用后马上恢复，不用重新连接。
