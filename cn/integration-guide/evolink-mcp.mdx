## 概述

EvoLink MCP 让 AI 助手直接调用 EvoLink 的模型：查有哪些模型和价格、上传参考文件、先报价再生成图片、视频和音频、查任务进度和账户余额。

- **服务地址：** `https://mcp.evolink.ai/mcp`
- **不需要 API Key：** 第一次使用时在浏览器里登录 EvoLink 并点同意，助手就连上了。
- **按用量扣费：** 费用从您的 EvoLink 账户余额扣，价格和 API 相同，MCP 本身不收费。

## 支持的客户端

| 客户端 | 添加方式 |
|---|---|
| Claude（网页版、桌面版） | 一键添加，或在设置里添加自定义连接器 |
| Claude Code | 一句命令 |
| Codex | 一句命令 |
| Cursor | 一键添加，或 MCP 配置文件 |
| Hermes Agent（还没实测） | 一句命令 |
| OpenClaw（还没实测） | 一句命令 |

ChatGPT 等其他支持远程 MCP 和 OAuth 登录的客户端，一般也能用同一个地址连接，但我们还没逐一测试，步骤见下面的「其他客户端」。

## 连接步骤

<Tabs>
  <Tab title="Claude（网页版 / 桌面版）">
    打开 [在 Claude 中添加 EvoLink](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp)，名称和地址会自动填好，点 **添加** 后接着做第 3 步。也可以手动添加：

    1. 打开 Claude 的 **设置 → 连接器**，点 **添加自定义连接器**。
    2. 名称填 `EvoLink`，地址填 `https://mcp.evolink.ai/mcp`，点 **添加**。
    3. 点 **连接**，在弹出的页面登录 EvoLink 并点同意。

    <Note>
    Claude 免费版可以添加 1 个自定义连接器，以 Claude 官方说明为准。网页版里添加的连接器，桌面版也能用。
    </Note>
  </Tab>
  <Tab title="Claude Code">
    复制下面这一句，在终端运行（也可以在 Claude Code 的输入框里先输入 `!`，再粘贴运行）：

    ```bash
    claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp && claude mcp login evolink
    ```

    浏览器会打开 EvoLink 登录页，登录后点同意。然后重新打开 Claude Code，就能直接用了。前半句添加 EvoLink，`--scope user` 让所有项目都能用；后半句完成登录。

    <Note>
    Windows PowerShell 5 不支持 `&&`，请把它换成 `;`，或者分两行运行。
    </Note>

    **想同时装上 EvoLink 技能？** 技能会教 Claude 先报价再生成。改用插件安装，在 Claude Code 里输入下面两行（如果提示运行 `/reload-plugins`，照做即可），再输入 `/mcp`，选 `evolink`，点 **Authenticate** 登录。用插件装了就不用再运行上面那一句。

    ```text
    /plugin marketplace add Evolink-AI/mcp-plugin
    /plugin install evolink@evolink
    ```
  </Tab>
  <Tab title="Codex">
    复制下面这一句，在终端运行：

    ```bash
    codex mcp add evolink --url https://mcp.evolink.ai/mcp
    ```

    Codex 会自动打开 EvoLink 登录页，登录后点同意，看到 `Successfully logged in.` 就好了。之后开一个新会话就能用。

    <Note>
    需要 Codex 0.77 或更新的版本。如果输出里提示 "may or may not require login"，或者浏览器没有打开，再运行 `codex mcp login evolink`；通过 SSH 使用时加 `--no-browser`。不用每次都运行 login，重复运行会让你再授权一次。
    </Note>

    **想直接改配置文件？** 也可以在 `~/.codex/config.toml` 里加上下面两行，再运行 `codex mcp login evolink` 登录：

    ```toml
    [mcp_servers.evolink]
    url = "https://mcp.evolink.ai/mcp"
    ```
  </Tab>
  <Tab title="Cursor">
    点 [添加到 Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9)，Cursor 会打开并请你确认安装。装好后在 Cursor 的 MCP 设置里找到 `evolink`，点 **Connect**，在浏览器登录 EvoLink 并点同意。

    也可以手动添加：在 `~/.cursor/mcp.json` 里加上下面的配置，再同样点 **Connect** 登录。

    ```json
    {
      "mcpServers": {
        "evolink": {
          "url": "https://mcp.evolink.ai/mcp"
        }
      }
    }
    ```

    <Note>
    用 Cursor 命令行（`agent`）的话，先写好上面的 `~/.cursor/mcp.json`，再运行 `agent mcp login evolink` 登录。
    </Note>
  </Tab>
  <Tab title="Hermes Agent">
    复制下面这一句，在终端运行：

    ```bash
    hermes mcp add evolink --url https://mcp.evolink.ai/mcp --auth oauth --connect-timeout 300
    ```

    浏览器会自动打开 EvoLink 登录页，登录后点同意。回到终端，问「Enable all … tools?」时直接回车。已经开着的会话输入 `/reload-mcp` 就能用，不用重启。

    <Note>
    `--auth oauth` 让 Hermes 用浏览器登录，不用填 API Key；`--connect-timeout 300` 给登录留出 5 分钟（默认只有 30 秒）。通过 SSH 使用、本机没有浏览器时，把浏览器跳转后的网址粘贴回终端即可。这一步按 Hermes 官方说明整理，我们还没逐一实测。
    </Note>
  </Tab>
  <Tab title="OpenClaw">
    在运行 OpenClaw Gateway 的机器上，复制下面这一句运行：

    ```bash
    openclaw mcp add evolink --url https://mcp.evolink.ai/mcp --transport streamable-http --auth oauth && openclaw mcp login evolink
    ```

    终端会打印一个登录链接，点开后登录 EvoLink 并点同意，看到 `MCP OAuth credentials saved for "evolink".` 就好了。不用重启，下一轮对话就能用。

    <Note>
    OpenClaw 默认按 SSE 连接远程服务，所以要写 `--transport streamable-http`。浏览器不在 Gateway 那台机器上时，回调传不回去，可以从跳转后的网址里复制 `code` 的值，再运行 `openclaw mcp login evolink --code <code>`。这一步按 OpenClaw 官方说明整理，我们还没逐一实测。
    </Note>
  </Tab>
  <Tab title="其他客户端">
    ChatGPT 等支持远程 MCP 和 OAuth 登录的客户端，一般也能用同一个地址连接。我们还没逐一测试，设置入口以各客户端的说明为准。

    1. 在客户端的 MCP 或连接器设置里添加远程服务器（Streamable HTTP），地址填 `https://mcp.evolink.ai/mcp`。
    2. 需要登录时选 OAuth，在浏览器登录 EvoLink 并点同意。
    3. 回到客户端，先查一次模型，有返回就说明连上了。
  </Tab>
</Tabs>

## 第一次连接：登录和同意

<Steps>
  <Step title="登录 EvoLink">
    浏览器打开 EvoLink 登录页。没有账号可以直接注册。
  </Step>
  <Step title="确认授权">
    同意页会写明是哪个助手（比如 Claude Code、Codex）在申请连接、连上后能做什么（查模型和价格、用您的账户运行模型、保持连接），以及您登录的是哪个 EvoLink 账户。确认无误后点 **Allow and connect**；要换账户，点 **Switch account**。
  </Step>
  <Step title="回到助手">
    浏览器提示可以回到助手，助手里显示已连接，就可以开始用了。
  </Step>
</Steps>

<Note>
同意页会标出 EvoLink 对申请连接的助手核对到了什么：Claude、Claude Code、Codex 这类公开了说明文件的助手，显示 "Published by" 加它的网站（比如 claude.ai）。Cursor 这类连接时自己登记的助手，EvoLink 没法核对名字，但授权结果只会回到您这台设备上的应用，所以页面只加一句说明，不显示警告。如果自己登记的助手要把授权结果送到某个网站，页面会显示 "Unverified"，只有连接是您自己发起的才继续。
</Note>

## 能做什么

| 工具 | 用途 | 是否收费 |
|---|---|---|
| `search_models` | 按类型和关键词找图片、视频、音频模型 | 免费 |
| `get_model` | 查看某个模型的参数和价格 | 免费 |
| `estimate_cost` | 生成之前先报价 | 免费 |
| `generate_image` | 生成图片 | 按模型价格扣费 |
| `generate_video` | 生成视频 | 按模型价格扣费 |
| `generate_audio` | 生成音乐、歌曲或语音 | 按模型价格扣费 |
| `get_task` | 查询任务进度和结果 | 免费 |
| `list_tasks` | 查看最近的任务 | 免费 |
| `check_balance` | 查看账户余额和 MCP 已花费 | 免费 |
| `upload_file` | 把公开链接或 1 MB 以内的小文件存到 EvoLink，换成可用于生成的链接 | 免费 |
| `prepare_upload` | 拿一个一次性上传地址，用来上传最大 95 MB 的本地文件 | 免费 |
| `get_upload` | 查看一次性上传的结果，拿到文件链接 | 免费 |

直接用自然语言说就行，比如"用 z-image-turbo 画一只红苹果"。助手会先报价，确认后再生成。视频和音频生成需要一些时间，助手会自动查询进度。

### 提供参考图片、视频或音频

EvoLink MCP 运行在 EvoLink 的服务器上，读不到您电脑里的文件路径。参考文件可以这样提供：

- **公开链接：** 直接把能公开访问的链接发给助手。
- **1 MB 以内的小文件：** 助手可以把文件内容直接交给 `upload_file`。
- **更大的本地文件（最大 95 MB）：** 助手先用 `prepare_upload` 拿一个一次性上传地址，再运行一条命令把文件传上去，最后用 `get_upload` 拿到文件链接。上传地址 15 分钟内有效，只能用一次。

上传不收费，文件保留 72 小时。Claude Code、Codex、Cursor 可以运行上传命令，第一次可能要您批准；Claude 网页版和桌面版一般不能运行命令，请改用公开链接或小文件。

## 费用和额度

- 费用从账户余额扣，价格和 API 相同。余额由 API、网页和 MCP 共用。
- 第一次连接（在 EvoLink 页面点同意）后，控制台的 [API Keys](https://evolink.ai/dashboard/keys) 里会多一把名为 `EvoLink MCP (OAuth)` 的 Key，名称右上角有 MCP 标记。您账户下所有通过 MCP 连接的助手共用这把 Key。这把 Key 不能复制，只在 MCP 里用；需要 API Key 的话请另外新建一把。
- 默认不设花费上限，只受账户余额限制。在 API Keys 里给这把 Key 设总额度、当日额度或过期时间，就能限制 MCP 的花费；停用这把 Key，所有助手的 MCP 就会暂停，不影响您其他的 Key。
- MCP 产生的任务、扣费和用量，在控制台照常显示，Key 名是 `EvoLink MCP (OAuth)`。

## 常见提示

助手遇到下面这些情况，会告诉您是哪一种、该怎么做：

| 提示（英文原文） | 含义 | 怎么做 |
|---|---|---|
| EvoLink MCP spending limit reached | MCP 总额度用完了，不是账户余额不足 | 在 API Keys 里调高 `EvoLink MCP (OAuth)` 的额度 |
| EvoLink MCP daily limit reached | MCP 当日额度用完了，零点重置 | 等重置，或调高当日额度 |
| Your EvoLink account balance is too low | 账户余额不足 | 到控制台充值 |
| EvoLink MCP is paused for this account | `EvoLink MCP (OAuth)` 被停用了 | 在 API Keys 里重新启用，不用重新连接 |
| EvoLink MCP key has expired | `EvoLink MCP (OAuth)` 过了您设的过期时间 | 在 API Keys 里延长或清除过期时间，不用重新连接 |
| This EvoLink connection was disconnected | 连接已断开或已过期 | 在助手里重新连接 EvoLink |
| EvoLink has temporarily turned off MCP access | EvoLink 暂时关闭了 MCP，所有用户都一样，不是您的设置问题 | 稍后再试；换模型、马上重试或重新连接都没用 |

这几种情况都不会扣费。

## 断开连接

- **只断开一个助手：** Claude 在连接器设置里断开；Claude Code 运行 `claude mcp remove evolink`（用插件装的运行 `claude plugin uninstall evolink@evolink`）；Codex 运行 `codex mcp logout evolink`；Cursor 删除配置里的 `evolink`；Hermes Agent、OpenClaw 删除配置文件（`~/.hermes/config.yaml`、`~/.openclaw/openclaw.json`）里的 `evolink`。
- **暂停所有助手：** 在 [API Keys](https://evolink.ai/dashboard/keys) 里停用 `EvoLink MCP (OAuth)`，重新启用后马上恢复，不用重新连接。
- **删除 MCP Key：** 在 API Keys 里删除 `EvoLink MCP (OAuth)`，会断开所有通过 MCP 连接的助手。之后要继续用，需要在助手里重新连接 EvoLink 并同意，系统会自动生成一把新的 MCP Key。只想暂停的话，停用即可。
