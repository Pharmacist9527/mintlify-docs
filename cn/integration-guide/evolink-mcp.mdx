## 概述

EvoLink MCP 让 AI 助手直接调用 EvoLink 的模型：查有哪些模型和价格、先报价再生成图片、视频和音频、查任务进度和账户余额。

- **服务地址：** `https://mcp.evolink.ai/mcp`
- **不需要 API Key：** 第一次使用时在浏览器里登录 EvoLink 并点同意，助手就连上了。
- **按用量扣费：** 费用从您的 EvoLink 账户余额扣，价格和 API 相同，MCP 本身不收费。

## 选择您的助手

点您正在用的助手，跳到对应的步骤。能一键添加的点一下按钮就行；不能一键添加的，复制一句命令运行；其余的按步骤手动添加。

## 一键添加

### Claude 网页版和桌面版

<Steps>
  <Step title="点一键添加">
    先在浏览器登录 claude.ai，然后点 [在 Claude 中添加 EvoLink](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp)。弹出的 **添加自定义连接器** 窗口里，名称和地址已经填好，点 **添加**。
  </Step>
  <Step title="连接并登录 EvoLink">
    在连接器列表里找到 EvoLink，点 **连接**。浏览器会打开 EvoLink 登录页，登录后点 **Allow and connect**。
  </Step>
  <Step title="在对话里打开 EvoLink">
    在对话输入框点 **+**，选 **Connectors**（连接器），打开 EvoLink；在输入框里输入 `/` 也能打开这个菜单。第一次调用 EvoLink 的工具时，Claude 会问是否允许，选 **Allow once** 或 **Always allow**。
  </Step>
</Steps>

<Note>
Claude 的 Free、Pro、Max、Team、Enterprise 都能用自定义连接器，Free 只能加 1 个。网页版里加的连接器，桌面版和手机 App 也能直接用。

**Team、Enterprise：** 由组织的 Owner 先添加：点 [管理员一键添加](https://claude.ai/admin-settings/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp)，或在 **Organization settings → Connectors** 里点 **Add → Custom**。成员再到 **Customize → Connectors** 里找到带 **Custom** 标签的 EvoLink，点 **Connect**。
</Note>

<Accordion title="链接打不开时：手动添加">
  1. 打开 Claude 的 **Customize → Connectors**（自定义 → 连接器），点 **Add custom connector**（添加自定义连接器）。
  2. 名称填 `EvoLink`，地址填 `https://mcp.evolink.ai/mcp`，点 **Continue**。
  3. 认证选 **Sign in now**；OAuth client 保持默认的 **Use Claude's published identity (Recommended)**，点 **Add**。
  4. 再按上面第 2 步点 **连接** 并登录。

  认证设置添加后不能改，要改的话删掉连接器再重新添加。
</Accordion>

### Cursor

<Steps>
  <Step title="点一键添加">
    点 [添加到 Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9)。浏览器会唤起 Cursor，Cursor 弹窗问是否安装 `evolink`，点安装。
  </Step>
  <Step title="点 Connect 登录">
    打开 Cursor 的 MCP 设置，`evolink` 旁边显示需要登录（Needs login），点 **Connect**。浏览器会打开 EvoLink 登录页，登录后点 **Allow and connect**。
  </Step>
  <Step title="确认已经连上">
    回到 Cursor，`evolink` 显示已连接并列出工具，就可以在 Agent 对话里用了。
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="手动添加：写配置文件">
    在 `~/.cursor/mcp.json` 的 `mcpServers` 里加上 `evolink` 这一项（文件里已有别的服务时，只加这一段），保存后在 MCP 设置里同样点 **Connect** 登录：

    ```json
    {
      "mcpServers": {
        "evolink": {
          "url": "https://mcp.evolink.ai/mcp"
        }
      }
    }
    ```
  </Accordion>
  <Accordion title="用 Cursor 命令行（agent）">
    先按上面写好 `~/.cursor/mcp.json`，再运行：

    ```bash
    agent mcp login evolink
    ```
  </Accordion>
  <Accordion title="点 Connect 后登录失败">
    Cursor 登录时会在本机 8787 端口等待浏览器回调。如果这个端口被别的程序占着（比如 `wrangler dev`），登录会失败。先关掉占用的程序，再点一次 **Connect**。
  </Accordion>
</AccordionGroup>

## 复制一句命令

### Claude Code

<Steps>
  <Step title="复制这一句并运行">
    在终端运行下面这一句；也可以在 Claude Code 的输入框里先输入 `!`，再粘贴运行：

    ```bash
    claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp && claude mcp login evolink
    ```

    前半句把 EvoLink 加到 Claude Code（`--scope user` 让所有项目都能用），后半句开始登录。
  </Step>
  <Step title="在浏览器登录并同意">
    浏览器会自动打开 EvoLink 登录页，登录后点 **Allow and connect**，回到终端看到登录成功的提示即可。
  </Step>
  <Step title="重新打开 Claude Code">
    重新打开 Claude Code，输入 `/mcp`，能看到 `evolink` 已连接，就可以用了。
  </Step>
</Steps>

<Tip>
如果您用 Claude 账号登录 Claude Code，并且已经在 claude.ai 加过 EvoLink 连接器，Claude Code 里也能直接用，不用再运行这句命令。两种方式选一种就行，都装会出现两套 EvoLink 工具。
</Tip>

<AccordionGroup>
  <Accordion title="想同时装上 EvoLink 技能：用插件安装">
    技能会教 Claude 先报价再生成。在 Claude Code 里输入下面两行（如果提示运行 `/reload-plugins`，照做即可），再输入 `/mcp`，选 `evolink`，点 **Authenticate** 登录。用插件装的，就不用再运行上面那一句。

    ```text
    /plugin marketplace add Evolink-AI/mcp-plugin
    /plugin install evolink@evolink
    ```
  </Accordion>
  <Accordion title="通过 SSH 使用、电脑上没有浏览器">
    把登录那半句换成下面这样，终端会打印一个授权链接。在您自己电脑的浏览器里打开它，登录并同意后，把浏览器最后跳转到的网址粘贴回终端：

    ```bash
    claude mcp login evolink --no-browser
    ```
  </Accordion>
  <Accordion title="Windows PowerShell 5">
    Windows 自带的 PowerShell 5 不支持 `&&`，请把它换成 `;`，或者分两行运行。PowerShell 7、cmd 和 WSL 可以直接用原句。
  </Accordion>
  <Accordion title="只想在某个项目里用">
    去掉 `--scope user`，EvoLink 就只在当前项目里可用；改成 `--scope project` 会写进项目的 `.mcp.json`，和团队共享。
  </Accordion>
</AccordionGroup>

### Codex

<Steps>
  <Step title="复制这一句并运行">
    ```bash
    codex mcp add evolink --url https://mcp.evolink.ai/mcp
    ```
  </Step>
  <Step title="在浏览器登录并同意">
    Codex 发现 EvoLink 需要登录，会自动打开 EvoLink 登录页。登录后点 **Allow and connect**，终端显示 `Successfully logged in.` 就好了。
  </Step>
  <Step title="开一个新会话">
    在新的 Codex 会话里就能用。运行 `codex mcp list` 可以看到 `evolink`。
  </Step>
</Steps>

<Warning>
不要在这一句后面再接 `codex mcp login evolink`：添加时已经登录过一次，再运行 login 会让您再授权一遍。只有输出提示 "may or may not require login"，或者浏览器没有打开时，才需要单独运行 login。
</Warning>

<AccordionGroup>
  <Accordion title="浏览器没有打开，或提示 may or may not require login">
    ```bash
    codex mcp login evolink
    ```

    通过 SSH 使用、电脑上没有浏览器时，加上 `--no-browser`，把打印的链接复制到您自己电脑的浏览器里打开。
  </Accordion>
  <Accordion title="提示不认识命令：Codex 版本太旧">
    需要 Codex 0.77 或更新的版本，请先把 Codex 升级到最新版。
  </Accordion>
  <Accordion title="想直接改配置文件">
    在 `~/.codex/config.toml` 里加上下面两行，再运行 `codex mcp login evolink` 登录：

    ```toml
    [mcp_servers.evolink]
    url = "https://mcp.evolink.ai/mcp"
    ```
  </Accordion>
  <Accordion title="Codex IDE 插件和 ChatGPT 桌面应用">
    在它们的 MCP 设置里手动添加：选 **Add server** → **Streamable HTTP**，地址填 `https://mcp.evolink.ai/mcp`，保存后重启，再在需要登录时点 **Authenticate**。
  </Accordion>
</AccordionGroup>

### Hermes Agent

<Tabs>
  <Tab title="命令行：复制一句命令">
    <Steps>
      <Step title="复制这一句并运行">
        ```bash
        hermes mcp add evolink --url https://mcp.evolink.ai/mcp --auth oauth --connect-timeout 300
        ```
      </Step>
      <Step title="在浏览器登录并同意">
        浏览器会自动打开 EvoLink 登录页，登录后点 **Allow and connect**。
      </Step>
      <Step title="启用工具">
        回到终端，问「Enable all … tools?」时直接按回车。已经开着的会话输入 `/reload-mcp` 就能用，不用重启。
      </Step>
    </Steps>
  </Tab>
  <Tab title="桌面版：一键添加">
    <Steps>
      <Step title="点一键添加">
        点 [添加到 Hermes](hermes://mcp/install?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCIsImF1dGgiOiJvYXV0aCJ9)，Hermes 桌面版会弹窗确认，点确认保存。
      </Step>
      <Step title="授权登录">
        在桌面版的 MCP 设置里找到 `evolink`，点 **Authorize**，在浏览器登录 EvoLink 并点 **Allow and connect**。
      </Step>
    </Steps>
  </Tab>
</Tabs>

<AccordionGroup>
  <Accordion title="为什么要加 --auth oauth 和 --connect-timeout 300">
    `--auth oauth` 让 Hermes 用浏览器登录，不加的话它会让您填 API Key。`--connect-timeout 300` 给登录留出 5 分钟；默认只有 30 秒，来不及登录就会超时。
  </Accordion>
  <Accordion title="通过 SSH 使用、电脑上没有浏览器">
    终端会同时打印授权链接。在您自己电脑的浏览器里打开它，登录并同意后，把浏览器最后跳转到的网址粘贴回终端。Hermes 的设备码登录（`--flow device`）目前不能用于 EvoLink。
  </Accordion>
  <Accordion title="想直接改配置文件">
    在 `~/.hermes/config.yaml` 的 `mcp_servers` 下加上 `evolink` 这一项，再运行 `hermes mcp login evolink` 登录：

    ```yaml
    mcp_servers:
      evolink:
        url: "https://mcp.evolink.ai/mcp"
        auth: oauth
    ```
  </Accordion>
</AccordionGroup>

<Note>
这些步骤按 Hermes Agent 官方文档整理，我们还没逐一实测。
</Note>

### OpenClaw

<Steps>
  <Step title="复制这一句，在 Gateway 所在的机器上运行">
    ```bash
    openclaw mcp add evolink --url https://mcp.evolink.ai/mcp --transport streamable-http --auth oauth && openclaw mcp login evolink
    ```
  </Step>
  <Step title="打开登录链接">
    终端会打印一个登录链接（不会自动打开浏览器），点开后登录 EvoLink 并点 **Allow and connect**。
  </Step>
  <Step title="看到保存成功的提示">
    终端显示 `MCP OAuth credentials saved for "evolink".` 就好了。不用重启，下一轮对话就能用。
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="浏览器不在 Gateway 那台机器上">
    回调会传不回去。从浏览器最后跳转到的网址里复制 `code` 的值，再运行：

    ```bash
    openclaw mcp login evolink --code <code>
    ```
  </Accordion>
  <Accordion title="为什么要写 --transport streamable-http">
    OpenClaw 默认用 SSE 连接远程服务，EvoLink 用的是 Streamable HTTP，不写就连不上。
  </Accordion>
  <Accordion title="检查连接">
    ```bash
    openclaw mcp doctor evolink --probe
    ```
  </Accordion>
  <Accordion title="想直接改配置文件">
    在 `~/.openclaw/openclaw.json` 的 `mcp.servers` 下加上 `evolink` 这一项，再运行 `openclaw mcp login evolink` 登录：

    ```json
    {
      "mcp": {
        "servers": {
          "evolink": {
            "url": "https://mcp.evolink.ai/mcp",
            "transport": "streamable-http",
            "auth": "oauth"
          }
        }
      }
    }
    ```
  </Accordion>
</AccordionGroup>

## 按步骤添加

### ChatGPT

<Steps>
  <Step title="新建自定义 MCP 服务器">
    打开 [ChatGPT 插件页](https://chatgpt.com/plugins)，点 **+**，选 **Create custom MCP server**。
  </Step>
  <Step title="填写连接信息">
    名称填 `EvoLink`；**Server URL** 填 `https://mcp.evolink.ai/mcp`；认证选 **OAuth**，注册方式保持默认。勾选 **I understand and want to continue**，点 **Create as a plugin**。
  </Step>
  <Step title="安装并登录">
    在 [个人插件页](https://chatgpt.com/plugins?view=personal) 打开 EvoLink，点 **+** 安装。提示登录时点 **Connect**，在浏览器登录 EvoLink 并点 **Allow and connect**。
  </Step>
  <Step title="在对话里用">
    在输入框输入 `@`，选 EvoLink，就可以让 ChatGPT 调用它。
  </Step>
</Steps>

<Note>
目前只能在 ChatGPT 网页版创建，需要付费套餐；Business、Enterprise、Edu 工作区要先由管理员开放 **Create custom MCP servers** 权限。不同套餐能不能用生成这类写操作工具，以 OpenAI 的说明为准。ChatGPT 的界面名称变化较快，这些步骤我们还没逐一实测。
</Note>

<Accordion title="ChatGPT 桌面应用">
  打开 **Settings → MCP servers**，点 **Add server**，选 **Streamable HTTP**，地址填 `https://mcp.evolink.ai/mcp`，保存后在需要登录时点 **Authenticate**。同意页上显示申请连接的是 Codex，这是正常的。
</Accordion>

### 其他客户端

支持远程 MCP 的客户端，一般都能用同一个地址连接。添加时填这几项：

| 项目 | 填什么 |
|---|---|
| 名称 | `EvoLink`（或 `evolink`） |
| 服务地址 | `https://mcp.evolink.ai/mcp` |
| 传输方式 | Streamable HTTP（有的客户端叫 HTTP） |
| 认证 | OAuth；Client ID、Client Secret 都留空，客户端会自动登记 |

很多客户端用 JSON 配置文件，常见的两种写法：

<CodeGroup>
```json mcpServers 写法
{
  "mcpServers": {
    "evolink": {
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

```json servers 写法
{
  "servers": {
    "evolink": {
      "type": "http",
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```
</CodeGroup>

保存后按客户端的提示登录：浏览器会打开 EvoLink 登录页，登录后点 **Allow and connect**。

<Accordion title="客户端只支持本地（stdio）MCP：用 mcp-remote 转接">
  用开源工具 [mcp-remote](https://github.com/geelen/mcp-remote) 把远程服务转成本地进程，需要 Node.js 18 或更新的版本：

  ```json
  {
    "mcpServers": {
      "evolink": {
        "command": "npx",
        "args": ["-y", "mcp-remote@latest", "https://mcp.evolink.ai/mcp", "--transport", "http-only"]
      }
    }
  }
  ```

  第一次启动会打开浏览器让您登录 EvoLink，同意页上申请连接的名字会显示为 "MCP CLI Proxy"。登录信息保存在 `~/.mcp-auth`，想重新登录就删掉这个文件夹。这种方式我们还没逐一实测。
</Accordion>

## 第一次连接：登录和同意

<Steps>
  <Step title="登录 EvoLink">
    浏览器打开 EvoLink 登录页。没有账号可以直接注册。
  </Step>
  <Step title="确认授权">
    同意页会写明是哪个助手（比如 Claude Code、Codex）在申请连接、连上后能做什么（查模型和价格、用您的账户运行模型、保持连接），以及您登录的是哪个 EvoLink 账户。确认无误后点 **Allow and connect**；要换账户，点 **Switch account**。
  </Step>
  <Step title="回到助手">
    浏览器提示可以回到助手，助手里显示已连接，就可以开始用了。
  </Step>
</Steps>

<Note>
同意页会标出 EvoLink 对申请连接的助手核对到了什么：Claude、Claude Code、Codex、ChatGPT、Hermes Agent 命令行这类公开了说明文件的助手，显示 "Published by" 加它的网站（比如 claude.ai、chatgpt.com）。Cursor、OpenClaw 这类连接时自己登记的助手，EvoLink 没法核对名字，但授权结果只会回到您这台设备上的应用，所以页面只加一句说明，不显示警告。如果自己登记的助手要把授权结果送到某个网站，页面会显示 "Unverified"，只有连接是您自己发起的才继续。
</Note>

## 确认已经连上

在助手里发一句话试试。下面两句都只是查询，不扣费：

```text
用 EvoLink 查一下我的账户余额。
```

```text
用 EvoLink 找 3 个能生成视频的模型，告诉我价格。
```

助手调用了 EvoLink 的工具并给出结果，就说明连上了。第一次调用时，有的助手会先问您是否允许使用这个工具，点允许即可。

助手说找不到 EvoLink 时，先看看连接状态：

| 助手 | 怎么看 |
|---|---|
| Claude 网页版和桌面版 | **Customize → Connectors** 里 EvoLink 显示已连接，并且在对话里点 **+ → Connectors** 打开了 |
| Cursor | MCP 设置里 `evolink` 显示已连接 |
| Claude Code | 输入 `/mcp`，`evolink` 显示已连接 |
| Codex | 运行 `codex mcp list` |
| Hermes Agent | 在会话里输入 `/reload-mcp` |
| OpenClaw | 运行 `openclaw mcp doctor evolink --probe` |
| ChatGPT | 在输入框输入 `@`，能选到 EvoLink |

## 能做什么

| 工具 | 用途 | 是否收费 |
|---|---|---|
| `search_models` | 按类型和关键词找图片、视频、音频模型 | 免费 |
| `get_model` | 查看某个模型的参数和价格 | 免费 |
| `estimate_cost` | 生成之前先报价 | 免费 |
| `generate_image` | 生成图片 | 按模型价格扣费 |
| `generate_video` | 生成视频 | 按模型价格扣费 |
| `generate_audio` | 生成音乐、歌曲或语音 | 按模型价格扣费 |
| `get_task` | 查询任务进度和结果 | 免费 |
| `list_tasks` | 查看最近的任务 | 免费 |
| `check_balance` | 查看账户余额和 MCP 已花费 | 免费 |
| `upload_file` | 把公开链接或 1 MB 以内的小文件存到 EvoLink，换成可用于生成的链接 | 免费 |
| `prepare_upload` | 拿一个一次性上传地址，用来上传最大 95 MB 的本地文件 | 免费 |
| `get_upload` | 查看一次性上传的结果，拿到文件链接 | 免费 |

直接用自然语言说就行，比如"用 z-image-turbo 画一只红苹果"。助手会先报价，确认后再生成。视频和音频生成需要一些时间，助手会自动查询进度。

### 提供参考图片、视频或音频

EvoLink MCP 运行在 EvoLink 的服务器上，读不到您电脑里的文件路径。参考文件可以这样提供：

- **公开链接：** 直接把能公开访问的链接发给助手。
- **1 MB 以内的小文件：** 助手可以把文件内容直接交给 `upload_file`。
- **更大的本地文件（最大 95 MB）：** 助手先用 `prepare_upload` 拿一个一次性上传地址，再运行一条命令把文件传上去，最后用 `get_upload` 拿到文件链接。上传地址 15 分钟内有效，只能用一次。

上传不收费，文件保留 72 小时。Claude Code、Codex、Cursor 可以运行上传命令，第一次可能要您批准；Claude 网页版和桌面版一般不能运行命令，请改用公开链接或小文件。

## 任务进度和结果

- **视频和音频**要生成一段时间，助手会自动查询进度，您不用一直盯着。
- **中途断开了**（比如关掉了窗口），回来后对助手说"用 EvoLink 查一下我最近的任务"，它会用 `list_tasks` 找到刚才的任务，再用 `get_task` 接着查。
- **不要让助手重新生成**同一个任务来"刷新"进度，那会再扣一次费。
- **结果链接 24 小时后失效**，拿到后请及时下载保存。上传的参考文件保留 72 小时，和结果链接是两回事。

## 费用和额度

- 费用从账户余额扣，价格和 API 相同。余额由 API、网页和 MCP 共用。
- 第一次连接（在 EvoLink 页面点同意）后，控制台的 [API Keys](https://evolink.ai/dashboard/keys) 里会多一把名为 `EvoLink MCP (OAuth)` 的 Key，名称右上角有 MCP 标记。您账户下所有通过 MCP 连接的助手共用这把 Key。这把 Key 不能复制，只在 MCP 里用；需要 API Key 的话请另外新建一把。
- 默认不设花费上限，只受账户余额限制。在 API Keys 里给这把 Key 设总额度、当日额度或过期时间，就能限制 MCP 的花费；停用这把 Key，所有助手的 MCP 就会暂停，不影响您其他的 Key。
- MCP 产生的任务、扣费和用量，在控制台照常显示，Key 名是 `EvoLink MCP (OAuth)`。

## 常见提示

助手遇到下面这些情况，会告诉您是哪一种、该怎么做：

| 提示（英文原文） | 含义 | 怎么做 |
|---|---|---|
| EvoLink MCP spending limit reached | MCP 总额度用完了，不是账户余额不足 | 在 API Keys 里调高 `EvoLink MCP (OAuth)` 的额度 |
| EvoLink MCP daily limit reached | MCP 当日额度用完了，零点重置 | 等重置，或调高当日额度 |
| Your EvoLink account balance is too low | 账户余额不足 | 到控制台充值 |
| EvoLink MCP is paused for this account | `EvoLink MCP (OAuth)` 被停用了 | 在 API Keys 里重新启用，不用重新连接 |
| EvoLink MCP key has expired | `EvoLink MCP (OAuth)` 过了您设的过期时间 | 在 API Keys 里延长或清除过期时间，不用重新连接 |
| This EvoLink connection was disconnected | 连接已断开或已过期 | 在助手里重新连接 EvoLink |
| EvoLink has temporarily turned off MCP access | EvoLink 暂时关闭了 MCP，所有用户都一样，不是您的设置问题 | 稍后再试；换模型、马上重试或重新连接都没用 |

这几种情况都不会扣费。

## 断开连接

- **只断开一个助手：** Claude 在连接器设置里断开；Claude Code 运行 `claude mcp remove evolink`（用插件装的运行 `claude plugin uninstall evolink@evolink`）；Codex 运行 `codex mcp logout evolink`；Cursor 在 MCP 设置里删除 `evolink`；ChatGPT 在插件页里移除 EvoLink；Hermes Agent、OpenClaw 删除配置文件（`~/.hermes/config.yaml`、`~/.openclaw/openclaw.json`）里的 `evolink`。
- **暂停所有助手：** 在 [API Keys](https://evolink.ai/dashboard/keys) 里停用 `EvoLink MCP (OAuth)`，重新启用后马上恢复，不用重新连接。
- **删除 MCP Key：** 在 API Keys 里删除 `EvoLink MCP (OAuth)`，会断开所有通过 MCP 连接的助手。之后要继续用，需要在助手里重新连接 EvoLink 并同意，系统会自动生成一把新的 MCP Key。只想暂停的话，停用即可。
