## 概述

手动配置需要安装客户端、修改配置文件、填写接口地址和 API Key。一键配置脚本（`evolink-config`）把这些步骤合成一条命令：

- 检查环境，电脑上还没有客户端时帮您安装
- 写入 EvoLink 的接口地址和您的 API Key
- 发一条测试消息，确认可以正常调用
- 改动前自动备份，随时可以用一条命令撤销

整个过程通常不到一分钟。

| 客户端 | 一键配置 |
|---|---|
| Claude Code CLI | 支持 |
| Codex CLI | 支持 |
| 其他客户端 | 请参考「AI 编程工具」中的手动教程 |

<Note>
目前提供 macOS 和 Linux 的命令。Windows 请先按 [Claude Code CLI](/cn/integration-guide/claude-code-cli) 或 [Codex CLI](/cn/integration-guide/codex-cli) 的教程手动配置。
</Note>

## 使用前准备

- **EvoLink API Key**：登录 [EvoLink 控制台](https://evolink.ai/dashboard)，在 API Keys 中创建并复制。Key 以 `sk-` 开头。
- **Node.js**：建议 22 或更高版本（最低 18）。在终端运行 `node -v` 查看版本。没有安装时，请从 [Node.js 官方网站](https://nodejs.org/) 下载 LTS 版本。

## 配置 Claude Code

在终端中运行：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash
```

脚本会一步一步提示您：

<Steps>
  <Step title="检查环境">
    检查 Node.js 和 Claude Code。如果电脑上还没有 Claude Code，脚本会询问“现在安装？”，按回车即可自动安装。
  </Step>
  <Step title="粘贴 API Key">
    粘贴您的 EvoLink API Key 后按回车。输入的内容不会显示在屏幕上。脚本会在线检查 Key 是否有效，并显示账户余额。
  </Step>
  <Step title="选择模型">
    选择 Claude Code 默认使用的模型。之后可以在 Claude Code 中输入 `/model` 随时更换。
  </Step>
  <Step title="确认改动">
    脚本会列出将要修改的文件和内容。确认无误后按回车写入。
  </Step>
  <Step title="写入并验证">
    写入配置后，脚本会发一条测试消息（费用约 0.01 积分）。返回正常就表示配置完成。
  </Step>
</Steps>

配置完成后，打开一个新的终端窗口，运行：

```bash
claude
```

进入后输入 `/status`。如果 Anthropic base URL 显示的是 EvoLink 的地址，就说明配置已经生效。

## 配置 Codex CLI

在终端中运行：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- codex
```

步骤与上面相同。配置完成后，用下面的命令启动 Codex：

```bash
codex -p evolink
```

<Note>
脚本会为 Codex 新建一份独立的配置档 `~/.codex/evolink.config.toml`，不会修改您原来的 `~/.codex/config.toml`。带上 `-p evolink` 才会使用 EvoLink；直接运行 `codex` 仍然是您原来的设置。
</Note>

## 脚本会改动哪些文件

### Claude Code

| 文件 | 改动 |
|---|---|
| `~/.claude/settings.json` | 写入接口地址 `ANTHROPIC_BASE_URL` 和您的 Key `ANTHROPIC_AUTH_TOKEN`；把 `ANTHROPIC_API_KEY` 置空，避免电脑里残留的旧 Key 导致 401；指定 Sonnet 使用的模型版本；关闭自动模式（原因见下方常见问题）。其余配置保持不变。 |
| `~/.claude.json` | 跳过首次启动时的登录引导；经您同意后，把当前文件夹设为已信任。 |

### Codex CLI

| 文件 | 改动 |
|---|---|
| `~/.codex/evolink.config.toml` | 新建。包含 EvoLink 的接口地址、默认模型和您的 Key，只有您本人可以读取。 |
| `~/.codex/config.toml` | 不修改。 |

### 共同说明

- 改动前的文件都会备份到 `~/.evolink/backups/`。
- 脚本自身保存在 `~/.evolink/` 目录，启动命令是 `~/.evolink/bin/evolink-config`，不会修改您的 PATH 或 shell 配置文件。
- 您的 Key 只保存在本机的配置文件中，只会发送给 EvoLink 的接口。

<Note>
`evolink-config` 只负责配置接口。它和用来生成图片、视频、音频的 `evolink` 命令行工具（见 CLI/MCP 栏目）是两个不同的工具，可以同时使用。
</Note>

## 检查、撤销和重新配置

### 先看会改什么（不写入）

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --dry-run
```

### 检查当前配置

```bash
~/.evolink/bin/evolink-config doctor
```

输出中的 Key 会自动隐去，可以直接发给客服。Codex 请使用 `~/.evolink/bin/evolink-config doctor codex`。

### 撤销配置

```bash
~/.evolink/bin/evolink-config reset
```

脚本会把它改过的内容恢复原样。Codex 请使用 `~/.evolink/bin/evolink-config reset codex`。

### 更换 Key 或默认模型

重新运行一次配置命令即可。

## 常见问题

### 1. 提示没有找到 Node.js 怎么办？

请从 [Node.js 官方网站](https://nodejs.org/) 安装 LTS 版本，然后重新打开终端，再运行一次配置命令。

### 2. 我已经手动配置过，原来的配置会被覆盖吗？

不会整个覆盖。脚本只修改上面列出的几项，其余配置保持不变。写入前会显示每一项的新旧内容，并备份原文件。

### 3. 为什么 Claude Code 里没有自动模式（auto mode）？

在自动模式下，Claude Code 不再逐条询问您，而是在执行命令前先发送一次审核请求，由模型判断这条命令是否安全。这些审核请求同样按 token 计费，使用的模型是 `claude-sonnet-5`，与您选择的默认模型无关。

为了避免产生您没有预期的费用，脚本默认关闭自动模式，Claude Code 会在执行命令前先询问您。配置完成时，脚本也会提示这一点。

如果您需要自动模式，可以这样开启：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --auto-mode
```

想再关闭时，重新运行一次不带 `--auto-mode` 的配置命令即可。

### 4. 我想先查看脚本内容再运行，可以吗？

可以。先下载，查看后再运行：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh -o setup.sh
less setup.sh
bash setup.sh
```

### 5. 提示“请求太频繁（429）”怎么办？

同一个账户在一分钟内检查 Key 的次数有上限。短时间内反复运行脚本，就会出现这个提示。请按提示里的秒数等待，然后再运行一次。

### 6. 配置完成后仍然无法使用怎么办？

运行 `~/.evolink/bin/evolink-config doctor`，把输出发给客服。也可以参考 [Claude Code CLI](/cn/integration-guide/claude-code-cli) 和 [Codex CLI](/cn/integration-guide/codex-cli) 页面中的排错部分。
