为已完成且属于当前账户的 Suno 歌曲获取逐词起止时间，适用于播放器高亮和歌词视频。本接口返回逐词数据，不提供独立的逐行时间戳。

## 如何使用这两个ID

由 [任务详情](/cn/api-manual/task-management/get-task-detail) 获取：source_task_id 使用 EvoLink 音乐生成任务的 id；result_id 使用该任务 result_data 中所选歌曲的 result_id。同一次生成返回的不同歌曲分别处理，不需要重新生成歌曲。

## 已有歌曲与支持范围

首次获取要求源歌曲仍可由原生成账号查询。已生成歌曲可以尝试，但不保证所有历史歌曲或超过14天的歌曲可取回；生成文件的保留期不等于时间戳可查询期限。纯音乐没有可对齐歌词。时间戳可能受漏词、重复副歌和演唱变化影响，制作成片前应核对音频。

## 处理中与结果未知

收到202后，按Retry-After等待，再使用相同source_task_id和result_id提交到本接口。处理中或结果核对中不会自动重新发起上游请求。即使首次HTTP响应丢失，也可以用相同两个ID找回操作。普通GET /v1/tasks/{id}查询的是音乐生成任务，不查询这个时间戳操作。

upstream_unknown表示首次请求的结果仍在核对，不代表已经明确失败。服务会在有限核对窗口内收口；无法确认结果时退还冻结费用，并保留终态。普通重复提交不会重新购买；不要通过更换Idempotency-Key尝试再次收费。

## 收费与重复查询

同一账户对同一 source_task_id + result_id 重复提交，读取已有操作的最新状态或已保存结果，不会因为更换 API Key 或 Idempotency-Key 再次购买。API Key 必须仍有效且有权限。完成结果可在支持的保留期限内免费复读，余额为零也可读取已购结果。首次成功取得并保存符合交付标准的对齐数据后按单首歌曲收费；明确失败、纯音乐或无可用对齐数据不收费，已冻结费用退还。首版不交付部分或无效的歌词对齐，返回alignment_unavailable且不收费。

## 请求限制

请求体必须是只包含source_task_id和result_id的单个JSON对象，不接受额外字段或尾随JSON；总大小最多4096字节。两个ID均不能为空或带前后空白；source_task_id最多50个UTF-8字节，result_id最多128个UTF-8字节。

202响应的status为preparing、calling、upstream_unknown、awaiting_settlement或refund_pending，并返回Retry-After: 2；使用相同两个ID复查最新状态。completed返回200和words；failed、unknown_refunded返回422和error。每个操作响应均包含operation_id、source_task_id、result_id、cached、billing_status。资金状态为not_charged、reserved、refunded或paid，应以billing_status判断是否已冻结、扣费或退还。操作尚未建立时的错误响应只包含error。

## 支持的歌词参考与交付检查

此Beta仅支持创建时使用custom_mode=true、且提供并保留了自定义歌词的已完成歌曲。自动生成歌词的模式，以及没有保留原自定义歌词的歌曲暂不支持。首次获取须先核实原生成账号、所选歌曲及有效音频时长，再开始付费对齐请求。缺少原歌词参考时返回422/source_lyrics_unavailable；无法核实音频时长时返回503/source_metadata_unavailable。这两种情况均在付费对齐请求前拒绝，不收费。

收费并交付前，所有歌词片段都须有位于已核实时长内的有效时间，返回歌词还须按顺序完整覆盖创建时保留的自定义歌词；忽略分词、空白和标点差异。章节标签可保留在words中，不作为缺失的实唱歌词。缺词、额外词、覆盖不全或时间畸形均返回alignment_unavailable并退还冻结费用。此检查比对的是返回文本与保留歌词，不证明每个时间戳都与实唱吻合；真实V6对齐质量仍需试听实测。
