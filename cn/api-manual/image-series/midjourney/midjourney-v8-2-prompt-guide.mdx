## 参数总览

| 参数 | 写法 | 类型 | 取值范围 | 默认值 | 说明 |
|------|------|------|---------|--------|------|
| 宽高比 | `--ar W:H` | 整数比 | 任意正整数比 | 1:1 | 图像宽高比 |
| 混沌 | `--c N` | int | 0 - 100 | 0 | 生成结果的多样性 |
| 种子 | `--seed N` | int | 0 - 4294967295 | 随机 | 固定种子可复现结果 |
| 风格化 | `--s N` | int | 0 - 1000 | 100 | 艺术风格强度 |
| 实验参数 | `--exp N` | int | 0 - 100 | 0 | 美学效果，可与风格化叠加 |
| 原始模式 | `--raw` | 标志 | — | 关闭 | 禁用默认美化 |
| 图像权重 | `--iw N` | float | 0 - 3 | 1 | 垫图影响力 |
| 风格参考 | `--sref [URL]` | URL | — | — | 匹配视觉风格 |
| 风格权重 | `--sw N` | int | 0 - 1000 | 100 | 风格参考强度 |
| 平铺 | `--tile` | 标志 | — | 关 | 生成无缝重复图案 |
| 怪异 | `--weird N` / `--w N` | int | 0 - 3000 | 0 | 非常规、实验性的美学效果 |

<Note>
以下三项设置**不**写在 prompt 里，而是通过 API 参数控制（写在 prompt 中无效，会被剥离）：

- **速度**（`draft` / `fast` / `turbo`）→ `model_params.speed`
- **输出质量**（`standard` / `hd`）→ 顶层 `quality` 参数
- **精细度**（`1` – `4`）→ `model_params.detail`

`--v` / `--version` 固定为 V8.2，不支持 `--niji`。详见下文[速度模式](#速度模式)、[输出质量](#输出质量)与[精细度等级](#精细度等级)。
</Note>

## 基础参数

### 宽高比 `--ar`

设置图像的宽高比，仅支持整数比。

```
一只猫 --ar 16:9
```

常见值：`1:1`、`4:3`、`3:2`、`16:9`、`9:16`、`2:3`。极端比例可能产生不可预测的结果。

### 混沌 `--chaos` / `--c`

控制生成结果的多样性。值越高，4 张图之间差异越大。

```
一只猫 --c 50
```

| 范围 | 效果 |
|------|------|
| 0 | 4 张图非常相似（默认） |
| 1-50 | 适度多样性 |
| 50-100 | 高度随机，适合创意探索 |

### 风格化 `--stylize` / `--s`

调节写实与艺术之间的平衡。

```
一只猫 --s 500
```

| 范围 | 效果 |
|------|------|
| 0-250 | 写实风格，忠实于提示词 |
| 250-750 | 平衡 |
| 750-1000 | 强烈艺术性，大胆色彩构图 |

### 实验参数 `--exp`

与 `--stylize` 类似但可叠加，生成更详细、动态、创意的图像。

```
一只猫 --exp 25
```

- 推荐值：5、10、25、50、100
- 5-50 效果变化明显，50-100 变化较小
- 超过 25-50 时可能覆盖 `--stylize` 的效果

### 原始模式 `--raw`

禁用默认美化，更严格地遵循提示词细节。适用于追求真实感或精确控制的场景。

```
产品照片 --raw
```

### 种子 `--seed`

固定初始随机状态，用于对比测试。

```
一只猫 --seed 23453422
```

- 范围：0 - 4294967295
- 相同种子 + 相同提示词 → 相似（非完全相同）的结果

## 图像引用参数

### 图像提示（垫图）

在提示词**开头**放置图片 URL，用图片影响生成内容。

```
https://example.com/ref.jpg 文本描述 --iw 1.5
```

**有效组合规则：**

| 组合方式 | 是否有效 |
|---------|---------|
| 1 张图 + 无文字 | 无效（会报错） |
| 1 张图 + 文字描述 | 有效 |
| 2+ 张图 + 无文字 | 有效 |
| 2+ 张图 + 文字描述 | 有效 |

- 最多 20 张垫图
- 支持格式：`.png`、`.gif`、`.webp`、`.jpg`、`.jpeg`
- 不支持 `draft` 速度（请改用 `fast`）

### 图像权重 `--iw`

控制垫图对结果的影响力。范围 0 - 3，默认 1，值越高越接近参考图。

```
https://example.com/ref.jpg 水彩风景 --iw 2.0
```

### 风格参考 `--sref`

匹配参考图的视觉风格（颜色、纹理、光照），不复制内容。**必须配合文本提示词使用**。

```
一只猫 --sref https://example.com/style.jpg
```

- 支持多张：`--sref URL1 URL2`
- 支持随机风格：`--sref random`（生成后返回数字代码，可重用）
- 最多 20 个 sref

### 风格权重 `--sw`

控制风格参考的影响程度。范围 0 - 1000，默认 100。

```
一只猫 --sref https://example.com/style.jpg --sw 500
```

## 速度模式

速度模式通过 API 的 `model_params.speed` 字段控制（请勿在提示词中写 `--draft` / `--fast`）。

| 模式 | 说明 | 费用 |
|------|------|------|
| `draft` | 单次运行返回 24 张轻量级 0.5K 草图。**仅限生图接口** | 与 fast 同倍率 |
| `fast` | 标准模式（默认），每次生成 4 张图 | 标准 |
| `turbo` | 极速模式，生成更快，每次生成 4 张图 | 2 倍 |

<Note>
与 V7 不同，V8.2 的 `draft` 模式**不**减半收费——它与 `fast` 使用相同倍率。草图模式单次运行返回 24 张小图，挑出喜欢的再以完整质量重跑。草图模式不能与 `hd` 质量组合使用。
</Note>

## 输出质量

输出分辨率通过顶层 `quality` 参数控制，**而非**提示词标志。请勿在提示词中写 `--hd`。

| 值 | 分辨率 | 费用 |
|----|--------|------|
| `standard` | 标准分辨率（默认） | 1 倍 |
| `hd` | 原生 2K 高清输出 | 1.5 倍 |

- 质量倍率与速度倍率是**相乘**关系。
- `hd` 与 `draft` 速度**不兼容**。

## 精细度等级

精细度通过 API 的 `model_params.detail` 字段控制，**不是** prompt 标志。请勿在 prompt 中书写 `--q` / `--quality`。

| 取值 | 说明 | 费用 |
|------|------|------|
| `1` | 默认精细度 | 1 倍 |
| `2` – `4` | 细节逐级更丰富，渲染时间更长 | 1 倍（不加价） |

- 对应 Midjourney 原生 `--quality N`；V8.2 接受 1 / 2 / 3 / 4（V8.1 仅接受 1 / 4）。
- 仅生图接口可用；派生任务继承源图。
- 精细度**不改变**价格。

## 依赖关系

以下参数必须搭配其他参数才能生效：

| 参数 | 前置依赖 |
|------|---------|
| `--sw` | 需要 `--sref` |
| `--iw` | 需要图像提示（垫图） |
| `--sref` | 需要文本提示词 |
| 单张垫图 | 需要文本提示词 |

---

## 冲突关系

| 参数 A | 参数 B | 说明 |
|--------|--------|------|
| `draft` 速度 | `hd` 质量 | 草图模式不能与 HD 组合 |
| `draft` 速度 | 图像提示 / `--sref` | 图像引用需要 `fast` |
| 纯图像提示 | `--stylize` / `--exp` | 无文字时不兼容 |
| `--exp` > 25 | `--stylize` | 高 `--exp` 可能压制 `--stylize`；组合使用时请调低 `--exp` |

## V8.2 不支持的参数

V8.2 只剥离会破坏版本锁定或计费的标志，**其余标志一律原样透传给上游**。若上游不支持某个标志，任务会失败并返回上游的报错原文，预扣积分全额退还——不会再静默丢弃。

| 参数 | 处理方式 |
|------|----------|
| `--v` / `--version` / `--niji` | 剥离——版本固定为 V8.2 |
| `--fast` / `--turbo` / `--draft` / `--relax` | 剥离——请使用 `model_params.speed` |
| `--hd` | 剥离——请使用顶层 `quality` 参数 |
| `--bs` / `--batchsize` | 剥离——批量张数不可配置 |
| `--q` / `--quality` | 剥离——请使用 `model_params.detail` |
| `--oref` / `--ow` | 上游拒绝（V8.2 不支持） |
| `--cref` / `--cw` | 上游拒绝（V8.2 不支持） |
| `--stop` | 上游拒绝 |
| 多提示词 `::` | 上游拒绝 |
| `--sv` | 仅接受 `--sv 6`，且须与 `--sref` 搭配 |
| `--repeat` / `--r`、`{}` 排列组合、`--stealth` / `--public` | API 不支持 |

## 提示词格式规范

### 基本结构

```
[图片URL] 文本描述 --参数1 值1 --参数2 值2
```

### 书写规则

- 参数放在文本提示**末尾**
- `--` 前必须有**空格**
- 参数中不使用标点符号
- 参数后面不能再写文本

### 示例

<CodeGroup>
```text 正确
a yellow Persian cat --ar 1:2 --s 500
```

```text 错误
a yellow Persian cat--ar 2:3          ← --前缺空格
a yellow Persian cat - - ar 2:3       ← --间有空格
a yellow Persian cat --ar 2:3, --s 50 ← 参数中有标点
a yellow Persian cat --ar 2:3 more description ← 参数后有文本
```
</CodeGroup>

## 内容审核说明

<Note>
Midjourney 内置内容审核机制。如果生成的部分图像触发了审核过滤，该次请求已消耗的积分将无法退还，请留意提示词的内容合规性。
</Note>
