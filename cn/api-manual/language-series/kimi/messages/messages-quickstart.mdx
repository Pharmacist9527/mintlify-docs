<Note>
**BaseURL 说明**：默认 BaseURL 为 `https://direct.evolink.ai`，对文本模型支持更好，支持长连接；`https://api.evolink.ai` 是多模态主力地址，对文本模型作为备用地址使用。
</Note>

<Note>
**Kimi 系列始终开启思考**，响应 `content` 里通常会带 `type="thinking"` 块，这部分计入 output token。因此 `max_tokens` 不宜设得过小，否则思考阶段可能耗尽输出预算，导致响应中没有正文。
</Note>
