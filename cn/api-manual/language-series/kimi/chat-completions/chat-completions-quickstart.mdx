<Note>
**BaseURL 说明**：默认 BaseURL 为 `https://direct.evolink.ai`，对文本模型支持更好，支持长连接；`https://api.evolink.ai` 是多模态主力地址，对文本模型作为备用地址使用。
</Note>

<Note>
**Kimi 系列始终开启思考**，推理内容通过 `reasoning_content` 返回，思考 Token 计入输出。手动设置 `max_completion_tokens` 时不宜过小，否则思考阶段可能耗尽输出预算，导致响应中没有正文。
</Note>
