<Note>
**BaseURL 说明**：默认 BaseURL 为 `https://direct.evolink.ai`，对文本模型支持更好，支持长连接；`https://api.evolink.ai` 是多模态主力地址，对文本模型作为备用地址使用。
</Note>

使用 `POST /v1/responses`，通过 `model` 选择 `kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed` 或 `kimi-k3`。最少需要 `model` 和 `input`。

<Warning>
**参数名称与 Chat Completions 不同**：输入使用 `input`，输出上限使用 `max_output_tokens`，思考强度使用 `reasoning.effort`。
</Warning>

## 读取正文

响应的 `output` 可能同时包含推理、正文和工具调用。遍历 `type="message"` 中的 `output_text` 内容块，不要假设第一项就是正文。

假设已将响应 JSON 解析为 `response`，可以这样提取文本：

```python
text = "".join(
    part["text"]
    for item in response.get("output", [])
    if item.get("type") == "message"
    for part in item.get("content", [])
    if part.get("type") == "output_text"
)
print(text)
```

<Note>
**为思考预留输出预算**：`max_output_tokens` 包含思考与正文。若 `status="incomplete"` 且 `incomplete_details.reason="max_output_tokens"`，请调高上限；预算耗尽时可能只有推理项，没有正文。
</Note>
