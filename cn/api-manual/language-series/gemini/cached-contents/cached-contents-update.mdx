---
title: "Gemini 显式上下文缓存 - 延长或缩短有效期"
openapi: '/cn/api-manual/language-series/gemini/cached-contents/cached-contents.json PATCH /v1beta/cachedContents/{id}'
---

<Note>
只能改有效期，不能改内容。请求体给 `ttl`（从**现在**起算的新有效期，如 `"7200s"`）或 `expireTime`（新的绝对到期时间，也可写作 `expire_time`）之一；新到期时间距现在最短 60 秒、最长 168 小时。
</Note>

- 请求体只接受 `ttl` 或 `expireTime`，两者同时传入、或传入 `contents`、`displayName` 等其它字段，都返回 400 并指出字段名。
- **延长**补收新增时长的存储费：新增时长（按秒计，不足 1 秒按 1 秒）× 缓存 token 数 × 缓存存储单价（每百万 token 每小时）。**缩短**不退已收的存储费。
- 这是付费操作：Key 需要有该模型的使用权限（与生成请求使用同一套白名单），按该 Key 当前所在用户组的价格计费；余额不足返回 402 `INSUFFICIENT_QUOTA`。
- 已过期或已删除的缓存不能再延长，返回 404 `CACHE_NOT_FOUND`。
- 同一条延长请求网络超时后重试，可带相同的 `Idempotency-Key` 请求头，避免重复扣费。
- 延长的扣费记录同样能在控制台「日志」页按缓存 id 搜到。
- 概念、计费与错误码见 [创建缓存](/cn/api-manual/language-series/gemini/cached-contents/cached-contents-create)。
