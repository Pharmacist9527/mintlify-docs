<Note>
**BaseURL 说明**：默认 BaseURL 为 `https://direct.evolink.ai`，对文本模型支持更好，支持长连接；`https://api.evolink.ai` 为备用地址。
</Note>

把会被反复使用的长前缀（长文档、系统指令、工具定义）创建成缓存，之后的生成请求只带缓存名和新问题。命中缓存的部分按缓存命中单价计费；缓存存在期间按 token 数和时长收取存储费。

## 支持的模型

| 系列 | 模型 |
|---|---|
| Gemini 3.x Flash | `gemini-3.8-flash`、`gemini-3.7-flash`、`gemini-3.6-flash`、`gemini-3.5-flash`、`gemini-3-flash-preview` |
| Gemini 3.x Flash-Lite | `gemini-3.5-flash-lite`、`gemini-3.1-flash-lite-preview` |
| Gemini 3.x Pro | `gemini-3.1-pro-preview`、`gemini-3.1-pro-preview-customtools`、`gemini-3-pro-preview` |

Gemini 4 系列不支持显式缓存，创建时返回 400 `EXPLICIT_CACHE_UNSUPPORTED`。

## 显式缓存与隐式缓存

| | 隐式缓存（默认） | 显式缓存（本页） |
|---|---|---|
| 使用方式 | 无需改动，前缀相同的请求可能自动命中 | 先创建缓存，生成请求中引用缓存名 |
| 是否命中 | 不保证 | 引用即命中 |
| 缓存写入费 | 无 | 按缓存 token 数收取 |
| 缓存存储费 | 无 | 按缓存 token 数 × 小时收取 |
| 适合场景 | 零改造、自然复用 | 同一长前缀在一段时间内被大量调用 |

## 使用流程

1. **创建**：`POST /v1beta/cachedContents`，把长前缀放进 `contents`、`systemInstruction` 或 `tools`（至少一项），返回缓存名 `name`。
2. **引用**：生成请求 `POST /v1beta/models/{model}:generateContent`（流式为 `streamGenerateContent`）的请求体加上 `"cachedContent": "<name>"`，`contents` 中只放新问题。
3. **延长**（可选）：还需要继续使用时，`PATCH /v1beta/cachedContents/{id}` 传入新的 `ttl` 或 `expireTime`，按新增时长补收存储费。
4. **删除**（可选）：不再使用时 `DELETE /v1beta/cachedContents/{id}`。不删除也会在到期后自动清除，已收的存储费不退。

缓存属于账号：同一账号下的任何 API Key 都可以引用（Key 设置了模型白名单时需包含该模型），其它账号使用该缓存名返回 404。引用和延长按发起请求的 Key 当前所在用户组的价格计费。

## 在生成请求中引用缓存

```bash
curl -X POST "https://direct.evolink.ai/v1beta/models/gemini-3.8-flash:generateContent" \
  -H "Authorization: Bearer $EVOLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "cachedContent": "cachedContents/20261103012026348092000s1oTuB96",
    "contents": [
      { "role": "user", "parts": [{ "text": "手册里退货政策是怎么规定的？" }] }
    ]
  }'
```

响应中的 `usageMetadata.cachedContentTokenCount` 是本次命中缓存的 token 数，按缓存命中单价计费；`promptTokenCount` 包含这部分，其余按常规输入单价计费。

```json
{
  "candidates": [
    { "content": { "role": "model", "parts": [{ "text": "手册第 7 章规定……" }] }, "finishReason": "STOP" }
  ],
  "usageMetadata": {
    "promptTokenCount": 7541,
    "cachedContentTokenCount": 7525,
    "candidatesTokenCount": 212,
    "totalTokenCount": 7753
  },
  "modelVersion": "gemini-3.8-flash"
}
```

<Warning>
引用缓存的生成请求中**不能再携带** `systemInstruction`、`tools`、`toolConfig`，这些内容需要在创建缓存时写入，携带时请求返回 400。生成请求的模型需与创建缓存时的模型一致，否则返回 400 `CACHE_MODEL_MISMATCH`。
</Warning>

## 完整示例（Python）

```python
import requests

BASE = "https://direct.evolink.ai"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json"}

# 1. 创建缓存：长文档 + 系统指令，保留 1 小时
manual = open("manual.txt", encoding="utf-8").read()   # 需达到模型的最小缓存 token 数
cache = requests.post(f"{BASE}/v1beta/cachedContents", headers=HEADERS, json={
    "model": "models/gemini-3.8-flash",
    "displayName": "product-manual-v3",
    "systemInstruction": {"parts": [{"text": "你是产品手册助手，只依据手册内容回答。"}]},
    "contents": [{"role": "user", "parts": [{"text": manual}]}],
    "ttl": "3600s",
}).json()
name = cache["name"]            # cachedContents/<id>
cache_id = name.split("/")[-1]  # <id>
print("cached tokens:", cache["usageMetadata"]["totalTokenCount"], "expire:", cache["expireTime"])

# 2. 多次引用：每次只发新问题
for question in ["退货政策是什么？", "保修期多久？", "海外能不能寄修？"]:
    resp = requests.post(f"{BASE}/v1beta/models/gemini-3.8-flash:generateContent", headers=HEADERS, json={
        "cachedContent": name,
        "contents": [{"role": "user", "parts": [{"text": question}]}],
    }).json()
    print(resp["candidates"][0]["content"]["parts"][0]["text"])
    print("cache hit tokens:", resp["usageMetadata"].get("cachedContentTokenCount", 0))

# 3. 还要继续使用：从现在起再保留 2 小时（按新增时长补收存储费）
requests.patch(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS, json={"ttl": "7200s"})

# 4. 用完删除（已收的存储费不退）
requests.delete(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS)
```

## 计费

| 项目 | 计费方式 |
|---|---|
| 缓存写入 | 缓存 token 数 × 缓存写入单价，创建时收取。写入单价与该模型的输入单价相同；Pro 系列缓存超过 20 万 token 时按长上下文单价 |
| 缓存存储 | 缓存 token 数 × 有效期（小时，按秒折算）× 缓存存储单价（每百万 token 每小时），创建时按整个有效期一次收取 |
| 引用缓存生成 | `cachedContentTokenCount` 按缓存命中单价；其余输入与输出按常规单价。缓存中声明了 `googleSearch` 时，每次搜索按搜索单价另计 |
| 延长有效期 | 按新增时长补收存储费，不足 1 秒按 1 秒计 |
| 缩短有效期 / 删除 / 到期 | 已收的存储费不退 |
| 查询列表 / 查询单个 | 免费 |

- 缓存 token 数以创建响应中的 `usageMetadata.totalTokenCount` 为准。
- 缓存名中的 `<id>` 就是创建请求的请求 ID：在控制台「日志」页按它搜索，可以看到创建和延长的扣费明细（缓存 token 数、存储时长与存储费）。
- 各模型的缓存写入、缓存命中、缓存存储单价见 [价格页](https://evolink.ai/pricing)。
- 是否划算：存储费按时长收取，命中按次节省。同一前缀在有效期内被调用的次数越多越划算；只用一两次时，直接发送原文更便宜。

## 限制

- **有效期**：最短 60 秒，最长 168 小时（`604800s`）；`ttl` 与 `expireTime` 只能给一个，都不填默认 1 小时。
- **内容**：`contents`、`systemInstruction`、`tools` 至少提供一项；单次创建请求体不超过 10 MB；缓存内容需达到模型要求的最小 token 数（如 `gemini-3.8-flash` 为 4,096 token），不足时返回 400。
- **字段**：请求体只接受本页列出的字段，传入其它字段返回 400 并指出字段名。
- **tools**：只接受 `googleSearch`、`codeExecution`、`functionDeclarations`。
- **不可修改**：缓存内容创建后不能修改，只能调整有效期；需要更换内容时请重新创建。
- **访问控制**：创建和延长与普通生成请求一样，受 Key 的 IP 白名单、模型白名单和频率限制约束。

## 错误码

错误响应为 Gemini 原生格式，`error.details[0].reason` 为具体原因码：

```json
{
  "error": {
    "code": 404,
    "message": "cached content not found",
    "status": "NOT_FOUND",
    "details": [{ "@type": "type.googleapis.com/google.rpc.ErrorInfo", "reason": "CACHE_NOT_FOUND", "domain": "evolink.ai" }]
  }
}
```

| HTTP | reason | 含义 |
|---|---|---|
| 400 | `INVALID_ARGUMENT` | 参数错误：没有可缓存的内容、`ttl` 超出 60 秒 ～ 168 小时、`ttl` 与 `expireTime` 同时传入、传入了不支持的字段、`tools` 不在支持范围内等 |
| 400 | `EXPLICIT_CACHE_UNSUPPORTED` | 该模型不支持显式缓存（Gemini 4 系列、图像模型） |
| 400 | `NO_AVAILABLE_CHANNEL` | 当前用户组暂不支持为该模型创建缓存 |
| 400 | `MODEL_PRICE_ERROR` | 该模型在当前用户组暂未开放显式缓存 |
| 400 | `CACHE_EXPIRED` | 缓存在请求处理过程中到期，或剩余有效期过短 |
| 400 | `CACHE_MODEL_MISMATCH` | 生成请求的模型与缓存的模型不一致 |
| 400 | `INVALID_CACHED_CONTENT` | `cachedContent` 格式不正确 |
| 4xx | `UPSTREAM_ERROR` | 请求内容不被模型接受，`message` 中说明具体原因，常见为缓存内容少于最小 token 数 |
| 402 | `INSUFFICIENT_QUOTA` | 余额不足以支付缓存写入费和存储费 |
| 403 | — | Key 无权使用该模型、来源 IP 不在 Key 的白名单内，或 Key 所在的用户组已不可用 |
| 404 | `CACHE_NOT_FOUND` | 缓存不存在、已过期、已删除或不属于当前账号 |
| 404 | `EXPLICIT_CACHE_DISABLED` | 显式缓存功能暂未开放 |
| 413 | `CACHE_CONTENT_TOO_LARGE` | 请求体超过 10 MB |
| 502 | `UPSTREAM_ERROR` | 服务暂时不可用，本次不扣费，请稍后重试 |
| 503 | `CACHE_CHANNEL_UNAVAILABLE` | 缓存暂时不可用，请稍后重试 |
| 503 | `INTERNAL` | 服务暂时不可用，请稍后重试 |
