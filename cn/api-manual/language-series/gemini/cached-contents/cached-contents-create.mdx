<Note>
**BaseURL 说明**：默认 BaseURL 为 `https://direct.evolink.ai`，对文本模型支持更好，支持长连接；`https://api.evolink.ai` 是多模态主力地址，对文本模型作为备用地址使用。
</Note>

<Note>
**显式上下文缓存**：把反复使用的长前缀（长文档、系统指令、工具定义）创建为缓存，之后的生成请求只带缓存名和新问题。命中部分按缓存命中单价计费；另收缓存写入费和按时长计的存储费，存储费在创建时按有效期一次收取，不退。
</Note>

<Tip>
**引用缓存**：在 `generateContent` 或 `streamGenerateContent` 的请求体中加入 `"cachedContent": "<name>"`，`contents` 只放新问题。引用缓存的请求不能再携带 `systemInstruction`、`tools`、`toolConfig`，模型需与创建缓存时一致。
</Tip>
