<Note>
**BaseURL 说明**：默认 BaseURL 为 `https://direct.evolink.ai`，对文本模型支持更好，支持长连接；`https://api.evolink.ai` 是多模态主力地址，对文本模型作为备用地址使用。
</Note>

<Note>
**GPT-6 Astra** 可以在 Chat Completions 中使用函数工具，但必须设置 `reasoning_effort: "none"`。如需同时保留推理能力，请使用 Responses 接口。
</Note>
