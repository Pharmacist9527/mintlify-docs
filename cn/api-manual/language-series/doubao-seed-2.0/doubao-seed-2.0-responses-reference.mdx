## 生成一小时有效的缓存请求

发送前运行以下 Python 代码，将输出的 JSON 作为请求体。首次请求无需设置环境变量。续接时，将 `PREVIOUS_RESPONSE_ID` 设为上一轮实际返回的 `id`，再运行一次。每次都会重新计算 `expire_at`。

```python
import json
import os
import time

body = {
    "model": "doubao-seed-2-1-pro",
    "input": "产品手册：电机和电池均保修两年。请记住这条保修政策。",
    "caching": {"type": "enabled"},
    "expire_at": int(time.time()) + 3600,
}
previous_id = os.getenv("PREVIOUS_RESPONSE_ID")
if previous_id:
    body["previous_response_id"] = previous_id
    body["input"] = "哪些部件在保修范围内？"
print(json.dumps(body, ensure_ascii=False))
```
