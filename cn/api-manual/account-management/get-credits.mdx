## 限流与重试

限额可能按账户、路径、模型和用户组生效；同一账户的多个 API Key 可能共享账户限额。QPS 与 RPM 属于不同时间窗口，应以账户生效配置及 429 响应为准，不能假定所有接口使用同一固定值。requests-limit 响应头可能表示分钟额度，不能直接当作 QPS。缓存 /v1/models，合并初始化时的重复获取；按余额新鲜度需求短时缓存 /v1/credits。收到 HTTP 429 时遵循 Retry-After，采用带随机退避和次数上限的重试，避免多实例同时重试。申请核查限额时提供请求时间、路径和请求 ID。生成接口与任务查询接口分别核对。
