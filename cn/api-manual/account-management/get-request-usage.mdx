---
title: "查询请求花费"
description: "按 Request ID 查询同步接口调用（主要是文本模型）的状态、用量和实际花费"
openapi: /cn/api-manual/account-management/get-request-usage.json GET /v1/requests/{request_id}
---

<Note>
本接口用于查询**同步接口调用**的花费，主要适用于**文本模型**，例如 Chat Completions、Messages、Responses 等接口。

Request ID 取原请求响应头 `X-Request-Id` 的值。请求完成后稍等片刻即可查询；异步任务请使用 [查询任务状态](/cn/api-manual/task-management/get-task-detail)。
</Note>
