[CLI/MCP 总览](/cn/cli-mcp/overview)可以按客户端选择入口；模型费用、任务素材和 Agent 资料集中在同一栏目的共用资料。

EvoLink CLI 让能执行终端命令的 Agent 和普通终端用户生成图片、视频、音乐与语音，查询模型、参数、余额和任务，并上传素材、保存原件。

本栏目以已发布 **CLI 0.9.0** 为参考。需要 Node.js 22+，支持 macOS、Windows 与 Linux；安装在 Agent 实际执行命令的机器和用户环境中。媒体业务直接走 **Agent／终端 → CLI → 平台 API**。

## 安装与验证

把下面整段发给能执行命令的 Agent，与官网安装提示词一致：

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 安装 CLI：运行 `npm install -g @evolinkai/cli`。
2. 完成登录：运行 `evolink auth login`。
3. 安装配套技能：运行 `evolink skills install`。
4. 验证连接，成功后告诉我可以开始了。
```

提示词放在对话框，命令由 Agent 或您在终端执行。浏览器登录和权限确认由您完成。详细步骤、成功标志、更新、退出及远程 SSH 登录见[安装与登录](/cn/cli/setup)。

手动安装的基本顺序是：

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
evolink doctor --json
```

登录命令必须等待完成再执行下一步；不要一次粘贴整块后忽略授权。让 Agent 确认已经读取 evolink-cli 技能。余额和诊断不会创建付费媒体任务，验证通过后再开始创作。

## CLI 能做什么

| 能力 | 用法与详细说明 |
|---|---|
| 环境与连接 | version、auth、setup、doctor，见[安装指南](/cn/cli/setup) |
| 模型与参数 | models search/recommend/show/schema、docs search，见[命令参考](/cn/cli/reference) |
| 报价与确认 | estimate 创建本地报价，用户批准后 generate，见[完整流程](/cn/cli/workflows) |
| 三媒体生成 | 图片、视频、音乐或语音，按模型能力选择参数 |
| 素材 | upload 本地文件，uploads get 查询原回执 |
| 任务 | get/wait、batch、分页历史和原报价恢复 |
| 原件下载 | 单项或全部结果、格式检查、批量恢复 |
| 账户与用量 | balance、有限历史 usage，不是完整账单 |
| Agent 技能 | skills install/status 与宿主发现检查 |

CLI 不提供通用文本聊天、取消排队、充值、Key 管理、自动剪辑或成片托管。代码开发和任意文件编辑属于 Agent 自身能力。平台生成完成后先交付原件；新变体、重新生成或编辑需要相应批准。

## 第一次创作

```text
用 EvoLink 做一张咖啡品牌广告图。
先查询可用图片模型、参数与费用，展示推荐理由和输出规格。
等我明确确认后只提交一次，保存任务编号，完成后下载原图并报告已返回的实际费用。
```

完整步骤按[模型 → 素材 → 报价 → 确认 → 任务 → 下载](/cn/cli/workflows)执行。安装成功不代表已经批准付费生成；估价不等于最终结算，边界见[费用与排错](/cn/cli/billing)。

## CLI 与 MCP 的关系

CLI 安装包含命令程序、共享业务模块和随包 evolink-cli 技能，不会要求克隆 MCP 或插件仓库，也不会自动注册原生 MCP。OAuth 登录使用 Passport；本地凭据由系统安全存储管理。

CLI 与远程 MCP 的会话分别管理，同账户 OAuth 当前共享内部 Key 的权限、额度和暂停设置。网页 Claude、ChatGPT 或想使用原生工具的客户端，请看[独立 MCP 栏目](/cn/mcp/overview)。
