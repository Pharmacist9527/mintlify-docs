Cursor 可通过 EvoLink CLI 执行媒体任务。本页说明当前客户端的环境与技能差异，通用安装集中在[安装与登录](/cn/cli/setup)。需要原生 MCP 工具时，直接按[对应 MCP 指南](/cn/mcp/cursor)配置。

## 让 Agent 帮您安装

把下面整段发到 Agent 对话框，与官网提示词一致。浏览器登录和权限确认由您完成。

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 安装 CLI：运行 `npm install -g @evolinkai/cli`。
2. 完成登录：运行 `evolink auth login`。
3. 安装配套技能：运行 `evolink skills install`。
4. 验证连接，成功后告诉我可以开始了。
```

## 当前客户端的三步设置

<Steps>
  <Step title="先完成通用安装与登录">
    在当前工作区的实际终端中安装；Remote SSH、WSL 和容器需在远端安装，并允许 Agent 执行命令。

    第一次安装请打开[通用五步指南](/cn/cli/setup#cli-install)，依次检查 Node.js 22+、安装 CLI、完成浏览器登录。每步都有命令、成功标志与排错入口。已完成时直接核对：

    ```bash
    evolink --version
    evolink auth status --json
    ```

    成功标志是显示 CLI 版本且 authenticated 为 true。命令找不到见[安装排错](/cn/cli/billing#cli-install)，登录未完成见[登录排错](/cn/cli/billing#login)，SSH 用户先看[回调转发](/cn/cli/setup#ssh-login)。
  </Step>
  <Step title="同步当前 Agent 的技能并确认读取">
    ```bash
    evolink skills install --agent cursor
    evolink skills status --agent cursor --json
    ```

    技能目录是 ~/.agents/skills/evolink-cli。current 为 true 表示文件匹配当前 CLI；回到 Agent 对话，发送：

    ```text
    请确认当前会话能发现并读取 evolink-cli 技能。先验证连接，不要生成媒体。
    ```

    assistant_discovery: not_checked 仍需要宿主确认加载。文件存在但不会调用时，按[技能发现](/cn/cli/billing#skills-discovery)刷新；宿主要求命令许可时审核所需操作。不要覆盖个人修改。
  </Step>
  <Step title="免费验证并开始使用">
    ```bash
    evolink balance --json
    evolink doctor --agent cursor --json
    ```

    余额返回账户数据，doctor 的 ok、connection_verified、model_discovery_verified 为 true，并且 Agent 确认读取技能，才算设置完成。这些查询不创建付费媒体任务；余额为零仍可验证连接。
  </Step>
</Steps>

### 已安装 CLI 的组合设置

```bash
evolink setup --agent cursor --json
```

该命令检查环境、同步技能、按需登录并验证，成功看 setup_complete: true；宿主技能发现仍需确认。失败看 phase、steps、error 和 recovery，再处理对应步骤。

## 更新与退出

更新 CLI 后同步当前客户端的技能，执行：

```bash
npm install -g @evolinkai/cli@latest
evolink --version
evolink skills install --agent cursor
evolink skills status --agent cursor --json
```

个人修改默认保留，`modified` 或 `conflict` 按[技能排错](/cn/cli/billing#skills-discovery)处理。需要退出 CLI 时单独运行下面命令；这是退出操作，不属于安装或更新步骤。

```bash
evolink auth logout
```

## 遇到问题时从这里开始

| 现象 | 对应步骤 |
|---|---|
| 找不到 npm/evolink、权限不足、安装超时 | [检查运行环境与安装](/cn/cli/billing#cli-install) |
| 浏览器未打开、授权超时、凭据存储报错 | [登录与回调](/cn/cli/billing#login)；远端看 [SSH 登录](/cn/cli/setup#ssh-login) |
| 技能已安装，Agent 仍不会调用 | [技能发现与宿主执行权限](/cn/cli/billing#skills-discovery) |
| 已提交但等待超时、结果丢失 | [恢复原任务](/cn/cli/billing#tasks-and-recovery) |

连接成功后，按[首次创作流程](/cn/cli/workflows#workflows)提出需求，先查模型、参数与费用，确认后提交。完整命令集中在[CLI 命令参考](/cn/cli/reference)。
