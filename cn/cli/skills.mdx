## CLI 技能的安装与管理

本页集中说明 evolink-cli 的安装目标、目录、宿主加载与更新。技能范围、CLI／MCP／插件的区别和共同规则见[共用资料](/cn/cli-mcp/agent-resources)。

## 安装与验证加载

```bash
evolink skills install
evolink skills status --json
```

默认覆盖支持的目标目录，不替您安装这些 Agent。只用一个宿主时可指定：

```bash
evolink skills install --agent codex
evolink skills status --agent codex --json
evolink doctor --agent codex --json
```

检查 `current: true`，然后在 Agent 对话发送：

```text
请确认当前会话能发现并读取 evolink-cli 技能。先查询余额和模型，不生成媒体。
```

`assistant_discovery: not_checked` 表示 CLI 不能代替宿主确认加载。文件正确但 Agent 不调用时，刷新技能或新开会话，并确认宿主允许所需命令执行。不能靠“读过文档”来判断连接已成功。

## 支持的目标和目录

| --agent 值 | 客户端 | 目录 |
|---|---|---|
| codex | Codex | ~/.agents/skills/evolink-cli |
| claude-code | Claude Code | ~/.claude/skills/evolink-cli |
| cursor | Cursor | ~/.agents/skills/evolink-cli |
| openclaw | OpenClaw | ~/.openclaw/skills/evolink-cli |
| hermes | Hermes | ~/.hermes/skills/evolink-cli |
| gemini | Gemini CLI | ~/.agents/skills/evolink-cli |
| opencode | OpenCode | ~/.agents/skills/evolink-cli |
| copilot | GitHub Copilot CLI | ~/.agents/skills/evolink-cli |

Gemini、OpenCode、Copilot 可按[通用五步安装](/cn/cli/setup#cli-install)，将上面 Codex 示例中的 agent 改成自己的值。SSH、WSL、容器和远端 Gateway 必须在真实执行环境安装。表格表示安装目标，不保证每个宿主版本自动发现同一目录；组织策略和技能加载方式按宿主管理。

## 更新与个人修改

```bash
npm install -g @evolinkai/cli@latest
evolink skills install
evolink skills status --json
```

升级程序后同步技能，并让 Agent 重新读取。默认保留个人修改。`modified` 或 `conflict` 时先核对现有内容；明确决定替换后才使用 `--replace-modified`，旧内容备份到 `~/.evolink-media/skill-backups/`。具体排错见[技能加载](/cn/cli/billing#skills-discovery)。
