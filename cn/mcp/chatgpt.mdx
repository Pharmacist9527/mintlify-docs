ChatGPT 网页版使用远程 MCP，不要求在电脑上安装 EvoLink CLI。EvoLink 服务地址：

```text
https://mcp.evolink.ai/mcp
```

## 通过插件页添加

<Steps>
  <Step title="创建自定义 MCP 服务器">
    打开 [ChatGPT Plugins](https://chatgpt.com/plugins)，选择添加按钮，再选 **Add custom MCP server**。入口名称可能随版本或界面语言变化。
  </Step>
  <Step title="填写连接">
    名称填 `EvoLink`，Connection 选择 Server URL，填上面的完整地址。Authentication 选 **OAuth**，高级 OAuth Client ID / Secret 保持默认，不填个人 API Key。
  </Step>
  <Step title="创建、连接并登录">
    阅读提示后创建为插件，找到刚创建的 EvoLink 并安装/连接。浏览器打开 EvoLink 同意页，由您登录并确认账户、批准连接。
  </Step>
  <Step title="启用并免费验证">
    在新对话中输入 `@` 选择 EvoLink，请它调用 `check_balance` 查询账户余额。返回真实余额才说明连接可用。
  </Step>
</Steps>

这些步骤依据 [OpenAI 的自定义 MCP 说明](https://developers.openai.com/api/docs/guides/custom-mcp-server)。本文是自定义连接流程，不代表 EvoLink 已在 ChatGPT 公共插件目录审核上架。

## 手动接入：开发者模式界面

如果您的账户仍显示旧版开发者模式入口：在 **Settings → Apps**（部分界面称 Connectors）中开启可用的开发者模式/高级设置，再选择创建自定义应用，填写同一个服务器 URL 和 OAuth，完成连接。

这个入口及读写权限由 OpenAI 的账户和工作区设置决定。能查询模型或余额，不一定表示生成工具已开放；确认 `generate_image`、`generate_video`、`generate_audio` 实际可用。没有创建入口或只有只读工具时，应先检查账户/工作区权限，不通过换认证方式绕过。以您的当前界面和官方说明为准。

## 第一项任务

```text
用 EvoLink 做一张白底咖啡杯产品图。先查模型、参数和本次费用，
等我明确确认后生成，完成后给我原图链接和实际扣费。
```

ChatGPT 的工具审批与任务费用确认是两回事。媒体生成费用来自 EvoLink 账户，不是 ChatGPT 模型额度。

## 附件、预览和桌面端

网页附件不一定能被远程模型读取，请提供公开链接，详见[参考素材](/cn/mcp/files)。MCP 可以提供小预览，但 ChatGPT 决定是否显示；灰框时先验证原图是否可打开，再查询原任务，不自动重做。

桌面端和不同套餐的创建入口、工具读写与图片显示需分别核对；本页以网页连接为主，不宣称所有客户端都已完整实测。排查见[任务结果](/cn/mcp/tasks)和[常见问题](/cn/mcp/troubleshooting)。
