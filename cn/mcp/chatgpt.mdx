ChatGPT 聊天客户端使用 **远程 MCP**。本页操作在客户端设置和浏览器中完成，不需要安装本地 CLI 或提供个人 API Key。

## 开始前准备

准备可登录的 EvoLink 账户与 ChatGPT 账户，以及允许添加自定义 MCP 的客户端版本、套餐和工作区权限。没有添加入口时先确认宿主权限，不要在聊天框执行 npm。

## 按顺序连接 EvoLink

<Steps>

<Step title="打开自定义 MCP 入口">

打开 [ChatGPT Plugins](https://chatgpt.com/plugins)，点“添加”或加号 → **Create/Add custom MCP server（创建自定义 MCP 服务器）**。这是官网介绍页使用的入口。界面名称可能随版本变化；没有入口时查看工作区权限。

</Step>

<Step title="填写连接信息">

| 字段 | 填写内容 |
|---|---|
| Icon / 头像（可选） | 下载 [EvoLink 图标](https://cdn.evolink.ai/next/evolink-logo.png) 后上传；表单没有这一项时跳过 |
| Name / 名称 | EvoLink |
| Connection / 连接 | Server URL |
| Server URL | `https://mcp.evolink.ai/mcp` |
| Authentication / 认证 | OAuth |
| Client ID / Client Secret | 保持默认，不手工填平台 API Key |

使用远程 HTTP 连接，核对完整 URL，末尾包含 `/mcp`。按页面要求查看并确认连接提示，选择 **Create as a plugin**。

</Step>

<Step title="安装并授权账户">

在个人插件列表打开 EvoLink 并安装/连接。宿主请求认证时，在浏览器登录 EvoLink，核对账户与权限并同意。保持原页面和登录流程运行，完成后返回 ChatGPT。创建配置与安装插件是两个步骤；授权按钮的出现时机以当前界面为准。

</Step>

<Step title="在对话启用并验证">

安装后新开对话，输入 `@` 并选择 EvoLink。当前界面若有 Chat / Work 页签，按插件使用方式切到 **Work** 再新开对话。发送下一节的免费验证提示词。

**成功标志**：实际返回账户余额与可用模型，而不是仅告诉您“已经连接”。

</Step>

</Steps>

步骤与 [OpenAI 自定义 MCP 说明](https://developers.openai.com/api/docs/guides/custom-mcp-server)和[插件快速开始](https://developers.openai.com/plugins/quickstart)对齐。创建个人连接不代表 EvoLink 已在公共目录上架。

## 免费验证与第一次创作

连接完成后，把下面提示词发到已启用 EvoLink 的对话：

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

确认助手调用 `check_balance` 与 `search_models`。登录与这些查询不创建付费媒体任务。生成前描述内容与规格，让助手先给方案、模型、参数和报价，您明确确认后才提交。完整例子见[首次创作](/cn/mcp/overview#workflows)。

参考素材可使用模型支持的公开文件链接。聊天附件未必能让 MCP 读取原始文件；远程服务不能读取电脑路径。上传步骤见[素材说明](/cn/mcp/overview#files)。

## 常见问题

| 现象 | 按顺序处理 |
|---|---|
| 没有自定义连接入口 | 核对套餐、版本和工作区权限；按当前宿主的设置办理 |
| 登录后仍提示未授权 | 返回原客户端完成连接，使用当前登录流程；见[授权排错](/cn/mcp/billing#login) |
| 已添加但对话没有工具 | 确认安装/启用、选择 EvoLink、新开对话；见[MCP 排错](/cn/mcp/billing#mcp-connection) |
| 能查余额但生成工具不可用 | 在宿主查看生成工具开关与工作区权限，不改用 Key 绕过 |
| 网络超时或 403 | 核对错误发生在宿主、登录页还是工具请求；保留时间与错误交给支持排查 |
| 已生成但只有链接或灰色缩略图 | 打开并保存原件；见[下载与预览排错](/cn/mcp/billing#download) |

## 更新与断开

工具变更后，在客户端刷新连接与工具列表，必要时新开对话。授权过期则通过当前宿主重新认证。要停止此客户端访问，在它自己的设置断开/退出连接；共享 Key 暂停与额度在 EvoLink 控制台管理。插件区别见[插件指南](/cn/mcp/plugins)，统一费用和更多问题见[费用与排错](/cn/mcp/billing#faq)。
