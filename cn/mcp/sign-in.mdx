## 浏览器登录

从智能体的 MCP 连接流程，或 `evolink auth login` 发起。浏览器打开 EvoLink 登录页；没有账户可先注册。核对同意页的账户和申请连接的客户端，再点 **允许并连接**。

需要换账户时，使用同意页的 **切换账户**。不想授权可以取消。完成后返回智能体，通过 MCP `check_balance` 或 CLI `evolink balance --json` 验证，都是免费操作。

连接授权使客户端可以使用工具，不代表批准每次付费生成；每次任务仍需先报价并明确确认，见[授权与安全](/cn/mcp/security)。

## 核对客户端

有些客户端公开了 OAuth 身份说明文件，同意页可以显示其发布网站。Codex 和 ChatGPT 的说明文件都可能来自 `chatgpt.com`，这不代表连错了产品。

客户端自行登记的名称不一定能独立验证；页面可能说明这是应用登记的名字，或提示未验证。请确认这次连接确实由您发起，并核对返回目标，不要因为图标或名字熟悉就批准陌生链接。

CLI 和原生 MCP 是独立登录。CLI 完成登录后，不会自动添加 `codex mcp` 或其他客户端的原生工具配置。

## 同意页语言

有七语言切换入口的同意页支持英语、中文、德语、法语、西班牙语、日语和韩语。手动切换会保留当前授权事务，不需要重新开始登录。

自动选择按以下顺序：明确的语言路径或 `ui_locales`，同一官网域名保存的 `EVOLINK_LOCALE` 偏好，浏览器 `Accept-Language`，最后英语。固定的 `/en` 授权入口还会检查偏好；明确选英语时使用 `ui_locales=en`。

官网标签页不是直接被读取的：用户在网站切换语言后，同域名 Cookie 可让下一次同意页采用这个偏好。隐私模式、不同浏览器或不同域名不一定共享偏好。没有可用偏好时使用浏览器请求头，识别不到支持语言则用英语。未更新到语言切换版本的部署可能仅按浏览器识别。

## 请求失效

授权同意事务约 10 分钟有效，客户端可能更早停止等待。CLI 本地回调等待约 3 分钟。看到失效或超时提示时，回到发起登录的客户端重新开始，不复用旧链接。

SSH 环境里，浏览器回调必须到达发起登录的机器；CLI 的端口转发步骤见[安装与登录](/cn/mcp/cli)。不要把回调 code 或令牌发进聊天。

## 换账户与退出

| 方式 | 操作 |
|---|---|
| CLI | `evolink auth logout` 后重新 `evolink auth login` |
| Codex 原生 MCP | `codex mcp logout evolink`，重新连接或登录 |
| Claude、ChatGPT、Cursor 等 | 在对应连接器或 MCP 设置中断开，再连接 |

删除配置、卸载技能或关闭窗口不一定撤销服务器上的登录。需要退出时使用客户端的退出/断开功能；需要暂停账户下的 OAuth 媒体调用时，在控制台停用 `EvoLink MCP (OAuth)`。更改额度不会替您批准新任务。
