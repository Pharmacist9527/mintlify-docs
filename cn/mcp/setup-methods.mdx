## 先选接入方式

| 方式 | 适合谁 | 安装与认证 |
|---|---|---|
| CLI 与技能 | 能运行终端的 Codex、Claude Code、Cursor、OpenClaw、Hermes 等 | 安装 `@evolinkai/cli`，浏览器 OAuth，安装 `evolink-cli` 技能 |
| 远程 MCP | Claude、ChatGPT 网页版，或希望直接使用 MCP 工具的客户端 | 添加 `https://mcp.evolink.ai/mcp`，浏览器 OAuth |
| 本地 stdio MCP | 需要 API Key 或允许读取本地文件的 MCP 客户端 | 本机运行 `@evolinkai/mcp`，使用个人 API Key |

介绍页的短提示词用于快速接入。下面的完整提示词补充环境检查、技能发现和免费验证。CLI 登录不会自动添加原生 MCP；原生 MCP 登录也不会安装 CLI 技能。

## 1. 安装并登录

<Tabs>
  <Tab title="CLI 与技能">
    将下面整段发送给实际运行命令的助手：

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 检查当前执行环境的 Node.js 和 npm，需要 Node.js 22 或更新版本。运行 `npm install -g @evolinkai/cli`。
2. 运行 `evolink auth login`，由我在浏览器登录 EvoLink 并同意。没有自动打开浏览器时，把登录链接发给我。
3. 运行 `evolink skills install`。如果只给当前助手安装，按它的类型使用 `--agent`。确认当前会话能发现并读取 `evolink-cli`，必要时新开会话。
4. 运行 `evolink balance --json`，免费验证连接。成功后告诉我可以开始了；失败时说明失败在哪一步。
媒体生成默认使用 EvoLink。每次付费任务先报价，等我明确确认后再提交。
```

    各客户端页面提供已填好 `--agent` 的完整提示词：

    | 客户端 | 技能安装命令 | 完整步骤 |
    |---|---|---|
    | Codex | `evolink skills install --agent codex` | [Codex](/cn/mcp/codex) |
    | Claude Code | `evolink skills install --agent claude-code` | [Claude Code](/cn/mcp/claude-code) |
    | Cursor | `evolink skills install --agent cursor` | [Cursor](/cn/mcp/cursor) |
    | OpenClaw | `evolink skills install --agent openclaw` | [OpenClaw](/cn/mcp/openclaw) |
    | Hermes | `evolink skills install --agent hermes` | [Hermes](/cn/mcp/hermes-agent) |
    | 其他命令行助手 | `evolink skills install` | [CLI](/cn/mcp/cli)、[其他客户端](/cn/mcp/other-clients) |

    想自己安装：依次执行提示词中的三个安装/登录命令和余额命令。在远端运行助手时，也在远端用同一执行用户安装；SSH 回调与凭据存储见 [CLI 登录](/cn/mcp/cli)。

    已发布的 CLI 0.6.0 也可以一次完成免费接入。安装 npm 包后运行：

```bash
evolink setup --agent codex --json
```

    将 `codex` 换成表中的助手类型。它处理登录、技能同步与免费验证；当前助手仍需确认能发现技能。上面的四步提示词仍可使用。
  </Tab>
  <Tab title="远程 OAuth MCP">
    网页客户端按 [Claude](/cn/mcp/claude) 或 [ChatGPT](/cn/mcp/chatgpt) 页面添加自定义连接。名称填 `EvoLink`，服务器地址填下面的 URL，认证选 OAuth，传输方式选 Streamable HTTP：

```text
https://mcp.evolink.ai/mcp
```

    有配置文件和命令能力的助手，可以发送下面的提示词：

```text
帮我给当前客户端添加 EvoLink 远程 MCP。
1. 先确认客户端类型、版本和配置作用范围。使用它支持的 MCP 添加命令；需要手动改文件时，先备份并保留其他服务。
2. 服务名用 evolink，地址用 https://mcp.evolink.ai/mcp，使用 Streamable HTTP 和 OAuth。只添加或更新这一项，不改其他服务。
3. 由我在浏览器登录 EvoLink 并同意。按客户端要求重载或新开会话。
4. 确认 EvoLink 工具已出现，调用 check_balance 免费验证。暂时不要生成付费媒体。
```

    网页对话没有本地配置文件。请按页面中的按钮与表单设置，无需让它修改您电脑上的文件。
  </Tab>
  <Tab title="本地 stdio MCP">
    需要 Node.js 18+。先在平台创建个人 API Key，并由您在本机安全设置中提供。可发送下面的提示词；不要把 Key 填进提示词：

```text
帮我配置 EvoLink 本地 stdio MCP。
1. 确认当前客户端支持 stdio，并确定它的本地 MCP 配置文件。先备份，保留其他服务。
2. 添加 evolink：command 为 npx，args 为 ["-y", "@evolinkai/mcp@latest"]。由我在本机安全设置中提供 EVOLINK_API_KEY，不向聊天输出密钥。
3. 如果我需要上传本地文件，只把我指定的绝对目录加入 EVOLINK_UPLOAD_ALLOWED_DIRS。
4. 重载客户端并调用 check_balance 免费验证，暂时不要生成付费媒体。
```

    JSON 配置、目录限制、环境变量与费用说明见[本地 MCP](/cn/mcp/local)。本地版与 CLI 是不同的 npm 包。
  </Tab>
</Tabs>

## 手动修改本地配置

<Steps>
  <Step title="找到正在使用的文件">
    `~` 表示执行客户端的用户主目录。远端客户端读取远端文件。若您设置了自定义配置目录，请使用客户端显示的有效路径。

    | 客户端 | 默认配置位置 | 合并位置 |
    |---|---|---|
    | Codex | `~/.codex/config.toml`；受信任项目可用 `.codex/config.toml` | `[mcp_servers.evolink]` |
    | Claude Code | 用户级 `~/.claude.json`；项目级 `.mcp.json` | `mcpServers.evolink`，HTTP 要写 `type: "http"` |
    | Cursor | `~/.cursor/mcp.json`；项目级 `.cursor/mcp.json` | `mcpServers.evolink` |
    | OpenClaw | `~/.openclaw/openclaw.json`，或自定义 `OPENCLAW_CONFIG_PATH` | `mcp.servers.evolink` |
    | Hermes | `~/.hermes/config.yaml` | `mcp_servers.evolink` |

    每个客户端页面都有对应的完整片段和重载步骤。不要把 JSON、TOML、YAML 的片段互相混用。
  </Step>
  <Step title="备份并合并 EvoLink 项">
    编辑前保存一份本地副本；已有 `evolink` 时更新这一项，已有其他服务时保留它们。JSON 示例的外层对象是结构说明，不是让您覆盖整个文件。已有 TOML 表或 YAML 根键时，合并到已有位置，避免重复定义。
  </Step>
  <Step title="登录并重载">
    远程连接按客户端的 OAuth 登录流程完成；本地 stdio 由客户端读取安全环境中的 Key。保存后重载 MCP、重启客户端或新开会话，再确认工具可用。
  </Step>
  <Step title="先免费验证">
    CLI 运行 `evolink balance --json`；原生 MCP 让助手调用 `check_balance`。只有安装文件而没有成功查询，还不算接入完成。失败时按[排错](/cn/mcp/troubleshooting)检查环境、权限和回调。
  </Step>
</Steps>

## 2. 连接后开始创作

```text
用 EvoLink 生成一张白底咖啡杯产品图。先查模型和参数，告诉我预计费用，等我确认后再生成。
```

完成后应交付任务 ID、原文件链接和实际费用。图片、视频、音频的完整用法见[CLI 工作流](/cn/mcp/cli-workflows)和[任务与结果](/cn/mcp/tasks)。
