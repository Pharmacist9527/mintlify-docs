## 选择 MCP 方式

| 方式 | 安装或连接 | 认证 | 适合谁 |
|---|---|---|---|
| 远程 MCP | https://mcp.evolink.ai/mcp | 浏览器 OAuth | 网页聊天、原生 MCP 客户端 |
| 本地 MCP | npx 启动 @evolinkai/mcp | 平台 API Key | stdio 客户端、允许目录内文件上传 |

连接远程 MCP 不需要安装本地 MCP 包。CLI 安装不会自动注册原生 MCP；技能安装也不等于登录或工具连接。

## 选择具体客户端

已列出的客户端使用自己的安装页：[Claude](/cn/mcp/claude)、[Codex](/cn/mcp/codex)、[Claude Code](/cn/mcp/claude-code)、[ChatGPT](/cn/mcp/chatgpt)、[Cursor](/cn/mcp/cursor)、[OpenClaw](/cn/mcp/openclaw)、[Hermes](/cn/mcp/hermes-agent)。本页说明其他客户端的通用远程 MCP 与本地 stdio 接入。

## 本地 stdio MCP 与 API Key

仅支持 stdio 的客户端可以由它启动本地 MCP 进程。需要 **Node.js 18+**；使用个人 API Key，不使用远程 MCP 的浏览器 OAuth。

<Steps>

<Step title="准备 Node 与专用 Key">

```bash
node --version
npx --version
```

两条命令可用，Node 主版本至少 18。到 [API Keys](https://evolink.ai/dashboard/keys)创建专用个人 Key 并设置额度；通过客户端的安全环境或秘密设置提供 `EVOLINK_API_KEY`。不要粘贴到 Agent 对话、分享截图或提交仓库。

</Step>

<Step title="添加本地启动配置">

在客户端 MCP 设置选择本地/stdio，填写：

```text
command: npx
args: -y @evolinkai/mcp@latest
```

首次启动时 npx 获取包，由宿主通过 stdio 通信，本地进程请求平台 API。宿主需能找到 npx；GUI 应用启动环境与终端不一定相同。下面 JSON 的 `YOUR_API_KEY` 是占位符，仅在私有、安全的本机设置中替换；客户端能继承环境时不重复保存 Key。

```json
{
  "mcpServers": {
    "evolink": {
      "command": "npx",
      "args": ["-y", "@evolinkai/mcp@latest"],
      "env": {"EVOLINK_API_KEY": "YOUR_API_KEY"}
    }
  }
}
```

</Step>

<Step title="需要本地文件时限定目录">

要上传本地路径，在进程环境设置 `EVOLINK_UPLOAD_ALLOWED_DIRS` 为允许的绝对目录。macOS/Linux 多目录用 `:`，Windows 用 `;`；未设置时不允许本地路径上传。远程 MCP 始终不接受 `file_path`。

这个设置限定本地进程读取范围，不会放宽模型的素材格式、时长或大小要求。只用 URL/base64 时无需启用本地目录。

</Step>

<Step title="重载服务并验证免费工具">

保存配置、启用 EvoLink，按宿主要求重载服务或新开会话。请求助手使用 EvoLink 调用 `check_balance`、`search_models`，确认真实结果。启动进程或看到工具列表还不算连接验证完成。

本地没有远程一次性上传工具 `prepare_upload` / `get_upload`，以实际 `tools/list` 为准。个人 Key 使用自己的额度，不继承 OAuth 内部 Key 的额度。

</Step>

</Steps>

### Claude Code 与 Codex 的配置形式

已通过安全环境提供 Key 的 Claude Code 可以用下面命令注册；它与上面的 JSON 方式选一种：

```bash
claude mcp add --scope user evolink -- npx -y @evolinkai/mcp@latest
```

Codex 可在配置中合并以下段落，从启动环境继承变量：

```toml
[mcp_servers.evolink]
command = "npx"
args = ["-y", "@evolinkai/mcp@latest"]
env_vars = ["EVOLINK_API_KEY", "EVOLINK_UPLOAD_ALLOWED_DIRS"]
```

更新本地 MCP 时重载服务，并查看实际版本；`@latest` 不会让运行中的旧进程自行换版。无法启动、Key 拒绝和本地路径错误见[集中排错](/cn/mcp/billing#mcp-connection)。

## 其他远程 MCP 客户端

客户端需支持 Streamable HTTP、OAuth 和浏览器回调；只支持静态 Key 或 stdio 的客户端选择上面的本地 MCP。

<Steps>

<Step title="添加服务器">

在 MCP 设置创建连接，名称 EvoLink，传输 Streamable HTTP，地址：

```text
https://mcp.evolink.ai/mcp
```

不填文档地址、平台 `/v1` 地址或本地 npx 命令。

</Step>

<Step title="完成 OAuth 并启用工具">

选择 OAuth，使用客户端提供的登录入口，在浏览器登录 EvoLink 并同意。回到客户端，确认连接已启用且工具可用。静态 API Key 不是这条连接的 OAuth 令牌。

</Step>

<Step title="免费验证">

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

看到真实余额与模型结果后，再按[首次创作流程](/cn/mcp/overview#workflows)提出需求。只有工具列表、没有真实调用结果时仍需排查授权。

</Step>

</Steps>
