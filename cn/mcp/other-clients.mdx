## 能执行命令：统一 CLI

Gemini CLI、OpenCode、Copilot CLI 等支持技能和命令执行的智能体可以使用[快速开始提示词](/cn/mcp/quickstart)。Node.js 22+，安装和登录所在环境必须与智能体实际执行环境一致。

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
```

可用 `--agent gemini`、`--agent opencode`、`--agent copilot` 只装对应技能。确认发现 `evolink-cli`，再进行模型查询和报价。技能安装不改变宿主安全策略；当前验收中 Gemini 的报价执行曾被宿主拒绝，不能把安装成功等同于所有流程通过。应保留预算、按宿主许可规则排查。

## 原生 MCP：兼容连接信息

| 设置 | 值 |
|---|---|
| 名称 | `EvoLink` 或 `evolink` |
| URL | `https://mcp.evolink.ai/mcp` |
| 传输 | Streamable HTTP（有些界面称 HTTP） |
| 认证 | OAuth，使用自动发现/登记或客户端支持的公开身份 |
| Client ID / Secret | 通常保持默认，不填 API Key |

常见 JSON 配置示例，实际结构以客户端说明为准：

```json
{
  "mcpServers": {
    "evolink": {"url": "https://mcp.evolink.ai/mcp"}
  }
}
```

不要覆盖已有服务器配置。完成浏览器登录后，实际调用 `check_balance` 验证，再确认所需生成工具可用。

## 只支持本地 stdio 的客户端

可选择[本地 API Key MCP](/cn/mcp/local)，或按第三方转接器的官方说明转接远程 HTTP。转接器的凭据和登录由该程序管理；不要删除整个共享认证目录来重置一个服务。第三方客户端的每项传输、OAuth、媒体显示都需分别验证。
