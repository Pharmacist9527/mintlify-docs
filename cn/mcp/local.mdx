各方式的可复制提示词、自定义接入和配置文件修改步骤，见[完整安装步骤](/cn/mcp/setup-methods)。

这是本地 stdio MCP，不是 EvoLink CLI。npm 包 `@evolinkai/mcp` 在客户端机器上运行，使用您自己的平台 API Key；需要 Node.js 18+。CLI 的 `@evolinkai/cli` 则需要 Node.js 22+，通过浏览器 OAuth 登录。

## 什么时候选本地版

需要 API Key 认证、只能运行 stdio MCP，或需要在允许的本地目录读文件时，可以选本地版。想统一用浏览器登录、上传和下载命令的终端智能体，优先看 [CLI](/cn/mcp/cli)。

| | 远程 OAuth MCP | 本地 stdio MCP |
|---|---|---|
| 运行位置 | EvoLink 服务器 | 客户端的机器 |
| 凭据 | 浏览器登录 | 您自己的 API Key |
| 计费 Key | `EvoLink MCP (OAuth)` | 提供的 API Key |
| 文件 | 公开 URL、小文件 base64、一次性上传 | URL/base64，或已允许目录内的本地文件 |
| 工具列表 | 12 个工具 | 以实际返回列表为准；不假设有远程一次性上传工具 |

## 配置

在控制台 [API Keys](https://evolink.ai/dashboard/keys) 新建或选择一把专用 Key，并配置额度。通过本机的安全设置或环境变量向 MCP 提供 `EVOLINK_API_KEY`，不要发进聊天或提交到仓库。

stdio 启动程序与参数：

```text
command: npx
args: -y @evolinkai/mcp@latest
```

支持 JSON MCP 配置的客户端可以合并这一项；`YOUR_API_KEY` 只是在本机填写的占位值：

```json
{
  "mcpServers": {
    "evolink": {
      "command": "npx",
      "args": ["-y", "@evolinkai/mcp@latest"],
      "env": {"EVOLINK_API_KEY": "YOUR_API_KEY"}
    }
  }
}
```

如果客户端可从安全环境继承密钥，优先用继承方式，不在配置文件重复保存。桌面 App 不一定继承终端环境变量，应按客户端说明检查。保留其他服务配置，并保护包含 Key 的本地文件。

### 修改哪一个文件

- Cursor：备份 `~/.cursor/mcp.json` 或项目 `.cursor/mcp.json`，把上面的服务项合并进 `mcpServers`。
- Claude Code：项目使用 `.mcp.json`；用户级使用 `~/.claude.json`。本地条目可显式增加 `"type": "stdio"`。
- Codex：在 `~/.codex/config.toml` 合并下面的表。Key 由启动客户端的安全环境提供，`env_vars` 只写变量名：

```toml
[mcp_servers.evolink]
command = "npx"
args = ["-y", "@evolinkai/mcp@latest"]
env_vars = ["EVOLINK_API_KEY", "EVOLINK_UPLOAD_ALLOWED_DIRS"]
```

- Hermes：在 `~/.hermes/config.yaml` 的 `mcp_servers` 下合并下面的项。变量值由它的安全环境提供：

```yaml
mcp_servers:
  evolink:
    command: npx
    args: ["-y", "@evolinkai/mcp@latest"]
    env:
      EVOLINK_API_KEY: "${EVOLINK_API_KEY}"
```

已有远程 `evolink` 时，先确定使用哪一种，再更新该项。不要同时在同一作用范围给远程和本地服务使用相同名字。保存后重启／重载客户端，确认它实际收到所需环境变量，再免费验证。其他客户端的配置路径见[手动设置](/cn/mcp/setup-methods)。

启动后用 `check_balance` 免费验证。查不到 Key、Key 停用或过期时，检查本地配置及控制台，不把原生 MCP 的错误指引当成 CLI 登录命令。

## 允许本地上传

设置 `EVOLINK_UPLOAD_ALLOWED_DIRS` 为允许读取的绝对目录。macOS/Linux 多目录用 `:` 分隔，Windows 用 `;`。不设置时不能上传本地路径；不允许用任意文件路径绕过目录限制。

例如本机目录可设置为 `/Users/you/Pictures`。客户端随后能在允许范围用 `upload_file` 的 `file_path`；远程 OAuth 服务不接受这个字段。单文件约 95 MB 上限，格式及 72 小时保留规则见[文件指南](/cn/mcp/files)。

## 费用、更新与迁移

费用按平台模型价格扣在这把个人 API Key 上，和 OAuth 内部 Key 区分。`max_cost_usd` 仍只是估价保护，见[费用说明](/cn/mcp/billing)。

`@latest` 表示请求 npm 的当前发行标签，不保证各客户端缓存立即刷新。更新后按客户端方式重启/重载并验证版本和工具。需要固定版本时用具体包版本。

迁移到 CLI 或远程 MCP 前，确认是否已有同名服务，避免重复连接和技能。移除一个 EvoLink 项时保留其他配置，撤销凭据请用客户端对应的退出功能。
