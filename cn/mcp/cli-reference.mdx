运行 `evolink --help` 查看本机版本的完整帮助。以下命令均支持 `--json`；示例中的 `MODEL_ID`、`QUOTE_ID`、`TASK_ID`、`UPLOAD_ID` 要替换成实际返回值。

## 登录与免费查询

| 命令 | 用途 |
|---|---|
| `evolink setup [--agent NAME] [--no-browser] [--timeout SECONDS]` | 免费检查环境、登录、技能同步与连接 |
| `evolink auth login [--no-browser] [--timeout SECONDS]` | 浏览器 OAuth 登录 |
| `evolink auth status` | 本地登录状态，不等于服务可用性检查 |
| `evolink auth logout` | 退出此 CLI 登录 |
| `evolink balance` | 账户余额和花费额度 |
| `evolink models search --type image --query seedream --limit 5` | 按关键词查模型 |
| `evolink models show MODEL_ID` | 参数、示例和定价 |
| `evolink doctor [--agent NAME]` | 分项检查环境、连接、模型与技能 |
| `evolink skills status [--agent NAME]` | 检查已安装技能的版本与内容 |

搜索的 `--type` 可选 `image`、`video`、`audio`、`all`，默认 `all`；`--limit` 为 1–50，默认 20。型号与参数用实时查询结果，不要仅凭本文示例判断可用性。

登录和 `setup` 的 `--timeout` 为 30–900 的整数秒，默认 180。`setup` 不创建付费媒体任务；文件校验通过后，仍需助手确认技能发现。`skills install` 同时负责更新随包技能，默认保护修改过的文件；决定替换时加 `--replace-modified`，替换会备份。支持的 `--agent` 名称见 [CLI 安装](/cn/mcp/cli)。

## 报价与生成

```bash
evolink estimate --model MODEL_ID --input-file input.json --max-cost-usd 1 --json
```

| 选项 | 说明 |
|---|---|
| `--model` | 必填，使用模型查询返回的 ID |
| `--input-file` 或 `--input` | 模型参数 JSON 文件或 JSON 对象，二选一 |
| `--prompt` | 可补充提示词；不能和 JSON 内不同的 `prompt` 同时提供 |
| `--max-cost-usd` | 用户批准的估价上限，必须大于 0 且不超过 10000 美元 |
| `--media-seconds` | 无 `duration` 参数的按秒模型的估价时长，大于 0 且不超过 3600 秒；不发给模型 |

`estimate` 返回 `quote_id`，报价保留 15 分钟，并绑定当前服务、登录、输入和价格。取得用户对这份报价的明确确认后再运行：

```bash
evolink generate image --quote QUOTE_ID --confirm --wait --timeout 1800 --json
```

把 `image` 换成报价对应的 `video` 或 `audio`。生成时只使用保存的报价，不接收新的模型或参数；改变输入、价格或登录后需重新报价和确认。`--confirm` 是您已获得批准的声明，不会替智能体询问用户。

`--wait` 继续等待结果；`--timeout` 为 1–86400 的整数秒，默认等待 1800 秒。预算检查的局限见[费用与上限](/cn/mcp/billing)。

## 任务与恢复

```bash
evolink tasks get TASK_ID --json
evolink tasks wait TASK_ID --timeout 1800 --json
evolink tasks list --type video --status processing --since 2h --limit 10 --json
evolink tasks resume --quote QUOTE_ID --json
```

`--status` 支持 `processing`、`completed`、`failed`、`cancelled`；`--type` 支持三种媒体；`--limit` 为 1–50。`resume` 用于已开始提交但结果未知的原报价，可能重试同一请求 ID；不能当作新任务入口。超过报价有效期时先核查近期任务，不要直接新建报价重复扣费。详见[任务与结果](/cn/mcp/tasks)。

## 文件与技能

```bash
evolink upload ./reference.png --json
evolink uploads get UPLOAD_ID --json
evolink download TASK_ID --output ./result.png --index 1 --json
evolink skills install --agent codex
```

上传可加 `--upload-path references` 指定相对文件夹。下载 `--index` 从 1 开始，范围 1–50，默认 1；目标父目录必须存在，不能覆盖已有文件。下载单个文件最多 1 GiB。支持格式和有效期见[文件指南](/cn/mcp/files)。

## JSON 与进程约定

- `--json` 在标准输出写一行 JSON，顶层带 `schema_version: 1` 和 `ok`。
- 错误返回 `ok: false` 和 `error`，进程退出码非零；等待进度写到标准错误。
- 成功返回字段因命令而异。先检查 `ok`，再读取 `quote_id`、`task_id` 或 `results`，不要只搜索终端里“成功”二字。
- Ctrl-C 停止本地等待，通常退出 130；已经提交的服务端任务继续运行。
- `--server URL` 选择 MCP 服务。通常保持默认生产地址；不同服务的登录和报价不能混用。
- `--token-stdin` 仅用于高级场景的一次性 **OAuth 访问令牌**输入，不是平台 API Key。不要把令牌写在命令参数、脚本、日志或聊天里。

CLI 暂无任务取消、余额充值、Key 管理、别名配置或通用 `run` 命令。远程 MCP 工具参数不一定与 CLI 命令选项一一对应。
