本页只说明 Hermes 的原生 MCP 接入。远程服务使用 Streamable HTTP 与浏览器 OAuth，不要求安装 EvoLink CLI。想用命令和技能时，请看[独立 CLI 指南](/cn/cli/hermes-agent)。

## 连接远程 MCP

选择原生工具调用时，使用 **Streamable HTTP + OAuth**，服务器地址为：

```text
https://mcp.evolink.ai/mcp
```

不需要先安装 CLI。已有配置时先备份，只合并 EvoLink 项并保留其他服务；命令添加与手工配置选一种。

<Steps>

<Step title="合并服务器配置">

在支持 OAuth 的 Hermes 版本中备份并编辑 `~/.hermes/config.yaml`，合并到已有 `mcp_servers`，不要重复创建顶层同名字段。使用空格缩进：

```yaml
mcp_servers:
  evolink:
    url: "https://mcp.evolink.ai/mcp"
    auth: oauth
    connect_timeout: 300
```

</Step>

<Step title="在新终端完成授权">

```bash
hermes mcp login evolink
```

在浏览器登录 EvoLink 并同意，保持命令等待。编辑配置后在新终端主动登录，可以避开运行会话自动重载时较短的等待窗口。

</Step>

<Step title="重载工具并免费验证">

回到 Hermes 会话执行：

```text
/reload-mcp
```

也可以新开会话，再发送下方验证提示词。检查 EvoLink 工具未被宿主禁用；列出工具并不等于已取得可调用的授权。

</Step>

</Steps>

远程 SSH 的浏览器回调按 Hermes 自己的配置处理，不套用 EvoLink CLI 选项。[Hermes 官方说明](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp/)。

授权后在 Agent 对话发送：

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

**成功标志：**实际调用 `check_balance` 和 `search_models` 并返回结果。请在本次 MCP 连接中实际验证工具调用。

## 更新、断开与排错

远程 MCP 服务由 EvoLink 更新。客户端修改配置后刷新实际持有连接的会话；需要重新授权时，使用该客户端自己的 OAuth 入口。要断开，在宿主 MCP 设置中禁用、退出或移除 EvoLink，保留其他服务。

| 现象 | 操作 |
|---|---|
| 已加地址但没有工具 | 确认连接已启用、授权完成，刷新会话，检查组织权限 |
| 401 或需要认证 | 在当前 MCP 客户端重新授权，保留原任务 ID |
| 403 或工具被拒绝 | 查看宿主许可、账户或 Key 状态与网络错误 |
| 等待超时或响应丢失 | 用原任务编号查询，先恢复，不重复生成 |
| 只显示链接或灰色预览 | 打开并交付原件，不自动重做 |

完整排错见[MCP 费用、授权与排错](/cn/mcp/billing#faq)。开始使用时先读[创作流程](/cn/mcp/overview#workflows)，调用形状见[MCP 工具参考](/cn/mcp/tools)。
