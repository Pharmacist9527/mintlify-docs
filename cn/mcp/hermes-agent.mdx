## 完整安装提示词

将下面整段发给Hermes；命令会在助手实际执行终端的环境运行：

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 检查 Node.js 和 npm，需要 Node.js 22 或更新版本。运行 `npm install -g @evolinkai/cli`。
2. 运行 `evolink auth login`，由我在浏览器里登录 EvoLink 并点同意；没有打开浏览器时，把登录链接发给我。
3. 运行 `evolink skills install --agent hermes`，确认当前助手能发现并读取 `evolink-cli`。需要时新开会话，再验证技能发现。
4. 运行 `evolink balance --json`，免费验证连接。成功后告诉我可以开始了；失败时说明具体步骤。
媒体生成默认使用 EvoLink。每次付费任务先报价，等我明确确认后再生成。
```

想自己操作或改用远程／本地 MCP，见[安装方式与手动设置](/cn/mcp/setup-methods)。


## 推荐：CLI 与技能

把[统一安装提示词](/cn/mcp/quickstart)交给能运行终端的 Hermes，或在它实际执行命令的环境运行：

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent hermes
evolink balance --json
```

需要 Node.js 22+。登录由您在浏览器完成；Linux/SSH 需安全凭据存储及可到达的回调，见 [CLI 登录](/cn/mcp/cli)。技能安装到 Hermes 的技能目录，名称为 `evolink-cli`。新会话中确认它确实发现技能，再查询模型与报价。

## 可选：原生远程 MCP

如果希望 Hermes 直接发现 MCP 工具，可使用支持 OAuth 的安装版本：

```bash
hermes mcp add evolink --url https://mcp.evolink.ai/mcp --auth oauth --connect-timeout 300
```

按客户端提示登录和启用工具，再在会话里通过 `/reload-mcp` 刷新，调用 `check_balance` 验证。命令参数和回调处理以 `hermes mcp --help` 为准；EvoLink CLI 的选项不要套到 Hermes 命令。

### 自己修改配置文件

1. 在 Hermes 执行环境备份并打开 `~/.hermes/config.yaml`；使用自定义配置目录时编辑实际文件。
2. 在已有 `mcp_servers` 下合并 `evolink`，保留其他服务和正确缩进，不重复添加根键：

```yaml
mcp_servers:
  evolink:
    url: "https://mcp.evolink.ai/mcp"
    auth: oauth
    connect_timeout: 300
```

3. 保存后在新终端运行 `hermes mcp login evolink`，由您完成浏览器登录；回到 Hermes 运行 `/reload-mcp` 或新开会话，再调用 `check_balance`。

配置位置与 OAuth 选项见 [Hermes 官方 MCP 文档](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp/)。

## 使用和验收范围

Hermes 的 EvoLink CLI 接入、技能发现和未确认零提交的报价流程已有云端记录；不等于 Hermes 桌面版、原生 OAuth 和真实付费媒体都已验收。

报价与生成见[CLI 工作流](/cn/mcp/cli-workflows)。发现不到技能、余额失败或媒体预览问题见[排错](/cn/mcp/troubleshooting)。
