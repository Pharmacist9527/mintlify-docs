本页只说明 Claude Code 的原生 MCP 接入。远程服务使用 Streamable HTTP 与浏览器 OAuth，不要求安装 EvoLink CLI。想用命令和技能时，请看[独立 CLI 指南](/cn/cli/claude-code)。

## 连接远程 MCP

选择原生工具调用时，使用 **Streamable HTTP + OAuth**，服务器地址为：

```text
https://mcp.evolink.ai/mcp
```

不需要先安装 CLI。已有配置时先备份，只合并 EvoLink 项并保留其他服务；命令添加与手工配置选一种。

<Steps>

<Step title="添加 HTTP 服务器">

在已安装 Claude Code 的终端执行：

```bash
claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp
```

`--scope user` 让当前用户在不同项目中使用此连接。添加成功只表示配置已写入。

</Step>

<Step title="在 Claude Code 中登录">

回到 Claude Code 对话，输入下面的会话命令，选择 EvoLink 的认证入口：

```text
/mcp
```

在浏览器完成登录与同意，回到 Claude Code 检查已连接。这个会话命令不放在普通终端执行。

</Step>

<Step title="确认工具并免费验证">

```bash
claude mcp list
```

若项目连接等待批准，进入 Claude Code 审核该连接。新会话发送下方验证提示词，确认返回真实余额和模型。

</Step>

</Steps>

项目级配置可合并到 `.mcp.json`：

```json
{
  "mcpServers": {
    "evolink": {
      "type": "http",
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

不要放进 `.claude/settings.local.json`；用户范围由上面的命令管理。[Claude Code 官方说明](https://code.claude.com/docs/en/mcp)。

授权后在 Agent 对话发送：

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

**成功标志**：实际调用 `check_balance` 和 `search_models` 并返回结果。请在本次 MCP 连接中实际验证工具调用。

## 更新、断开与排错

远程 MCP 服务由 EvoLink 更新。客户端修改配置后刷新实际持有连接的会话；需要重新授权时，使用该客户端自己的 OAuth 入口。要断开，在宿主 MCP 设置中禁用、退出或移除 EvoLink，保留其他服务。

| 现象 | 操作 |
|---|---|
| 已加地址但没有工具 | 确认连接已启用、授权完成，刷新会话，检查组织权限 |
| 401 或需要认证 | 在当前 MCP 客户端重新授权，保留原任务 ID |
| 403 或工具被拒绝 | 查看宿主许可、账户或 Key 状态与网络错误 |
| 等待超时或响应丢失 | 用原任务编号查询，先恢复，不重复生成 |
| 只显示链接或灰色预览 | 打开并交付原件，不自动重做 |

完整排错见[MCP 费用、授权与排错](/cn/mcp/billing#faq)。开始使用时先读[创作流程](/cn/mcp/overview#workflows)，调用形状见[MCP 工具参考](/cn/mcp/tools)。
