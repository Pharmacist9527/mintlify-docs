## 完整安装提示词

将下面整段发给Claude Code；命令会在助手实际执行终端的环境运行：

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 检查 Node.js 和 npm，需要 Node.js 22 或更新版本。运行 `npm install -g @evolinkai/cli`。
2. 运行 `evolink auth login`，由我在浏览器里登录 EvoLink 并点同意；没有打开浏览器时，把登录链接发给我。
3. 运行 `evolink skills install --agent claude-code`，确认当前助手能发现并读取 `evolink-cli`。需要时新开会话，再验证技能发现。
4. 运行 `evolink balance --json`，免费验证连接。成功后告诉我可以开始了；失败时说明具体步骤。
媒体生成默认使用 EvoLink。每次付费任务先报价，等我明确确认后再生成。
```

想自己操作或改用远程／本地 MCP，见[安装方式与手动设置](/cn/mcp/setup-methods)。


## 推荐：CLI 与技能

把[统一安装提示词](/cn/mcp/quickstart)发给 Claude Code，或按顺序运行：

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent claude-code
evolink balance --json
```

Node.js 22+，在浏览器由您登录和同意。确认 Claude Code 能发现 `evolink-cli`；看不到时新开会话。CLI 已云端验证接入、技能发现和模拟生成交付；真实账户付费和各桌面界面仍需按当前客户端验证。

## 可选：原生远程 MCP

```bash
claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp
```

在 Claude Code 会话中输入 `/mcp`，选择 EvoLink 并完成 OAuth 认证。登录后调用 `check_balance` 免费验证。`--scope user` 让服务在该用户的项目中可用；需要项目级共享配置时按 [Claude Code 官方说明](https://code.claude.com/docs/en/mcp)选择作用域，不覆盖已有配置。

原生 MCP 的配套技能是 `evolink-mcp`，可用[插件](/cn/mcp/plugins)安装；CLI 使用 `evolink-cli`。如果已经从 claude.ai 连接器或插件加载同一服务，先检查 `/mcp`，避免重复添加。

### 自定义项目配置

1. 全部项目共用时优先使用上面的 `--scope user` 命令，它写入 `~/.claude.json`。只对一个项目启用时，在项目根目录备份并编辑 `.mcp.json`。
2. 将下面的 `evolink` 项合并进已有 `mcpServers`，保留其他服务；HTTP 项必须包含 `type`：

```json
{
  "mcpServers": {
    "evolink": {
      "type": "http",
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

3. 保存后重新启动 Claude Code，按提示批准项目 MCP，再通过 `/mcp` 登录；调用 `check_balance` 验证。

用户级与项目级位置见 [Claude Code 官方 MCP 文档](https://code.claude.com/docs/en/mcp)。不要把 MCP 配置写进 `.claude/settings.local.json`。

## SSH 与权限

CLI 登录见[Linux 与 SSH](/cn/mcp/cli#linux-与-ssh)。原生 MCP 使用 Claude Code 自己的 OAuth 回调流程，不要把 CLI 的选项直接套到其他程序。

工具许可不是费用批准。智能体应先展示报价等待确认；命令或工具被宿主拒绝时，按权限提示处理，不要自动绕过。更多见[费用与上限](/cn/mcp/billing)与[排错](/cn/mcp/troubleshooting)。
