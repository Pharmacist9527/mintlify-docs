## 原生 MCP 要读哪些资料

1. 先读[MCP 总览](/cn/mcp/overview)和自己的客户端安装页，完成宿主配置与 OAuth。
2. 查询[MCP 工具参考](/cn/mcp/tools)，按实际工具 schema 调用。
3. 可选安装 evolink-mcp 技能或宿主插件，步骤见[插件指南](/cn/mcp/plugins)。读到技能不代表工具已注册或登录成功。
4. 使用[共同 Agent 规则](/cn/cli-mcp/agent-resources#agent-rules)，再按[MCP 排错](/cn/mcp/billing#faq)验证实际调用。

evolink-cli 讲终端命令；原生 MCP 使用 evolink-mcp 工具说明。安装和授权分别验证。llms.txt 是文档索引；MCP 服务地址仍为 https://mcp.evolink.ai/mcp。
