## 费用和额度

MCP 与 CLI 不另收接入费。生成按平台模型价格计费，余额与 API、网页共用。模型查询、报价、余额、任务查询和上传免费。积分换算约为 **68 credits = 1 美元**；实际扣费以完成任务和控制台记录为准。

浏览器授权后，控制台 [API Keys](https://evolink.ai/dashboard/keys) 中会出现 `EvoLink MCP (OAuth)`。它是同一账户通过 OAuth 连接的智能体共用的内部 Key，不能复制作为个人 API Key。CLI 同样使用 OAuth 服务访问，退出一个客户端不等于停用整把 Key。

可以在控制台为它设总额度、当日额度、有效期或停用。花费和任务照常在控制台显示。账户余额、内部 Key 额度、任务估价预算是不同的限制；不要把一个数值当作全部预算。

## 报价和花费上限

| 返回情况 | 可以怎么理解 |
|---|---|
| `estimated` | 根据已发布价格和当前输入计算的估价范围 |
| `partial` | 已知有费用未覆盖，不能看作总价或上限 |
| `token_billed` | 只知道 Token 单价，运行前不知道总用量 |
| `needs_input` | 还缺估价所需输入或时长提示 |
| `no_price` | 没有足够定价信息，不能编造总费用 |

智能体先展示真实估价和警告，结束回复，等待您明确批准。CLI 报价保存 15 分钟，生成前重新检查价格和输入；变化后要重新报价确认。

<Warning>
原生 MCP 的 `max_cost_usd` 与 CLI 的 `--max-cost-usd` 都是**提交前基于估价的检查**，不是网关最终结算的硬上限。发布价中的部分分辨率、声音及参考视频信息仍在补齐，即便返回 `estimated`，也不保证最终扣费绝不会超过估价。要求不可超支的任务应先选择计费足够明确的方案，并配合账户/Key 额度；不要把它们宣传为逐任务结算保证。
</Warning>

### 参考视频、声音和分辨率

时长、输出画质、声音和参考输入可能影响费用。按秒视频请求带 `video_urls`、`video_url` 或 `source_task_id` 时，MCP 会把总价标为部分估价；有 `max_cost_usd` 时拒绝提交。填 `media_seconds` 不能补全参考视频费用。

### 无法指定输出时长的音频

不能给不支持时长参数的模型塞 `input.duration`。`media_seconds` 只用于估价提示；输出时长未知时，它是“按假设长度举例”，不是总价。MCP 不会据此承诺花费上限。

### Token 计费

展示文本/图片等输入输出单价和总费用未知，得到明确同意后才提交。不能根据模型起价或另一任务的扣费承诺本次金额。

### 预算被拒绝时

不要自行去掉预算、更换 Key 或绕过调用路径。智能体应解释原因，让您选择降低规格、换模型、增加预算，或明确接受无法事前算出完整金额的任务。已有批准的预算应保留，除非您明确修改。

## 常见提示

| 提示 | 含义与处理 |
|---|---|
| MCP spending limit reached | MCP 总额度不足，在控制台查看或调整 |
| MCP daily limit reached | 当日额度不足，按控制台重置时间或调整额度 |
| account balance is too low | 账户余额不足，需要充值 |
| MCP is paused for this account | 内部 Key 被停用，确认后在控制台恢复 |
| MCP key has expired | 检查内部 Key 有效期 |
| connection was disconnected | 当前登录连接已断开或过期，重新登录 |
| temporarily turned off MCP access | 服务暂时暂停，稍后再试 |
| max_cost_usd cannot be checked | 估价不完整或未知，保留预算并讨论替代方案 |

这些提交前拒绝不产生生成费用。网络超时或“状态未知”则不能据此断定未扣费；先按[任务恢复](/cn/mcp/tasks)查已有任务。重复生成、变体和再次编辑都是新的付费任务。
