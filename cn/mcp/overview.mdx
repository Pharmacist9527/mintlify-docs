EvoLink 把模型查询、参数检查、报价、媒体生成、文件上传和任务查询接到您的智能体中。您用自然语言描述需求，智能体调用 EvoLink；任务和费用归入同一个 EvoLink 账户。

## 选择您的助手

| 您在哪里使用 | 推荐接入方式 | 下一步 |
|---|---|---|
| Claude 网页版、桌面版 | 远程 MCP 连接器 | [Claude](/cn/mcp/claude) |
| ChatGPT 网页版 | 自定义 MCP 服务器，OAuth 登录 | [ChatGPT](/cn/mcp/chatgpt) |
| Codex、Claude Code、Cursor 等能运行终端命令的智能体 | EvoLink CLI 和随包技能 | [快速开始](/cn/mcp/quickstart) |
| OpenClaw、Hermes 等命令行智能体 | EvoLink CLI 和随包技能 | [OpenClaw](/cn/mcp/openclaw)、[Hermes](/cn/mcp/hermes-agent) |
| 自己的脚本或应用 | CLI 的 JSON 输出，或平台 API | [CLI 工作流](/cn/mcp/cli-workflows) |
| 必须用 API Key 的本地 MCP 客户端 | 本地 stdio MCP | [本地 MCP](/cn/mcp/local) |

## 怎么接入

先选 MCP 或 CLI，再打开对应接入指南：

| | 远程 MCP | EvoLink CLI |
|---|---|---|
| 入口 | `https://mcp.evolink.ai/mcp` | npm 包 `@evolinkai/cli`，命令 `evolink` |
| 谁调用 | 客户端原生 MCP 工具 | 智能体的终端能力，或您直接运行命令 |
| 安装要求 | 支持 Streamable HTTP 和 OAuth 的客户端 | Node.js 22+；登录所在机器有可用安全凭据存储 |
| 配套技能 | `evolink-mcp`，单独安装或通过插件安装 | `evolink-cli`，运行 `evolink skills install` |
| 本地文件 | 公开 URL、小文件 base64，或一次性上传地址 | `evolink upload` 直接上传本地媒体 |
| 结果 | 工具返回任务、原文件链接和可用预览 | JSON、任务查询及 `evolink download` |

CLI 复用远程 MCP 服务，但它的登录不会把 MCP 工具注册到客户端。CLI 接入成功的标志是命令和技能可用；原生 MCP 接入成功的标志是 `check_balance` 工具可用。两种登录分别管理。

## 一次生成怎么完成

1. 查模型，读取该模型支持的参数和输入要求。
2. 上传参考素材（有需要时），检查参数并报价。
3. 向您展示模型、规格、参考素材、预计费用和不确定项，等待明确确认。
4. 提交一次付费任务，保存任务 ID，查询进度。
5. 交付原文件链接和实际费用，及时保存结果。

MCP/CLI 不另收接入费；媒体生成按平台模型价格扣费。查询和上传免费。详见[费用、报价与上限](/cn/mcp/billing)。

<Warning>
当前 `max_cost_usd` 是提交前的估价检查，不是最终结算硬上限。部分参考视频、倍率和 Token 计费不能事先给出完整总价；智能体应说明未知费用并等待您的决定。不能为了让任务通过而自行删除您设置的预算。
</Warning>
