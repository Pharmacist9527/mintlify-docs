## 什么是 EvoLink MCP

EvoLink MCP 让 AI 助手直接调用 EvoLink 的模型：查有哪些模型和价格、先报价再生成图片、视频和音频、查任务进度和账户余额。

- **服务地址：** `https://mcp.evolink.ai/mcp`
- **不需要 API Key：** 第一次使用时在浏览器里登录 EvoLink 并点同意，助手就连上了。
- **按用量扣费：** 费用从您的 EvoLink 账户余额扣，价格和 API 相同，MCP 本身不收费。

## 选择您的助手

点您正在用的助手，跳到对应的步骤。能一键添加的点一下按钮就行；不能一键添加的，复制一句命令运行；其余的按步骤手动添加。

| 助手 | 怎么添加 | 怎么登录 | 支持情况 |
|---|---|---|---|
| Claude 网页版和桌面版 | 一键添加 | 点 **连接**，在浏览器登录 | 首批支持 |
| Cursor | 一键添加 | 在 MCP 设置里点 **Connect** | 首批支持 |
| Claude Code | 复制一句命令 | 命令会自动打开浏览器 | 首批支持 |
| Codex | 复制一句命令 | 命令会自动打开浏览器 | 首批支持 |
| Hermes Agent | 复制一句命令；桌面版一键添加 | 命令会自动打开浏览器 | 还没实测 |
| OpenClaw | 复制一句命令 | 点终端打印的链接 | 还没实测 |
| ChatGPT | 按步骤添加 | 按 ChatGPT 的提示 | 还没实测 |
| 其他客户端 | 按步骤添加 | 按客户端的提示 | 还没实测 |
| CLI（命令行 Agent） | 复制一段话给 Agent | Agent 带您在浏览器登录 | 首批支持 |
| 本地版（API Key） | 运行一句命令 | 用您自己的 API Key，不用登录 | Claude Code、Codex 已实测 |

所有助手登录时看到的都是同一个 EvoLink 同意页，见[第一次连接：登录和同意](/cn/mcp/sign-in)。

## 怎么接入

<Steps>
  <Step title="添加 EvoLink">
    按您用的助手，点一键添加，或者复制一句命令运行。
  </Step>
  <Step title="登录并同意">
    浏览器会打开 EvoLink 登录页，登录后在同意页点 **Allow and connect**，详见[登录与授权](/cn/mcp/sign-in)。
  </Step>
  <Step title="在对话里使用">
    直接说想做什么，比如"用 EvoLink 生成一张产品主图"。能报价的模型会先报价，您确认后再生成，详见[工具与用法](/cn/mcp/tools)。
  </Step>
</Steps>
