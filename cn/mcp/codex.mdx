## 让 Codex 帮你接入

把下面这段话发给 Codex，它会装好 EvoLink 技能、加上 EvoLink MCP，再带您在浏览器登录。Codex App 和命令行都能用。

```text
帮我在 Codex 里接入 EvoLink，让我能在这里生成图片、视频和音频。
1. 安装配套技能：运行 `npx skills add Evolink-AI/mcp-plugin -g -y`。
2. 添加 EvoLink MCP 服务：运行 `codex mcp add evolink --url https://mcp.evolink.ai/mcp`，它会在浏览器里开始登录；没打开的话，把它打印的链接发给我。
3. 我会在浏览器里登录 EvoLink 并点同意。然后请我重新打开你：命令行用 `codex resume --last`；Codex App 新开一个对话，还看不到 EvoLink 就重启 App。
完成后告诉我已经可以用了。
```

<Note>
Codex 默认在沙箱里运行命令。这两条命令要联网下载，还要写工作区外的 `~/.codex` 和 `~/.agents`，所以 Codex 会先请您批准，同意即可。Codex App 这条路我们还没实测，不顺利的话按下面 [Codex App](#codex-app) 的步骤手动添加。
</Note>

## Codex App

<Steps>
  <Step title="新建插件">
    在 Codex App 左侧点 **Customize** → **Plugins**，再点右上角的 **Add**，打开 **New Plugin**。
  </Step>
  <Step title="填写连接信息">
    - **Choose icon** 可以不选。
    - **Name** 填 `evolink`，**Description** 可以不填。
    - **Connection** 选 **Server URL**，填 `https://mcp.evolink.ai/mcp`。
    - **Authentication** 选 **OAuth**，**Advanced OAuth settings** 不用改。
    - 勾选 **I understand and want to continue**，点 **Create**。
  </Step>
  <Step title="连接并登录">
    弹出 **Connect evolink** 后点 **Continue to evolink**，在浏览器登录 EvoLink 并点 **允许并连接**。
  </Step>
</Steps>

Codex IDE 插件和 ChatGPT 桌面应用的添加入口我们还没核实。

## 命令行（Codex CLI）

<Steps>
  <Step title="复制这一句并运行">
    ```bash
    codex mcp add evolink --url https://mcp.evolink.ai/mcp
    ```
  </Step>
  <Step title="在浏览器登录并同意">
    Codex 发现 EvoLink 需要登录，会自动打开 EvoLink 登录页。登录后点 **允许并连接**，终端显示 `Successfully logged in.` 就好了。
  </Step>
  <Step title="开一个新会话">
    在新的 Codex 会话里就能用。运行 `codex mcp list` 可以看到 `evolink`。
  </Step>
</Steps>

想让 Codex 自己装好，把 [CLI](/cn/mcp/cli) 页的那段话发给它。

<Warning>
不要在这一句后面再接 `codex mcp login evolink`：添加时已经登录过一次，再运行 login 会让您再授权一遍。只有输出提示 "may or may not require login"，或者浏览器没有打开时，才需要单独运行 login。
</Warning>

<AccordionGroup>
  <Accordion title="浏览器没有打开，或提示 may or may not require login">
    ```bash
    codex mcp login evolink
    ```

    通过 SSH 使用、电脑上没有浏览器时，加上 `--no-browser`，把打印的链接复制到您自己电脑的浏览器里打开。
  </Accordion>
  <Accordion title="提示不认识命令：Codex 版本太旧">
    需要 Codex 0.77 或更新的版本，请先把 Codex 升级到最新版。
  </Accordion>
  <Accordion title="想直接改配置文件">
    在 `~/.codex/config.toml` 里加上下面两行，再运行 `codex mcp login evolink` 登录：

    ```toml
    [mcp_servers.evolink]
    url = "https://mcp.evolink.ai/mcp"
    ```
  </Accordion>
  <Accordion title="在 codex exec 或自动模式里，生成被拒绝（MCP tool call requires approval）">
    EvoLink 的生成工具会花钱，Codex 默认每次先问您。`codex exec` 或 `approval_policy = "never"` 时没人确认，Codex 就会直接拒绝。要让它不经确认直接生成，在 `~/.codex/config.toml` 里加上下面两行（视频、音频把 `generate_image` 换成 `generate_video`、`generate_audio`）：

    ```toml
    [mcp_servers.evolink.tools.generate_image]
    approval_mode = "approve"
    ```

    这样生成会直接扣费，建议同时在 [API Keys](https://evolink.ai/dashboard/keys) 里给 `EvoLink MCP (OAuth)` 设一个额度上限。
  </Accordion>
</AccordionGroup>

## 试一下

在对话里发这句话，只是查询，不扣费：

```text
用 EvoLink 查一下我的账户余额。
```

助手调用了 EvoLink 的工具并给出结果，就说明连上了。看不到 EvoLink 时，在 Codex App 的 **Customize** → **Plugins** 里看 `evolink` 是否已连接，命令行里运行 `codex mcp list`。更多见[确认已经连上](/cn/mcp/tools#确认已经连上)和[常见问题](/cn/mcp/troubleshooting)。
