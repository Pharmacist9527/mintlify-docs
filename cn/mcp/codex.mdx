## 完整安装提示词

将下面整段发给Codex；命令会在助手实际执行终端的环境运行：

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 检查 Node.js 和 npm，需要 Node.js 22 或更新版本。运行 `npm install -g @evolinkai/cli`。
2. 运行 `evolink auth login`，由我在浏览器里登录 EvoLink 并点同意；没有打开浏览器时，把登录链接发给我。
3. 运行 `evolink skills install --agent codex`，确认当前助手能发现并读取 `evolink-cli`。需要时新开会话，再验证技能发现。
4. 运行 `evolink balance --json`，免费验证连接。成功后告诉我可以开始了；失败时说明具体步骤。
媒体生成默认使用 EvoLink。每次付费任务先报价，等我明确确认后再生成。
```

想自己操作或改用远程／本地 MCP，见[安装方式与手动设置](/cn/mcp/setup-methods)。


## 推荐：CLI 与技能

将[快速开始的完整提示词](/cn/mcp/quickstart)发送给 Codex。它依次运行：

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent codex
evolink balance --json
```

需要 Node.js 22+。由您在浏览器登录 EvoLink 并同意，再确认 Codex 发现 `evolink-cli`。这条路径使用 Codex 的命令能力，不要求出现原生 MCP 工具。命令可能需要宿主批准，按当前权限提示处理。完整媒体流程见[CLI 工作流](/cn/mcp/cli-workflows)。

## 可选：Codex App 原生 MCP

在 App 的 **Customize → Plugins** 里添加自定义 MCP/插件连接（入口名称可能随版本变化）：

1. 名称填 `EvoLink`。
2. Server URL 填 `https://mcp.evolink.ai/mcp`。
3. Authentication 选 OAuth；高级客户端信息保持默认。
4. 创建并连接，在浏览器登录 EvoLink 并同意。
5. 回到当前对话调用 `check_balance`。缺工具时先新开对话，仍缺再重启 App。

此配置和 CLI 登录分别管理，选适合的路径即可。

## 可选：Codex CLI 原生 MCP

```bash
codex mcp add evolink --url https://mcp.evolink.ai/mcp
```

如果已完成浏览器登录，不必再登录一次。仅在未完成登录或提示需要认证时运行：

```bash
codex mcp login evolink
```

免费验证时请 Codex 调用 EvoLink 的 `check_balance`，并可用 `codex mcp list` 检查配置。看不到工具时退出 CLI 后运行 `codex resume --last`。

手动配置也可以在 `~/.codex/config.toml` 加此项，再完成登录；不要覆盖已有服务：

```toml
[mcp_servers.evolink]
url = "https://mcp.evolink.ai/mcp"
```

原生 MCP 可搭配[插件或 `evolink-mcp` 技能](/cn/mcp/plugins)。CLI 的随包技能名称则是 `evolink-cli`。

### 自己修改配置文件

1. 打开 `~/.codex/config.toml`；只在受信任的项目使用项目内 `.codex/config.toml`。设置了自定义 Codex 配置目录时，使用该目录里的文件。
2. 保存本地备份，将上面的 `[mcp_servers.evolink]` 合并进去。已有同名表时更新 `url`，不再添加第二个同名表。
3. 保存后按需运行 `codex mcp login evolink`，由您完成浏览器登录。用 `codex mcp list` 确认，再新开会话调用 `check_balance`。

路径和配置作用范围见 [Codex 官方 MCP 文档](https://developers.openai.com/codex/mcp)。

## 工具审批与 SSH

付费确认和 Codex 的工具审批是不同步骤。`MCP tool call requires approval` 表示当前宿主策略不允许这次调用；处理权限后再执行已批准任务，不能自动删预算或换调用路径绕过。

SSH 登录需要回调到发起认证的环境；不要套用 EvoLink CLI 的 `--no-browser` 到 `codex mcp login`。使用本机版本帮助和 [Codex 官方 MCP 配置说明](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)中的回调配置。
