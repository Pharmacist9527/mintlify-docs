本页只说明 Codex 的原生 MCP 接入。远程服务使用 Streamable HTTP 与浏览器 OAuth，不要求安装 EvoLink CLI。想用命令和技能时，请看[独立 CLI 指南](/cn/cli/codex)。

## 连接远程 MCP

选择原生工具调用时，使用 **Streamable HTTP + OAuth**，服务器地址为：

```text
https://mcp.evolink.ai/mcp
```

不需要先安装 CLI。已有配置时先备份，只合并 EvoLink 项并保留其他服务；命令添加与手工配置选一种。

<Steps>

<Step title="添加远程服务器">

在已安装 Codex CLI 的终端执行：

```bash
codex mcp add evolink --url https://mcp.evolink.ai/mcp
```

成功后配置中出现 `evolink`。已有同名服务器时先查看现有配置，避免与插件重复注册。

</Step>

<Step title="完成独立的 MCP 授权">

```bash
codex mcp login evolink
```

在浏览器登录 EvoLink 并同意，等待命令完成。添加时已经完成授权的环境可跳过重复登录；`evolink auth login` 不代替这一步。

</Step>

<Step title="检查连接并查询余额">

```bash
codex mcp list
```

回到 Codex，新开会话或在会话输入 `/mcp` 查看连接，发送下方免费验证提示词。成功标志是实际获得账户余额和可用模型。

</Step>

</Steps>

如果需要手工配置，只合并用户 `~/.codex/config.toml` 或受信任项目 `.codex/config.toml` 中的这一段：

```toml
[mcp_servers.evolink]
url = "https://mcp.evolink.ai/mcp"
```

Codex App 使用自己的插件或自定义 MCP 入口配置同一 URL 与 OAuth；终端 CLI 登录不会自动连接 App。[Codex 官方说明](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。

授权后在 Agent 对话发送：

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

**成功标志：**实际调用 `check_balance` 和 `search_models` 并返回结果。请在本次 MCP 连接中实际验证工具调用。

## 更新、断开与排错

远程 MCP 服务由 EvoLink 更新。客户端修改配置后刷新实际持有连接的会话；需要重新授权时，使用该客户端自己的 OAuth 入口。要断开，在宿主 MCP 设置中禁用、退出或移除 EvoLink，保留其他服务。

| 现象 | 操作 |
|---|---|
| 已加地址但没有工具 | 确认连接已启用、授权完成，刷新会话，检查组织权限 |
| 401 或需要认证 | 在当前 MCP 客户端重新授权，保留原任务 ID |
| 403 或工具被拒绝 | 查看宿主许可、账户或 Key 状态与网络错误 |
| 等待超时或响应丢失 | 用原任务编号查询，先恢复，不重复生成 |
| 只显示链接或灰色预览 | 打开并交付原件，不自动重做 |

完整排错见[MCP 费用、授权与排错](/cn/mcp/billing#faq)。开始使用时先读[创作流程](/cn/mcp/overview#workflows)，调用形状见[MCP 工具参考](/cn/mcp/tools)。
