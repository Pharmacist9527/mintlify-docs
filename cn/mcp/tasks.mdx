## 查询已有任务

MCP `get_task` 接收 `task_id` 和 `wait_seconds`（0–45，默认 30）；等待结束仍未完成，可以继续查询同一个 ID。CLI：

```bash
evolink tasks get TASK_ID --json
evolink tasks wait TASK_ID --timeout 1800 --json
```

任务运行时可能是排队或处理中；完成状态为 `completed`，失败或取消按返回的 `failed` / `cancelled` 处理。查询免费。不要用 `generate_*` 查询进度，那会创建新的付费任务。

## 找回中断的任务

```bash
evolink tasks list --since 2h --type image --limit 10 --json
```

MCP `list_tasks` 也可以一次查 1–50 个已知 `task_ids`。指定 ID 时不再应用近期任务筛选。

近期列表覆盖整个 EvoLink 账户，按时间倒序，不仅是当前对话。用型号、时间和任务信息核对；查询一页没找到，不代表提交一定失败。CLI 保存了已开始提交的报价时，可以用 `tasks resume --quote QUOTE_ID` 恢复原请求，见[工作流](/cn/mcp/cli-workflows)。

Ctrl-C、客户端超时或关窗口只是停止本地等待，不会取消已提交的任务。目前 MCP/CLI 不提供服务端取消工具或命令。

## 交付结果

完成后至少给用户：

- 所用模型、任务 ID、完成状态。
- 每个相关结果的可打开原文件链接。
- 实际扣费；只有估价时不能称为实扣。
- 链接有效期，结果通常 24 小时后过期，建议及时保存。

小缩略图、视频首帧和音频封面不是原文件。音乐或多图任务可能有多个结果，不能只交付第一项。

## CLI 下载原文件

```bash
evolink download TASK_ID --output ./result.png --index 1 --json
```

`--index` 从 1 开始，与任务的 `results` 数组对应。目标父目录要存在，目标文件不能已存在；下载不会覆盖旧文件，最多 1 GiB。按真实媒体格式选扩展名，不会自动转码。下载成功返回本地路径、字节数和 SHA-256。

## 图片是灰框或打不开

| 现象 | 排查方式 |
|---|---|
| 原图链接能打开，内嵌图是灰框 | 客户端内嵌预览、缓存或解码问题；重新查同一任务，保留原链接 |
| 原图链接也打不开 | 检查链接有效期、HTTP 状态、网络和文件服务 |
| Python 默认下载返回 403/1010 | 使用明确的产品 User-Agent，见[排错指南](/cn/mcp/troubleshooting#下载返回-403) |
| 新 MCP 已上线，但旧消息仍是灰框 | 旧消息不自动重取预览；重新查询任务可获取新返回内容 |
| Qwen 等大图显示不顺畅 | 先用返回的小预览和原图入口区分客户端渲染与实际文件问题；不要据此重新生成 |

MCP 会尝试返回兼容的小图或视频首帧，但显示位置、尺寸、平台图标和是否可点击由客户端决定，无法保证所有客户端出现同一种卡片。不要为绕过宿主显示限制自动下载或重新编码媒体；用户明确要保存文件时，可以使用 CLI 下载。
