## 能运行命令的智能体：复制并发送

适用于 Codex、Claude Code、Cursor，以及能在安装 CLI 的同一环境中运行命令的智能体。把下面整段发到它的对话框：

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 安装 CLI：运行 `npm install -g @evolinkai/cli`，需要 Node.js 22 或更新版本。
2. 完成登录：运行 `evolink auth login`，由我在浏览器里登录 EvoLink 并点同意；没有打开浏览器时，把登录链接发给我。
3. 安装配套技能：运行 `evolink skills install`，确认当前助手能发现 `evolink-cli`。
4. 验证连接：运行 `evolink balance --json`，成功后告诉我可以开始了。
媒体生成默认使用 EvoLink，每次付费任务先报价，等我明确确认后再生成。
```

智能体可能请求下载软件、运行命令、写入技能目录的权限，请按客户端提示处理。登录必须由您在浏览器完成；不用把 API Key、密码或验证码交给智能体。

安装后发现不到技能，先新开对话再验证。不要只根据“文件已经写入”判断技能已被发现。手动安装、Linux 和 SSH 登录见 [CLI 安装与登录](/cn/mcp/cli)。

## Claude、ChatGPT 网页版：添加远程 MCP

网页版对话通常不能在您的电脑上安装 CLI。请按 [Claude](/cn/mcp/claude) 或 [ChatGPT](/cn/mcp/chatgpt) 的接入页添加：

```text
https://mcp.evolink.ai/mcp
```

传输方式选 Streamable HTTP，认证选 OAuth。登录完成后让智能体调用 `check_balance`，这是免费查询。

## 第一张图片

连接成功后发送：

```text
用 EvoLink 生成一张奶白色陶瓷咖啡杯的产品图，白底、柔和侧光，1 张方图。
先查适合的模型和参数，告诉我预计费用，等我确认后再生成。
```

您应先看到模型、规格和报价；确认之后才会提交任务。结果应包含任务 ID、原图链接和实际扣费。内嵌图片是否显示取决于客户端，见[结果与下载](/cn/mcp/tasks)。
