本页只说明 OpenClaw 的原生 MCP 接入。远程服务使用 Streamable HTTP 与浏览器 OAuth，不要求安装 EvoLink CLI。想用命令和技能时，请看[独立 CLI 指南](/cn/cli/openclaw)。

## 连接远程 MCP

选择原生工具调用时，使用 **Streamable HTTP + OAuth**，服务器地址为：

```text
https://mcp.evolink.ai/mcp
```

不需要先安装 CLI。已有配置时先备份，只合并 EvoLink 项并保留其他服务；命令添加与手工配置选一种。

<Steps>

<Step title="确认当前版本支持远程 MCP">

```bash
openclaw mcp --help
```

需要实际 Gateway 版本支持 Streamable HTTP 与 OAuth。不存在这组命令时按该版本官方指南升级，或使用[独立 CLI 指南](/cn/cli/openclaw)；不要给旧版添加猜测的参数。

</Step>

<Step title="添加连接并设置 OAuth">

```bash
openclaw mcp add evolink --url https://mcp.evolink.ai/mcp --transport streamable-http
```

在 Gateway 的 `~/.openclaw/openclaw.json` 或实际配置中，将 `mcp.servers.evolink` 的 `auth` 设为 `"oauth"`，保留命令生成的其他字段。支持控制台的版本也可在 Settings → MCP 添加并启用连接。

</Step>

<Step title="授权、探测并让 Agent 查询">

```bash
openclaw mcp login evolink
openclaw mcp doctor evolink --probe
```

完成浏览器授权后，让实际 Gateway 所属 Agent 发送下方验证提示词。修改未生效时刷新拥有连接的 Gateway 会话；只刷新笔记本终端不会刷新远端 Gateway。

</Step>

</Steps>

工具是否开放还受 OpenClaw 的工具策略控制。按 [OpenClaw 官方说明](https://docs.openclaw.ai/tools/mcp)处理版本、授权和连接所属环境。

授权后在 Agent 对话发送：

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

**成功标志**：实际调用 `check_balance` 和 `search_models` 并返回结果。请在本次 MCP 连接中实际验证工具调用。

## 更新、断开与排错

远程 MCP 服务由 EvoLink 更新。客户端修改配置后刷新实际持有连接的会话；需要重新授权时，使用该客户端自己的 OAuth 入口。要断开，在宿主 MCP 设置中禁用、退出或移除 EvoLink，保留其他服务。

| 现象 | 操作 |
|---|---|
| 已加地址但没有工具 | 确认连接已启用、授权完成，刷新会话，检查组织权限 |
| 401 或需要认证 | 在当前 MCP 客户端重新授权，保留原任务 ID |
| 403 或工具被拒绝 | 查看宿主许可、账户或 Key 状态与网络错误 |
| 等待超时或响应丢失 | 用原任务编号查询，先恢复，不重复生成 |
| 只显示链接或灰色预览 | 打开并交付原件，不自动重做 |

完整排错见[MCP 费用、授权与排错](/cn/mcp/billing#faq)。开始使用时先读[创作流程](/cn/mcp/overview#workflows)，调用形状见[MCP 工具参考](/cn/mcp/tools)。
