<AccordionGroup>
  <Accordion title="助手里看不到 EvoLink 的工具">
    先按[确认已经连上](/cn/mcp/tools#确认已经连上)里的方法看连接状态，显示需要登录的就重新登录一次。Claude Code 要重新打开，Codex 要开一个新会话，Hermes Agent 在会话里输入 `/reload-mcp`。

    Claude Code 里助手说找不到 evolink 的工具时，输入 `/mcp`，选 `evolink`，点 **Authenticate** 重新登录，再重新打开 Claude Code。
  </Accordion>
  <Accordion title="同意页显示“这个请求已失效”">
    从助手发起登录到您点同意，要在 10 分钟内完成，超过时间请求就会失效。回到助手重新发起登录即可。
  </Accordion>
  <Accordion title="同意页显示“未验证”">
    说明申请连接的助手是自己登记的（见[登录与授权](/cn/mcp/sign-in#同意页上的核对标识)），而且要把授权结果送到某个网站。只有这次连接是您自己发起的，才继续点同意。
  </Accordion>
  <Accordion title="想换一个 EvoLink 账户">
    在同意页点 **切换账户**，换成要用的账户再同意。已经连上的助手，先断开再重新连接。
  </Accordion>
  <Accordion title="Cursor：点 Connect 后登录失败">
    Cursor 登录时会在本机 8787 端口等待浏览器回调，这个端口被别的程序占着（比如 `wrangler dev`）就会失败。先关掉占用的程序，再点一次 **Connect**。见 [Cursor 接入](/cn/mcp/cursor)。
  </Accordion>
  <Accordion title="Codex：提示不认识命令，或浏览器没有打开">
    需要 Codex 0.77 或更新的版本。浏览器没打开时运行 `codex mcp login evolink`。见 [Codex 接入](/cn/mcp/codex)。
  </Accordion>
  <Accordion title="Codex：在同意页点了取消，又打开了一次登录页">
    这是 Codex 自己的重试：第一次授权没成功时，它会自动再发起一次。再点一次 **取消**，或在终端按 Ctrl+C 即可。
  </Accordion>
  <Accordion title="Hermes Agent：登录超时，或让我填 API Key">
    命令里要带上 `--auth oauth` 和 `--connect-timeout 300`。见 [Hermes Agent 接入](/cn/mcp/hermes-agent)。
  </Accordion>
  <Accordion title="OpenClaw：连不上">
    命令里要写 `--transport streamable-http`，OpenClaw 默认用的 SSE 连不上 EvoLink。见 [OpenClaw 接入](/cn/mcp/openclaw)。
  </Accordion>
  <Accordion title="通过 SSH 使用、电脑上没有浏览器">
    Claude Code 用 `claude mcp login evolink --no-browser`，Codex 用 `codex mcp login evolink --no-browser`：把打印的链接复制到您自己电脑的浏览器里打开。Hermes Agent 把浏览器最后跳转到的网址粘贴回终端；OpenClaw 用 `--code`。
  </Accordion>
  <Accordion title="Claude：提示连接器数量已满">
    Claude 免费版只能加 1 个自定义连接器。先删掉一个不用的，或者升级套餐。
  </Accordion>
</AccordionGroup>

## 常见提示

助手调用工具时遇到额度用完、余额不足、MCP 被暂停等情况，会直接告诉您原因，见[费用与额度](/cn/mcp/billing#常见提示)。

## 联系客服

上面的办法都解决不了时，发邮件到 [support@evolink.ai](mailto:support@evolink.ai)，或者在 [Discord](https://discord.gg/P9xzmJWndW) 里找我们。附上下面这些信息，能更快查到问题：

- 您的 EvoLink 账户邮箱；
- 用的是哪个助手，比如 Claude Code、Codex、ChatGPT；
- 出问题的大致时间，以及完整的报错提示；
- 生成相关的问题，附上任务编号（`task_id`）。

请不要发送 API Key 或密码。
