## 连接授权和付费确认是两回事

浏览器同意页允许客户端连接您的 EvoLink 账户，并查询或执行工具。它不代表您批准以后所有生成任务。配套技能要求先说明模型、规格、费用和未知项，等待明确确认。

批准可以覆盖明确的任务或批次及预算。新增变体、改参数、改价格或出现未知费用，应重新说明并获得相应批准。账户有余额、上传成功或此前批准过其他任务，都不等于批准本次付费生成。

这些是智能体工作规则，不是声称服务器每次都弹审批页面。`--confirm` 和客户端工具许可也不能替代用户对费用的确认。

## 凭据怎么处理

| 方式 | 凭据在哪里 |
|---|---|
| 远程 MCP | 客户端管理 OAuth 登录与令牌 |
| EvoLink CLI | 操作系统安全凭据存储；Linux 需要 Secret Service |
| 本地 API Key MCP | 由用户在本地安全配置环境变量 |

不要把 API Key、访问令牌、验证码、回调 code 或一次性上传 URL 放进聊天、仓库和公开日志。文件原链接可能在有效期内被持有者访问，分享时同样要注意内容。

## 换账户、断开与限额

- CLI 先 `evolink auth logout`，再 `evolink auth login`；原生 MCP 在对应客户端中断开并重新连接。
- CLI 登录和原生 MCP 登录分别管理，退出一处不代表所有客户端都已退出。
- 控制台的 `EvoLink MCP (OAuth)` 是浏览器授权调用共用的内部 Key，可设额度、有效期或暂停。它不是可复制的个人 API Key。
- 删除客户端连接只影响该客户端；停用这把内部 Key 会暂停账户下通过它调用的智能体。详见[费用与额度](/cn/mcp/billing)。

## 权限边界

EvoLink MCP/CLI 提供媒体生成、模型/参数/报价查询、素材上传、任务结果和余额查询。编程、网站搭建、读取普通文档和本地媒体编辑由宿主智能体自己的工具承担。

目前不提供 Key 管理、充值、账户设置修改或任务取消工具。生成完成也不自动授权智能体本地合成、转码、修改作品或再花钱修复。

## 自动化

脚本运行前明确批准范围和预算，并使用可审计的任务 ID 与原请求 ID。遇到宿主工具审批拒绝或预算检查失败，应停止并说明原因，不要改成另一种调用方式绕过限制。无人值守 Linux/SSH 环境的登录方案见 [CLI 安装与登录](/cn/mcp/cli)。
