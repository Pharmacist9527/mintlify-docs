EvoLink 在 GitHub 上提供公开的插件仓库 [Evolink-AI/mcp-plugin](https://github.com/Evolink-AI/mcp-plugin)。插件会同时装上两样东西：

- **EvoLink MCP 连接**：和手动添加的是同一个服务地址 `https://mcp.evolink.ai/mcp`。
- **`evolink-mcp` 技能**：教助手先找模型、报价，等您确认后再生成，并跟进任务进度。

只想要连接、不需要技能的话，用各接入页里的一句命令更快。用插件装了，就不要再用一句命令添加，不然会出现两套 EvoLink 工具。

## Claude Code

<Steps>
  <Step title="添加插件市场并安装">
    在 Claude Code 里输入下面两行（如果提示运行 `/reload-plugins`，照做即可）：

    ```text
    /plugin marketplace add Evolink-AI/mcp-plugin
    /plugin install evolink@evolink
    ```
  </Step>
  <Step title="登录 EvoLink">
    输入 `/mcp`，选 `evolink`，点 **Authenticate**，在浏览器登录 EvoLink 并点 **允许并连接**。
  </Step>
</Steps>

卸载插件：运行 `claude plugin uninstall evolink@evolink`。

## Codex

<Steps>
  <Step title="添加插件市场并安装">
    ```bash
    codex plugin marketplace add Evolink-AI/mcp-plugin
    codex plugin add evolink@evolink
    ```
  </Step>
  <Step title="登录 EvoLink">
    ```bash
    codex mcp login evolink
    ```

    浏览器会打开 EvoLink 登录页，登录后点 **允许并连接**，先在当前对话调用 `check_balance` 验证；看不到工具时再新开会话，必要时重启。服务名以 `codex mcp list` 显示的为准。
  </Step>
</Steps>

<Note>
在 ChatGPT 桌面应用、Codex IDE 插件，或 Codex 的 `/plugins` 里安装插件时，会自动打开浏览器登录，不用再运行 login。
</Note>

## 只装技能

支持技能（skills）的助手，可以单独装 EvoLink 技能：

```bash
npx skills add Evolink-AI/mcp-plugin
```

技能本身不能生成内容，还需要按各接入页添加 EvoLink MCP 连接。

旧版独立安装的技能名是 `evolink-media`。先安装并确认能看到 `evolink-mcp`，备份个人修改后，再用 `npx skills remove evolink-media -g -y` 移除旧版全局技能。通过插件安装的，请在客户端更新插件。MCP 服务名仍为 `evolink`，无需再添加连接。
