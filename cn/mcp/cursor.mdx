## 完整安装提示词

将下面整段发给Cursor；命令会在助手实际执行终端的环境运行：

```text
帮我设置 EvoLink，让我可以直接在这里生成图片、视频和音频。
1. 检查 Node.js 和 npm，需要 Node.js 22 或更新版本。运行 `npm install -g @evolinkai/cli`。
2. 运行 `evolink auth login`，由我在浏览器里登录 EvoLink 并点同意；没有打开浏览器时，把登录链接发给我。
3. 运行 `evolink skills install --agent cursor`，确认当前助手能发现并读取 `evolink-cli`。需要时新开会话，再验证技能发现。
4. 运行 `evolink balance --json`，免费验证连接。成功后告诉我可以开始了；失败时说明具体步骤。
媒体生成默认使用 EvoLink。每次付费任务先报价，等我明确确认后再生成。
```

想自己操作或改用远程／本地 MCP，见[安装方式与手动设置](/cn/mcp/setup-methods)。


## 推荐：CLI 与技能

把[统一安装提示词](/cn/mcp/quickstart)发给能运行终端的 Cursor Agent，或运行：

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent cursor
evolink balance --json
```

需要 Node.js 22+；由您在浏览器登录并批准连接。确认 Agent 发现 `evolink-cli`，并且安装目录在它的执行环境中可用。

## 可选：原生远程 MCP

点[添加到 Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9)，按提示安装，并在 Cursor 的 MCP 设置里登录/连接 EvoLink。

手动配置可在 `~/.cursor/mcp.json` 中合并下面的服务项，不要覆盖已有服务：

只对当前项目启用时，使用项目目录的 `.cursor/mcp.json`。编辑前保存本地备份，将 `evolink` 合并到已有 `mcpServers`；不要用示例覆盖整个文件。

```json
{
  "mcpServers": {
    "evolink": {"url": "https://mcp.evolink.ai/mcp"}
  }
}
```

连接使用 Streamable HTTP 和 OAuth。浏览器同意后，请 Agent 调用 `check_balance`，确认免费查询成功；需要原生工作规则时安装 [`evolink-mcp` 技能](/cn/mcp/plugins)。

保存后重启 Cursor，在 MCP 设置中确认 EvoLink 已启用并完成登录，再新开对话验证。若全局和项目都有同名配置，项目项优先。

## 排查

CLI 登录与 Cursor 原生 MCP 登录独立管理。CLI 接入不要求 MCP 设置出现 EvoLink；原生接入则要确认工具已加载。如果使用 Cursor 云端执行，注意安装、登录和技能所在环境可能不同于本机。

界面与能力以 [Cursor 官方 MCP 说明](https://prod.cursor.com/help/customization/mcp)为准。图片灰框但原图可打开时，见[结果与下载](/cn/mcp/tasks)，不要自动重做付费任务。
