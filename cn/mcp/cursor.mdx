本页只说明 Cursor 的原生 MCP 接入。远程服务使用 Streamable HTTP 与浏览器 OAuth，不要求安装 EvoLink CLI。想用命令和技能时，请看[独立 CLI 指南](/cn/cli/cursor)。

## 连接远程 MCP

选择原生工具调用时，使用 **Streamable HTTP + OAuth**，服务器地址为：

```text
https://mcp.evolink.ai/mcp
```

不需要先安装 CLI。已有配置时先备份，只合并 EvoLink 项并保留其他服务；命令添加与手工配置选一种。

<Steps>

<Step title="在 Cursor 添加服务器">

点[添加到 Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9)，允许浏览器打开 Cursor，检查名称为 EvoLink、地址为本页地址后确认。没有打开应用时可使用下方手工配置。

</Step>

<Step title="启用连接并授权">

打开 Cursor 的 MCP 设置，启用 EvoLink，按认证提示在浏览器登录 EvoLink 并同意。回到 Cursor 检查连接与工具列表。

</Step>

<Step title="在 Agent 中免费验证">

打开具备工具调用权限的 Agent 对话，发送下方验证提示词。未出现工具时刷新连接或新开会话，确认当前项目未覆盖或禁用全局配置。

</Step>

</Steps>

手动添加时，全局文件为 `~/.cursor/mcp.json`，仅当前项目用 `.cursor/mcp.json`。在已有 `mcpServers` 中合并：

```json
{
  "mcpServers": {
    "evolink": {
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

[Cursor 官方配置](https://cursor.com/docs/mcp)。

授权后在 Agent 对话发送：

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

**成功标志**：实际调用 `check_balance` 和 `search_models` 并返回结果。请在本次 MCP 连接中实际验证工具调用。

## 更新、断开与排错

远程 MCP 服务由 EvoLink 更新。客户端修改配置后刷新实际持有连接的会话；需要重新授权时，使用该客户端自己的 OAuth 入口。要断开，在宿主 MCP 设置中禁用、退出或移除 EvoLink，保留其他服务。

| 现象 | 操作 |
|---|---|
| 已加地址但没有工具 | 确认连接已启用、授权完成，刷新会话，检查组织权限 |
| 401 或需要认证 | 在当前 MCP 客户端重新授权，保留原任务 ID |
| 403 或工具被拒绝 | 查看宿主许可、账户或 Key 状态与网络错误 |
| 等待超时或响应丢失 | 用原任务编号查询，先恢复，不重复生成 |
| 只显示链接或灰色预览 | 打开并交付原件，不自动重做 |

完整排错见[MCP 费用、授权与排错](/cn/mcp/billing#faq)。开始使用时先读[创作流程](/cn/mcp/overview#workflows)，调用形状见[MCP 工具参考](/cn/mcp/tools)。
