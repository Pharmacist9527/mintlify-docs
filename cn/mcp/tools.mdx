## 能做什么

| 工具 | 用途 | 是否收费 |
|---|---|---|
| `search_models` | 按类型和关键词找图片、视频、音频模型 | 免费 |
| `get_model` | 查看某个模型的参数和价格 | 免费 |
| `estimate_cost` | 生成之前先报价 | 免费 |
| `generate_image` | 生成图片 | 按模型价格扣费 |
| `generate_video` | 生成视频 | 按模型价格扣费 |
| `generate_audio` | 生成音乐、歌曲或语音 | 按模型价格扣费 |
| `get_task` | 查询任务进度和结果 | 免费 |
| `list_tasks` | 查看最近的任务 | 免费 |
| `check_balance` | 查看账户余额和 MCP 已花费 | 免费 |
| `upload_file` | 把公开链接或 1 MB 以内的小文件存到 EvoLink，换成可用于生成的链接 | 免费 |
| `prepare_upload` | 拿一个一次性上传地址，用来上传最大 95 MB 的本地文件 | 免费 |
| `get_upload` | 查看一次性上传的结果，拿到文件链接 | 免费 |

直接用自然语言说就行，比如"用 z-image-turbo 画一只红苹果"。助手先说明模型、参数和预计费用，结束回复后等您明确确认，再提交付费任务。报价不完整或无法预估时，应先说明哪些费用未知，再请您决定是否继续。助手推荐的预算不是您批准的预算；变体和重新生成也是新的付费任务。只有您明确批准了任务或批次范围以及足够的预算，才能在该范围内继续。实际扣费以任务结算为准。

安装 `evolink-mcp` 技能后，媒体生成默认使用 EvoLink。只有您明确指定或同意时，才换用其他平台。这些是助手的工作规则，服务端没有逐笔审批；客户端是否弹出工具确认由客户端设置决定。

## 提供参考图片、视频或音频

EvoLink MCP 运行在 EvoLink 的服务器上，读不到您电脑里的文件路径。参考文件可以这样提供：

- **公开链接：** 直接把能公开访问的链接发给助手，它会用 `upload_file` 存到 EvoLink。
- **1 MB 以内的小文件：** 在 Claude Code、Codex、Cursor 里，助手可以读出文件内容，直接交给 `upload_file`。
- **更大的本地文件（最大 95 MB）：** 助手先用 `prepare_upload` 拿一个一次性上传地址，再运行一条 `curl` 命令把文件传上去，最后用 `get_upload` 拿到文件链接。上传地址 15 分钟内有效，只能用一次；上传结果保留 1 小时，只有您自己的账户能查。

<Note>
上传本地文件要能运行命令：Claude Code、Codex、Cursor 可以，第一次可能要您批准。Claude 网页版和桌面版、ChatGPT 一般不能运行命令，也拿不到您拖进对话的文件原件，请改用公开链接。
</Note>

上传不收费，文件保留 72 小时后删除。支持的格式：

| 类型 | 格式 |
|---|---|
| 图片 | JPEG、PNG、GIF、WebP |
| 音频 | MP3、WAV、M4A、AAC、FLAC、OGG |
| 视频 | MP4、MOV、WebM |

## 任务进度和结果

- **要等多久：** 图片一般会直接返回结果；视频通常要 3–5 分钟，音乐 20–60 秒。助手会自动查询进度，您不用一直盯着。
- **结果可以接着用：** 生成结果的链接可以直接当参考图拿去改图，或者当首帧做图生视频，不用先下载再上传。
- **中途断开了**（比如关掉了窗口），回来后对助手说"用 EvoLink 查一下我最近的任务"，它会用 `list_tasks` 找到刚才的任务，再用 `get_task` 接着查。
- **不要让助手重新生成**同一个任务来"刷新"进度，那会再扣一次费。
- **结果链接 24 小时后失效**，拿到后请及时下载保存。上传的参考文件保留 72 小时，和结果链接是两回事。

## 确认已经连上

在助手里发一句话试试。下面两句都只是查询，不扣费：

```text
用 EvoLink 查一下我的账户余额。
```

```text
用 EvoLink 找 3 个能生成视频的模型，告诉我价格。
```

助手调用了 EvoLink 的工具并给出结果，就说明连上了。第一次调用时，有的助手会先问您是否允许使用这个工具，点允许即可。

助手说找不到 EvoLink 时，先看看连接状态：

| 助手 | 怎么看 |
|---|---|
| Claude 网页版和桌面版 | **Customize → Connectors** 里 EvoLink 显示已连接，并且在对话里点 **+ → Connectors** 打开了 |
| Cursor | MCP 设置里 `evolink` 显示已连接 |
| Claude Code | 输入 `/mcp`，`evolink` 显示已连接 |
| Codex | 运行 `codex mcp list` |
| Hermes Agent | 在会话里输入 `/reload-mcp` |
| OpenClaw | 运行 `openclaw mcp doctor evolink --probe` |
| ChatGPT | 在输入框输入 `@`，能选到 EvoLink |

助手调用工具时遇到额度用完、余额不足、MCP 被暂停等情况，会直接告诉您原因，见[费用与额度](/cn/mcp/billing#常见提示)。
