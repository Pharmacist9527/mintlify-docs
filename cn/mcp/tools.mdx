以下是浏览器 OAuth 登录的远程 MCP 提供的 12 个工具。本地 stdio MCP 的工具列表和上传方式可能不同，以实际连接返回的列表为准。JSON 示例展示工具名称与参数，交由 MCP 客户端调用；不是平台 REST API 的请求体。示例不代表付费批准。

| 分组 | 工具 | 是否收费 |
|---|---|---|
| 模型 | `search_models`、`get_model` | 免费 |
| 报价 | `estimate_cost` | 免费 |
| 生成 | `generate_image`、`generate_video`、`generate_audio` | 按模型计费 |
| 任务 | `get_task`、`list_tasks` | 免费 |
| 账户 | `check_balance` | 免费 |
| 上传 | `upload_file`、`prepare_upload`、`get_upload` | 免费 |

## search_models

`type` 为 `image`、`video`、`audio`、`all`，默认 `all`；`query` 可选，最多 100 字符；`limit` 为 1–50，默认 20。返回规范 ID、别名、类型、起价、参数文档状态及适用的推荐字段。

```json
{"name":"search_models","arguments":{"type":"video","query":"seedance","limit":5}}
```

起价不是任务总价；实际选型见[模型与参数](/cn/mcp/models)。

## get_model

必填 `model`，字符串长度 1–128。返回输入要求、参数范围、示例和公开价格；缺信息时会给出提示。

```json
{"name":"get_model","arguments":{"model":"z-image-turbo"}}
```

## estimate_cost

必填 `model`；`input` 是计划提交的参数对象；可选 `media_seconds` 为大于 0、不超过 3600 的数字。它独立于 `input`，只参与估价，不发给模型。

```json
{"name":"estimate_cost","arguments":{"model":"z-image-turbo","input":{"prompt":"A cream ceramic coffee cup on a white background"}}}
```

检查输入是否有效、估价状态、警告及余额/额度是否足够。可能返回估价、部分估价、Token 计费、缺少输入或价格不可用。任何非完整报价都不能被当作可保证的总价。此工具不接收 `max_cost_usd`；原生 MCP 的预算放在生成工具，CLI 预算放在 `estimate --max-cost-usd`。见[费用与上限](/cn/mcp/billing)。

## generate_image、generate_video、generate_audio

三个工具分别提交图片、视频、音频任务，共用下列顶层参数：

| 参数 | 说明 |
|---|---|
| `model` | 必填，所选媒体类型的模型 ID，1–128 字符 |
| `input` | 模型定义的参数对象；不要在其中放 `model` 或 `callback_url` |
| `prompt` | 可选的 `input.prompt` 快捷方式，仍受模型自身限制；避免重复且冲突 |
| `client_request_id` | 可选幂等 ID，16–96 字符，字母、数字、`.`、`_`、`-`；只在重试同一请求时复用 |
| `max_cost_usd` | 可选提交前估价上限，大于 0 且不超过 10000；不是结算硬上限 |
| `media_seconds` | 同估价工具，不能把未知或部分费用变成可保证的预算 |

先查参数、报价并取得明确批准，再调用对应工具。下面仅示意一张图片的参数：

```json
{"name":"generate_image","arguments":{"model":"z-image-turbo","input":{"prompt":"A cream ceramic coffee cup on a white background"},"client_request_id":"image-coffee-demo-001"}}
```

返回 `task_id` 后用任务工具继续查询。媒体参数和工作流分别见[图片](/cn/mcp/images)、[视频](/cn/mcp/video)、[音频](/cn/mcp/audio)。

## get_task

必填 `task_id`；`wait_seconds` 是 0–45 的整数，默认 30。返回状态、进度、结果链接、费用或错误；设 0 立即查询。

```json
{"name":"get_task","arguments":{"task_id":"TASK_ID_FROM_RESPONSE","wait_seconds":30}}
```

结果通常 24 小时后过期。继续查询同一任务，不要重新生成来刷新进度。

## list_tasks

两种模式：`task_ids`（1–50 个已知 ID）批量查询，或不填 ID、按 `type` / `status` / `since` / `limit` 找近期任务。`status` 支持 `processing`、`completed`、`failed`、`cancelled`；`processing` 包含排队任务。`since` 可用 ISO 8601 或 `30m`、`2h`、`1d`；`limit` 为 1–50，默认 20。

```json
{"name":"list_tasks","arguments":{"type":"image","since":"2h","limit":10}}
```

指定 `task_ids` 时其他筛选不生效。近期任务是整个账户的任务，并非当前对话；`since` 过滤当前获取的页，不扫描全部历史。

## check_balance

无参数。返回账户余额、花费范围和额度信息。OAuth 登录的 MCP 花费覆盖同一账户连接的智能体，不能当作单次对话的花费。

```json
{"name":"check_balance","arguments":{}}
```

## upload_file

`file_url` 和 `base64_data` 二选一。`file_url` 必须是公开 HTTPS；`base64_data` 在远程 OAuth 连接中最多 1 MB，裸 base64 还需 `mime_type`，data URL 可自带 MIME。可选 `file_name`（不含文件夹）和 `upload_path`（相对路径、不含 `..`）。

```json
{"name":"upload_file","arguments":{"file_url":"https://example.com/reference.png","file_name":"reference.png"}}
```

以上域名只是占位，请换成实际可访问的文件。远程不支持 `file_path`。文件保留约 72 小时。

## prepare_upload

必填 `file_name`（扩展名决定媒体类型），可选 `upload_path`。返回一次性 `upload_url`、`upload_id`、PUT 方法、上传命令和有效期；15 分钟内最多一次，文件最大 95 MB。

```json
{"name":"prepare_upload","arguments":{"file_name":"reference.mp4"}}
```

需在能读取文件的环境执行 PUT。见[上传指南](/cn/mcp/files)。

## get_upload

必填 `upload_id`。查询同一账户的上传状态，成功返回 `file_url`；状态记录约 1 小时后过期。

```json
{"name":"get_upload","arguments":{"upload_id":"UPLOAD_ID_FROM_RESPONSE"}}
```

## 确认已经连上

让智能体查询账户余额，确认它确实调用了 `check_balance` 并成功返回。CLI 接入则运行 `evolink balance --json`，不需要客户端出现原生 MCP 工具。两者都还需确认相应技能可用。排查见[常见问题](/cn/mcp/troubleshooting)。

## 任务进度和结果

使用 `get_task` 和 `list_tasks` 继续已有任务，完成后交付原文件链接与实际费用。等待、中断恢复、预览和 CLI 下载见[任务与结果](/cn/mcp/tasks)。
