## 先查型号，再读参数

MCP 使用 `search_models` 查候选，`get_model` 查具体输入。CLI 对应：

```bash
evolink models search --type image --query seedream --limit 5 --json
evolink models show doubao-seedream-5.0-pro --json
```

可以按图片、视频、音频类型和关键词搜索。搜索会处理目录别名及连字符、点等常见写法；提交时使用查询返回的规范型号，不要凭模型名称猜 ID。

## 读懂返回内容

| 内容 | 怎么使用 |
|---|---|
| 模型 ID、类型、别名 | 选择对应图片、视频或音频工具，保存规范 ID |
| 参数与示例 | 检查必填字段、允许取值、默认值和组合限制 |
| 参考输入 | 确认是否支持图片、视频、音频，数量与尺寸是否符合要求 |
| 起价与计费单位 | 理解按张、按次、按秒或按 Token 计费；不是本次总价 |
| 参数文档或价格缺失提示 | 不要猜参数或用起价代替报价；查看模型文章或选择信息完整的型号 |
| 平台推荐字段 | 作为未指定型号时的候选提示；仍需检查适配与预算 |

目录会用平台可用模型列表过滤，并结合参数和价格信息。模型可能新增、停用或调整；请实时查询。缺少起价不等于平台没有定价，缺少参数也不等于能接受任意输入。

## 默认如何选型

用户明确指定的模型、功能和预算优先。没有指定时，可以先查这些平台偏好系列，再比较实际可用型号：

| 任务 | 候选系列 | 还要核对 |
|---|---|---|
| 图片、产品图、图片编辑 | GPT Image 2.5 / 2、Seedream 5.0 | 图片输入、输出尺寸、数量、Token 计费 |
| 视频 | Seedance 2.5 / 2.0、Wan 3.0 | 文生/图生/参考视频、时长、清晰度、声音 |
| 音乐、歌曲 | Suno v6 | 简单/自定义模式、歌词、风格和输出 |
| 配音、语音 | 搜索适合的语音模型 | 文本字段、声音、语言和参考输入 |

这些不是热度排行，也不是发布先后顺序。不要把音乐模型推荐为所有配音任务的通用模型；延长、编辑、分层或升清晰度等专用任务应匹配专用能力。

## 输入约束与校验

参数不同于自然语言描述：比如 `duration` 只能在模型支持时放进 `input`；尺寸可能要求指定格式、像素范围或倍数；有些音频的参考图片和参考音频互斥。

提交前用实际输入调用 `estimate_cost` 或 `evolink estimate`，查看校验问题与费用说明。校验通过也不是最终扣费保证；模型文档和返回的警告仍要阅读。详见[费用与上限](/cn/mcp/billing)。
