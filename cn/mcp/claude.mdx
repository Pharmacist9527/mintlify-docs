Claude 聊天客户端使用 **远程 MCP**。本页操作在客户端设置和浏览器中完成，不需要安装本地 CLI 或提供个人 API Key。

## 开始前准备

准备可登录的 EvoLink 账户与 Claude 账户，以及允许添加自定义 MCP 的客户端版本、套餐和工作区权限。没有添加入口时先确认宿主权限，不要在聊天框执行 npm。

## 按顺序连接 EvoLink

<Steps>

<Step title="打开添加连接器入口">

点[添加到 Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp)。该按钮与官网一致，预填 EvoLink 名称与地址。按钮不能打开时，在 Claude 的 Connectors / 连接器设置选择添加自定义连接器。

</Step>

<Step title="核对服务器地址并添加">

名称填写 EvoLink，远程服务器 URL 填：

```text
https://mcp.evolink.ai/mcp
```

选择支持 Streamable HTTP 的远程连接，使用 OAuth / 浏览器登录。不要填文档链接或平台 REST 地址。保存后确认列表出现 EvoLink。

</Step>

<Step title="在浏览器登录并同意">

点连接/认证，按提示登录 EvoLink，核对账户和申请权限，点同意后回到原来的 Claude 页面。没有自动弹出页面时使用当前流程给出的登录入口；旧链接超时后重新发起。

</Step>

<Step title="在对话中启用并验证">

在新对话的连接器/工具选择中启用 EvoLink，再发送下一节的免费验证提示词。只保存连接器还不表示当前对话会调用它。

**成功标志：**实际查询余额与可用模型。Claude Code 是独立终端客户端，使用[自己的安装页](/cn/mcp/claude-code)。

</Step>

</Steps>

连接器入口、套餐与工作区限制以 [Claude 官方指南](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)为准。

## 免费验证与第一次创作

连接完成后，把下面提示词发到已启用 EvoLink 的对话：

```text
请使用 EvoLink 查询账户余额，并搜索可用图片模型，先不要生成。
```

确认助手调用 `check_balance` 与 `search_models`。登录与这些查询不创建付费媒体任务。生成前描述内容与规格，让助手先给方案、模型、参数和报价，您明确确认后才提交。完整例子见[首次创作](/cn/mcp/overview#workflows)。

参考素材可使用模型支持的公开文件链接。聊天附件未必能让 MCP 读取原始文件；远程服务不能读取电脑路径。上传步骤见[素材说明](/cn/mcp/overview#files)。

## 常见问题

| 现象 | 按顺序处理 |
|---|---|
| 没有自定义连接入口 | 核对套餐、版本和工作区权限；按当前宿主的设置办理 |
| 登录后仍提示未授权 | 返回原客户端完成连接，使用当前登录流程；见[授权排错](/cn/mcp/billing#login) |
| 已添加但对话没有工具 | 确认安装/启用、选择 EvoLink、新开对话；见[MCP 排错](/cn/mcp/billing#mcp-connection) |
| 能查余额但生成工具不可用 | 在宿主查看生成工具开关与工作区权限，不改用 Key 绕过 |
| 网络超时或 403 | 核对错误发生在宿主、登录页还是工具请求；保留时间与错误交给支持排查 |
| 已生成但只有链接或灰色缩略图 | 打开并保存原件；见[下载与预览排错](/cn/mcp/billing#download) |

## 更新与断开

工具变更后，在客户端刷新连接与工具列表，必要时新开对话。授权过期则通过当前宿主重新认证。要停止此客户端访问，在它自己的设置断开/退出连接；共享 Key 暂停与额度在 EvoLink 控制台管理。插件区别见[插件指南](/cn/mcp/plugins)，统一费用和更多问题见[费用与排错](/cn/mcp/billing#faq)。
