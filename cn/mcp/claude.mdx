Claude 的聊天界面使用远程 MCP 连接器。CLI 安装提示词适合 [Claude Code](/cn/mcp/claude-code)，不要把聊天版和能运行终端的编程智能体混为一谈。

## 添加与登录

1. 打开 [Claude 连接器](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp)，或在 **Customize → Connectors** 选择添加自定义连接器。
2. 名称填 `EvoLink`，URL 填 `https://mcp.evolink.ai/mcp`。
3. 按页面确认认证设置；选浏览器登录，OAuth client 使用 Claude 推荐的身份设置，不需 API Key。
4. 连接 EvoLink，在浏览器登录并点 **允许并连接**。
5. 在对话的 **+ → Connectors** 启用 EvoLink，查询账户余额，确认 `check_balance` 成功。

团队或企业工作区可能需要有连接器管理权限的人先为组织添加，再由成员各自连接。套餐、添加入口和跨设备同步以 [Claude 官方连接器说明](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)及当前账户界面为准。

## 使用示例

```text
用 EvoLink 找适合生成五秒横版视频的模型，告诉我支持的参数和本次报价。
先不提交生成，等我确认。
```

查询免费。确认后才能运行付费任务；选 Allow once 或其他工具许可不代表用户批准了任意后续费用。见[费用与上限](/cn/mcp/billing)。

## 参考素材与显示

网页或聊天桌面版通常不能直接运行电脑上的上传命令，也不一定能把拖进对话的附件原件提供给模型。优先提供公开 URL，见[上传指南](/cn/mcp/files)。

客户端控制平台图标、工具卡片和缩略图是否出现。任务完成后应始终交付原链接和实际费用。连不上时检查账户/组织权限、OAuth 和网络，再查[排错指南](/cn/mcp/troubleshooting)；不要以重新生成修复显示问题。
