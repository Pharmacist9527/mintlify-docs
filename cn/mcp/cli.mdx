用 Claude Code、Codex 这类命令行 Agent 时，不用自己一条条敲命令：把下面这段话复制给 Agent，它会装好 EvoLink 技能、接上 EvoLink MCP，再带您在浏览器登录 EvoLink。不需要 API Key。

## 复制这段话

```text
帮我接入 EvoLink，让我能在这里生成图片、视频和音频。
1. 安装配套技能：运行 `npx skills add Evolink-AI/mcp-plugin -g -y`。
2. 添加 EvoLink MCP 服务并开始登录：
   - Claude Code：运行 `claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp`，请我用 `claude --continue` 重新打开你，再调用 evolink 的 authenticate 工具，把登录链接发给我。
   - Codex：运行 `codex mcp add evolink --url https://mcp.evolink.ai/mcp`，它会在浏览器里打开登录页（没打开的话，把它打印的链接发给我）。然后请我用 `codex resume --last` 重新打开你。
   - 其他命令行 Agent：把 `https://mcp.evolink.ai/mcp` 加成远程 MCP 服务（Streamable HTTP），需要登录时用 OAuth。
3. 我会在浏览器里登录 EvoLink 并点同意。
完成后告诉我已经可以用了。
```

## 接下来会发生什么

<Steps>
  <Step title="Agent 安装技能">
    Agent 运行 `npx skills add Evolink-AI/mcp-plugin -g -y`，把 EvoLink 技能装到 `~/.agents/skills/evolink-media`，Claude Code 也能直接用。技能会教 Agent 先报价、等您确认再生成。Agent 第一次运行命令时，可能会先请您批准。
  </Step>
  <Step title="Agent 添加 EvoLink，开始登录">
    - **Claude Code**：加好以后，Agent 会请您用 `claude --continue` 重新打开它，接着原来的对话；然后它调用 evolink 的 authenticate 工具，把登录链接发给您。您也可以输入 `/mcp`，选 `evolink`，点 **Authenticate**。
    - **Codex**：添加时会自动打开浏览器登录页；没打开的话，Agent 会把链接发给您。登录后请用 `codex resume --last` 重新打开 Codex，接着原来的对话。
  </Step>
  <Step title="在浏览器登录并同意">
    登录 EvoLink 后点 **允许并连接**，回到 Agent 就可以用了。
  </Step>
</Steps>

<Note>
Agent 自己运行命令的终端不能交互，`claude mcp login` 在里面会失败，所以 Claude Code 要先重新打开，再用 authenticate 工具登录。
</Note>

## 想自己运行命令

- Claude Code、Codex 的一句命令见 [Claude Code](/cn/mcp/claude-code) 和 [Codex](/cn/mcp/codex)；其他命令行 Agent 见[其他客户端](/cn/mcp/other-clients)。
- 只装技能、不用 Agent 帮忙：见[插件与技能](/cn/mcp/plugins)。
- 不想在浏览器登录，想用自己的 API Key：见[本地版（API Key）](/cn/mcp/local)。

## 试一下

在对话里发这句话，只是查询，不扣费：

```text
用 EvoLink 查一下我的账户余额。
```

助手调用了 EvoLink 的工具并给出结果，就说明连上了。更多见[确认已经连上](/cn/mcp/tools#确认已经连上)和[常见问题](/cn/mcp/troubleshooting)。
