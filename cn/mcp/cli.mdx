Claude Code 和 Codex 有各自的接入页，见 [Claude Code](/cn/mcp/claude-code) 和 [Codex](/cn/mcp/codex)。用其他命令行 Agent 时，不用自己一条条敲命令：把下面这段话复制给 Agent，它会装好 EvoLink 技能、把 EvoLink 加成远程 MCP 服务，再带您在浏览器登录 EvoLink。不需要 API Key。

## 复制这段话

```text
帮我接入 EvoLink，让我能在这里生成图片、视频和音频。
1. 安装配套技能：运行 `npx skills add Evolink-AI/mcp-plugin -g -y`。
2. 把 `https://mcp.evolink.ai/mcp` 加成远程 MCP 服务（Streamable HTTP），名称 `evolink`，登录用 OAuth。
3. 开始登录：我会在浏览器里登录 EvoLink 并点同意；浏览器没打开的话，把登录链接发给我。要重新打开你才能用的话，告诉我怎么做。
完成后告诉我已经可以用了。
```

## 接下来会发生什么

<Steps>
  <Step title="Agent 安装技能">
    Agent 运行 `npx skills add Evolink-AI/mcp-plugin -g -y`，把 EvoLink 技能装到 `~/.agents/skills/evolink-mcp`。技能会教 Agent 能报价的先报价，等您确认再生成。Agent 第一次运行命令时，可能会先请您批准。
  </Step>
  <Step title="Agent 添加 EvoLink">
    Agent 用它自己的命令或配置，把 `https://mcp.evolink.ai/mcp` 加成远程 MCP 服务，名称 `evolink`，登录方式选 OAuth。各家的写法不同，可以参考 [OpenClaw](/cn/mcp/openclaw)、[Hermes Agent](/cn/mcp/hermes-agent) 和[其他客户端](/cn/mcp/other-clients)。
  </Step>
  <Step title="在浏览器登录并同意">
    浏览器会打开 EvoLink 登录页；没打开的话，Agent 会把登录链接发给您。登录后点 **允许并连接**。有的 Agent 要重新打开才能用上新加的服务，它会告诉您怎么做。
  </Step>
</Steps>

## 想自己运行命令

- Claude Code、Codex：见各自的接入页 [Claude Code](/cn/mcp/claude-code) 和 [Codex](/cn/mcp/codex)。
- 其他命令行 Agent：见 [OpenClaw](/cn/mcp/openclaw)、[Hermes Agent](/cn/mcp/hermes-agent) 和[其他客户端](/cn/mcp/other-clients)。
- 只装技能：见[插件与技能](/cn/mcp/plugins)。
- 不想在浏览器登录，想用自己的 API Key：见[本地版（API Key）](/cn/mcp/local)。

## 试一下

在对话里发这句话，只是查询，不扣费：

```text
用 EvoLink 查一下我的账户余额。
```

助手调用了 EvoLink 的工具并给出结果，就说明连上了。更多见[确认已经连上](/cn/mcp/tools#确认已经连上)和[常见问题](/cn/mcp/troubleshooting)。
