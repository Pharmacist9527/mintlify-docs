不想用浏览器登录，或者想让助手直接上传您电脑上的文件，可以用本地版：npm 包 `@evolinkai/mcp` 在您的电脑上运行，用您自己的 API Key 调用 EvoLink。查模型、报价、生成、查任务和余额、上传文件的工具都有；生成按模型价格扣费，花费记在这把 Key 上。

<Note>
需要 Node.js 18 或更高版本。在终端运行 `node -v` 可以查看版本。
</Note>

## 本地版和远程版的区别

| | 远程版（其他接入页） | 本地版（本页） |
|---|---|---|
| 在哪里运行 | EvoLink 的服务器 `https://mcp.evolink.ai/mcp` | 您的电脑 |
| 怎么接入 | 浏览器登录并同意，不用 API Key | 用您自己的 API Key |
| 花费记在哪把 Key 上 | `EvoLink MCP (OAuth)` | 您给它用的那把 Key |
| 上传本地文件 | 见[提供参考图片、视频或音频](/cn/mcp/tools#提供参考图片、视频或音频) | 直接读您允许的文件夹，单个最大 100 MB |
| 需要安装 | 不需要 | Node.js 18+ |

## 接入步骤

<Steps>
  <Step title="新建一把 API Key">
    在控制台 [API Keys](https://evolink.ai/dashboard/keys) 新建一把 Key。建议只给 MCP 用，这样能单独设额度或停用，不影响其他 Key。
  </Step>
  <Step title="把 EvoLink 加到您的客户端">
    把命令里的 `YOUR_API_KEY` 换成您的 Key，在您自己的终端里运行。不要把 Key 发到和助手的对话里；Key 会保存在您电脑上的客户端配置里。

    <Tabs>
      <Tab title="Claude Code">
        ```bash
        claude mcp add evolink --scope user -e EVOLINK_API_KEY=YOUR_API_KEY -- npx -y @evolinkai/mcp@latest
        ```
      </Tab>
      <Tab title="Codex">
        ```bash
        codex mcp add evolink --env EVOLINK_API_KEY=YOUR_API_KEY -- npx -y @evolinkai/mcp@latest
        ```
      </Tab>
      <Tab title="Cursor、Claude 桌面版等">
        把下面的内容加进 MCP 配置文件，比如 Cursor 的 `~/.cursor/mcp.json`、Claude 桌面版的 `claude_desktop_config.json`：

        ```json
        {
          "mcpServers": {
            "evolink": {
              "command": "npx",
              "args": ["-y", "@evolinkai/mcp@latest"],
              "env": { "EVOLINK_API_KEY": "YOUR_API_KEY" }
            }
          }
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="重启客户端">
    重启客户端。在 Claude Code 里输入 `/mcp`，能看到 `evolink` 已连接，就可以用了。第一次启动要下载程序，可能要等几秒。
  </Step>
</Steps>

<Warning>
之前加过远程版？两个都叫 `evolink`，先删掉远程版再添加，不然会出现两套 EvoLink 工具：

```bash
# Claude Code
claude mcp remove evolink --scope user
# Codex
codex mcp remove evolink
```

用插件装过的，先运行 `claude plugin uninstall evolink@evolink`。
</Warning>

## 上传本地文件

想让助手直接上传您电脑上的文件，再加一个环境变量 `EVOLINK_UPLOAD_ALLOWED_DIRS`，值是允许它读取的文件夹：

- 写绝对路径；多个文件夹在 macOS 和 Linux 上用 `:` 隔开，在 Windows 上用 `;` 隔开。
- 助手只能读这些文件夹里的文件，单个最大 100 MB。支持图片（JPEG、PNG、GIF、WebP）、音频（MP3、WAV、M4A、AAC、FLAC、OGG）和视频（MP4、MOV、WebM）。
- 上传的文件保留 72 小时。没设置这个变量时，本地文件传不了，请给公开链接。

以 Claude Code 为例，用这条命令代替上面那条：

```bash
claude mcp add evolink --scope user -e EVOLINK_API_KEY=YOUR_API_KEY -e EVOLINK_UPLOAD_ALLOWED_DIRS=/Users/you/Pictures -- npx -y @evolinkai/mcp@latest
```

Codex 用 `--env EVOLINK_UPLOAD_ALLOWED_DIRS=…`，JSON 配置写进 `env` 里。

## 试一下

在对话里发这句话，只是查询，不扣费：

```text
用 EvoLink 查一下我的账户余额。
```

助手调用了 EvoLink 的工具并给出结果，就说明连上了。

## 遇到问题

<AccordionGroup>
  <Accordion title="evolink 显示连接失败">
    多半是 Key 没填或填错了：没有 Key 时程序一启动就会退出。再运行 `node -v`，确认装了 Node.js 18 或更高版本。改好后重启客户端。
  </Accordion>
  <Accordion title="换一把 Key">
    先删掉 `evolink`（命令见上面的提示），再用新 Key 重新运行添加命令。
  </Accordion>
  <Accordion title="暂停或限制花费">
    在 [API Keys](https://evolink.ai/dashboard/keys) 里给这把 Key 设额度，或者停用它。本地版不会出现 `EvoLink MCP (OAuth)`，花费都记在您给它用的那把 Key 上。费用规则见[费用和额度](/cn/mcp/billing)。
  </Accordion>
  <Accordion title="更新到新版本">
    命令里的 `@latest` 让客户端每次启动时都用最新版本，不用手动更新。
  </Accordion>
</AccordionGroup>
