OpenClaw puede ejecutar tareas multimedia mediante EvoLink CLI. Esta página trata las diferencias de entorno y de habilidades de este host; el procedimiento común completo está en [Instalación e inicio de sesión](/es/cli/setup). Para usar herramientas nativas, ve directamente a la [guía de MCP](/es/mcp/openclaw).

## Pide a tu agente que lo instale

Pega lo siguiente en la conversación con el agente. Coincide con el prompt del sitio web. Completa tú mismo el inicio de sesión en el navegador y la revisión de permisos.

```text
Configura EvoLink para que pueda generar imágenes, vídeos y audio directamente aquí.
1. Instala la CLI: ejecuta `npm install -g @evolinkai/cli`.
2. Inicia sesión: ejecuta `evolink auth login`.
3. Instala la habilidad complementaria: ejecuta `evolink skills install`.
4. Verifica la conexión y, cuando funcione, dime que puedo empezar.
```

## Tres pasos para este cliente

<Steps>
  <Step title="Completa la instalación común y el inicio de sesión">
    Instala en el equipo y con el usuario que ejecutan el Gateway; cuando haga falta, vuelve a cargar las habilidades con el procedimiento del host. Que funcione en tu equipo de escritorio no demuestra que esté disponible en remoto.

    Si es tu primera vez, abre la [guía de cinco pasos](/es/cli/setup#cli-install): comprueba Node.js 22+, instala la CLI y completa el inicio de sesión en el navegador. Incluye los comandos, los indicadores de éxito y la solución de problemas. Si ya lo has hecho, verifica:

    ```bash
    evolink --version
    evolink auth status --json
    ```

    Deben aparecer una versión de la CLI y authenticated: true. Según la etapa que falle, consulta [errores de instalación](/es/cli/billing#cli-install), [errores de inicio de sesión](/es/cli/billing#login) o [callbacks por SSH](/es/cli/setup#ssh-login).
  </Step>
  <Step title="Sincroniza la habilidad de este agente y verifica la detección">
    ```bash
    evolink skills install --agent openclaw
    evolink skills status --agent openclaw --json
    ```

    El directorio es ~/.openclaw/skills/evolink-cli. current: true significa que los archivos coinciden con la CLI. Pide al agente:

    ```text
    Confirma que esta sesión puede detectar y leer la habilidad evolink-cli. Verifica el acceso sin generar contenido multimedia.
    ```

    assistant_discovery: not_checked sigue requiriendo la verificación del host. Sigue [Detección de habilidades](/es/cli/billing#skills-discovery) si los archivos existen pero no se usan. Revisa los permisos de ejecución necesarios y conserva los cambios personales.
  </Step>
  <Step title="Verifica gratis antes de crear contenido multimedia">
    ```bash
    evolink balance --json
    evolink doctor --agent openclaw --json
    ```

    La configuración está completa cuando balance devuelve los datos de la cuenta, doctor indica ok, connection_verified y model_discovery_verified con valor true, y el agente confirma que ha leído la habilidad. Estas consultas no crean tareas multimedia de pago. Con saldo cero también se puede verificar la conexión.
  </Step>
</Steps>

### Configuración combinada con la CLI ya instalada

```bash
evolink setup --agent openclaw --json
```

Este comando comprueba el entorno, sincroniza las habilidades, inicia sesión si hace falta y verifica el acceso. Debe aparecer setup_complete: true; la detección por parte del host aún debe confirmarse. Usa phase, steps, error y recovery para identificar los fallos.

## Actualiza y cierra sesión

A partir de la CLI 0.10.0, la propia CLI avisa de las versiones nuevas; consulta [Cómo saber si hay una versión nueva](/es/cli/setup#update-check). Después de actualizar la CLI, sincroniza la habilidad del agente actual:

```bash
npm install -g @evolinkai/cli@latest
evolink --version
evolink skills install --agent openclaw
evolink skills status --agent openclaw --json
```

Los cambios locales se conservan; resuelve los estados `modified` o `conflict` con la [solución de problemas de habilidades](/es/cli/billing#skills-discovery). Ejecuta lo siguiente solo cuando quieras cerrar sesión en la CLI; no es un paso de instalación ni de actualización.

```bash
evolink auth logout
```

## Por dónde empezar a solucionar problemas

| Síntoma | Siguiente paso |
|---|---|
| Falta npm o evolink, problemas de permisos o tiempo de espera agotado en la instalación | [Entorno e instalación](/es/cli/billing#cli-install) |
| El navegador no se abrió, se agotó el tiempo de espera de OAuth o hay un error del almacén de credenciales | [Inicio de sesión y callbacks](/es/cli/billing#login); [Inicio de sesión por SSH](/es/cli/setup#ssh-login) |
| La habilidad está instalada, pero el agente no la usa | [Detección de habilidades y permiso de ejecución](/es/cli/billing#skills-discovery) |
| Se agotó el tiempo de espera de una tarea enviada o se perdió el resultado | [Recupera la tarea original](/es/cli/billing#tasks-and-recovery) |

Una vez conectado, sigue el [primer flujo de trabajo multimedia](/es/cli/workflows#workflows): revisa los modelos, los parámetros y los costos, aprueba y después envía. Los comandos completos están en la [referencia de comandos de la CLI](/es/cli/reference).
