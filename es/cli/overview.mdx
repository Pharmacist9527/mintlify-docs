Usa el [resumen de CLI/MCP](/es/cli-mcp/overview) para elegir según tu cliente. Los recursos comunes de esta sección tratan los costos, las tareas, los archivos y las instrucciones para agentes.

EvoLink CLI permite a los agentes con acceso a la terminal y a quienes trabajan directamente en ella generar imágenes, video, música y voz, revisar modelos y parámetros, consultar el saldo y las tareas, subir referencias y guardar los originales.

Esta sección describe la versión publicada **CLI 0.14.1**. Requiere Node.js 22+ en macOS, Windows o Linux. Instálala con el usuario y en el equipo donde el agente ejecuta los comandos. El contenido multimedia sigue la ruta **agente/terminal → CLI → API de la plataforma**.

## Instalación y verificación

Envía este prompt a un agente con acceso a la terminal. Coincide con el prompt de instalación del sitio web:

```text
Configura EvoLink para que pueda generar imágenes, vídeos y audio directamente aquí.
1. Instala la CLI: ejecuta `npm install -g @evolinkai/cli`.
2. Inicia sesión: ejecuta `evolink auth login`.
3. Instala la habilidad complementaria: ejecuta `evolink skills install`.
4. Verifica la conexión y, cuando funcione, dime que puedo empezar.
```

Pega el prompt en el chat; los comandos se ejecutan en la terminal del agente o en la tuya. Completa tú mismo el inicio de sesión en el navegador y la concesión de permisos. Consulta [Instalación e inicio de sesión](/es/cli/setup) para ver los pasos detallados, los indicadores de éxito, las actualizaciones, el cierre de sesión y los callbacks por SSH.

La secuencia manual básica es:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
evolink doctor --json
```

Espera a que termine el inicio de sesión antes de continuar. No pegues el bloque entero pasando por alto la autorización. Pide al agente que confirme que ha leído evolink-cli. Las consultas de saldo y de diagnóstico no crean tareas multimedia de pago; empieza a crear después de la verificación.

## Capacidades de la CLI

| Capacidad | Uso y guía |
|---|---|
| Entorno y acceso | version, auth, setup, doctor; [instalación](/es/cli/setup) |
| Modelos y parámetros | models search/recommend/show/schema, docs search; [referencia](/es/cli/reference) |
| Estimación y aprobación | estimate crea una cotización local; generate después de la aprobación; [flujo de trabajo](/es/cli/workflows) |
| Contenido multimedia | Imágenes, video, música y voz, según las capacidades de cada modelo |
| Referencias | upload para archivos locales; uploads get consulta el comprobante original |
| Tareas | get/wait, batch, historial paginado y recuperación a partir de la cotización |
| Descarga de originales | Un resultado o todos, comprobaciones de formato y recuperación de descargas en lote |
| Cuenta y uso | balance y usage con un historial acotado, no una factura completa |
| Habilidades | skills install/status y comprobaciones de detección en el host |

La CLI no ofrece chat de texto general, cancelación de tareas en cola, recarga de saldo, gestión de claves, edición automática ni alojamiento de videos terminados. El desarrollo de código y la edición de archivos arbitrarios son capacidades del agente host. Entrega primero los originales generados; las variantes nuevas, las ediciones y las regeneraciones necesitan la aprobación correspondiente.

## Primera creación

```text
Usa EvoLink para crear una imagen publicitaria de una marca de café.
Consulta primero los modelos de imagen disponibles, los parámetros y el costo, y después explica la recomendación y la especificación de salida.
Envía una sola vez tras mi aprobación explícita, guarda el identificador de la tarea y descarga el original indicando el costo real informado.
```

Sigue el flujo [modelo → referencias → estimación → aprobación → tarea → descarga](/es/cli/workflows). La instalación no equivale a aprobar una generación de pago. Las estimaciones no son la liquidación final; consulta [costos y solución de problemas](/es/cli/billing).

## CLI y MCP

La instalación de la CLI incluye el ejecutable, los módulos de negocio compartidos y la habilidad evolink-cli incluida en el paquete. No requiere clonar los repositorios de MCP ni de plugins, y tampoco registra el MCP nativo. Passport proporciona OAuth; el sistema operativo guarda las credenciales de forma segura.

Las sesiones de la CLI y del MCP remoto se gestionan por separado. Actualmente, el OAuth de la cuenta comparte los permisos, los límites y el estado de pausa de la clave interna. Para Claude o ChatGPT en la web, o para invocar herramientas nativas, usa la [sección aparte de MCP](/es/mcp/overview).
