<Note>
**BaseURL**: La BaseURL predeterminada es `https://direct.evolink.ai`, que ofrece mejor compatibilidad con modelos de texto y admite conexiones persistentes. `https://api.evolink.ai` es el endpoint principal para servicios multimodales y actúa como dirección de respaldo para los modelos de texto.
</Note>

<Note>
**Las herramientas del lado del servidor** (búsqueda web, búsqueda en X, ejecución de código, búsqueda de adjuntos, búsqueda de colecciones) solo están disponibles en la [Responses API](../responses/responses-reference). El endpoint Chat Completions solo admite las llamadas a herramientas `function` normales.
</Note>
