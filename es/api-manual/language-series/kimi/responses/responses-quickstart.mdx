<Note>
**BaseURL**: La BaseURL predeterminada es `https://direct.evolink.ai`, que ofrece mejor compatibilidad con los modelos de texto y las conexiones de larga duración. `https://api.evolink.ai` es el endpoint principal para los servicios multimodales y sirve como dirección de respaldo para los modelos de texto.
</Note>

Usa `POST /v1/responses` y selecciona `kimi-k3.1-pro`, `kimi-k3.1-pro-highspeed` o `kimi-k3` con `model`. Solo se requieren `model` e `input`.

<Warning>
**Los nombres de los parámetros difieren de Chat Completions**: usa `input` para la entrada, `max_output_tokens` para el límite de salida y `reasoning.effort` para el esfuerzo de razonamiento.
</Warning>

## Leer el texto de respuesta

El campo `output` puede incluir razonamiento, texto de respuesta y llamadas a herramientas. Recorre los bloques de contenido `output_text` de los elementos `type="message"`; no supongas que el primer elemento contiene la respuesta.

Si el JSON de la respuesta ya se ha analizado en `response`, extrae el texto así:

```python
text = "".join(
    part["text"]
    for item in response.get("output", [])
    if item.get("type") == "message"
    for part in item.get("content", [])
    if part.get("type") == "output_text"
)
print(text)
```

<Note>
**Reserva presupuesto de salida para el razonamiento**: `max_output_tokens` incluye el razonamiento y la respuesta. Si `status="incomplete"` e `incomplete_details.reason="max_output_tokens"`, aumenta el límite. Al agotarse el presupuesto, la respuesta puede contener solo elementos de razonamiento, sin texto de respuesta.
</Note>

Para llamadas a herramientas, búsqueda web, imágenes de entrada y salida estructurada, consulta la [referencia completa](/es/api-manual/language-series/kimi/responses/responses-reference).
