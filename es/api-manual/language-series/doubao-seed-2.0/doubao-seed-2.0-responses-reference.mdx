<Note>
**BaseURL**: La BaseURL predeterminada es `https://direct.evolink.ai`, que ofrece mejor compatibilidad con modelos de texto y admite conexiones persistentes. `https://api.evolink.ai` es el endpoint principal para servicios multimodales y actúa como dirección de respaldo para los modelos de texto.
</Note>

<Note>
Solo Seed 2.1 y `doubao-seed-evolving` admiten búsqueda web. Cada búsqueda realizada se cobra según su fuente. La caché explícita conlleva un coste adicional de almacenamiento. Consulta `caching` y `expire_at`. Los dos ejemplos de caché explícita del menú de solicitudes omiten `expire_at`, por lo que el almacenamiento se factura por el período predeterminado de tres días.
</Note>

## Generar una solicitud de caché que caduque en una hora

Ejecuta este código Python justo antes del envío y usa el JSON generado como cuerpo de la solicitud. Deja `PREVIOUS_RESPONSE_ID` sin definir en la primera solicitud. Para continuar, asígnale el `id` real de la respuesta anterior y vuelve a ejecutar el código. Cada ejecución calcula un nuevo `expire_at`.

```python
import json
import os
import time

body = {
    "model": "doubao-seed-2-1-pro",
    "input": "Manual del producto: el motor y la batería tienen dos años de garantía. Recuerda esta política.",
    "caching": {"type": "enabled"},
    "expire_at": int(time.time()) + 3600,
}
previous_id = os.getenv("PREVIOUS_RESPONSE_ID")
if previous_id:
    body["previous_response_id"] = previous_id
    body["input"] = "¿Qué piezas cubre la garantía?"
print(json.dumps(body, ensure_ascii=False))
```
