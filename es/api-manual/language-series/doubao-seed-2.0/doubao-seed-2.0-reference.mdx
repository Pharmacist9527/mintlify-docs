<Note>
**BaseURL**: La BaseURL predeterminada es `https://direct.evolink.ai`, que ofrece mejor compatibilidad con modelos de texto y admite conexiones persistentes. `https://api.evolink.ai` es el endpoint principal para servicios multimodales y actúa como dirección de respaldo para los modelos de texto.
</Note>

<Note>
Solo `doubao-seed-2-1-lite` admite entradas de audio. La búsqueda web está disponible en [Responses](/es/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-responses-reference) o [Messages](/es/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-messages-reference) con Seed 2.1 y `doubao-seed-evolving`. Chat Completions no la admite.
</Note>
