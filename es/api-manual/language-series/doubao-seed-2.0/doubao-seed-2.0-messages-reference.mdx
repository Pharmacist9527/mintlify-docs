<Note>
**BaseURL**: La BaseURL predeterminada es `https://direct.evolink.ai`, que ofrece mejor compatibilidad con modelos de texto y admite conexiones persistentes. `https://api.evolink.ai` es el endpoint principal para servicios multimodales y actúa como dirección de respaldo para los modelos de texto.
</Note>

<Note>
Solo Seed 2.1 y `doubao-seed-evolving` admiten `web_search_20250305`. Messages no admite audio. Para enviar audio con `doubao-seed-2-1-lite`, usa [Chat Completions](/es/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-reference) o [Responses](/es/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-responses-reference).
</Note>
