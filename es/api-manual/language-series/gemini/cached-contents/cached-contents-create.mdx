<Note>
**BaseURL**: Use `https://direct.evolink.ai` por defecto, con mejor soporte para modelos de texto y conexiones largas; `https://api.evolink.ai` es la dirección alternativa.
</Note>

Cree una caché para un prefijo largo reutilizable (documentos, instrucciones del sistema o herramientas). Las generaciones siguientes solo envían el nombre y una pregunta nueva. Los tokens en caché se cobran a la tarifa de acierto; mientras exista, el almacenamiento se cobra por tokens y duración.

## Modelos compatibles

| Familia | Modelos |
|---|---|
| Gemini 3.x Flash | `gemini-3.8-flash`, `gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-3-flash-preview` |
| Gemini 3.x Flash-Lite | `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite-preview` |
| Gemini 3.x Pro | `gemini-3.1-pro-preview`, `gemini-3.1-pro-preview-customtools`, `gemini-3-pro-preview` |

Gemini 4 no admite caché explícita; crearla devuelve 400 `EXPLICIT_CACHE_UNSUPPORTED`.

## Caché explícita e implícita

| | Caché implícita (por defecto) | Caché explícita (esta página) |
|---|---|---|
| Uso | Sin cambios; un prefijo idéntico puede acertar automáticamente | Crear la caché y referenciar su nombre al generar |
| Acierto | No garantizado | Referenciar la caché produce un acierto |
| Coste de escritura | Ninguno | Según tokens en caché |
| Coste de almacenamiento | Ninguno | Tokens en caché × horas |
| Uso adecuado | Reutilización natural sin cambios | Muchas llamadas con el mismo prefijo largo durante un periodo |

## Flujo de uso

1. **Crear**: `POST /v1beta/cachedContents`, con el prefijo en al menos uno de `contents`, `systemInstruction` o `tools`. Devuelve `name`.
2. **Referenciar**: añada `"cachedContent": "<name>"` al cuerpo de `POST /v1beta/models/{model}:generateContent` (`streamGenerateContent` para streaming), y solo la pregunta nueva en `contents`.
3. **Ampliar** (opcional): `PATCH /v1beta/cachedContents/{id}` con un nuevo `ttl` o `expireTime`. Se cobra el almacenamiento del tiempo añadido.
4. **Eliminar** (opcional): `DELETE /v1beta/cachedContents/{id}` cuando ya no la necesite. Si no, se elimina al caducar. El almacenamiento ya cobrado no se reembolsa.

La caché pertenece a la cuenta: cualquier API Key de esa cuenta puede usarla (si tiene lista de modelos permitidos, debe incluir el modelo). Otras cuentas reciben 404 para el mismo nombre. El uso y la ampliación aplican los precios del grupo actual de la clave solicitante.

## Referenciar la caché al generar

```bash
curl -X POST "https://direct.evolink.ai/v1beta/models/gemini-3.8-flash:generateContent" \
  -H "Authorization: Bearer $EVOLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "cachedContent": "cachedContents/20261103012026348092000s1oTuB96",
    "contents": [
      { "role": "user", "parts": [{ "text": "¿Qué dice el manual sobre las devoluciones?" }] }
    ]
  }'
```

`usageMetadata.cachedContentTokenCount` indica los tokens servidos desde caché, a la tarifa de acierto. `promptTokenCount` los incluye; el resto usa la tarifa de entrada normal.

```json
{
  "candidates": [
    { "content": { "role": "model", "parts": [{ "text": "El capítulo 7 del manual establece…" }] }, "finishReason": "STOP" }
  ],
  "usageMetadata": {
    "promptTokenCount": 7541,
    "cachedContentTokenCount": 7525,
    "candidatesTokenCount": 212,
    "totalTokenCount": 7753
  },
  "modelVersion": "gemini-3.8-flash"
}
```

<Warning>
Las generaciones que usan caché **no deben incluir** `systemInstruction`, `tools` ni `toolConfig`. Defínalos al crearla; enviarlos devuelve 400. El modelo de generación debe coincidir con el de la caché, o se devuelve 400 `CACHE_MODEL_MISMATCH`.
</Warning>

## Ejemplo completo (Python)

```python
import requests

BASE = "https://direct.evolink.ai"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json"}

# 1. Crear caché: documento largo + instrucciones del sistema, durante 1 hora
manual = open("manual.txt", encoding="utf-8").read()   # Debe alcanzar el mínimo de tokens del modelo
cache = requests.post(f"{BASE}/v1beta/cachedContents", headers=HEADERS, json={
    "model": "models/gemini-3.8-flash",
    "displayName": "product-manual-v3",
    "systemInstruction": {"parts": [{"text": "Eres un asistente del manual del producto. Responde solo con el manual."}]},
    "contents": [{"role": "user", "parts": [{"text": manual}]}],
    "ttl": "3600s",
}).json()
name = cache["name"]            # cachedContents/<id>
cache_id = name.split("/")[-1]  # <id>
print("cached tokens:", cache["usageMetadata"]["totalTokenCount"], "expire:", cache["expireTime"])

# 2. Reutilizar: enviar solo la pregunta nueva cada vez
for question in ["¿Cuál es la política de devoluciones?", "¿Cuánto dura la garantía?", "¿Puedo enviar el producto desde el extranjero para repararlo?"]:
    resp = requests.post(f"{BASE}/v1beta/models/gemini-3.8-flash:generateContent", headers=HEADERS, json={
        "cachedContent": name,
        "contents": [{"role": "user", "parts": [{"text": question}]}],
    }).json()
    print(resp["candidates"][0]["content"]["parts"][0]["text"])
    print("cache hit tokens:", resp["usageMetadata"].get("cachedContentTokenCount", 0))

# 3. Continuar: conservar 2 horas desde ahora (se cobra el tiempo añadido)
requests.patch(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS, json={"ttl": "7200s"})

# 4. Eliminar al terminar (el almacenamiento cobrado no se reembolsa)
requests.delete(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS)
```

## Facturación

| Concepto | Cálculo |
|---|---|
| Escritura | Tokens en caché × tarifa de escritura, al crear. Equivale a la tarifa de entrada del modelo; las cachés Pro de más de 200 000 tokens usan la tarifa de contexto largo |
| Almacenamiento | Tokens en caché × vigencia (horas, prorrateadas por segundos) × tarifa de almacenamiento (por millón de tokens por hora), cobrado al crear para toda la vigencia |
| Generación con caché | `cachedContentTokenCount` a la tarifa de acierto; demás entradas y salidas a tarifas normales. Si se declara `googleSearch` en la caché, cada búsqueda se cobra aparte a su tarifa |
| Ampliar vigencia | Almacenamiento del tiempo añadido; menos de 1 segundo se cobra como 1 segundo |
| Reducir / eliminar / caducar | Sin reembolso del almacenamiento ya cobrado |
| Listar / consultar | Gratis |

- El número de tokens procede de `usageMetadata.totalTokenCount` en la respuesta de creación.
- `<id>` en el nombre de caché es el ID de la solicitud de creación. Búsquelo en «Logs» del panel para ver cargos de creación y ampliación (tokens, tiempo y coste de almacenamiento).
- Consulte los [precios](https://evolink.ai/pricing) de escritura, acierto y almacenamiento de cada modelo.
- Rentabilidad: el almacenamiento se cobra por tiempo y cada acierto ahorra entrada. Cuantas más llamadas usen el mismo prefijo durante su vigencia, más compensa; para una o dos, enviar el texto original es más barato.

## Límites

- **Vigencia**: entre 60 segundos y 168 horas (`604800s`). Solo uno de `ttl` o `expireTime`; sin los dos, 1 hora por defecto.
- **Contenido**: al menos uno de `contents`, `systemInstruction` o `tools`. Cuerpo de hasta 10 MB y mínimo de tokens del modelo (por ejemplo, 4096 para `gemini-3.8-flash`); si no, devuelve 400.
- **Campos**: solo los documentados en esta página. Otros devuelven 400 indicando su nombre.
- **tools**: solo `googleSearch`, `codeExecution` y `functionDeclarations`.
- **Contenido inmutable**: tras crear, solo cambia la vigencia. Para otro contenido, cree una nueva caché.
- **Control de acceso**: creación y ampliación siguen las mismas listas de IP/modelos permitidos y límites de frecuencia que la generación.

## Códigos de error

Los errores usan el formato nativo de Gemini; `error.details[0].reason` contiene el motivo concreto:

```json
{
  "error": {
    "code": 404,
    "message": "cached content not found",
    "status": "NOT_FOUND",
    "details": [{ "@type": "type.googleapis.com/google.rpc.ErrorInfo", "reason": "CACHE_NOT_FOUND", "domain": "evolink.ai" }]
  }
}
```

| HTTP | reason | Significado |
|---|---|---|
| 400 | `INVALID_ARGUMENT` | Parámetros inválidos: sin contenido, `ttl` fuera de 60 segundos–168 horas, `ttl` y `expireTime` juntos, campos o herramientas no admitidos, etc. |
| 400 | `EXPLICIT_CACHE_UNSUPPORTED` | Modelo sin caché explícita (Gemini 4 o modelos de imagen) |
| 400 | `NO_AVAILABLE_CHANNEL` | El grupo actual no permite crear cachés para este modelo |
| 400 | `MODEL_PRICE_ERROR` | Caché explícita del modelo no habilitada para el grupo actual |
| 400 | `CACHE_EXPIRED` | Caché caducada durante el procesamiento o con muy poca vigencia restante |
| 400 | `CACHE_MODEL_MISMATCH` | El modelo de generación no coincide con el de la caché |
| 400 | `INVALID_CACHED_CONTENT` | Formato de `cachedContent` incorrecto |
| 4xx | `UPSTREAM_ERROR` | El modelo rechaza el contenido; `message` explica el motivo, a menudo menos tokens que el mínimo |
| 402 | `INSUFFICIENT_QUOTA` | Saldo insuficiente para escritura y almacenamiento |
| 403 | — | La clave no tiene acceso al modelo, la IP de origen no está autorizada o el grupo de la clave ya no está disponible |
| 404 | `CACHE_NOT_FOUND` | Caché inexistente, caducada, eliminada o de otra cuenta |
| 404 | `EXPLICIT_CACHE_DISABLED` | La caché explícita no está habilitada |
| 413 | `CACHE_CONTENT_TOO_LARGE` | El cuerpo de la solicitud supera 10 MB |
| 502 | `UPSTREAM_ERROR` | Servicio no disponible temporalmente. Esta solicitud no se cobra; inténtelo más tarde |
| 503 | `CACHE_CHANNEL_UNAVAILABLE` | Caché no disponible temporalmente; inténtelo más tarde |
| 503 | `INTERNAL` | Servicio no disponible temporalmente; inténtelo más tarde |
