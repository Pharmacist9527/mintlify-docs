<Note>
**BaseURL**: La BaseURL predeterminada es `https://direct.evolink.ai`, que ofrece mejor compatibilidad con modelos de texto y admite conexiones persistentes. `https://api.evolink.ai` es el endpoint principal para servicios multimodales y actúa como dirección de respaldo para los modelos de texto.
</Note>

<Note>
**Las herramientas del lado del servidor** (búsqueda web, MCP) solo se ofrecen en la [API Responses](/es/api-manual/language-series/gpt/responses/responses-reference). El endpoint de Chat Completions solo admite llamadas a herramientas `function` normales.
</Note>

<Note>
**GPT-6**: Las llamadas a funciones con `gpt-6-sol` / `gpt-6-luna` requieren `reasoning_effort: "none"` en este endpoint. Use [Responses](/es/api-manual/language-series/gpt/responses/responses-reference) para llamadas a funciones con `gpt-6.2-astra` / `gpt-6.2-sol` / `gpt-6-astra`, `gpt-6.1-sol` y `gpt-6.1-terra`, o para el nivel `max` de GPT-6.
</Note>
