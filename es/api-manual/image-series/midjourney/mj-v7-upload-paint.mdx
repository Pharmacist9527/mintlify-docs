<Note>
Midjourney V7 Inpaint (`mj-v7-inpaint`) se retiró el 18 de octubre de 2026 por un cambio de política de nuestro proveedor de origen. Las solicitudes ahora devuelven HTTP 410 (`mj_v7_inpaint_discontinued`) y no se cobran. Para repintar parte de una imagen, usar esta interfaz (`mj-v7-upload-paint`).
</Note>

<Note>
Midjourney cuenta con un sistema de moderación de contenido integrado. Si algunas imágenes generadas son filtradas por la moderación, los créditos consumidos en esa solicitud no serán reembolsados. Asegúrese de que sus prompts cumplan con las directrices de contenido.
</Note>
