Qwen Audio 3.1 TTS Flash elige la voz con el parámetro `voice` de la [API de síntesis de voz](/es/api-manual/audio-series/qwen-audio-tts/qwen-audio-3.1-tts-flash). Las **68** voces del sistema se pueden usar directamente, sin crearlas antes.

- `voice` **distingue mayúsculas y minúsculas**; copia el valor exactamente como aparece
- Si omites `voice`, se usa `longanhuan_v3.1`
- Usa la columna `voice` en las solicitudes; nombres, género, características y usos ayudan a elegir
- El texto debe estar en un idioma admitido por la voz; de lo contrario puede haber pronunciación incorrecta o voz poco natural

## Ejemplos

Envía este cuerpo de solicitud a `POST /v1/audios/generations` y reemplaza `voice` por el ID deseado. Consulta parámetros y tareas en la [API de síntesis de voz](/es/api-manual/audio-series/qwen-audio-tts/qwen-audio-3.1-tts-flash).

<CodeGroup>
```json Voz en chino
{
  "model": "qwen-audio-3.1-tts-flash",
  "prompt": "欢迎使用语音合成，让文字变成自然流畅的声音。",
  "voice": "longanhuan_v3.1"
}
```

```json Voz en inglés
{
  "model": "qwen-audio-3.1-tts-flash",
  "prompt": "Welcome to our audio guide. Let us turn your words into speech.",
  "voice": "Emily_v3.1",
  "language": "en"
}
```
</CodeGroup>

<Tip>
  Todas las voces permiten `instruction` y etiquetas emocionales en el texto, como `[excited]` y `[laughing]`, para controlar la emoción y el tono. Consulta `prompt` e `instruction` en la [API de síntesis de voz](/es/api-manual/audio-series/qwen-audio-tts/qwen-audio-3.1-tts-flash).
</Tip>

## Voces personalizadas

Crea tu voz con [Voice Enrollment](/es/api-manual/audio-series/qwen-audio-tts/voice-enrollment): envía una grabación para clonarla o una descripción para diseñarla. Tras completar la tarea, pasa el nombre completo `voice` devuelto a la API de síntesis.

- Solo la cuenta que creó una voz personalizada puede usarla
- Caduca por defecto **6 horas** después de completar la creación; las llamadas de síntesis no amplían la vigencia
- Tras caducar, la síntesis devuelve `404` (`voice_expired`); crea una nueva voz con Voice Enrollment
- Las voces del antiguo `qwen-voice-design` no son compatibles; vuelve a crearlas con Voice Enrollment al migrar
