title: "Consultar el coste de una solicitud"
description: "Consultar el estado, el uso y el coste real por Request ID de llamadas síncronas a la API, principalmente a modelos de texto"
openapi: /es/api-manual/account-management/get-request-usage.json GET /v1/requests/{request_id}
---

<Note>
Este endpoint consulta el coste de **llamadas síncronas a la API**, principalmente a **modelos de texto** mediante interfaces como Chat Completions, Messages y Responses.

Utilice como Request ID el valor del encabezado `X-Request-Id` de la respuesta original. Espere un momento después de que finalice la solicitud antes de consultar. Para tareas asíncronas, utilice [Consultar el estado de una tarea](/es/api-manual/task-management/get-task-detail).
</Note>
