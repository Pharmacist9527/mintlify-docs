## Descripción general

<Frame caption="Página de inicio de ComfyUI Desktop: elija o cree una instancia para entrar al lienzo (las demás formas de instalación tienen una interfaz similar)">
  ![Página de inicio de ComfyUI Desktop](/images/integration-guide/comfyui/desktop-home.jpg)
</Frame>

[ComfyUI](https://www.comfy.org/) es la herramienta **de código abierto basada en nodos** más popular para la generación de imágenes con IA: cada paso — cargar un modelo, escribir un prompt, generar una imagen — se convierte en un nodo que usted conecta sobre un lienzo, como si armara bloques, para construir flujos de trabajo altamente flexibles y reutilizables. Gratuita, de código abierto y respaldada por un enorme ecosistema de plugins, se ha convertido en la mesa de trabajo de referencia para la creación visual con IA.

Con el **plugin oficial de EvoLink para ComfyUI**, puede llamar al modelo en la nube `gpt-image-2` directamente desde sus flujos de trabajo de ComfyUI — tanto texto a imagen como imagen a imagen, **sin necesidad de GPU local**.

**Compatible con**: ComfyUI Desktop, versiones portátiles, instalaciones manuales y el paquete todo-en-uno chino "aki" (ComfyUI-aki).

## Antes de comenzar

### Obtenga una API Key de EvoLink

1. Inicie sesión en el [panel de EvoLink](https://evolink.ai/dashboard)
2. Abra la [página de API Keys](https://evolink.ai/dashboard/keys), cree una clave y cópiela (comienza con `sk-`)

<Frame caption="Página de API Keys → Create New Key (arriba a la derecha) → copie la clave generada">
  ![Crear una API Key](/images/integration-guide/comfyui/create-api-key.png)
</Frame>

<Warning>
**Su API Key es la llave del saldo de su cuenta.** Guárdela únicamente en la configuración local del nodo — nunca la pegue en chats, capturas de pantalla ni repositorios públicos. Si sospecha una filtración, elimínela y vuelva a crearla de inmediato.
</Warning>

### Confirme que tiene créditos

La generación consume créditos. Verifique su saldo en el [panel](https://evolink.ai/dashboard); el consumo de cada tarea aparece en el [registro de tareas](https://evolink.ai/dashboard/logs).

  </Tab>
  <Tab title="Opción B: paquete todo-en-uno aki">

    Usuarios del paquete todo-en-uno aki: `custom_nodes` está dentro de su carpeta de instalación `ComfyUI-aki-vX.X`; ejecute el comando desde el terminal del lanzador o abra PowerShell en ese directorio.

    2. Mueva la carpeta a `ComfyUI/custom_nodes/`

    Un diseño correcto se ve así:

    ```

      └─ custom_nodes\
           ├─ ComfyUI-Manager\

    ```
  </Tab>

La única dependencia es `requests` (normalmente ya incluida con ComfyUI).

<Accordion title="¿La opción A / B falla con only custom nodes from the default channel can be installed? Despliegue para ver la solución">
  <Frame caption="El error: instalación bloqueada por la configuración actual del nivel de seguridad">
    ![Error de default channel](/images/integration-guide/comfyui/manager-default-channel-error.png)
  </Frame>

  Esto ocurre porque las versiones del plugin están pasando la revisión de seguridad del registro oficial de ComfyUI (un proceso habitual para nodos de API en la nube), y el nivel de seguridad predeterminado del Manager bloquea la instalación mientras tanto. Puede **bajar temporalmente el nivel de seguridad del Manager** — y restaurarlo después:

  **Paso 1: Cierre ComfyUI por completo**
  - Paquete todo-en-uno aki: lanzador → **Terminar proceso**
  - Desktop oficial / portátil / instalación manual: salga completamente de la aplicación, incluida la ventana de consola

  **Paso 2: Edite el archivo de configuración del Manager `config.ini`**

  Localícelo según su tipo de instalación (o simplemente busque `config.ini` dentro de su carpeta de ComfyUI y elija el que tenga `manager` en la ruta):

  | Entorno | Ubicación de config.ini |
  |---|---|
  | Paquete todo-en-uno aki | `su-ruta-de-descarga\ComfyUI-aki-vX.X\ComfyUI-aki-vX.X\ComfyUI\user\__manager\config.ini` |
  | Versión oficial (Desktop / portátil / manual) | `directorio de instalación de ComfyUI\user\default\ComfyUI-Manager\config.ini` |

  Ábralo con el Bloc de notas, localice la línea `security_level` y cambie `normal` por `weak`:

  ```ini
  security_level = weak
  ```

  Guarde y cierre.

  <Frame caption="Cambie el valor de security_level a weak y guarde (no toque ninguna otra línea)">
    ![Editar security_level](/images/integration-guide/comfyui/manager-config-security-level.png)
  </Frame>

  **Paso 3: Reinicie ComfyUI e instale de nuevo**

  Inicie ComfyUI → Manager → busque `evolink` → **Install**. Ignore el mensaje `Neither 'pip' nor 'uv'...` si aparece. Cuando vea **Restart Required**, reinicie por completo una vez más y actualice el navegador.

  **Paso 4: Verifique y restaure el nivel de seguridad**
  - Confirme que los nodos cargan según [Verificar la instalación](#verificar-la-instalación) más abajo
  - **Vuelva a cambiar `security_level` a `normal` después de instalar** (repita los pasos 1–2) para restaurar la protección predeterminada del Manager
</Accordion>

### Verificar la instalación

Tras un reinicio completo y una actualización del navegador, **haga doble clic** en el lienzo vacío → busque `evolink`. Si ve los dos nodos **EvoLink GPT Image 2 (Official)** y **EvoLink Upload Image (Official)**, la instalación fue exitosa:

  ![Verificar la instalación: buscar evolink](/images/integration-guide/comfyui/search-nodes.png)

¿No aparecen los nodos? Asegúrese de haber hecho un **reinicio completo** (no solo actualizar el navegador); si persiste, consulte las [preguntas frecuentes](#preguntas-frecuentes).

## Paso 2: Su primera imagen (texto a imagen, 5 minutos)

1. **Haga doble clic** en el lienzo vacío (o clic derecho → Add Node) → busque **`EvoLink`** → añada **EvoLink GPT Image 2 (Official)**
2. Complete los campos:
   - `api_key`: pegue su clave `sk-`. **Solo la primera vez** — tras la primera ejecución se guarda en un archivo de configuración local; después deje el campo vacío (y límpielo antes de compartir flujos de trabajo)
   - `prompt`: su descripción (puede escribirla en español), p. ej. `un shiba inu con una bufanda roja sentado en la nieve, ilustración plana`
   - Mantenga los demás valores predeterminados (`quality=low` es lo más barato para pruebas)
3. **Conecte un nodo de visualización (imprescindible)**: arrastre desde el punto de salida `image` hasta el lienzo vacío y elija **Preview Image**; añada también un nodo **Save Image** si quiere que los archivos se escriban en la carpeta `output` de ComfyUI

<Warning>
**El error más común de los principiantes**: el nodo EvoLink genera pero no muestra. Si la salida `image` no está conectada a nada, la tarea termina y usted no ve ninguna imagen.
</Warning>

<Frame caption="Flujo de trabajo completo de texto a imagen: parámetros completados, image conectado a Preview Image (api_key oculta — déjela vacía tras el primer uso)">
  ![Flujo de trabajo completo de texto a imagen](/images/integration-guide/comfyui/text2img-workflow.png)
</Frame>

4. Pulse **Queue Prompt**. El nodo envía la tarea, consulta el progreso con una barra en tiempo real y recupera el resultado, que se muestra directamente en el nodo Preview.

## Paso 3: Imagen a imagen (3 pasos)

1. Añada un nodo **Load Image** y elija su imagen local
2. Conecte su salida de imagen a la entrada **`image1`** del nodo EvoLink
3. Describa la modificación en `prompt` → ejecute

<Frame caption="Conexión completa de imagen a imagen: Load Image → image1, instrucción de edición en el prompt (ejemplo: estilo Ghibli, fondo de calle nocturna) — composición conservada">
  ![Flujo de trabajo completo de imagen a imagen](/images/integration-guide/comfyui/img2img-workflow.png)
</Frame>

<Note>
Su imagen se sube automáticamente a través del **canal oficial de archivos de EvoLink** para obtener una URL temporal (**se elimina automáticamente a las 72 horas**) — sin pasar por ningún alojamiento de imágenes de terceros ni registrarse en servicios adicionales.
</Note>

**Uso avanzado**:

- **Múltiples imágenes de referencia**: las entradas `image1`–`image4` más el cuadro de texto `image_urls` (una URL pública por línea) pueden combinarse — hasta **16 imágenes** en total
- **Flujos de trabajo complejos**: el nodo incluido **EvoLink Upload Image (Official)** convierte imágenes locales en texto de URL (no es necesario para imagen a imagen normal)
- **Flujos de trabajo listos para usar**: [example_workflows](https://github.com/deeplearning-goethe/comfyui-evolink/tree/main/example_workflows) incluye ejemplos de texto a imagen / imagen a imagen / referencias múltiples. **El PNG de resultado de cada ejemplo lleva incrustado el flujo de trabajo completo — descargue la imagen y arrástrela al lienzo para restaurar todos los nodos y conexiones** (capacidad nativa de ComfyUI); también se incluyen los archivos JSON correspondientes

## Parámetros

| Parámetro | Descripción |
|---|---|
| `prompt` | Descripción / instrucción de edición, admite varios idiomas (español incluido), hasta 32.000 caracteres |
| `model` | `gpt-image-2` (predeterminado) / `gpt-image-2-beta` |
| `size` | `auto` (predeterminado, el modelo decide la composición) / proporción como `1:1`, `16:9` / píxeles como `1024x1024` |
| `resolution` | `1K` / `2K` / `4K`, se aplica cuando size es una proporción o auto |
| `quality` | `low` / `medium` / `high` — **cuanto más alta, más cara**; use `low` para pruebas |
| `n` | Imágenes por ejecución (1–10) |
| `api_key` | Se guarda localmente en el primer uso, después déjela vacía; también funciona la variable de entorno `EVOLINK_API_KEY` |
| `image1`–`image4` | Entradas de imágenes de referencia — conecte Load Image para imagen a imagen |
| `image_urls` | Avanzado: una URL pública por línea |
| `timeout_seconds` | Espera máxima (300 s por defecto); las tareas que agotan el tiempo no se cobran |

Salidas: `image` (resultado, ya descargado), `task_id` (para consultas de facturación y soporte), `status_info` (resumen de la ejecución: tiempo, créditos consumidos, etc.).

## Facturación y verificación

- **Pago por uso, sin suscripción**: los créditos se reservan al enviar la tarea (`credits_reserved`) y se liquidan al completarse
- **Las tareas fallidas o con tiempo agotado no se cobran** — los créditos se devuelven automáticamente
- **La caché no consume créditos**: repetir la ejecución sin cambiar parámetros reutiliza la caché local de ComfyUI, sin lanzar una nueva solicitud
- **Cada tarea es auditable**: consulte cualquier `task_id` en el [registro de tareas](https://evolink.ai/dashboard/logs); si tiene dudas sobre un cargo, envíe el `task_id` a soporte para su verificación

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿El nodo EvoLink no aparece en la búsqueda?">
    Compruebe en orden: ① la carpeta del plugin está directamente bajo `custom_nodes`; ② no hay carpetas anidadas duplicadas por la descompresión (`__init__.py` debe verse al abrir la carpeta); ③ reinició ComfyUI por completo (ventana de consola cerrada, no solo el navegador); ④ busque `evolink` en el registro de arranque — capture cualquier error en rojo para soporte. Los usuarios del paquete todo-en-uno aki también pueden ejecutar un diagnóstico del entorno con un clic desde el panel de solución de problemas del lanzador.
  </Accordion>
  <Accordion title="¿La instalación desde el Manager falla con only custom nodes from the default channel can be installed?">
    Las versiones del plugin están pasando la revisión de seguridad del registro oficial de ComfyUI, y el nivel de seguridad predeterminado del Manager bloquea temporalmente la instalación. Consulte la solución desplegable en la [sección de instalación](#paso-1-instalar-el-plugin-oficial): cambie temporalmente el `security_level` del Manager a `weak`, instale y vuelva a ponerlo en `normal` — o use directamente la opción C (git) / opción D (ZIP); el plugin funciona exactamente igual.
  </Accordion>
  <Accordion title="¿El Manager muestra Neither pip nor uv are available durante la instalación?">
    Puede ignorarlo. El Manager simplemente no encontró un gestor de paquetes para instalar dependencias; la única dependencia de este plugin es `requests`, que ComfyUI ya incluye. Si la lista muestra **Restart Required**, reinicie y los nodos cargarán sin problemas.
  </Accordion>
  <Accordion title="¿La tarea terminó pero no aparece ninguna imagen?">
    La salida `image` no está conectada a un nodo Preview Image / Save Image. Conéctela y ejecute de nuevo — el resultado en caché se muestra al instante sin cargo adicional.
  </Accordion>
  <Accordion title="¿El panel de recursos multimedia dice que no se encontraron archivos generados?">
    Es normal cuando solo hay conectado un nodo **Preview Image** (las vistas previas no se escriben en disco). Para que las imágenes aparezcan en el panel y en la carpeta `output`, use un nodo **Save Image**.
  </Accordion>
  <Accordion title="¿Error 401 / Unauthorized?">
    Clave incorrecta, espacios de más o la clave fue eliminada. Verifíquela en la [página de API Keys](https://evolink.ai/dashboard/keys); tras recrearla, rellene una vez el campo `api_key` del nodo para sobrescribir la clave antigua guardada localmente.
  </Accordion>
  <Accordion title="¿Error 402 / saldo insuficiente?">
    No hay créditos suficientes — recargue en el [panel](https://evolink.ai/dashboard) y reintente.
  </Accordion>
  <Accordion title="¿Error 429 / demasiadas solicitudes?">
    Alcanzó el límite de frecuencia — espere un momento y ejecute de nuevo.
  </Accordion>
  <Accordion title="¿Fallo por moderación de contenido?">
    El prompt o una imagen de referencia activó la moderación de la plataforma. Ajuste y reintente — **las tareas fallidas no se cobran**.
  </Accordion>
  <Accordion title="¿Los enlaces del resultado expiraron?">
    Las URL de los resultados expiran a las **24 horas** y las referencias subidas a las **72 horas** — pero el nodo ya descarga los resultados dentro del flujo de trabajo; use un nodo **Save Image** para conservarlos permanentemente en la carpeta local `output`.
  </Accordion>
  <Accordion title="¿Lleva mucho tiempo girando sin generar la imagen?">
    Las tareas de alta resolución / alta calidad / muchas imágenes (n grande) tardan más; el nodo espera hasta 300 s por defecto (ajustable con `timeout_seconds`). Los tiempos agotados **no se cobran** — verifique el estado final de la tarea en el [registro de tareas](https://evolink.ai/dashboard/logs).
  </Accordion>
  <Accordion title="¿Cómo migro desde el plugin oficial antiguo o el de la comunidad?">
    **Nodos oficiales antiguos** (con entradas de imagen): uso idéntico — Load Image → `image1`. **Comunidad `ComfyUI_EvoLink`**: los nombres de parámetros coinciden; su nodo `Evolink Image Input` basado en imgbb ya no es necesario (conecte las imágenes directamente a `image1`); `poll_interval`/`max_polls` se unificaron en `timeout_seconds`. Ambos plugins pueden coexistir, no hace falta desinstalar primero.
  </Accordion>
  <Accordion title="¿No puede abrir 127.0.0.1:8188 en el navegador?">
    Primero asegúrese de que el registro de la consola muestre `To see the GUI go to` (el primer arranque es lento); si sigue sin abrir, pruebe `http://localhost:8188`, o compruebe si un proxy del sistema / VPN está interceptando las direcciones locales (añada `127.0.0.1` a la lista de exclusiones del proxy). Si usa un proxy, configure `api.evolink.ai` y `files-api.evolink.ai` para conexión directa.
  </Accordion>
  <Accordion title="¿Qué modelos son compatibles? ¿Y el video?">
    El plugin cubre actualmente la serie `gpt-image-2`. Nano Banana (serie Gemini), Seedream y los modelos de video (Veo / Sora / Kling) están en la hoja de ruta; mientras tanto, todos los modelos del [catálogo completo](https://evolink.ai/models) pueden llamarse mediante la [API directa](#apéndice-llamar-a-la-api-sin-el-plugin).
  </Accordion>
</AccordionGroup>

¿Sigue con problemas? Envíe el **ID de la tarea / captura del registro de arranque / texto exacto del error** a [support@evolink.ai](mailto:support@evolink.ai).

## Apéndice: llamar a la API sin el plugin

Útil para verificar una clave, o para modelos que el plugin aún no cubre.

**Verifique su clave en 30 segundos (gratis):**

```bash
curl -s -H "Authorization: Bearer sk-TU_CLAVE" https://api.evolink.ai/v1/models
```

Una lista de modelos (`{"data":[{"id":...`) significa que la clave funciona; `Unauthorized` significa que no.

**Envíe una tarea de generación:**

```bash
curl -s -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer sk-TU_CLAVE" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"a cute cat, watercolor style","size":"1:1","resolution":"1K","quality":"low","n":1}'
```

Anote el `id` de la tarea devuelto (comienza con `task-unified-`) y consulte hasta que `status` sea `completed`; el arreglo `results` contiene las URL de las imágenes (descárguelas dentro de las 24 horas):

```bash
curl -s -H "Authorization: Bearer sk-TU_CLAVE" https://api.evolink.ai/v1/tasks/TASK_ID
```

Referencia completa de la API: [Generación de imágenes](https://evolink.ai/docs/es/api-manual/image-series/gpt-image-2/gpt-image-2-image-generation) | [Consulta de tareas](https://evolink.ai/docs/es/api-manual/task-management/get-task-detail) | [Subida de archivos](https://evolink.ai/docs/es/api-manual/file-series/upload-base64)
