## Descripción general

Configurarlo todo a mano implica instalar el cliente, editar un archivo de configuración e introducir el endpoint y tu clave API. El script de configuración (`evolink-config`) hace todo eso con un solo comando:

- Comprueba tu entorno e instala el cliente si todavía no está en tu equipo
- Escribe el endpoint de EvoLink y tu clave API
- Envía un mensaje de prueba para confirmar que las llamadas funcionan
- Hace una copia de seguridad de cada archivo antes de cambiarlo y puede deshacerlo todo con un solo comando

Todo el proceso suele tardar menos de un minuto.

| Cliente | Configuración en un clic |
|---|---|
| Claude Code CLI | Compatible |
| Codex CLI | Compatible |
| Otros clientes | Consulta las guías manuales en "Herramientas de programación IA" |

<Note>
Los comandos de abajo son para macOS y Linux. En Windows, por ahora sigue la guía manual de [Claude Code CLI](/es/integration-guide/claude-code-cli) o de [Codex CLI](/es/integration-guide/codex-cli).
</Note>

## Requisitos previos

- **Clave API de EvoLink**: inicia sesión en la [consola de EvoLink](https://evolink.ai/dashboard), crea una clave en API Keys y cópiala. Las claves empiezan por `sk-`.
- **Node.js**: se recomienda la versión 22 o posterior (la mínima es la 18). Ejecuta `node -v` en una terminal para comprobarlo. Si no está instalado, descarga la versión LTS desde el [sitio web de Node.js](https://nodejs.org/).

## Configurar Claude Code

Ejecuta esto en una terminal:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash
```

El script te guía en cinco pasos (sus mensajes están en inglés):

<Steps>
  <Step title="Entorno">
    Comprueba Node.js y Claude Code. Si Claude Code todavía no está instalado, el script pregunta "Install now?"; pulsa Enter y lo instalará por ti.
  </Step>
  <Step title="Clave API">
    Pega tu clave API de EvoLink y pulsa Enter. Lo que pegas no se muestra en pantalla. El script comprueba en línea que la clave es válida y muestra tu saldo.
  </Step>
  <Step title="Modelo">
    Elige el modelo que Claude Code usará por defecto. Puedes cambiarlo en cualquier momento dentro de Claude Code con `/model`.
  </Step>
  <Step title="Revisar los cambios">
    El script muestra los archivos y los ajustes que va a cambiar. Pulsa Enter para aplicarlos.
  </Step>
  <Step title="Aplicar y verificar">
    Después de escribir los ajustes, el script envía un mensaje de prueba (unos 0.01 créditos). Si la respuesta es normal, la configuración está completa.
  </Step>
</Steps>

Cuando termine, abre una nueva ventana de terminal y ejecuta:

```bash
claude
```

Dentro de Claude Code, ejecuta `/status`. Si en Anthropic base URL aparece la dirección de EvoLink, la configuración ya está activa.

## Configurar Codex CLI

Ejecuta esto en una terminal:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- codex
```

Los pasos son los mismos que arriba. Cuando termine, inicia Codex con:

```bash
codex -p evolink
```

<Note>
El script crea un perfil independiente para Codex, `~/.codex/evolink.config.toml`, y no modifica tu propio `~/.codex/config.toml`. Codex solo usa EvoLink cuando lo inicias con `-p evolink`; un `codex` sin más mantiene tu configuración original.
</Note>

## Qué cambia el script

### Claude Code

| Archivo | Cambio |
|---|---|
| `~/.claude/settings.json` | Escribe el endpoint `ANTHROPIC_BASE_URL` y tu clave `ANTHROPIC_AUTH_TOKEN`; deja `ANTHROPIC_API_KEY` vacío, para que una clave antigua que haya quedado en el equipo no provoque errores 401; fija la versión del modelo que se usa para Sonnet; desactiva el modo automático (el motivo está en las preguntas frecuentes de abajo). El resto del archivo se conserva. |
| `~/.claude.json` | Omite las pantallas de inicio de sesión del primer arranque; con tu consentimiento, marca la carpeta actual como de confianza. |

### Codex CLI

| Archivo | Cambio |
|---|---|
| `~/.codex/evolink.config.toml` | Archivo nuevo. Contiene el endpoint de EvoLink, el modelo predeterminado y tu clave. Solo tú puedes leerlo. |
| `~/.codex/config.toml` | No se modifica. |

### En ambos casos

- Antes de cambiar cada archivo, se guarda una copia de seguridad en `~/.evolink/backups/`.
- El script se guarda en `~/.evolink/` y su comando es `~/.evolink/bin/evolink-config`. No cambia tu PATH ni tu perfil de shell.
- Tu clave solo se guarda en los archivos de configuración de tu equipo y solo se envía a la API de EvoLink.

<Note>
`evolink-config` solo configura la conexión con la API. Es una herramienta distinta de la herramienta de línea de comandos `evolink`, que genera imágenes, videos y audio (consulta la sección CLI/MCP). Puedes usar ambas.
</Note>

## Comprobar, deshacer y volver a configurar

### Ver los cambios antes (no se escribe nada)

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --dry-run
```

### Comprobar la configuración actual

```bash
~/.evolink/bin/evolink-config doctor
```

Tu clave aparece oculta en la salida, así que puedes enviarla tal cual al soporte. Para Codex, usa `~/.evolink/bin/evolink-config doctor codex`.

### Deshacer la configuración

```bash
~/.evolink/bin/evolink-config reset
```

El script restaura todo lo que cambió. Para Codex, usa `~/.evolink/bin/evolink-config reset codex`.

### Cambiar la clave o el modelo predeterminado

Vuelve a ejecutar el comando de configuración.

## Preguntas frecuentes

### 1. ¿Qué hago si dice que no se encuentra Node.js?

Instala la versión LTS desde el [sitio web de Node.js](https://nodejs.org/), abre una nueva terminal y vuelve a ejecutar el comando de configuración.

### 2. Ya lo configuré a mano. ¿Se sobrescribirá mi configuración?

No en su totalidad. El script solo cambia los elementos indicados arriba y conserva todo lo demás. Antes de escribir, muestra el valor anterior y el nuevo de cada elemento y hace una copia de seguridad del archivo original.

### 3. ¿Por qué no hay modo automático (auto mode) en Claude Code?

En el modo automático, Claude Code deja de preguntarte antes de cada comando. En su lugar, primero envía una solicitud de revisión y un modelo decide si el comando se puede ejecutar de forma segura. Estas solicitudes de revisión se facturan por tokens, como cualquier otra solicitud. Usan `claude-sonnet-5`, sea cual sea el modelo predeterminado que hayas elegido.

Para evitar cargos que no esperabas, el script desactiva el modo automático de forma predeterminada, y Claude Code te pregunta antes de ejecutar un comando. El script también te lo indica al terminar.

Si quieres el modo automático, actívalo así:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --auto-mode
```

Para volver a desactivarlo, ejecuta otra vez el comando de configuración sin `--auto-mode`.

### 4. ¿Puedo leer el script antes de ejecutarlo?

Sí. Descárgalo, léelo y luego ejecútalo:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh -o setup.sh
less setup.sh
bash setup.sh
```

### 5. ¿Qué hago si aparece "Rate limited (429)"?

Cada cuenta solo puede comprobar su clave un número limitado de veces por minuto. Si ejecutas el script varias veces seguidas, verás este mensaje. Espera los segundos que indica el mensaje y vuelve a ejecutar el script.

### 6. ¿Qué hago si sigue sin funcionar después de la configuración?

Ejecuta `~/.evolink/bin/evolink-config doctor` y envía la salida al soporte. También puedes consultar las secciones de solución de problemas de las páginas [Claude Code CLI](/es/integration-guide/claude-code-cli) y [Codex CLI](/es/integration-guide/codex-cli).
