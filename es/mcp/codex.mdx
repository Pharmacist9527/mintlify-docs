Esta página trata el MCP nativo en Codex. El servicio remoto usa Streamable HTTP y OAuth en el navegador, sin necesidad de EvoLink CLI. Para ejecutar comandos y habilidades, usa la [guía de la CLI](/es/cli/codex), que es independiente.

## Conecta el MCP remoto

Para las herramientas nativas, usa **Streamable HTTP + OAuth** con esta URL del servidor:

```text
https://mcp.evolink.ai/mcp
```

No hace falta instalar la CLI. Haz una copia de seguridad de la configuración existente, fusiona solo EvoLink y conserva los demás servicios. Elige entre el registro mediante comandos y el registro manual.

<Steps>

<Step title="Añade el servidor remoto">

En una terminal que tenga Codex CLI instalado, ejecuta:

```bash
codex mcp add evolink --url https://mcp.evolink.ai/mcp
```

La configuración debe contener `evolink`. Si ya existe una entrada, revísala antes de añadir otra; evita registros duplicados entre la configuración manual y el plugin.

</Step>

<Step title="Autoriza MCP por separado">

```bash
codex mcp login evolink
```

Inicia sesión en EvoLink en el navegador, autoriza y espera a que termine. Si la autorización ya se completó al añadir el servidor, no repitas el inicio de sesión. `evolink auth login` no autoriza esta conexión nativa.

</Step>

<Step title="Comprueba la conexión y consulta el saldo">

```bash
codex mcp list
```

Abre una sesión nueva de Codex o usa `/mcp`, y después envía el prompt de verificación gratuita de más abajo. El resultado es correcto cuando se devuelven el saldo real de la cuenta y los modelos disponibles.

</Step>

</Steps>

Para la configuración manual, fusiona solo esta sección en el archivo de usuario `~/.codex/config.toml` o en el `.codex/config.toml` de un proyecto de confianza:

```toml
[mcp_servers.evolink]
url = "https://mcp.evolink.ai/mcp"
```

La app de Codex tiene su propia conexión mediante plugin o MCP personalizado, con la misma URL y OAuth. Iniciar sesión en la CLI de la terminal no conecta la app automáticamente. Consulta la [documentación de Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

Tras la autorización, envía esto en el chat del agente:

```text
Usa EvoLink para consultar el saldo de mi cuenta y buscar los modelos de imagen disponibles. No generes nada todavía.
```

**Éxito**: las llamadas reales a `check_balance` y `search_models` devuelven resultados. Verifica estas herramientas en la conexión MCP real.

## Actualizaciones, desconexión y solución de problemas

EvoLink se encarga de actualizar el servidor MCP alojado. Después de cambiar la configuración, vuelve a cargar la sesión real del cliente. Cuando haga falta, vuelve a autorizar con la opción de OAuth de ese cliente. Para desconectar, desactiva EvoLink, cierra sesión o elimínalo en la configuración de MCP del host; conserva los demás servidores.

| Síntoma | Acción |
|---|---|
| La URL está añadida, pero no hay herramientas | Activa la conexión, completa la autorización, vuelve a cargar la sesión y comprueba la política de la organización |
| 401 o se requiere autenticación | Vuelve a autorizar esta conexión MCP y conserva los identificadores de las tareas originales |
| 403 o herramienta denegada | Comprueba los permisos del host, el estado de la cuenta y de la clave, y los errores de red |
| Tiempo de espera agotado o respuesta perdida | Consulta y recupera la operación original en lugar de volver a generar |
| Solo aparece un enlace o la vista previa está gris | Abre y entrega el original sin rehacerlo automáticamente |

Consulta [Costos, acceso y solución de problemas de MCP](/es/mcp/billing#faq). Lee el [flujo de trabajo de creación](/es/mcp/overview#workflows) antes de enviar; el formato de las llamadas está en la [referencia de herramientas de MCP](/es/mcp/tools).
