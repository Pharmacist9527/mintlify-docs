El chat de ChatGPT usa el **MCP remoto**. Configúralo en el cliente y en el navegador; no hace falta instalar la CLI en local ni tener una clave API personal.

## Antes de empezar

Necesitas cuentas de EvoLink y de ChatGPT, además de una versión del cliente, un plan y un permiso del espacio de trabajo que permitan un MCP personalizado. Si la opción de añadir no está disponible, comprueba primero el acceso en el host en lugar de ejecutar instrucciones de terminal en el chat.

## Conecta EvoLink paso a paso

<Steps>

<Step title="Abre la opción de MCP personalizado">

Abre [ChatGPT Plugins](https://chatgpt.com/plugins), elige Add o el botón con el signo más y después **Create/Add custom MCP server**. Este es el punto de entrada de configuración que usa el sitio web. Las etiquetas pueden variar según la versión; si falta, comprueba el acceso del espacio de trabajo.

</Step>

<Step title="Introduce los datos de la conexión">

| Campo | Valor |
|---|---|
| Icon / Icono (opcional) | Descarga el [icono de EvoLink](https://cdn.evolink.ai/next/evolink-logo.png) y súbelo; omite este paso si el formulario no tiene un campo de icono |
| Name / Nombre | EvoLink |
| Connection / Conexión | Server URL |
| Server URL | `https://mcp.evolink.ai/mcp` |
| Authentication / Autenticación | OAuth |
| Client ID / Client Secret | Deja los valores predeterminados; no introduzcas una clave API de la plataforma |

Usa HTTP remoto y conserva el `/mcp` final. Revisa el aviso de conexión y selecciona **Create as a plugin**.

</Step>

<Step title="Instala y autoriza la cuenta">

Abre EvoLink en tus plugins personales e instálalo o conéctalo. Cuando se solicite la autenticación, inicia sesión en EvoLink en el navegador, revisa la cuenta y los permisos, y autoriza. Mantén el flujo abierto y después vuelve a ChatGPT. Crear la configuración e instalar el plugin son pasos distintos; la opción de autorización puede aparecer en momentos diferentes.

</Step>

<Step title="Actívalo en una conversación y verifica">

Inicia una conversación nueva y selecciona EvoLink con `@`. Si tu interfaz tiene las pestañas Chat / Work, cambia a **Work** antes de iniciar la conversación con el plugin. Envía el prompt de verificación gratuita de más abajo.

**Éxito**: aparecen el saldo real de la cuenta y los modelos disponibles, no solo un mensaje de que la configuración ha terminado.

</Step>

</Steps>

Consulta [MCP personalizado de OpenAI](https://developers.openai.com/api/docs/guides/custom-mcp-server) y la [guía de inicio rápido de plugins](https://developers.openai.com/plugins/quickstart). Una conexión personal no significa que EvoLink aparezca en el directorio público.

## Verificación gratuita y primera tarea multimedia

Una vez conectado, envía esto en una conversación con EvoLink activado:

```text
Usa EvoLink para consultar el saldo de mi cuenta y buscar los modelos de imagen disponibles. No generes nada todavía.
```

Confirma que se hacen llamadas reales a `check_balance` y `search_models`. El inicio de sesión y estas consultas no crean tareas multimedia de pago. Para generar, describe el contenido y las especificaciones, revisa el modelo, los parámetros y la estimación propuestos, y aprueba explícitamente el envío. Consulta el [primer flujo de trabajo multimedia](/es/mcp/overview#workflows).

Usa enlaces de referencia de acceso público que el modelo admita. Un archivo adjunto del chat puede no dar a MCP acceso a los bytes del archivo original, y el servicio remoto no puede leer las rutas de tu computadora. Consulta [Referencias y subidas](/es/mcp/overview#files).

## Problemas habituales

| Síntoma | Siguientes pasos |
|---|---|
| No aparece la opción de conector personalizado | Comprueba el plan, la versión y los permisos del espacio de trabajo en el host actual |
| Sigue sin autorización después de iniciar sesión en el navegador | Vuelve al cliente original y completa el flujo actual; consulta la [solución de problemas de autorización](/es/mcp/billing#login) |
| La conexión está añadida, pero no hay herramientas en el chat | Comprueba que está instalada y activada, selecciona EvoLink y abre una conversación nueva; consulta la [solución de problemas de MCP](/es/mcp/billing#mcp-connection) |
| El saldo funciona, pero la herramienta de generación no está disponible | Revisa los interruptores de herramientas del host y los permisos del espacio de trabajo; no los eludas con una clave |
| Tiempo de espera de red agotado o error 403 | Identifica si el fallo está en el host, en la página de inicio de sesión o en la solicitud de la herramienta; conserva la hora y el error para soporte |
| El resultado es un enlace o una vista previa gris | Abre y guarda el original; consulta la [solución de problemas de descarga y vista previa](/es/mcp/billing#download) |

## Vuelve a cargar y desconecta

Después de hacer cambios, vuelve a cargar la conexión y las herramientas, o abre una conversación nueva. Cuando haga falta, vuelve a autorizar desde este host. Para retirar el acceso de este cliente, desconéctalo o cierra sesión en su configuración. Gestiona en EvoLink los límites y la pausa de la clave compartida. Consulta [Plugins](/es/mcp/plugins) y [Costos y solución de problemas](/es/mcp/billing#faq).
