Los plugins pueden empaquetar la configuración del MCP remoto junto con la guía para agentes. Cada host usa su propio mecanismo de instalación y de autorización.

| Punto de entrada | Contenido instalado | Ejecución multimedia |
|---|---|---|
| Plugin de MCP personalizado de ChatGPT | Una conexión de servidor creada en ChatGPT | ChatGPT llama al MCP remoto |
| Plugin de repositorio para Codex | La configuración del MCP remoto de EvoLink y la habilidad evolink-mcp | Codex llama al MCP remoto |
| Plugin de repositorio para Claude Code | La configuración del MCP remoto de EvoLink y la habilidad evolink-mcp | Claude Code llama al MCP remoto |
| Habilidad incluida en la CLI | Las instrucciones y los documentos de referencia de evolink-cli | El agente ejecuta la CLI, que llama directamente a la API |
| Habilidad evolink-mcp por separado | Solo la guía para invocar MCP | Siguen haciendo falta la configuración y la autorización de MCP |

## Plugin de MCP personalizado de ChatGPT

Sigue la [configuración de ChatGPT](/es/mcp/chatgpt) para añadir un servidor MCP personalizado:

```text
https://mcp.evolink.ai/mcp
```

Elige OAuth, autoriza el inicio de sesión en el navegador y después activa EvoLink en tu conversación. ChatGPT no usa los comandos de marketplace de Codex que aparecen más abajo, ni requiere instalar la CLI en local con npm.

Una conexión personalizada no significa que EvoLink aparezca en el directorio público de plugins. La posibilidad de crearla y el acceso a las herramientas de generación dependen de tu cuenta, de la versión del host y de los permisos del espacio de trabajo. Consulta la [guía de MCP personalizado de OpenAI](https://developers.openai.com/api/docs/guides/custom-mcp-server).

## Plugin de repositorio para Codex

Confirma que tu versión de Codex admite `plugin`. Este plugin usa el MCP remoto nativo; el prompt de la CLI del sitio web es otro método. Quienes usan la CLI no necesitan además un plugin para generar.

<Steps>

<Step title="Añade la fuente e instala el plugin">

Ejecuta en la terminal del equipo y del usuario que ejecutan Codex:

```bash
codex plugin marketplace add Evolink-AI/mcp-plugin
codex plugin add evolink@evolink
codex plugin list --json
```

Confirma que EvoLink aparece en la lista de plugins. Aporta la configuración del MCP remoto y la habilidad `evolink-mcp`, no EvoLink CLI.

</Step>

<Step title="Carga el plugin y autoriza">

Vuelve a cargar los plugins o abre una conversación nueva de Codex y confirma que el servidor de EvoLink está cargado. Cuando se te pida, completa el OAuth del host en el navegador. Si el servidor está registrado y tu versión admite este comando, usa:

```bash
codex mcp login evolink
```

Mantenlo en ejecución durante el inicio de sesión y la autorización, y después vuelve a Codex. Si ya existe una configuración manual de MCP, elige una sola fuente de registro.

</Step>

<Step title="Verifica las herramientas y la habilidad">

```text
Confirma que has leído evolink-mcp y después usa EvoLink para consultar el saldo y los modelos de imagen disponibles. No generes nada todavía.
```

El resultado es correcto cuando la habilidad se ha leído y las llamadas reales a `check_balance` y `search_models` han funcionado; una lista de plugins por sí sola no verifica la autorización.

</Step>

</Steps>

Para actualizar la fuente, ejecuta esto y vuelve a cargar el plugin en el host; comprueba su versión real:

```bash
codex plugin marketplace upgrade evolink
```

Consulta la [referencia de Codex CLI](https://learn.chatgpt.com/docs/cli/reference) y la [configuración de Codex](/es/mcp/codex) para la configuración manual de MCP; las instrucciones de la CLI están en la [guía de la CLI](/es/cli/codex), que es independiente.

## Plugin de repositorio para Claude Code

Usa una versión de Claude Code compatible con plugins. Estos son **comandos de la conversación de Claude Code**, no comandos normales de shell.

<Steps>

<Step title="Instala el plugin de repositorio">

```text
/plugin marketplace add Evolink-AI/mcp-plugin
/plugin install evolink@evolink
```

Espera a que termine la instalación y confirma que EvoLink está activado para el usuario o el proyecto actual. Conserva los demás plugins.

</Step>

<Step title="Autoriza el MCP remoto">

```text
/mcp
```

Después de volver a cargar el plugin, selecciona EvoLink y completa la autenticación en el navegador. Evita duplicarlo con una conexión registrada manualmente.

</Step>

<Step title="Verifica gratis">

Pide al asistente que confirme que ha leído `evolink-mcp` y que consulte de verdad el saldo y los modelos, sin generar. Consulta la [configuración de Claude Code](/es/mcp/claude-code) para la configuración manual de MCP; las instrucciones de la CLI están en la [guía de la CLI](/es/cli/claude-code), que es independiente.

</Step>

</Steps>

## Instala solo la habilidad de MCP

Si el MCP nativo ya está configurado y solo necesitas la guía para agentes:

```bash
npx skills add Evolink-AI/mcp-plugin -g -y
```

Este comando obtiene las habilidades del repositorio mediante el instalador skills. No instala EvoLink CLI, no inicia el MCP local ni completa OAuth. Verifica que el host detecta el destino y lee evolink-mcp.

## Qué enseña el plugin

La fuente es [Evolink-AI/mcp-plugin](https://github.com/Evolink-AI/mcp-plugin). La configuración apunta al MCP remoto alojado. Su habilidad abarca la búsqueda de modelos, la validación de parámetros, las estimaciones y la aprobación, la subida de referencias, la generación, las tareas, la recuperación tras fallos y la entrega de los originales. No añade a las herramientas de EvoLink MCP el desarrollo de código, la edición de archivos arbitrarios ni la edición completa de video.

Las habilidades de la CLI y de MCP pueden compartir las mismas reglas sobre contenido multimedia, pero usan comandos y herramientas distintos. Elige una sola vía por tarea. Si un envío agota el tiempo de espera y su resultado es desconocido, recupera la solicitud o el task_id original en lugar de volver a generar por otra vía. Consulta [Recursos para agentes](/es/cli-mcp/agent-resources#skills) para el contenido y los directorios, y la [referencia de la plataforma](/es/mcp/tools) para los parámetros.

Consulta [Costos y conservación](/es/mcp/billing) para los límites y la revocación. La instalación de un plugin, la instalación de una habilidad y la autorización OAuth no aprueban ninguna solicitud de generación de pago.

## Problemas de instalación del plugin

| Síntoma | Siguiente paso |
|---|---|
| Faltan los comandos plugin / marketplace | Comprueba la versión del host y su configuración oficial, o usa su guía manual de MCP o la [configuración de la CLI](/es/cli/setup), que es independiente |
| No se puede obtener el repositorio | Comprueba la conexión con GitHub y la configuración de fuentes del host; conserva el error original |
| Está instalado, pero faltan las herramientas | Vuelve a cargar la sesión real, activa el plugin y completa OAuth |
| Servidor o habilidad duplicados | Haz una copia de seguridad de la configuración, revisa las fuentes, conserva la que quieres usar y mantén los demás servicios |
| Las herramientas aparecen en la lista, pero las llamadas fallan | Verifica la autorización con consultas gratuitas de saldo; consulta la [solución de problemas de MCP](/es/mcp/billing#mcp-connection) |

La instalación de un plugin no aprueba pruebas de pago. Consulta la [solución de problemas centralizada](/es/mcp/billing#faq) para los problemas de detección y de otro tipo.
