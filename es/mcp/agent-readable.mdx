## Qué debe leer un agente con MCP nativo

1. Lee el [resumen de MCP](/es/mcp/overview) y la página de configuración del cliente, y después configura y autoriza el host.
2. Consulta la [referencia de herramientas de MCP](/es/mcp/tools) y los esquemas reales de las herramientas.
3. Si quieres, instala la guía evolink-mcp o un plugin del host siguiendo los [pasos del plugin](/es/mcp/plugins). Leer las habilidades no registra ni autentica las herramientas.
4. Aplica las [reglas comunes para agentes](/es/cli-mcp/agent-resources#agent-rules) y después verifica las llamadas reales con la [solución de problemas de MCP](/es/mcp/billing#faq).

evolink-cli enseña los comandos de terminal; el MCP nativo usa las instrucciones de herramientas de evolink-mcp. Verifica por separado la instalación y la autenticación. llms.txt es un índice de la documentación; el endpoint MCP sigue siendo https://mcp.evolink.ai/mcp.
