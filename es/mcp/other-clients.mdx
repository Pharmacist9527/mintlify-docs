## Elige una conexión MCP

| Conexión | Instalación o conexión | Autenticación | Para |
|---|---|---|---|
| MCP remoto | https://mcp.evolink.ai/mcp | OAuth en el navegador | Chat web y clientes MCP nativos |
| MCP local | npx inicia @evolinkai/mcp | Clave API de la plataforma | Clientes stdio y subidas locales permitidas |

El MCP remoto no requiere el paquete MCP local. Instalar la CLI no registra ningún servidor MCP nativo. Instalar una habilidad no inicia sesión ni conecta herramientas.

## Elige una guía específica

Usa las páginas específicas de [Claude](/es/mcp/claude), [Codex](/es/mcp/codex), [Claude Code](/es/mcp/claude-code), [ChatGPT](/es/mcp/chatgpt), [Cursor](/es/mcp/cursor), [OpenClaw](/es/mcp/openclaw) y [Hermes](/es/mcp/hermes-agent). Esta página trata las conexiones genéricas de MCP remoto y de stdio local para otros clientes.

## Guías aparte de la CLI para agentes de terminal

Para terminales, scripts, Gemini CLI, OpenCode y GitHub Copilot CLI, sigue la [configuración de EvoLink CLI](/es/cli/setup#cli-install) para la instalación, el inicio de sesión, los destinos de la habilidad y la verificación gratuita. Los agentes que ejecutan comandos pueden usar la CLI; para configurar el MCP nativo, sigue las instrucciones de MCP remoto o local de más abajo.

<span id="ssh-login" />

### Inicio de sesión en Linux y por SSH

Cuando la CLI se ejecuta en remoto pero tu navegador está en local, sigue el [reenvío del callback por SSH](/es/cli/setup#ssh-login) después de cumplir los requisitos de almacenamiento seguro de credenciales en Linux. Los callbacks del MCP remoto los gestiona el host y no usan los pasos de reenvío de la CLI.

## MCP local por stdio con una clave API

Un cliente que solo admite stdio puede iniciar un proceso MCP local. Necesita **Node.js 20+** y una clave API personal, en lugar del OAuth en el navegador del MCP remoto.

<Steps>

<Step title="Prepara Node y una clave dedicada">

```bash
node --version
npx --version
```

Los dos comandos deben funcionar, con Node 20 o posterior. Crea una clave personal dedicada y con límites en [Claves API](https://evolink.ai/dashboard/keys). Proporciona `EVOLINK_API_KEY` mediante el entorno seguro o la configuración de secretos del cliente, no en el chat del agente, en capturas de pantalla compartidas ni en un repositorio.

</Step>

<Step title="Configura el inicio local">

Elige local/stdio en la configuración de MCP del cliente:

```text
command: npx
args: -y @evolinkai/mcp@latest
```

En el primer inicio, npx descarga el paquete. El host se comunica por stdio y el proceso local llama a la API de la plataforma. Asegúrate de que el host puede encontrar npx; una aplicación con interfaz gráfica puede tener un entorno distinto al de tu terminal. `YOUR_API_KEY`, más abajo, es un marcador de posición para la configuración local privada. Cuando el cliente lo admita, es preferible heredar la clave del entorno.

```json
{
  "mcpServers": {
    "evolink": {
      "command": "npx",
      "args": ["-y", "@evolinkai/mcp@latest"],
      "env": {"EVOLINK_API_KEY": "YOUR_API_KEY"}
    }
  }
}
```

</Step>

<Step title="Permite directorios cuando hagan falta archivos locales">

Para subir archivos desde rutas locales, define `EVOLINK_UPLOAD_ALLOWED_DIRS` en el entorno del proceso con los directorios absolutos permitidos. Separa varios directorios con `:` en macOS/Linux o con `;` en Windows. Sin este ajuste, las subidas desde rutas locales están desactivadas. El MCP remoto nunca acepta `file_path`.

Esto controla el acceso a los archivos locales, no los límites de formato, duración o tamaño del modelo. El uso de URL o base64 no necesita acceso a directorios locales.

</Step>

<Step title="Vuelve a cargar y verifica las herramientas gratuitas">

Guarda la configuración, activa EvoLink y vuelve a cargar o abre una sesión nueva, según lo requiera tu host. Pídele que llame a `check_balance` y `search_models` y confirma que los resultados son reales. Iniciar un proceso o listar las herramientas no basta para dar por verificada la cuenta.

El stdio local no ofrece las herramientas remotas de subida de un solo uso `prepare_upload` / `get_upload`. Revisa el `tools/list` real. La clave personal tiene sus propios límites, no los de la clave de OAuth.

</Step>

</Steps>

### Configuración de Claude Code y Codex

Con la clave ya proporcionada mediante el entorno seguro, Claude Code puede registrar el servidor con este comando en lugar del ejemplo JSON:

```bash
claude mcp add --scope user evolink -- npx -y @evolinkai/mcp@latest
```

En Codex puedes fusionar esta sección para heredar las variables de su entorno de inicio:

```toml
[mcp_servers.evolink]
command = "npx"
args = ["-y", "@evolinkai/mcp@latest"]
env_vars = ["EVOLINK_API_KEY", "EVOLINK_UPLOAD_ALLOWED_DIRS"]
```

Después de actualizar, vuelve a cargar y revisa la versión real. `@latest` no sustituye a un proceso que ya está en ejecución. Consulta la [solución de problemas centralizada](/es/mcp/billing#mcp-connection) para los fallos de inicio, de clave y de rutas locales.

## Otros clientes de MCP remoto

El cliente necesita Streamable HTTP, OAuth y callbacks del navegador. Un cliente limitado a claves estáticas o a stdio debe usar el MCP local descrito más arriba.

<Steps>

<Step title="Añade el servidor">

Crea una conexión MCP llamada EvoLink con Streamable HTTP y esta URL:

```text
https://mcp.evolink.ai/mcp
```

No introduzcas una URL de la documentación, una URL `/v1` de la plataforma ni un comando npx.

</Step>

<Step title="Completa OAuth y activa las herramientas">

Elige OAuth, usa la opción de inicio de sesión del cliente, autoriza en el navegador y vuelve. Confirma que la conexión y las herramientas están activadas. Una clave API estática no es el token de OAuth de esta conexión.

</Step>

<Step title="Verifica gratis">

```text
Usa EvoLink para consultar mi saldo y buscar los modelos de imagen disponibles. No generes nada todavía.
```

Cuando recibas resultados reales de saldo y de modelos, sigue el [primer flujo de trabajo multimedia](/es/mcp/overview#workflows). Una lista de herramientas sin llamadas correctas sigue necesitando la solución de problemas de autorización.

</Step>

</Steps>

## Recursos de habilidades y plugins

La habilidad evolink-cli incluida en el paquete guía la ejecución de comandos; evolink-mcp, del repositorio, guía las herramientas nativas. Consulta [Recursos para agentes](/es/cli-mcp/agent-resources#skills) para conocer las fuentes, los directorios y las actualizaciones, y la [guía de plugins](/es/mcp/plugins) para la configuración remota empaquetada.
