Usa EvoLink desde tu agente para generar imágenes, video, música y voz, consultar modelos y costos, subir referencias, seguir las tareas y guardar los originales. Elige un método de conexión y sigue su guía de instalación y de verificación gratuita.

## Elige un método de conexión

| Dónde trabajas | Vía recomendada | Instalación y autenticación |
|---|---|---|
| El chat de Claude o ChatGPT | [MCP remoto](/es/mcp/overview) | Añade una conexión y autoriza con OAuth en el navegador; no hace falta instalar la CLI |
| Codex, Claude Code, Cursor, OpenClaw o Hermes, con ejecución de comandos en la terminal | [CLI](/es/cli/setup) | Instala la CLI, inicia sesión e instala y carga la habilidad |
| Terminal, SSH o scripts | [CLI](/es/cli/setup) | Instala en el entorno de ejecución; SSH tiene pasos propios para el callback |
| Un agente de terminal que usa herramientas MCP nativas | [Guía de tu cliente MCP](/es/mcp/overview#choose-your-assistant) | Configura y autoriza directamente la conexión del host |
| Un cliente que solo admite stdio local | [MCP local](/es/mcp/other-clients#local-mcp) | Configura un proceso local, Node.js y una clave API personal |

Codex CLI es el cliente de tu agente; EvoLink CLI es la herramienta multimedia a la que este llama. Son productos distintos. Cada tarjeta recomienda una vía; las guías de la CLI para cada cliente también enlazan a la alternativa de MCP nativo.

## Verifica antes de generar

<Steps>
  <Step title="Instala y autentica la vía elegida">
    Sigue la [instalación de la CLI](/es/cli/setup) en cinco pasos o la [guía de tu cliente MCP](/es/mcp/overview#choose-your-assistant). Completa tú mismo el inicio de sesión en el navegador. No pongas claves ni tokens en el chat.
  </Step>
  <Step title="Consulta el saldo y los modelos, y verifica las habilidades o las herramientas">
    Con la CLI, consulta el saldo, ejecuta doctor y pide al agente que confirme que detecta la habilidad. Con MCP, llama de verdad a check_balance y search_models. Que haya archivos instalados o una lista de herramientas no demuestra que la ejecución funcione. Estas comprobaciones no envían tareas multimedia de pago.
  </Step>
  <Step title="Revisa el plan y el costo estimado antes de aprobar la generación">
    Comprueba el modelo y las entradas exactos, prepara las referencias y revisa el plan y la estimación. Tras la aprobación explícita, envía una sola vez, conserva el identificador de la tarea y guarda los originales. Consulta los [flujos de trabajo de la CLI](/es/cli/workflows) o los [flujos de trabajo de MCP](/es/mcp/overview#workflows).
  </Step>
</Steps>

## Cómo se relacionan las vías

Las solicitudes multimedia de la CLI siguen `agente / terminal → CLI → API de la plataforma`. El MCP nativo sigue `agente → MCP remoto o local → API de la plataforma`. La ejecución multimedia de la CLI no depende del MCP remoto. El inicio de sesión usa Passport; las subidas y las descargas de originales tienen endpoints de archivos propios.

La instalación, las sesiones y las comprobaciones de conexión son independientes. Actualmente, el OAuth de una misma cuenta puede compartir los permisos y las cuotas de la clave interna. Usa una sola vía para la tarea. Recupera los envíos de resultado desconocido por la vía original en lugar de volver a generar por la otra.
