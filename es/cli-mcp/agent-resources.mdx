Esta página explica las herramientas, las habilidades y la documentación para usuarios y agentes. Después de leer las instrucciones siguen haciendo falta la configuración real, la autenticación y la verificación gratuita de la conexión.

<span id="skills" />
## Qué hace cada componente

| Componente | Finalidad | Siguiente paso |
|---|---|---|
| EvoLink CLI | Ejecuta las operaciones de la plataforma en una terminal; las llamadas multimedia van directamente a las APIs | [Instalar, iniciar sesión y verificar](/es/cli/setup) |
| MCP remoto | Ofrece herramientas al host por HTTP, con inicio de sesión OAuth | [Elegir un cliente](/es/mcp/overview#choose-your-assistant) |
| MCP local | Ejecuta las herramientas en un proceso stdio local | [Configurar el inicio y una clave de la plataforma](/es/mcp/other-clients#local-mcp) |
| Habilidad | Guía la búsqueda de modelos, la aprobación, la recuperación y la entrega | Instálala donde el host la detecte y confirma que se carga |
| Plugin | Empaqueta la configuración y las habilidades específicas de cada host | [Pasos del plugin](/es/mcp/plugins), además de las comprobaciones de autenticación y permisos |
| Markdown/llms.txt | Instrucciones legibles o un índice de la documentación | Lee las páginas enlazadas; estos recursos no ejecutan herramientas |

Instalar la CLI no clona los repositorios de MCP ni de plugins, ni registra el MCP nativo. La CLI incluye evolink-cli; el repositorio del plugin de MCP ofrece la guía de herramientas evolink-mcp. Siguen siendo puntos de entrada que se mantienen por separado, no una fuente de habilidades ya unificada.

## Qué contienen las habilidades

Las habilidades actuales abarcan modelos y parámetros, flujos de trabajo de imagen, video y audio, referencias, estimaciones y aprobación, comprobaciones de presupuesto, recuperación del envío original, espera, descarga y entrega de los originales. La CLI incluye SKILL.md y tres documentos de referencia: capabilities, media-workflows y usage-and-budget. Consulta [Habilidades de la CLI](/es/cli/skills) para los destinos, los directorios, la carga y las actualizaciones, y [Plugins de MCP](/es/mcp/plugins) para la configuración en el host.

No existe una biblioteca aparte de habilidades para anuncios virales, piezas UGC terminadas, edición automática o ajustes preestablecidos. Los ejemplos no garantizan popularidad. El desarrollo de código, la edición de archivos arbitrarios y la creación de sitios web corresponden al host, no a las herramientas de EvoLink.

## Instrucciones comunes para agentes

```text
Elige EvoLink CLI o el MCP nativo para esta tarea y verifica la conexión real.
Consulta los modelos disponibles para la cuenta y los esquemas reales; explica la elección según la tarea, las referencias, la calidad y el presupuesto.
Muestra las especificaciones finales y el costo estimado, y envía una sola vez tras la aprobación explícita.
Recupera los resultados desconocidos por la vía original, con la misma identidad y el mismo identificador de solicitud.
Consulta el task_id original y entrega los originales, los costos reales informados y la caducidad.
Explica las capacidades no admitidas; no inventes modelos, entradas, herramientas, precios ni reembolsos.
No presentes los presupuestos de una estimación como garantía del cargo final, ni edites o regeneres los resultados automáticamente.
```

Vincula la tarea a una sola vía. La CLI usa comandos y cotizaciones locales; MCP usa herramientas y el client_request_id original. Consulta la referencia correspondiente. Que los archivos de la habilidad estén instalados no demuestra que el host la haya cargado, y leer las habilidades no configura las herramientas ni concede permiso de ejecución. No generes repetidamente para probar la detección.

<span id="readable-docs" />
## Usa Markdown y llms.txt

1. Lee el [resumen](/es/cli-mcp/overview) y elige el cliente y la vía.
2. Lee su guía de configuración, la referencia de comandos o herramientas y las reglas comunes. Consulta los esquemas actuales de los modelos durante la ejecución.
3. Usa la copia de página o la exportación a Markdown, cuando estén disponibles, para guardar un archivo .md para tu agente. No incluyas en él claves, tokens ni enlaces de autorización privados.
4. [llms.txt](https://docs.evolink.ai/llms.txt) es un índice de la documentación; no es un endpoint MCP, un instalador de la CLI ni una API de autenticación.

## Verifica después de actualizar

Tras actualizar la CLI, sincroniza las habilidades incluidas y vuelve a cargarlas en el host. Tras cambiar un plugin o la configuración manual de MCP, comprueba la conexión actual, OAuth y los permisos. Conserva los demás servicios y los cambios personales. Las versiones del paquete, de la documentación y de las herramientas pueden diferir; resuelve las discrepancias tomando como referencia las versiones realmente publicadas y los esquemas devueltos, y explica lo que quede sin confirmar.
