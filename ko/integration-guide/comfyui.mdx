## 개요

<Frame caption="ComfyUI 공식 Desktop 홈 화면: 인스턴스를 선택하거나 새로 만들면 캔버스로 진입합니다 (다른 설치 방식도 화면은 비슷합니다)">
  ![ComfyUI Desktop 홈 화면](/images/integration-guide/comfyui/desktop-home.jpg)
</Frame>

[ComfyUI](https://www.comfy.org/)는 현재 가장 인기 있는 **오픈소스 노드 기반 AI 이미지 생성 도구**입니다. "모델 로드, 프롬프트 작성, 이미지 생성" 같은 단계를 하나하나의 노드로 나누고, 캔버스 위에서 블록을 조립하듯 연결하면 매우 자유롭고 재사용 가능한 이미지 생성 워크플로를 만들 수 있습니다. 무료 오픈소스에 방대한 플러그인 생태계를 갖추어 AI 이미지 창작의 대표적인 작업 환경으로 자리 잡았습니다.

**EvoLink 공식 ComfyUI 플러그인**을 사용하면 ComfyUI 워크플로 안에서 클라우드의 `gpt-image-2` 모델을 직접 호출해 이미지를 생성할 수 있습니다. 텍스트-이미지와 이미지-이미지를 모두 지원하며, **로컬 GPU가 필요 없습니다**.

    ![이미지-이미지 결과](/images/integration-guide/comfyui/img2img-showcase.png)
  </Frame>
</Columns>

**지원 환경**: aki 올인원 패키지(ComfyUI-aki), ComfyUI 공식 Desktop, 포터블 버전, 수동 설치 버전 모두 사용할 수 있습니다.

## 시작하기 전에

### EvoLink API Key 발급

1. [EvoLink 대시보드](https://evolink.ai/dashboard)에 로그인합니다
2. [API Keys 관리 페이지](https://evolink.ai/dashboard/keys)에서 "Create New Key"를 클릭해 키를 만들고 복사합니다 (`sk-`로 시작)

<Frame caption="API Keys 관리 페이지 → 오른쪽 상단 Create New Key 클릭 → 생성된 Key 복사">
  ![API Key 생성](/images/integration-guide/comfyui/create-api-key.png)
</Frame>

<Warning>
**API Key는 계정 잔액을 여는 열쇠와 같습니다.** 로컬 노드 설정에만 입력하고, 채팅창·스크린샷·공개 저장소 등 어디에도 올리지 마세요. 유출이 의심되면 즉시 관리 페이지에서 삭제하고 새로 만드세요.
</Warning>

### 계정 잔액 확인

이미지 생성에는 크레딧(credits)이 소모됩니다. [대시보드](https://evolink.ai/dashboard)에서 잔액이 충분한지 확인하세요. 건별 사용 내역은 [작업 로그 페이지](https://evolink.ai/dashboard/logs)에서 조회할 수 있습니다.

## 1단계: EvoLink 공식 플러그인 설치

<Tabs>
  <Tab title="방법 A: ComfyUI 공식 Desktop">

    2. **`evolink`** 검색 → Created By가 **evolink**인 **EvoLink** 항목 선택 → **Install** 클릭
    3. 안내에 따라 ComfyUI를 재시작합니다

    <Frame caption="Desktop 노드 관리자에서 EvoLink 검색 → 설치 (그림은 설치 완료 후의 노드 정보 패널)">

    </Frame>

  </Tab>
  <Tab title="방법 B: aki 올인원 패키지">
    1. 런처에서 ComfyUI를 실행한 뒤, 브라우저에 열린 ComfyUI에서 상단 툴바의 **Manager** 클릭 → **Custom Nodes Manager**를 엽니다

    <Frame caption="Manager 패널 → Custom Nodes Manager">
      ![Manager 패널](/images/integration-guide/comfyui/manager-menu.png)
    </Frame>

    2. 검색창에 **`evolink`** 입력 → Author가 **evolink**인 **EvoLink** 항목 선택 → **Install** 클릭

    <Frame caption="evolink 검색 → Author가 evolink인 공식 패키지 확인 → Install">
      ![Manager에서 EvoLink 검색](/images/integration-guide/comfyui/manager-search-evolink.png)
    </Frame>

    3. Action 열이 **Restart Required**로 바뀌면 설치 성공입니다 → 런처에서 프로세스를 종료한 뒤 다시 실행 → **브라우저 새로고침**

    <Note>
    설치 중 `Neither 'pip' nor 'uv' are available for package management` 오류가 뜨더라도 **무시해도 됩니다**. 이 플러그인의 유일한 의존성은 `requests`이며 aki 패키지 환경에 이미 포함되어 있어 기능에 아무 영향이 없습니다. Action 열에 **Restart Required**가 표시되면 설치는 이미 성공한 것입니다.
    </Note>
  </Tab>
  <Tab title="방법 C: git 설치">
    `ComfyUI/custom_nodes` 디렉터리에서 다음을 실행합니다.

    ```bash
    git clone https://github.com/deeplearning-goethe/comfyui-evolink.git
    ```

    aki 올인원 패키지 사용자: `custom_nodes`는 `ComfyUI-aki-vX.X` 설치 폴더 안에 있습니다. 런처의 터미널을 사용하거나, 해당 디렉터리에서 PowerShell을 열어 위 명령을 실행하면 됩니다.
  </Tab>
  <Tab title="방법 D: ZIP 다운로드">
    1. [플러그인 저장소](https://github.com/deeplearning-goethe/comfyui-evolink)를 열고 → 초록색 **Code** 버튼 → **Download ZIP** → 압축 해제
    2. 압축을 푼 폴더를 `ComfyUI/custom_nodes/` 안에 넣습니다
    3. **중첩 폴더 확인(필수)**: `custom_nodes/comfyui-evolink/`를 열었을 때 `__init__.py`가 **바로 보여야** 합니다. 같은 이름의 폴더가 한 겹 더 있다면(ZIP 압축 해제 시 흔한 문제) 안쪽 폴더를 `custom_nodes` 바로 아래로 옮기고 바깥의 빈 껍데기 폴더는 삭제하세요

    올바른 구조 예시:

    ```
    ComfyUI-aki-v3.7\
      └─ custom_nodes\
           ├─ ComfyUI-Manager\
           └─ comfyui-evolink\
                ├─ __init__.py
                └─ ...기타 파일
    ```
  </Tab>
</Tabs>

플러그인의 유일한 의존성은 `requests`입니다 (ComfyUI 환경에 보통 이미 포함되어 있어 별도 설치가 필요 없습니다).

<Accordion title="방법 A / B에서 Install 클릭 시 only custom nodes from the default channel can be installed 오류가 나나요? 해결 방법 펼쳐 보기">
  <Frame caption="오류 예시: 현재 보안 수준 설정에서는 설치할 수 없음">
    ![default channel 오류](/images/integration-guide/comfyui/manager-default-channel-error.png)
  </Frame>

  이 오류는 플러그인 버전이 ComfyUI 공식 저장소의 보안 검토를 받는 중이어서 발생합니다(클라우드 API 계열 노드의 일반적인 절차로, 검토 기간에는 Manager의 기본 보안 수준이 설치를 차단합니다). **Manager 보안 수준을 임시로 낮추면** 해결할 수 있으며, 설치 후 다시 원래대로 되돌리면 됩니다.

  **1단계: ComfyUI 완전히 종료**
  - aki 올인원 패키지: 런처 → **프로세스 종료**
  - 공식 Desktop / 포터블 / 수동 설치: 검은색 콘솔 창까지 포함해 앱을 완전히 종료

  **2단계: Manager 설정 파일 `config.ini` 수정**

  설치 방식에 따라 파일을 찾습니다 (못 찾겠다면 ComfyUI 설치 폴더에서 `config.ini`를 검색하고, 경로에 `manager`가 들어간 것을 선택하세요):

  | 환경 | config.ini 위치 |
  |---|---|
  | aki 올인원 패키지 | `다운로드 경로\ComfyUI-aki-vX.X\ComfyUI-aki-vX.X\ComfyUI\user\__manager\config.ini` |
  | 공식 버전(Desktop / 포터블 / 수동) | `ComfyUI 설치 디렉터리\user\default\ComfyUI-Manager\config.ini` |

  메모장으로 열어 `security_level` 줄을 찾고 `normal`을 `weak`로 바꿉니다.

  ```ini
  security_level = weak
  ```

  저장하고 닫습니다.

  <Frame caption="security_level 값을 weak로 바꾸고 저장하세요 (다른 줄은 건드리지 마세요)">
    ![security_level 수정](/images/integration-guide/comfyui/manager-config-security-level.png)
  </Frame>

  **3단계: ComfyUI 재시작 후 다시 설치**

  ComfyUI 실행 → Manager → `evolink` 검색 → **Install**. 이번에는 다운로드가 시작됩니다. `Neither 'pip' nor 'uv'...` 오류가 뜨면 위 설명대로 무시하세요. **Restart Required**가 표시되면 한 번 더 완전히 재시작하고 브라우저를 새로고침합니다.

  **4단계: 확인 후 보안 수준 복원**
  - 아래 [설치 확인](#설치-확인) 절차에 따라 노드가 로드되었는지 확인합니다
  - **설치가 끝나면 `security_level`을 다시 `normal`로 되돌리는 것을 권장합니다** (1~2단계를 한 번 더 수행). Manager의 기본 보안 보호를 복원하기 위함입니다
</Accordion>

### 설치 확인

완전히 재시작하고 브라우저를 새로고침한 뒤, 캔버스 빈 곳을 **더블 클릭** → `evolink`를 검색합니다. **EvoLink GPT Image 2 (Official)**과 **EvoLink Upload Image (Official)** 두 노드가 보이면 설치 성공입니다.

<Frame caption="캔버스 더블 클릭 후 evolink 검색: 공식 노드 두 개가 나타나면 설치 성공 (aki 올인원 패키지 실제 스크린샷)">
  ![설치 확인: evolink 검색](/images/integration-guide/comfyui/search-nodes.png)
</Frame>

노드가 검색되지 않나요? 먼저 **완전히 재시작**했는지(브라우저 새로고침만으로는 안 됩니다) 확인하고, 그래도 안 되면 [자주 묻는 질문](#자주-묻는-질문)을 참고하세요.

## 2단계: 첫 이미지 생성 (텍스트-이미지, 5분)

1. 캔버스 빈 곳을 **더블 클릭**(또는 우클릭 → Add Node) → **`EvoLink`** 검색 → **EvoLink GPT Image 2 (Official)** 노드를 추가합니다 (앞서 설치 확인 때 본 노드입니다)

2. 파라미터 입력:
   - `api_key`: `sk-` Key를 붙여넣습니다. **처음 한 번만 입력하면 됩니다** — 첫 실행 후 로컬 설정 파일에 자동 저장되므로 이후에는 비워 두면 됩니다 (워크플로를 공유하기 전에 비워 두었는지 꼭 확인하세요)
   - `prompt`: 화면 묘사입니다. **한국어를 지원**하며, 예: `빨간 목도리를 두른 시바견이 눈밭에 앉아 있는 모습, 플랫 일러스트 스타일`
   - 나머지 파라미터는 기본값 유지 (`quality=low`가 가장 저렴해 테스트에 적합합니다)

3. **표시 노드 연결(필수)**: 노드 오른쪽의 `image` 출력 점을 마우스로 잡고 빈 곳으로 드래그해 놓으면 뜨는 메뉴에서 **Preview Image**를 선택합니다. 이미지를 로컬에 저장하려면 **Save Image** 노드도 연결하세요 (이미지가 ComfyUI의 `output` 폴더에 저장됩니다)

<Warning>
**초보자가 가장 자주 빠뜨리는 단계입니다**: EvoLink 노드는 생성만 담당하고 표시는 하지 않습니다. `image` 출력을 아무 노드에도 연결하지 않으면 작업이 끝나도 이미지를 볼 수 없습니다.
</Warning>

<Frame caption="파라미터를 입력하고 image를 Preview Image에 연결한 완성 워크플로 (api_key는 첫 입력 후 비워 두면 되며, 스크린샷은 마스킹 처리됨)">
  ![텍스트-이미지 완성 워크플로](/images/integration-guide/comfyui/text2img-workflow.png)
</Frame>

4. 오른쪽 상단의 **Queue Prompt**를 클릭합니다. 노드가 "작업 제출 → 진행 상황 폴링 → 이미지 수신"을 자동으로 처리하며, 진행률이 실시간으로 표시되고 결과는 Preview 노드에 바로 나타납니다 (위 그림 참조).

## 3단계: 이미지-이미지 (3단계로 끝)

1. **Load Image** 노드를 추가하고 로컬 이미지를 선택합니다
2. 해당 노드의 이미지 출력을 EvoLink 노드의 **`image1`** 입력에 연결합니다
3. `prompt`에 수정 요청을 적고 → 실행합니다

<Frame caption="이미지-이미지 전체 연결: Load Image → image1, prompt에 수정 요청 작성 (예시: 지브리 스타일로 바꾸고 배경을 밤거리로 변경) — 구도는 그대로 유지">
  ![이미지-이미지 완성 워크플로](/images/integration-guide/comfyui/img2img-workflow.png)
</Frame>

<Note>
이미지는 **EvoLink 공식 채널**을 통해 자동 업로드되어 임시 링크로 변환됩니다 (**72시간 후 자동 삭제**). 어떤 서드파티 이미지 호스팅도 거치지 않으며, 별도의 서비스 가입도 필요 없습니다.
</Note>

**고급 활용**:

- **다중 참조 이미지**: `image1`~`image4` 네 개의 입력에 모두 이미지를 연결할 수 있고, `image_urls` 텍스트 상자에 한 줄에 하나씩 공개 이미지 URL을 붙여넣을 수도 있습니다. 두 방식을 섞어 최대 **16장**까지 사용할 수 있습니다
- **복잡한 워크플로 구성**: 플러그인에 함께 포함된 **EvoLink Upload Image (Official)** 노드로 로컬 이미지를 일괄 URL 텍스트로 변환할 수 있습니다 (일반적인 이미지-이미지에는 필요 없습니다)
- **바로 쓰는 예제 워크플로**: [example_workflows](https://github.com/deeplearning-goethe/comfyui-evolink/tree/main/example_workflows)에 텍스트-이미지 / 이미지-이미지 / 다중 참조 이미지 세 가지 예제가 있습니다. **각 예제의 결과 PNG에 전체 워크플로가 내장되어 있어, 이미지를 내려받아 캔버스에 드래그하면 모든 노드와 연결이 그대로 복원됩니다** (ComfyUI 기본 기능). 같은 이름의 JSON 파일로 가져올 수도 있습니다

## 파라미터 상세

| 파라미터 | 설명 |
|---|---|
| `prompt` | 화면 묘사 / 수정 요청, 한국어 지원, 최대 32,000자 |
| `model` | `gpt-image-2`(기본값) / `gpt-image-2-beta` |
| `size` | `auto`(기본값, 모델이 구도 결정) / `1:1`, `16:9` 같은 비율 / `1024x1024` 같은 픽셀 |
| `resolution` | `1K` / `2K` / `4K`, size가 비율이거나 auto일 때 적용 |
| `quality` | `low` / `medium` / `high`, **높을수록 비쌉니다**. 테스트에는 `low` 권장 |
| `n` | 한 번에 생성할 매수 (1–10) |
| `api_key` | 첫 입력 후 로컬에 자동 저장되며 이후 비워 두면 됩니다. 환경 변수 `EVOLINK_API_KEY`도 지원 |
| `image1`~`image4` | 참조 이미지 입력. Load Image를 연결하면 이미지-이미지가 됩니다 |
| `image_urls` | 고급: 이미 공개 이미지 URL이 있다면 한 줄에 하나씩 입력 |
| `timeout_seconds` | 최대 대기 시간 (기본 300초). 타임아웃으로 실패한 작업은 과금되지 않습니다 |

노드 출력: `image`(결과 이미지, 자동 다운로드 완료), `task_id`(정산 조회 및 문의 시 증빙), `status_info`(작업 요약: 소요 시간, 소모 credits 등).

## 요금 및 확인 방법

- **사용량 기반 과금, 구독 없음**: 작업 제출 시 선차감(`credits_reserved`)되고, 완료 후 실제 사용량으로 정산됩니다
- **실패 / 타임아웃 작업은 과금되지 않으며**, 크레딧이 자동 환불됩니다
- **캐시는 과금되지 않습니다**: 파라미터를 바꾸지 않고 다시 실행하면 ComfyUI 로컬 캐시가 재사용되어 새 요청이 발생하지 않습니다
- **모든 내역 조회 가능**: [작업 로그 페이지](https://evolink.ai/dashboard/logs)에서 `task_id`(노드 출력 중 하나)로 상태와 차감 내역을 확인할 수 있습니다. 특정 차감에 의문이 있다면 `task_id`를 고객 지원에 보내 주시면 확인해 드립니다

## 부록: 플러그인 없이 API 직접 호출

Key가 유효한지 먼저 확인하거나, 플러그인이 아직 지원하지 않는 다른 모델을 호출하고 싶을 때 유용합니다.

**30초 만에 Key 검증하기 (무료)** — `sk-YOUR_KEY`를 본인의 Key로 바꾸세요.

```bash
curl -s -H "Authorization: Bearer sk-YOUR_KEY" https://api.evolink.ai/v1/models
```

모델 목록(`{"data":[{"id":...`)이 반환되면 Key가 유효한 것이고, `Unauthorized`가 반환되면 Key가 잘못됐거나 만료된 것입니다.

**생성 작업 제출**:

```bash
curl -s -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer sk-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"a cute cat, watercolor style","size":"1:1","resolution":"1K","quality":"low","n":1}'
```

반환된 작업 `id`(`task-unified-`로 시작)를 기록해 두고, `status`가 `completed`가 될 때까지 폴링하세요. `results` 배열이 이미지 링크입니다 (24시간 이내에 다운로드해 저장하세요).

```bash
curl -s -H "Authorization: Bearer sk-YOUR_KEY" https://api.evolink.ai/v1/tasks/TASK_ID
```
