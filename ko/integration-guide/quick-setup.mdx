## 개요

직접 설정하려면 클라이언트를 설치하고, 설정 파일을 수정하고, 엔드포인트와 API Key를 입력해야 합니다. 설정 스크립트(`evolink-config`)는 이 모든 작업을 명령어 한 줄로 처리합니다:

- 환경을 확인하고, 클라이언트가 아직 컴퓨터에 없으면 설치합니다
- EvoLink 엔드포인트와 API Key를 입력합니다
- 테스트 메시지를 한 번 보내 호출이 정상적으로 되는지 확인합니다
- 파일을 변경하기 전에 모두 백업하며, 명령어 한 줄로 모든 변경을 되돌릴 수 있습니다

전체 과정은 보통 1분도 걸리지 않습니다.

| 클라이언트 | 원클릭 설정 |
|---|---|
| Claude Code CLI | 지원 |
| Codex CLI | 지원 |
| 기타 클라이언트 | "AI 코딩 도구"의 수동 가이드를 참고하세요 |

<Note>
아래 명령어는 macOS와 Linux용입니다. Windows에서는 당분간 [Claude Code CLI](/ko/integration-guide/claude-code-cli) 또는 [Codex CLI](/ko/integration-guide/codex-cli) 수동 가이드를 따라 설정하세요.
</Note>

## 사전 준비

- **EvoLink API Key**: [EvoLink 콘솔](https://evolink.ai/dashboard)에 로그인하고 API Keys에서 Key를 만든 뒤 복사합니다. Key는 `sk-`로 시작합니다.
- **Node.js**: 버전 22 이상을 권장합니다(최소 18). 터미널에서 `node -v`를 실행해 확인하세요. 설치되어 있지 않으면 [Node.js 공식 웹사이트](https://nodejs.org/)에서 LTS 버전을 다운로드하세요.

## Claude Code 설정

터미널에서 다음을 실행합니다:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash
```

스크립트가 다섯 단계로 안내합니다(스크립트 메시지는 영어로 표시됩니다):

<Steps>
  <Step title="환경 확인">
    Node.js와 Claude Code를 확인합니다. Claude Code가 아직 설치되어 있지 않으면 스크립트가 "Install now?"라고 묻습니다. Enter 키를 누르면 자동으로 설치합니다.
  </Step>
  <Step title="API Key">
    EvoLink API Key를 붙여넣고 Enter 키를 누릅니다. 붙여넣은 내용은 화면에 표시되지 않습니다. 스크립트가 Key가 유효한지 온라인으로 확인하고 잔액을 보여 줍니다.
  </Step>
  <Step title="모델 선택">
    Claude Code가 기본으로 사용할 모델을 선택합니다. Claude Code 안에서 `/model`로 언제든지 바꿀 수 있습니다.
  </Step>
  <Step title="변경 사항 확인">
    스크립트가 변경할 파일과 설정 목록을 보여 줍니다. Enter 키를 누르면 적용됩니다.
  </Step>
  <Step title="적용 및 확인">
    설정을 저장한 뒤 스크립트가 테스트 메시지를 한 번 보냅니다(약 0.01 크레딧). 정상 응답이 오면 설정이 완료된 것입니다.
  </Step>
</Steps>

완료되면 새 터미널 창을 열고 다음을 실행합니다:

```bash
claude
```

Claude Code 안에서 `/status`를 실행합니다. Anthropic base URL에 EvoLink 주소가 표시되면 설정이 적용된 것입니다.

## Codex CLI 설정

터미널에서 다음을 실행합니다:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- codex
```

단계는 위와 같습니다. 완료되면 다음 명령어로 Codex를 시작합니다:

```bash
codex -p evolink
```

<Note>
스크립트는 Codex용으로 별도의 프로필 `~/.codex/evolink.config.toml`을 만들며, 기존 `~/.codex/config.toml`은 변경하지 않습니다. Codex는 `-p evolink`를 붙여 시작할 때만 EvoLink를 사용하며, `codex`만 실행하면 원래 설정을 그대로 사용합니다.
</Note>

## 스크립트가 변경하는 파일

### Claude Code

| 파일 | 변경 내용 |
|---|---|
| `~/.claude/settings.json` | 엔드포인트 `ANTHROPIC_BASE_URL`과 Key `ANTHROPIC_AUTH_TOKEN`을 입력합니다. 컴퓨터에 남아 있는 이전 Key 때문에 401 오류가 나지 않도록 `ANTHROPIC_API_KEY`를 빈 값으로 설정합니다. Sonnet에 사용할 모델 버전을 고정합니다. 자동 모드를 끕니다(이유는 아래 FAQ 참고). 파일의 나머지 설정은 그대로 유지됩니다. |
| `~/.claude.json` | 첫 실행 시 표시되는 로그인 화면을 건너뜁니다. 동의하시면 현재 폴더를 신뢰할 수 있는 폴더로 표시합니다. |

### Codex CLI

| 파일 | 변경 내용 |
|---|---|
| `~/.codex/evolink.config.toml` | 새로 만듭니다. EvoLink 엔드포인트, 기본 모델, Key가 들어 있으며 본인만 읽을 수 있습니다. |
| `~/.codex/config.toml` | 변경하지 않습니다. |

### 공통 사항

- 모든 파일은 변경하기 전에 `~/.evolink/backups/`에 백업됩니다.
- 스크립트 자체는 `~/.evolink/`에 저장되며, 명령어는 `~/.evolink/bin/evolink-config`입니다. PATH나 셸 프로필은 변경하지 않습니다.
- Key는 컴퓨터의 설정 파일에만 저장되며 EvoLink API로만 전송됩니다.

<Note>
`evolink-config`는 API 연결 설정만 담당합니다. 이미지, 동영상, 오디오를 생성하는 커맨드라인 도구 `evolink`(CLI/MCP 섹션 참고)와는 다른 도구이며, 두 도구를 함께 사용할 수 있습니다.
</Note>

## 확인, 되돌리기, 다시 설정하기

### 변경 내용 미리 보기(아무것도 저장하지 않음)

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --dry-run
```

### 현재 설정 확인

```bash
~/.evolink/bin/evolink-config doctor
```

출력에서는 Key가 가려지므로 그대로 고객 지원팀에 보내셔도 됩니다. Codex는 `~/.evolink/bin/evolink-config doctor codex`를 사용하세요.

### 설정 되돌리기

```bash
~/.evolink/bin/evolink-config reset
```

스크립트가 변경한 내용을 모두 원래대로 되돌립니다. Codex는 `~/.evolink/bin/evolink-config reset codex`를 사용하세요.

### Key 또는 기본 모델 변경

설정 명령어를 다시 실행하세요.

## FAQ

### 1. Node.js를 찾을 수 없다고 나오면 어떻게 하나요?

[Node.js 공식 웹사이트](https://nodejs.org/)에서 LTS 버전을 설치한 뒤 새 터미널을 열고 설정 명령어를 다시 실행하세요.

### 2. 이미 직접 설정했습니다. 기존 설정이 덮어쓰기되나요?

통째로 덮어쓰지는 않습니다. 스크립트는 위에 나열한 항목만 변경하고 나머지는 그대로 둡니다. 저장하기 전에 각 항목의 이전 값과 새 값을 보여 주고 원본 파일을 백업합니다.

### 3. Claude Code에 자동 모드(auto mode)가 없는 이유는 무엇인가요?

자동 모드에서는 Claude Code가 명령어마다 확인을 요청하지 않습니다. 대신 먼저 검토 요청을 보내고, 모델이 해당 명령어를 안전하게 실행할 수 있는지 판단합니다. 이 검토 요청도 다른 요청과 마찬가지로 토큰 단위로 과금됩니다. 어떤 기본 모델을 선택했든 `claude-sonnet-5`가 사용됩니다.

예상하지 못한 비용이 발생하지 않도록 스크립트는 기본적으로 자동 모드를 끄며, Claude Code는 명령어를 실행하기 전에 확인을 요청합니다. 설정이 끝날 때 스크립트가 이 점을 다시 안내합니다.

자동 모드를 사용하려면 다음과 같이 켜세요:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --auto-mode
```

다시 끄려면 `--auto-mode` 없이 설정 명령어를 한 번 더 실행하세요.

### 4. 실행하기 전에 스크립트 내용을 확인할 수 있나요?

네. 다운로드해서 내용을 확인한 뒤 실행하세요:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh -o setup.sh
less setup.sh
bash setup.sh
```

### 5. "Rate limited (429)"라고 나오면 어떻게 하나요?

각 계정이 1분 동안 Key를 확인할 수 있는 횟수는 제한되어 있습니다. 스크립트를 여러 번 연달아 실행하면 이 메시지가 표시됩니다. 메시지에 표시된 시간(초)만큼 기다린 뒤 스크립트를 다시 실행하세요.

### 6. 설정 후에도 작동하지 않으면 어떻게 하나요?

`~/.evolink/bin/evolink-config doctor`를 실행하고 출력 내용을 고객 지원팀에 보내 주세요. [Claude Code CLI](/ko/integration-guide/claude-code-cli) 및 [Codex CLI](/ko/integration-guide/codex-cli) 페이지의 문제 해결 섹션도 참고하세요.
