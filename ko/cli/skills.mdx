## CLI 스킬 설치와 관리

이 페이지는 evolink-cli의 설치 대상, 디렉토리, 호스트 인식, 업데이트를 다룹니다. 적용 범위, CLI/MCP/플러그인 개념, 공통 규칙은 [공통 자료](/ko/cli-mcp/agent-resources)를 참고하세요.

## 설치하고 인식 검증하기

```bash
evolink skills install
evolink skills status --json
```

기본 설치는 지원되는 대상 디렉토리 전체에 설치하며, 에이전트 자체를 설치하지는 않습니다. 호스트 하나만 선택하려면 다음을 실행하세요:

```bash
evolink skills install --agent codex
evolink skills status --agent codex --json
evolink doctor --agent codex --json
```

current:true를 확인하고 에이전트 채팅에 다음을 보내세요:

```text
이 세션에서 evolink-cli를 인식하고 읽을 수 있는지 확인해 주세요. 먼저 잔액과 모델을 조회하고, 미디어는 생성하지 마세요.
```

assistant_discovery:not_checked는 CLI가 호스트를 대신해 인식 여부를 검증할 수 없다는 뜻입니다. 파일은 있는데 사용되지 않는다면 스킬을 새로 고치거나 새 세션을 열고 명령 권한을 확인하세요. 문서를 읽었다는 것만으로는 계정에 접근할 수 있다는 증거가 되지 않습니다.

## 지원되는 설치 대상과 디렉토리

| --agent | 클라이언트 | 디렉토리 |
|---|---|---|
| codex | Codex | ~/.agents/skills/evolink-cli |
| claude-code | Claude Code | ~/.claude/skills/evolink-cli |
| cursor | Cursor | ~/.agents/skills/evolink-cli |
| openclaw | OpenClaw | ~/.openclaw/skills/evolink-cli |
| hermes | Hermes | ~/.hermes/skills/evolink-cli |
| gemini | Gemini CLI | ~/.agents/skills/evolink-cli |
| opencode | OpenCode | ~/.agents/skills/evolink-cli |
| copilot | GitHub Copilot CLI | ~/.agents/skills/evolink-cli |

Gemini, OpenCode, Copilot은 각자의 agent 값으로 [일반적인 다섯 단계 설치](/ko/cli/setup#cli-install)를 따르면 됩니다. 실제로 사용하는 SSH/WSL/컨테이너/Gateway 환경에 설치하세요. 이들은 설치 대상일 뿐, 모든 호스트 버전에서 인식된다는 보장은 아닙니다. 호스트 정책과 스킬 로드는 여전히 호스트가 책임지는 영역입니다.

## 업데이트와 개인 수정 사항

```bash
npm install -g @evolinkai/cli@latest
evolink skills install
evolink skills status --json
```

CLI를 업데이트한 뒤에는 스킬을 동기화하고 에이전트에게 다시 읽으라고 요청하세요. 개인 변경 사항은 기본적으로 유지됩니다. 먼저 modified/conflict 상태를 확인하세요. --replace-modified는 개인 수정 내용을 교체하기로 결정한 뒤에만 사용하세요. 원본은 ~/.evolink-media/skill-backups/ 에 백업됩니다. [스킬 문제 해결](/ko/cli/billing#skills-discovery)을 참고하세요.

CLI 0.10.0부터는 `--agent` 없이 실행한 `evolink doctor`가 각 에이전트에 설치된 스킬 사본도 검사합니다. 사본이 CLI보다 오래되었으면 `guidance`가 `evolink skills install`을 실행하라고 안내합니다. 개인 수정 사항과 충돌은 보고만 할 뿐 교체하지 않습니다. 이 검사 결과는 `ok` 값을 바꾸지 않습니다. CLI가 새 릴리스를 알리는 방식은 [새 버전이 나왔는지 확인하는 방법](/ko/cli/setup#update-check)을 참고하세요.

## 에이전트용 자료

에이전트에게 [공통 규칙과 읽을 수 있는 자료](/ko/cli-mcp/agent-resources#agent-rules), [CLI 레퍼런스](/ko/cli/reference), [미디어 작업 흐름](/ko/cli/workflows)을 제공하세요. 모델 스키마는 models schema MODEL_ID로 조회하세요. 스킬 로드와 계정 연결은 따로 검증하세요. 네이티브 MCP 설치는 [MCP 플러그인](/ko/mcp/plugins)을 참고하세요.
