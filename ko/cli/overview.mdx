클라이언트별로 선택하려면 [CLI/MCP 개요](/ko/cli-mcp/overview)를 참고하세요. 이 섹션의 공통 자료는 비용, 작업, 파일, 에이전트 지침을 다룹니다.

EvoLink CLI를 사용하면 터미널을 쓸 수 있는 에이전트와 터미널 사용자가 이미지, 영상, 음악, 음성을 생성하고, 모델과 매개변수를 확인하고, 잔액과 작업을 조회하고, 참조 파일을 업로드하고, 원본을 저장할 수 있습니다.

이 섹션은 정식 출시된 **CLI 0.14.1**을 기준으로 합니다. macOS, Windows 또는 Linux에서 Node.js 22+가 필요합니다. 에이전트가 명령을 실행하는 컴퓨터와 사용자 계정에 설치하세요. 미디어 요청은 **에이전트/터미널 → CLI → 플랫폼 API** 순서로 전달됩니다.

## 설치와 검증

터미널을 쓸 수 있는 에이전트에게 아래 프롬프트를 보내세요. 웹사이트의 설치 프롬프트와 같은 내용입니다:

```text
여기서 이미지, 동영상, 오디오를 바로 생성할 수 있도록 EvoLink를 설정해 주세요.
1. CLI 설치: `npm install -g @evolinkai/cli`를 실행하세요.
2. 로그인: `evolink auth login`을 실행하세요.
3. 함께 제공되는 스킬 설치: `evolink skills install`을 실행하세요.
4. 연결을 확인하고 성공하면 시작할 수 있다고 알려 주세요.
```

프롬프트는 채팅에 붙여넣으세요. 명령은 에이전트의 터미널이나 사용자의 터미널에서 실행됩니다. 브라우저 로그인과 권한 승인은 직접 완료하세요. 자세한 단계, 성공 표시, 업데이트, 로그아웃, SSH 콜백은 [설치와 로그인](/ko/cli/setup)을 참고하세요.

기본적인 수동 설치 순서는 다음과 같습니다:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
evolink doctor --json
```

로그인이 완료될 때까지 기다린 뒤 다음으로 넘어가세요. 블록 전체를 한꺼번에 붙여넣고 인증 단계를 건너뛰지 마세요. 에이전트에게 evolink-cli를 읽었는지 확인해 달라고 요청하세요. 잔액 조회와 진단은 유료 미디어 작업을 만들지 않습니다. 검증을 마친 뒤 제작을 시작하세요.

## CLI 기능

| 기능 | 사용법과 가이드 |
|---|---|
| 환경과 접근 권한 | version, auth, setup, doctor. [설치](/ko/cli/setup) 참고 |
| 모델과 매개변수 | models search/recommend/show/schema, docs search. [레퍼런스](/ko/cli/reference) 참고 |
| 예상 비용 산정과 승인 | estimate가 로컬 견적을 만들고, 승인 후에 생성합니다. [작업 흐름](/ko/cli/workflows) 참고 |
| 미디어 | 모델 기능에 따라 이미지, 영상, 음악, 음성 |
| 참조 파일 | upload로 로컬 파일을 업로드하고, uploads get으로 원래 접수 확인을 조회합니다 |
| 작업 | get/wait, batch, 페이지 단위 기록 조회, 견적 기반 복구 |
| 원본 다운로드 | 결과 하나 또는 전체, 형식 검사, 배치 복구 |
| 계정과 사용량 | balance와 범위가 제한된 과거 사용량 조회. 완전한 청구서가 아닙니다 |
| 스킬 | skills install/status와 호스트 인식 확인 |

CLI는 일반 텍스트 채팅, 대기열 취소, 충전, 키 관리, 자동 편집, 완성 영상 호스팅을 제공하지 않습니다. 코드 개발과 임의의 파일 편집은 호스트 에이전트의 기능입니다. 생성된 원본을 먼저 전달하세요. 새 변형, 편집, 재생성에는 그에 맞는 승인이 필요합니다.

## 첫 제작

```text
EvoLink로 커피 브랜드 광고 이미지를 만들어 주세요.
먼저 사용할 수 있는 이미지 모델, 매개변수, 비용을 조회한 뒤 추천 이유와 출력 사양을 설명해 주세요.
제가 명시적으로 승인한 뒤 한 번만 제출하고, 작업 ID를 저장하고, 원본을 다운로드하면서 보고된 실제 비용도 알려 주세요.
```

[모델 → 참조 파일 → 예상 비용 → 승인 → 작업 → 다운로드](/ko/cli/workflows) 순서를 따르세요. 설치는 유료 생성에 대한 승인이 아닙니다. 예상 비용은 최종 정산 금액이 아닙니다. [비용과 문제 해결](/ko/cli/billing)을 참고하세요.

## CLI와 MCP

CLI를 설치하면 실행 파일, 공유 비즈니스 모듈, 번들 evolink-cli 스킬이 함께 설치됩니다. MCP/플러그인 저장소를 복제할 필요가 없으며, 네이티브 MCP를 등록하지도 않습니다. OAuth는 Passport가 제공하고, 자격 증명은 운영 체제가 안전하게 저장합니다.

CLI 세션과 원격 MCP 세션은 따로 관리됩니다. 현재 계정 OAuth는 내부 키의 권한, 한도, 일시 중지 상태를 공유합니다. Claude/ChatGPT 웹이나 네이티브 도구 호출에는 [별도의 MCP 섹션](/ko/mcp/overview)을 이용하세요.
