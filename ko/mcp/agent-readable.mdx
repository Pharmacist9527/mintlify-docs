CLI/MCP/스킬/플러그인의 공통 개념, 현재 스킬이 다루는 범위, 공통 지침, Markdown, llms.txt는 [에이전트용 자료](/ko/cli-mcp/agent-resources)에서 관리합니다. 기존 URL인 이 페이지는 예전 링크를 위해 계속 제공됩니다.

<span id="skills" />
## 네이티브 MCP 에이전트가 읽어야 할 내용

1. [MCP 개요](/ko/mcp/overview)와 클라이언트 설정 페이지를 읽은 뒤 호스트를 설정하고 인증하세요.
2. [MCP 도구 레퍼런스](/ko/mcp/tools)와 실제 도구 스키마를 참고하세요.
3. 필요하면 [플러그인 설치 단계](/ko/mcp/plugins)에 따라 evolink-mcp 안내나 호스트 플러그인을 설치하세요. 스킬을 읽는다고 도구가 등록되거나 인증되지는 않습니다.
4. [에이전트 공통 규칙](/ko/cli-mcp/agent-resources#agent-rules)을 적용한 뒤 [MCP 문제 해결](/ko/mcp/billing#faq)을 참고해 실제 호출을 검증하세요.

evolink-cli는 터미널 명령을 안내하고, 네이티브 MCP는 evolink-mcp 도구 지침을 사용합니다. 설치와 인증은 따로 검증하세요. llms.txt는 문서 색인이며, MCP 엔드포인트는 여전히 다음 주소입니다: https://mcp.evolink.ai/mcp.
