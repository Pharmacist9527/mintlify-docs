ChatGPT 채팅은 **원격 MCP**를 사용합니다. 클라이언트와 브라우저에서 설정하면 되며, 로컬 CLI 설치와 개인 API Key는 필요 없습니다.

## 시작하기 전에

EvoLink 계정과 ChatGPT 계정, 그리고 커스텀 MCP를 허용하는 클라이언트 버전, 요금제, 워크스페이스 권한이 필요합니다. 추가 버튼을 사용할 수 없다면 채팅에서 터미널 안내를 실행하지 말고 먼저 호스트의 접근 권한을 확인하세요.

## 단계별로 EvoLink 연결하기

<Steps>

<Step title="커스텀 MCP 추가 화면 열기">

[ChatGPT Plugins](https://chatgpt.com/plugins)를 열고 Add 또는 더하기 버튼을 선택한 다음 **Create/Add custom MCP server**를 선택하세요. 웹사이트에서 안내하는 설정 진입점과 같습니다. 버튼 이름은 버전에 따라 다를 수 있습니다. 해당 항목이 없으면 워크스페이스 접근 권한을 확인하세요.

</Step>

<Step title="연결 정보 입력">

| 항목 | 값 |
|---|---|
| Icon(아이콘, 선택 사항) | [EvoLink 아이콘](https://cdn.evolink.ai/next/evolink-logo.png)을 다운로드해 업로드하세요. 양식에 아이콘 항목이 없으면 건너뛰세요 |
| Name(이름) | EvoLink |
| Connection(연결) | Server URL |
| Server URL | `https://mcp.evolink.ai/mcp` |
| Authentication(인증) | OAuth |
| Client ID / Client Secret | 기본값 그대로 두세요. 플랫폼 API Key를 입력하지 마세요 |

원격 HTTP를 사용하고 끝의 `/mcp`를 그대로 유지하세요. 연결 안내 문구를 확인한 뒤 **Create as a plugin**을 선택하세요.

</Step>

<Step title="설치하고 계정 인증">

개인 플러그인에서 EvoLink를 열고 설치/연결하세요. 인증을 요청받으면 브라우저에서 EvoLink에 로그인하고 계정과 권한을 확인한 뒤 승인하세요. 진행 중인 화면을 닫지 말고 그대로 둔 채 ChatGPT로 돌아오세요. 설정을 만드는 것과 플러그인을 설치하는 것은 별개의 단계이며, 인증 버튼은 서로 다른 단계에서 나타날 수 있습니다.

</Step>

<Step title="대화에서 활성화하고 검증">

새 대화를 시작하고 `@`로 EvoLink를 선택하세요. 화면에 Chat / Work 탭이 있다면 플러그인 대화를 시작하기 전에 **Work**로 전환하세요. 아래의 무료 검증 프롬프트를 보내세요.

**성공 표시**: 설정이 완료되었다는 말만이 아니라 실제 계정 잔액과 사용할 수 있는 모델이 나옵니다.

</Step>

</Steps>

[OpenAI 커스텀 MCP](https://developers.openai.com/api/docs/guides/custom-mcp-server)와 [플러그인 빠른 시작](https://developers.openai.com/plugins/quickstart)을 참고하세요. 개인 연결을 만들었다고 해서 EvoLink가 공개 디렉토리에 등록되어 있다는 뜻은 아닙니다.

## 무료 검증과 첫 미디어 작업

연결한 뒤 EvoLink가 활성화된 대화에서 다음을 보내세요:

```text
EvoLink로 제 계정 잔액을 확인하고 사용할 수 있는 이미지 모델을 검색해 주세요. 아직 생성하지 마세요.
```

실제 `check_balance`와 `search_models` 호출이 이루어졌는지 확인하세요. 로그인과 이 조회들은 유료 미디어 작업을 만들지 않습니다. 생성하려면 내용과 사양을 설명하고, 제안된 모델, 매개변수, 예상 비용을 검토한 뒤 제출을 명시적으로 승인하세요. [첫 미디어 작업 흐름](/ko/mcp/overview#workflows)을 참고하세요.

모델이 지원하는, 공개적으로 접근할 수 있는 참조 링크를 사용하세요. 채팅 첨부 파일은 원본 파일 데이터를 MCP에 전달하지 않을 수 있으며, 원격 서비스는 사용자 컴퓨터의 경로를 읽을 수 없습니다. [참조 파일과 업로드](/ko/mcp/overview#files)를 참고하세요.

## 자주 발생하는 문제

| 증상 | 다음 단계 |
|---|---|
| 커스텀 커넥터 추가 버튼이 없음 | 현재 호스트의 요금제, 버전, 워크스페이스 권한을 확인하세요 |
| 브라우저에서 로그인한 뒤에도 인증되지 않음 | 원래 클라이언트로 돌아가 현재 진행 중인 절차를 완료하세요. [인증 문제 해결](/ko/mcp/billing#login)을 참고하세요 |
| 연결은 추가했지만 채팅에 도구가 없음 | 설치/활성화 상태를 확인하고, EvoLink를 선택하고, 새 대화를 여세요. [MCP 문제 해결](/ko/mcp/billing#mcp-connection)을 참고하세요 |
| 잔액 조회는 되지만 생성 도구를 사용할 수 없음 | 호스트의 도구 토글과 워크스페이스 권한을 확인하세요. 키를 써서 우회하지 마세요 |
| 네트워크 시간 초과 또는 403 | 호스트, 로그인 페이지, 도구 요청 중 어디에서 실패했는지 확인하세요. 고객 지원에 전달할 수 있도록 시간과 오류를 보존하세요 |
| 결과가 링크로만 보이거나 미리보기가 회색임 | 원본을 열어 저장하세요. [다운로드와 미리보기 문제 해결](/ko/mcp/billing#download)을 참고하세요 |

## 새로 고침과 연결 해제

변경한 뒤에는 연결과 도구를 새로 고치거나 새 대화를 여세요. 필요하면 이 호스트에서 다시 인증하세요. 이 클라이언트의 접근을 중단하려면 클라이언트 설정에서 연결을 해제하거나 로그아웃하세요. 공유 키의 한도와 일시 중지는 EvoLink에서 관리하세요. [플러그인](/ko/mcp/plugins)과 [비용과 문제 해결](/ko/mcp/billing#faq)을 참고하세요.
