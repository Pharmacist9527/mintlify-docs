Claude 채팅은 **원격 MCP**를 사용합니다. 클라이언트와 브라우저에서 설정하면 되며, 로컬 CLI 설치와 개인 API Key는 필요 없습니다.

## 시작하기 전에

EvoLink 계정과 Claude 계정, 그리고 커스텀 MCP를 허용하는 클라이언트 버전, 요금제, 워크스페이스 권한이 필요합니다. 추가 버튼을 사용할 수 없다면 채팅에서 터미널 안내를 실행하지 말고 먼저 호스트의 접근 권한을 확인하세요.

## 단계별로 EvoLink 연결하기

<Steps>

<Step title="커넥터 추가 화면 열기">

[Claude에 추가](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp)를 선택하세요. 웹사이트의 버튼과 같으며 이름과 URL이 미리 채워져 있습니다. 열리지 않으면 Claude의 Connectors 설정에서 커스텀 커넥터를 추가하세요.

</Step>

<Step title="URL을 확인하고 커넥터 추가">

이름은 EvoLink로 지정하고 다음 원격 서버 URL을 사용하세요:

```text
https://mcp.evolink.ai/mcp
```

OAuth/브라우저 로그인을 사용하는 Streamable HTTP 원격 연결을 사용하세요. 문서 URL이나 REST URL을 입력하지 마세요. 저장된 목록에 EvoLink가 나타나는지 확인하세요.

</Step>

<Step title="브라우저에서 로그인하고 승인">

Connect/Authenticate를 선택하고 EvoLink에 로그인한 뒤, 계정과 권한을 확인하고 승인한 다음 Claude로 돌아오세요. 창이 열리지 않으면 현재 표시된 로그인 버튼을 사용하세요. 이전 링크가 만료되면 새로 시도하세요.

</Step>

<Step title="대화에서 활성화하고 검증">

대화의 커넥터/도구 선택 메뉴에서 EvoLink를 활성화한 뒤 아래 프롬프트를 보내세요. 커넥터를 저장하는 것만으로는 현재 채팅에서 활성화되지 않습니다.

**성공 표시**: 실제 잔액과 모델 결과가 나옵니다. Claude Code는 별개의 터미널 클라이언트이므로 [해당 설정 페이지](/ko/mcp/claude-code)를 이용하세요.

</Step>

</Steps>

커넥터 제공 여부, 요금제, 워크스페이스 제한은 [Claude 공식 가이드](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)를 참고하세요.

## 무료 검증과 첫 미디어 작업

연결한 뒤 EvoLink가 활성화된 대화에서 다음을 보내세요:

```text
EvoLink로 제 계정 잔액을 확인하고 사용할 수 있는 이미지 모델을 검색해 주세요. 아직 생성하지 마세요.
```

실제 `check_balance`와 `search_models` 호출이 이루어졌는지 확인하세요. 로그인과 이 조회들은 유료 미디어 작업을 만들지 않습니다. 생성하려면 내용과 사양을 설명하고, 제안된 모델, 매개변수, 예상 비용을 검토한 뒤 제출을 명시적으로 승인하세요. [첫 미디어 작업 흐름](/ko/mcp/overview#workflows)을 참고하세요.

모델이 지원하는, 공개적으로 접근할 수 있는 참조 링크를 사용하세요. 채팅 첨부 파일은 원본 파일 데이터를 MCP에 전달하지 않을 수 있으며, 원격 서비스는 사용자 컴퓨터의 경로를 읽을 수 없습니다. [참조 파일과 업로드](/ko/mcp/overview#files)를 참고하세요.

## 자주 발생하는 문제

| 증상 | 다음 단계 |
|---|---|
| 커스텀 커넥터 추가 버튼이 없음 | 현재 호스트의 요금제, 버전, 워크스페이스 권한을 확인하세요 |
| 브라우저에서 로그인한 뒤에도 인증되지 않음 | 원래 클라이언트로 돌아가 현재 진행 중인 절차를 완료하세요. [인증 문제 해결](/ko/mcp/billing#login)을 참고하세요 |
| 연결은 추가했지만 채팅에 도구가 없음 | 설치/활성화 상태를 확인하고, EvoLink를 선택하고, 새 대화를 여세요. [MCP 문제 해결](/ko/mcp/billing#mcp-connection)을 참고하세요 |
| 잔액 조회는 되지만 생성 도구를 사용할 수 없음 | 호스트의 도구 토글과 워크스페이스 권한을 확인하세요. 키를 써서 우회하지 마세요 |
| 네트워크 시간 초과 또는 403 | 호스트, 로그인 페이지, 도구 요청 중 어디에서 실패했는지 확인하세요. 고객 지원에 전달할 수 있도록 시간과 오류를 보존하세요 |
| 결과가 링크로만 보이거나 미리보기가 회색임 | 원본을 열어 저장하세요. [다운로드와 미리보기 문제 해결](/ko/mcp/billing#download)을 참고하세요 |

## 새로 고침과 연결 해제

변경한 뒤에는 연결과 도구를 새로 고치거나 새 대화를 여세요. 필요하면 이 호스트에서 다시 인증하세요. 이 클라이언트의 접근을 중단하려면 클라이언트 설정에서 연결을 해제하거나 로그아웃하세요. 공유 키의 한도와 일시 중지는 EvoLink에서 관리하세요. [플러그인](/ko/mcp/plugins)과 [비용과 문제 해결](/ko/mcp/billing#faq)을 참고하세요.
