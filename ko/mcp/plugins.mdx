플러그인은 원격 MCP 설정과 에이전트 안내를 하나로 묶어 제공할 수 있습니다. 호스트마다 자체 설치 방식과 인증 방식을 사용합니다.

| 진입점 | 설치되는 내용 | 미디어 실행 방식 |
|---|---|---|
| ChatGPT 커스텀 MCP 플러그인 | ChatGPT에서 만든 서버 연결 | ChatGPT가 원격 MCP를 호출합니다 |
| Codex 저장소 플러그인 | EvoLink 원격 MCP 설정과 evolink-mcp 스킬 | Codex가 원격 MCP를 호출합니다 |
| Claude Code 저장소 플러그인 | EvoLink 원격 MCP 설정과 evolink-mcp 스킬 | Claude Code가 원격 MCP를 호출합니다 |
| CLI 번들 스킬 | evolink-cli 지침과 레퍼런스 | 에이전트가 CLI를 실행하고, CLI가 API를 직접 호출합니다 |
| 독립형 evolink-mcp 스킬 | MCP 호출 안내만 포함 | MCP 설정과 인증은 여전히 필요합니다 |

## ChatGPT 커스텀 MCP 플러그인

[ChatGPT 설정](/ko/mcp/chatgpt)에 따라 커스텀 MCP 서버를 추가하세요:

```text
https://mcp.evolink.ai/mcp
```

OAuth를 선택하고 브라우저 로그인을 승인한 뒤 대화에서 EvoLink를 활성화하세요. ChatGPT는 아래의 Codex marketplace 명령을 사용하지 않으며, 로컬 npm CLI 설치도 필요 없습니다.

커스텀 연결을 만들었다고 해서 EvoLink가 공개 플러그인 디렉토리에 등록되어 있다는 뜻은 아닙니다. 연결 생성과 생성 도구 사용 가능 여부는 계정, 호스트 버전, 워크스페이스 권한에 따라 달라집니다. [OpenAI 커스텀 MCP 안내](https://developers.openai.com/api/docs/guides/custom-mcp-server)를 참고하세요.

## Codex 저장소 플러그인

사용하는 Codex 버전이 `plugin`을 지원하는지 확인하세요. 이 플러그인은 네이티브 원격 MCP를 사용하며, 웹사이트의 CLI 프롬프트는 또 다른 방법입니다. CLI 사용자는 생성을 위해 플러그인을 추가로 설치할 필요가 없습니다.

<Steps>

<Step title="소스를 추가하고 플러그인 설치">

Codex를 실행하는 컴퓨터와 사용자의 터미널에서 실행하세요:

```bash
codex plugin marketplace add Evolink-AI/mcp-plugin
codex plugin add evolink@evolink
codex plugin list --json
```

플러그인 목록에 EvoLink가 나타나는지 확인하세요. 이 플러그인은 원격 MCP 설정과 `evolink-mcp` 스킬을 제공하며, EvoLink CLI를 제공하지는 않습니다.

</Step>

<Step title="플러그인을 로드하고 인증">

플러그인을 새로 고치거나 새 Codex 대화를 열고 EvoLink 서버가 로드되었는지 확인하세요. 안내가 나오면 호스트의 브라우저 OAuth를 완료하세요. 서버가 등록되어 있고 이 명령이 지원된다면 다음을 사용하세요:

```bash
codex mcp login evolink
```

로그인과 승인이 끝날 때까지 실행 중인 상태로 둔 뒤 Codex로 돌아오세요. 수동 MCP 설정이 이미 있다면 등록 출처를 하나만 선택하세요.

</Step>

<Step title="도구와 스킬 검증">

```text
evolink-mcp를 읽었음을 확인해 준 뒤, EvoLink로 잔액과 사용할 수 있는 이미지 모델을 확인해 주세요. 아직 생성하지 마세요.
```

스킬을 읽었고 실제 `check_balance`와 `search_models` 호출이 성공했다면 성공입니다. 플러그인 목록만으로는 인증이 검증되지 않습니다.

</Step>

</Steps>

소스를 업데이트하려면 다음을 실행하고, 호스트에서 플러그인을 새로 고친 뒤 실제 버전을 확인하세요:

```bash
codex plugin marketplace upgrade evolink
```

수동 MCP 설정은 [Codex CLI 레퍼런스](https://learn.chatgpt.com/docs/cli/reference)와 [Codex 설정](/ko/mcp/codex)을 참고하세요. CLI 안내는 [별도의 CLI 가이드](/ko/cli/codex)에 있습니다.

## Claude Code 저장소 플러그인

플러그인을 지원하는 Claude Code 버전을 사용하세요. 아래 명령은 **Claude Code 대화 명령**이며, 일반 셸 명령이 아닙니다.

<Steps>

<Step title="저장소 플러그인 설치">

```text
/plugin marketplace add Evolink-AI/mcp-plugin
/plugin install evolink@evolink
```

설치가 끝날 때까지 기다린 뒤 현재 사용자/프로젝트에 EvoLink가 활성화되어 있는지 확인하세요. 다른 플러그인은 그대로 유지하세요.

</Step>

<Step title="원격 MCP 인증">

```text
/mcp
```

플러그인을 새로 고친 뒤 EvoLink를 선택하고 브라우저 인증을 완료하세요. 수동으로 등록한 연결과 중복되지 않게 하세요.

</Step>

<Step title="무료로 검증">

어시스턴트에게 `evolink-mcp`를 읽었음을 확인해 주고, 생성 없이 잔액과 모델을 실제로 조회해 달라고 요청하세요. 수동 MCP 설정은 [Claude Code 설정](/ko/mcp/claude-code)을 참고하세요. CLI 안내는 [별도의 CLI 가이드](/ko/cli/claude-code)에 있습니다.

</Step>

</Steps>

## MCP 스킬만 설치하기

네이티브 MCP가 이미 설정되어 있고 에이전트 안내만 필요하다면 다음을 실행하세요:

```bash
npx skills add Evolink-AI/mcp-plugin -g -y
```

이 명령은 skills 설치 프로그램으로 저장소의 스킬을 가져옵니다. EvoLink CLI를 설치하거나, 로컬 MCP를 시작하거나, OAuth를 완료하지는 않습니다. 호스트가 설치 위치를 인식하고 evolink-mcp를 읽는지 검증하세요.

## 플러그인이 안내하는 내용

소스는 [Evolink-AI/mcp-plugin](https://github.com/Evolink-AI/mcp-plugin)입니다. 설정은 호스팅형 원격 MCP를 가리킵니다. 스킬은 모델 탐색, 매개변수 검증, 예상 비용과 승인, 참조 파일 업로드, 생성, 작업, 실패 복구, 원본 전달을 다룹니다. EvoLink MCP 도구에 코드 개발, 임의의 파일 편집, 본격적인 영상 편집 기능을 추가하지는 않습니다.

CLI 스킬과 MCP 스킬은 미디어 정책을 공유할 수 있지만, 사용하는 명령과 도구는 서로 다릅니다. 작업 하나에는 한 가지 경로만 선택하세요. 제출 시간이 초과되어 결과를 알 수 없다면, 다른 진입점으로 다시 생성하지 말고 원래 요청이나 task_id를 복구하세요. 내용과 디렉토리는 [에이전트용 자료](/ko/cli-mcp/agent-resources#skills)를, 매개변수는 [플랫폼 레퍼런스](/ko/mcp/tools)를 참고하세요.

한도와 접근 권한 해지는 [비용과 보관 기간](/ko/mcp/billing)을 참고하세요. 플러그인 설치, 스킬 설치, OAuth 인증은 유료 생성 요청에 대한 승인이 아닙니다.

## 플러그인 설치 문제

| 증상 | 다음 단계 |
|---|---|
| plugin / marketplace 명령이 없음 | 호스트 버전과 공식 설정 안내를 확인하거나, 해당 호스트의 수동 MCP 가이드 또는 [별도의 CLI 설정](/ko/cli/setup)을 이용하세요 |
| 저장소를 가져올 수 없음 | GitHub 연결과 호스트의 소스 설정을 확인하세요. 원래 오류는 보관하세요 |
| 설치했지만 도구가 없음 | 실제 세션을 새로 고치고, 플러그인을 활성화하고, OAuth를 완료하세요 |
| 서버 또는 스킬이 중복됨 | 설정을 백업하고, 출처를 확인하고, 의도한 항목만 남기고, 다른 서비스는 그대로 유지하세요 |
| 도구는 목록에 보이지만 호출이 실패함 | 무료 잔액 조회로 인증을 검증하세요. [MCP 문제 해결](/ko/mcp/billing#mcp-connection)을 참고하세요 |

플러그인 설치는 유료 테스트에 대한 승인이 아닙니다. 인식 문제와 그 밖의 문제는 [통합 문제 해결](/ko/mcp/billing#faq)을 참고하세요.
