이 페이지는 Claude Code의 네이티브 MCP를 다룹니다. 원격 서비스는 Streamable HTTP와 브라우저 OAuth를 사용하며 EvoLink CLI가 필요 없습니다. 명령과 스킬로 실행하려면 별도의 [CLI 가이드](/ko/cli/claude-code)를 이용하세요.

## 원격 MCP 연결하기

네이티브 도구를 쓰려면 다음 서버 URL로 **Streamable HTTP + OAuth**를 사용하세요:

```text
https://mcp.evolink.ai/mcp
```

CLI를 설치할 필요는 없습니다. 기존 설정을 백업하고, EvoLink 항목만 병합하고, 다른 서비스는 그대로 유지하세요. 명령으로 등록하는 방법과 수동으로 등록하는 방법 중 하나를 선택하세요.

<Steps>

<Step title="HTTP 서버 추가">

Claude Code가 설치된 터미널에서 다음을 실행하세요:

```bash
claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp
```

`--scope user`를 지정하면 현재 사용자의 모든 프로젝트에서 이 연결을 사용할 수 있습니다. 추가에 성공했다는 것은 설정이 기록되었다는 뜻일 뿐입니다.

</Step>

<Step title="Claude Code 안에서 로그인">

Claude Code 대화에서 다음 세션 명령을 입력하고 EvoLink의 인증 항목을 선택하세요:

```text
/mcp
```

브라우저에서 로그인과 승인을 완료한 뒤 Claude Code에서 연결을 확인하세요. 이 세션 명령은 일반 셸 명령이 아닙니다.

</Step>

<Step title="도구를 확인하고 무료로 검증">

```bash
claude mcp list
```

승인 대기 중인 프로젝트 연결이 있다는 안내가 나오면 Claude Code 안에서 승인하세요. 새 세션에서 아래의 검증 프롬프트를 보내고 실제 잔액과 모델이 나오는지 확인하세요.

</Step>

</Steps>

프로젝트 단위로 설정하려면 `.mcp.json`에 병합하세요:

```json
{
  "mcpServers": {
    "evolink": {
      "type": "http",
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

이 블록을 `.claude/settings.local.json`에 넣지 마세요. 사용자 범위는 위의 명령이 관리합니다. [Claude Code 문서](https://code.claude.com/docs/en/mcp)를 참고하세요.

인증을 마친 뒤 에이전트 채팅에 다음을 보내세요:

```text
EvoLink로 제 계정 잔액을 확인하고 사용할 수 있는 이미지 모델을 검색해 주세요. 아직 생성하지 마세요.
```

**성공 표시**: 실제 `check_balance`와 `search_models` 호출이 결과를 반환합니다. 이 도구들은 실제 MCP 연결에서 검증하세요.

## 업데이트, 연결 해제, 문제 해결

원격 MCP 서버는 EvoLink가 업데이트합니다. 설정을 변경한 뒤에는 실제 클라이언트 세션을 새로 고치세요. 필요하면 해당 클라이언트의 OAuth 인증 기능으로 다시 인증하세요. 연결을 해제하려면 호스트의 MCP 설정에서 EvoLink를 비활성화하거나, 로그아웃하거나, 제거하세요. 다른 서버는 그대로 두세요.

| 증상 | 조치 |
|---|---|
| URL은 추가했지만 도구가 없음 | 연결을 활성화하고, 인증을 완료하고, 새로 고친 뒤 조직 정책을 확인하세요 |
| 401 또는 인증 필요 | 이 MCP 연결을 다시 인증하고 원래 작업 ID를 보관하세요 |
| 403 또는 도구 거부 | 호스트 권한, 계정/키 상태, 네트워크 오류를 확인하세요 |
| 시간 초과 또는 응답 유실 | 다시 생성하지 말고 원래 요청을 조회해 복구하세요 |
| 링크만 표시되거나 미리보기가 회색임 | 자동으로 다시 만들지 말고 원본을 열어 전달하세요 |

[MCP 비용, 접근 권한, 문제 해결](/ko/mcp/billing#faq)을 참고하세요. 제출하기 전에 [제작 작업 흐름](/ko/mcp/overview#workflows)을 읽어 보세요. 호출 형식은 [MCP 도구 레퍼런스](/ko/mcp/tools)에 있습니다.
