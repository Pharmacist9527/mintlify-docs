이 페이지는 Codex의 네이티브 MCP를 다룹니다. 원격 서비스는 Streamable HTTP와 브라우저 OAuth를 사용하며 EvoLink CLI가 필요 없습니다. 명령과 스킬로 실행하려면 별도의 [CLI 가이드](/ko/cli/codex)를 이용하세요.

## 원격 MCP 연결하기

네이티브 도구를 쓰려면 다음 서버 URL로 **Streamable HTTP + OAuth**를 사용하세요:

```text
https://mcp.evolink.ai/mcp
```

CLI를 설치할 필요는 없습니다. 기존 설정을 백업하고, EvoLink 항목만 병합하고, 다른 서비스는 그대로 유지하세요. 명령으로 등록하는 방법과 수동으로 등록하는 방법 중 하나를 선택하세요.

<Steps>

<Step title="원격 서버 추가">

Codex CLI가 설치된 터미널에서 다음을 실행하세요:

```bash
codex mcp add evolink --url https://mcp.evolink.ai/mcp
```

설정에 `evolink`가 들어 있어야 합니다. 추가하기 전에 기존 항목이 있는지 확인하고, 수동 등록과 플러그인 등록이 중복되지 않게 하세요.

</Step>

<Step title="MCP를 따로 인증">

```bash
codex mcp login evolink
```

브라우저에서 EvoLink에 로그인하고 승인한 뒤 완료될 때까지 기다리세요. 추가하는 과정에서 이미 인증이 완료되었다면 다시 로그인할 필요는 없습니다. `evolink auth login`으로는 이 네이티브 연결이 인증되지 않습니다.

</Step>

<Step title="연결을 확인하고 잔액 조회">

```bash
codex mcp list
```

새 Codex 세션을 열거나 `/mcp`를 사용한 뒤 아래의 무료 검증 프롬프트를 보내세요. 실제 계정 잔액과 사용할 수 있는 모델이 반환되면 성공입니다.

</Step>

</Steps>

수동으로 설정하려면 사용자의 `~/.codex/config.toml` 또는 신뢰할 수 있는 프로젝트의 `.codex/config.toml`에 이 섹션만 병합하세요:

```toml
[mcp_servers.evolink]
url = "https://mcp.evolink.ai/mcp"
```

Codex App에는 같은 URL과 OAuth를 사용하는 자체 플러그인/커스텀 MCP 연결이 있습니다. 터미널 CLI에 로그인해도 App이 자동으로 연결되지는 않습니다. [Codex 문서](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)를 참고하세요.

인증을 마친 뒤 에이전트 채팅에 다음을 보내세요:

```text
EvoLink로 제 계정 잔액을 확인하고 사용할 수 있는 이미지 모델을 검색해 주세요. 아직 생성하지 마세요.
```

**성공 표시**: 실제 `check_balance`와 `search_models` 호출이 결과를 반환합니다. 이 도구들은 실제 MCP 연결에서 검증하세요.

## 업데이트, 연결 해제, 문제 해결

원격 MCP 서버는 EvoLink가 업데이트합니다. 설정을 변경한 뒤에는 실제 클라이언트 세션을 새로 고치세요. 필요하면 해당 클라이언트의 OAuth 인증 기능으로 다시 인증하세요. 연결을 해제하려면 호스트의 MCP 설정에서 EvoLink를 비활성화하거나, 로그아웃하거나, 제거하세요. 다른 서버는 그대로 두세요.

| 증상 | 조치 |
|---|---|
| URL은 추가했지만 도구가 없음 | 연결을 활성화하고, 인증을 완료하고, 새로 고친 뒤 조직 정책을 확인하세요 |
| 401 또는 인증 필요 | 이 MCP 연결을 다시 인증하고 원래 작업 ID를 보관하세요 |
| 403 또는 도구 거부 | 호스트 권한, 계정/키 상태, 네트워크 오류를 확인하세요 |
| 시간 초과 또는 응답 유실 | 다시 생성하지 말고 원래 요청을 조회해 복구하세요 |
| 링크만 표시되거나 미리보기가 회색임 | 자동으로 다시 만들지 말고 원본을 열어 전달하세요 |

[MCP 비용, 접근 권한, 문제 해결](/ko/mcp/billing#faq)을 참고하세요. 제출하기 전에 [제작 작업 흐름](/ko/mcp/overview#workflows)을 읽어 보세요. 호출 형식은 [MCP 도구 레퍼런스](/ko/mcp/tools)에 있습니다.
