## 이 워크플로가 하는 일

어시스턴트에게 짧은 참조 광고와 내 제품, 그리고 크리에이터가 있다면 크리에이터까지 제공하세요. 어시스턴트는 참조 광고를 분석하고, 내 제품에 맞춰 같은 구조로 계획을 세우고, 키프레임 이미지를 준비한 뒤, 사운드가 포함된 광고 전체를 영상 작업 하나로 생성합니다. 그런 다음 계획과 대조해 검사하고 결과를 전달합니다.

어시스턴트는 로그인 후 EvoLink가 보내 주는 단계별 규칙을 따릅니다. 따라서 긴 프롬프트를 작성할 필요가 없습니다. 요금이 부과되기 전에 예상 합계 하나만 확인하면 됩니다.

<span id="requirements" />
## 시작하기 전에

| 필요한 것 | 설명 |
|---|---|
| EvoLink 로그인 | [EvoLink 플러그인 또는 원격 MCP](/ko/mcp/overview)로 연결하거나, [EvoLink CLI](/ko/cli/setup)를 설치하고 로그인하세요. 이 워크플로는 로그인한 연결에만 제공되며, API Key만으로는 사용할 수 없습니다 |
| 프레임을 다룰 수 있는 어시스턴트 | 명령을 실행할 수 있는 어시스턴트(예: Claude Code, Codex, Cursor)는 자신이 실행되는 컴퓨터에서 ffmpeg과 ffprobe로 영상의 프레임을 추출합니다. 브라우저의 채팅처럼 터미널이 없는 어시스턴트는 같은 작업을 `make_frames`로 합니다. 이는 원격 MCP가 로그인한 연결에 제공하는 무료 도구입니다 |
| 충분한 잔액 | 예상 비용 결과는 잔액으로 이번 실행을 충당할 수 있는지, 그리고 EvoLink MCP 지출 한도를 설정해 두었다면 그 한도 안에서 가능한지 알려 줍니다 |

<Note>
터미널도 `make_frames` 도구도 없는 어시스턴트는 이 워크플로의 프레임 처리를 할 수 없습니다. 이런 어시스턴트는 요금이 부과되기 전에 그 사실을 알려 줍니다.
</Note>

<span id="inputs" />
## 제공할 자료

| 입력 | 설명 |
|---|---|
| 참조 영상 | MP4 또는 MOV, **30초 이하**. 더 길면 어시스턴트가 어느 부분을 사용할지 묻습니다 |
| 제품 | 제품 사진 한 장 이상, 제품이 하는 일을 한 줄로 설명한 문장, 그리고 사실이라고 확인해 줄 수 있는 제품 관련 주장. 참조 광고에 나온 주장은 내 제품에도 해당한다고 확인해 주지 않는 한 옮겨 오지 않습니다 |
| 크리에이터(선택 사항) | 크리에이터의 사진. 크리에이터가 없으면, 광고에 인물이 필요할 때 어시스턴트가 가상의 성인 인물을 만듭니다. 참조 광고에 나온 인물을 복제하지는 않습니다 |
| 옵션 | 언어, 인물이 직접 말하는 대사 또는 보이스오버, 음악, 길이(4–30초), 화면 비율, 그리고 해상도: 480p, 720p, 1080p 또는 4K, 또는 먼저 480p 드래프트. 빠진 항목은 어시스턴트가 메시지 하나로 묻고 기본값을 제안합니다. 해상도를 정하지 않으면 720p로 예상 비용을 산정하고, 다른 옵션을 합계와 함께 보여 줍니다. 어시스턴트가 선택 버튼을 보여 줄 수 있으면 버튼으로 묻지만, 언제든 직접 답을 입력할 수 있습니다 |

직접 소유하고 있거나 사용 허가를 받은 자료를 사용하세요. 이 워크플로는 참조 광고의 구조(훅, 장면별 전개, 동작, 카메라 리듬)는 유지하고, 인물, 제품, 공간, 문구, 주장은 바꿉니다.

<span id="cost" />
## 예상 합계 하나, 확인은 한 번

확인을 받기 전까지 어시스턴트는 요금이 들지 않는 일만 합니다. 로그인 상태와 잔액을 점검하고, 참조 영상의 길이와 화면 비율을 읽고, 샷 수를 세고, 예상 비용을 산정합니다. 그런 다음 아래 예시처럼 합계 하나를 보여 줍니다:

```text
예상 합계: 약 $3.67(249.4 크레딧), 사운드가 포함된 720p 10초 광고 기준.
포함 항목: 참조 영상 분석, 이 광고에 쓸 이미지, 영상, 최종 검사.
다른 옵션: 480p, 1080p 또는 4K, 또는 먼저 480p 드래프트를 만들고 나중에 1080p나 4K로 변환하는 방법
(변환할 때마다 가격을 따로 알려 드리고 따로 확인을 받습니다). 하나를 고르시면 그 합계를 알려 드리겠습니다.
요금은 각 단계가 실행될 때 부과됩니다. 중간에 멈추셔도 그 전에 끝난 단계의 요금은 그대로 남습니다.
실패한 생성에는 요금이 부과되지 않으며, 각각 최대 두 번까지 재시도하겠습니다.
720p로 진행하시려면 "확인"이라고 답해 주세요. 작업 비용이 이 합계를 넘게 되면 먼저 여쭤보겠습니다.
```

- **합계가 곧 예산입니다**. 확인을 받은 뒤에는 어시스턴트가 단계마다 요금을 묻지 않습니다. 진행 중에 합계를 넘게 될 때에만 다시 물어봅니다.
- **다른 옵션의 예상 비용도 무료로 산정합니다**. 다른 해상도나 드래프트를 고르면 어시스턴트가 대신 그 합계를 보여 주며, 확인은 여전히 한 번입니다.
- **포함되는 항목**: 참조 영상 분석, 필요한 경우 크리에이터 이미지, 키프레임 이미지와 그중 일부를 수정하는 데 필요한 여유분, 사운드가 포함된 영상 하나, 최종 검사.
- **포함되지 않는 항목**: 가격을 따로 알리고 따로 확인을 받는 드래프트 변환, 그리고 영상 하나가 완성된 뒤에 전체 영상을 하나 더 만드는 것. 완성된 광고가 계획에 맞지 않으면 어시스턴트는 무엇이 어긋났는지, 새로 시도하면 비용이 얼마인지 설명하고 결정을 기다립니다.
- **잔액이 부족하면** 예상 비용 결과가 얼마나 부족한지 알려 주고 충전 페이지 링크를 제공합니다. 아무것도 시작되지 않습니다.
- 가격은 예상 비용을 산정한 시점에 계정에 적용되는 가격이며, 이를 읽을 수 없으면 공개 기본 가격을 사용하고 예상 비용에 그 사실이 표시됩니다. 요금은 실제 사용량에 따라 부과됩니다. 예상 비용은 24시간 동안 유효합니다.

전달할 때 어시스턴트는 실제로 부과된 요금을 예상 비용과 함께 알려 줍니다. 자세한 내용이 필요하면 작업별 내역을 요청하세요. 부과된 요금은 모두 [콘솔](https://evolink.ai/dashboard)의 기록에 모델, 비용과 함께 표시됩니다. 이미지와 영상은 생성 작업으로, 영상 분석은 건마다 Gemini 모델 호출로 표시됩니다. 어시스턴트가 사용하는 것과 같은 EvoLink 계정으로 로그인해 확인하세요.

<span id="steps" />
## 어시스턴트가 하는 일

| 단계 | 진행 내용 | 과금 여부 |
|---|---|---|
| 0. 점검 및 예상 비용 산정 | 참조 영상의 길이와 화면 비율, 샷 수, 예상 합계. 확인은 한 번만 하면 됩니다 | 아니요 |
| 1. 참조 영상 읽기 | 참조 영상을 업로드하고, 샷과 사운드를 분석하고, 그 결과를 추출한 프레임과 비교합니다 | 예 |
| 2. 목표 작성 | 샷별로 무엇을 바꾸고 무엇을 유지할지 정리합니다: 인물, 제품, 공간, 동작, 대사, 음악 | 아니요 |
| 3. 광고 전체 계획 | 타임라인, 필요한 키프레임 이미지, 단일 영상 작업 | 아니요 |
| 4. 키프레임 이미지 제작 | 필요한 경우 크리에이터 참조 이미지를 만든 다음, 각 샷의 첫 프레임과 그 사이의 중간 상태를 만듭니다. 각 이미지는 다음 단계로 넘어가기 전에 검사합니다 | 예 |
| 5. 영상 요청 구성 | 모든 키프레임 이미지, 그리고 화면과 사운드를 빠짐없이 담은 설명 하나 | 아니요 |
| 6. 생성 및 검사 | 대사나 보이스오버, 음악, 효과음이 포함된 광고 전체를 영상 작업 하나로 생성합니다. 결과물은 목표와 대조해 분석합니다 | 예 |
| 7. 전달 | 원본 영상, 키프레임 이미지를 한데 모은 시트, 짧은 검사 요약, 중요한 미해결 문제, 그리고 비용(예상 비용과 실제 부과 요금). 샷별 판정은 요청하면 받을 수 있습니다 | 아니요 |

확인을 받으면 어시스턴트는 전달까지 이어서 진행합니다. 진행 중에 합계를 넘게 될 때, 직접 결정해야만 하는 사항이 있을 때(예: 내 제품으로는 할 수 없는 동작), 완성된 광고를 새로 시도해야 할 때, 또는 드래프트를 선택했다면 드래프트가 준비되어 변환할지 정해야 할 때에만 멈춥니다. 영상을 만들기 전에 키프레임 이미지를 보고 싶다면 확인할 때 그렇게 말해 주세요.

<span id="draft" />
## 먼저 드래프트로

드래프트를 선택하면 광고 전체를 480p로 한 번 생성하고 480p 가격으로 요금이 부과됩니다. 따라서 예상 합계에는 드래프트만 포함됩니다. 어시스턴트는 드래프트를 완성된 광고와 똑같이 검사하고 같은 방식으로 전달합니다.

그런 다음 드래프트를 1080p나 4K로 변환할지, 그대로 둘지 묻습니다. 변환은 매번 새 작업입니다. 어시스턴트가 가격을 알려 주고 확인을 기다리며, 변환 요금은 확인한 합계와 별도로 부과됩니다. 같은 드래프트를 여러 번 변환할 수 있습니다. 예를 들어 먼저 1080p로, 나중에 4K로 변환할 수 있으며, 변환할 때마다 요금이 부과됩니다.

드래프트는 기한 전까지 변환할 수 있습니다. 정확한 기한은 어시스턴트가 알려 주며, 작업을 조회하면 `draft_expires_at`으로 반환됩니다.

<span id="start" />
## 재구성 시작하기

1. 어시스턴트에 EvoLink를 연결하세요. [EvoLink 플러그인](/ko/mcp/plugins)을 설치하거나, 원격 MCP([Claude Code](/ko/mcp/claude-code), [Codex](/ko/mcp/codex), [Cursor](/ko/mcp/cursor))를 추가하거나, [EvoLink CLI](/ko/cli/setup)를 설정하세요.
2. 참조 영상과 제품 사진을 어시스턴트가 읽을 수 있는 위치에 두세요.
3. 평소 쓰는 말로 요청하세요. 예를 들면 다음과 같습니다:

```text
이 광고를 제 제품으로 재구성해 주세요. 참조 영상: ./reference.mp4. 제품: ./product.png, 로즈 워터 페이스 미스트이며 고운 안개처럼 분사됩니다. 영어, 10초, 720p, 세로형.
```

어시스턴트는 워크플로 규칙을 가져오고, 무료 점검을 마친 뒤 예상 합계를 제시합니다.

<span id="limits" />
## 제한 사항과 알아 둘 점

- **길이**: 참조 영상과 완성된 광고는 각각 최대 30초입니다.
- **영상 작업 하나**: 광고 전체를 사운드와 함께 한 번에 생성합니다. 이 워크플로는 샷을 따로 렌더링하거나, 나중에 더빙하거나, 결과물을 편집하지 않습니다.
- **타이밍은 대략적입니다**. 영상 모델은 계획한 컷 전환 시점을 참고 사항으로 취급합니다. 컷 전환과 동작은 약 1초 빠르거나 늦게 나올 수 있으며, 어디가 그런지는 전달 전 검사에서 알려 줍니다.
- **화면 속 글자와 라벨**은 결과물에서 검사하지만, 그래도 왜곡될 수 있습니다.
- **콘텐츠 심사**: 모델이 자료를 거부하면 어시스턴트가 이를 알리고 다른 자료를 요청합니다. 심사를 통과하려고 요청의 표현을 바꾸지는 않습니다.
- **횟수 제한**: 한 계정이 분당, 그리고 하루에 시작할 수 있는 영상 분석 횟수에는 제한이 있습니다. 얼마나 기다려야 하는지는 메시지에 나옵니다.
- **재생**: 1080p와 4K 영상은 10비트 HEVC 파일입니다. 일부 플레이어에서는 열리지 않지만, VLC와 QuickTime에서는 재생됩니다.

<span id="recovery" />
## 중간에 중단된 경우

완료된 단계는 완료된 상태로 유지됩니다. 나중에 문제가 생겨도 참조 영상을 다시 읽거나 검사를 통과한 이미지를 다시 생성해야 하는 일은 없습니다.

| 상황 | 어시스턴트의 대응 |
|---|---|
| 영상 분석 도중 연결이 끊김 | 완전히 같은 요청을 다시 보냅니다. 이미 실행 중이던 분석의 결과가 반환되며, 요금은 한 번만 부과됩니다 |
| 서비스가 혼잡함 | 메시지에 나온 시간만큼 기다렸다가 같은 단계를 다시 시도합니다. 최대 두 번까지 더 시도한 뒤 알려 줍니다 |
| 생성 작업이 실패함 | 이 작업에는 요금이 부과되지 않았습니다. 어시스턴트는 위의 재시도 횟수 안에서 같은 입력으로 재시도합니다 |
| 잔액 또는 지출 한도가 부족함 | 다음 요금이 부과되기 전에 멈추고, 무엇이 완료되었고 무엇이 남았는지 알려 준 다음, 충전하거나 한도를 높이면 이어서 진행합니다 |
| 업로드한 파일 또는 결과 링크가 만료됨 | 보통 업로드한 파일은 72시간, 결과 링크는 24시간 동안 보관됩니다. 어시스턴트가 로컬 사본으로 다시 업로드합니다 |

<span id="reference" />
## 도구와 명령

어시스턴트가 알아서 사용하므로 직접 호출할 필요는 없습니다.

| 원격 MCP 도구 | CLI 명령 | 용도 | 과금 여부 |
|---|---|---|---|
| get_media_workflow | `evolink workflow rules ad-rebuild` | 현재 단계의 규칙과 실행 ID | 아니요 |
| 예상 비용을 요청하는 get_media_workflow | `evolink workflow estimate ad-rebuild --seconds 10 --keyframes 5` | 계획한 실행에 대한 예상 합계 하나 | 아니요 |
| analyze_video | `evolink video analyze FILE_URL_OR_TASK_ID --run RUN_ID --step STEP --purpose PURPOSE` | 워크플로의 한 단계를 위한 영상 분석 | 예, 토큰 기준 |
| get_video_analysis | `evolink video analysis ANALYSIS_ID` | 아직 실행 중이던 분석 결과 수집 | 아니요 |
| generate_workflow_media | `evolink estimate --model MODEL --input-file FILE --run RUN_ID --step STEP`, 그다음 `evolink generate image\|video\|audio --quote ID --confirm` | 이 실행의 유료 생성. 실행과 함께 기록됩니다 | 예, 모델 가격 기준 |
| record_workflow_delivery | `evolink workflow deliver TASK_ID --run RUN_ID` | 완성된 영상 중 어느 것이 전달되었는지 기록 | 아니요 |
| make_frames | CLI에는 없음: 어시스턴트가 자신의 컴퓨터에서 ffmpeg을 사용 | 터미널이 없는 어시스턴트를 위한 프레임 추출, 잘라내기, 프레임 시트, 번호가 붙은 이미지 보드 | 아니요 |

생성을 그 실행과 함께 남기는 기록은 나중에 그 생성을 찾는 데 도움이 되며, 가격도 결과도 바꾸지 않습니다. 업로드, 단일 생성의 예상 비용 산정, 생성, 작업 조회에는 평소와 같은 [MCP 도구](/ko/mcp/tools)와 [CLI 명령](/ko/cli/reference)을 사용합니다. 예상 비용과 실제로 부과되는 요금의 관계는 [모델, 비용, 할당량](/ko/cli-mcp/models-and-billing)을 참고하세요.
