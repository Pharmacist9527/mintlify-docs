에이전트에서 EvoLink를 사용해 이미지, 영상, 음악, 음성을 생성하고, 모델과 비용을 찾아보고, 참조 파일을 업로드하고, 작업을 추적하고, 원본을 저장하세요. 연결 방식을 선택한 뒤 해당 방식의 설치 및 무료 검증 가이드를 따르세요.

## 연결 방식 선택

| 작업 환경 | 권장 경로 | 설치와 인증 |
|---|---|---|
| Claude 채팅 또는 ChatGPT | [원격 MCP](/ko/mcp/overview) | 연결을 추가하고 브라우저 OAuth로 인증합니다. CLI 설치는 필요 없습니다 |
| 터미널 실행이 가능한 Codex, Claude Code, Cursor, OpenClaw 또는 Hermes | [CLI](/ko/cli/setup) | CLI를 설치하고 로그인한 뒤 스킬을 설치/로드합니다 |
| 터미널, SSH 또는 스크립트 | [CLI](/ko/cli/setup) | 실행 환경에 설치합니다. SSH에는 별도의 콜백 단계가 있습니다 |
| 네이티브 MCP 도구를 사용하는 터미널 에이전트 | [MCP 클라이언트 가이드](/ko/mcp/overview#choose-your-assistant) | 호스트 연결을 직접 설정하고 인증합니다 |
| 로컬 stdio만 지원하는 클라이언트 | [로컬 MCP](/ko/mcp/other-clients#local-mcp) | 로컬 프로세스, Node.js, 개인 API Key를 설정합니다 |

Codex CLI는 에이전트 클라이언트이고, EvoLink CLI는 그 클라이언트가 호출하는 미디어 도구입니다. 둘은 서로 다른 제품입니다. 각 카드는 경로 하나를 권장하며, CLI 클라이언트 가이드에는 대안인 네이티브 MCP로 가는 링크도 있습니다.

## 생성 전에 검증하기

<Steps>
  <Step title="선택한 경로를 설치하고 인증하기">
    다섯 단계로 된 [CLI 설치](/ko/cli/setup) 또는 사용하는 클라이언트의 [MCP 클라이언트 가이드](/ko/mcp/overview#choose-your-assistant)를 따르세요. 브라우저 로그인은 직접 완료하세요. 키와 토큰은 채팅에 입력하지 마세요.
  </Step>
  <Step title="잔액과 모델을 조회하고 스킬 또는 도구 검증하기">
    CLI 사용자는 잔액을 조회하고 doctor를 실행한 뒤, 에이전트에게 스킬을 인식했는지 확인해 달라고 요청합니다. MCP 사용자는 check_balance와 search_models를 실제로 호출합니다. 파일이 설치되어 있거나 도구 목록이 보인다고 해서 실행에 성공했다는 뜻은 아닙니다. 이 확인 과정에서는 유료 미디어 작업을 제출하지 않습니다.
  </Step>
  <Step title="생성을 승인하기 전에 계획과 예상 비용 검토하기">
    정확한 모델과 입력을 확인하고 참조 파일을 준비한 뒤 계획과 예상 비용을 검토하세요. 명시적으로 승인한 뒤 한 번만 제출하고, 작업 ID를 보관하고, 원본을 저장하세요. [CLI 작업 흐름](/ko/cli/workflows) 또는 [MCP 작업 흐름](/ko/mcp/overview#workflows)을 참고하세요.
  </Step>
</Steps>

## 경로 간의 관계

CLI 미디어 요청은 `에이전트 / 터미널 → CLI → 플랫폼 API` 순서로 전달됩니다. 네이티브 MCP는 `에이전트 → 원격 또는 로컬 MCP → 플랫폼 API` 순서를 따릅니다. CLI의 미디어 실행은 원격 MCP에 의존하지 않습니다. 로그인에는 Passport를 사용하며, 업로드와 원본 다운로드에는 별도의 파일 엔드포인트가 있습니다.

설치, 세션, 연결 확인은 서로 별개입니다. 현재 같은 계정의 OAuth는 내부 키의 권한과 할당량을 공유할 수 있습니다. 하나의 작업에는 한 가지 경로만 사용하세요. 결과를 알 수 없는 제출은 다른 경로로 다시 생성하지 말고 원래 경로에서 복구하세요.

| 다음에 읽을 내용 | 레퍼런스 |
|---|---|
| CLI 명령, 옵션, JSON, API 매핑 | [CLI 레퍼런스](/ko/cli/reference) |
| MCP 도구, 입력, 결과, 복구 | [MCP 레퍼런스](/ko/mcp/tools) |
| 모델 선택, 예상 비용, 예산, 접근 권한 | [모델, 비용, 할당량](/ko/cli-mcp/models-and-billing) |
| 작업 상태, 업로드, 다운로드, 만료 | [작업, 참조 파일, 결과](/ko/cli-mcp/tasks-and-files) |
| 스킬, 플러그인, Markdown, llms.txt | [에이전트용 자료](/ko/cli-mcp/agent-resources) |
| 설치 또는 연결 실패 | [CLI 문제 해결](/ko/cli/billing#faq) / [MCP 문제 해결](/ko/mcp/billing#faq) |

이 가이드는 정식 출시된 CLI 0.14.1과 MCP 1.12.1을 기준으로 합니다. 개발 중인 후보 버전은 출시 검수를 통과한 뒤에 문서화됩니다. 현재 제공되는 도구와 계정에서 사용할 수 있는 모델은 연결된 서비스에서 조회하세요.
