이 페이지는 사용자와 에이전트를 위한 도구, 스킬, 문서를 설명합니다. 안내문을 읽는 것만으로는 충분하지 않으며, 실제 설정과 인증, 무료 연결 검증을 거쳐야 합니다.

<span id="skills" />
## 구성 요소별 역할

| 구성 요소 | 용도 | 다음 단계 |
|---|---|---|
| EvoLink CLI | 터미널에서 플랫폼 동작을 실행합니다. 미디어 호출은 API로 직접 전달됩니다 | [설치, 로그인, 검증](/ko/cli/setup) |
| 원격 MCP | HTTP를 통해 호스트에 도구를 제공하며, 로그인에는 OAuth를 사용합니다 | [클라이언트 선택](/ko/mcp/overview#choose-your-assistant) |
| 로컬 MCP | 로컬 stdio 프로세스에서 도구를 실행합니다 | [실행 방식과 플랫폼 키 설정](/ko/mcp/other-clients#local-mcp) |
| 스킬 | 탐색, 승인, 복구, 전달 과정을 안내합니다 | 호스트가 인식하는 위치에 설치하고 로드되었는지 확인합니다 |
| 플러그인 | 호스트별 설정과 스킬을 묶어 제공합니다 | [플러그인 설치 단계](/ko/mcp/plugins)를 따르고 인증과 권한도 확인합니다 |
| Markdown/llms.txt | 읽을 수 있는 안내문 또는 문서 색인입니다 | 링크된 페이지를 읽습니다. 이 자료가 도구를 실행하지는 않습니다 |

CLI를 설치해도 MCP/플러그인 저장소가 복제되거나 네이티브 MCP가 등록되지는 않습니다. CLI에는 evolink-cli가 번들로 포함되어 있고, MCP 플러그인 저장소는 evolink-mcp 도구 안내를 제공합니다. 둘은 따로 관리되는 진입점이며, 이미 하나로 통합된 스킬 소스가 아닙니다.

## 스킬에 담긴 내용

현재 스킬은 모델/매개변수, 이미지/영상/오디오 작업 흐름, 참조 파일, 예상 비용/승인, 예산 확인, 원래 제출의 복구, 대기, 다운로드, 원본 전달을 다룹니다. CLI에는 SKILL.md와 세 가지 레퍼런스인 capabilities, media-workflows, usage-and-budget이 포함되어 있습니다. 설치 대상, 디렉토리, 로드, 업그레이드는 [CLI 스킬](/ko/cli/skills)을, 호스트 설정은 [MCP 플러그인](/ko/mcp/plugins)을 참고하세요.

바이럴 광고, UGC 완성본, 자동 편집, 프리셋을 위한 별도의 스킬 라이브러리는 없습니다. 예시가 인기를 보장하지는 않습니다. 코드 개발, 임의의 파일 편집, 웹사이트 제작은 EvoLink 도구가 아니라 호스트의 기능입니다.

## 에이전트 공통 지침

```text
이번 작업에 EvoLink CLI와 네이티브 MCP 중 무엇을 쓸지 정하고 실제 연결을 검증하세요.
계정에서 사용할 수 있는 모델과 실제 스키마를 조회하고, 작업, 참조 파일, 품질, 예산을 기준으로 선택 이유를 설명하세요.
최종 사양과 예상 비용을 보여 준 뒤, 명시적인 승인을 받고 한 번만 제출하세요.
결과를 알 수 없으면 원래 경로, 원래 신원, 원래 요청 ID로 복구하세요.
원래 task_id를 조회하고 원본, 보고된 실제 비용, 만료 시점을 전달하세요.
지원하지 않는 기능은 그렇다고 설명하고, 모델, 입력, 도구, 가격, 환불을 지어내지 마세요.
예상 비용 단계에서 정한 예산을 최종 청구액에 대한 보장처럼 설명하지 말고, 결과를 자동으로 편집하거나 다시 생성하지 마세요.
```

작업 하나는 한 가지 경로에 묶어 두세요. CLI는 명령과 로컬 견적을 사용하고, MCP는 도구와 원래 client_request_id를 사용합니다. 해당 경로의 레퍼런스를 참고하세요. 스킬 파일이 설치되어 있다고 해서 호스트가 로드했다는 뜻은 아니며, 스킬을 읽는다고 도구가 설정되거나 실행 권한이 부여되지도 않습니다. 스킬 인식 여부를 시험하려고 생성을 반복하지 마세요.

## Markdown과 llms.txt 활용하기

1. [개요](/ko/cli-mcp/overview)를 읽고 클라이언트/경로를 선택하세요.
2. 해당 경로의 설정, 명령/도구 레퍼런스, 공통 규칙을 읽으세요. 현재 모델 스키마는 실행할 때 조회하세요.
3. 지원되는 페이지 복사 또는 Markdown 내보내기 기능으로 에이전트용 .md 파일을 저장하세요. 키, 토큰, 비공개 인증 링크는 파일에 넣지 마세요.
4. [llms.txt](https://docs.evolink.ai/llms.txt)는 문서 색인입니다. MCP 엔드포인트, CLI 설치 프로그램, 인증 API가 아닙니다.

| 자료 | 용도 |
|---|---|
| [CLI 레퍼런스](/ko/cli/reference) / [MCP 레퍼런스](/ko/mcp/tools) | 정확한 동작, 입력, 결과, 복구 |
| [모델, 비용, 할당량](/ko/cli-mcp/models-and-billing) | 모델 선택, 예상 비용, 승인, 예산의 적용 범위 |
| [작업, 참조 파일, 결과](/ko/cli-mcp/tasks-and-files) | 업로드, 만료, 복구, 다운로드, 회색 미리보기 |
| [CLI 스킬](/ko/cli/skills) / [MCP 플러그인](/ko/mcp/plugins) | 설치, 인식, 개인 수정 사항, 업그레이드 |

## 업데이트 후 검증하기

CLI를 업그레이드한 뒤에는 번들 스킬을 동기화하고 호스트에서 다시 로드하세요. 플러그인이나 수동 MCP 설정을 변경한 뒤에는 현재 연결, OAuth, 권한을 확인하세요. 다른 서비스와 개인 수정 사항은 그대로 유지하세요. 패키지, 문서, 도구의 버전은 서로 다를 수 있습니다. 내용이 충돌하면 실제 출시 버전과 반환된 스키마를 기준으로 판단하고, 불확실한 점은 설명하세요.
