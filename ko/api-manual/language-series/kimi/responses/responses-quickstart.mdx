<Note>
**BaseURL**: 기본 BaseURL은 `https://direct.evolink.ai`이며 텍스트 모델과 장시간 연결을 더 잘 지원합니다. `https://api.evolink.ai`는 멀티모달 서비스의 기본 엔드포인트이자 텍스트 모델의 대체 주소입니다.
</Note>

`POST /v1/responses`를 사용하고 `model`로 `kimi-k3.1-pro`, `kimi-k3.1-pro-highspeed`, `kimi-k3`를 선택합니다. `model`과 `input`만 필요합니다.

<Warning>
**매개변수 이름은 Chat Completions와 다릅니다**. 입력은 `input`, 출력 한도는 `max_output_tokens`, 추론 강도는 `reasoning.effort`를 사용합니다.
</Warning>

## 답변 본문 읽기

응답의 `output`에는 추론, 본문, 도구 호출이 함께 포함될 수 있습니다. `type="message"` 항목의 `output_text` 콘텐츠 블록을 순회하세요. 첫 항목이 본문이라고 가정하지 마세요.

응답 JSON을 `response`로 파싱했다면 다음과 같이 텍스트를 추출할 수 있습니다.

```python
text = "".join(
    part["text"]
    for item in response.get("output", [])
    if item.get("type") == "message"
    for part in item.get("content", [])
    if part.get("type") == "output_text"
)
print(text)
```

<Note>
**추론을 위한 출력 예산을 확보하세요**. `max_output_tokens`는 추론과 본문을 모두 포함합니다. `status="incomplete"`이고 `incomplete_details.reason="max_output_tokens"`라면 한도를 높이세요. 예산이 소진되면 추론 항목만 있고 본문은 없을 수 있습니다.
</Note>

도구 호출, 웹 검색, 이미지 입력, 구조화된 출력은 [전체 참조](/ko/api-manual/language-series/kimi/responses/responses-reference)를 확인하세요.
