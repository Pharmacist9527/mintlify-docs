<Note>
**BaseURL**: 기본 BaseURL은 `https://direct.evolink.ai`이며 텍스트 모델과 장시간 연결을 더 잘 지원합니다. `https://api.evolink.ai`는 멀티모달 서비스의 기본 엔드포인트이자 텍스트 모델의 대체 주소입니다.
</Note>

<Note>
**Kimi 모델은 추론이 항상 활성화**되며 `reasoning_content`로 반환됩니다. 추론 토큰은 출력에 포함됩니다. `max_completion_tokens`를 너무 작게 설정하면 추론 중 출력 예산을 모두 사용하여 응답 본문이 없을 수 있습니다.
</Note>
