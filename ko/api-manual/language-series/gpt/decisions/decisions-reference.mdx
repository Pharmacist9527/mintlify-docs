<Note>
**BaseURL**: 기본 BaseURL은 `https://direct.evolink.ai`이며, 텍스트 모델 지원이 더 우수하고 장시간 연결을 지원합니다. `https://api.evolink.ai`는 멀티모달 서비스의 주력 엔드포인트이며, 텍스트 모델에 대해서는 대체 주소로 사용됩니다.
</Note>

<Note>
**이 모델 ID는 이 엔드포인트 전용입니다**: `gpt-6-luna-decisions`는 `/v1/decisions`에서만 사용할 수 있습니다. Chat Completions, Responses 등 다른 엔드포인트에서 사용하면 `400 model_endpoint_mismatch`을 반환합니다. 대화나 텍스트 생성에는 `gpt-6-luna`를 [Chat Completions](/ko/api-manual/language-series/gpt/chat-completions/chat-completions-reference) 또는 [Responses API](/ko/api-manual/language-series/gpt/responses/responses-reference)에서 사용하세요.
</Note>

<Note>
**세 가지 질문 유형을 선택하는 방법**

| 유형 | 적합한 질문 | 반환값 사용 방법 |
|---|---|---|
| `predicate` | 예/아니요 질문. 예: 불만 메시지인지, 이미지에 파손이 있는지 | `probability`는 “예”의 확률입니다. 자체 임계값을 정하고 이를 초과하면 해당 조건에 맞는 것으로 판단합니다 |
| `choice` | 서로 겹치지 않는 범주 중 하나 선택. 예: 문의를 배정할 부서 | `choice`는 선택된 항목입니다. `confidence`가 낮으면 사람이 검토하는 것이 좋습니다 |
| `score` | 낮은 순서부터 높은 순서의 등급으로 평가. 예: 문제의 심각도 | `score`는 확률 가중 등급 점수(등급 번호는 0부터 시작)이며 소수일 수 있습니다 |

하나의 요청에 여러 독립적인 질문을 넣을 수 있으며 같은 `input`을 공유합니다. 뒤의 질문이 앞의 답변에 의존하면 두 번의 요청으로 나누세요.
</Note>

<Note>
**Chat Completions / Responses와의 차이**: 이 엔드포인트는 `model`, `input`, `questions`, `safety_identifier` 네 필드만 허용합니다. 다른 필드를 추가하면 `400 unknown_parameter`을 반환합니다. 이미지는 base64 데이터 URL만 허용하며 스트리밍은 지원하지 않습니다.
</Note>
