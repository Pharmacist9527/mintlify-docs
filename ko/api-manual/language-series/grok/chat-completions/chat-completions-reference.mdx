<Note>
**BaseURL**: 기본 BaseURL은 `https://direct.evolink.ai`이며, 텍스트 모델 지원이 더 우수하고 장시간 연결을 지원합니다. `https://api.evolink.ai`는 멀티모달 서비스의 주력 엔드포인트이며, 텍스트 모델에 대해서는 대체 주소로 사용됩니다.
</Note>

<Note>
이 페이지는 일반 `function` 호출을 설명합니다. **서버 측 도구**(웹 검색, X 검색, 코드 실행, 첨부 파일 검색, 컬렉션 검색)는 도구 설정과 과금을 설명하는 [Responses API](../responses/responses-reference)를 권장합니다.
</Note>

### Grok 4.7 사용 방법

`model`을 `grok-4.7`로 설정하고 기존 `messages` 요청 형식을 유지하세요. 컨텍스트 윈도우는 500,000 토큰이며 지식 기준은 2026년 5월입니다.

최상위 `reasoning_effort` 매개변수를 사용하세요. 추론 깊이: `low` / `medium` / `high`(기본값) / `xhigh`. 추론은 끌 수 없습니다. `grok-4.7`과 `grok-4.6`은 `xhigh`를 지원하며, `grok-4.5`는 이 값을 받지만 `high`로 처리합니다. 추론 토큰은 출력 토큰으로 과금됩니다.

`prompt_cache_key`는 동일한 프롬프트 접두사를 공유하는 요청에 안정적인 캐시 라우팅 힌트를 제공하지만 캐시 적중을 보장하지 않습니다. 실제 적중량은 `usage.prompt_tokens_details.cached_tokens`를 확인하세요. 여러 대화 턴에서 암호화된 추론을 유지하려면 [Responses API](../responses/responses-reference)를 사용하세요.
