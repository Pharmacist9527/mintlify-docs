<Note>
**BaseURL**: 기본 BaseURL은 `https://direct.evolink.ai`이며, 텍스트 모델 지원이 더 우수하고 장시간 연결을 지원합니다. `https://api.evolink.ai`는 멀티모달 서비스의 주력 엔드포인트이며, 텍스트 모델에 대해서는 대체 주소로 사용됩니다.
</Note>

<Note>
**명시적 컨텍스트 캐싱**: 반복해서 사용하는 긴 프리픽스(긴 문서, 시스템 지침, 도구 정의)를 캐시로 생성하면 이후 생성 요청에는 캐시 이름과 새 질문만 보내면 됩니다. 캐시 토큰은 캐시 적중 단가로 과금됩니다. 별도로 캐시 쓰기 요금과 시간 단위 저장 요금이 발생하며, 저장 요금은 생성 시 전체 유효 기간분을 청구하고 환불되지 않습니다.
</Note>

<Tip>
**캐시 참조**: `generateContent` 또는 `streamGenerateContent` 요청 본문에 `"cachedContent": "<name>"`을 추가하고 `contents`에는 새 질문만 넣습니다. 캐시를 참조하는 요청에는 `systemInstruction`, `tools`, `toolConfig`를 포함할 수 없으며, 캐시 생성 시와 같은 모델을 사용해야 합니다.
</Tip>
