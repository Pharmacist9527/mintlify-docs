openapi: '/ko/api-manual/language-series/gemini/cached-contents/cached-contents.json GET /v1beta/cachedContents/{id}'
---

<Note>
경로의 `{id}`는 생성 시 `name`에서 `cachedContents/`를 뺀 부분입니다. 모델, 토큰 수, 생성/수정/만료 시각을 반환하며 내용은 반환하지 않습니다. 무료입니다.
</Note>

- 만료·삭제·미존재·다른 계정의 캐시는 모두 404 `CACHE_NOT_FOUND`입니다.
- 개념·요금·오류는 [캐시 생성](/ko/api-manual/language-series/gemini/cached-contents/cached-contents-create)을 참고하세요.
