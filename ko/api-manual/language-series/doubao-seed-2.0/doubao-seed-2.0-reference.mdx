<Note>
**BaseURL**: 기본 BaseURL은 `https://direct.evolink.ai`이며, 텍스트 모델 지원이 더 우수하고 장시간 연결을 지원합니다. `https://api.evolink.ai`는 멀티모달 서비스의 주력 엔드포인트이며, 텍스트 모델에 대해서는 대체 주소로 사용됩니다.
</Note>

<Note>
오디오 입력은 `doubao-seed-2-1-lite`만 지원합니다. Chat Completions는 웹 검색을 지원하지 않습니다. Seed 2.1 또는 `doubao-seed-evolving`에서 [Responses](/ko/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-responses-reference)나 [Messages](/ko/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-messages-reference)를 사용하세요.
</Note>
