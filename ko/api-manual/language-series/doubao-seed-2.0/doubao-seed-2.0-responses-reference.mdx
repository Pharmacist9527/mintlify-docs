## 1시간 후 만료되는 캐시 요청 만들기

보내기 직전에 다음 Python 코드를 실행하고 출력된 JSON을 요청 본문으로 사용하세요. 첫 요청에서는 `PREVIOUS_RESPONSE_ID`를 설정하지 않습니다. 이어갈 때는 이전 응답에서 실제로 받은 `id`를 이 환경 변수에 설정하고 코드를 다시 실행하세요. 실행할 때마다 `expire_at`을 새로 계산합니다.

```python
import json
import os
import time

body = {
    "model": "doubao-seed-2-1-pro",
    "input": "제품 설명서: 모터와 배터리의 보증 기간은 2년입니다. 이 정책을 기억해 주세요.",
    "caching": {"type": "enabled"},
    "expire_at": int(time.time()) + 3600,
}
previous_id = os.getenv("PREVIOUS_RESPONSE_ID")
if previous_id:
    body["previous_response_id"] = previous_id
    body["input"] = "보증 대상 부품은 무엇인가요?"
print(json.dumps(body, ensure_ascii=False))
```
