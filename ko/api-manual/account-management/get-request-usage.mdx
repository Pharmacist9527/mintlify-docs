<Note>
이 엔드포인트는 **동기 API 호출**의 비용을 조회하며, 주로 Chat Completions, Messages, Responses 등의 인터페이스를 통한 **텍스트 모델** 호출에 사용합니다.

원래 응답의 `X-Request-Id` 헤더 값을 Request ID로 사용합니다. 요청이 완료된 후 잠시 기다렸다가 조회하세요. 비동기 작업은 [작업 상태 조회](/ko/api-manual/task-management/get-task-detail)를 사용하세요.
</Note>
