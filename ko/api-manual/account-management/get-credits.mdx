## 요청 제한 및 재시도

제한은 계정, 경로, 모델, 사용자 그룹별로 적용될 수 있으며 같은 계정의 여러 API 키가 계정 제한을 공유할 수 있습니다. QPS와 RPM은 다른 시간 창입니다. 모든 인터페이스의 고정값을 가정하지 말고 유효 설정과 429 응답을 확인하세요. requests-limit 헤더는 QPS가 아닌 분당 한도를 나타낼 수 있습니다. /v1/models를 캐시하고 중복 초기화 호출을 합치세요. /v1/credits는 잔액 최신성 요구에 맞게 짧게 캐시하세요. HTTP 429에서는 Retry-After를 따르고 무작위 대기와 횟수 제한을 두며 인스턴스 간 동시 재시도를 피하세요. 제한 검토 시 시간, 경로, 요청 ID를 제공하세요. 생성과 작업 조회 제한은 따로 확인합니다.
