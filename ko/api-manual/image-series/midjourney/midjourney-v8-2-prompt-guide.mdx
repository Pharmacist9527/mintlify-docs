## 매개변수 개요

| 매개변수 | 작성법 | 유형 | 값 범위 | 기본값 | 설명 |
|------|------|------|---------|--------|------|
| 화면 비율 | `--ar W:H` | 정수 비율 | 임의의 양의 정수 비율, 소수 불가 | 1:1 | 이미지 화면 비율 |
| 카오스 | `--c N` | int | 0 - 100 | 0 | 생성 결과의 다양성 |
| 시드 | `--seed N` | int | 0 - 4294967295 | 무작위 | 시드를 고정하여 결과 재현 |
| 스타일라이즈 | `--s N` | int | 0 - 1000 | 100 | 예술적 스타일 강도 |
| 실험 매개변수 | `--exp N` | int | 0 - 100 | 0 | 미적 효과, 스타일라이즈와 중첩 가능 |
| 퀄리티 (정밀도) | `--quality N` / `--q N` | int | 1 - 4 | 1 | 렌더링 정밀도; 4는 고품질 모드. 추가 비용 없음. V8.1은 1 / 4만 허용 |
| RAW 모드 | `--raw` | 스위치 | — | 꺼짐 | 기본 미화 비활성화 |
| 네거티브 프롬프트 | `--no item1, item2` | 텍스트 | — | — | 이미지에서 제외할 요소 |
| 이미지 가중치 | `--iw N` | float | 0 - 3 | 1 | 참조 이미지 영향도 |
| 스타일 참조 | `--sref [URL]` | URL | — | — | 비주얼 스타일 매칭 |
| 스타일 가중치 | `--sw N` | int | 0 - 1000 | 100 | 스타일 참조 강도 |
| 개인화 | `--p [code]` | 코드 | — | — | 업스트림 채널에서 생성한 무드보드 id, 그대로 전달 |
| 타일 | `--tile` | 스위치 | — | 꺼짐 | 이음새 없는 반복 패턴 생성 |
| 위어드 | `--weird N` / `--w N` | int | 0 - 3000 | 0 | 비관습적이고 실험적인 미학 |

<Note>
다음 두 가지 설정은 prompt에 **쓰지 않고** API로 제어합니다 (prompt에 써도 효과가 없으며 매개변수는 제거됨):

- **속도**(`draft` / `fast`) → `model_params.speed`
- **출력 품질**(`standard` / `hd`) → 최상위 `quality` 매개변수

`--v` / `--version`은 V8.2로 고정되며 `--niji`는 지원되지 않습니다. 아래 [속도 모드](#속도-모드)와 [출력 품질](#출력-품질)을 참고하세요.
</Note>

## 기본 매개변수

### 화면 비율 `--ar`

이미지의 화면 비율을 설정합니다. 정수 비율만 지원되며 소수는 거부됩니다(`1.39:1`이 아니라 `139:100`으로 작성). 극단적인 비율은 실험적이며 예측 불가능한 결과를 만들 수 있습니다.

```
a cat --ar 16:9
```

일반적인 값: `1:1`, `4:3`, `3:2`, `16:9`, `9:16`, `2:3`. 픽셀 크기는 [출력 품질](#출력-품질)을 참고하세요.

### 카오스 `--chaos` / `--c`

생성 결과의 다양성을 제어합니다. 값이 높을수록 4장의 이미지 간 차이가 커집니다.

```
a cat --c 50
```

| 범위 | 효과 |
|------|------|
| 0 | 4장의 이미지가 매우 일관됨 (기본값) |
| 1-30 | 미세한 차이 |
| 30-70 | 적당한 다양성 |
| 70-100 | 뚜렷한 차이, 창의적 탐색에 적합 |

### 스타일라이즈 `--stylize` / `--s`

사실적 표현과 예술적 표현 사이의 균형을 조절합니다.

```
a cat --s 500
```

| 범위 | 효과 |
|------|------|
| 0-250 | 사실적 스타일, 프롬프트에 충실 |
| 250-750 | 균형 |
| 750-1000 | 강한 예술성, 대담한 색상과 구도 |

### 실험 매개변수 `--exp`

`--stylize`와 유사하지만 중첩 사용이 가능하며, 더 상세하고 역동적이며 창의적인 이미지를 생성합니다.

```
a cat --exp 25
```

- 권장 값: 5, 10, 25, 50, 100
- 5-50에서 효과 변화가 뚜렷하고, 50-100에서는 변화가 적음
- 25-50을 초과하면 `--stylize`와 `--p`의 효과를 덮어쓸 수 있음. 함께 사용할 때는 낮은 값을 사용하세요

### 퀄리티 `--quality` / `--q`

렌더링 정밀도를 설정합니다. 범위 1 - 4, 기본값 1. `4`는 고품질 모드입니다. 이 매개변수는 업스트림에 그대로 전달되며 **가격을 변경하지 않습니다**.

```
a cat --q 3
```

- V8.2는 `1` / `2` / `3` / `4`를 허용하고, V8.1은 `1` / `4`만 허용합니다. 범위를 벗어난 값은 업스트림에서 거부되며(`quality: should in [1 2 3 4]`), 작업은 실패하고 예약된 크레딧은 환불됩니다
- 값이 높을수록 렌더링 시간이 길어집니다
- 이미지 생성 인터페이스 전용. 파생 작업(변형, 리믹스, 편집 등)은 원본 이미지를 상속합니다

### RAW 모드 `--raw`

기본 미화를 비활성화하고 프롬프트 세부사항을 더 엄격하게 따릅니다. 사실감 또는 정밀한 제어를 추구하는 장면에 적합합니다.

```
product photo --raw
```

### 네거티브 프롬프트 `--no`

이미지에 나타나지 않아야 할 요소를 나열합니다. 여러 항목은 쉼표로 구분합니다. 해당 요소에 -0.5의 가중치를 주는 것과 동일합니다. 설명에 "no fruit"나 "without fruit"라고 써도 효과가 없습니다. Midjourney는 그 단어들을 내용으로 취급하므로 대신 이 매개변수를 사용하세요.

```
still life gouache painting --no fruit, flowers
```

### 시드 `--seed`

초기 무작위 상태를 고정하여 비교 테스트에 사용합니다.

```
a cat --seed 23453422
```

- 범위: 0 - 4294967295
- 시드는 초기 상태만 고정하며 동일한 출력을 보장하지 않습니다. 프롬프트, 매개변수, 모델 버전 중 하나라도 바뀌면 결과가 달라집니다
- 테스트할 때는 고정 시드를, 프로덕션에서는 다양성을 위해 무작위 시드를 사용하세요

## 이미지 참조 매개변수

### 이미지 프롬프트 (참조 이미지)

프롬프트 **앞부분**에 이미지 URL을 배치하여 이미지로 생성 내용에 영향을 줍니다.

```
https://cdn.evolink.ai/model-cards/midjourney-v8-2/midjourney-v8-2-og-v1.jpg 텍스트 설명 --iw 1.5
```

**유효한 조합 규칙:**

| 조합 방식 | 유효 여부 |
|---------|---------|
| 이미지 1장 + 텍스트 없음 | 무효 (오류 발생) |
| 이미지 1장 + 텍스트 설명 | 유효 |
| 이미지 2장 이상 + 텍스트 없음 | 유효 |
| 이미지 2장 이상 + 텍스트 설명 | 유효 |

- 최대 20장의 참조 이미지
- 지원 형식: `.png`, `.gif`, `.webp`, `.jpg`, `.jpeg`; 파일당 최대 20 MB, 한 변당 최대 16k 픽셀
- 순수 이미지 프롬프트(텍스트 없음)는 `--stylize` 및 `--weird`와 호환되지 않음
- `draft` 속도에서도 사용 가능 (본 플랫폼에서 검증됨); `--tile`만 `draft`와 함께 사용할 수 없음
- URL은 몇 초 이내에 공개적으로 접근 가능해야 합니다. [입력 이미지 요구 사항](#입력-이미지-요구-사항)을 참고하세요

### 이미지 가중치 `--iw`

참조 이미지가 결과에 미치는 영향도를 제어합니다. 범위 0 - 3, 기본값 1, 값이 높을수록 참조 이미지에 가까워집니다.

```
https://cdn.evolink.ai/model-cards/midjourney-v8-2/midjourney-v8-2-og-v1.jpg watercolor landscape --iw 2.0
```

### 스타일 참조 `--sref`

참조 이미지의 비주얼 스타일(색상, 텍스처, 조명)에 매칭합니다. 내용은 복사하지 않습니다. **텍스트 프롬프트와 함께 사용해야 합니다**.

```
a cat --sref https://cdn.evolink.ai/model-cards/midjourney-v8-2/midjourney-v8-2-og-v1.jpg
```

- 다중 지원: `--sref URL1 URL2`; 상대 가중치는 `--sref URL1::2 URL2::1` 형식으로 지정 가능 (업스트림 문서에 기재, 이 플랫폼에서는 아직 검증되지 않음)
- 랜덤 스타일 지원: `--sref random` (생성 후 숫자 코드가 반환되며 재사용 가능)
- 최대 20개 sref
- 텍스트 프롬프트는 지시가 아닌 내용을 서술하세요("make this look like the reference"가 아니라 "a cat")

### 스타일 가중치 `--sw`

스타일 참조의 영향 정도를 제어합니다. 범위 0 - 1000, 기본값 100.

```
a cat --sref https://cdn.evolink.ai/model-cards/midjourney-v8-2/midjourney-v8-2-og-v1.jpg --sw 500
```

### 개인화 `--p`

`--p`는 업스트림에 그대로 전달됩니다. 허용되는 값은 업스트림 채널이 본 플랫폼의 조직 계정 아래에 생성한 무드보드 id입니다. 본 플랫폼은 아직 무드보드 생성 / 목록 조회 엔드포인트를 제공하지 않으며, midjourney.com의 개인 프로필 코드는 적용되지 않습니다. 일관된 스타일이 필요하면 대신 `--sref` / `--sw`와 `--seed`를 사용하세요. `--p`는 `--weird`와 함께 사용할 수 없습니다.

```
a cat --p abc123
```

## 속도 모드

속도 모드는 API의 `model_params.speed` 필드로 제어합니다(프롬프트에 `--draft` / `--fast`를 작성하지 마세요).

라우트별 허용 값: 이미지 생성은 `draft` / `fast`, 리믹스·캔버스 편집·리텍스처·업로드 페인트는 `fast`만, 변형과 배경 제거에는 speed 필드가 없습니다 (변형은 `speed: fast`를 받아들이되 무시하며, 다른 값은 `400`을 반환합니다).

| 모드 | 설명 | 비용 |
|------|------|------|
| `draft` | 단일 실행으로 24장의 경량 512 px 스케치 이미지를 반환합니다. 이미지 생성 인터페이스 전용. | fast와 동일 배율 |
| `fast` | 표준 모드 (기본값), 매회 4장 생성 | 표준 |

<Note>
V7과 달리 V8.2의 `draft` 모드는 비용이 절반이 **아니며**, `fast`와 동일한 배율을 사용합니다. 드래프트 모드는 단일 실행으로 24장의 작은 스케치를 반환하므로, 마음에 드는 것을 골라 완전한 품질로 다시 실행하세요. 드래프트 모드는 `hd` 품질 또는 `--tile`과 함께 사용할 수 없습니다 (`--oref`는 V8.2에서 아예 지원되지 않습니다).

**V8.2에서는 turbo를 사용할 수 없습니다.** 업스트림 채널 문서에서 V8은 turbo 모드를 지원하지 않는 것으로 명시되어 있으므로, `speed: "turbo"`는 모든 V8.2 엔드포인트에서 `400`으로 거부됩니다(V8.1과 동일).
</Note>

## 출력 품질

출력 해상도는 프롬프트 매개변수가 **아닌** 최상위 `quality` 매개변수로 제어합니다. 프롬프트에 `--hd`를 작성하지 마세요.

| 값 | 해상도 | 비용 |
|----|--------|------|
| `standard` | 표준 해상도, 1:1 기준 긴 변 약 1024 px (기본값) | 1배 |
| `hd` | 네이티브 2K 출력, 1:1 기준 약 2048 x 2048 | 1.5배 |

- 품질 배율은 속도 배율과 **상승(곱셈)** 관계입니다
- `hd`는 `draft` 속도와 **호환되지 않습니다**
- V8.2에는 별도의 업스케일 엔드포인트가 없습니다. 업스트림은 V8의 "업스케일"을 `hd`로 새로 생성하는 방식으로 구현하므로, 2K 출력이 필요하면 `quality: "hd"`를 사용하세요

## 프롬프트 길이 제한

| 엔드포인트 | 제한 | 비고 |
|----------|-------|-------|
| `mj-v8.2` (이미지 생성) | 업스트림이 적용하는 **텍스트 설명 1024자**; API는 총 2048자까지 허용 | 업스트림은 이미지 URL과 `--매개변수`를 제거한 뒤 설명만 계산합니다. 여유분은 URL과 매개변수용입니다 |
| `mj-v8.2-remix` / `-edit` / `-retexture` / `-upload-paint` | 8100자 | 프롬프트는 편집 지시로 전송되며 1024 규칙은 적용되지 않습니다 |
| `mj-v8.2-variation` / `-remove-bg` | — | `prompt`는 무시됩니다 |

설명이 너무 길면 업스트림이 `v8系列模型提示词长度限制为1024`로 거부하며, 작업은 실패하고 예약된 크레딧은 환불됩니다.

## 의존 관계

다음 매개변수는 다른 매개변수와 함께 사용해야 작동합니다:

| 매개변수 | 전제 의존 |
|------|---------|
| `--sw` | `--sref` 필요 |
| `--iw` | 이미지 프롬프트 (참조 이미지) 필요 |
| `--sref` | 텍스트 프롬프트 필요 |
| 단일 참조 이미지 | 텍스트 프롬프트 필요 |

---

## 충돌 관계

| 매개변수 A | 매개변수 B | 설명 |
|--------|--------|------|
| `draft` 속도 | `hd` 품질 | 드래프트 모드는 HD와 함께 사용할 수 없음 |
| `draft` 속도 | `--tile` | 함께 사용할 수 없음 |
| `--weird` | `--p` | 함께 사용할 수 없음 |
| 순수 이미지 프롬프트 | `--stylize` / `--weird` | 텍스트 없이는 호환되지 않음 |
| `--exp` > 25 | `--stylize` / `--p` | 높은 `--exp`는 이들을 억제할 수 있음. 함께 사용할 때는 `--exp`를 낮추세요 |

## V8.2에서 지원하지 않는 매개변수

V8.2는 버전 고정이나 과금을 깨뜨리는 매개변수만 제거하며, **그 외 모든 매개변수는 업스트림에 그대로 전달됩니다**. 업스트림이 매개변수를 지원하지 않으면 작업은 업스트림 오류 메시지와 함께 실패하고 예약된 크레딧은 환불됩니다 — 조용히 무시되는 것은 없습니다.

| 매개변수 | 처리 |
|----------|------|
| `--v` / `--version` / `--niji` | 제거 — 버전은 V8.2로 고정 |
| `--fast` / `--turbo` / `--draft` / `--relax` | 제거 — `model_params.speed` 사용 (`draft` / `fast`; V8.2에서는 turbo 사용 불가) |
| `--hd` | 제거 — 최상위 `quality` 매개변수 사용 |
| `--bs` / `--batchsize` | 제거 — 배치 크기는 설정 불가 |
| `--edit` | 업스트림의 지시 기반 편집 엔드포인트용으로 예약되어 있으며, 이 플랫폼에서는 아직 제공되지 않음; 현재의 모든 엔드포인트에서 업스트림이 거부 |
| `--oref` / `--ow` | 업스트림 거부 (V8.2 미지원) |
| `--cref` / `--cw` | 업스트림 거부 (V8.2 미지원) |
| `--stop` | 업스트림 거부 |
| 멀티 프롬프트 `::` | 업스트림 거부 |
| `--sv` | `--sv 6`만 허용되며 `--sref`와 함께 사용해야 함 |
| `--repeat` / `--r`, `{}` 순열, `--stealth` / `--public` | API에서 미지원 |

<Note>
업스트림 채널은 V8.1 / V8.2용 **지시 기반 편집** 엔드포인트(Midjourney Edit Model: `--edit`, 최대 4장의 참조 이미지, 선택적 투명 마스크 다시 그리기)도 공개했습니다. 이 플랫폼에서는 아직 제공되지 않으며 제공 일정을 조율 중입니다. `mj-v8.2-edit`와 `mj-v8.2-upload-paint`는 캔버스 편집(`canvas` + `img_pos` + 선택적 `mask`)이며, `mj-v8.2-retexture`는 리텍스처 도구입니다. 현재의 어떤 엔드포인트에서든 프롬프트에 `--edit`를 작성하면 업스트림에서 거부됩니다.
</Note>

## 입력 이미지 요구 사항

다음 규칙은 이미지 프롬프트, `--sref` URL, 그리고 retexture / upload-paint / remove-bg의 `image_urls` 필드에 적용됩니다.

- **공개 HTTP(S) URL만 가능.** Base64와 data URL은 허용되지 않습니다. URL 자체는 1024자 이하여야 합니다.
- **업스트림은 작업 생성 시 이미지를 동기적으로 가져오며 약 10초 후 포기합니다**(이 플랫폼에서 측정한 값). 제한 시간 내에 파일을 다운로드하지 못하면 요청은 `400`으로 실패하고 작업은 생성되지 않습니다. 중국 본토 외 이미지 호스트(imgur, ibb, raw.githubusercontent, pinimg, picsum 등)는 실제로 거의 매번 실패합니다. 이미지를 빠른 CDN에 호스팅하거나, 먼저 [파일 업로드 API](/ko/api-manual/file-series/upload-url)로 업로드한 뒤 반환된 URL을 사용하세요.
- 지원 형식: `.png`, `.gif`, `.webp`, `.jpg`, `.jpeg` (`mj-v8.2-remove-bg`는 `.png`, `.jpg`, `.jpeg`만 허용). 파일당 최대 20 MB, 한 변당 최대 16k 픽셀. 매우 큰 파일은 접근 가능한 호스트에서도 가져오기 제한 시간을 초과할 수 있습니다.
- `mj-v8.2-remove-bg`는 이 플랫폼의 Midjourney 작업이 반환하는 서명된 결과 링크(`Expires` / `Signature`가 포함된 URL)를 허용하지 않습니다. 이미지를 다시 호스팅하거나 서명되지 않은 URL을 사용하세요. retexture와 upload-paint는 해당 링크를 허용합니다.
- 이미지 프롬프트와 `--sref` URL은 `draft` 속도에서도 허용됩니다 (본 플랫폼에서 검증됨). `draft`와 함께 거부되는 것은 `--tile`뿐입니다.

## 프롬프트 작성 규칙

### 기본 구조

```
[이미지URL] 텍스트 설명 --매개변수1 값1 --매개변수2 값2
```

### 작성 규칙

- 매개변수는 텍스트 프롬프트의 **끝**에 배치
- `--` 앞에는 반드시 **공백**이 필요
- 매개변수 안에 구두점을 사용하지 않음
- 매개변수 뒤에 텍스트를 작성하지 않음
- 이미지 안에 글자를 렌더링하려면 큰따옴표로 감쌈: `a neon sign that says "OPEN" --ar 3:2`

### 예시

<CodeGroup>
```text 올바름
a yellow Persian cat --ar 1:2 --s 500
```

```text 잘못됨
a yellow Persian cat--ar 2:3          ← -- 앞에 공백 없음
a yellow Persian cat - - ar 2:3       ← -- 사이에 공백 있음
a yellow Persian cat --ar 2:3, --s 50 ← 매개변수에 구두점 있음
a yellow Persian cat --ar 2:3 more description ← 매개변수 뒤에 텍스트 있음
```
</CodeGroup>

## 작업 워크플로

V8.2의 7개 모델은 모두 비동기이며 호출당 과금됩니다.

1. **제출** — `POST /v1/images/generations`는 작업 `id`, `status: processing`, `usage.credits_reserved`를 즉시 반환합니다. 업스트림 작업은 백그라운드에서 생성됩니다.
2. **폴링** — `GET /v1/tasks/{task_id}` ([작업 상태 조회](/ko/api-manual/task-management/get-task-detail)). 업스트림에 따르면 생성과 편집의 평균 소요 시간은 약 40초입니다. 3~5초마다 폴링하고 클라이언트 측에서 약 20분의 상한을 두세요. 작업이 아직 `processing`인 동안 동일한 프롬프트를 다시 제출하지 마세요. 업스트림은 조직 계정별로 동시 실행 수를 제한하며, 한도를 초과하면 본 플랫폼이 자동으로 백오프 후 재제출합니다. 사용자 측에서는 실패가 아니라 작업 소요 시간이 길어지는 것으로 나타납니다.
3. **결과 읽기** — `status`가 `completed`가 되면 `results`에 이미지 URL이 담깁니다. `fast`는 4장, `draft`는 24장입니다. `usage.cost`에 최종 청구 금액이 표시됩니다.
4. **이미지 저장** — 결과 링크는 서명된 OSS URL로 **30일** 동안 유효하며, 서명은 `GET`에만 유효하므로 `HEAD`로 확인하면 `403`이 반환됩니다. 보관이 필요한 것은 다운로드하거나 다시 호스팅하세요.
5. **선택적 콜백** — `callback_url`(HTTPS, 공개 호스트)을 전달하면 `completed` / `failed` 시 알림을 받습니다. 콜백은 백오프와 함께 3회 재시도됩니다. 참고용 신호로 취급하고 작업 조회로 확인하세요.

| 상태 | 의미 | 최종 상태? |
|--------|---------|--------|
| `pending` | 접수됨, 업스트림 대기열 대기 중 | 아니요 |
| `processing` | 렌더링 중 | 아니요 |
| `completed` | `results`에 이미지 준비됨 | 예 |
| `failed` | 업스트림 오류, 매개변수 거부, 콘텐츠 검토 또는 가져오기 실패; 메시지는 `error`에 있으며 예약된 크레딧은 환불됨 (검토로 모든 이미지가 차단된 경우만 예외, 아래 참고) | 예 |

실패한 작업은 생성 단계에서 거부된 요청, 업스트림 매개변수 거부(`--oref`, 범위를 벗어난 `--q`, 너무 긴 설명), 이미지 가져오기 실패를 포함해 전액 환불됩니다. 유일한 예외: 업스트림 콘텐츠 검토가 작업의 **모든** 이미지를 차단한 경우 작업은 `failed`가 되고 업스트림에서 이미 과금되었으므로 크레딧은 **환불되지 않습니다**. 일부 이미지만 차단된 경우 작업은 `completed`이며 차단된 위치의 URL은 비어 있습니다. 오류 코드와 재시도 지침은 [오류 코드 참조](/ko/api-manual/task-management/error-codes) 페이지에 있습니다.

### 파생 작업

변형, 리믹스, 캔버스 편집은 동일한 계정의 완료된 `mj-v8.2` 시리즈 작업을 원본(`task_id` + `image_number`)으로 사용합니다. 업스트림 채널 문서에 기재되어 있고 이 플랫폼에서 검증된 규칙:

- 이러한 파생 작업에서 원본 작업은 업스트림의 Midjourney V7 엔진으로 렌더링되므로, 결과는 원본 이미지와 스타일이 약간 다를 수 있습니다. 가격은 변경되지 않습니다. V8.1 원본은 허용되지 않습니다.
- `image_number`로 원본 이미지를 선택합니다: `fast` 원본 작업은 `0`~`3`, `draft` 원본 작업은 `0`~`23`(24장의 스케치 모두 변형, 리믹스, 편집의 원본으로 사용 가능).
- `mj-v8.2-upload-paint`, `mj-v8.2-retexture`, `mj-v8.2-remove-bg`의 결과는 변형, 리믹스, 편집의 원본으로 **사용할 수 없습니다**. 업스트림은 이들의 업스케일만 허용하며, 이 경로에서는 제공하지 않습니다. 대신 이미지 생성, 변형, 리믹스 또는 편집 작업을 원본으로 사용하세요.

## 자주 묻는 질문

**V8.1에서 이전할 때 프롬프트를 변경해야 하나요?**
아니요. `model` 값만 변경하면 되며 프롬프트, `model_params`, 가격은 그대로입니다. `--oref` / `--ow`만 더 이상 작동하지 않고, `--q`는 `1`과 `4` 외에 `2`와 `3`도 허용합니다.

**이미지 프롬프트가 작업이 생성되기도 전에 400으로 실패하는 이유는 무엇인가요?**
업스트림이 가져오기 제한 시간 내에 이미지를 다운로드하지 못했기 때문입니다. 파일을 빠르고 공개적으로 접근 가능한 호스트로 옮기거나 파일 업로드 API를 사용한 뒤 다시 시도하세요.

**turbo 속도가 있나요?**
아니요. 업스트림 문서에서 V8은 turbo를 지원하지 않는 것으로 명시되어 있으므로, V8.2는 V8.1과 마찬가지로 `draft`와 `fast`만 제공합니다.

**`--q 4`는 더 느리거나 더 비싼가요?**
과금은 다르지 않습니다. 업스트림은 `4`를 고품질 모드로 설명하며, 렌더링 시간이 더 오래 걸립니다.

**V8.2 이미지를 업스케일할 수 있나요?**
V8.2에는 업스케일 엔드포인트가 없습니다. 대신 `quality: "hd"`로 생성하여 네이티브 2K 출력을 받으세요.

## 콘텐츠 검토 안내

<Note>
Midjourney에는 콘텐츠 검토 시스템이 내장되어 있습니다. 검토는 이미지별로 개별 진행됩니다. 생성된 이미지 중 일부가 필터링된 경우 작업은 `completed`로 유지되고 해당 자리는 비어 있는 상태로 반환되며 나머지 이미지는 정상적으로 전달됩니다. **모든** 이미지가 필터링된 경우 작업은 `failed`가 됩니다. 두 경우 모두 업스트림에서 이미 과금되었으므로 해당 요청에서 소비된 크레딧은 환불되지 않습니다. 프롬프트가 콘텐츠 가이드라인을 준수하는지 확인해 주세요.
</Note>
