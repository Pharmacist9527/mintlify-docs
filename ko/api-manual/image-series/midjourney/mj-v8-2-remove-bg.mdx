<Note>
Midjourney에는 콘텐츠 검토 시스템이 내장되어 있습니다. 검토는 이미지 단위로 진행되며, 생성된 이미지 중 일부가 필터링되면 해당 위치의 URL은 비어 있고 나머지 이미지는 정상적으로 반환됩니다. 해당 요청에서 소비된 크레딧은 환불되지 않습니다. 프롬프트가 콘텐츠 가이드라인을 준수하는지 확인해 주세요.
</Note>
