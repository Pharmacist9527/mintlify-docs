<Note>
상위 제공업체의 정책 변경으로 Midjourney V7 Inpaint(`mj-v7-inpaint`) 제공이 2026년 10월 18일에 종료되었습니다. 현재 요청은 HTTP 410(`mj_v7_inpaint_discontinued`)을 반환하며 요금이 부과되지 않습니다. 이미지 일부를 다시 그리려면 이 인터페이스(`mj-v7-upload-paint`)를 사용하세요.
</Note>

<Note>
Midjourney에는 콘텐츠 검토 시스템이 내장되어 있습니다. 생성된 이미지 중 일부가 검토에 의해 필터링된 경우, 해당 요청에서 소비된 크레딧은 환불되지 않습니다. 프롬프트가 콘텐츠 가이드라인을 준수하는지 확인해 주세요.
</Note>
