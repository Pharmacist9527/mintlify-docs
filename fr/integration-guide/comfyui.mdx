## Vue d'ensemble

<Frame caption="Accueil de ComfyUI Desktop : choisissez ou créez une instance pour accéder au canevas (les autres types d'installation sont similaires)">
  ![Accueil de ComfyUI Desktop](/images/integration-guide/comfyui/desktop-home.jpg)
</Frame>

[ComfyUI](https://www.comfy.org/) est l'outil **open source de génération d'images par IA à base de nœuds** le plus populaire : chaque étape — charger un modèle, écrire un prompt, générer une image — devient un nœud que vous reliez sur un canevas, ce qui permet de construire des workflows très flexibles et réutilisables, comme un jeu de construction. Gratuit, open source et doté d'un immense écosystème de plugins, il est devenu un environnement de travail incontournable pour la création visuelle par IA.

Avec le **plugin ComfyUI officiel EvoLink**, vous pouvez appeler le modèle cloud `gpt-image-2` directement depuis vos workflows ComfyUI — en texte vers image comme en image vers image, **sans aucun GPU local**.

**Compatible avec** : ComfyUI Desktop, les versions portables, les installations manuelles et le package tout-en-un chinois « aki ».

## Avant de commencer

### Obtenir une clé API EvoLink

1. Connectez-vous au [tableau de bord EvoLink](https://evolink.ai/dashboard)
2. Ouvrez la [page API Keys](https://evolink.ai/dashboard/keys), créez une clé et copiez-la (elle commence par `sk-`)

<Frame caption="Page API Key Management → Create New Key (en haut à droite) → copiez la clé générée">
  ![Créer une clé API](/images/integration-guide/comfyui/create-api-key.png)
</Frame>

<Warning>
**Votre clé API donne accès au solde de votre compte.** Conservez-la uniquement dans la configuration locale de votre nœud — ne la collez jamais dans un chat, une capture d'écran ou un dépôt public. En cas de doute sur une fuite, supprimez et recréez la clé immédiatement.
</Warning>

### Vérifier que vous disposez de crédits

La génération consomme des crédits. Vérifiez votre solde sur le [tableau de bord](https://evolink.ai/dashboard) ; la consommation de chaque tâche est visible dans les [journaux de tâches](https://evolink.ai/dashboard/logs).

## Étape 1 : Installer le plugin officiel

<Tabs>
  <Tab title="Option A : ComfyUI Desktop">

    2. Recherchez **`evolink`** → sélectionnez l'entrée **EvoLink** dont le champ Created By est **evolink** → cliquez sur **Install**
    3. Redémarrez ComfyUI lorsque cela vous est demandé

    <Frame caption="Recherchez EvoLink dans le gestionnaire de nœuds de Desktop → Install (illustration : le panneau d'informations du pack après installation)">
      ![Installer EvoLink dans Desktop](/images/integration-guide/comfyui/manager-install.png)
    </Frame>

    <Note>Publié sur le Registry officiel de ComfyUI ([registry.comfy.org/nodes/evolink-nodes](https://registry.comfy.org/nodes/evolink-nodes)) — trouvable via le Manager dans Desktop, les versions navigateur et les distributions packagées.</Note>
  </Tab>
  <Tab title="Option B : package tout-en-un aki">
    1. Lancez ComfyUI depuis le lanceur, puis dans le navigateur cliquez sur **Manager** dans la barre d'outils supérieure → **Custom Nodes Manager**

    <Frame caption="Panneau Manager → Custom Nodes Manager">
      ![Panneau Manager](/images/integration-guide/comfyui/manager-menu.png)
    </Frame>

    2. Saisissez **`evolink`** dans le champ de recherche → sélectionnez l'entrée **EvoLink** dont l'Author est **evolink** → cliquez sur **Install**

    <Frame caption="Recherchez evolink → le pack officiel (Author : evolink) → Install">
      ![Rechercher EvoLink dans le Manager](/images/integration-guide/comfyui/manager-search-evolink.png)

    3. Lorsque la colonne Action affiche **Restart Required**, l'installation a réussi → arrêtez puis relancez depuis le lanceur → **actualisez le navigateur**

    <Note>
    Si une erreur `Neither 'pip' nor 'uv' are available for package management` apparaît pendant l'installation, **vous pouvez l'ignorer** : la seule dépendance de ce plugin est `requests`, déjà incluse dans le package. Tant que la colonne Action affiche **Restart Required**, l'installation a fonctionné.
    </Note>
  </Tab>
  <Tab title="Option C : git">
    Dans le dossier `ComfyUI/custom_nodes`, exécutez :

    ```bash
    git clone https://github.com/deeplearning-goethe/comfyui-evolink.git
    ```

    Utilisateurs du package tout-en-un aki : `custom_nodes` se trouve dans votre dossier d'installation `ComfyUI-aki-vX.X` ; exécutez la commande depuis le terminal du lanceur, ou ouvrez PowerShell dans ce répertoire.
  </Tab>
  <Tab title="Option D : téléchargement ZIP">
    1. Ouvrez le [dépôt du plugin](https://github.com/deeplearning-goethe/comfyui-evolink) → bouton vert **Code** → **Download ZIP**, puis décompressez
    2. Déplacez le dossier dans `ComfyUI/custom_nodes/`
    3. **Vérification d'imbrication (indispensable)** : en ouvrant `custom_nodes/comfyui-evolink/`, vous devez voir `__init__.py` directement. Si vous voyez un second dossier du même nom à l'intérieur (problème courant de décompression), remontez le dossier interne d'un niveau et supprimez la coquille vide.

    Une arborescence correcte ressemble à ceci :

    ```
    ComfyUI-aki-v3.7\
      └─ custom_nodes\
           ├─ ComfyUI-Manager\
           └─ comfyui-evolink\
                ├─ __init__.py
                └─ ...autres fichiers
    ```
  </Tab>
</Tabs>

La seule dépendance est `requests` (généralement déjà incluse avec ComfyUI).

<Accordion title="L'installation en Option A / B échoue avec only custom nodes from the default channel can be installed ? Dépliez pour la solution">
  <Frame caption="L'erreur : installation bloquée par la configuration actuelle du niveau de sécurité">
    ![Erreur default channel](/images/integration-guide/comfyui/manager-default-channel-error.png)
  </Frame>

  Cette erreur survient parce que les versions du plugin sont en cours d'examen de sécurité par le registre officiel de ComfyUI (procédure courante pour les nœuds d'API cloud), et le niveau de sécurité par défaut du Manager bloque l'installation pendant ce temps. Vous pouvez **abaisser temporairement le niveau de sécurité du Manager** — puis le rétablir ensuite :

  **Étape 1 : Fermez complètement ComfyUI**
  - Package tout-en-un aki : lanceur → **Terminer le processus**
  - Desktop officiel / portable / installation manuelle : quittez complètement l'application, y compris la fenêtre de console

  **Étape 2 : Modifiez le fichier de configuration du Manager `config.ini`**

  Localisez-le selon votre type d'installation (ou recherchez simplement `config.ini` dans votre dossier ComfyUI et choisissez celui dont le chemin contient `manager`) :

  | Environnement | Emplacement de config.ini |
  |---|---|
  | Package tout-en-un aki | `votre-dossier-de-téléchargement\ComfyUI-aki-vX.X\ComfyUI-aki-vX.X\ComfyUI\user\__manager\config.ini` |
  | Version officielle (Desktop / portable / manuelle) | `dossier d'installation ComfyUI\user\default\ComfyUI-Manager\config.ini` |

  Ouvrez-le dans un éditeur de texte, trouvez la ligne `security_level` et remplacez `normal` par `weak` :

  ```ini
  security_level = weak
  ```

  Enregistrez et fermez.

  <Frame caption="Remplacez la valeur de security_level par weak puis enregistrez (ne touchez à aucune autre ligne)">
    ![Modifier security_level](/images/integration-guide/comfyui/manager-config-security-level.png)
  </Frame>

  **Étape 3 : Redémarrez ComfyUI et relancez l'installation**

  Démarrez ComfyUI → Manager → recherchez `evolink` → **Install**. Ignorez le message `Neither 'pip' nor 'uv'...` s'il apparaît. Une fois **Restart Required** affiché, redémarrez complètement une nouvelle fois et actualisez le navigateur.

  **Étape 4 : Vérifiez, puis rétablissez le niveau de sécurité**
  - Confirmez que les nœuds se chargent en suivant [Vérifier l'installation](#vérifier-l’installation) ci-dessous
  - **Remettez `security_level` sur `normal` après l'installation** (répétez les étapes 1 et 2) pour restaurer la protection par défaut du Manager
</Accordion>

Après un redémarrage complet et une actualisation du navigateur, **double-cliquez** sur une zone vide du canevas → recherchez `evolink`. Si vous voyez à la fois **EvoLink GPT Image 2 (Official)** et **EvoLink Upload Image (Official)**, l'installation a réussi :

Nœuds introuvables ? Assurez-vous d'avoir fait un **redémarrage complet** (pas une simple actualisation du navigateur) ; sinon, consultez la [FAQ](#faq).

## Étape 2 : Votre première image (texte vers image, 5 minutes)

1. **Double-cliquez** sur une zone vide du canevas (ou clic droit → Add Node) → recherchez **`EvoLink`** → ajoutez **EvoLink GPT Image 2 (Official)**
2. Renseignez :
   - `api_key` : collez votre clé `sk-`. **Une seule fois** — elle est enregistrée dans un fichier de configuration local après la première exécution ; laissez ensuite le champ vide (et videz-le avant de partager vos workflows)
   - `prompt` : votre description, par exemple `un shiba inu avec une écharpe rouge assis dans la neige, illustration flat design`
   - Conservez les autres valeurs par défaut (`quality=low` est l'option la moins chère pour vos tests)
3. **Connectez un nœud d'affichage (indispensable)** : faites glisser depuis le point de sortie `image` vers une zone vide du canevas et choisissez **Preview Image** ; ajoutez aussi un nœud **Save Image** si vous voulez que les fichiers soient écrits dans le dossier `output` de ComfyUI

<Warning>
**L'erreur de débutant la plus fréquente** : le nœud EvoLink génère mais n'affiche pas. Si la sortie `image` n'est connectée à rien, la tâche se termine sans qu'aucune image n'apparaisse.
</Warning>

<Frame caption="Le workflow texte vers image complet : paramètres renseignés, image reliée à Preview Image (api_key masquée — laissez le champ vide après la première utilisation)">
  ![Workflow texte vers image complet](/images/integration-guide/comfyui/text2img-workflow.png)
</Frame>

4. Cliquez sur **Queue Prompt**. Le nœud soumet la tâche, interroge la progression avec une barre en temps réel et récupère le résultat, affiché directement dans le nœud Preview.

## Étape 3 : Image vers image (en 3 étapes)

1. Ajoutez un nœud **Load Image** et sélectionnez votre image locale
2. Connectez sa sortie image à l'entrée **`image1`** du nœud EvoLink
3. Décrivez la modification dans `prompt` → lancez l'exécution

<Frame caption="Câblage image vers image complet : Load Image → image1, instruction de modification dans le prompt (exemple : style Ghibli, rue de nuit en arrière-plan) — composition préservée">
  ![Workflow image vers image complet](/images/integration-guide/comfyui/img2img-workflow.png)
</Frame>

<Note>
Votre image est téléversée automatiquement via le **canal de fichiers officiel EvoLink** pour obtenir une URL temporaire (**supprimée automatiquement après 72 heures**) — aucun hébergeur d'images tiers, aucune inscription supplémentaire.
</Note>

**Utilisation avancée** :

- **Références multiples** : les entrées `image1` à `image4` plus la zone de texte `image_urls` (une URL publique par ligne) peuvent être combinées — jusqu'à **16 images** au total
- **Workflows complexes** : le nœud **EvoLink Upload Image (Official)** fourni convertit des images locales en texte d'URL (inutile pour l'image vers image classique)
- **Workflows prêts à l'emploi** : [example_workflows](https://github.com/deeplearning-goethe/comfyui-evolink/tree/main/example_workflows) contient des exemples texte vers image / image vers image / références multiples. **Le PNG de résultat de chaque exemple embarque le workflow complet — téléchargez l'image et glissez-la sur le canevas pour restaurer tous les nœuds et connexions** (fonctionnalité native de ComfyUI) ; les fichiers JSON correspondants sont également fournis

## Paramètres

| Paramètre | Description |
|---|---|
| `prompt` | Description / instruction de modification, plusieurs langues prises en charge (dont le français), jusqu'à 32 000 caractères |
| `model` | `gpt-image-2` (par défaut) / `gpt-image-2-beta` |
| `size` | `auto` (par défaut, le modèle choisit la composition) / ratio comme `1:1`, `16:9` / pixels comme `1024x1024` |
| `resolution` | `1K` / `2K` / `4K`, s'applique quand size est un ratio ou auto |
| `quality` | `low` / `medium` / `high` — **plus la qualité est élevée, plus c'est cher** ; utilisez `low` pour les tests |
| `n` | Nombre d'images par exécution (1–10) |
| `api_key` | Enregistrée localement à la première utilisation, laissez vide ensuite ; la variable d'environnement `EVOLINK_API_KEY` fonctionne aussi |
| `image1`–`image4` | Entrées d'images de référence — connectez Load Image pour l'image vers image |
| `image_urls` | Avancé : une URL publique par ligne |
| `timeout_seconds` | Attente maximale (300 s par défaut) ; les tâches expirées ne sont pas facturées |

Sorties : `image` (résultat, déjà téléchargé), `task_id` (pour la vérification de facturation et le support), `status_info` (résumé de l'exécution : durée, crédits consommés, etc.).

## Facturation et vérifications en autonomie

- **Paiement à l'usage, sans abonnement** : les crédits sont réservés à la soumission (`credits_reserved`) puis décomptés selon la consommation réelle
- **Les tâches échouées ou expirées ne sont pas facturées** — les crédits sont remboursés automatiquement
- **Les résultats en cache sont gratuits** : relancer avec des paramètres inchangés réutilise le cache local de ComfyUI
- **Chaque tâche est traçable** : recherchez n'importe quel `task_id` dans les [journaux de tâches](https://evolink.ai/dashboard/logs) ; en cas de question sur une facturation, envoyez le `task_id` au support

## FAQ

<AccordionGroup>
  <Accordion title="Le nœud EvoLink n'apparaît pas dans la recherche ?">
    Vérifiez dans l'ordre : ① le dossier du plugin est directement sous `custom_nodes` ; ② pas de double imbrication de dossiers après décompression (`__init__.py` doit être visible en ouvrant le dossier) ; ③ vous avez complètement redémarré ComfyUI (fenêtre de console fermée, pas seulement le navigateur) ; ④ recherchez `evolink` dans le journal de démarrage — faites une capture d'écran de toute erreur en rouge pour le support. Les utilisateurs du package tout-en-un aki peuvent aussi lancer un diagnostic d'environnement en un clic depuis le panneau Dépannage du lanceur.
  </Accordion>
  <Accordion title="L'installation via le Manager échoue avec only custom nodes from the default channel can be installed ?">
    Les versions du plugin sont en cours d'examen de sécurité par le registre officiel de ComfyUI, et le niveau de sécurité par défaut du Manager bloque l'installation pendant ce temps. Consultez la solution dépliable dans la [section d'installation](#étape-1--installer-le-plugin-officiel) : passez temporairement le `security_level` du Manager sur `weak`, installez, puis remettez `normal` — ou utilisez simplement l'Option C (git) / l'Option D (ZIP) ; le plugin fonctionne exactement pareil.
  </Accordion>
  <Accordion title="Le Manager signale Neither pip nor uv are available pendant l'installation ?">
    Vous pouvez l'ignorer. Le Manager n'a simplement pas trouvé de gestionnaire de paquets pour installer les dépendances ; la seule dépendance de ce plugin est `requests`, déjà incluse avec ComfyUI. Si la liste affiche **Restart Required**, redémarrez et les nœuds se chargeront normalement.
  </Accordion>
  <Accordion title="La tâche est terminée mais aucune image n'apparaît ?">
    La sortie `image` n'est connectée à aucun nœud Preview/Save Image. Reliez-la et relancez — le résultat en cache s'affiche instantanément sans facturation supplémentaire.
  </Accordion>
  <Accordion title="Le panneau des ressources média indique qu'aucun fichier généré n'a été trouvé ?">
    C'est normal quand seul un nœud **Preview Image** est connecté (les aperçus ne sont pas écrits sur le disque). Pour que les images apparaissent dans le panneau et dans le dossier `output`, utilisez un nœud **Save Image**.
  </Accordion>
  <Accordion title="Erreur 401 / Unauthorized ?">
    Clé erronée, espace parasite, ou clé supprimée. Vérifiez sur la [page API Keys](https://evolink.ai/dashboard/keys) ; après recréation, renseignez une fois le champ `api_key` du nœud pour écraser l'ancienne clé enregistrée localement.
  </Accordion>
  <Accordion title="Erreur 402 / solde insuffisant ?">
    Crédits insuffisants — rechargez sur le [tableau de bord](https://evolink.ai/dashboard) et réessayez.
  </Accordion>
  <Accordion title="Erreur 429 / trop de requêtes ?">
    Vous avez atteint la limite de débit — patientez un instant et relancez.
  </Accordion>
  <Accordion title="Échec pour cause de politique de contenu ?">
    Le prompt ou une image de référence a déclenché la modération. Ajustez et réessayez — **les tâches échouées ne sont pas facturées**.
  </Accordion>
  <Accordion title="Les liens de résultat ont expiré ?">
    Les URL de résultat expirent après **24 heures** et les références téléversées après **72 heures** — mais le nœud télécharge déjà les résultats dans le workflow ; utilisez un nœud **Save Image** pour les conserver définitivement dans le dossier `output` local.
  </Accordion>
  <Accordion title="Le chargement tourne longtemps sans résultat ?">
    Les tâches en haute résolution / haute qualité / par lot prennent plus de temps ; le nœud attend jusqu'à 300 s par défaut (`timeout_seconds`). Les expirations **ne sont pas facturées** — vérifiez le statut final de la tâche dans les [journaux de tâches](https://evolink.ai/dashboard/logs).
  </Accordion>
  <Accordion title="Comment migrer depuis l'ancien plugin ou le plugin communautaire ?">
    **Anciens nœuds officiels** : usage identique — Load Image → `image1`. **`ComfyUI_EvoLink` communautaire** : les noms de paramètres correspondent ; son nœud `Evolink Image Input` et la clé imgbb ne sont plus nécessaires (connectez les images directement à `image1`) ; `poll_interval`/`max_polls` sont devenus `timeout_seconds`. Les deux plugins peuvent coexister.
  </Accordion>
  <Accordion title="Impossible d'ouvrir 127.0.0.1:8188 dans le navigateur ?">
    Assurez-vous d'abord que le journal de la console affiche `To see the GUI go to` (le premier lancement est lent) ; si cela ne s'ouvre toujours pas, essayez `http://localhost:8188`, ou vérifiez si un proxy système / VPN intercepte les adresses locales (ajoutez `127.0.0.1` à la liste d'exclusion du proxy). Si vous utilisez un proxy, configurez `api.evolink.ai` et `files-api.evolink.ai` en connexion directe.
  </Accordion>
  <Accordion title="Quels modèles sont pris en charge ? Et la vidéo ?">
    Le plugin couvre actuellement `gpt-image-2`. Nano Banana (série Gemini), Seedream et les modèles vidéo (Veo / Sora / Kling) sont sur la feuille de route ; en attendant, tous les modèles du [catalogue complet](https://evolink.ai/models) peuvent être appelés via l'[API directe](#annexe--appeler-l’api-sans-le-plugin).
  </Accordion>
</AccordionGroup>

Toujours bloqué ? Envoyez l'**ID de tâche / une capture d'écran du journal de démarrage / le texte exact de l'erreur** à [support@evolink.ai](mailto:support@evolink.ai).

## Annexe : appeler l'API sans le plugin

Utile pour vérifier une clé, ou pour les modèles que le plugin ne couvre pas encore.

**Vérifiez votre clé en 30 secondes (gratuit) :**

```bash
curl -s -H "Authorization: Bearer sk-VOTRE_CLE" https://api.evolink.ai/v1/models
```

Une liste de modèles (`{"data":[{"id":...`) signifie que la clé fonctionne ; `Unauthorized` signifie qu'elle est invalide.

**Soumettez une tâche de génération :**

```bash
curl -s -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer sk-VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"a cute cat, watercolor style","size":"1:1","resolution":"1K","quality":"low","n":1}'
```

Notez l'`id` de tâche retourné (il commence par `task-unified-`), puis interrogez l'API jusqu'à ce que `status` soit `completed` ; le tableau `results` contient les URL des images (à télécharger sous 24 heures) :

```bash
curl -s -H "Authorization: Bearer sk-VOTRE_CLE" https://api.evolink.ai/v1/tasks/TASK_ID
```
