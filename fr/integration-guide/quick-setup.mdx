## Aperçu

La configuration manuelle demande d’installer le client, de modifier un fichier de configuration et de renseigner le point de terminaison ainsi que votre clé API. Le script de configuration (`evolink-config`) fait tout cela en une seule commande :

- Vérifie votre environnement et installe le client s’il n’est pas encore sur votre ordinateur
- Renseigne le point de terminaison EvoLink et votre clé API
- Envoie un message de test pour confirmer que les appels aboutissent
- Sauvegarde chaque fichier avant de le modifier et peut tout annuler en une seule commande

L’ensemble prend généralement moins d’une minute.

| Client | Configuration en un clic |
|---|---|
| Claude Code CLI | Pris en charge |
| Codex CLI | Pris en charge |
| Autres clients | Voir les guides manuels sous « Outils de programmation IA » |

<Note>
Les commandes ci-dessous concernent macOS et Linux. Sous Windows, suivez pour l’instant le guide manuel de [Claude Code CLI](/fr/integration-guide/claude-code-cli) ou de [Codex CLI](/fr/integration-guide/codex-cli).
</Note>

## Prérequis

- **Clé API EvoLink** : connectez-vous à la [console EvoLink](https://evolink.ai/dashboard), créez une clé dans API Keys, puis copiez-la. Une clé commence par `sk-`.
- **Node.js** : la version 22 ou ultérieure est recommandée (18 au minimum). Exécutez `node -v` dans un terminal pour vérifier. S’il n’est pas installé, téléchargez la version LTS depuis le [site de Node.js](https://nodejs.org/).

## Configurer Claude Code

Exécutez dans un terminal :

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash
```

Le script vous guide en cinq étapes (ses messages sont en anglais) :

<Steps>
  <Step title="Environnement">
    Vérifie Node.js et Claude Code. Si Claude Code n’est pas encore installé, le script demande « Install now? » ; appuyez sur Entrée et il l’installe pour vous.
  </Step>
  <Step title="Clé API">
    Collez votre clé API EvoLink et appuyez sur Entrée. Ce que vous collez ne s’affiche pas à l’écran. Le script vérifie en ligne que la clé est valide et affiche votre solde.
  </Step>
  <Step title="Modèle">
    Choisissez le modèle que Claude Code utilise par défaut. Vous pouvez en changer à tout moment dans Claude Code avec `/model`.
  </Step>
  <Step title="Vérifier les modifications">
    Le script liste les fichiers et les paramètres qu’il va modifier. Appuyez sur Entrée pour les appliquer.
  </Step>
  <Step title="Appliquer et vérifier">
    Après avoir écrit les paramètres, le script envoie un message de test (environ 0,01 crédit). Une réponse normale signifie que la configuration est terminée.
  </Step>
</Steps>

Une fois terminé, ouvrez une nouvelle fenêtre de terminal et exécutez :

```bash
claude
```

Dans Claude Code, exécutez `/status`. Si la ligne Anthropic base URL affiche l’adresse d’EvoLink, la configuration est active.

## Configurer Codex CLI

Exécutez dans un terminal :

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- codex
```

Les étapes sont les mêmes que ci-dessus. Une fois terminé, lancez Codex avec :

```bash
codex -p evolink
```

<Note>
Le script crée un profil distinct pour Codex, `~/.codex/evolink.config.toml`, et ne modifie pas votre propre `~/.codex/config.toml`. Codex n’utilise EvoLink que si vous le lancez avec `-p evolink` ; un simple `codex` conserve vos paramètres d’origine.
</Note>

## Ce que le script modifie

### Claude Code

| Fichier | Modification |
|---|---|
| `~/.claude/settings.json` | Renseigne le point de terminaison `ANTHROPIC_BASE_URL` et votre clé `ANTHROPIC_AUTH_TOKEN` ; définit `ANTHROPIC_API_KEY` sur une valeur vide, pour qu’une ancienne clé restée sur l’ordinateur ne provoque pas d’erreurs 401 ; fixe la version du modèle utilisée pour Sonnet ; désactive le mode automatique (la raison est expliquée dans la FAQ ci-dessous). Tout le reste du fichier est conservé. |
| `~/.claude.json` | Ignore les écrans de connexion affichés au premier lancement ; avec votre accord, marque le dossier actuel comme fiable. |

### Codex CLI

| Fichier | Modification |
|---|---|
| `~/.codex/evolink.config.toml` | Nouveau fichier. Contient le point de terminaison EvoLink, le modèle par défaut et votre clé. Vous seul pouvez le lire. |
| `~/.codex/config.toml` | Non modifié. |

### Dans les deux cas

- Chaque fichier est sauvegardé dans `~/.evolink/backups/` avant d’être modifié.
- Le script lui-même est enregistré dans `~/.evolink/`, et sa commande est `~/.evolink/bin/evolink-config`. Il ne modifie ni votre PATH ni votre profil de shell.
- Votre clé est stockée uniquement dans les fichiers de configuration de votre ordinateur et n’est envoyée qu’à l’API EvoLink.

<Note>
`evolink-config` configure uniquement la connexion à l’API. C’est un outil différent de l’outil en ligne de commande `evolink`, qui génère des images, des vidéos et de l’audio (voir la section CLI/MCP). Vous pouvez utiliser les deux.
</Note>

## Vérifier, annuler et reconfigurer

### Prévisualiser les modifications (rien n’est écrit)

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --dry-run
```

### Vérifier la configuration actuelle

```bash
~/.evolink/bin/evolink-config doctor
```

Votre clé est masquée dans la sortie : vous pouvez donc l’envoyer telle quelle au support. Pour Codex, utilisez `~/.evolink/bin/evolink-config doctor codex`.

### Annuler la configuration

```bash
~/.evolink/bin/evolink-config reset
```

Le script rétablit tout ce qu’il a modifié. Pour Codex, utilisez `~/.evolink/bin/evolink-config reset codex`.

### Changer de clé ou de modèle par défaut

Exécutez à nouveau la commande de configuration.

## FAQ

### 1. Que faire si Node.js est introuvable ?

Installez la version LTS depuis le [site de Node.js](https://nodejs.org/), ouvrez un nouveau terminal et exécutez à nouveau la commande de configuration.

### 2. J’ai déjà tout configuré à la main. Mes paramètres seront-ils écrasés ?

Pas en bloc. Le script modifie uniquement les éléments listés ci-dessus et conserve tout le reste. Avant d’écrire, il affiche l’ancienne et la nouvelle valeur de chaque élément et sauvegarde le fichier d’origine.

### 3. Pourquoi n’y a-t-il pas de mode automatique (auto mode) dans Claude Code ?

En mode automatique, Claude Code ne vous demande plus votre accord avant chaque commande. À la place, il envoie d’abord une requête de vérification, et un modèle décide si la commande peut être exécutée sans risque. Ces requêtes de vérification sont facturées au token comme toute autre requête. Elles utilisent `claude-sonnet-5`, quel que soit le modèle par défaut que vous avez choisi.

Pour éviter des frais inattendus, le script désactive le mode automatique par défaut, et Claude Code vous demande votre accord avant d’exécuter une commande. Le script vous le rappelle aussi à la fin de la configuration.

Si vous voulez le mode automatique, activez-le ainsi :

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --auto-mode
```

Pour le désactiver de nouveau, exécutez encore une fois la commande de configuration sans `--auto-mode`.

### 4. Puis-je lire le script avant de l’exécuter ?

Oui. Téléchargez-le, lisez-le, puis exécutez-le :

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh -o setup.sh
less setup.sh
bash setup.sh
```

### 5. Que faire si le message « Rate limited (429) » s’affiche ?

Chaque compte ne peut vérifier sa clé qu’un nombre limité de fois par minute. Si vous exécutez le script plusieurs fois de suite, ce message s’affiche. Attendez le nombre de secondes indiqué dans le message, puis exécutez à nouveau le script.

### 6. Que faire si cela ne fonctionne toujours pas après la configuration ?

Exécutez `~/.evolink/bin/evolink-config doctor` et envoyez la sortie au support. Vous pouvez aussi consulter les sections de dépannage des pages [Claude Code CLI](/fr/integration-guide/claude-code-cli) et [Codex CLI](/fr/integration-guide/codex-cli).
