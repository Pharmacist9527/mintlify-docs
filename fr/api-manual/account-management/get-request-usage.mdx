description: "Consulter, par Request ID, le statut, l'utilisation et le coût réel des appels d'API synchrones, principalement aux modèles de texte"
openapi: /fr/api-manual/account-management/get-request-usage.json GET /v1/requests/{request_id}
---

<Note>
Cet endpoint permet de consulter le coût des **appels d'API synchrones**, principalement aux **modèles de texte** via les interfaces Chat Completions, Messages et Responses.

Utilisez comme Request ID la valeur de l'en-tête `X-Request-Id` de la réponse initiale. Attendez un moment après la fin de la requête avant de la consulter. Pour les tâches asynchrones, utilisez [Consulter le statut d'une tâche](/fr/api-manual/task-management/get-task-detail).
</Note>
