<Note>
  Midjourney dispose d’un système de modération de contenu intégré. Chaque image est modérée individuellement : les images filtrées n’apparaissent pas dans les résultats et les autres images sont livrées normalement, vous pouvez donc recevoir moins d’images que d’habitude. Si au moins une image est validée, la tâche est `completed` et facturée normalement ; si toutes les images sont filtrées, la tâche se termine en `failed` et les crédits réservés sont intégralement remboursés. Veuillez vous assurer que vos prompts et vos images de référence respectent les directives de contenu.
</Note>
