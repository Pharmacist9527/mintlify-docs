<Note>
  Midjourney dispose d’un système de modération de contenu intégré. Chaque image est modérée individuellement : si certaines images générées sont filtrées, leurs emplacements sont renvoyés vides, les autres images sont livrées normalement et les crédits consommés pour cette requête ne sont pas remboursés. Veuillez vous assurer que vos prompts respectent les directives de contenu.
</Note>
