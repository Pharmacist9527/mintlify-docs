<Note>
Midjourney V7 Inpaint (`mj-v7-inpaint`) a été retiré le 21 octobre 2026 à la suite d’un changement de politique de notre fournisseur amont. Les requêtes renvoient désormais HTTP 410 (`mj_v7_inpaint_discontinued`) et ne sont pas facturées. Pour repeindre une partie d’une image, utiliser cette interface (`mj-v7-upload-paint`).
</Note>

<Note>
Midjourney dispose d'un système de modération de contenu intégré. Si certaines images générées sont filtrées par la modération, les crédits consommés pour cette requête ne seront pas remboursés. Veuillez vous assurer que vos prompts respectent les directives de contenu.
</Note>
