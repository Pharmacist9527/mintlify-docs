## Aperçu des paramètres

| Paramètre | Syntaxe | Type | Plage | Par défaut | Description |
|-----------|---------|------|-------|------------|-------------|
| Rapport d'aspect | `--ar W:H` | Ratio entier | Tout ratio d'entiers positifs | 1:1 | Rapport d'aspect de l'image |
| Chaos | `--c N` | int | 0 - 100 | 0 | Diversité des résultats générés |
| Seed | `--seed N` | int | 0 - 4294967295 | Aléatoire | Fixer le seed pour des résultats reproductibles |
| Stylisation | `--s N` | int | 0 - 1000 | 100 | Intensité du style artistique |
| Expérimental | `--exp N` | int | 0 - 100 | 0 | Effet esthétique, cumulable avec la stylisation |
| Mode Raw | `--raw` | Drapeau | — | Désactivé | Désactiver l'embellissement par défaut |
| Poids de l'image | `--iw N` | float | 0 - 3 | 1 | Influence du prompt image |
| Référence de style | `--sref [URL]` | URL | — | — | Correspondre au style visuel |
| Poids du style | `--sw N` | int | 0 - 1000 | 100 | Force de la référence de style |
| Mosaïque | `--tile` | Drapeau | — | Désactivé | Générer des motifs répétitifs sans couture |
| Weird | `--weird N` / `--w N` | int | 0 - 3000 | 0 | Esthétique non conventionnelle et expérimentale |

<Note>
Trois réglages ne s'écrivent **pas** dans le prompt — ils sont contrôlés via l'API (les écrire dans le prompt n'a aucun effet, les drapeaux sont retirés) :

- **Vitesse** (`draft` / `fast` / `turbo`) → `model_params.speed`
- **Qualité de sortie** (`standard` / `hd`) → paramètre de premier niveau `quality`
- **Niveau de détail** (`1` – `4`) → `model_params.detail`

`--v` / `--version` est verrouillé sur V8.2 et `--niji` n'est pas pris en charge. Voir ci-dessous [Modes de vitesse](#modes-de-vitesse), [Qualité de sortie](#qualité-de-sortie) et [Niveau de détail](#niveau-de-détail).
</Note>

## Paramètres de base

### Rapport d'aspect `--ar`

Définit le rapport d'aspect de l'image. Seuls les ratios entiers sont pris en charge.

```
un chat --ar 16:9
```

Valeurs courantes : `1:1`, `4:3`, `3:2`, `16:9`, `9:16`, `2:3`. Les ratios extrêmes peuvent produire des résultats imprévisibles.

### Chaos `--chaos` / `--c`

Contrôle la diversité des résultats générés. Des valeurs plus élevées produisent de plus grandes différences entre les 4 images.

```
un chat --c 50
```

| Plage | Effet |
|-------|-------|
| 0 | Les 4 images sont très similaires (par défaut) |
| 1-50 | Diversité modérée |
| 50-100 | Hautement aléatoire, adapté à l'exploration créative |

### Stylisation `--stylize` / `--s`

Ajuste l'équilibre entre réalisme et style artistique.

```
un chat --s 500
```

| Plage | Effet |
|-------|-------|
| 0-250 | Style réaliste, fidèle au prompt |
| 250-750 | Équilibré |
| 750-1000 | Expression artistique forte, couleurs et composition audacieuses |

### Expérimental `--exp`

Similaire à `--stylize` mais cumulable, génère des images plus détaillées, dynamiques et créatives.

```
un chat --exp 25
```

- Valeurs recommandées : 5, 10, 25, 50, 100
- Changements d'effet notables de 5 à 50, rendements décroissants de 50 à 100
- Peut remplacer les effets de `--stylize` au-dessus de 25-50

### Mode Raw `--raw`

Désactive l'embellissement par défaut pour une adhérence plus stricte aux détails du prompt. Adapté au photoréalisme ou aux scénarios de contrôle précis.

```
photo de produit --raw
```

### Seed `--seed`

Fixe l'état aléatoire initial pour les tests comparatifs.

```
un chat --seed 23453422
```

- Plage : 0 - 4294967295
- Même seed + même prompt → résultats similaires (non identiques)

## Paramètres de référence d'image

### Prompt image

Placez les URL d'images au **début** du prompt pour influencer le contenu généré.

```
https://example.com/ref.jpg description textuelle --iw 1.5
```

**Règles de combinaison valides :**

| Combinaison | Valide ? |
|-------------|----------|
| 1 image + pas de texte | Invalide (provoquera une erreur) |
| 1 image + description textuelle | Valide |
| 2+ images + pas de texte | Valide |
| 2+ images + description textuelle | Valide |

- Maximum 20 prompts image
- Formats pris en charge : `.png`, `.gif`, `.webp`, `.jpg`, `.jpeg`
- Non disponible avec la vitesse `draft` (utilisez `fast`)

### Poids de l'image `--iw`

Contrôle l'influence des prompts image sur le résultat. Plage 0 - 3, par défaut 1. Des valeurs plus élevées produisent des résultats plus proches de l'image de référence.

```
https://example.com/ref.jpg paysage aquarelle --iw 2.0
```

### Référence de style `--sref`

Correspond au style visuel (couleurs, textures, éclairage) de l'image de référence sans copier le contenu. **Doit être utilisé avec un prompt textuel**.

```
un chat --sref https://example.com/style.jpg
```

- Plusieurs prises en charge : `--sref URL1 URL2`
- Style aléatoire pris en charge : `--sref random` (renvoie un code numérique après génération, réutilisable)
- Maximum 20 srefs

### Poids du style `--sw`

Contrôle l'influence de la référence de style. Plage 0 - 1000, par défaut 100.

```
un chat --sref https://example.com/style.jpg --sw 500
```

## Modes de vitesse

Le mode de vitesse est contrôlé via le champ API `model_params.speed` (n'écrivez pas `--draft` / `--fast` dans le prompt).

| Mode | Description | Coût |
|------|-------------|------|
| `draft` | Renvoie 24 images d'esquisse légères en 0.5K en une seule exécution. Uniquement pour le point de terminaison de génération d'images. | Même multiplicateur que fast |
| `fast` | Mode standard (par défaut), 4 images par génération | Standard |
| `turbo` | Mode turbo, génération plus rapide, 4 images par génération | 2x |

<Note>
Contrairement à V7, le mode `draft` de V8.2 n'est **pas** à moitié prix — il utilise le même multiplicateur que `fast`. Le mode draft renvoie 24 petites esquisses en une seule exécution ; choisissez celles que vous préférez et relancez-les en pleine qualité. Le mode draft ne peut pas être combiné avec la qualité `hd`.
</Note>

## Qualité de sortie

La résolution de sortie est contrôlée via le paramètre de premier niveau `quality`, et **non** par un drapeau de prompt. N'écrivez pas `--hd` dans le prompt.

| Valeur | Résolution | Coût |
|--------|------------|------|
| `standard` | Résolution standard (par défaut) | 1x |
| `hd` | Sortie HD native 2K | 1.5x |

- Le multiplicateur de qualité est **combiné (multiplié)** avec le multiplicateur de vitesse.
- `hd` est **incompatible** avec la vitesse `draft`.

## Niveau de détail

Le niveau de détail est contrôlé via le champ `model_params.detail` de l'API, **pas** par un drapeau de prompt. N'écrivez pas `--q` / `--quality` dans le prompt.

| Valeur | Description | Coût |
|--------|-------------|------|
| `1` | Détail par défaut | 1x |
| `2` – `4` | Détails progressivement plus riches, temps de rendu plus long | 1x (sans surcoût) |

- Correspond au `--quality N` natif de Midjourney ; V8.2 accepte 1 / 2 / 3 / 4 (V8.1 n'acceptait que 1 / 4).
- Uniquement pour le point de terminaison de génération d'images ; les tâches dérivées héritent de l'image source.
- Le niveau de détail ne change **pas** le prix.

## Dépendances

Les paramètres suivants nécessitent d'autres paramètres pour prendre effet :

| Paramètre | Prérequis |
|-----------|-----------|
| `--sw` | Nécessite `--sref` |
| `--iw` | Nécessite un prompt image |
| `--sref` | Nécessite un prompt textuel |
| Prompt image unique | Nécessite un prompt textuel |

---

## Conflits

| Paramètre A | Paramètre B | Description |
|-------------|-------------|-------------|
| Vitesse `draft` | Qualité `hd` | Le mode draft ne peut pas être combiné avec HD |
| Vitesse `draft` | Prompt image / `--sref` | Les références d'image nécessitent `fast` |
| Prompt image uniquement | `--stylize` / `--exp` | Incompatible sans texte |
| `--exp` > 25 | `--stylize` | Un `--exp` élevé peut supprimer `--stylize` ; abaissez `--exp` lors de leur combinaison |

## Paramètres non pris en charge dans V8.2

V8.2 ne retire que les drapeaux qui fausseraient le verrouillage de version ou la facturation ; **tous les autres drapeaux sont transmis tels quels au fournisseur**. Si le fournisseur ne prend pas en charge un drapeau, la tâche échoue avec le message d'erreur du fournisseur et les crédits réservés sont remboursés — rien n'est ignoré silencieusement.

| Paramètre | Traitement |
|-----------|------------|
| `--v` / `--version` / `--niji` | Retiré — la version est verrouillée sur V8.2 |
| `--fast` / `--turbo` / `--draft` / `--relax` | Retiré — utilisez `model_params.speed` |
| `--hd` | Retiré — utilisez le paramètre de premier niveau `quality` |
| `--bs` / `--batchsize` | Retiré — la taille de lot n'est pas configurable |
| `--q` / `--quality` | Retiré — utilisez `model_params.detail` |
| `--oref` / `--ow` | Rejeté par le fournisseur (non pris en charge sur V8.2) |
| `--cref` / `--cw` | Rejeté par le fournisseur (non pris en charge sur V8.2) |
| `--stop` | Rejeté par le fournisseur |
| Multi-prompt `::` | Rejeté par le fournisseur |
| `--sv` | Seul `--sv 6` est accepté, et uniquement avec `--sref` |
| `--repeat` / `--r`, permutations `{}`, `--stealth` / `--public` | Non pris en charge via API |

## Directives de format de prompt

### Structure de base

```
[URL d'image] description textuelle --param1 valeur1 --param2 valeur2
```

### Règles d'écriture

- Les paramètres se placent à la **fin** du prompt textuel
- Un **espace** est requis avant `--`
- Ne pas utiliser de ponctuation dans les paramètres
- Aucun texte ne peut suivre après les paramètres

### Exemples

<CodeGroup>
```text Correct
a yellow Persian cat --ar 1:2 --s 500
```

```text Incorrect
a yellow Persian cat--ar 2:3          ← espace manquant avant --
a yellow Persian cat - - ar 2:3       ← espace entre --
a yellow Persian cat --ar 2:3, --s 50 ← ponctuation dans les paramètres
a yellow Persian cat --ar 2:3 more description ← texte après les paramètres
```
</CodeGroup>

## Avis de modération de contenu

<Note>
Midjourney dispose d'un système de modération de contenu intégré. Si certaines images générées sont filtrées par la modération, les crédits consommés pour cette requête ne seront pas remboursés. Veuillez vous assurer que vos prompts respectent les directives de contenu.
</Note>
