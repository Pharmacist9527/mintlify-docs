Qwen Audio 3.1 TTS Flash choisit la voix avec le paramètre `voice` de l’[API de synthèse vocale](/fr/api-manual/audio-series/qwen-audio-tts/qwen-audio-3.1-tts-flash). Les **68** voix système sont utilisables directement, sans création préalable.

- `voice` est **sensible à la casse** ; recopiez exactement la valeur indiquée
- Sans `voice`, la voix par défaut est `longanhuan_v3.1`
- Utilisez la colonne `voice` dans les requêtes ; noms, genre, qualités vocales et usages vous aident à choisir
- Le texte doit être dans une langue prise en charge par la voix, sinon la prononciation peut être incorrecte ou la parole peu naturelle

## Exemples

Envoyez ce corps de requête à `POST /v1/audios/generations`, en remplaçant `voice` par l’ID souhaité. Paramètres complets et consultation des tâches : [API de synthèse vocale](/fr/api-manual/audio-series/qwen-audio-tts/qwen-audio-3.1-tts-flash).

<CodeGroup>
```json Voix chinoise
{
  "model": "qwen-audio-3.1-tts-flash",
  "prompt": "欢迎使用语音合成，让文字变成自然流畅的声音。",
  "voice": "longanhuan_v3.1"
}
```

```json Voix anglaise
{
  "model": "qwen-audio-3.1-tts-flash",
  "prompt": "Welcome to our audio guide. Let us turn your words into speech.",
  "voice": "Emily_v3.1",
  "language": "en"
}
```
</CodeGroup>

<Tip>
  Toutes les voix acceptent `instruction` et des balises émotionnelles dans le texte, comme `[excited]` et `[laughing]`, pour contrôler émotion et ton. Consultez les paramètres `prompt` et `instruction` de l’[API de synthèse vocale](/fr/api-manual/audio-series/qwen-audio-tts/qwen-audio-3.1-tts-flash).
</Tip>

## Voix personnalisées

Créez votre voix avec [Voice Enrollment](/fr/api-manual/audio-series/qwen-audio-tts/voice-enrollment) : un enregistrement pour la cloner, ou une description pour la concevoir. Une fois la tâche terminée, passez le nom complet `voice` renvoyé à l’API de synthèse.

- Seul le compte créateur peut utiliser une voix personnalisée
- Expiration par défaut **6 heures** après la fin de la création ; la synthèse ne prolonge pas cette durée
- Après expiration, la synthèse renvoie `404` (`voice_expired`) ; créez une nouvelle voix avec Voice Enrollment
- Les voix de l’ancien `qwen-voice-design` ne sont pas compatibles ; recréez-les avec Voice Enrollment lors de la migration
