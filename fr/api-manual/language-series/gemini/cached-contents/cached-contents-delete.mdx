---
title: "Gemini Cache explicite du contexte - Supprimer un cache"
openapi: '/fr/api-manual/language-series/gemini/cached-contents/cached-contents.json DELETE /v1beta/cachedContents/{id}'
---

<Note>
Supprime immédiatement le cache ; renvoie l’objet vide `{}` en cas de succès. Toute référence ultérieure renvoie 404 `CACHE_NOT_FOUND`. La suppression est gratuite, mais **le stockage payé à la création n’est pas remboursé**.
</Note>

- Sans suppression manuelle, le cache est supprimé automatiquement à `expireTime`. Une suppression anticipée le libère sans remboursement.
- Pour les concepts, la facturation et les erreurs, voir [Créer un cache](/fr/api-manual/language-series/gemini/cached-contents/cached-contents-create).
