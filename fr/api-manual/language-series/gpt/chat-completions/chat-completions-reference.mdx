<Note>
**BaseURL** : La BaseURL par défaut est `https://direct.evolink.ai`, qui offre une meilleure prise en charge des modèles de texte et des connexions persistantes. `https://api.evolink.ai` est le point d'accès principal pour les services multimodaux et sert d'adresse de secours pour les modèles de texte.
</Note>

<Note>
**Les outils côté serveur** (recherche web, exécution de code, recherche documentaire, MCP) ne sont proposés que sur l'[API Responses](../responses/responses-reference). Le point de terminaison Chat Completions ne prend en charge que les appels d'outils `function` ordinaires.
</Note>

<Note>
**GPT-6** : Les appels de fonctions avec Sol / Luna exigent `reasoning_effort: "none"` sur cet endpoint. Utilisez [Responses](../responses/responses-reference) pour les appels de fonctions avec Astra ou le niveau `max` de GPT-6.
</Note>
