<Note>
**BaseURL** : La BaseURL par défaut est `https://direct.evolink.ai`, qui offre une meilleure prise en charge des modèles textuels et des connexions de longue durée. `https://api.evolink.ai` est le point de terminaison principal pour les services multimodaux et sert d'adresse de repli pour les modèles textuels.
</Note>

<Note>
**Le raisonnement est toujours activé sur les modèles Kimi**. Le champ `content` contient généralement des blocs `type="thinking"`, qui comptent dans les tokens de sortie. Évitez une valeur trop basse pour `max_tokens` : le raisonnement pourrait épuiser le budget avant de produire le texte de réponse.
</Note>
