<Note>
**BaseURL** : La BaseURL par défaut est `https://direct.evolink.ai`, qui offre une meilleure prise en charge des modèles textuels et des connexions de longue durée. `https://api.evolink.ai` est le point de terminaison principal pour les services multimodaux et sert d'adresse de repli pour les modèles textuels.
</Note>

Utilisez `POST /v1/responses` et sélectionnez `kimi-k3.1-pro`, `kimi-k3.1-pro-highspeed` ou `kimi-k3` avec `model`. Seuls `model` et `input` sont requis.

<Warning>
**Les noms des paramètres diffèrent de Chat Completions** : utilisez `input` pour l’entrée, `max_output_tokens` pour la limite de sortie et `reasoning.effort` pour l’effort de raisonnement.
</Warning>

## Lire le texte de réponse

Le champ `output` peut contenir du raisonnement, du texte de réponse et des appels d’outils. Parcourez les blocs `output_text` des éléments `type="message"` ; ne supposez pas que le premier élément contient la réponse.

En supposant que le JSON de la réponse a été analysé dans `response`, extrayez le texte ainsi :

```python
text = "".join(
    part["text"]
    for item in response.get("output", [])
    if item.get("type") == "message"
    for part in item.get("content", [])
    if part.get("type") == "output_text"
)
print(text)
```

<Note>
**Réservez un budget de sortie pour le raisonnement** : `max_output_tokens` inclut le raisonnement et la réponse. Si `status="incomplete"` et `incomplete_details.reason="max_output_tokens"`, augmentez la limite. Une fois le budget épuisé, la réponse peut ne contenir que du raisonnement, sans texte de réponse.
</Note>

Pour les appels d’outils, la recherche Web, les images en entrée et les sorties structurées, consultez la [référence complète](/fr/api-manual/language-series/kimi/responses/responses-reference).
