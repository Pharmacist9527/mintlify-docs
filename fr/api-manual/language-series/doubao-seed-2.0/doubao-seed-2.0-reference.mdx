<Note>
**BaseURL** : La BaseURL par défaut est `https://direct.evolink.ai`, qui offre une meilleure prise en charge des modèles de texte et des connexions persistantes. `https://api.evolink.ai` est le point d'accès principal pour les services multimodaux et sert d'adresse de secours pour les modèles de texte.
</Note>

<Note>
Seul `doubao-seed-2-1-lite` accepte l’audio en entrée. Pour la recherche web, utilisez [Responses](/fr/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-responses-reference) ou [Messages](/fr/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-messages-reference) avec Seed 2.1 ou `doubao-seed-evolving`. Chat Completions ne la propose pas.
</Note>
