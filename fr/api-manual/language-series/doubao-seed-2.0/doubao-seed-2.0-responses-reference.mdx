<Note>
**BaseURL** : La BaseURL par défaut est `https://direct.evolink.ai`, qui offre une meilleure prise en charge des modèles de texte et des connexions persistantes. `https://api.evolink.ai` est le point d'accès principal pour les services multimodaux et sert d'adresse de secours pour les modèles de texte.
</Note>

<Note>
Seuls Seed 2.1 et `doubao-seed-evolving` acceptent la recherche web. Chaque recherche effectuée est facturée selon sa source. Le cache explicite entraîne des frais de stockage supplémentaires. Consultez `caching` et `expire_at`. Les deux exemples de cache explicite du menu des requêtes omettent `expire_at`. Le stockage est donc facturé pour la durée par défaut de trois jours.
</Note>

## Générer une requête de cache valable une heure

Exécutez ce code Python juste avant l’envoi et utilisez le JSON affiché comme corps de requête. Laissez `PREVIOUS_RESPONSE_ID` non définie pour la première requête. Pour continuer, affectez-lui l’`id` réellement renvoyé par la requête précédente, puis relancez le code. Chaque exécution recalcule `expire_at`.

```python
import json
import os
import time

body = {
    "model": "doubao-seed-2-1-pro",
    "input": "Manuel du produit : le moteur et la batterie sont garantis deux ans. Retenez cette règle.",
    "caching": {"type": "enabled"},
    "expire_at": int(time.time()) + 3600,
}
previous_id = os.getenv("PREVIOUS_RESPONSE_ID")
if previous_id:
    body["previous_response_id"] = previous_id
    body["input"] = "Quelles pièces sont couvertes par la garantie ?"
print(json.dumps(body, ensure_ascii=False))
```
