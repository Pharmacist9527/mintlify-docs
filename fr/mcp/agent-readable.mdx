## Ce qu’un agent MCP natif doit lire

1. Lisez la [présentation de MCP](/fr/mcp/overview) et la page de configuration du client, puis configurez et autorisez l’hôte.
2. Consultez la [référence des outils MCP](/fr/mcp/tools) et les schémas réels des outils.
3. Si vous le souhaitez, installez les instructions evolink-mcp ou un plugin d’hôte en suivant les [étapes du plugin](/fr/mcp/plugins). Lire des compétences n’enregistre pas les outils et ne les authentifie pas.
4. Appliquez les [règles communes aux agents](/fr/cli-mcp/agent-resources#agent-rules), puis vérifiez les appels réels à l’aide du [dépannage MCP](/fr/mcp/billing#faq).

evolink-cli enseigne les commandes de terminal ; le MCP natif utilise les instructions evolink-mcp pour l’utilisation des outils. Vérifiez séparément l’installation et l’authentification. llms.txt est un index de la documentation ; le point de terminaison MCP reste https://mcp.evolink.ai/mcp.
