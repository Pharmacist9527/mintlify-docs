La conversation ChatGPT utilise le **MCP distant**. Configurez-le dans le client et dans le navigateur ; ni installation locale de la CLI ni clé API personnelle ne sont nécessaires.

## Avant de commencer

Munissez-vous d’un compte EvoLink et d’un compte ChatGPT, ainsi que d’une version du client, d’un forfait et d’une permission d’espace de travail qui autorisent les MCP personnalisés. Si l’action d’ajout n’est pas disponible, vérifiez d’abord l’accès côté hôte au lieu d’exécuter des instructions de terminal dans la conversation.

## Connecter EvoLink pas à pas

<Steps>

<Step title="Ouvrir l’action MCP personnalisé">

Ouvrez [ChatGPT Plugins](https://chatgpt.com/plugins), choisissez Add ou le bouton plus, puis **Create/Add custom MCP server**. C’est le point d’entrée de configuration utilisé par le site web. Les libellés peuvent varier selon la version ; s’il est absent, vérifiez l’accès de l’espace de travail.

</Step>

<Step title="Saisir les informations de connexion">

| Champ | Valeur |
|---|---|
| Icon / Icône (facultatif) | Téléchargez l’[icône EvoLink](https://cdn.evolink.ai/next/evolink-logo.png) et importez-la ; ignorez cette étape si le formulaire n’a pas de champ d’icône |
| Name / Nom | EvoLink |
| Connection / Connexion | Server URL |
| Server URL / URL du serveur | `https://mcp.evolink.ai/mcp` |
| Authentication / Authentification | OAuth |
| Client ID / Client Secret | Conservez les valeurs par défaut ; n’y saisissez pas de clé API de la plateforme |

Utilisez le HTTP distant et conservez le `/mcp` final. Examinez l’invite de connexion et sélectionnez **Create as a plugin**.

</Step>

<Step title="Installer le plugin et autoriser le compte">

Ouvrez EvoLink dans vos plugins personnels, puis installez-le ou connectez-le. Lorsque l’authentification est demandée, connectez-vous à EvoLink dans le navigateur, vérifiez le compte et les permissions, puis autorisez l’accès. Laissez le flux ouvert, puis revenez à ChatGPT. La création de la configuration et l’installation du plugin sont deux étapes distinctes ; l’action d’autorisation peut apparaître à différents moments.

</Step>

<Step title="L’activer dans une conversation et vérifier">

Démarrez une nouvelle conversation et sélectionnez EvoLink avec `@`. Si votre interface comporte des onglets Chat / Work, passez à **Work** avant de démarrer la conversation avec le plugin. Envoyez le prompt de vérification gratuite ci-dessous.

**Réussite** : le solde réel du compte et les modèles disponibles, et pas seulement une affirmation que la configuration est terminée.

</Step>

</Steps>

Consultez la [documentation OpenAI sur les MCP personnalisés](https://developers.openai.com/api/docs/guides/custom-mcp-server) et le [démarrage rapide des plugins](https://developers.openai.com/plugins/quickstart). Une connexion personnelle ne signifie pas qu’EvoLink figure dans le répertoire public.

## Vérification gratuite et première tâche média

Une fois la connexion établie, envoyez ceci dans une conversation où EvoLink est activé :

```text
Utilise EvoLink pour vérifier le solde de mon compte et rechercher les modèles d’image disponibles. Ne génère rien pour le moment.
```

Confirmez que `check_balance` et `search_models` sont réellement appelés. La connexion au compte et ces consultations ne créent aucune tâche média payante. Pour générer, décrivez le contenu et les spécifications, examinez le modèle, les paramètres et l’estimation proposés, puis approuvez explicitement la soumission. Consultez le [premier flux de travail média](/fr/mcp/overview#workflows).

Utilisez des liens de référence accessibles publiquement et pris en charge par le modèle. Une pièce jointe d’une conversation peut ne pas exposer à MCP les octets du fichier d’origine, et le service distant ne peut pas lire les chemins de votre ordinateur. Consultez [Références et importations](/fr/mcp/overview#files).

## Problèmes courants

| Symptôme | Prochaines étapes |
|---|---|
| Aucune action de connecteur personnalisé | Vérifiez le forfait, la version et les permissions de l’espace de travail dans l’hôte actuel |
| Toujours non autorisé après la connexion dans le navigateur | Revenez au client d’origine et terminez le flux en cours ; voir le [dépannage de l’autorisation](/fr/mcp/billing#login) |
| Connexion ajoutée mais aucun outil dans la conversation | Vérifiez l’état d’installation et d’activation, sélectionnez EvoLink, ouvrez une nouvelle conversation ; voir le [dépannage MCP](/fr/mcp/billing#mcp-connection) |
| Le solde fonctionne mais l’outil de génération est indisponible | Examinez les options d’activation des outils de l’hôte et les permissions de l’espace de travail ; ne les contournez pas avec une clé |
| Délai réseau dépassé ou 403 | Déterminez si l’échec se situe dans l’hôte, sur la page de connexion ou dans la requête d’outil ; conservez l’heure et l’erreur pour le support |
| Le résultat est un lien ou un aperçu gris | Ouvrez et enregistrez l’original ; voir le [dépannage des téléchargements et des aperçus](/fr/mcp/billing#download) |

## Actualiser et déconnecter

Après une modification, actualisez la connexion et les outils, ou ouvrez une nouvelle conversation. Si nécessaire, renouvelez l’autorisation depuis cet hôte. Pour mettre fin à l’accès de ce client, déconnectez EvoLink ou déconnectez-vous dans ses paramètres. Gérez les limites et la mise en pause de la clé partagée dans EvoLink. Consultez [Plugins](/fr/mcp/plugins) et [Coûts et dépannage](/fr/mcp/billing#faq).
