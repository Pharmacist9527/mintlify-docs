## Choisir une connexion MCP

| Connexion | Installation ou connexion | Authentification | Pour |
|---|---|---|---|
| MCP distant | https://mcp.evolink.ai/mcp | OAuth dans le navigateur | Conversation sur le web et clients MCP natifs |
| MCP local | npx démarre @evolinkai/mcp | Clé API de la plateforme | Clients stdio et importations locales autorisées |

Le MCP distant ne nécessite pas le paquet MCP local. Installer la CLI n’enregistre pas de serveur MCP natif. Installer une compétence ne vous connecte pas à votre compte et ne connecte pas les outils.

## Guides CLI distincts pour les agents de terminal

Pour les terminaux, les scripts, Gemini CLI, OpenCode et GitHub Copilot CLI, suivez la [configuration d’EvoLink CLI](/fr/cli/setup#cli-install) pour l’installation, la connexion, les cibles de compétences et la vérification gratuite. Les agents qui exécutent des commandes peuvent utiliser la CLI ; configurez le MCP natif à l’aide des instructions pour le mode distant ou local ci-dessous.

<span id="ssh-login" />

### Connexion sous Linux et par SSH

Lorsque la CLI s’exécute à distance mais que votre navigateur est local, suivez le [transfert du rappel SSH](/fr/cli/setup#ssh-login) après avoir satisfait aux exigences de stockage sécurisé des identifiants de connexion sous Linux. Les rappels du MCP distant sont gérés par l’hôte et n’utilisent pas les étapes de transfert de la CLI.

## MCP stdio local avec une clé API

Un client limité à stdio peut lancer un processus MCP local. Il lui faut **Node.js 20+** et une clé API personnelle, au lieu de l’OAuth dans le navigateur du MCP distant.

<Steps>

<Step title="Préparer Node et une clé dédiée">

```bash
node --version
npx --version
```

Les deux commandes doivent fonctionner avec Node 20 ou une version ultérieure. Créez une clé personnelle dédiée, assortie de limites, dans [Clés API](https://evolink.ai/dashboard/keys). Fournissez `EVOLINK_API_KEY` par l’environnement sécurisé du client ou par ses paramètres de secrets, et non dans la conversation de l’agent, dans des captures d’écran partagées ou dans un dépôt.

</Step>

<Step title="Configurer le lanceur local">

Choisissez local/stdio dans les paramètres MCP du client :

```text
command: npx
args: -y @evolinkai/mcp@latest
```

Au premier lancement, npx récupère le paquet. L’hôte communique par stdio et le processus local appelle l’API de la plateforme. Assurez-vous que l’hôte peut trouver npx ; une application graphique peut avoir un environnement différent de celui de votre terminal. `YOUR_API_KEY` ci-dessous est une valeur fictive destinée à une configuration locale privée. Préférez l’héritage de l’environnement lorsqu’il est pris en charge.

```json
{
  "mcpServers": {
    "evolink": {
      "command": "npx",
      "args": ["-y", "@evolinkai/mcp@latest"],
      "env": {"EVOLINK_API_KEY": "YOUR_API_KEY"}
    }
  }
}
```

</Step>

<Step title="Autoriser des répertoires lorsque des fichiers locaux sont nécessaires">

Pour les importations par chemin local, définissez `EVOLINK_UPLOAD_ALLOWED_DIRS` dans l’environnement du processus avec les répertoires absolus autorisés. Séparez plusieurs répertoires par `:` sous macOS/Linux ou par `;` sous Windows. Sans ce réglage, les importations par chemin local sont désactivées. Le MCP distant n’accepte jamais `file_path`.

Ce réglage contrôle l’accès aux fichiers locaux, et non les limites de format, de durée ou de taille du modèle. L’utilisation d’une URL ou du base64 ne nécessite pas d’accès à des répertoires locaux.

</Step>

<Step title="Recharger et vérifier les outils gratuits">

Enregistrez la configuration, activez EvoLink, puis rechargez ou ouvrez une nouvelle session selon ce qu’exige votre hôte. Demandez-lui d’appeler `check_balance` et `search_models` et confirmez que les résultats sont réels. Démarrer un processus ou lister des outils ne suffit pas à vérifier le compte.

Le stdio local ne fournit pas les outils d’importation à usage unique du MCP distant, `prepare_upload` / `get_upload`. Examinez la réponse `tools/list` réelle. La clé personnelle a ses propres limites, et non celles de la clé OAuth.

</Step>

</Steps>

### Configuration de Claude Code et de Codex

Lorsque la clé est déjà fournie par l’environnement sécurisé, Claude Code peut effectuer l’enregistrement avec cette commande à la place de l’exemple JSON :

```bash
claude mcp add --scope user evolink -- npx -y @evolinkai/mcp@latest
```

Codex peut fusionner cette section pour hériter des variables de son environnement de démarrage :

```toml
[mcp_servers.evolink]
command = "npx"
args = ["-y", "@evolinkai/mcp@latest"]
env_vars = ["EVOLINK_API_KEY", "EVOLINK_UPLOAD_ALLOWED_DIRS"]
```

Après une mise à jour, rechargez et examinez la version réelle. `@latest` ne remplace pas un processus déjà en cours d’exécution. Consultez le [dépannage centralisé](/fr/mcp/billing#mcp-connection) pour les échecs de démarrage, de clé et de chemin local.

## Autres clients MCP distants

Le client doit prendre en charge Streamable HTTP, OAuth et les rappels du navigateur. Un client limité à des clés statiques ou à stdio doit utiliser le MCP local décrit plus haut.

<Steps>

<Step title="Ajouter le serveur">

Créez une connexion MCP nommée EvoLink avec Streamable HTTP et cette URL :

```text
https://mcp.evolink.ai/mcp
```

Ne saisissez ni une URL de documentation, ni une URL `/v1` de la plateforme, ni une commande npx.

</Step>

<Step title="Terminer l’autorisation OAuth et activer les outils">

Choisissez OAuth, utilisez l’action de connexion du client, autorisez l’accès dans le navigateur, puis revenez au client. Confirmez que la connexion et les outils sont activés. Une clé API statique n’est pas le jeton OAuth de cette connexion.

</Step>

<Step title="Vérifier gratuitement">

```text
Utilise EvoLink pour vérifier mon solde et rechercher les modèles d’image disponibles. Ne génère rien pour le moment.
```

Une fois que vous obtenez des résultats réels pour le solde et les modèles, suivez le [premier flux de travail média](/fr/mcp/overview#workflows). Une liste d’outils sans appels réussis nécessite encore un dépannage de l’autorisation.

</Step>

</Steps>
