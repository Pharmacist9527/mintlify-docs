Claude Code peut exécuter des tâches média avec EvoLink CLI. Cette page décrit ce qui est propre à cet hôte en matière d’environnement et de compétence ; la procédure commune complète se trouve dans [Installation et connexion](/fr/cli/setup). Pour les outils natifs, utilisez directement le [guide MCP](/fr/mcp/claude-code).

## Demander à votre agent de procéder à l’installation

Collez le texte suivant dans la conversation de l’agent. Il est identique au prompt du site web. Effectuez vous-même la connexion dans le navigateur et l’examen des permissions.

```text
Configure EvoLink pour que je puisse créer directement ici des images, des vidéos et de l’audio.
1. Installe la CLI : exécute `npm install -g @evolinkai/cli`.
2. Connecte-toi : exécute `evolink auth login`.
3. Installe la compétence associée : exécute `evolink skills install`.
4. Vérifie la connexion et confirme que je peux commencer une fois la vérification réussie.
```

## Trois étapes pour ce client

<Steps>
  <Step title="Effectuer l’installation commune et la connexion">
    Exécutez les commandes dans l’environnement Claude Code actuel ; actualisez les compétences ou démarrez une nouvelle session pour confirmer la détection.

    Pour une première installation, ouvrez le [guide en cinq étapes](/fr/cli/setup#cli-install) : vérifiez Node.js 22+, installez la CLI et effectuez la connexion dans le navigateur. Il contient les commandes, les indicateurs de réussite et le dépannage. Si c’est déjà fait, vérifiez :

    ```bash
    evolink --version
    evolink auth status --json
    ```

    Vous devez obtenir une version de la CLI et authenticated: true. Selon l’étape en échec, consultez [Erreurs d’installation](/fr/cli/billing#cli-install), [Erreurs de connexion](/fr/cli/billing#login) ou [Rappels SSH](/fr/cli/setup#ssh-login).
  </Step>
  <Step title="Synchroniser la compétence de cet agent et vérifier sa détection">
    ```bash
    evolink skills install --agent claude-code
    evolink skills status --agent claude-code --json
    ```

    Le répertoire est ~/.claude/skills/evolink-cli. current: true signifie que les fichiers correspondent à la CLI. Demandez à l’agent :

    ```text
    Confirme que cette session peut détecter et lire la compétence evolink-cli. Vérifie l’accès sans générer de média.
    ```

    assistant_discovery: not_checked exige encore une vérification par l’hôte. Suivez [Détection des compétences](/fr/cli/billing#skills-discovery) si les fichiers existent mais ne sont pas utilisés. Examinez les permissions d’exécution requises et conservez les modifications personnelles.
  </Step>
  <Step title="Vérifier gratuitement avant de créer des médias">
    ```bash
    evolink balance --json
    evolink doctor --agent claude-code --json
    ```

    La configuration est terminée lorsque balance renvoie les données du compte, que doctor indique true pour ok, connection_verified et model_discovery_verified, et que l’agent confirme avoir lu la compétence. Ces consultations ne créent aucune tâche média payante. Un solde nul permet tout de même de vérifier la connexion.
  </Step>
</Steps>

### Configuration combinée pour une CLI déjà installée

```bash
evolink setup --agent claude-code --json
```

Cette commande vérifie l’environnement, synchronise les compétences, lance la connexion si nécessaire et vérifie l’accès. Vous devez obtenir setup_complete: true ; la détection par l’hôte doit encore être confirmée. Utilisez phase, steps, error et recovery pour identifier les échecs.

## Mise à jour et déconnexion

À partir de la CLI 0.10.0, la CLI annonce elle-même les nouvelles versions ; voir [Comment savoir qu’une nouvelle version existe](/fr/cli/setup#update-check). Après avoir mis à jour la CLI, synchronisez la compétence de l’agent actuel :

```bash
npm install -g @evolinkai/cli@latest
evolink --version
evolink skills install --agent claude-code
evolink skills status --agent claude-code --json
```

Les modifications locales sont conservées ; traitez les états `modified` ou `conflict` en suivant le [dépannage des compétences](/fr/cli/billing#skills-discovery). N’exécutez la commande suivante que lorsque vous voulez vous déconnecter de la CLI ; ce n’est pas une étape d’installation ni de mise à jour.

```bash
evolink auth logout
```

## Points de départ pour le dépannage

| Symptôme | Prochaine étape |
|---|---|
| npm ou evolink introuvable, permissions, délai d’installation dépassé | [Environnement et installation](/fr/cli/billing#cli-install) |
| Le navigateur ne s’est pas ouvert, délai OAuth dépassé, erreur de stockage des identifiants de connexion | [Connexion et rappels](/fr/cli/billing#login) ; [Connexion par SSH](/fr/cli/setup#ssh-login) |
| Compétence installée mais non utilisée par l’agent | [Détection des compétences et permission d’exécution](/fr/cli/billing#skills-discovery) |
| La tâche soumise a dépassé le délai ou le résultat a été perdu | [Reprendre la tâche initiale](/fr/cli/billing#tasks-and-recovery) |

Une fois connecté, suivez le [premier flux de travail média](/fr/cli/workflows#workflows) : examinez les modèles, les paramètres et les coûts, approuvez, puis soumettez. Les commandes complètes se trouvent dans la [référence des commandes de la CLI](/fr/cli/reference).
