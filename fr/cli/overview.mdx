Utilisez la [présentation CLI/MCP](/fr/cli-mcp/overview) pour choisir selon votre client. Les ressources communes de cette section couvrent les coûts, les tâches, les fichiers et les instructions destinées aux agents.

EvoLink CLI permet aux agents disposant d’un accès au terminal et aux utilisateurs du terminal de générer des images, des vidéos, de la musique et de la voix, d’examiner les modèles et leurs paramètres, de consulter le solde et les tâches, d’importer des références et d’enregistrer les originaux.

Cette section décrit la version publiée **CLI 0.14.1**. Elle nécessite Node.js 22+ sous macOS, Windows ou Linux. Installez-la sous l’utilisateur et sur la machine où l’agent exécute les commandes. Les médias suivent le chemin **agent/terminal → CLI → API de la plateforme**.

## Installation et vérification

Envoyez ce prompt à un agent disposant d’un accès au terminal. Il est identique au prompt d’installation du site web :

```text
Configure EvoLink pour que je puisse créer directement ici des images, des vidéos et de l’audio.
1. Installe la CLI : exécute `npm install -g @evolinkai/cli`.
2. Connecte-toi : exécute `evolink auth login`.
3. Installe la compétence associée : exécute `evolink skills install`.
4. Vérifie la connexion et confirme que je peux commencer une fois la vérification réussie.
```

Collez le prompt dans la conversation ; les commandes s’exécutent dans le terminal de l’agent ou dans le vôtre. Effectuez vous-même la connexion dans le navigateur et accordez vous-même les permissions. Consultez [Installation et connexion](/fr/cli/setup) pour les étapes détaillées, les indicateurs de réussite, les mises à jour, la déconnexion et les rappels SSH.

La séquence manuelle de base est la suivante :

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
evolink doctor --json
```

Attendez que la connexion soit terminée avant de continuer. Ne collez pas tout le bloc en ignorant l’autorisation. Demandez à l’agent de confirmer qu’il a lu evolink-cli. La consultation du solde et les diagnostics ne créent aucune tâche média payante ; commencez à créer une fois la vérification effectuée.

## Capacités de la CLI

| Capacité | Utilisation et guide |
|---|---|
| Environnement et accès | version, auth, setup, doctor ; [installation](/fr/cli/setup) |
| Modèles et paramètres | models search/recommend/show/schema, docs search ; [référence](/fr/cli/reference) |
| Estimation et accord | estimate crée un devis local ; generate après l’accord ; [flux de travail](/fr/cli/workflows) |
| Médias | Images, vidéos, musique et voix selon les capacités des modèles |
| Références | upload pour les fichiers locaux ; uploads get consulte le reçu d’origine |
| Tâches | get/wait, batch, historique paginé et reprise à partir du devis |
| Téléchargement des originaux | Un résultat ou tous, vérifications de format et reprise par lot |
| Compte et usage | balance et usage historique borné, qui n’est pas une facture complète |
| Compétences | skills install/status et vérifications de détection par l’hôte |

La CLI ne propose ni conversation textuelle générale, ni annulation de file d’attente, ni rechargement du solde, ni gestion des clés, ni montage automatique, ni hébergement de vidéos finalisées. Le développement de code et la modification de fichiers arbitraires sont des capacités de l’agent hôte. Livrez d’abord les originaux générés ; les nouvelles variantes, les modifications ou les nouvelles générations nécessitent l’accord correspondant.

## Première création

```text
Utilise EvoLink pour créer une image publicitaire pour une marque de café.
Recherche d’abord les modèles d’image disponibles, leurs paramètres et leur coût, puis explique ta recommandation et les spécifications de sortie.
Soumets une seule fois après mon accord explicite, enregistre l’identifiant de tâche, puis télécharge l’original et indique-moi le coût réel renvoyé.
```

Suivez le parcours [modèle → références → estimation → accord → tâche → téléchargement](/fr/cli/workflows). L’installation ne vaut pas accord pour une génération payante. Les estimations ne constituent pas le règlement final ; consultez [Coûts et dépannage](/fr/cli/billing).

## CLI et MCP

L’installation de la CLI comprend l’exécutable, les modules métier partagés et la compétence evolink-cli fournie avec elle. Elle n’exige pas de cloner les dépôts MCP ou de plugins et n’enregistre pas le MCP natif. Passport fournit OAuth ; le système d’exploitation stocke les identifiants de connexion de manière sécurisée.

Les sessions de la CLI et du MCP distant sont gérées séparément. L’OAuth du compte partage actuellement les permissions, les limites et l’état de pause de la clé interne. Pour Claude ou ChatGPT sur le web, ou pour appeler les outils natifs, utilisez la [section MCP distincte](/fr/mcp/overview).
