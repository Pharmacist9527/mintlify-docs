Diese Seite behandelt natives MCP in Claude Code. Der Remote-Dienst verwendet Streamable HTTP und Browser-OAuth und benötigt keine EvoLink CLI. Für die Ausführung von Befehlen und Skills nutzen Sie die separate [CLI-Anleitung](/de/cli/claude-code).

## Remote-MCP verbinden

Verwenden Sie für native Werkzeuge **Streamable HTTP + OAuth** mit dieser Server-URL:

```text
https://mcp.evolink.ai/mcp
```

Eine CLI-Installation ist nicht erforderlich. Sichern Sie die vorhandene Konfiguration, fügen Sie nur EvoLink ein und lassen Sie andere Dienste unverändert. Wählen Sie die Registrierung per Befehl oder die manuelle Registrierung.

<Steps>

<Step title="HTTP-Server hinzufügen">

Führen Sie in einem Terminal, in dem Claude Code installiert ist, aus:

```bash
claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp
```

`--scope user` macht diese Verbindung für den aktuellen Benutzer projektübergreifend verfügbar. Das Hinzufügen bestätigt nur, dass die Konfiguration geschrieben wurde.

</Step>

<Step title="In Claude Code anmelden">

Geben Sie in der Unterhaltung in Claude Code den folgenden Sitzungsbefehl ein und wählen Sie die Authentifizierungsaktion von EvoLink:

```text
/mcp
```

Schließen Sie Anmeldung und Zustimmung im Browser ab und prüfen Sie dann die Verbindung in Claude Code. Dieser Sitzungsbefehl ist kein normaler Shell-Befehl.

</Step>

<Step title="Werkzeuge ansehen und kostenlos prüfen">

```bash
claude mcp list
```

Stimmen Sie einer ausstehenden Projektverbindung in Claude Code zu, wenn Sie dazu aufgefordert werden. Senden Sie in einer neuen Sitzung den Prompt zur Prüfung unten und prüfen Sie, ob echte Guthaben- und Modelldaten zurückkommen.

</Step>

</Steps>

Für die Projektkonfiguration fügen Sie dies in `.mcp.json` ein:

```json
{
  "mcpServers": {
    "evolink": {
      "type": "http",
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

Legen Sie diesen Block nicht in `.claude/settings.local.json` ab; der Befehl oben verwaltet den Benutzerbereich. Siehe [Dokumentation von Claude Code](https://code.claude.com/docs/en/mcp).

Senden Sie dies nach der Autorisierung im Chat des Agenten:

```text
Prüfe mit EvoLink mein Kontoguthaben und suche verfügbare Bildmodelle. Generiere noch nichts.
```

**Erfolg**: Tatsächliche Aufrufe von `check_balance` und `search_models` liefern Ergebnisse. Prüfen Sie diese Werkzeuge in der tatsächlichen MCP-Verbindung.

## Updates, Trennen und Fehlerbehebung

EvoLink aktualisiert den gehosteten MCP-Server. Aktualisieren Sie nach Konfigurationsänderungen die tatsächliche Client-Sitzung. Autorisieren Sie bei Bedarf über die OAuth-Aktion dieses Clients erneut. Um die Verbindung zu trennen, deaktivieren oder entfernen Sie EvoLink in den MCP-Einstellungen des Hosts oder melden Sie sich dort ab; behalten Sie andere Server bei.

| Symptom | Maßnahme |
|---|---|
| URL hinzugefügt, aber keine Werkzeuge | Verbindung aktivieren, Autorisierung abschließen, aktualisieren und die Richtlinie der Organisation prüfen |
| 401 oder Authentifizierung erforderlich | Diese MCP-Verbindung erneut autorisieren und die ursprünglichen Auftragskennungen aufbewahren |
| 403 oder Werkzeug verweigert | Host-Berechtigungen, Status von Konto und Key sowie Netzwerkfehler prüfen |
| Zeitüberschreitung oder verlorene Antwort | Den ursprünglichen Vorgang abfragen und wiederaufnehmen, statt neu zu generieren |
| Nur Link oder graue Vorschau | Das Original öffnen und übergeben, ohne es automatisch neu zu erstellen |

Siehe [MCP: Kosten, Zugriff und Fehlerbehebung](/de/mcp/billing#faq). Lesen Sie vor dem Absenden den [Erstellungsablauf](/de/mcp/overview#workflows); die Aufrufformen stehen in der [MCP-Werkzeugreferenz](/de/mcp/tools).
