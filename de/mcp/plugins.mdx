Plugins können die Konfiguration des Remote-MCP zusammen mit Anleitungen für Agenten bündeln. Jeder Host nutzt seinen eigenen Mechanismus für Installation und Autorisierung.

| Einstieg | Installierter Inhalt | Medienausführung |
|---|---|---|
| Benutzerdefiniertes MCP-Plugin für ChatGPT | Eine in ChatGPT erstellte Serververbindung | ChatGPT ruft das Remote-MCP auf |
| Repository-Plugin für Codex | Konfiguration des Remote-MCP von EvoLink und der Skill evolink-mcp | Codex ruft das Remote-MCP auf |
| Repository-Plugin für Claude Code | Konfiguration des Remote-MCP von EvoLink und der Skill evolink-mcp | Claude Code ruft das Remote-MCP auf |
| Mit der CLI gelieferter Skill | Anweisungen und Referenzen von evolink-cli | Der Agent führt die CLI aus, die die API direkt aufruft |
| Eigenständiger Skill evolink-mcp | Nur Anleitung zum Aufruf von MCP | MCP-Konfiguration und Autorisierung sind weiterhin erforderlich |

## Benutzerdefiniertes MCP-Plugin für ChatGPT

Folgen Sie der [Einrichtung für ChatGPT](/de/mcp/chatgpt), um einen benutzerdefinierten MCP-Server hinzuzufügen:

```text
https://mcp.evolink.ai/mcp
```

Wählen Sie OAuth, stimmen Sie bei der Anmeldung im Browser zu und aktivieren Sie EvoLink dann in Ihrer Unterhaltung. ChatGPT verwendet nicht die unten aufgeführten Marketplace-Befehle von Codex und erfordert keine lokale Installation der CLI über npm.

Eine benutzerdefinierte Verbindung bedeutet nicht, dass EvoLink im öffentlichen Plugin-Verzeichnis gelistet ist. Das Erstellen und der Zugriff auf die Generierungswerkzeuge hängen von Ihrem Konto, der Host-Version und den Berechtigungen des Arbeitsbereichs ab. Siehe [OpenAI-Hinweise zu benutzerdefiniertem MCP](https://developers.openai.com/api/docs/guides/custom-mcp-server).

## Repository-Plugin für Codex

Stellen Sie sicher, dass Ihre Codex-Version `plugin` unterstützt. Dieses Plugin nutzt natives Remote-MCP; der CLI-Prompt der Website ist eine andere Methode. CLI-Benutzer brauchen für die Generierung nicht zusätzlich ein Plugin.

<Steps>

<Step title="Quelle hinzufügen und Plugin installieren">

Führen Sie dies im Terminal des Rechners und Benutzers aus, unter dem Codex läuft:

```bash
codex plugin marketplace add Evolink-AI/mcp-plugin
codex plugin add evolink@evolink
codex plugin list --json
```

Prüfen Sie, ob EvoLink in der Plugin-Liste erscheint. Das Plugin liefert die Konfiguration des Remote-MCP und den Skill `evolink-mcp`, nicht die EvoLink CLI.

</Step>

<Step title="Plugin laden und autorisieren">

Aktualisieren Sie die Plugins oder öffnen Sie eine neue Unterhaltung in Codex und prüfen Sie, ob der EvoLink-Server geladen ist. Schließen Sie das Browser-OAuth des Hosts ab, wenn Sie dazu aufgefordert werden. Ist der Server registriert und wird dieser Befehl unterstützt, verwenden Sie:

```bash
codex mcp login evolink
```

Lassen Sie den Befehl während Anmeldung und Zustimmung laufen und kehren Sie dann zu Codex zurück. Wählen Sie eine einzige Registrierungsquelle, wenn bereits eine manuelle MCP-Konfiguration vorhanden ist.

</Step>

<Step title="Werkzeuge und Skill prüfen">

```text
Bestätige, dass du evolink-mcp gelesen hast, und prüfe dann mit EvoLink das Guthaben und die verfügbaren Bildmodelle. Generiere noch nichts.
```

Erfolg bedeutet, dass der Skill gelesen wurde und tatsächliche Aufrufe von `check_balance` und `search_models` erfolgreich waren; eine Plugin-Liste allein bestätigt keine Autorisierung.

</Step>

</Steps>

Um die Quelle zu aktualisieren, führen Sie dies aus, aktualisieren Sie das Plugin im Host und prüfen Sie dessen tatsächliche Version:

```bash
codex plugin marketplace upgrade evolink
```

Zur manuellen MCP-Einrichtung siehe die [Referenz zu Codex CLI](https://learn.chatgpt.com/docs/cli/reference) und die [Einrichtung für Codex](/de/mcp/codex); die CLI-Anweisungen finden Sie in der [separaten CLI-Anleitung](/de/cli/codex).

## Repository-Plugin für Claude Code

Verwenden Sie eine Version von Claude Code, die Plugins unterstützt. Dies sind **Befehle für die Unterhaltung in Claude Code**, keine normalen Shell-Befehle.

<Steps>

<Step title="Repository-Plugin installieren">

```text
/plugin marketplace add Evolink-AI/mcp-plugin
/plugin install evolink@evolink
```

Warten Sie die Installation ab und prüfen Sie, ob EvoLink für den aktuellen Benutzer oder das aktuelle Projekt aktiviert ist. Lassen Sie andere Plugins unverändert.

</Step>

<Step title="Remote-MCP autorisieren">

```text
/mcp
```

Wählen Sie nach dem Aktualisieren des Plugins EvoLink aus und schließen Sie die Authentifizierung im Browser ab. Vermeiden Sie eine doppelte, manuell registrierte Verbindung.

</Step>

<Step title="Kostenlos prüfen">

Bitten Sie den Assistenten zu bestätigen, dass er `evolink-mcp` gelesen hat, und Guthaben und Modelle tatsächlich abzufragen, ohne zu generieren. Zur manuellen MCP-Einrichtung siehe die [Einrichtung für Claude Code](/de/mcp/claude-code); die CLI-Anweisungen finden Sie in der [separaten CLI-Anleitung](/de/cli/claude-code).

</Step>

</Steps>

## Nur den MCP-Skill installieren

Wenn natives MCP bereits konfiguriert ist und Sie nur die Anleitung für den Agenten brauchen:

```bash
npx skills add Evolink-AI/mcp-plugin -g -y
```

Dies ruft die Skills des Repositorys über den Skills-Installer ab. Es installiert keine EvoLink CLI, startet kein lokales MCP und schließt OAuth nicht ab. Prüfen Sie, ob der Host das Zielverzeichnis erkennt und evolink-mcp liest.

## Was das Plugin vermittelt

Die Quelle ist [Evolink-AI/mcp-plugin](https://github.com/Evolink-AI/mcp-plugin). Die Konfiguration verweist auf das gehostete Remote-MCP. Der zugehörige Skill behandelt Modellsuche, Parameterprüfung, Kostenschätzungen und Zustimmung, Upload von Referenzen, Generierung, Aufträge, Wiederaufnahme nach Fehlern und die Übergabe der Originale. Er ergänzt die Werkzeuge von EvoLink MCP nicht um Codeentwicklung, beliebige Dateibearbeitung oder vollständigen Videoschnitt.

Die Skills von CLI und MCP können dieselben Medienrichtlinien teilen, verwenden aber unterschiedliche Befehle und Werkzeuge. Wählen Sie pro Auftrag einen Weg. Läuft das Absenden in eine Zeitüberschreitung mit unbekanntem Ausgang, nehmen Sie die ursprüngliche Anfrage oder task_id wieder auf, statt über einen anderen Einstieg neu zu generieren. Inhalte und Verzeichnisse finden Sie unter [Ressourcen für Agenten](/de/cli-mcp/agent-resources#skills), Parameter in der [Plattformreferenz](/de/mcp/tools).

Limits und Widerruf finden Sie unter [Kosten und Aufbewahrung](/de/mcp/billing). Die Installation eines Plugins, die Installation eines Skills und die OAuth-Autorisierung sind keine Zustimmung zu einer kostenpflichtigen Generierungsanfrage.

## Probleme bei der Plugin-Installation

| Symptom | Nächster Schritt |
|---|---|
| Befehle plugin / marketplace fehlen | Host-Version und offizielle Einrichtung prüfen oder die Anleitung des Hosts zur manuellen MCP-Einrichtung oder die [separate CLI-Einrichtung](/de/cli/setup) verwenden |
| Repository lässt sich nicht abrufen | Verbindung zu GitHub und Quelleneinstellungen des Hosts prüfen; den ursprünglichen Fehler aufbewahren |
| Installiert, aber Werkzeuge fehlen | Die tatsächliche Sitzung aktualisieren, das Plugin aktivieren und OAuth abschließen |
| Doppelter Server oder Skill | Konfiguration sichern, Quellen prüfen, die gewünschte behalten und andere Dienste unverändert lassen |
| Werkzeuge werden aufgelistet, aber Aufrufe schlagen fehl | Autorisierung mit kostenlosen Guthabenabfragen prüfen; siehe [MCP-Fehlerbehebung](/de/mcp/billing#mcp-connection) |

Die Installation eines Plugins ist keine Zustimmung zu kostenpflichtigen Tests. Zu Erkennung und anderen Problemen siehe die [zentrale Fehlerbehebung](/de/mcp/billing#faq).
