Der ChatGPT-Chat verwendet **Remote-MCP**. Konfigurieren Sie es im Client und im Browser; eine lokale CLI-Installation und ein persönlicher API Key sind nicht erforderlich.

## Bevor Sie beginnen

Sie brauchen ein EvoLink-Konto und ein ChatGPT-Konto sowie eine Client-Version, einen Plan und eine Berechtigung im Arbeitsbereich, die benutzerdefiniertes MCP erlauben. Ist die Aktion zum Hinzufügen nicht verfügbar, prüfen Sie zuerst den Zugriff im Host, statt Terminalanweisungen im Chat auszuführen.

## EvoLink Schritt für Schritt verbinden

<Steps>

<Step title="Aktion für benutzerdefiniertes MCP öffnen">

Öffnen Sie [ChatGPT Plugins](https://chatgpt.com/plugins), wählen Sie Add oder die Plus-Schaltfläche und dann **Create/Add custom MCP server**. Dies ist der Einstieg, den auch die Website für die Einrichtung nutzt. Die Bezeichnungen können je nach Version abweichen; prüfen Sie den Zugriff im Arbeitsbereich, wenn der Eintrag fehlt.

</Step>

<Step title="Verbindungsdaten eingeben">

| Feld | Wert |
|---|---|
| Icon / Symbol (optional) | Laden Sie das [EvoLink-Symbol](https://cdn.evolink.ai/next/evolink-logo.png) herunter und laden Sie es hoch; überspringen Sie dies, wenn das Formular kein Symbolfeld hat |
| Name | EvoLink |
| Connection / Verbindung | Server URL |
| Server URL | `https://mcp.evolink.ai/mcp` |
| Authentication / Authentifizierung | OAuth |
| Client ID / Client Secret | Standardwerte belassen; keinen API Key der Plattform eintragen |

Verwenden Sie Remote-HTTP und behalten Sie das abschließende `/mcp` bei. Prüfen Sie den Verbindungshinweis und wählen Sie **Create as a plugin**.

</Step>

<Step title="Installieren und das Konto autorisieren">

Öffnen Sie EvoLink in Ihren persönlichen Plugins und installieren oder verbinden Sie es. Wird eine Authentifizierung verlangt, melden Sie sich im Browser bei EvoLink an, prüfen Sie Konto und Berechtigungen und stimmen Sie zu. Lassen Sie den Ablauf geöffnet und kehren Sie dann zu ChatGPT zurück. Das Erstellen der Konfiguration und das Installieren des Plugins sind getrennte Schritte; die Autorisierungsaktion kann in unterschiedlichen Phasen erscheinen.

</Step>

<Step title="In einer Unterhaltung aktivieren und prüfen">

Starten Sie eine neue Unterhaltung und wählen Sie EvoLink mit `@` aus. Hat Ihre Oberfläche die Tabs Chat / Work, wechseln Sie zu **Work**, bevor Sie die Plugin-Unterhaltung starten. Senden Sie den Prompt für die kostenlose Prüfung unten.

**Erfolg**: tatsächliches Kontoguthaben und verfügbare Modelle, nicht nur die Aussage, dass die Einrichtung abgeschlossen ist.

</Step>

</Steps>

Siehe [Benutzerdefiniertes MCP bei OpenAI](https://developers.openai.com/api/docs/guides/custom-mcp-server) und [Plugin-Schnellstart](https://developers.openai.com/plugins/quickstart). Eine persönliche Verbindung bedeutet nicht, dass EvoLink im öffentlichen Verzeichnis gelistet ist.

## Kostenlose Prüfung und der erste Medienauftrag

Senden Sie dies nach dem Verbinden in einer Unterhaltung, in der EvoLink aktiviert ist:

```text
Prüfe mit EvoLink mein Kontoguthaben und suche verfügbare Bildmodelle. Generiere noch nichts.
```

Prüfen Sie, ob `check_balance` und `search_models` tatsächlich aufgerufen wurden. Die Anmeldung und diese Abfragen erstellen keine kostenpflichtigen Medienaufträge. Beschreiben Sie für die Generierung Inhalt und Spezifikationen, prüfen Sie das vorgeschlagene Modell, die Parameter und die Kostenschätzung und stimmen Sie dem Absenden dann ausdrücklich zu. Siehe den [Ablauf für den ersten Medienauftrag](/de/mcp/overview#workflows).

Verwenden Sie öffentlich erreichbare Referenzlinks, die das Modell unterstützt. Ein Chat-Anhang stellt MCP die Originalbytes der Datei möglicherweise nicht bereit, und der Remote-Dienst kann die Pfade Ihres Computers nicht lesen. Siehe [Referenzen und Uploads](/de/mcp/overview#files).

## Häufige Probleme

| Symptom | Nächste Schritte |
|---|---|
| Keine Aktion für benutzerdefinierte Connectors | Plan, Version und Berechtigungen des Arbeitsbereichs im aktuellen Host prüfen |
| Nach der Anmeldung im Browser weiterhin nicht autorisiert | Zum ursprünglichen Client zurückkehren und den aktuellen Ablauf abschließen; siehe [Fehlerbehebung bei der Autorisierung](/de/mcp/billing#login) |
| Verbindung hinzugefügt, aber keine Werkzeuge im Chat | Installations- und Aktivierungsstatus prüfen, EvoLink auswählen, eine neue Unterhaltung öffnen; siehe [MCP-Fehlerbehebung](/de/mcp/billing#mcp-connection) |
| Guthabenabfrage funktioniert, aber das Generierungswerkzeug ist nicht verfügbar | Werkzeugschalter des Hosts und Berechtigungen des Arbeitsbereichs prüfen; umgehen Sie sie nicht mit einem Key |
| Netzwerk-Zeitüberschreitung oder 403 | Feststellen, ob der Fehler im Host, auf der Anmeldeseite oder in der Werkzeuganfrage liegt; Zeitpunkt und Fehler für den Support aufbewahren |
| Ergebnis ist ein Link oder eine graue Vorschau | Das Original öffnen und speichern; siehe [Fehlerbehebung bei Download und Vorschau](/de/mcp/billing#download) |

## Aktualisieren und trennen

Aktualisieren Sie nach Änderungen die Verbindung und die Werkzeuge oder öffnen Sie eine neue Unterhaltung. Autorisieren Sie bei Bedarf über diesen Host erneut. Um den Zugriff dieses Clients zu beenden, trennen Sie die Verbindung oder melden Sie sich in dessen Einstellungen ab. Limits und das Pausieren des gemeinsam genutzten Keys verwalten Sie in EvoLink. Siehe [Plugins](/de/mcp/plugins) und [Kosten und Fehlerbehebung](/de/mcp/billing#faq).
