## Was ein Agent mit nativem MCP lesen sollte

1. Lesen Sie den [MCP-Überblick](/de/mcp/overview) und die Einrichtungsseite des Clients und konfigurieren und autorisieren Sie dann den Host.
2. Ziehen Sie die [MCP-Werkzeugreferenz](/de/mcp/tools) und die tatsächlichen Werkzeug-Schemas heran.
3. Installieren Sie optional die Anleitung evolink-mcp oder ein Host-Plugin anhand der [Plugin-Schritte](/de/mcp/plugins). Das Lesen von Skills registriert oder authentifiziert keine Werkzeuge.
4. Wenden Sie die [gemeinsamen Regeln für Agenten](/de/cli-mcp/agent-resources#agent-rules) an und prüfen Sie dann tatsächliche Aufrufe mithilfe der [MCP-Fehlerbehebung](/de/mcp/billing#faq).

evolink-cli vermittelt Terminalbefehle; natives MCP nutzt die Werkzeuganleitung evolink-mcp. Prüfen Sie Installation und Authentifizierung getrennt. llms.txt ist ein Index der Dokumentation; der MCP-Endpunkt bleibt https://mcp.evolink.ai/mcp.
