title: "Anfragekosten abfragen"
description: "Status, Nutzung und tatsächliche Kosten synchroner API-Aufrufe, vor allem an Textmodelle, anhand der Request ID abfragen"
openapi: /de/api-manual/account-management/get-request-usage.json GET /v1/requests/{request_id}
---

<Note>
Dieser Endpunkt fragt die Kosten **synchroner API-Aufrufe** ab, vor allem an **Textmodelle** über Schnittstellen wie Chat Completions, Messages und Responses.

Verwenden Sie den Wert des Headers `X-Request-Id` aus der ursprünglichen Antwort als Request ID. Warten Sie nach Abschluss der Anfrage einen Moment, bevor Sie die Abfrage ausführen. Verwenden Sie für asynchrone Aufgaben [Aufgabenstatus abfragen](/de/api-manual/task-management/get-task-detail).
</Note>
