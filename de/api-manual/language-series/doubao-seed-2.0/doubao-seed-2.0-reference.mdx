<Note>
**BaseURL**: Die Standard-BaseURL ist `https://direct.evolink.ai` und bietet bessere Unterstützung für Textmodelle sowie persistente Verbindungen. `https://api.evolink.ai` ist der primäre Endpunkt für multimodale Dienste und dient bei Textmodellen als Ausweichadresse.
</Note>

<Note>
Nur `doubao-seed-2-1-lite` akzeptiert Audioeingaben. Für die Websuche nutzen Sie [Responses](/de/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-responses-reference) oder [Messages](/de/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-messages-reference) mit Seed 2.1 oder `doubao-seed-evolving`. Chat Completions unterstützt sie nicht.
</Note>
