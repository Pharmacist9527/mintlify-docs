<Note>
**BaseURL**: Die Standard-BaseURL ist `https://direct.evolink.ai` und bietet bessere Unterstützung für Textmodelle sowie persistente Verbindungen. `https://api.evolink.ai` ist der primäre Endpunkt für multimodale Dienste und dient bei Textmodellen als Ausweichadresse.
</Note>

<Note>
Nur Seed 2.1 und `doubao-seed-evolving` unterstützen Websuche. Abgerechnet wird jede ausgeführte Suche nach Quelle. Für explizites Caching fallen zusätzliche Speichergebühren an. Details stehen bei `caching` und `expire_at`. In beiden Beispielen für explizites Caching im Anfragemenü fehlt `expire_at`. Dadurch wird der Speicher für die standardmäßige Laufzeit von drei Tagen berechnet.
</Note>

## Cache-Anfrage mit einer Stunde Gültigkeit erstellen

Führen Sie diesen Python-Code direkt vor dem Senden aus und verwenden Sie die JSON-Ausgabe als Anfragekörper. Lassen Sie `PREVIOUS_RESPONSE_ID` bei der ersten Anfrage ungesetzt. Setzen Sie die Variable zur Fortsetzung auf die tatsächlich zurückgegebene `id` der vorherigen Antwort und führen Sie den Code erneut aus. Bei jedem Aufruf wird `expire_at` neu berechnet.

```python
import json
import os
import time

body = {
    "model": "doubao-seed-2-1-pro",
    "input": "Produkthandbuch: Für Motor und Akku gilt eine zweijährige Garantie. Merke dir diese Regelung.",
    "caching": {"type": "enabled"},
    "expire_at": int(time.time()) + 3600,
}
previous_id = os.getenv("PREVIOUS_RESPONSE_ID")
if previous_id:
    body["previous_response_id"] = previous_id
    body["input"] = "Welche Teile sind durch die Garantie abgedeckt?"
print(json.dumps(body, ensure_ascii=False))
```
