<Note>
**BaseURL**: Die Standard-BaseURL ist `https://direct.evolink.ai` und bietet bessere Unterstützung für Textmodelle sowie persistente Verbindungen. `https://api.evolink.ai` ist der primäre Endpunkt für multimodale Dienste und dient bei Textmodellen als Ausweichadresse.
</Note>

<Note>
**Serverseitige Tools** (Websuche, Codeausführung, Dokumentensuche, MCP) werden nur auf der [Responses API](/de/api-manual/language-series/gpt/responses/responses-reference) bereitgestellt. Der Chat-Completions-Endpunkt unterstützt ausschließlich gewöhnliche `function`-Werkzeugaufrufe.
</Note>

<Note>
**GPT-6**: Funktionsaufrufe mit `gpt-6-sol` / `gpt-6-luna` erfordern hier `reasoning_effort: "none"`. Verwenden Sie die [Responses API](/de/api-manual/language-series/gpt/responses/responses-reference) für Funktionsaufrufe mit `gpt-6.2-astra` / `gpt-6.2-sol` / `gpt-6-astra`, `gpt-6.1-sol` oder `gpt-6.1-terra` sowie für die GPT-6-Stufe `max`.
</Note>
