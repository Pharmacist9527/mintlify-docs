<Note>
**BaseURL**: Die Standard-BaseURL ist `https://direct.evolink.ai` und bietet bessere Unterstützung für Textmodelle sowie persistente Verbindungen. `https://api.evolink.ai` ist der primäre Endpunkt für multimodale Dienste und dient bei Textmodellen als Ausweichadresse.
</Note>

<Note>
**Modell-ID nur für diesen Endpunkt**: `gpt-6-luna-decisions` kann nur mit `/v1/decisions` verwendet werden. Bei Chat Completions, Responses oder anderen Endpunkten wird `400 model_endpoint_mismatch` zurückgegeben. Für Konversationen oder Textgenerierung verwenden Sie `gpt-6-luna` mit [Chat Completions](/de/api-manual/language-series/gpt/chat-completions/chat-completions-reference) oder der [Responses API](/de/api-manual/language-series/gpt/responses/responses-reference).
</Note>

<Note>
**Den passenden Fragetyp auswählen**

| Typ | Geeignete Fragen | Ergebnis verwenden |
|---|---|---|
| `predicate` | Ja/Nein-Fragen, etwa ob eine Nachricht eine Beschwerde ist oder ein Bild einen Schaden zeigt | `probability` ist die Wahrscheinlichkeit für „Ja“; legen Sie einen eigenen Schwellenwert fest und werten Sie höhere Werte als Treffer |
| `choice` | Auswahl aus sich gegenseitig ausschließenden Kategorien, etwa der zuständigen Abteilung | `choice` ist die ausgewählte Option; bei niedriger `confidence` empfiehlt sich eine manuelle Prüfung |
| `score` | Bewertung anhand aufsteigender Stufen, etwa des Schweregrads eines Problems | `score` ist die nach Wahrscheinlichkeiten gewichtete Stufenbewertung (Indizes ab 0) und kann Nachkommastellen enthalten |

Eine Anfrage kann mehrere unabhängige Fragen enthalten, die dieselbe `input` verwenden. Wenn eine spätere Frage von einer vorherigen Antwort abhängt, teilen Sie sie auf zwei Anfragen auf.
</Note>

<Note>
**Unterschied zu Chat Completions / Responses**: Dieser Endpunkt akzeptiert nur `model`, `input`, `questions` und `safety_identifier`. Jedes zusätzliche Feld führt zu `400 unknown_parameter`; Bilder müssen base64-Daten-URLs verwenden; Streaming wird nicht unterstützt.
</Note>
