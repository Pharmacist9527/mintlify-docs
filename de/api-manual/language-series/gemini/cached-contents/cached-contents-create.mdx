<Note>
**BaseURL**: Standard ist `https://direct.evolink.ai` mit besserer Unterstützung für Textmodelle und lange Verbindungen; `https://api.evolink.ai` dient als Ersatzadresse.
</Note>

Erstellen Sie einen Cache für ein wiederverwendbares langes Präfix (Dokumente, Systemanweisungen oder Tool-Definitionen). Nachfolgende Generierungsanfragen senden nur den Cache-Namen und eine neue Frage. Cache-Tokens werden zum Trefferpreis abgerechnet; während der Speicherung fallen Gebühren nach Token-Anzahl und Dauer an.

## Unterstützte Modelle

| Familie | Modelle |
|---|---|
| Gemini 3.x Flash | `gemini-3.8-flash`, `gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-3-flash-preview` |
| Gemini 3.x Flash-Lite | `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite-preview` |
| Gemini 3.x Pro | `gemini-3.1-pro-preview`, `gemini-3.1-pro-preview-customtools`, `gemini-3-pro-preview` |

Gemini 4 unterstützt kein explizites Caching. Beim Erstellen wird 400 `EXPLICIT_CACHE_UNSUPPORTED` zurückgegeben.

## Explizites und implizites Caching

| | Implizites Caching (Standard) | Explizites Caching (diese Seite) |
|---|---|---|
| Verwendung | Keine Anpassung; gleiche Präfixe können automatisch treffen | Cache erstellen und seinen Namen in Generierungsanfragen referenzieren |
| Cache-Treffer | Nicht garantiert | Verweis auf den Cache erzeugt einen Treffer |
| Schreibgebühr | Keine | Nach Anzahl gecachter Tokens |
| Speichergebühr | Keine | Nach gecachten Tokens × Stunden |
| Geeignet für | Natürliche Wiederverwendung ohne Anpassung | Viele Aufrufe mit demselben langen Präfix innerhalb eines Zeitraums |

## Ablauf

1. **Erstellen**: `POST /v1beta/cachedContents` mit dem langen Präfix in mindestens einem von `contents`, `systemInstruction` oder `tools`. Liefert den Cache-Namen `name`.
2. **Referenzieren**: `"cachedContent": "<name>"` zum Body von `POST /v1beta/models/{model}:generateContent` hinzufügen (Streaming: `streamGenerateContent`); in `contents` nur die neue Frage senden.
3. **Verlängern** (optional): Mit `PATCH /v1beta/cachedContents/{id}` einen neuen `ttl` oder `expireTime` übergeben. Für die zusätzliche Dauer fallen Speichergebühren an.
4. **Löschen** (optional): Bei Nichtbedarf `DELETE /v1beta/cachedContents/{id}` aufrufen. Sonst erfolgt die Löschung automatisch bei Ablauf. Bereits berechnete Speichergebühren werden nicht erstattet.

Caches gehören zum Konto: Jeder API-Key desselben Kontos kann darauf verweisen (bei Modell-Positivliste muss das Modell enthalten sein). Andere Konten erhalten für denselben Cache-Namen 404. Für Verweise und Verlängerungen gelten die Preise der aktuellen Benutzergruppe des anfragenden Keys.

## Cache in Generierungsanfragen referenzieren

```bash
curl -X POST "https://direct.evolink.ai/v1beta/models/gemini-3.8-flash:generateContent" \
  -H "Authorization: Bearer $EVOLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "cachedContent": "cachedContents/20261103012026348092000s1oTuB96",
    "contents": [
      { "role": "user", "parts": [{ "text": "Was steht im Handbuch zur Rückgabe?" }] }
    ]
  }'
```

`usageMetadata.cachedContentTokenCount` enthält die zum Trefferpreis berechneten Cache-Tokens. `promptTokenCount` umfasst diese Tokens; der Rest wird zum regulären Eingabepreis abgerechnet.

```json
{
  "candidates": [
    { "content": { "role": "model", "parts": [{ "text": "Kapitel 7 des Handbuchs besagt …" }] }, "finishReason": "STOP" }
  ],
  "usageMetadata": {
    "promptTokenCount": 7541,
    "cachedContentTokenCount": 7525,
    "candidatesTokenCount": 212,
    "totalTokenCount": 7753
  },
  "modelVersion": "gemini-3.8-flash"
}
```

<Warning>
Generierungsanfragen mit Cache **dürfen `systemInstruction`, `tools` und `toolConfig` nicht erneut enthalten**. Diese beim Erstellen festlegen; erneutes Übergeben führt zu 400. Das Generierungsmodell muss zum Cache-Modell passen, andernfalls folgt 400 `CACHE_MODEL_MISMATCH`.
</Warning>

## Vollständiges Beispiel (Python)

```python
import requests

BASE = "https://direct.evolink.ai"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json"}

# 1. Cache erstellen: langes Dokument + Systemanweisungen, für 1 Stunde
manual = open("manual.txt", encoding="utf-8").read()   # Mindestanzahl an Cache-Tokens des Modells erforderlich
cache = requests.post(f"{BASE}/v1beta/cachedContents", headers=HEADERS, json={
    "model": "models/gemini-3.8-flash",
    "displayName": "product-manual-v3",
    "systemInstruction": {"parts": [{"text": "Sie sind ein Assistent für das Produkthandbuch. Antworten Sie nur anhand des Handbuchs."}]},
    "contents": [{"role": "user", "parts": [{"text": manual}]}],
    "ttl": "3600s",
}).json()
name = cache["name"]            # cachedContents/<id>
cache_id = name.split("/")[-1]  # <id>
print("cached tokens:", cache["usageMetadata"]["totalTokenCount"], "expire:", cache["expireTime"])

# 2. Wiederholt referenzieren: jeweils nur die neue Frage senden
for question in ["Wie lautet die Rückgaberichtlinie?", "Wie lange gilt die Garantie?", "Ist eine Einsendung zur Reparatur aus dem Ausland möglich?"]:
    resp = requests.post(f"{BASE}/v1beta/models/gemini-3.8-flash:generateContent", headers=HEADERS, json={
        "cachedContent": name,
        "contents": [{"role": "user", "parts": [{"text": question}]}],
    }).json()
    print(resp["candidates"][0]["content"]["parts"][0]["text"])
    print("cache hit tokens:", resp["usageMetadata"].get("cachedContentTokenCount", 0))

# 3. Weiterverwenden: ab jetzt noch 2 Stunden (Speichergebühr für die zusätzliche Dauer)
requests.patch(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS, json={"ttl": "7200s"})

# 4. Anschließend löschen (berechnete Speichergebühren werden nicht erstattet)
requests.delete(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS)
```

## Abrechnung

| Posten | Berechnung |
|---|---|
| Cache-Schreiben | Gecachte Tokens × Schreibpreis, bei Erstellung berechnet. Schreibpreis entspricht dem Eingabepreis des Modells; Pro-Caches über 200.000 Tokens nutzen den Langkontextpreis |
| Cache-Speicherung | Gecachte Tokens × Dauer (Stunden, sekundengenau umgerechnet) × Speicherpreis (pro Million Tokens pro Stunde), bei Erstellung für die gesamte Dauer berechnet |
| Generierung mit Cache | `cachedContentTokenCount` zum Trefferpreis; übrige Ein- und Ausgabe zu regulären Preisen. Bei im Cache deklariertem `googleSearch` wird jede Suche separat zum Suchpreis berechnet |
| Verlängerung | Speichergebühr für die zusätzliche Dauer; weniger als 1 Sekunde wird als 1 Sekunde berechnet |
| Verkürzen / Löschen / Ablauf | Bereits berechnete Speichergebühren werden nicht erstattet |
| Auflisten / Abrufen | Kostenlos |

- Die Token-Anzahl stammt aus `usageMetadata.totalTokenCount` der Erstellungsantwort.
- `<id>` im Cache-Namen ist die ID der Erstellungsanfrage. Auf der Dashboard-Seite „Logs“ danach suchen, um Gebühren für Erstellung und Verlängerung zu sehen (Tokens, Speicherdauer und Speichergebühr).
- Schreib-, Treffer- und Speicherpreise je Modell finden Sie auf der [Preisseite](https://evolink.ai/pricing).
- Wirtschaftlichkeit: Speicherung kostet pro Zeit, Treffer sparen pro Aufruf. Je öfter dasselbe Präfix während der Gültigkeit genutzt wird, desto eher lohnt es sich. Bei nur ein oder zwei Aufrufen ist der Originaltext günstiger.

## Einschränkungen

- **Gültigkeitsdauer**: Mindestens 60 Sekunden, höchstens 168 Stunden (`604800s`). Nur eines von `ttl` oder `expireTime`; ohne beide gilt 1 Stunde.
- **Inhalt**: Mindestens eines von `contents`, `systemInstruction` oder `tools`; maximal 10 MB Anfrageinhalt. Die Mindestanzahl an Tokens des Modells muss erreicht werden (z. B. 4.096 für `gemini-3.8-flash`), sonst folgt 400.
- **Felder**: Nur die auf dieser Seite dokumentierten Felder sind zulässig. Andere liefern 400 mit dem Feldnamen.
- **tools**: Nur `googleSearch`, `codeExecution` und `functionDeclarations`.
- **Unveränderlicher Inhalt**: Nach Erstellung ist nur die Dauer änderbar. Für andere Inhalte einen neuen Cache erstellen.
- **Zugriffskontrolle**: Erstellung und Verlängerung unterliegen wie Generierungsanfragen den IP-/Modell-Positivlisten und Anfragelimits des Keys.

## Fehlercodes

Fehler verwenden das native Gemini-Format; `error.details[0].reason` enthält den konkreten Grund:

```json
{
  "error": {
    "code": 404,
    "message": "cached content not found",
    "status": "NOT_FOUND",
    "details": [{ "@type": "type.googleapis.com/google.rpc.ErrorInfo", "reason": "CACHE_NOT_FOUND", "domain": "evolink.ai" }]
  }
}
```

| HTTP | reason | Bedeutung |
|---|---|---|
| 400 | `INVALID_ARGUMENT` | Ungültige Parameter: kein Cache-Inhalt, `ttl` außerhalb von 60 Sekunden–168 Stunden, sowohl `ttl` als auch `expireTime`, unzulässige Felder oder Tools usw. |
| 400 | `EXPLICIT_CACHE_UNSUPPORTED` | Modell unterstützt kein explizites Caching (Gemini 4 oder Bildmodelle) |
| 400 | `NO_AVAILABLE_CHANNEL` | Aktuelle Benutzergruppe kann für dieses Modell keine Caches erstellen |
| 400 | `MODEL_PRICE_ERROR` | Explizites Caching dieses Modells ist für die aktuelle Benutzergruppe nicht freigeschaltet |
| 400 | `CACHE_EXPIRED` | Cache während der Verarbeitung abgelaufen oder verbleibende Dauer zu kurz |
| 400 | `CACHE_MODEL_MISMATCH` | Generierungsmodell stimmt nicht mit dem Cache-Modell überein |
| 400 | `INVALID_CACHED_CONTENT` | Ungültiges Format von `cachedContent` |
| 4xx | `UPSTREAM_ERROR` | Modell lehnt den Inhalt ab; Grund in `message`, häufig zu wenige Cache-Tokens |
| 402 | `INSUFFICIENT_QUOTA` | Guthaben reicht nicht für Schreib- und Speichergebühren |
| 403 | — | Der Key hat keinen Modellzugriff, die Quell-IP steht nicht auf seiner Positivliste oder seine Benutzergruppe ist nicht mehr verfügbar |
| 404 | `CACHE_NOT_FOUND` | Cache fehlt, ist abgelaufen, gelöscht oder gehört einem anderen Konto |
| 404 | `EXPLICIT_CACHE_DISABLED` | Explizites Caching ist nicht freigeschaltet |
| 413 | `CACHE_CONTENT_TOO_LARGE` | Anfrageinhalt überschreitet 10 MB |
| 502 | `UPSTREAM_ERROR` | Dienst vorübergehend nicht verfügbar. Diese Anfrage wird nicht berechnet; bitte später erneut versuchen |
| 503 | `CACHE_CHANNEL_UNAVAILABLE` | Cache vorübergehend nicht verfügbar; bitte später erneut versuchen |
| 503 | `INTERNAL` | Dienst vorübergehend nicht verfügbar; bitte später erneut versuchen |
