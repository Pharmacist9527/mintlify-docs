Nutzen Sie EvoLink in Ihrem Agenten, um Bilder, Videos, Musik und Sprache zu generieren, Modelle und Kosten zu ermitteln, Referenzen hochzuladen, Aufträge zu verfolgen und Originale zu speichern. Wählen Sie eine Verbindungsart und folgen Sie dann der zugehörigen Anleitung für Installation und kostenlose Prüfung.

## Verbindungsart wählen

| Wo Sie arbeiten | Empfohlener Weg | Installation und Authentifizierung |
|---|---|---|
| Claude-Chat oder ChatGPT | [Remote-MCP](/de/mcp/overview) | Verbindung hinzufügen und per Browser-OAuth autorisieren; keine CLI-Installation |
| Codex, Claude Code, Cursor, OpenClaw oder Hermes mit Terminalausführung | [CLI](/de/cli/setup) | CLI installieren, anmelden und den Skill installieren/laden |
| Terminal, SSH oder Skripte | [CLI](/de/cli/setup) | In der Ausführungsumgebung installieren; für SSH gibt es eigene Callback-Schritte |
| Ein Terminal-Agent, der native MCP-Werkzeuge nutzt | [MCP-Client-Anleitung](/de/mcp/overview#choose-your-assistant) | Host-Verbindung direkt konfigurieren und autorisieren |
| Ein Client, der nur lokales stdio unterstützt | [Lokales MCP](/de/mcp/other-clients#local-mcp) | Lokalen Prozess, Node.js und einen persönlichen API Key konfigurieren |

Codex CLI ist Ihr Agenten-Client; EvoLink CLI ist das Medienwerkzeug, das er aufruft. Es sind unterschiedliche Produkte. Jede Karte empfiehlt einen Weg; die CLI-Anleitungen für die einzelnen Clients verweisen zusätzlich auf die native MCP-Alternative.

## Vor dem Generieren prüfen

<Steps>
  <Step title="Gewählten Weg installieren und authentifizieren">
    Folgen Sie der [CLI-Installation](/de/cli/setup) in fünf Schritten oder Ihrer [MCP-Client-Anleitung](/de/mcp/overview#choose-your-assistant). Schließen Sie die Anmeldung im Browser selbst ab. Geben Sie keine Keys oder Tokens in den Chat ein.
  </Step>
  <Step title="Guthaben und Modelle abfragen, Skills oder Werkzeuge prüfen">
    CLI-Benutzer fragen das Guthaben ab, führen doctor aus und lassen den Agenten bestätigen, dass er den Skill erkennt. MCP-Benutzer rufen check_balance und search_models tatsächlich auf. Installierte Dateien oder eine Werkzeugliste belegen keine erfolgreiche Ausführung. Diese Prüfungen senden keine kostenpflichtigen Medienaufträge ab.
  </Step>
  <Step title="Plan und geschätzte Kosten prüfen, bevor Sie der Generierung zustimmen">
    Prüfen Sie das genaue Modell und die Eingaben, bereiten Sie Referenzen vor und sehen Sie sich Plan und Kostenschätzung an. Senden Sie nach ausdrücklicher Zustimmung einmal ab, bewahren Sie die Auftragskennung auf und speichern Sie die Originale. Siehe [CLI-Abläufe](/de/cli/workflows) oder [MCP-Abläufe](/de/mcp/overview#workflows).
  </Step>
</Steps>

## Wie die Wege zusammenhängen

Medienanfragen der CLI laufen über `Agent / Terminal → CLI → Plattform-API`. Natives MCP läuft über `Agent → Remote- oder lokales MCP → Plattform-API`. Die Medienausführung der CLI hängt nicht vom Remote-MCP ab. Die Anmeldung erfolgt über Passport; für Uploads und für Downloads der Originale gibt es eigene Datei-Endpunkte.

Installation, Sitzungen und Verbindungsprüfungen sind voneinander getrennt. OAuth desselben Kontos kann derzeit die Berechtigungen und Kontingente des internen Keys gemeinsam nutzen. Nutzen Sie für den Auftrag nur einen Weg. Nehmen Sie Übermittlungen mit unbekanntem Ausgang über den ursprünglichen Weg wieder auf, statt über den anderen Weg erneut zu generieren.
