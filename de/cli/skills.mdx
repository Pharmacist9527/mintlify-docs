## Den CLI-Skill installieren und verwalten

Diese Seite behandelt Ziele, Verzeichnisse, Erkennung durch den Host und Updates von evolink-cli. Umfang, die Konzepte von CLI, MCP und Plugin sowie die gemeinsamen Regeln finden Sie unter [Gemeinsame Ressourcen](/de/cli-mcp/agent-resources).

## Installieren und Erkennung prüfen

```bash
evolink skills install
evolink skills status --json
```

Die Standardinstallation deckt die unterstützten Zielverzeichnisse ab, ohne die Agenten zu installieren. So wählen Sie einen einzelnen Host:

```bash
evolink skills install --agent codex
evolink skills status --agent codex --json
evolink doctor --agent codex --json
```

Prüfen Sie current:true und senden Sie dies im Chat des Agenten:

```text
Bestätige, dass diese Sitzung evolink-cli erkennen und lesen kann. Frage zuerst Guthaben und Modelle ab; generiere keine Medien.
```

assistant_discovery:not_checked bedeutet, dass die CLI die Erkennung nicht stellvertretend für den Host prüfen kann. Sind Dateien vorhanden, werden aber nicht genutzt, aktualisieren Sie die Skills oder öffnen Sie eine neue Sitzung und prüfen Sie die Befehlsberechtigungen. Das Lesen eines Dokuments allein beweist keinen Kontozugriff.

Gemini, OpenCode und Copilot können der [allgemeinen Installation in fünf Schritten](/de/cli/setup#cli-install) mit ihrem Agent-Wert folgen. Installieren Sie in der tatsächlich genutzten SSH-, WSL-, Container- oder Gateway-Umgebung. Dies sind Installationsziele und keine Garantie für die Erkennung in jeder Host-Version. Die Richtlinien des Hosts und das Laden der Skills bleiben in der Verantwortung des Hosts.

## Updates und persönliche Änderungen

```bash
npm install -g @evolinkai/cli@latest
evolink skills install
evolink skills status --json
```

Synchronisieren Sie die Skills nach dem Aktualisieren der CLI und bitten Sie den Agenten, sie erneut zu lesen. Persönliche Änderungen bleiben standardmäßig erhalten. Prüfen Sie zuerst die Status modified/conflict. Verwenden Sie --replace-modified erst, wenn Sie entschieden haben, persönliche Inhalte zu ersetzen; die bisherigen Inhalte werden nach ~/.evolink-media/skill-backups/ gesichert. Siehe [Fehlerbehebung bei Skills](/de/cli/billing#skills-discovery).

Ab CLI 0.10.0 prüft `evolink doctor` ohne `--agent` auch die Skill-Kopien, die für die einzelnen Agenten installiert sind. Ist eine Kopie älter als die CLI, fordert `guidance` Sie auf, `evolink skills install` auszuführen; persönliche Änderungen und Konflikte werden gemeldet, aber nie ersetzt. Diese Befunde ändern `ok` nicht. Wie die CLI neue Versionen meldet, lesen Sie unter [So erfahren Sie von einer neuen Version](/de/cli/setup#update-check).

## Ressourcen für Agenten

Geben Sie dem Agenten die [gemeinsamen Regeln und lesbaren Ressourcen](/de/cli-mcp/agent-resources#agent-rules), die [CLI-Referenz](/de/cli/reference) und die [Medienabläufe](/de/cli/workflows). Fragen Sie Modell-Schemas mit models schema MODEL_ID ab. Prüfen Sie das Laden der Skills und die Verbindung zum Konto getrennt. Zur Installation von nativem MCP siehe [MCP-Plugins](/de/mcp/plugins).
