Im [CLI/MCP-Überblick](/de/cli-mcp/overview) wählen Sie nach Client aus. Die gemeinsamen Ressourcen in diesem Bereich behandeln Kosten, Aufträge, Dateien und Anweisungen für Agenten.

Mit EvoLink CLI generieren Agenten mit Terminalzugriff und Terminalbenutzer Bilder, Videos, Musik und Sprache, prüfen Modelle und Parameter, fragen Guthaben und Aufträge ab, laden Referenzen hoch und speichern Originale.

Dieser Bereich beschreibt die veröffentlichte **CLI 0.14.1**. Sie benötigt Node.js 22+ unter macOS, Windows oder Linux. Installieren Sie sie unter dem Benutzer und auf dem Rechner, auf dem der Agent Befehle ausführt. Medien laufen über **Agent/Terminal → CLI → Plattform-API**.

## Installation und Prüfung

Senden Sie diesen Prompt an einen Agenten mit Terminalzugriff. Er entspricht dem Installationsprompt der Website:

```text
Richte EvoLink ein, damit ich hier direkt Bilder, Videos und Audio erzeugen kann.
1. Installiere die CLI: führe `npm install -g @evolinkai/cli` aus.
2. Melde dich an: führe `evolink auth login` aus.
3. Installiere den zugehörigen Skill: führe `evolink skills install` aus.
4. Prüfe die Verbindung und sage mir nach erfolgreicher Prüfung, dass ich loslegen kann.
```

Fügen Sie den Prompt in den Chat ein; die Befehle laufen im Terminal des Agenten oder in Ihrem Terminal. Die Anmeldung im Browser und die Berechtigungen erledigen Sie selbst. Ausführliche Schritte, Erfolgsmerkmale, Updates, Abmeldung und SSH-Callbacks finden Sie unter [Installation und Anmeldung](/de/cli/setup).

Die grundlegende manuelle Reihenfolge lautet:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
evolink doctor --json
```

Warten Sie, bis die Anmeldung abgeschlossen ist, bevor Sie fortfahren. Fügen Sie nicht den ganzen Block ein, ohne auf die Autorisierung zu achten. Lassen Sie den Agenten bestätigen, dass er evolink-cli gelesen hat. Guthabenabfrage und Diagnose erstellen keine kostenpflichtigen Medienaufträge; beginnen Sie mit dem Erstellen erst nach der Prüfung.

## Funktionen der CLI

| Funktion | Verwendung und Anleitung |
|---|---|
| Umgebung und Zugriff | version, auth, setup, doctor; [Installation](/de/cli/setup) |
| Modelle und Parameter | models search/recommend/show/schema, docs search; [Referenz](/de/cli/reference) |
| Kostenschätzung und Zustimmung | estimate erstellt ein lokales Preisangebot; generate nach der Zustimmung; [Ablauf](/de/cli/workflows) |
| Medien | Bilder, Videos, Musik und Sprache entsprechend den Funktionen des Modells |
| Referenzen | upload für lokale Dateien; uploads get prüft den ursprünglichen Beleg |
| Aufträge | get/wait, batch, seitenweiser Verlauf und Wiederaufnahme anhand des Preisangebots |
| Download der Originale | Ein Ergebnis oder alle, Formatprüfungen und Batch-Wiederaufnahme |
| Konto und Nutzung | balance sowie usage mit begrenztem Verlauf, keine vollständige Rechnung |
| Skills | skills install/status und Prüfungen der Erkennung durch den Host |

Die CLI bietet keinen allgemeinen Text-Chat, kein Abbrechen in der Warteschlange, keine Guthabenaufladung, keine Key-Verwaltung, keinen automatischen Schnitt und kein Hosting fertiger Videos. Codeentwicklung und beliebige Dateibearbeitung sind Funktionen des Host-Agenten. Übergeben Sie zuerst die generierten Originale; neue Varianten, Bearbeitungen oder Neugenerierungen brauchen eine entsprechende Zustimmung.

## Erste Erstellung

```text
Erstelle mit EvoLink ein Werbebild für eine Kaffeemarke.
Frage zuerst verfügbare Bildmodelle, Parameter und Kosten ab und erläutere dann die Empfehlung und die Ausgabespezifikation.
Sende nach meiner ausdrücklichen Zustimmung einmal ab, speichere die Auftragskennung und lade das Original herunter; nenne dabei die gemeldeten tatsächlichen Kosten.
```

Folgen Sie dem Ablauf [Modell → Referenzen → Kostenschätzung → Zustimmung → Auftrag → Download](/de/cli/workflows). Die Installation ist keine Zustimmung zu einer kostenpflichtigen Generierung. Kostenschätzungen sind keine endgültige Abrechnung; siehe [Kosten und Fehlerbehebung](/de/cli/billing).

## CLI und MCP

Die CLI-Installation umfasst das ausführbare Programm, gemeinsame Module mit der Geschäftslogik und den mitgelieferten Skill evolink-cli. Sie erfordert kein Klonen von MCP- oder Plugin-Repositories und registriert kein natives MCP. Passport stellt OAuth bereit; das Betriebssystem speichert die Anmeldedaten sicher.

Die Sitzungen von CLI und Remote-MCP werden getrennt verwaltet. Das Konto-OAuth teilt derzeit Berechtigungen, Limits und Pausenstatus des internen Keys. Für Claude oder ChatGPT im Web oder für den nativen Werkzeugaufruf nutzen Sie den [separaten MCP-Bereich](/de/mcp/overview).
