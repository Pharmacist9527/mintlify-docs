Codex kann Medienaufträge über EvoLink CLI ausführen. Diese Seite behandelt die Unterschiede bei Host-Umgebung und Skill; das vollständige gemeinsame Vorgehen steht unter [Installation und Anmeldung](/de/cli/setup). Für native Werkzeuge nutzen Sie direkt die [MCP-Anleitung](/de/mcp/codex).

## Den Agenten installieren lassen

Fügen Sie Folgendes in die Unterhaltung mit dem Agenten ein. Es entspricht dem Prompt der Website. Die Anmeldung im Browser und die Prüfung der Berechtigungen erledigen Sie selbst.

```text
Richte EvoLink ein, damit ich hier direkt Bilder, Videos und Audio erzeugen kann.
1. Installiere die CLI: führe `npm install -g @evolinkai/cli` aus.
2. Melde dich an: führe `evolink auth login` aus.
3. Installiere den zugehörigen Skill: führe `evolink skills install` aus.
4. Prüfe die Verbindung und sage mir nach erfolgreicher Prüfung, dass ich loslegen kann.
```

## Drei Schritte für diesen Client

<Steps>
  <Step title="Gemeinsame Installation und Anmeldung abschließen">
    Installieren Sie auf dem Rechner und unter dem Betriebssystembenutzer, der die Befehle von Codex ausführt; Remote-Sitzungen sind getrennte Umgebungen.

    Öffnen Sie bei der ersten Einrichtung die [Anleitung in fünf Schritten](/de/cli/setup#cli-install): Node.js 22+ prüfen, CLI installieren und die Anmeldung im Browser abschließen. Sie enthält Befehle, Erfolgsmerkmale und Fehlerbehebung. Ist das bereits erledigt, prüfen Sie:

    ```bash
    evolink --version
    evolink auth status --json
    ```

    Achten Sie auf eine CLI-Version und authenticated: true. Je nach fehlgeschlagener Phase siehe [Installationsfehler](/de/cli/billing#cli-install), [Anmeldefehler](/de/cli/billing#login) oder [SSH-Callbacks](/de/cli/setup#ssh-login).
  </Step>
  <Step title="Skill dieses Agenten synchronisieren und Erkennung prüfen">
    ```bash
    evolink skills install --agent codex
    evolink skills status --agent codex --json
    ```

    Das Verzeichnis ist ~/.agents/skills/evolink-cli. current: true bedeutet, dass die Dateien zur CLI passen. Bitten Sie den Agenten:

    ```text
    Bestätige, dass diese Sitzung den Skill evolink-cli erkennen und lesen kann. Prüfe den Zugriff, ohne Medien zu generieren.
    ```

    assistant_discovery: not_checked erfordert weiterhin eine Prüfung durch den Host. Folgen Sie der [Skill-Erkennung](/de/cli/billing#skills-discovery), wenn Dateien vorhanden sind, aber nicht genutzt werden. Prüfen Sie die erforderlichen Ausführungsberechtigungen und lassen Sie persönliche Änderungen unangetastet.
  </Step>
  <Step title="Kostenlos prüfen, bevor Sie Medien erstellen">
    ```bash
    evolink balance --json
    evolink doctor --agent codex --json
    ```

    Die Einrichtung ist abgeschlossen, wenn balance Kontodaten liefert, doctor ok, connection_verified und model_discovery_verified als true meldet und der Agent bestätigt, dass er den Skill gelesen hat. Diese Abfragen erstellen keine kostenpflichtigen Medienaufträge. Auch ein Guthaben von null kann die Verbindung bestätigen.
  </Step>
</Steps>

### Kombinierte Einrichtung bei installierter CLI

```bash
evolink setup --agent codex --json
```

Der Befehl prüft die Umgebung, synchronisiert Skills, meldet bei Bedarf an und prüft den Zugriff. Achten Sie auf setup_complete: true; die Erkennung durch den Host muss weiterhin bestätigt werden. Grenzen Sie Fehler anhand von phase, steps, error und recovery ein.

## Aktualisieren und abmelden

Ab CLI 0.10.0 meldet die CLI neue Versionen selbst; siehe [So erfahren Sie von einer neuen Version](/de/cli/setup#update-check). Synchronisieren Sie nach dem Aktualisieren der CLI den Skill des aktuellen Agenten:

```bash
npm install -g @evolinkai/cli@latest
evolink --version
evolink skills install --agent codex
evolink skills status --agent codex --json
```

Lokale Änderungen bleiben erhalten; `modified` oder `conflict` behandeln Sie nach der [Fehlerbehebung bei Skills](/de/cli/billing#skills-discovery). Führen Sie den folgenden Befehl nur aus, wenn Sie sich von der CLI abmelden möchten; er ist kein Installations- oder Update-Schritt.

```bash
evolink auth logout
```

## Einstiegspunkte für die Fehlerbehebung

| Symptom | Nächster Schritt |
|---|---|
| npm/evolink fehlt, Berechtigungen, Zeitüberschreitung bei der Installation | [Umgebung und Installation](/de/cli/billing#cli-install) |
| Browser hat sich nicht geöffnet, OAuth-Zeitüberschreitung, Fehler im Anmeldedatenspeicher | [Anmeldung und Callbacks](/de/cli/billing#login); [SSH-Anmeldung](/de/cli/setup#ssh-login) |
| Skill installiert, aber der Agent nutzt ihn nicht | [Skill-Erkennung und Ausführungsberechtigung](/de/cli/billing#skills-discovery) |
| Abgesendeter Auftrag mit Zeitüberschreitung oder verlorenem Ergebnis | [Ursprünglichen Auftrag wiederaufnehmen](/de/cli/billing#tasks-and-recovery) |

Folgen Sie nach dem Verbinden dem [Ablauf für den ersten Medienauftrag](/de/cli/workflows#workflows): Modelle, Parameter und Kosten prüfen, zustimmen, dann absenden. Die vollständigen Befehle stehen in der [CLI-Befehlsreferenz](/de/cli/reference).
