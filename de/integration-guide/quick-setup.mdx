## Überblick

Bei der manuellen Einrichtung installieren Sie den Client, bearbeiten eine Konfigurationsdatei und tragen den Endpunkt sowie Ihren API Key ein. Das Einrichtungsskript (`evolink-config`) erledigt all das mit einem einzigen Befehl:

- Prüft Ihre Umgebung und installiert den Client, falls er auf Ihrem Computer noch fehlt
- Trägt den EvoLink-Endpunkt und Ihren API Key ein
- Sendet eine Testnachricht, um zu bestätigen, dass Aufrufe durchgehen
- Sichert jede Datei, bevor es sie ändert, und kann alles mit einem Befehl rückgängig machen

Das Ganze dauert in der Regel weniger als eine Minute.

| Client | Einrichtung mit einem Klick |
|---|---|
| Claude Code CLI | Unterstützt |
| Codex CLI | Unterstützt |
| Andere Clients | Siehe die manuellen Anleitungen unter „KI-Programmierwerkzeuge“ |

<Note>
Die folgenden Befehle gelten für macOS und Linux. Unter Windows folgen Sie bitte vorerst der manuellen Anleitung für [Claude Code CLI](/de/integration-guide/claude-code-cli) oder [Codex CLI](/de/integration-guide/codex-cli).
</Note>

## Voraussetzungen

- **EvoLink API Key**: Melden Sie sich im [EvoLink Dashboard](https://evolink.ai/dashboard) an, erstellen Sie unter API Keys einen Key und kopieren Sie ihn. Ein Key beginnt mit `sk-`.
- **Node.js**: Empfohlen wird Version 22 oder neuer (mindestens 18). Führen Sie zur Prüfung `node -v` in einem Terminal aus. Falls Node.js nicht installiert ist, laden Sie die LTS-Version von der [Node.js-Website](https://nodejs.org/) herunter.

## Claude Code einrichten

Führen Sie in einem Terminal aus:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash
```

Das Skript führt Sie in fünf Schritten durch die Einrichtung (seine Meldungen sind auf Englisch):

<Steps>
  <Step title="Umgebung">
    Prüft Node.js und Claude Code. Ist Claude Code noch nicht installiert, fragt das Skript „Install now?“. Drücken Sie die Eingabetaste, dann wird es für Sie installiert.
  </Step>
  <Step title="API Key">
    Fügen Sie Ihren EvoLink API Key ein und drücken Sie die Eingabetaste. Der eingefügte Text wird nicht angezeigt. Das Skript prüft online, ob der Key gültig ist, und zeigt Ihr Guthaben an.
  </Step>
  <Step title="Modell">
    Wählen Sie das Modell, das Claude Code standardmäßig verwendet. In Claude Code können Sie es jederzeit mit `/model` wechseln.
  </Step>
  <Step title="Änderungen prüfen">
    Das Skript listet die Dateien und Einstellungen auf, die es ändern wird. Drücken Sie die Eingabetaste, um sie zu übernehmen.
  </Step>
  <Step title="Übernehmen und prüfen">
    Nach dem Schreiben der Einstellungen sendet das Skript eine Testnachricht (etwa 0,01 Credits). Kommt eine normale Antwort zurück, ist die Einrichtung abgeschlossen.
  </Step>
</Steps>

Öffnen Sie danach ein neues Terminalfenster und führen Sie aus:

```bash
claude
```

Führen Sie in Claude Code `/status` aus. Zeigt die Zeile Anthropic base URL die EvoLink-Adresse, ist die Einrichtung wirksam.

## Codex CLI einrichten

Führen Sie in einem Terminal aus:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- codex
```

Die Schritte sind dieselben wie oben. Starten Sie Codex danach mit:

```bash
codex -p evolink
```

<Note>
Das Skript legt für Codex ein separates Profil an, `~/.codex/evolink.config.toml`, und ändert Ihre eigene `~/.codex/config.toml` nicht. Codex nutzt EvoLink nur, wenn Sie es mit `-p evolink` starten; ein einfaches `codex` behält Ihre bisherigen Einstellungen.
</Note>

## Was das Skript ändert

### Claude Code

| Datei | Änderung |
|---|---|
| `~/.claude/settings.json` | Trägt den Endpunkt `ANTHROPIC_BASE_URL` und Ihren Key `ANTHROPIC_AUTH_TOKEN` ein; setzt `ANTHROPIC_API_KEY` auf einen leeren Wert, damit ein alter Key auf dem Computer keine 401-Fehler verursachen kann; legt die Modellversion für Sonnet fest; schaltet den Auto-Modus aus (den Grund finden Sie in den FAQ unten). Alles andere in der Datei bleibt erhalten. |
| `~/.claude.json` | Überspringt die Anmeldebildschirme beim ersten Start; markiert mit Ihrer Zustimmung den aktuellen Ordner als vertrauenswürdig. |

### Codex CLI

| Datei | Änderung |
|---|---|
| `~/.codex/evolink.config.toml` | Neue Datei. Enthält den EvoLink-Endpunkt, das Standardmodell und Ihren Key. Nur Sie können sie lesen. |
| `~/.codex/config.toml` | Wird nicht geändert. |

### In beiden Fällen

- Jede Datei wird vor der Änderung in `~/.evolink/backups/` gesichert.
- Das Skript selbst wird unter `~/.evolink/` gespeichert, sein Befehl ist `~/.evolink/bin/evolink-config`. Es ändert weder Ihren PATH noch Ihr Shell-Profil.
- Ihr Key wird nur in den Konfigurationsdateien auf Ihrem Computer gespeichert und nur an die EvoLink API gesendet.

<Note>
`evolink-config` richtet nur die API-Verbindung ein. Es ist ein anderes Werkzeug als das Kommandozeilen-Tool `evolink`, das Bilder, Videos und Audio erzeugt (siehe Bereich CLI/MCP). Sie können beide verwenden.
</Note>

## Prüfen, rückgängig machen und neu einrichten

### Änderungen vorab ansehen (es wird nichts geschrieben)

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --dry-run
```

### Aktuelle Einrichtung prüfen

```bash
~/.evolink/bin/evolink-config doctor
```

Ihr Key ist in der Ausgabe verborgen, Sie können sie also unverändert an den Support senden. Für Codex verwenden Sie `~/.evolink/bin/evolink-config doctor codex`.

### Einrichtung rückgängig machen

```bash
~/.evolink/bin/evolink-config reset
```

Das Skript stellt alles wieder her, was es geändert hat. Für Codex verwenden Sie `~/.evolink/bin/evolink-config reset codex`.

### Key oder Standardmodell ändern

Führen Sie den Einrichtungsbefehl erneut aus.

## FAQ

### 1. Was tun, wenn Node.js nicht gefunden wird?

Installieren Sie die LTS-Version von der [Node.js-Website](https://nodejs.org/), öffnen Sie ein neues Terminal und führen Sie den Einrichtungsbefehl erneut aus.

### 2. Ich habe bereits manuell eingerichtet. Werden meine Einstellungen überschrieben?

Nicht als Ganzes. Das Skript ändert nur die oben aufgeführten Punkte und behält alles andere bei. Vor dem Schreiben zeigt es für jeden Punkt den alten und den neuen Wert an und sichert die Originaldatei.

### 3. Warum gibt es in Claude Code keinen Auto-Modus (auto mode)?

Im Auto-Modus fragt Claude Code nicht mehr vor jedem Befehl nach. Stattdessen sendet es zuerst eine Prüfanfrage, und ein Modell entscheidet, ob der Befehl sicher ausgeführt werden kann. Diese Prüfanfragen werden wie jede andere Anfrage nach Tokens abgerechnet. Sie verwenden `claude-sonnet-5`, unabhängig davon, welches Standardmodell Sie gewählt haben.

Damit keine unerwarteten Kosten entstehen, schaltet das Skript den Auto-Modus standardmäßig aus, und Claude Code fragt Sie, bevor es einen Befehl ausführt. Darauf weist das Skript auch am Ende der Einrichtung hin.

Wenn Sie den Auto-Modus nutzen möchten, schalten Sie ihn so ein:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --auto-mode
```

Um ihn wieder auszuschalten, führen Sie den Einrichtungsbefehl noch einmal ohne `--auto-mode` aus.

### 4. Kann ich das Skript lesen, bevor ich es ausführe?

Ja. Laden Sie es herunter, lesen Sie es und führen Sie es dann aus:

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh -o setup.sh
less setup.sh
bash setup.sh
```

### 5. Was tun bei der Meldung „Rate limited (429)“?

Jedes Konto kann seinen Key nur begrenzt oft pro Minute prüfen lassen. Wenn Sie das Skript mehrmals hintereinander ausführen, erscheint diese Meldung. Warten Sie die in der Meldung angegebene Anzahl Sekunden ab und führen Sie das Skript dann erneut aus.

### 6. Was tun, wenn es nach der Einrichtung immer noch nicht funktioniert?

Führen Sie `~/.evolink/bin/evolink-config doctor` aus und senden Sie die Ausgabe an den Support. Sie können auch die Abschnitte zur Fehlerbehebung auf den Seiten [Claude Code CLI](/de/integration-guide/claude-code-cli) und [Codex CLI](/de/integration-guide/codex-cli) lesen.
