CLI・MCP・スキル・プラグインに共通する考え方、現在のスキルの対象範囲、共通の指示、Markdown、llms.txt については、[エージェント向けリソース](/ja/cli-mcp/agent-resources)にまとめています。この既存の URL は、古いリンクのために引き続き利用できます。

<span id="skills" />
## ネイティブ MCP のエージェントが読むべきもの

1. [MCP の概要](/ja/mcp/overview)とクライアントの設定ページを読み、ホストを設定して認証します。
2. [MCP ツールリファレンス](/ja/mcp/tools)と、実際のツールのスキーマを参照します。
3. 必要に応じて、[プラグインの手順](/ja/mcp/plugins)に従って、evolink-mcp のガイダンスまたはホストのプラグインをインストールします。スキルを読んでも、ツールが登録されたり認証されたりするわけではありません。
4. [エージェント共通のルール](/ja/cli-mcp/agent-resources#agent-rules)を適用し、[MCP のトラブルシューティング](/ja/mcp/billing#faq)を使って、実際の呼び出しを検証します。

evolink-cli はターミナルコマンドの使い方を案内し、ネイティブ MCP は evolink-mcp のツール向けの説明を使います。インストールと認証は、別々に検証してください。llms.txt はドキュメントの索引です。MCP のエンドポイントは、引き続き https://mcp.evolink.ai/mcp です。
