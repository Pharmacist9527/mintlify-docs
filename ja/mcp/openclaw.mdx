このページでは、OpenClaw でのネイティブ MCP を扱います。リモートのサービスは Streamable HTTP とブラウザの OAuth を使い、EvoLink CLI は必要ありません。コマンドやスキルを実行する場合は、別の [CLI ガイド](/ja/cli/openclaw)を使ってください。

## リモート MCP を接続する

ネイティブツールを使う場合は、**Streamable HTTP + OAuth** と、次のサーバー URL を使います：

```text
https://mcp.evolink.ai/mcp
```

CLI のインストールは必要ありません。既存の設定をバックアップし、EvoLink の部分だけをマージして、ほかのサービスはそのまま残してください。コマンドによる登録か、手動での登録のどちらかを選びます。

<Steps>

<Step title="リモート MCP に対応しているかを確認する">

```bash
openclaw mcp --help
```

実際に使っている Gateway のバージョンが、Streamable HTTP と OAuth に対応している必要があります。これらのコマンドがない場合は、そのバージョンのアップグレード手順に従うか、[別の CLI ガイド](/ja/cli/openclaw)を使ってください。古いホスト向けに、フラグを勝手に作らないでください。

</Step>

<Step title="サーバーを追加して OAuth を設定する">

```bash
openclaw mcp add evolink --url https://mcp.evolink.ai/mcp --transport streamable-http
```

Gateway の `~/.openclaw/openclaw.json`、または実際に使っている設定で、生成されたほかのフィールドを残したまま、`mcp.servers.evolink` の中の `auth` を `"oauth"` に設定します。対応しているバージョンの Control UI では、Settings → MCP から追加して有効にできます。

</Step>

<Step title="認証、疎通確認、照会を行う">

```bash
openclaw mcp login evolink
openclaw mcp doctor evolink --probe
```

ブラウザで承認したら、実際の Gateway が持つエージェントを使って、下記のプロンプトを送信します。変更が反映されない場合は、その接続を持つ Gateway を再読み込みしてください。ノート PC のターミナルを再読み込みしても、リモートの Gateway は再読み込みされません。

</Step>

</Steps>

ツールを利用できるかどうかは、OpenClaw のツールポリシーにも左右されます。バージョン、認証、接続の所有先については、[OpenClaw のドキュメント](https://docs.openclaw.ai/tools/mcp)を参照してください。

認証が済んだら、エージェントのチャットで次を送信します：

```text
EvoLink でアカウントの残高を確認し、利用可能な画像モデルを検索してください。まだ生成しないでください。
```

**成功の目安**：`check_balance` と `search_models` の実際の呼び出しが結果を返すこと。これらのツールは、実際の MCP 接続で検証してください。

## アップデート、切断、トラブルシューティング

ホスト型の MCP サーバーは、EvoLink が更新します。設定を変更したら、実際に使っているクライアントのセッションを再読み込みしてください。必要に応じて、そのクライアントの OAuth 操作から再認証します。切断するには、ホストの MCP 設定で EvoLink を無効にするか、ログアウトするか、削除してください。ほかのサーバーはそのまま残します。

| 症状 | 対処 |
|---|---|
| URL を追加したのにツールがない | 接続を有効にし、認証を完了して、再読み込みし、組織のポリシーを確認します |
| 401、または認証を求められる | この MCP 接続を再認証し、元のタスク ID を保持します |
| 403、またはツールが拒否される | ホストの権限、アカウントやキーの状態、ネットワークのエラーを確認します |
| タイムアウト、またはレスポンスを受け取れない | 生成し直すのではなく、元の操作を照会して復旧します |
| リンクだけが表示される、またはプレビューがグレーになる | 自動的に作り直さずに、オリジナルファイルを開いて渡します |

[MCP の料金、アクセス、トラブルシューティング](/ja/mcp/billing#faq)を参照してください。送信の前に、[制作のワークフロー](/ja/mcp/overview#workflows)を読んでください。呼び出しの形は、[MCP ツールリファレンス](/ja/mcp/tools)にあります。
