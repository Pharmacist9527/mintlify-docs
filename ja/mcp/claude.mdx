Claude のチャットは**リモート MCP** を使います。設定は、クライアントとブラウザで行います。ローカルへの CLI のインストールや、個人用の API Key は必要ありません。

## 始める前に

EvoLink と Claude のアカウントに加えて、カスタム MCP を利用できるクライアントのバージョン、プラン、ワークスペースの権限が必要です。カスタム MCP を追加する操作が利用できない場合は、チャットでターミナル向けの手順を実行するのではなく、まずホスト側の利用権限を確認してください。

## EvoLink を手順に沿って接続する

<Steps>

<Step title="コネクタの追加画面を開く">

[Claude に追加](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp)を選びます。これは公式サイトのボタンと同じもので、名前と URL があらかじめ入力されます。開かない場合は、Claude の Connectors 設定で、カスタムコネクタを追加してください。

</Step>

<Step title="URL を確認してコネクタを追加する">

名前を EvoLink とし、次のリモートサーバー URL を使います：

```text
https://mcp.evolink.ai/mcp
```

Streamable HTTP のリモート接続と、OAuth（ブラウザでのログイン）を使います。ドキュメントの URL や REST の URL は入力しないでください。保存済みの一覧に EvoLink が表示されることを確認します。

</Step>

<Step title="ブラウザでログインして承認する">

Connect/Authenticate を選び、EvoLink にログインして、アカウントと権限を確認し、承認してから Claude に戻ります。ウィンドウが開かない場合は、現在表示されているログイン操作を使ってください。古いリンクの有効期限が切れた場合は、新しく試行をやり直します。

</Step>

<Step title="会話で有効にして検証する">

会話のコネクタまたはツールの選択で EvoLink を有効にしてから、下記のプロンプトを送信します。コネクタを保存しただけでは、現在のチャットで有効にはなりません。

**成功の目安**：実際の残高とモデルの結果が返ること。Claude Code は、別のターミナルクライアントです。[Claude Code の設定ページ](/ja/mcp/claude-code)を使ってください。

</Step>

</Steps>

コネクタを利用できるかどうか、プラン、ワークスペースの制限については、[Claude の公式ガイド](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)を参照してください。

## 無料の検証と、はじめてのメディアタスク

接続できたら、EvoLink を有効にした会話で、次を送信します：

```text
EvoLink でアカウントの残高を確認し、利用可能な画像モデルを検索してください。まだ生成しないでください。
```

`check_balance` と `search_models` が実際に呼び出されたことを確認してください。ログインやこれらの照会では、有料のメディアタスクは作成されません。生成するときは、内容と仕様を伝え、提案されたモデル、パラメータ、見積もりを確認してから、送信を明確に承認します。[はじめてのメディアワークフロー](/ja/mcp/overview#workflows)を参照してください。

参照素材には、モデルが対応している、公開アクセス可能なリンクを使ってください。チャットの添付ファイルでは、元のファイルのバイト列が MCP に渡されないことがあり、リモートのサービスは、お使いのコンピュータ上のパスを読み取れません。[参照素材とアップロード](/ja/mcp/overview#files)を参照してください。

## よくある問題

| 症状 | 次の手順 |
|---|---|
| カスタムコネクタの操作が表示されない | 現在のホストで、プラン、バージョン、ワークスペースの権限を確認します |
| ブラウザでログインしても、未認証のままになる | 元のクライアントに戻り、現在のフローを完了します。[認証のトラブルシューティング](/ja/mcp/billing#login)を参照してください |
| 接続を追加したのに、チャットにツールが表示されない | インストールと有効化の状態を確認し、EvoLink を選択して、新しい会話を開きます。[MCP のトラブルシューティング](/ja/mcp/billing#mcp-connection)を参照してください |
| 残高の照会はできるのに、生成ツールが使えない | ホストのツールのオン／オフ設定と、ワークスペースの権限を確認します。キーを使ってそれらを回避しないでください |
| ネットワークのタイムアウト、または 403 | ホスト、ログインページ、ツールのリクエストのどこで失敗しているかを特定します。サポートに伝えるために、時刻とエラーを残しておいてください |
| 結果がリンクだけ、またはプレビューがグレーになる | オリジナルファイルを開いて保存します。[ダウンロードとプレビューのトラブルシューティング](/ja/mcp/billing#download)を参照してください |

## 再読み込みと切断

変更したあとは、接続とツールを再読み込みするか、新しい会話を開いてください。必要に応じて、このホストから再認証します。このクライアントからのアクセスを止めるには、その設定で切断またはログアウトしてください。共有キーの上限と一時停止は、EvoLink で管理します。[プラグイン](/ja/mcp/plugins)と[料金とトラブルシューティング](/ja/mcp/billing#faq)を参照してください。
