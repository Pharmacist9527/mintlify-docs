このページでは、Cursor でのネイティブ MCP を扱います。リモートのサービスは Streamable HTTP とブラウザの OAuth を使い、EvoLink CLI は必要ありません。コマンドやスキルを実行する場合は、別の [CLI ガイド](/ja/cli/cursor)を使ってください。

## リモート MCP を接続する

ネイティブツールを使う場合は、**Streamable HTTP + OAuth** と、次のサーバー URL を使います：

```text
https://mcp.evolink.ai/mcp
```

CLI のインストールは必要ありません。既存の設定をバックアップし、EvoLink の部分だけをマージして、ほかのサービスはそのまま残してください。コマンドによる登録か、手動での登録のどちらかを選びます。

<Steps>

<Step title="Cursor にサーバーを追加する">

[Cursor に追加](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9)を選び、ブラウザが Cursor を開くことを許可して、名前と URL を確認してから、確定します。アプリケーションが開かない場合は、下記の手動設定を使ってください。

</Step>

<Step title="接続を有効にして認証する">

Cursor の MCP 設定を開き、EvoLink を有効にして、ブラウザでのログインと承認を進めます。Cursor に戻り、接続とツールの一覧を確認してください。

</Step>

<Step title="Agent で無料で検証する">

ツールの実行権限がある Agent の会話を開き、下記の検証用プロンプトを送信します。ツールが見つからない場合は、接続を再読み込みするか、新しい会話を開始してください。また、プロジェクトの設定が、グローバルの項目を上書きしたり無効にしたりしていないかを確認してください。

</Step>

</Steps>

手動で設定する場合、グローバルには `~/.cursor/mcp.json` を、単一のプロジェクトには `.cursor/mcp.json` を使います。既存の `mcpServers` オブジェクトにマージしてください：

```json
{
  "mcpServers": {
    "evolink": {
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

[Cursor の設定](https://cursor.com/docs/mcp)を参照してください。

認証が済んだら、エージェントのチャットで次を送信します：

```text
EvoLink でアカウントの残高を確認し、利用可能な画像モデルを検索してください。まだ生成しないでください。
```

**成功の目安**：`check_balance` と `search_models` の実際の呼び出しが結果を返すこと。これらのツールは、実際の MCP 接続で検証してください。

## アップデート、切断、トラブルシューティング

ホスト型の MCP サーバーは、EvoLink が更新します。設定を変更したら、実際に使っているクライアントのセッションを再読み込みしてください。必要に応じて、そのクライアントの OAuth 操作から再認証します。切断するには、ホストの MCP 設定で EvoLink を無効にするか、ログアウトするか、削除してください。ほかのサーバーはそのまま残します。

| 症状 | 対処 |
|---|---|
| URL を追加したのにツールがない | 接続を有効にし、認証を完了して、再読み込みし、組織のポリシーを確認します |
| 401、または認証を求められる | この MCP 接続を再認証し、元のタスク ID を保持します |
| 403、またはツールが拒否される | ホストの権限、アカウントやキーの状態、ネットワークのエラーを確認します |
| タイムアウト、またはレスポンスを受け取れない | 生成し直すのではなく、元の操作を照会して復旧します |
| リンクだけが表示される、またはプレビューがグレーになる | 自動的に作り直さずに、オリジナルファイルを開いて渡します |

[MCP の料金、アクセス、トラブルシューティング](/ja/mcp/billing#faq)を参照してください。送信の前に、[制作のワークフロー](/ja/mcp/overview#workflows)を読んでください。呼び出しの形は、[MCP ツールリファレンス](/ja/mcp/tools)にあります。
