ChatGPT のチャットは**リモート MCP** を使います。設定は、クライアントとブラウザで行います。ローカルへの CLI のインストールや、個人用の API Key は必要ありません。

## 始める前に

EvoLink と ChatGPT のアカウントに加えて、カスタム MCP を利用できるクライアントのバージョン、プラン、ワークスペースの権限が必要です。カスタム MCP を追加する操作が利用できない場合は、チャットでターミナル向けの手順を実行するのではなく、まずホスト側の利用権限を確認してください。

## EvoLink を手順に沿って接続する

<Steps>

<Step title="カスタム MCP の追加画面を開く">

[ChatGPT Plugins](https://chatgpt.com/plugins) を開き、Add またはプラスボタンを選んでから、**Create/Add custom MCP server** を選びます。これは、公式サイトで案内している設定の入口です。表示名は、バージョンによって異なる場合があります。項目が見つからない場合は、ワークスペースの利用権限を確認してください。

</Step>

<Step title="接続情報を入力する">

| 項目 | 値 |
|---|---|
| アイコン（任意） | [EvoLink のアイコン](https://cdn.evolink.ai/next/evolink-logo.png)をダウンロードして、アップロードします。フォームにアイコンの項目がない場合は、省略してください |
| 名前 | EvoLink |
| 接続 | サーバー URL |
| サーバー URL | `https://mcp.evolink.ai/mcp` |
| 認証 | OAuth |
| Client ID / Client Secret | デフォルトのままにします。プラットフォームの API Key を入力しないでください |

リモート HTTP を使い、末尾の `/mcp` は残してください。接続に関する確認メッセージを読み、**Create as a plugin** を選びます。

</Step>

<Step title="インストールしてアカウントを認証する">

個人用のプラグインにある EvoLink を開き、インストールまたは接続します。認証を求められたら、ブラウザで EvoLink にログインし、アカウントと権限を確認して、承認します。フローは開いたままにし、そのあとで ChatGPT に戻ってください。設定の作成と、プラグインのインストールは、別々の手順です。認証の操作は、異なる段階で表示されることがあります。

</Step>

<Step title="会話で有効にして検証する">

新しい会話を開始し、`@` で EvoLink を選択します。画面に Chat / Work のタブがある場合は、プラグインを使う会話を始める前に、**Work** に切り替えてください。下記の、無料で検証するためのプロンプトを送信します。

**成功の目安**：設定が完了したという説明だけでなく、実際のアカウント残高と利用可能なモデルが返ること。

</Step>

</Steps>

[OpenAI のカスタム MCP](https://developers.openai.com/api/docs/guides/custom-mcp-server)と[プラグインのクイックスタート](https://developers.openai.com/plugins/quickstart)を参照してください。個人用の接続を作成できても、EvoLink が公開ディレクトリに掲載されているという意味ではありません。

## 無料の検証と、はじめてのメディアタスク

接続できたら、EvoLink を有効にした会話で、次を送信します：

```text
EvoLink でアカウントの残高を確認し、利用可能な画像モデルを検索してください。まだ生成しないでください。
```

`check_balance` と `search_models` が実際に呼び出されたことを確認してください。ログインやこれらの照会では、有料のメディアタスクは作成されません。生成するときは、内容と仕様を伝え、提案されたモデル、パラメータ、見積もりを確認してから、送信を明確に承認します。[はじめてのメディアワークフロー](/ja/mcp/overview#workflows)を参照してください。

参照素材には、モデルが対応している、公開アクセス可能なリンクを使ってください。チャットの添付ファイルでは、元のファイルのバイト列が MCP に渡されないことがあり、リモートのサービスは、お使いのコンピュータ上のパスを読み取れません。[参照素材とアップロード](/ja/mcp/overview#files)を参照してください。

## よくある問題

| 症状 | 次の手順 |
|---|---|
| カスタムコネクタの操作が表示されない | 現在のホストで、プラン、バージョン、ワークスペースの権限を確認します |
| ブラウザでログインしても、未認証のままになる | 元のクライアントに戻り、現在のフローを完了します。[認証のトラブルシューティング](/ja/mcp/billing#login)を参照してください |
| 接続を追加したのに、チャットにツールが表示されない | インストールと有効化の状態を確認し、EvoLink を選択して、新しい会話を開きます。[MCP のトラブルシューティング](/ja/mcp/billing#mcp-connection)を参照してください |
| 残高の照会はできるのに、生成ツールが使えない | ホストのツールのオン／オフ設定と、ワークスペースの権限を確認します。キーを使ってそれらを回避しないでください |
| ネットワークのタイムアウト、または 403 | ホスト、ログインページ、ツールのリクエストのどこで失敗しているかを特定します。サポートに伝えるために、時刻とエラーを残しておいてください |
| 結果がリンクだけ、またはプレビューがグレーになる | オリジナルファイルを開いて保存します。[ダウンロードとプレビューのトラブルシューティング](/ja/mcp/billing#download)を参照してください |

## 再読み込みと切断

変更したあとは、接続とツールを再読み込みするか、新しい会話を開いてください。必要に応じて、このホストから再認証します。このクライアントからのアクセスを止めるには、その設定で切断またはログアウトしてください。共有キーの上限と一時停止は、EvoLink で管理します。[プラグイン](/ja/mcp/plugins)と[料金とトラブルシューティング](/ja/mcp/billing#faq)を参照してください。
