クライアントから選ぶ場合は、[CLI/MCP の概要](/ja/cli-mcp/overview)を参照してください。このセクションの共通リソースでは、料金、タスク、ファイル、エージェント向けの指示を扱っています。

EvoLink MCP は、モデルの探索、見積もり、メディア生成、参照素材、タスク、残高を、エージェントのネイティブツールとして提供します。このセクションでは MCP を扱います。ターミナルコマンドと evolink-cli については、[別の CLI セクション](/ja/cli/overview)を参照してください。

このガイドは、リリース済みの **MCP 1.12.1** を対象としています。リモート MCP には16個のツールがあり、ブラウザの OAuth を使います。ローカル stdio には14個のツールがあり、個人用の API Key を使います。実行の前に、現在のアカウントで使えるモデルと入力を照会してください。

## クイックスタート：リモート MCP

<Steps>
<Step title="サーバーを追加する">
EvoLink という名前のカスタム MCP またはコネクタを、URL https://mcp.evolink.ai/mcp で追加します。上記のクライアント別ガイドに従ってください。ローカルの MCP パッケージは必要ありません。
</Step>
<Step title="ブラウザでログインして認証する">
OAuth を選択し、EvoLink にログインして、アカウントと権限を確認し、承認してから戻ります。接続とツールを有効にしてください。CLI へのログインは、ホスト側の MCP の認証の代わりにはなりません。
</Step>
<Step title="実際のツールを無料で検証する">
次を送信し、実際の残高とモデルの結果が返ることを確認します：

```text
EvoLink で残高を確認し、利用可能な画像モデルを検索してください。まだ生成しないでください。
```

check_balance と search_models の呼び出しが成功すれば、アクセスできることが確認できます。ツール一覧が表示されるだけでは、確認になりません。この確認では、有料のメディアタスクは作成されません。
</Step>
</Steps>

stdio のみに対応するクライアントの場合は、[ローカル MCP の設定](/ja/mcp/other-clients#local-mcp)に従ってください。起動方法と認証は、別途設定します。

## はじめての生成

接続できたら、やりたいことを伝えます：

```text
EvoLink で、暖かい光、クリーム色の陶器のカップ、上部にブランドのテキストを入れる余白のある、コーヒーブランドの広告を作成してください。
適したモデルを比較し、出力仕様、見積もり、制限を示してください。私の承認を待ってください。
オリジナル画像のリンクと、報告された最終的な請求額を返してください。結果を自動的に再生成したり変更したりしないでください。
```
  </Tab>
  <Tab title="動画">
```text
EvoLink で、海に沈む夕日の短い動画を作成してください。まず、適したモデル、対応している長さ、品質、音声のオプション、見積もりを示してください。
承認後に一度だけ送信し、タスク ID を保存して、完了するまで照会してください。オリジナル動画のリンクと、報告された請求額を返してください。
```
  </Tab>
  <Tab title="音声">
```text
EvoLink で、“欢迎来到我们的咖啡店” と話す中国語のウェルカム音声を生成してください。
読み上げ音声モデルを選び、声と入力の要件を確認し、課金について説明したうえで、承認を待ってから生成し、オリジナルの音声を返してください。
```

生成には EvoLink のクレジットが使われます。これらのプロンプトは、アシスタントに承認を待つよう求めています。アカウントの認証、ホストのツール権限、タスク料金の承認は、それぞれ別のものです。ネイティブ MCP には、サーバー側で用意された会話内の承認ボタンはありません。エージェントが、このタスクについて明確な承認を得る必要があります。[課金と認証](/ja/mcp/billing)を参照してください。

## 仕組み

リモート MCP は `お使いのアシスタント → EvoLink MCP → プラットフォーム API` の経路をたどります。OAuth のログインはホストが管理し、ツールはリモートのサービスが実行します。ブラウザのチャットクライアントには、Node.js も EvoLink CLI も必要ありません。

ローカル stdio は `お使いのアシスタント → ローカルの MCP プロセス → プラットフォーム API` の経路をたどります。アシスタントを実行するマシンに Node.js 20 以上をインストールし、ホストにプロセスを起動させ、プラットフォームの API Key を指定してください。設定については、[その他の MCP クライアント](/ja/mcp/other-clients#local-mcp)を参照してください。

どちらのモードでも、モデル、見積もり、生成、タスクの主要なツールが提供されます。リモート MCP では、これに加えて `prepare_upload` と `get_upload` が提供されます。任意で使えるスキルやプラグインは、操作の手引きを提供するものです。サーバーの登録、アカウントの認証、ホストのツール権限の代わりにはなりません。

| 目的 | ツール |
|---|---|
| 残高とアカウントへのアクセスを確認する | `check_balance` |
| モデル、パラメータ、ドキュメントを探す | `search_models`、`get_model`、`search_docs` |
| タスクに合う候補を比較する | `recommend_models` |
| 料金を見積もる | `estimate_cost` |
| 画像、動画、音声を生成する | `generate_image`、`generate_video`、`generate_audio` |
| タスクを照会する、待機する、一覧表示する | `get_task`、`list_tasks` |
| アカウントの使用量を確認する | `get_task_usage` |
| 参照素材をアップロードする | `upload_file`。リモートには `prepare_upload`、`get_upload` もあります |

これらのツールは、コード開発、ローカルでの動画編集、ウェブサイト構築を提供しません。エージェントのホストが、そうした機能を独自に備えていることはあります。EvoLink について説明するときは、それらをホストの機能として扱ってください。

## ステップ 1：モデルを選び、入力を検証する

現在の候補は `search_models` または `recommend_models` で調べ、正確な ID、対応している機能、必須項目、制限は `get_model` で確認します。補足の説明が必要な場合は `search_docs` を使います。シリーズ名が、有効な送信用 ID であるとは限りません。

選ぶ順序、比較すべき新しいシリーズ、価格ルールについては、[モデル、料金、クォータ](/ja/cli-mcp/models-and-billing#models)を参照してください。現在のアカウントのモデル一覧と入力を確認してください。例に挙げたモデルは、デフォルトの推奨ではありません。

次の例では `z-image-turbo` を使います。どのモデルも、使う前にパラメータを確認してください：

```json
{"name":"get_model","arguments":{"model":"z-image-turbo"}}
```

<span id="files" />

## ステップ 2：参照素材を準備する

入力がテキストだけの場合、アップロードは不要です。参照画像、参照動画、参照音声を使う場合は、まず対応している種類、数、サイズの制限を確認してください。

1. **アクセス可能な URL**：`file_url` を指定して `upload_file` を呼び出します。サーバーがその URL を取得できる必要があります。ユーザーのコンピュータ上のパスは、公開 URL ではありません。
2. **小さなインラインファイル**：リモートの `upload_file` は、最大 1 MiB の base64 コンテンツを受け付けます。内容に合った MIME タイプが必要です。大きなファイルは、ツールのメッセージに含めないでください。
3. **リモート MCP でのローカルファイル**：`prepare_upload` を呼び出し、ファイルにアクセスでき HTTP を使える環境からアップロードしてから、`get_upload` でレシートを確認します。アップロードの上限は 95 MiB で、モデルごとの制限も適用されます。アップロード許可は1回限りで、約15分で失効します。状態確認用 URL の有効期間は約1時間です。
4. **ローカル stdio**：`upload_file` は、ローカルの `file_path` に対応しています。これは MCP プロセスが動作するマシン上の絶対パスであり、チャットしているユーザーのコンピュータ上のパスとは限りません。ファイルサービスとモデルの制限は、引き続き適用されます。

```json
{"name":"prepare_upload","arguments":{"file_name":"reference.png"}}
```

```json
{"name":"get_upload","arguments":{"upload_id":"UPLOAD_ID"}}
```

チャットの添付ファイルが、そのままモデルで使える URL になるわけではありません。ホストがファイルを読み取れない、またはアップロードできない場合は、アクセス可能な URL を求めてください。結果が不明な場合は、元の `upload_id` を保持してください。すぐにアップロードし直してはいけません。レシートの互換性は、ファイルサービスのデプロイ環境によって異なります。参照素材の有効期間は、通常72時間です。失効した入力は再アップロードし、リクエストを更新してください。

<span id="images" />

## ステップ 3：見積もり、承認、画像の生成

見積もりの前に、最終的な入力を準備します。モデル、画像の枚数、サイズ、内容、見積もり額を示してください。見積もりは、最終的な精算額を保証するものではありません。リリース済みバージョンで価格がカバーされている範囲と制限については、[料金](/ja/mcp/billing#pricing)を参照してください。

```json
{"name":"estimate_cost","arguments":{"model":"z-image-turbo","input":{"prompt":"A minimalist coffee advertisement with a ceramic cup"}}}
```

生成を呼び出すのは、このプランと見積もり額が明確に承認されてからにしてください。`client_request_id` は、16–96文字の、変わらないリクエスト ID です。同じ送信を再試行するときは、そのリクエスト ID と入力を変えてはいけません。下記の予算は、パラメータの使い方を示すだけのものです。実際には、ユーザーが明示した予算に基づいて設定してください：

```json
{"name":"generate_image","arguments":{"model":"z-image-turbo","input":{"prompt":"A minimalist coffee advertisement with a ceramic cup"},"client_request_id":"coffee-image-demo-001","max_cost_usd":1}}
```

`max_cost_usd` は送信前のチェックであり、最終請求額に対して強制される上限ではありません。`estimate_cost` は、これを受け付けません。ホストがツールの呼び出しを許可していても、それだけで購入が承認されたことにはなりません。

見積もりや確認は不要だとアシスタントに伝えた場合（たとえば「直接生成して」）、アシスタントは `skip_estimate: true` を渡し、指定された範囲について、確認なしで送信します。[見積もりなしで生成する](/ja/mcp/tools#skip-estimate)を参照してください。同じモデルで複数の画像やタスクを扱う場合は、`inputs`（最大50件）を `estimate_cost` と生成ツールに渡します。見積もり、承認、呼び出しがそれぞれ一度で済み、すべての task_id がまとめて返されます。[バッチ](/ja/mcp/tools#batches)を参照してください。

<span id="video" />

## 動画：長さ、解像度、サウンド、参照素材を確認する

`get_model` を使って、テキストからの動画生成、または画像からの動画生成の正確な ID を調べます。長さ、解像度、サウンドのオプション、参照動画は、価格に影響することがあります。異なる入力に対する見積もりを使い回さないでください。同じシリーズのタスクでも、異なる ID を使うことがあります。

パラメータを検証する → 参照素材をアップロードする → 最終的な入力で `estimate_cost` を呼び出す → プランを示して明確な承認を得る → 同じ入力で `generate_video` を呼び出す → 元のタスクを照会する → オリジナルの動画を渡す。

`media_seconds` が必要な場合は、実測した入力の長さを使ってください。必要な実測値が分からない場合、価格が不完全な場合、予算との比較ができない場合は、いったん止めてください。グレーのサムネイルを直すために、完成した動画を自動的に編集したり再生成したりしないでください。

<span id="audio" />

## 音声：音楽と読み上げ音声を区別する

音楽には、利用可能な Suno v6 のモデルを比較してください。ナレーションやボイスオーバーには、適切な読み上げ音声モデルを使います。モデルのパラメータを確認し、テキスト、言語、声、歌詞、長さ、参照音声のうち必要なものを準備してから、最終的な入力で見積もり、承認を得て、`generate_audio` を呼び出します。

音声の価格が不完全であっても、無料で使えるわけではありません。完了したタスクから得たオリジナルの音声の URL を渡し、返されたすべての出力を保持して、その実際の形式と保存方法を説明してください。

<span id="tasks" />

## ステップ 4：元のタスクを待機、照会、復旧する

生成は、結果を返すことも、`task_id` を返すこともあります。生成をもう一度送信するのではなく、そのタスクを照会してください。`get_task.wait_seconds` は、1回の呼び出しの中で待機する時間で、0–45秒を指定できます。待機がタイムアウトしても、終了するのはその待機だけです。

```json
{"name":"get_task","arguments":{"task_id":"TASK_ID","wait_seconds":30}}
```

バッチ照会には、`task_ids` を指定して `list_tasks` を使います。履歴を調べる場合は、そのフィルターを使います。ID が返される前に送信がタイムアウトした場合は、復旧のために、元のリクエスト ID、入力、認証情報、エラーを保持してください。原因を調べるために、アカウントやリクエスト ID を切り替えて生成し直さないでください。

現在、キューをキャンセルするための、利用できる公開ツールはありません。エージェントの待機を止めたり、ページを閉じたり、MCP を切断したりしても、サーバー側のタスクはキャンセルされません。また、課金が発生しなかったことや、返金が完了したことの根拠にもなりません。

<span id="delivery" />

## ステップ 5：オリジナルの結果を渡す

完了したら、アクセス可能なオリジナルの URL を、モデル、出力の数、判明している料金の情報、有効期限とともに返してください。生成されたオリジナルファイルの有効期間は、通常24時間です。早めに保存してください。ホストがプレビューを表示することもあります。結果がリンクだけの場合や、サムネイルがグレーの場合は、まずオリジナルの URL を確認してください。

保存の前に、HTTP ステータス、コンテンツタイプ、実際のファイル形式を確認してください。エラーページはメディアではありません。Python のデフォルトのリクエストがブロックされる場合は、自分で管理しているダウンロード用コードで、製品の User-Agent を設定できます。[ダウンロードのトラブルシューティング](/ja/mcp/billing#download)を参照してください。

受け渡しやプレビューの問題を、承認のない再生成で解決しようとしないでください。ユーザーが別途編集を求めた場合は、ホストの該当する機能を使い、必要な料金の承認を得てください。

引数と結果については [MCP ツールリファレンス](/ja/mcp/tools)を、エージェント向けの指示の全体については[スキルとエージェントが読めるリソース](/ja/cli-mcp/agent-resources)を参照してください。
