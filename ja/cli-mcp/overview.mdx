お使いのエージェントから EvoLink を使って、画像、動画、音楽、読み上げ音声の生成、モデルと料金の確認、参照素材のアップロード、タスクの追跡、オリジナルファイルの保存ができます。接続方法を選び、その方法のインストール手順と無料の検証手順に従ってください。

## 接続方法を選ぶ

| 作業する場所 | おすすめのルート | インストールと認証 |
|---|---|---|
| Claude のチャットまたは ChatGPT | [リモート MCP](/ja/mcp/overview) | 接続を追加し、ブラウザの OAuth で認証します。CLI のインストールは不要です |
| ターミナルでコマンドを実行できる Codex、Claude Code、Cursor、OpenClaw、Hermes | [CLI](/ja/cli/setup) | CLI をインストールしてログインし、スキルをインストールして読み込みます |
| ターミナル、SSH、スクリプト | [CLI](/ja/cli/setup) | 実行環境にインストールします。SSH にはコールバック用の別手順があります |
| ネイティブ MCP ツールを使うターミナルエージェント | [MCP クライアントガイド](/ja/mcp/overview#choose-your-assistant) | ホスト側の接続を直接設定して認証します |
| ローカル stdio のみに対応するクライアント | [ローカル MCP](/ja/mcp/other-clients#local-mcp) | ローカルプロセス、Node.js、個人用の API Key を設定します |

Codex CLI はエージェントのクライアントで、EvoLink CLI はそこから呼び出されるメディアツールです。両者は別の製品です。各カードは1つのルートをすすめています。CLI のクライアント別ガイドには、代わりに使えるネイティブ MCP へのリンクもあります。

## 生成の前に検証する

<Steps>
  <Step title="選んだルートをインストールして認証する">
    5ステップの [CLI インストール](/ja/cli/setup)、またはお使いのクライアントの [MCP クライアントガイド](/ja/mcp/overview#choose-your-assistant)に従ってください。ブラウザでのログインはご自身で完了してください。キーやトークンはチャットに入力しないでください。
  </Step>
  <Step title="残高とモデルを照会し、スキルまたはツールを検証する">
    CLI の場合は、残高を照会して doctor を実行し、スキルを検出できているかをエージェントに確認してもらいます。MCP の場合は、check_balance と search_models を実際に呼び出します。ファイルがインストールされていることや、ツール一覧が表示されることだけでは、実行に成功したことにはなりません。これらの確認では、有料のメディアタスクは送信されません。
  </Step>
  <Step title="生成を承認する前に、プランと見積もり額を確認する">
    正確なモデルと入力を確認し、参照素材を準備して、プランと見積もりを確認します。明確な承認のあとに一度だけ送信し、タスク ID を控えて、オリジナルファイルを保存します。[CLI のワークフロー](/ja/cli/workflows)または [MCP のワークフロー](/ja/mcp/overview#workflows)を参照してください。
  </Step>
</Steps>

## 各ルートの関係

CLI のメディアリクエストは `エージェント / ターミナル → CLI → プラットフォーム API` の経路をたどります。ネイティブ MCP は `エージェント → リモートまたはローカルの MCP → プラットフォーム API` の経路です。CLI でのメディア実行はリモート MCP に依存しません。ログインには Passport を使い、アップロードとオリジナルファイルのダウンロードには、別途ファイル用のエンドポイントがあります。

インストール、セッション、接続確認は、それぞれ別のものです。現在、同じアカウントの OAuth は、内部キーの権限とクォータを共有できます。そのタスクでは1つのルートだけを使ってください。送信結果が不明な場合は、もう一方のルートで生成し直すのではなく、元のルートで復旧してください。

| MCP のツール、入力、結果、復旧 | [MCP リファレンス](/ja/mcp/tools) |
