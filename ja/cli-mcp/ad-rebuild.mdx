<span id="ad-rebuild" />
## このワークフローが行うこと

アシスタントに、短い参照広告と自分の商品の素材を渡します。出演するクリエイターがいる場合は、その素材も渡します。アシスタントは、その参照広告を調べ、同じ構成でその商品を使うプランを立て、キーフレーム画像を用意し、サウンド付きの広告全体を1つの動画タスクで生成し、プランと照らし合わせて確認したうえで、結果を渡します。

アシスタントは、ログイン後に EvoLink から送られてくるステップごとのルールに従って進めるため、長いプロンプトを書く必要はありません。課金が一切発生しないうちに、見積もり合計額を1つ承認します。

<span id="requirements" />
## 始める前に

| 必要なもの | 詳細 |
|---|---|
| EvoLink へのログイン | [EvoLink プラグインまたはリモート MCP](/ja/mcp/overview) で接続するか、[EvoLink CLI](/ja/cli/setup) をインストールしてログインします。このワークフローは、ログイン済みの接続にのみ提供されます。API Key だけでは利用できません |
| フレームを扱えるアシスタント | コマンドを実行できるアシスタント（たとえば Claude Code、Codex、Cursor）は、自身のマシン上で ffmpeg と ffprobe を使って、動画からフレームを抽出します。ブラウザのチャットなど、ターミナルのないアシスタントは、同じ作業を `make_frames` で行います。これは、リモート MCP がログイン済みの接続に提供する無料のツールです |
| 十分な残高 | 残高と、EvoLink MCP に支出の上限を設定している場合はその上限で、今回の実行をまかなえるかどうかが、見積もりに示されます |

<Note>
ターミナルも `make_frames` ツールもないアシスタントは、このワークフローに必要なフレームを扱う作業を行えません。そうしたアシスタントは、課金が発生する前にその旨を伝えます。
</Note>

<span id="inputs" />
## 用意するもの

| 入力 | 詳細 |
|---|---|
| 参照動画 | MP4 または MOV で、**30秒以内**。それより長い場合は、どの部分を使うかをアシスタントが尋ねます |
| 商品 | 商品の画像を1枚以上、何をする商品かを1行で、そして事実だと確認できる訴求内容。参照動画での訴求内容は、自分の商品にも当てはまると確認したものでないかぎり、引き継がれません |
| クリエイター（任意） | クリエイターの画像。クリエイターがいない場合で、人物が必要なときは、アシスタントが広告用に架空の成人を作成します。参照動画に登場する人物をコピーすることはありません |
| 選択項目 | 言語、画面に映る人物のセリフかボイスオーバーか、音楽、長さ（4–30秒）、アスペクト比、そして解像度（480p、720p、1080p、4K のいずれか。または、まず 480p の下書き）。足りない項目は、アシスタントが1つのメッセージでまとめて尋ね、デフォルト値を提示します。解像度の指定がなければ 720p で見積もり、ほかの選択肢を合計額と一緒に示します。アシスタントが選択肢のボタンを表示できる場合はそれを使って尋ねますが、いつでも自分で回答を入力できます |

素材は、ご自身が権利を持っているもの、または使用許諾を得ているものを使ってください。このワークフローは、参照動画の構成（フック、展開の節目、動作、カメラのリズム）を保ち、人物、商品、部屋、文言、訴求内容を置き換えます。

<span id="cost" />
## 見積もり合計額は1つ、承認は一度

承認の前にアシスタントが行うのは、無料の作業だけです。ログインと残高を確認し、参照動画の長さとアスペクト比を読み取り、ショット数を数えて、見積もりを算出します。そのうえで、合計額を1つ提示します。たとえば次のとおりです：

```text
見積もり合計額：約 $3.67（249.4 クレジット）。720p、サウンド付きの10秒の広告です。
含まれるもの：参照動画の分析、この広告用の画像、動画、最終確認。
ほかの選択肢：480p、1080p、4K。または、まず 480p の下書きを作り、あとから 1080p か 4K に変換することもできます
（変換ごとに料金を提示し、承認をいただきます）。選んでいただければ、その合計額をお伝えします。
課金はステップごとに、実行時に行われます。途中で止めた場合も、それまでに完了したステップの分は課金されたままです。
失敗した生成は課金されません。それぞれ最大2回まで再試行します。
720p で進める場合は「承認」と返信してください。作業がこの合計額を超えそうなときは、先にご相談します。
```

- **この合計額が予算です**。承認後は、アシスタントが料金についてステップごとに尋ねることはありません。改めて相談するのは、作業が合計額を超えそうな場合だけです。
- **ほかの選択肢の見積もりも無料です**。別の解像度や下書きを選ぶと、アシスタントは代わりにその合計額を提示します。承認は、それでも一度だけです。
- **含まれるもの**：参照動画の分析、必要な場合はクリエイターの画像、キーフレーム画像とその一部を修正するための予備分、サウンド付きの動画1本、最終確認。
- **含まれないもの**：下書きの変換（料金の提示と承認は別に行います）と、動画が1本完成したあとに、動画全体をもう1本生成する分。完成した広告がプランに合っていない場合、アシスタントは、どこが合っていないかと、やり直しにかかる料金を説明し、判断を待ちます。
- **残高が不足している場合**、見積もりには不足額と、チャージページへのリンクが示されます。何も開始されません。
- 価格は、見積もり時点のアカウントに適用される価格です。読み取れない場合は公開のデフォルト価格を使い、見積もりにそのことが示されます。課金は、実際の使用量に基づいて行われます。見積もりは24時間有効です。

受け渡しの際、アシスタントは実際に課金された額を見積もりと並べて伝えます。詳しく知りたい場合は、タスクごとの内訳を求めてください。すべての課金は、[ダッシュボード](https://evolink.ai/dashboard)の履歴に、モデルと料金とともに表示されます。画像と動画は生成タスクとして、動画分析はそれぞれ Gemini モデルの呼び出しとして表示されます。アシスタントが使っているのと同じ EvoLink アカウントでログインして確認してください。

<span id="steps" />
## アシスタントが行うこと

| ステップ | 内容 | 課金 |
|---|---|---|
| 0. 確認して見積もる | 参照動画の長さとアスペクト比、ショット数、見積もり合計額。承認するのは一度です | なし |
| 1. 参照動画を読み取る | 参照動画をアップロードし、そのショットとサウンドを分析して、結果をフレームと照らし合わせます | あり |
| 2. 目標を書く | ショットごとに、何を変えて何を残すか：人物、商品、部屋、動作、セリフ、音楽 | なし |
| 3. 広告全体のプランを立てる | タイムライン、必要なキーフレーム画像、単一の動画タスク | なし |
| 4. キーフレーム画像を作る | 必要な場合はクリエイターの参照画像、続いて各ショットの最初のフレームと、その間の状態。各画像は、次のステップに進む前に確認されます | あり |
| 5. 動画リクエストを組み立てる | すべてのキーフレーム画像と、映像とサウンドの完全な説明1つ | なし |
| 6. 生成して確認する | セリフやボイスオーバー、音楽、効果音を含む広告全体を、1つの動画タスクで生成します。結果は、目標と照らし合わせて分析されます | あり |
| 7. 受け渡す | オリジナルの動画、キーフレーム画像をまとめたシート、確認結果の短いまとめ、重要な未解決の問題、料金（見積もりと実際の課金額）。ショットごとの判定は、求めれば提示されます | なし |

承認後、アシスタントは受け渡しまで続けて進めます。止まるのは、作業が合計額を超えそうな場合、ご自身にしか決められないことがある場合（たとえば、商品にはできない動作がある場合）、完成した広告にやり直しが必要な場合、そして下書きを選んだ場合に、下書きができあがり、変換するかどうかを決めていただくときだけです。動画を作る前にキーフレーム画像を見たい場合は、承認の際にそう伝えてください。

<span id="draft" />
## まず下書きを作る

下書きを選ぶと、広告全体を 480p で一度生成し、480p の価格で課金されます。そのため、見積もり合計額に含まれるのは下書きだけです。アシスタントは、下書きを完成した広告と同じように確認し、同じ形で受け渡します。

そのあとで、下書きを 1080p または 4K に変換するか、そのまま残すかを尋ねます。変換はそれぞれ新しいタスクです。アシスタントが料金を示して承認を待ち、変換の分は、承認済みの合計額とは別に課金されます。同じ下書きを複数回変換できます。たとえば、先に 1080p に、あとで 4K に変換できます。変換するたびに課金されます。

下書きは、期限までであれば変換できます。正確な期限はアシスタントが伝えます。これは、タスクの照会で `draft_expires_at` として返される時刻です。

<span id="start" />
## 作り直しを始める

1. お使いのアシスタントに EvoLink を接続します。方法は、[EvoLink プラグイン](/ja/mcp/plugins)のインストール、リモート MCP の追加（[Claude Code](/ja/mcp/claude-code)、[Codex](/ja/mcp/codex)、[Cursor](/ja/mcp/cursor)）、[EvoLink CLI](/ja/cli/setup) のセットアップのいずれかです。
2. 参照動画と商品の画像を、アシスタントが読み取れる場所に置きます。
3. 自分の言葉で依頼します。たとえば次のとおりです：

```text
この広告を私の商品で作り直してください。参照動画は ./reference.mp4 です。商品は ./product.png で、ローズウォーターのフェイスミストです。細かいミストを噴霧します。英語、10秒、720p、縦型でお願いします。
```

アシスタントは、ワークフローのルールを取得し、無料の確認を行ってから、見積もり合計額を提示します。

<span id="limits" />
## 制限と、あらかじめ知っておくこと

- **長さ**：参照動画と完成した広告は、どちらも30秒以内です。
- **動画タスクは1つ**：広告全体が、サウンドも含めて一度に生成されます。このワークフローでは、ショットを個別にレンダリングすることも、あとから音声を付けることも、結果を編集することもありません。
- **タイミングはおおよそのものです**。動画モデルは、プランで決めたカットの時刻を目安として扱います。カットや動作は、1秒ほど早くなったり遅くなったりすることがあります。どこでずれたかは、受け渡し時の確認で報告されます。
- **画面上の文字とラベル**は、結果の中で確認されますが、それでも崩れることがあります。
- **コンテンツ審査**：モデルが素材を拒否した場合、アシスタントはそのことを伝え、別の素材を求めます。審査を通すためにリクエストを言い換えることはありません。
- **レート制限**：1つのアカウントが開始できる動画分析の数には、1分あたりと1日あたりの上限があります。どれだけ待てばよいかは、メッセージに示されます。
- **再生**：1080p と 4K の動画は、10ビット HEVC のファイルです。開けないプレーヤーもありますが、VLC と QuickTime では再生できます。

<span id="recovery" />
## 途中で中断された場合

完了したステップは、完了したままです。あとで問題が起きても、参照動画をもう一度読み取ったり、確認を通った画像をもう一度生成したりする必要はありません。

| 起きたこと | アシスタントの対応 |
|---|---|
| 動画分析の途中で接続が切れた | まったく同じリクエストをもう一度送信します。すでに実行中だった分析が返され、課金されるのは1回だけです |
| サービスが混雑している | メッセージに示された時間だけ待ってから、同じステップをもう一度試します。試すのは最大であと2回までで、そのあとで報告します |
| 生成タスクが失敗した | そのタスクは課金されていません。アシスタントは、上記の回数の範囲内で、同じ入力で再試行します |
| 残高または支出の上限が足りない | 次の課金の前に停止し、何が完了していて、何が残っているかを伝えます。チャージするか上限を引き上げたあとで、続行します |
| アップロードしたファイルまたは結果のリンクの有効期限が切れた | 通常、アップロードしたファイルは72時間、結果のリンクは24時間保持されます。アシスタントは、ローカルのコピーからもう一度アップロードします |

<span id="reference" />
## ツールとコマンド

これらはアシスタントが自分で使います。ご自身で呼び出す必要はありません。

| リモート MCP ツール | CLI コマンド | 用途 | 課金 |
|---|---|---|---|
| get_media_workflow | `evolink workflow rules ad-rebuild` | 現在のステップのルールと実行 ID | なし |
| 見積もりを指定した get_media_workflow | `evolink workflow estimate ad-rebuild --seconds 10 --keyframes 5` | 予定している実行に対する1つの見積もり合計額 | なし |
| analyze_video | `evolink video analyze FILE_URL --run RUN_ID --step STEP --purpose PURPOSE` | ワークフローのステップ用に動画を分析する | あり（トークン課金） |
| get_video_analysis | `evolink video analysis ANALYSIS_ID` | まだ実行中だった分析を取得する | なし |
| make_frames | CLI にはありません。アシスタントが自身のマシン上で ffmpeg を使います | ターミナルのないアシスタント向けの、フレームの抽出、切り抜き、一覧シート、番号付きの画像ボード | なし |

アップロード、単一の生成の見積もり、生成、タスクの照会には、通常の [MCP ツール](/ja/mcp/tools)と [CLI コマンド](/ja/cli/reference)を使います。見積もりと課金の関係については、[モデル、料金、クォータ](/ja/cli-mcp/models-and-billing)を参照してください。
