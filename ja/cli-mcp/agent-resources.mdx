このページでは、ユーザーとエージェント向けに、ツール、スキル、ドキュメントについて説明します。説明を読んだあとも、実際のセットアップ、認証、無料の接続検証は別途必要です。

<span id="skills" />
## 各コンポーネントの役割

| コンポーネント | 役割 | 次の手順 |
|---|---|---|
| EvoLink CLI | ターミナルでプラットフォームの操作を実行します。メディアの呼び出しは API に直接送られます | [インストール、ログイン、検証](/ja/cli/setup) |
| リモート MCP | HTTP 経由でホストにツールを提供します。ログインには OAuth を使います | [クライアントを選ぶ](/ja/mcp/overview#choose-your-assistant) |
| ローカル MCP | ローカルの stdio プロセスでツールを実行します | [起動方法とプラットフォームのキーを設定する](/ja/mcp/other-clients#local-mcp) |
| スキル | モデルの探索、承認、復旧、受け渡しの進め方を案内します | ホストが検出できる場所にインストールし、読み込まれたことを確認します |
| プラグイン | ホストごとの設定とスキルをまとめてパッケージ化します | [プラグインの手順](/ja/mcp/plugins)に加えて、認証と権限を確認します |
| Markdown/llms.txt | 読める形式の説明、またはドキュメントの索引です | リンク先のページを読みます。これら自体はツールを実行しません |

CLI をインストールしても、MCP やプラグインのリポジトリはクローンされず、ネイティブ MCP も登録されません。CLI には evolink-cli が同梱されており、MCP プラグインのリポジトリは evolink-mcp のツールガイダンスを提供します。両者は別々に保守されている入口であり、すでに統合された単一のスキルソースではありません。

## スキルに含まれる内容

現在のスキルは、モデルとパラメータ、画像・動画・音声のワークフロー、参照素材、見積もりと承認、予算の確認、元の送信の復旧、待機、ダウンロード、オリジナルファイルの受け渡しを扱います。CLI には SKILL.md と、capabilities、media-workflows、usage-and-budget の3つのリファレンスが含まれます。インストール先、ディレクトリ、読み込み、アップグレードについては [CLI スキル](/ja/cli/skills)を、ホストの設定については [MCP プラグイン](/ja/mcp/plugins)を参照してください。

バイラル広告、完成済み UGC、自動編集、プリセットといった専用のスキルライブラリはありません。例は、人気が出ることを保証するものではありません。コード開発、任意のファイル編集、ウェブサイト構築は、EvoLink のツールではなくホストの機能です。

## エージェント共通の指示

```text
このタスクで EvoLink CLI とネイティブ MCP のどちらを使うかを決め、実際の接続を検証してください。
アカウントで利用できるモデルと実際のスキーマを照会し、タスク、参照素材、品質、予算に基づいて選定理由を説明してください。
最終的な仕様と見積もり額を示し、明確な承認を得てから一度だけ送信してください。
結果が不明な場合は、元のルート、元のアカウント、元のリクエスト ID を使って復旧してください。
元の task_id を照会し、オリジナルファイルを渡して、報告された実際の料金と有効期限を伝えてください。
対応していない機能はその旨を説明し、モデル、入力、ツール、価格、返金を捏造しないでください。
見積もり時の予算を最終請求額の保証として説明しないでください。また、結果を自動的に編集または再生成しないでください。
```

タスクは1つのルートに固定してください。CLI ではコマンドとローカルの見積書を使い、MCP ではツールと元の client_request_id を使います。それぞれ対応するリファレンスを参照してください。スキルのファイルがインストールされていても、ホストが読み込んだことにはなりません。また、スキルを読んでも、ツールが設定されたり実行権限が付与されたりするわけではありません。スキルが検出されるかを試すために、生成を繰り返さないでください。

## Markdown と llms.txt を使う

1. [概要](/ja/cli-mcp/overview)を読み、クライアントとルートを選びます。
2. 選んだクライアントとルートのセットアップ手順、コマンドまたはツールのリファレンス、共通ルールを読みます。モデルの最新のスキーマは、実行時に照会してください。
3. ページのコピー機能や Markdown エクスポートが使える場合は、それを使って .md ファイルを保存し、エージェントに渡します。キー、トークン、非公開の認証リンクはファイルに含めないでください。
4. [llms.txt](https://docs.evolink.ai/llms.txt) はドキュメントの索引です。MCP のエンドポイントでも、CLI のインストーラーでも、認証 API でもありません。

| リソース | 用途 |
|---|---|
| [CLI リファレンス](/ja/cli/reference) / [MCP リファレンス](/ja/mcp/tools) | 正確な操作、入力、結果、復旧 |
| [モデル、料金、クォータ](/ja/cli-mcp/models-and-billing) | モデルの選択、見積もり、承認、予算の適用範囲 |
| [タスク、参照素材、結果](/ja/cli-mcp/tasks-and-files) | アップロード、有効期限、復旧、ダウンロード、グレーのプレビュー |
| [CLI スキル](/ja/cli/skills) / [MCP プラグイン](/ja/mcp/plugins) | インストール、検出、個人による編集、アップグレード |

## 更新後に検証する

CLI をアップグレードしたら、同梱のスキルを同期し、ホストで再読み込みしてください。プラグインや手動の MCP 設定を変更したら、現在の接続、OAuth、権限を確認してください。ほかのサービスの設定や個人による編集は、そのまま残してください。パッケージ、ドキュメント、ツールのバージョンは一致しないことがあります。食い違いがある場合は、実際にリリースされているバージョンと返されたスキーマに照らして解決し、確認できていない点は説明してください。
