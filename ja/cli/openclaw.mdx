OpenClaw は、EvoLink CLI を通じてメディアタスクを実行できます。このページでは、ホスト環境とスキルに関する違いを説明します。共通の手順の全体は、[インストールとログイン](/ja/cli/setup)にまとめています。ネイティブツールを使う場合は、[MCP ガイド](/ja/mcp/openclaw)を直接参照してください。

## エージェントにインストールを依頼する

次の内容を、エージェントとの会話に貼り付けてください。公式サイトのプロンプトと同じ内容です。ブラウザでのログインと権限の確認は、ご自身で完了してください。

```text
ここで画像・動画・音声を直接生成できるように、EvoLink を設定してください。
1. CLI をインストール：`npm install -g @evolinkai/cli` を実行してください。
2. ログイン：`evolink auth login` を実行してください。
3. 対応スキルをインストール：`evolink skills install` を実行してください。
4. 接続を確認し、成功したら利用を開始できると伝えてください。
```

## このクライアントでの3つのステップ

<Steps>
  <Step title="共通のインストールとログインを完了する">
    Gateway を実行しているマシンとユーザーに対してインストールしてください。必要に応じて、ホスト側の手順でスキルを再読み込みします。デスクトップで成功しても、リモートで利用できることの証明にはなりません。

    はじめての場合は、[5ステップのガイド](/ja/cli/setup#cli-install)を開いてください。Node.js 22 以上であることを確認し、CLI をインストールして、ブラウザでのログインを完了します。ガイドには、コマンド、成功の目安、トラブルシューティングが含まれています。すでに完了している場合は、次で検証します：

    ```bash
    evolink --version
    evolink auth status --json
    ```

    CLI のバージョンと authenticated: true が表示されることを確認します。失敗した段階に応じて、[インストールのエラー](/ja/cli/billing#cli-install)、[ログインのエラー](/ja/cli/billing#login)、[SSH コールバック](/ja/cli/setup#ssh-login)を参照してください。
  </Step>
  <Step title="このエージェントのスキルを同期し、検出を検証する">
    ```bash
    evolink skills install --agent openclaw
    evolink skills status --agent openclaw --json
    ```

    ディレクトリは ~/.openclaw/skills/evolink-cli です。current: true は、ファイルが CLI と一致していることを意味します。エージェントに次のように依頼します：

    ```text
    このセッションで evolink-cli スキルを検出して読み込めることを確認してください。メディアを生成せずに、アクセスを検証してください。
    ```

    assistant_discovery: not_checked の場合は、引き続きホスト側での検証が必要です。ファイルがあるのに使われない場合は、[スキルの検出](/ja/cli/billing#skills-discovery)に従ってください。必要な実行権限を確認し、個人による変更は保持してください。
  </Step>
  <Step title="メディアを制作する前に無料で検証する">
    ```bash
    evolink balance --json
    evolink doctor --agent openclaw --json
    ```

    balance がアカウントのデータを返し、doctor が ok、connection_verified、model_discovery_verified を true と報告し、エージェントがスキルを読んだことを確認すれば、セットアップは完了です。これらの照会では、有料のメディアタスクは作成されません。残高がゼロでも、接続は検証できます。
  </Step>
</Steps>

### インストール済みの CLI でまとめてセットアップする

```bash
evolink setup --agent openclaw --json
```

このコマンドは、環境を確認し、スキルを同期し、必要に応じてログインして、アクセスを検証します。setup_complete: true が表示されることを確認してください。ホストでの検出は、別途確認が必要です。失敗した場合は、phase、steps、error、recovery を使って原因を特定します。

## アップデートとログアウト

CLI 0.10.0 以降では、CLI が自分で新しいリリースを知らせます。[新しいバージョンがあることを知る方法](/ja/cli/setup#update-check)を参照してください。CLI を更新したら、現在のエージェントのスキルを同期します：

```bash
npm install -g @evolinkai/cli@latest
evolink --version
evolink skills install --agent openclaw
evolink skills status --agent openclaw --json
```

ローカルでの変更は保持されます。`modified` または `conflict` の場合は、[スキルのトラブルシューティング](/ja/cli/billing#skills-discovery)に従って対処してください。次のコマンドは、CLI からログアウトしたい場合にだけ実行します。インストールやアップデートの手順ではありません。

```bash
evolink auth logout
```

## トラブルシューティングの出発点

| 症状 | 次の手順 |
|---|---|
| npm/evolink が見つからない、権限、インストールのタイムアウト | [環境とインストール](/ja/cli/billing#cli-install) |
| ブラウザが開かない、OAuth のタイムアウト、認証情報ストアのエラー | [ログインとコールバック](/ja/cli/billing#login)、[SSH でのログイン](/ja/cli/setup#ssh-login) |
| スキルをインストールしたのに、エージェントが使わない | [スキルの検出と実行権限](/ja/cli/billing#skills-discovery) |
| 送信したタスクがタイムアウトした、または結果が失われた | [元のタスクを復旧する](/ja/cli/billing#tasks-and-recovery) |

接続できたら、[はじめてのメディアワークフロー](/ja/cli/workflows#workflows)に従ってください。モデル、パラメータ、料金を確認し、承認してから送信します。すべてのコマンドは、[CLI コマンドリファレンス](/ja/cli/reference)にあります。
