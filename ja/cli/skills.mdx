## CLI スキルをインストールして管理する

このページでは、evolink-cli のインストール先、ディレクトリ、ホストでの検出、アップデートを扱います。対象範囲、CLI・MCP・プラグインの考え方、共通ルールについては、[共通リソース](/ja/cli-mcp/agent-resources)を参照してください。

## インストールして検出を検証する

```bash
evolink skills install
evolink skills status --json
```

デフォルトのインストールでは、対応しているインストール先のディレクトリが対象になります。エージェント自体はインストールされません。特定のホストだけを選ぶには：

```bash
evolink skills install --agent codex
evolink skills status --agent codex --json
evolink doctor --agent codex --json
```

current:true を確認し、エージェントのチャットで次を送信します：

```text
このセッションで evolink-cli を検出して読み込めることを確認してください。まず残高とモデルを照会し、メディアは生成しないでください。
```

assistant_discovery:not_checked は、CLI がホストに代わって検出を検証できないことを意味します。ファイルがあるのに使われない場合は、スキルを再読み込みするか新しいセッションを開き、コマンドの実行権限を確認してください。ドキュメントを読んだだけでは、アカウントにアクセスできることの証明にはなりません。

## 対応しているインストール先とディレクトリ

| --agent | クライアント | ディレクトリ |
|---|---|---|
| codex | Codex | ~/.agents/skills/evolink-cli |
| claude-code | Claude Code | ~/.claude/skills/evolink-cli |
| cursor | Cursor | ~/.agents/skills/evolink-cli |
| openclaw | OpenClaw | ~/.openclaw/skills/evolink-cli |
| hermes | Hermes | ~/.hermes/skills/evolink-cli |
| gemini | Gemini CLI | ~/.agents/skills/evolink-cli |
| opencode | OpenCode | ~/.agents/skills/evolink-cli |
| copilot | GitHub Copilot CLI | ~/.agents/skills/evolink-cli |

Gemini、OpenCode、Copilot は、それぞれの agent の値を指定して、[共通の5ステップのインストール](/ja/cli/setup#cli-install)に従えます。実際に使う SSH、WSL、コンテナ、Gateway の環境にインストールしてください。これらはインストール先であり、ホストのすべてのバージョンで検出されることを保証するものではありません。ホストのポリシーとスキルの読み込みは、引き続きホスト側の責任です。

## アップデートと個人による変更

```bash
npm install -g @evolinkai/cli@latest
evolink skills install
evolink skills status --json
```

CLI を更新したら、スキルを同期し、エージェントに読み直してもらってください。個人による変更は、デフォルトで保持されます。まず modified/conflict の状態を確認してください。--replace-modified は、個人の内容を置き換えると決めた場合にだけ使ってください。元の内容は ~/.evolink-media/skill-backups/ にバックアップされます。[スキルのトラブルシューティング](/ja/cli/billing#skills-discovery)を参照してください。

CLI 0.10.0 以降では、`--agent` を付けない `evolink doctor` は、各エージェント向けにインストールされたスキルのコピーも調べます。コピーが CLI より古い場合は、`guidance` が `evolink skills install` の実行を促します。個人による編集と競合は報告されるだけで、置き換えられることはありません。これらの結果によって `ok` が変わることはありません。CLI が新しいリリースを知らせる方法については、[新しいバージョンがあることを知る方法](/ja/cli/setup#update-check)を参照してください。

## エージェント向けのリソース

エージェントには、[共通ルールとエージェントが読めるリソース](/ja/cli-mcp/agent-resources#agent-rules)、[CLI リファレンス](/ja/cli/reference)、[メディアのワークフロー](/ja/cli/workflows)を渡してください。モデルのスキーマは、models schema MODEL_ID で照会します。スキルの読み込みと、アカウントへの接続は、別々に検証してください。ネイティブ MCP のインストールについては、[MCP プラグイン](/ja/mcp/plugins)を参照してください。
