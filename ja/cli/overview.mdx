クライアントから選ぶ場合は、[CLI/MCP の概要](/ja/cli-mcp/overview)を参照してください。このセクションの共通リソースでは、料金、タスク、ファイル、エージェント向けの指示を扱っています。

EvoLink CLI を使うと、ターミナルにアクセスできるエージェントやターミナルのユーザーが、画像、動画、音楽、読み上げ音声の生成、モデルとパラメータの確認、残高とタスクの照会、参照素材のアップロード、オリジナルファイルの保存を行えます。

このセクションは、リリース済みの **CLI 0.14.1** を対象としています。macOS、Windows、Linux のいずれかで、Node.js 22 以上が必要です。エージェントがコマンドを実行するマシンとユーザーの環境にインストールしてください。メディアは**エージェントまたはターミナル → CLI → プラットフォーム API** の経路を通ります。

## インストールと検証

ターミナルにアクセスできるエージェントに、次のプロンプトを送ってください。公式サイトのインストール用プロンプトと同じ内容です：

```text
ここで画像・動画・音声を直接生成できるように、EvoLink を設定してください。
1. CLI をインストール：`npm install -g @evolinkai/cli` を実行してください。
2. ログイン：`evolink auth login` を実行してください。
3. 対応スキルをインストール：`evolink skills install` を実行してください。
4. 接続を確認し、成功したら利用を開始できると伝えてください。
```

プロンプトはチャットに貼り付けます。コマンドは、エージェントのターミナルまたはご自身のターミナルで実行されます。ブラウザでのログインと権限の許可は、ご自身で完了してください。詳しい手順、成功の目安、アップデート、ログアウト、SSH コールバックについては、[インストールとログイン](/ja/cli/setup)を参照してください。

手動で行う場合の基本的な流れは次のとおりです：

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
evolink doctor --json
```

ログインが完了するのを待ってから、次に進んでください。ブロック全体を貼り付けて、認証を無視したまま進めないでください。エージェントに、evolink-cli を読んだことを確認してもらいます。残高の照会と診断では、有料のメディアタスクは作成されません。検証が済んでから制作を始めてください。

## CLI の機能

| 機能 | 使い方とガイド |
|---|---|
| 環境とアクセス | version、auth、setup、doctor。[インストール](/ja/cli/setup) |
| モデルとパラメータ | models search/recommend/show/schema、docs search。[リファレンス](/ja/cli/reference) |
| 見積もりと承認 | estimate がローカルに見積書を作成し、承認後に generate を実行します。[ワークフロー](/ja/cli/workflows) |
| メディア | モデルの機能に応じた画像、動画、音楽、読み上げ音声 |
| 参照素材 | upload でローカルファイルをアップロードし、uploads get で元のレシートを確認します |
| タスク | get/wait、batch、ページ分割された履歴、見積書に基づく復旧 |
| オリジナルファイルのダウンロード | 単一またはすべての結果、形式チェック、バッチの復旧 |
| アカウントと使用量 | balance と、範囲に上限のある過去の使用量。完全な請求書ではありません |
| スキル | skills install/status と、ホストでの検出の確認 |

CLI は、汎用のテキストチャット、キューのキャンセル、チャージ、キー管理、自動編集、完成動画のホスティングを提供しません。コード開発と任意のファイル編集は、ホスト側のエージェントの機能です。まず、生成されたオリジナルファイルを渡してください。新しいバリエーション、編集、再生成には、それぞれ適切な承認が必要です。

## はじめての制作

```text
EvoLink でコーヒーブランドの広告画像を作成してください。
まず利用可能な画像モデル、パラメータ、料金を照会し、おすすめのモデルと出力仕様を説明してください。
私が明確に承認してから一度だけ送信し、タスク ID を保存して、オリジナルファイルをダウンロードし、報告された実際の料金もあわせて伝えてください。
```

[モデル → 参照素材 → 見積もり → 承認 → タスク → ダウンロード](/ja/cli/workflows)の流れに従ってください。インストールしたことは、有料生成の承認にはなりません。見積もりは最終的な精算額ではありません。[料金とトラブルシューティング](/ja/cli/billing)を参照してください。

## CLI と MCP

CLI のインストールには、実行ファイル、共通の業務モジュール、同梱の evolink-cli スキルが含まれます。MCP やプラグインのリポジトリをクローンする必要はなく、ネイティブ MCP が登録されることもありません。OAuth は Passport が提供し、認証情報はオペレーティングシステムが安全に保存します。

CLI とリモート MCP のセッションは別々に管理されます。現在、アカウントの OAuth は、内部キーの権限、上限、一時停止状態を共有します。Claude や ChatGPT のウェブ版を使う場合や、ネイティブツールを呼び出す場合は、[別の MCP セクション](/ja/mcp/overview)を使ってください。
