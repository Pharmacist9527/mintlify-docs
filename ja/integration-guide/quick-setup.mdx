## 概要

手動で設定する場合は、クライアントのインストール、設定ファイルの編集、エンドポイントと API Key の入力が必要です。セットアップスクリプト（`evolink-config`）は、これらをすべてコマンド 1 つで行います：

- 環境を確認し、クライアントがまだパソコンに入っていなければインストールします
- EvoLink のエンドポイントと API Key を書き込みます
- テストメッセージを 1 通送り、呼び出しが通ることを確認します
- ファイルを変更する前に必ずバックアップし、コマンド 1 つですべて元に戻せます

全体の所要時間は通常 1 分以内です。

| クライアント | ワンクリック設定 |
|---|---|
| Claude Code CLI | 対応 |
| Codex CLI | 対応 |
| その他のクライアント | 「AIコーディングツール」の手動ガイドを参照してください |

<Note>
以下のコマンドは macOS と Linux 用です。Windows の場合は、当面 [Claude Code CLI](/ja/integration-guide/claude-code-cli) または [Codex CLI](/ja/integration-guide/codex-cli) の手動ガイドに従って設定してください。
</Note>

## 前提条件

- **EvoLink API Key**：[EvoLink ダッシュボード](https://evolink.ai/dashboard) にログインし、API Keys で Key を作成してコピーします。Key は `sk-` で始まります。
- **Node.js**：バージョン 22 以上を推奨します（最低 18）。ターミナルで `node -v` を実行して確認できます。インストールされていない場合は、[Node.js 公式サイト](https://nodejs.org/) から LTS 版をダウンロードしてください。

## Claude Code を設定する

ターミナルで次のコマンドを実行します：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash
```

スクリプトが 5 つのステップで案内します（スクリプトのメッセージは英語で表示されます）：

<Steps>
  <Step title="環境の確認">
    Node.js と Claude Code を確認します。Claude Code がまだインストールされていない場合、スクリプトが「Install now?」と尋ねます。Enter キーを押すと自動でインストールされます。
  </Step>
  <Step title="API Key">
    EvoLink の API Key を貼り付けて Enter キーを押します。貼り付けた内容は画面に表示されません。スクリプトが Key の有効性をオンラインで確認し、残高を表示します。
  </Step>
  <Step title="モデルの選択">
    Claude Code がデフォルトで使うモデルを選びます。あとから Claude Code の中で `/model` を使っていつでも切り替えられます。
  </Step>
  <Step title="変更内容の確認">
    スクリプトが変更するファイルと設定の一覧を表示します。Enter キーを押すと適用されます。
  </Step>
  <Step title="書き込みと検証">
    設定を書き込んだあと、スクリプトがテストメッセージを 1 通送ります（約 0.01 クレジット）。正常に応答があれば設定は完了です。
  </Step>
</Steps>

完了したら、新しいターミナルウィンドウを開いて次のコマンドを実行します：

```bash
claude
```

Claude Code の中で `/status` を実行します。Anthropic base URL に EvoLink のアドレスが表示されていれば、設定は有効です。

## Codex CLI を設定する

ターミナルで次のコマンドを実行します：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- codex
```

手順は上と同じです。完了したら、次のコマンドで Codex を起動します：

```bash
codex -p evolink
```

<Note>
スクリプトは Codex 用に別のプロファイル `~/.codex/evolink.config.toml` を作成し、既存の `~/.codex/config.toml` は変更しません。Codex が EvoLink を使うのは `-p evolink` を付けて起動したときだけで、`codex` だけで起動した場合は元の設定のままです。
</Note>

## スクリプトが変更するファイル

### Claude Code

| ファイル | 変更内容 |
|---|---|
| `~/.claude/settings.json` | エンドポイント `ANTHROPIC_BASE_URL` と Key `ANTHROPIC_AUTH_TOKEN` を書き込みます。パソコンに残っている古い Key で 401 エラーが起きないよう、`ANTHROPIC_API_KEY` を空の値にします。Sonnet で使うモデルのバージョンを固定します。自動モードをオフにします（理由は下の「よくある質問」を参照）。ファイル内のそれ以外の設定はそのまま残ります。 |
| `~/.claude.json` | 初回起動時のログイン画面をスキップします。同意いただいた場合は、現在のフォルダを信頼済みにします。 |

### Codex CLI

| ファイル | 変更内容 |
|---|---|
| `~/.codex/evolink.config.toml` | 新規作成します。EvoLink のエンドポイント、デフォルトモデル、Key が入ります。読めるのはご本人だけです。 |
| `~/.codex/config.toml` | 変更しません。 |

### 共通事項

- 変更するファイルは、変更前に `~/.evolink/backups/` にバックアップされます。
- スクリプト本体は `~/.evolink/` に保存され、コマンドは `~/.evolink/bin/evolink-config` です。PATH やシェルのプロファイルは変更しません。
- Key はパソコン上の設定ファイルにのみ保存され、EvoLink API にのみ送信されます。

<Note>
`evolink-config` は API 接続の設定だけを行います。画像・動画・音声を生成するコマンドラインツール `evolink`（CLI/MCP セクションを参照）とは別のツールで、両方を使うことができます。
</Note>

## 確認・元に戻す・再設定

### 変更内容を事前に確認する（何も書き込みません）

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --dry-run
```

### 現在の設定を確認する

```bash
~/.evolink/bin/evolink-config doctor
```

出力では Key が伏せられるので、そのままサポートに送れます。Codex の場合は `~/.evolink/bin/evolink-config doctor codex` を使います。

### 設定を元に戻す

```bash
~/.evolink/bin/evolink-config reset
```

スクリプトが変更した内容がすべて元に戻ります。Codex の場合は `~/.evolink/bin/evolink-config reset codex` を使います。

### Key やデフォルトモデルを変更する

設定コマンドをもう一度実行してください。

## よくある質問

### 1. Node.js が見つからないと表示された場合は？

[Node.js 公式サイト](https://nodejs.org/) から LTS 版をインストールし、新しいターミナルを開いてから、設定コマンドをもう一度実行してください。

### 2. すでに手動で設定しています。設定は上書きされますか？

まるごと上書きされることはありません。スクリプトが変更するのは上に挙げた項目だけで、それ以外はそのまま残ります。書き込む前に各項目の変更前と変更後の値を表示し、元のファイルをバックアップします。

### 3. Claude Code で自動モード（auto mode）が使えないのはなぜですか？

自動モードでは、Claude Code はコマンドごとに確認を求めなくなります。その代わり、まず審査リクエストを送り、コマンドを安全に実行できるかどうかをモデルが判断します。この審査リクエストも、ほかのリクエストと同じくトークン単位で課金されます。どのデフォルトモデルを選んだかに関係なく、`claude-sonnet-5` が使われます。

想定外の費用が発生しないよう、スクリプトはデフォルトで自動モードをオフにし、Claude Code はコマンドを実行する前に確認を求めます。設定の最後にも、スクリプトがこの点をお知らせします。

自動モードを使いたい場合は、次のようにオンにします：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh | bash -s -- --auto-mode
```

再びオフにするには、`--auto-mode` を付けずに設定コマンドをもう一度実行してください。

### 4. 実行する前にスクリプトの中身を確認できますか？

はい。ダウンロードして内容を確認してから実行してください：

```bash
curl -fsSL https://cdn.evolink.ai/cli/setup.sh -o setup.sh
less setup.sh
bash setup.sh
```

### 5. 「Rate limited (429)」と表示された場合は？

各アカウントが 1 分間に Key を確認できる回数には上限があります。スクリプトを短時間に何度も実行すると、このメッセージが表示されます。メッセージに表示された秒数だけ待ってから、もう一度実行してください。

### 6. 設定後もうまく動かない場合は？

`~/.evolink/bin/evolink-config doctor` を実行し、出力をサポートに送ってください。[Claude Code CLI](/ja/integration-guide/claude-code-cli) と [Codex CLI](/ja/integration-guide/codex-cli) のページにあるトラブルシューティングも参考にしてください。
