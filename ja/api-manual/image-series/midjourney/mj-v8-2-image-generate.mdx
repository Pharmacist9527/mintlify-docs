<Note>
Midjourney にはコンテンツ審査機能が組み込まれています。審査は画像ごとに行われ、フィルタリングされた画像は結果に含まれず、残りの画像は通常どおり返されるため、受け取る画像の枚数が通常より少なくなる場合があります。1 枚でも審査を通過すればタスクは `completed` となり、通常どおり課金されます。すべての画像がフィルタリングされた場合、タスクは `failed` となり、予約されたクレジットは全額返金されます。プロンプトと参考画像がコンテンツガイドラインに準拠しているかご確認ください。
</Note>
