<Note>
上流プロバイダーのポリシー変更により、Midjourney V7 Inpaint（`mj-v7-inpaint`）は 2026年10月21日に提供を終了しました。現在のリクエストは HTTP 410（`mj_v7_inpaint_discontinued`）を返し、料金は発生しません。画像の一部を描き直す場合は、このインターフェース（`mj-v7-upload-paint`）を使用してください。
</Note>

<Note>
Midjourneyにはコンテンツ審査機能が組み込まれています。生成された画像の一部が審査でフィルタリングされた場合、そのリクエストで消費されたクレジットは返金されません。プロンプトの内容がガイドラインに準拠しているかご確認ください。
</Note>
