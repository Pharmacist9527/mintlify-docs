<Note>
**BaseURL**：デフォルトの BaseURL は `https://direct.evolink.ai` で、テキストモデルへの対応が優れており、長時間接続をサポートします。`https://api.evolink.ai` はマルチモーダルの主力エンドポイントで、テキストモデルに対しては代替アドレスとして使用されます。
</Note>

<Note>
**明示的コンテキストキャッシュ**：繰り返し使う長いプレフィックス（長文ドキュメント、システム指示、ツール定義）をキャッシュとして作成すると、以降の生成リクエストではキャッシュ名と新しい質問だけを送れます。キャッシュ分はキャッシュヒット単価で課金されます。別途キャッシュ書き込み料金と時間単位の保存料金がかかり、保存料金は作成時に有効期間全体分を徴収し、返金されません。
</Note>

<Tip>
**キャッシュの参照**：`generateContent` または `streamGenerateContent` のリクエストボディに `"cachedContent": "<name>"` を追加し、`contents` には新しい質問だけを入れます。キャッシュを参照するリクエストには `systemInstruction`・`tools`・`toolConfig` を含められず、モデルはキャッシュ作成時と同じである必要があります。
</Tip>
