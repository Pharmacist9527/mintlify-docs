<Note>
**BaseURL**：デフォルトの BaseURL は `https://direct.evolink.ai` で、テキストモデルへの対応が優れており、長時間接続をサポートします。`https://api.evolink.ai` はマルチモーダルの主力エンドポイントで、テキストモデルに対しては代替アドレスとして使用されます。
</Note>

<Note>
ウェブ検索は Seed 2.1 と `doubao-seed-evolving` のみ対応し、検索元別の実行回数で課金されます。明示的キャッシュには保存料金が別途かかります。`caching` と `expire_at` を参照してください。 リクエストメニューの 2 つの明示的キャッシュ例では `expire_at` を省略しているため、既定の有効期間である 3 日分の保存料金がかかります。
</Note>

## 有効期限が 1 時間のキャッシュリクエストを作る

送信直前に次の Python コードを実行し、出力された JSON をリクエスト本文に使います。初回は `PREVIOUS_RESPONSE_ID` を設定しません。続行するときは直前の応答の実際の `id` をこの環境変数に設定して再実行します。実行のたびに `expire_at` が再計算されます。

```python
import json
import os
import time

body = {
    "model": "doubao-seed-2-1-pro",
    "input": "製品マニュアル：モーターとバッテリーの保証期間は 2 年です。この規定を覚えてください。",
    "caching": {"type": "enabled"},
    "expire_at": int(time.time()) + 3600,
}
previous_id = os.getenv("PREVIOUS_RESPONSE_ID")
if previous_id:
    body["previous_response_id"] = previous_id
    body["input"] = "保証の対象となる部品は何ですか。"
print(json.dumps(body, ensure_ascii=False))
```
