<Note>
**BaseURL**: デフォルトの BaseURL は `https://direct.evolink.ai` で、テキストモデルと長時間接続をより適切にサポートします。`https://api.evolink.ai` はマルチモーダルサービスの主要エンドポイントで、テキストモデルの代替アドレスとして使用されます。
</Note>

`POST /v1/responses` を使用し、`model` で `kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed`、`kimi-k3` を選択します。必須項目は `model` と `input` のみです。

<Warning>
**パラメータ名は Chat Completions と異なります**：入力は `input`、出力上限は `max_output_tokens`、推論強度は `reasoning.effort` を使用します。
</Warning>

## 回答本文の読み取り

レスポンスの `output` には推論、回答本文、ツール呼び出しが含まれる場合があります。`type="message"` の `output_text` コンテンツブロックを走査してください。先頭の項目が本文とは限りません。

レスポンス JSON を `response` にパース済みの場合、次のようにテキストを抽出できます。

```python
text = "".join(
    part["text"]
    for item in response.get("output", [])
    if item.get("type") == "message"
    for part in item.get("content", [])
    if part.get("type") == "output_text"
)
print(text)
```

<Note>
**推論用の出力枠を確保してください**：`max_output_tokens` は推論と回答本文の両方を含みます。`status="incomplete"` かつ `incomplete_details.reason="max_output_tokens"` の場合は上限を増やしてください。出力枠を使い切ると、推論項目のみが返り、本文が含まれない場合があります。
</Note>

ツール呼び出し、Web 検索、画像入力、構造化出力は[完全リファレンス](/ja/api-manual/language-series/kimi/responses/responses-reference)をご覧ください。
