title: "リクエスト料金の照会"
description: "Request ID を指定して、主にテキストモデルの同期 API 呼び出しの状態、使用量、実際の料金を照会します"
openapi: /ja/api-manual/account-management/get-request-usage.json GET /v1/requests/{request_id}
---

<Note>
このエンドポイントは**同期 API 呼び出し**の料金照会に使用し、主に Chat Completions、Messages、Responses などのインターフェース経由の**テキストモデル**呼び出しを対象とします。

元のレスポンスヘッダー `X-Request-Id` の値を Request ID として使用します。リクエスト完了後、少し待ってから照会してください。非同期タスクについては、[タスク状態の照会](/ja/api-manual/task-management/get-task-detail) を使用してください。
</Note>
