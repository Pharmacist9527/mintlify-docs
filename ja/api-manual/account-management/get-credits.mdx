## レート制限と再試行

制限はアカウント、パス、モデル、ユーザーグループ単位で適用される場合があり、同一アカウントの複数キーで共有されることがあります。QPS と RPM の時間枠は異なります。一律の固定値を想定せず、有効な設定と 429 応答を確認してください。requests-limit ヘッダーは QPS ではなく分単位の枠を示す場合があります。/v1/models をキャッシュし、重複する初期化要求をまとめます。/v1/credits は必要な鮮度に合わせ短時間キャッシュします。HTTP 429 では Retry-After に従い、回数制限とランダムな待機を設け、複数インスタンスの同時再試行を避けます。制限の確認依頼には時刻、パス、要求 ID を添えてください。生成とタスク照会の制限は別々に確認します。
