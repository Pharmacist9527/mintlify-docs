## Let Codex set itself up

Send this to Codex. It installs the EvoLink skill, adds EvoLink MCP and walks you through signing in from your browser. It works in both the Codex app and the CLI.

```text
Set up EvoLink in Codex for me so I can generate images, videos and audio from here.
1. Install the companion skill: run `npx skills add Evolink-AI/mcp-plugin -g -y`.
2. Add the EvoLink MCP server: run `codex mcp add evolink --url https://mcp.evolink.ai/mcp`. It starts the sign-in in my browser; if no browser opens, give me the link it prints.
3. I'll sign in to EvoLink in the browser and approve. Then ask me to reopen you: in the CLI with `codex resume --last`; in the Codex app, start a new chat, and restart the app if EvoLink still doesn't show up.
Once that's done, let me know when it's ready.
```

<Note>
Codex runs commands in a sandbox by default. These commands download from the internet and write to `~/.codex` and `~/.agents`, outside your workspace, so Codex asks you to approve them first. We haven't tested this in the Codex app yet; if it doesn't work there, add EvoLink by hand as described in [Codex app](#codex-app).
</Note>

## Codex app

<Steps>
  <Step title="Create a plugin">
    In the Codex app, click **Customize** → **Plugins** on the left, then **Add** at the top right to open **New Plugin**.
  </Step>
  <Step title="Fill in the connection">
    - **Choose icon** is optional; you can skip it.
    - Enter `evolink` as the **Name**; the **Description** is optional.
    - Under **Connection**, choose **Server URL** and enter `https://mcp.evolink.ai/mcp`.
    - Under **Authentication**, choose **OAuth** and leave **Advanced OAuth settings** as they are.
    - Check **I understand and want to continue**, then click **Create**.
  </Step>
  <Step title="Connect and sign in">
    When **Connect evolink** appears, click **Continue to evolink**, then sign in to EvoLink in your browser and click **Allow and connect**.
  </Step>
</Steps>

We haven't checked where the Codex IDE extension and the ChatGPT desktop app add servers.

## Command line (Codex CLI)

<Steps>
  <Step title="Copy and run this line">
    ```bash
    codex mcp add evolink --url https://mcp.evolink.ai/mcp
    ```
  </Step>
  <Step title="Sign in and approve in the browser">
    Codex sees that EvoLink requires sign-in and opens the EvoLink sign-in page by itself. Sign in and click **Allow and connect**; `Successfully logged in.` in the terminal means you're done.
  </Step>
  <Step title="Start a new session">
    EvoLink is available in new Codex sessions. Run `codex mcp list` to see `evolink`.
  </Step>
</Steps>

To let Codex set itself up, send it the prompt on the [CLI](/en/mcp/cli) page.

<Warning>
Don't add `codex mcp login evolink` after this line: Codex already signed you in while adding EvoLink, and running login again asks you to approve again. Run login on its own only if the output says "may or may not require login" or no browser opens.
</Warning>

<AccordionGroup>
  <Accordion title="No browser opened, or the output says may or may not require login">
    ```bash
    codex mcp login evolink
    ```

    Over SSH, or without a browser on this machine, add `--no-browser` and open the printed link in the browser on your own computer.
  </Accordion>
  <Accordion title="The command isn't recognized: Codex is too old">
    You need Codex 0.77 or later. Update Codex to the latest version first.
  </Accordion>
  <Accordion title="Edit the config file instead">
    Add these two lines to `~/.codex/config.toml`, then run `codex mcp login evolink` to sign in:

    ```toml
    [mcp_servers.evolink]
    url = "https://mcp.evolink.ai/mcp"
    ```
  </Accordion>
  <Accordion title="Generations are refused in codex exec or automatic mode (MCP tool call requires approval)">
    EvoLink's generate tools spend credits, so Codex asks you before each call. With `codex exec` or `approval_policy = "never"` nobody can confirm, and Codex refuses the call. To let it generate without asking, add these two lines to `~/.codex/config.toml` (for video and audio, use `generate_video` and `generate_audio`):

    ```toml
    [mcp_servers.evolink.tools.generate_image]
    approval_mode = "approve"
    ```

    Generations are then charged without confirmation, so also set a spending limit on the `EvoLink MCP (OAuth)` key in [API Keys](https://evolink.ai/dashboard/keys).
  </Accordion>
</AccordionGroup>

## Try it

Send this in a chat; it only looks something up and costs nothing:

```text
Use EvoLink to check my account balance.
```

If the assistant calls an EvoLink tool and answers, you're connected. If EvoLink doesn't show up, check that `evolink` is connected under **Customize** → **Plugins** in the Codex app, or run `codex mcp list` on the command line. See [Check the connection](/en/mcp/tools#check-the-connection) and [Troubleshooting](/en/mcp/troubleshooting) for more.
