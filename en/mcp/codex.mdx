## Full installation prompt

Send this entire prompt to Codex. Commands run in the agent's actual terminal environment:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Check Node.js and npm. Node.js 22 or newer is required. Run `npm install -g @evolinkai/cli`.
2. Run `evolink auth login`. I will sign in to EvoLink and approve in the browser. If no browser opens, give me the sign-in URL.
3. Run `evolink skills install --agent codex`. Verify that this agent can discover and read `evolink-cli`. Start a new session if needed and check skill discovery again.
4. Run `evolink balance --json` for free verification. Tell me when I can get started, or which step failed.
Use EvoLink for media generation by default. Quote each paid task and wait for my explicit confirmation before generating.
```

For manual installation or remote/local MCP, see [installation methods and manual setup](/en/mcp/setup-methods).


## Recommended: CLI and skill

Send Codex the [complete Quickstart prompt](/en/mcp/quickstart). It runs these steps:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent codex
evolink balance --json
```

Node.js 22+ is required. Sign in and approve in your browser, then verify Codex discovers `evolink-cli`. This route uses Codex's command execution and does not require native MCP tools. Follow host permission prompts. See [CLI workflows](/en/mcp/cli-workflows).

## Optional: native MCP in the Codex app

Add a custom MCP/plugin connection under **Customize → Plugins**; labels may vary by app version:

1. Name: `EvoLink`.
2. Server URL: `https://mcp.evolink.ai/mcp`.
3. Authentication: OAuth; leave advanced client settings at their defaults.
4. Create and connect, then sign in to EvoLink and approve in the browser.
5. Call `check_balance` in the current chat. If tools are missing, start a new chat, then restart the app only if still missing.

Native MCP and CLI sessions are managed separately; choose the route that suits your client.

## Optional: native MCP in Codex CLI

```bash
codex mcp add evolink --url https://mcp.evolink.ai/mcp
```

If browser login already completed, do not sign in twice. Only when authentication remains incomplete, run:

```bash
codex mcp login evolink
```

Ask Codex to call EvoLink `check_balance` for free verification. `codex mcp list` checks configuration. If tools are missing, exit the CLI and run `codex resume --last`.

For manual configuration, add this entry to `~/.codex/config.toml` without replacing other servers, then sign in:

```toml
[mcp_servers.evolink]
url = "https://mcp.evolink.ai/mcp"
```

Native MCP can use the [plugin or `evolink-mcp` skill](/en/mcp/plugins). The CLI's bundled skill is named `evolink-cli`.

### Edit the configuration file yourself

1. Open `~/.codex/config.toml`; project `.codex/config.toml` applies to trusted projects. If you use a custom Codex configuration directory, edit its active file.
2. Keep a local backup and merge the `[mcp_servers.evolink]` snippet above. Update an existing table's `url` instead of adding the same table twice.
3. Save and run `codex mcp login evolink` if sign-in is needed. Complete browser sign-in yourself, check `codex mcp list`, then start a new session and call `check_balance`.

See the [official Codex MCP documentation](https://developers.openai.com/codex/mcp) for paths and configuration scope.

## Tool approval and SSH

Cost approval and Codex tool approval are separate. `MCP tool call requires approval` means the host policy blocked this invocation. Resolve permissions before executing an approved task; do not remove budgets or change call paths to bypass the denial.

SSH callbacks must reach the authentication environment. Do not assume EvoLink CLI's `--no-browser` applies to `codex mcp login`. Check your installed help and callback configuration in the [official Codex MCP guide](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).
