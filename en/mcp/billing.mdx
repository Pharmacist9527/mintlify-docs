## Prices and limits

MCP and CLI have no additional connection fee. Generation uses platform model pricing and the same balance as API and website use. Discovery, quotes, balance queries, tasks and uploads are free. Approximately **68 credits = $1**. Final tasks and dashboard records determine actual charges.

After browser consent, [API Keys](https://evolink.ai/dashboard/keys) shows `EvoLink MCP (OAuth)`, the shared internal key for OAuth-connected agents on the account. It cannot be copied as a personal API key. The CLI also accesses the OAuth service; signing out one client does not disable the shared key.

Set total limits, daily limits, expiry or pause it in the dashboard. Tasks and charges appear there normally. Account balance, key limits and per-task estimate budgets are separate controls.

## Quotes and spending caps

| Status | Interpretation |
|---|---|
| `estimated` | Range calculated from published prices and current input |
| `partial` | Known missing costs; not a total or upper bound |
| `token_billed` | Token unit rates are known but total usage is not |
| `needs_input` | Required estimate input or a length hint is missing |
| `no_price` | Insufficient pricing; do not invent a total |

The agent shows the actual estimate and warnings, ends its response and waits for explicit approval. CLI quotes last 15 minutes and are checked again before submission. Changes require a new quote and approval.

<Warning>
Native MCP `max_cost_usd` and CLI `--max-cost-usd` check the **estimate before submission**, not a hard gateway settlement cap. Some resolution, sound and reference-video pricing is still being completed. Even an `estimated` response does not guarantee the final charge stays below the quote. For strict budgets, choose sufficiently predictable billing and configure account/key limits; do not describe these controls as guaranteed per-task settlement caps.
</Warning>

### References, sound and resolution

Duration, output quality, sound and references can affect costs. Per-second video requests with `video_urls`, `video_url` or `source_task_id` produce partial estimates. With `max_cost_usd`, submission is refused. `media_seconds` cannot fill the missing reference-video costs.

### Audio with unknown output duration

Do not add `input.duration` to a model that does not support it. `media_seconds` is an estimate hint. For unknown output length it illustrates a hypothetical length rather than a total. It cannot establish a spending cap.

### Token billing

Show input/output unit rates and disclose that the total is unknown. Obtain explicit approval before submission. A starting price or previous task's charge cannot guarantee this task's cost.

### If a budget is refused

Do not remove the budget, switch credentials or bypass the call path automatically. Explain the reason and let the user reduce settings, select another model, raise the budget or explicitly accept unresolved total costs. Preserve an existing approved budget unless the user changes it.

## Common messages

| Message | Meaning and next step |
|---|---|
| MCP spending limit reached | Check or adjust the total MCP key limit |
| MCP daily limit reached | Check dashboard reset time or adjust the daily limit |
| account balance is too low | Top up the account |
| MCP is paused for this account | Check and re-enable the internal key if intended |
| MCP key has expired | Check internal key expiry |
| connection was disconnected | Sign in again for this connection |
| temporarily turned off MCP access | Service is temporarily paused; retry later |
| max_cost_usd cannot be checked | Estimate is incomplete/unknown; preserve the budget and discuss alternatives |

Pre-submission refusals do not create a generation charge. A network timeout or unknown outcome is different: inspect existing tasks using [task recovery](/en/mcp/tasks) before concluding no charge occurred. Reruns, variants and further edits are new paid tasks.
