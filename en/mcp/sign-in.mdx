## Browser sign-in

Start from the client's MCP connection flow or `evolink auth login`. Sign in to EvoLink or create an account. Check the account and requesting client on the consent page, then select **Allow and connect**.

Use **Switch account** if needed, or cancel the request. Return to the agent and verify with MCP `check_balance` or CLI `evolink balance --json`; both are free.

Connection consent grants tool access, not approval of every paid generation. Quote and obtain explicit approval for each task or defined batch. See [authorization and security](/en/mcp/security).

## Check the client

Some clients publish OAuth identity documents whose publisher is shown on the consent page. Codex and ChatGPT may both use documents on `chatgpt.com`; this does not mean you selected the wrong product.

Self-registered names cannot always be independently verified. The page may explain self-registration or show an unverified notice. Confirm you initiated the connection and inspect its return target. A familiar icon or name alone does not justify approving an unexpected link.

CLI and native MCP logins are independent. CLI login does not configure native MCP tools in Codex or another client.

## Consent-page language

Consent versions with a language selector support English, Chinese, German, French, Spanish, Japanese and Korean. Switching language preserves the authorization transaction.

Automatic selection prioritizes explicit language paths or `ui_locales`, then the same website host's saved `EVOLINK_LOCALE` preference, then the browser's `Accept-Language`, and finally English. The fixed `/en` authorization entry also checks preferences; explicitly choosing English uses `ui_locales=en`.

The page does not read open website tabs. Switching website language saves a same-host cookie that a later consent page can use. Private windows, different browsers and different hosts may not share it. Without a saved preference, browser request headers apply; unsupported languages fall back to English. Deployments without the selector update may still use browser detection only.

## Expiry

Consent transactions last approximately ten minutes, while the client may stop waiting earlier. CLI callbacks wait about three minutes. If expired or timed out, start sign-in again in the initiating client instead of reusing an old link.

For SSH, callbacks must reach the machine that initiated login. See [CLI installation and sign-in](/en/mcp/cli) for port forwarding. Never share callback codes or tokens in chat.

## Account changes and logout

| Connection | Action |
|---|---|
| CLI | `evolink auth logout`, then `evolink auth login` |
| Native Codex MCP | `codex mcp logout evolink`, then reconnect or sign in |
| Claude, ChatGPT, Cursor and other clients | Disconnect and reconnect in their connector/MCP settings |

Deleting configuration, uninstalling skills or closing a window may not revoke server sessions. Use the client's logout/disconnect action. To pause account-wide OAuth media calls, disable `EvoLink MCP (OAuth)` in the dashboard. Changing a limit does not approve a new task.
