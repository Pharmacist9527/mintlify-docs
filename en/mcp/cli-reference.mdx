Run `evolink --help` for the installed version's full help. Every command below supports `--json`. Replace `MODEL_ID`, `QUOTE_ID`, `TASK_ID` and `UPLOAD_ID` with actual returned values.

## Authentication and free queries

| Command | Purpose |
|---|---|
| `evolink setup [--agent NAME] [--no-browser] [--timeout SECONDS]` | Free prerequisite check, sign-in, skill sync and verification |
| `evolink auth login [--no-browser] [--timeout SECONDS]` | Browser OAuth login |
| `evolink auth status` | Local login state, not a service availability check |
| `evolink auth logout` | Sign out this CLI session |
| `evolink balance` | Balance and spending limits |
| `evolink models search --type image --query seedream --limit 5` | Search models |
| `evolink models show MODEL_ID` | Parameters, examples and prices |
| `evolink doctor [--agent NAME]` | Prerequisite, connection, model and skill diagnostics |
| `evolink skills status [--agent NAME]` | Check installed skill version and content |

Search `--type` accepts `image`, `video`, `audio`, `all` (default). `--limit` is 1–50, default 20. Query current model availability and parameters rather than relying on example names.

Sign-in and `setup` use an integer `--timeout` from 30–900 seconds, default 180. `setup` does not create paid media tasks; the agent still needs to confirm skill discovery. `skills install` also updates the bundled skill and protects modified files by default. Add `--replace-modified` if you choose to replace them; replaced files are backed up. See [CLI installation](/en/mcp/cli) for agent names.

## Quotes and generation

```bash
evolink estimate --model MODEL_ID --input-file input.json --max-cost-usd 1 --json
```

| Option | Meaning |
|---|---|
| `--model` | Required ID from model discovery |
| `--input-file` or `--input` | JSON file or JSON object; choose one |
| `--prompt` | Optional prompt shortcut; cannot conflict with `prompt` in the JSON |
| `--max-cost-usd` | Approved estimate cap, greater than 0 and at most $10000 |
| `--media-seconds` | Estimate-only length for per-second models without `duration`: greater than 0, at most 3600 seconds; not sent to the model |

`estimate` returns a `quote_id` valid for 15 minutes, bound to the service, login, input and pricing. Obtain explicit approval of this quote before running:

```bash
evolink generate image --quote QUOTE_ID --confirm --wait --timeout 1800 --json
```

Use the quote's media type: `image`, `video` or `audio`. Generation uses the saved input and accepts no new model or input parameters. Changed input, pricing or login requires a new quote and approval. `--confirm` declares that approval was already obtained; it does not ask the user for you.

`--wait` waits for results. `--timeout` accepts integer seconds from 1–86400; the default wait is 1800 seconds. See [billing and caps](/en/mcp/billing) for estimate limitations.

## Tasks and recovery

```bash
evolink tasks get TASK_ID --json
evolink tasks wait TASK_ID --timeout 1800 --json
evolink tasks list --type video --status processing --since 2h --limit 10 --json
evolink tasks resume --quote QUOTE_ID --json
```

`--status` accepts `processing`, `completed`, `failed`, `cancelled`; task `--type` accepts the three media types; `--limit` is 1–50. `resume` recovers an original quote whose submission started but has an uncertain outcome. It may retry the same request ID; it is not a new-task command. If the quote expired, inspect recent tasks before preparing another submission. See [tasks and results](/en/mcp/tasks).

## Files and skills

```bash
evolink upload ./reference.png --json
evolink uploads get UPLOAD_ID --json
evolink download TASK_ID --output ./result.png --index 1 --json
evolink skills install --agent codex
```

Upload accepts `--upload-path references` for a relative storage folder. Download `--index` is 1-based, from 1–50, default 1. Its parent directory must exist and the destination must not exist. The per-file download limit is 1 GiB. See [files](/en/mcp/files) for formats and expiry.

## JSON and process behavior

- `--json` writes one JSON line to stdout with `schema_version: 1` and `ok`.
- Errors include `ok: false` and `error`, with a nonzero exit code. Wait progress goes to stderr.
- Success fields depend on the command. Check `ok` before reading `quote_id`, `task_id` or `results`.
- Ctrl-C stops local waiting, typically exiting 130. Submitted server tasks continue.
- `--server URL` selects the MCP service. Keep the default production address for normal use; sessions and quotes cannot be mixed between services.
- Advanced `--token-stdin` accepts an **OAuth access token** for one command, not a platform API key. Never put tokens in arguments, scripts, logs or chats.

The CLI does not provide task cancellation, top-ups, key management, alias configuration or a generic `run` command. MCP tool parameters and CLI options do not always map one-to-one.
