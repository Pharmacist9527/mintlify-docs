## What is EvoLink MCP

EvoLink MCP lets AI assistants use EvoLink's models directly: find models and prices, get a quote before generating images, video and audio, and check task progress and your balance.

- **Server URL:** `https://mcp.evolink.ai/mcp`
- **No API key needed:** the first time, sign in to EvoLink in your browser and approve; the assistant is then connected.
- **Pay as you go:** usage is charged to your EvoLink balance at the same prices as the API. The MCP itself is free.

## Choose your assistant

Pick the assistant you use to jump to its steps. Where there's a one-click button, click it; otherwise copy one command and run it; the rest you add by hand, step by step.

| Assistant | How to add | How to sign in | Support |
|---|---|---|---|
| Claude web and desktop | One-click add | Click **Connect**, sign in in the browser | First wave |
| Cursor | One-click add | Click **Connect** in the MCP settings | First wave |
| Claude Code | Copy one command | The command opens the browser | First wave |
| Codex | Copy one command | The command opens the browser | First wave |
| Hermes Agent | Copy one command; one click in the desktop app | The command opens the browser | Not tested yet |
| OpenClaw | Copy one command | Open the link the terminal prints | Not tested yet |
| ChatGPT | Add step by step | Follow ChatGPT's prompts | Not tested yet |
| Other clients | Add step by step | Follow the client's prompts | Not tested yet |
| CLI (command-line agents) | Copy one prompt to your agent | The agent walks you through browser sign-in | First batch |
| Local version (API key) | Run one command | Your own API key, no sign-in | Tested in Claude Code and Codex |

Every assistant shows the same EvoLink approval page when you sign in; see [First connection: sign in and approve](/en/mcp/sign-in).

## How it works

<Steps>
  <Step title="Add EvoLink">
    Depending on your assistant, click the one-click button or copy one command and run it.
  </Step>
  <Step title="Sign in and approve">
    Your browser opens the EvoLink sign-in page. Sign in and click **Allow and connect** on the approval page; see [Sign-in and approval](/en/mcp/sign-in).
  </Step>
  <Step title="Use it in chat">
    Say what you want, for example "Use EvoLink to make a product hero image". For models that can be quoted, the assistant quotes first and generates after you confirm; see [Tools and usage](/en/mcp/tools).
  </Step>
</Steps>
