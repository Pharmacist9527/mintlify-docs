EvoLink gives your agent model discovery, parameter checks, quotes, media generation, uploads and task queries. Describe what you want in natural language; your agent calls EvoLink using your account.

## Choose your assistant

| Where you work | Recommended connection | Guide |
|---|---|---|
| Claude web or desktop | Remote MCP connector | [Claude](/en/mcp/claude) |
| ChatGPT web | Custom MCP server with OAuth | [ChatGPT](/en/mcp/chatgpt) |
| Codex, Claude Code, Cursor and other terminal-capable agents | EvoLink CLI and bundled skill | [Quickstart](/en/mcp/quickstart) |
| OpenClaw or Hermes terminal agents | EvoLink CLI and bundled skill | [OpenClaw](/en/mcp/openclaw), [Hermes](/en/mcp/hermes-agent) |
| Your scripts or applications | CLI JSON output, or platform API | [CLI workflows](/en/mcp/cli-workflows) |
| A local MCP client that must use an API key | Local stdio MCP | [Local MCP](/en/mcp/local) |

## How it works

Choose MCP or CLI, then follow the corresponding setup guide:

| | Remote MCP | EvoLink CLI |
|---|---|---|
| Entry point | `https://mcp.evolink.ai/mcp` | npm package `@evolinkai/cli`, command `evolink` |
| Caller | The client's native MCP tools | Your agent's terminal tools, or your shell |
| Requirements | Streamable HTTP and OAuth support | Node.js 22+ and working secure credential storage on the login machine |
| Skill | `evolink-mcp`, installed separately or through a plugin | `evolink-cli`, installed with `evolink skills install` |
| Local files | Public URLs, small base64 files, or a one-time upload URL | `evolink upload` reads local media |
| Results | Task details, original links and available previews | JSON, task commands and `evolink download` |

The CLI uses the remote MCP service, but CLI login does not register MCP tools in your client. Verify a CLI connection with a command and skill discovery; verify native MCP with the `check_balance` tool. Their login sessions are managed separately.

## The generation workflow

1. Find a model and read its supported parameters and input requirements.
2. Upload reference media if needed, validate the input and get a quote.
3. Show the model, settings, references, expected cost and uncertainties; wait for explicit approval.
4. Submit one paid task, retain its ID and check progress.
5. Deliver the original result links and actual charge. Save results promptly.

MCP and CLI have no additional connection fee. Generation uses platform model pricing; queries and uploads are free. See [billing, quotes and caps](/en/mcp/billing).

<Warning>
`max_cost_usd` currently checks the estimate before submission. It is not a hard cap on final settlement. Some reference-video costs, multipliers and token-billed totals are not fully known beforehand. Explain the uncertainty and obtain approval; never remove a user's budget just to make a request pass.
</Warning>
