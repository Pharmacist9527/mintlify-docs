## Terminal-capable agents: copy and send

Use this with Codex, Claude Code, Cursor or an agent that can run commands in the same environment where the CLI is installed. Send the entire prompt to its chat:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Install the CLI: run `npm install -g @evolinkai/cli`; Node.js 22 or newer is required.
2. Sign in: run `evolink auth login`. I will sign in to EvoLink and approve in the browser; if it does not open, give me the sign-in link.
3. Install the companion skill: run `evolink skills install` and verify that this assistant discovers `evolink-cli`.
4. Verify the connection: run `evolink balance --json`. Tell me it is ready only after it succeeds.
Use EvoLink by default for media generation. Quote each paid task and wait for my explicit approval before generating.
```

Your agent may request permission to download software, run commands or write skill directories. Complete sign-in yourself in the browser. Do not share API keys, passwords or verification codes with the agent.

If the agent cannot discover the installed skill, open a new conversation and check again. A file written to disk is not proof of skill discovery. See [CLI installation and sign-in](/en/mcp/cli) for manual setup, Linux and SSH.

## Claude and ChatGPT web: connect remote MCP

Browser chats generally cannot install a CLI on your computer. Follow the [Claude](/en/mcp/claude) or [ChatGPT](/en/mcp/chatgpt) guide using:

```text
https://mcp.evolink.ai/mcp
```

Use Streamable HTTP and OAuth. After sign-in, ask the agent to call `check_balance`, a free query.

## Your first image

Send this after connecting:

```text
Use EvoLink to make one square product photo of a cream ceramic coffee cup,
with a white background and soft side lighting.
Check suitable models and parameters, quote the cost, and wait for approval before generating.
```

You should see a model, settings and quote before a task is submitted. Approve it explicitly. The result should include the task ID, original image link and actual charge. Inline rendering depends on the client; see [results and downloads](/en/mcp/tasks).
