## Connection consent versus paid-task approval

Browser consent lets a client connect to your EvoLink account and query or execute tools. It does not approve every future generation. The bundled skills require the agent to explain model, settings, cost and unknowns before waiting for explicit approval.

Approval may cover a defined task or batch and budget. Added variants, changed input, changed pricing or newly unknown costs need corresponding approval. Available balance, a successful upload or approval of another task is not approval of this task.

These are agent instructions, not a claim that the server displays an approval page for every call. `--confirm` and client tool permission cannot replace cost approval.

## Credential handling

| Connection | Credential storage |
|---|---|
| Remote MCP | Client-managed OAuth sessions and tokens |
| EvoLink CLI | OS secure credential storage; Secret Service on Linux |
| Local API-key MCP | User-configured local environment variables |

Do not put API keys, tokens, verification codes, callback codes or one-time upload URLs in chats, repositories or public logs. Original-file links may grant access to anyone holding them while valid; consider their content before sharing.

## Account changes, disconnects and limits

- For CLI, run `evolink auth logout`, then `evolink auth login`. For native MCP, disconnect and reconnect in that client.
- CLI and native MCP sessions are separate. Logging out one does not log out all clients.
- The dashboard's `EvoLink MCP (OAuth)` is the shared internal key for browser-authorized calls. Set limits, expiry or pause it; it is not a copyable personal API key.
- Removing a client connection affects that client. Disabling the shared key pauses agents using it across the account. See [billing](/en/mcp/billing).

## Capability boundaries

EvoLink MCP/CLI provides media generation, model/parameter/price discovery, reference uploads, task/results and balance queries. Coding, website building, general documents and local media editing depend on the host agent's own tools.

There are no key-management, top-up, account-settings or cancellation tools. Successful generation does not authorize automatic local compositing, transcoding, editing or paid repairs.

## Automation

Define approved scope and budget beforehand, and retain task and original request IDs for audit and recovery. Stop and explain client approval denials or budget failures; do not switch invocation methods to bypass them. See [CLI installation and sign-in](/en/mcp/cli) for Linux/SSH environments.
