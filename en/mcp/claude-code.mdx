## Full installation prompt

Send this entire prompt to Claude Code. Commands run in the agent's actual terminal environment:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Check Node.js and npm. Node.js 22 or newer is required. Run `npm install -g @evolinkai/cli`.
2. Run `evolink auth login`. I will sign in to EvoLink and approve in the browser. If no browser opens, give me the sign-in URL.
3. Run `evolink skills install --agent claude-code`. Verify that this agent can discover and read `evolink-cli`. Start a new session if needed and check skill discovery again.
4. Run `evolink balance --json` for free verification. Tell me when I can get started, or which step failed.
Use EvoLink for media generation by default. Quote each paid task and wait for my explicit confirmation before generating.
```

For manual installation or remote/local MCP, see [installation methods and manual setup](/en/mcp/setup-methods).


## Recommended: CLI and skill

Send the [unified setup prompt](/en/mcp/quickstart) to Claude Code, or run these in order:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent claude-code
evolink balance --json
```

Use Node.js 22+. Sign in and approve yourself in the browser. Verify discovery of `evolink-cli`; open a new session if missing. Cloud acceptance covered CLI setup, skill discovery and simulated delivery. Real paid-account and desktop flows still require client-specific verification.

## Optional: native remote MCP

```bash
claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp
```

Enter `/mcp` in Claude Code, select EvoLink and complete OAuth authentication. Verify with free `check_balance`. User scope makes it available in this user's projects. See [Claude Code's official guide](https://code.claude.com/docs/en/mcp) for project scopes; do not overwrite existing configuration.

Native MCP uses the `evolink-mcp` skill, available through the [plugin](/en/mcp/plugins). CLI uses `evolink-cli`. If the same service is already loaded from claude.ai or a plugin, inspect `/mcp` before adding it again.

### Custom project configuration

1. For all projects, prefer the `--scope user` command above, which writes to `~/.claude.json`. For one project, back up and edit `.mcp.json` in its root.
2. Merge this `evolink` entry into the existing `mcpServers` and preserve other servers. An HTTP entry must include `type`:

```json
{
  "mcpServers": {
    "evolink": {
      "type": "http",
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

3. Save and restart Claude Code, approve the project MCP when prompted, then sign in through `/mcp`. Call `check_balance` to verify.

See the [official Claude Code MCP documentation](https://code.claude.com/docs/en/mcp) for scopes and paths. MCP configuration does not belong in `.claude/settings.local.json`.

## SSH and permissions

For CLI login, see [Linux and SSH](/en/mcp/cli#linux-and-ssh). Native MCP uses Claude Code's own callback flow; do not copy CLI-specific flags to another program.

Tool permission is not cost approval. Show the quote and wait for confirmation. Resolve host denials through its permission prompts rather than bypassing them. See [billing](/en/mcp/billing) and [troubleshooting](/en/mcp/troubleshooting).
