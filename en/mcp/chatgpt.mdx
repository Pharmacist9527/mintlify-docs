ChatGPT web uses remote MCP; no local EvoLink CLI installation is required. Server URL:

```text
https://mcp.evolink.ai/mcp
```

## Add from Plugins

<Steps>
  <Step title="Create a custom MCP server">
    Open [ChatGPT Plugins](https://chatgpt.com/plugins), select the add button, then **Add custom MCP server**. Labels can vary by version or interface language.
  </Step>
  <Step title="Configure the connection">
    Name it `EvoLink`. Choose Server URL and enter the full address above. Select **OAuth**. Leave advanced OAuth client settings at their defaults; do not enter a personal API key.
  </Step>
  <Step title="Create, connect and sign in">
    Review the warning and create the plugin. Install/connect the resulting EvoLink entry, then sign in and approve in the browser after checking your account.
  </Step>
  <Step title="Enable and verify for free">
    In a new chat, type `@` to select EvoLink and ask it to call `check_balance`. An actual balance response verifies the connection.
  </Step>
</Steps>

These steps follow [OpenAI's custom MCP guide](https://developers.openai.com/api/docs/guides/custom-mcp-server). This is a custom connection; it does not imply a reviewed EvoLink listing in ChatGPT's public plugin directory.

## Manual setup: developer-mode interfaces

If your account still shows the older developer-mode entry, use **Settings → Apps** (Connectors in some interfaces), enable available developer/advanced settings, and create a custom app with the same server URL and OAuth.

Availability and read/write permissions depend on OpenAI account and workspace settings. Model or balance queries do not prove generation is enabled. Check actual availability of `generate_image`, `generate_video` and `generate_audio`. For missing creation entries or read-only tools, check account/workspace permissions rather than bypassing them through another authentication method. Follow your current interface and official documentation.

## First task

```text
Use EvoLink for a coffee-cup product photo on white. Check the model,
parameters and cost, wait for my approval, then return the original link and actual charge.
```

ChatGPT tool approval and task cost approval are separate. Generation spends EvoLink balance, not ChatGPT model allowance.

## Attachments, previews and desktop

Remote models may not access browser-chat attachments. Provide public links; see [references](/en/mcp/files). MCP can return small previews, while ChatGPT controls rendering. For gray images, test the original link and query the existing task instead of regenerating.

Desktop entry points, plan permissions and rendering require separate verification. This page focuses on web setup and does not claim full testing of every client. See [results](/en/mcp/tasks) and [troubleshooting](/en/mcp/troubleshooting).
