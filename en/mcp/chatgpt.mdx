ChatGPT chat uses **remote MCP**. Configure it in the client and browser; local CLI installation and a personal API Key are not required.

## Before you begin

Have EvoLink and ChatGPT accounts, plus a client version, plan, and workspace permission that allows custom MCP. If the add action is unavailable, check host access first rather than running terminal instructions in chat.

## Connect EvoLink step by step

<Steps>

<Step title="Open the custom MCP action">

Open [ChatGPT Plugins](https://chatgpt.com/plugins), choose Add or the plus button, then **Create/Add custom MCP server**. This is the website’s setup entry. Labels can vary by version; check workspace access if it is missing.

</Step>

<Step title="Enter the connection details">

| Field | Value |
|---|---|
| Icon (optional) | Download the [EvoLink icon](https://cdn.evolink.ai/next/evolink-logo.png) and upload it; skip this if the form has no icon field |
| Name | EvoLink |
| Connection | Server URL |
| Server URL | `https://mcp.evolink.ai/mcp` |
| Authentication | OAuth |
| Client ID / Client Secret | Leave defaults; do not insert a platform API Key |

Use remote HTTP and keep the trailing `/mcp`. Review the connection prompt and select **Create as a plugin**.

</Step>

<Step title="Install and authorize the account">

Open EvoLink in your personal plugins and install/connect it. When authentication is requested, sign in to EvoLink in the browser, review the account and permissions, and approve. Keep the flow open, then return to ChatGPT. Creating the configuration and installing the plugin are separate steps; the authorization action may appear at different stages.

</Step>

<Step title="Enable it in a conversation and verify">

Start a new conversation and select EvoLink with `@`. If your interface has Chat / Work tabs, switch to **Work** before starting the plugin conversation. Send the free verification prompt below.

**Success:** actual account balance and available models, not only a statement that setup is complete.

</Step>

</Steps>

See [OpenAI custom MCP](https://developers.openai.com/api/docs/guides/custom-mcp-server) and [plugin quickstart](https://developers.openai.com/plugins/quickstart). A personal connection does not mean EvoLink is listed in the public directory.

## Free verification and the first media task

Once connected, send this in a conversation with EvoLink enabled:

```text
Use EvoLink to check my account balance and search available image models. Do not generate anything yet.
```

Confirm actual `check_balance` and `search_models` calls. Sign-in and these queries do not create paid media tasks. For generation, describe content and specifications, review the proposed model, parameters, and estimate, then explicitly approve submission. See the [first media workflow](/en/mcp/overview#workflows).

Use publicly accessible reference links supported by the model. A chat attachment may not expose original file bytes to MCP, and the remote service cannot read your computer’s paths. See [references and uploads](/en/mcp/overview#files).

## Common problems

| Symptom | Next steps |
|---|---|
| No custom connector action | Check plan, version, and workspace permissions in the current host |
| Still unauthorized after browser sign-in | Return to the original client and complete the current flow; see [authorization troubleshooting](/en/mcp/billing#login) |
| Added connection but no tools in chat | Check install/enable status, select EvoLink, open a new conversation; see [MCP troubleshooting](/en/mcp/billing#mcp-connection) |
| Balance works but generation tool is unavailable | Inspect host tool toggles and workspace permissions; do not bypass them with a Key |
| Network timeout or 403 | Identify whether the failure is in the host, login page, or tool request; preserve time and error for support |
| Result is a link or gray preview | Open and save the original; see [download and preview troubleshooting](/en/mcp/billing#download) |

## Refresh and disconnect

Refresh the connection and tools after changes, or open a new conversation. Reauthorize through this host when needed. To stop this client’s access, disconnect/sign out in its settings. Manage shared Key limits and pausing in EvoLink. See [plugins](/en/mcp/plugins) and [costs and troubleshooting](/en/mcp/billing#faq).
