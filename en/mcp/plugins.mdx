## Match the skill to the connection

| Skill | Used with | Installation |
|---|---|---|
| `evolink-cli` | `evolink` terminal commands | Install `@evolinkai/cli`, then `evolink skills install` |
| `evolink-mcp` | Native client MCP tools | MCP plugin or separate skill from `Evolink-AI/mcp-plugin` |

Both require discovery, parameter checks, quotes and explicit paid-task approval, then task recovery and original delivery. A skill is not account login or a tool connection. Verify actual agent discovery after installation.

## Bundled CLI skill

```bash
evolink skills install
evolink skills install --agent codex
```

Reinstall the bundled skill after upgrading the CLI package. See [CLI installation](/en/mcp/cli) for agent names and environments.

## Native MCP plugin

Repository: [Evolink-AI/mcp-plugin](https://github.com/Evolink-AI/mcp-plugin). It combines the remote connection with `evolink-mcp`.

In Claude Code:

```text
/plugin marketplace add Evolink-AI/mcp-plugin
/plugin install evolink@evolink
```

Refresh plugins if prompted, then authenticate EvoLink through `/mcp`. In Codex, add this repository/marketplace through plugin management and install EvoLink. Check version-specific UI or commands; see [Codex setup](/en/mcp/codex).

The plugin uses the same service as a manual MCP connection. Inspect existing tools to avoid duplicates. CLI setup does not require installing another native MCP plugin.

## Native MCP skill only

```bash
npx skills add Evolink-AI/mcp-plugin -g -y
npx skills ls -g -a codex
```

Verify `evolink-mcp` appears. For other agents, use their discovery mechanism. A skill alone has no generation connection: add remote MCP and verify with `check_balance`.

The old `evolink-media` skill was renamed to `evolink-mcp`. Verify the new skill and back up personal changes before removing the old one. `evolink-cli` is a separate execution route, not another rename.
