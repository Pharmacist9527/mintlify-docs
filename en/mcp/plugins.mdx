EvoLink has a public plugin repository on GitHub, [Evolink-AI/mcp-plugin](https://github.com/Evolink-AI/mcp-plugin). The plugin installs two things at once:

- **The EvoLink MCP connection:** the same server, `https://mcp.evolink.ai/mcp`, as adding it by hand.
- **The EvoLink skill:** it teaches the assistant to find a model and quote the price, generate only after you confirm, and follow tasks through.

If you only want the connection, the one-line commands on each setup page are quicker. If you install the plugin, don't also add EvoLink with the command, or you'll get two sets of EvoLink tools.

## Claude Code

<Steps>
  <Step title="Add the marketplace and install">
    Enter these two lines in Claude Code (run `/reload-plugins` if asked):

    ```text
    /plugin marketplace add Evolink-AI/mcp-plugin
    /plugin install evolink@evolink
    ```
  </Step>
  <Step title="Sign in to EvoLink">
    Type `/mcp`, choose `evolink` and select **Authenticate**, then sign in to EvoLink in your browser and click **Allow and connect**.
  </Step>
</Steps>

To uninstall, run `claude plugin uninstall evolink@evolink`.

## Codex

<Steps>
  <Step title="Add the marketplace and install">
    ```bash
    codex plugin marketplace add Evolink-AI/mcp-plugin
    codex plugin add evolink@evolink
    ```
  </Step>
  <Step title="Sign in to EvoLink">
    ```bash
    codex mcp login evolink
    ```

    Your browser opens the EvoLink sign-in page. Sign in and click **Allow and connect**, then start a new session. Use the server name that `codex mcp list` shows.
  </Step>
</Steps>

<Note>
Installing the plugin from the ChatGPT desktop app, the Codex IDE extension or `/plugins` in Codex opens the browser sign-in by itself; no need to run login.
</Note>

## Skill only

Assistants that support skills can install the EvoLink skill on its own:

```bash
npx skills add Evolink-AI/mcp-plugin
```

The skill can't generate anything by itself; add the EvoLink MCP connection as shown on the setup pages.
