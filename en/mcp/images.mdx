## Text-to-image

Describe the scene, purpose, count and settings:

```text
Use EvoLink for one landscape product photo: a cream coffee cup,
white background and soft side lighting. Compare suitable GPT Image and
Seedream models, show parameters and a quote, then wait for approval.
```

The agent discovers models, reads parameters, prepares input, quotes and waits for approval before calling `generate_image`. See [CLI workflows](/en/mcp/cli-workflows) for commands.

## Reference-image editing

Provide a public original-image URL or [upload a local image with the CLI](/en/mcp/files). State what to change and preserve, such as replacing a background while preserving the product. Choose a model with image-input support and use its documented input field.

- A browser-chat attachment may not be accessible to the remote model. Provide a public link when needed.
- An unexpired result URL can be reused as a reference without downloading and reuploading.
- More edits or variants are new paid tasks and require corresponding quotes and approval.

## Size, quality and count

Do not map “2K” or “16:9” to arbitrary input fields. Models may use `size`, `aspect_ratio`, `quality` or other fields; count is model-specific too. GPT image models can constrain pixels, proportions, formats and combinations. Check `get_model` / `models show`.

## Approval template

```text
Ready to generate:
Model: the selected image model
Output: one landscape image, supported size and quality
Input: scene description and any reference media
Cost: the quote and billing unit; disclose unknown totals for token billing
Approve to start generation.
```

Quote the actual input instead of using the search result's starting price. Token-billed totals may be known only after completion; see [billing and caps](/en/mcp/billing).

## Results and previews

Deliver the original image link, task ID and actual charge. MCP may include a small inline preview; the original file defines output quality and dimensions. A gray client placeholder does not mean generation failed. Do not automatically regenerate or create a new thumbnail. Result links usually expire after 24 hours; save promptly. See [tasks and results](/en/mcp/tasks).
