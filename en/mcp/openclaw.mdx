## Full installation prompt

Send this entire prompt to OpenClaw. Commands run in the agent's actual terminal environment:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Check Node.js and npm. Node.js 22 or newer is required. Run `npm install -g @evolinkai/cli`.
2. Run `evolink auth login`. I will sign in to EvoLink and approve in the browser. If no browser opens, give me the sign-in URL.
3. Run `evolink skills install --agent openclaw`. Verify that this agent can discover and read `evolink-cli`. Start a new session if needed and check skill discovery again.
4. Run `evolink balance --json` for free verification. Tell me when I can get started, or which step failed.
Use EvoLink for media generation by default. Quote each paid task and wait for my explicit confirmation before generating.
```

For manual installation or remote/local MCP, see [installation methods and manual setup](/en/mcp/setup-methods).


## Recommended: CLI and skill

Send the [unified setup prompt](/en/mcp/quickstart) to a terminal-capable OpenClaw agent, or run on the machine where its Gateway/agent executes commands:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent openclaw
evolink balance --json
```

Use Node.js 22+ and satisfy OpenClaw's own runtime requirements. Sign in and approve in the browser. Match execution user, PATH, secure storage and skill directory to the installation, then verify discovery of `evolink-cli`.

Installing on a laptop does not install or authenticate a remote Gateway. See [Linux and SSH](/en/mcp/cli#linux-and-ssh).

## Optional: native remote MCP

For an OpenClaw version with native MCP:

```bash
openclaw mcp add evolink --url https://mcp.evolink.ai/mcp --transport streamable-http --auth oauth
openclaw mcp login evolink
```

Complete the client's callback flow, then inspect:

```bash
openclaw mcp doctor evolink --probe
```

Use the installed `openclaw mcp --help`. CLI login does not authenticate native MCP too. Callback and device-code options depend on the client.

### Edit the configuration file yourself

1. On the Gateway host, back up and open `~/.openclaw/openclaw.json`. Use the active file if `OPENCLAW_CONFIG_PATH` is set.
2. Merge `evolink` into the existing `mcp.servers` and preserve other settings. The file supports JSON5; this example uses standard JSON:

```json
{
  "mcp": {
    "servers": {
      "evolink": {
        "url": "https://mcp.evolink.ai/mcp",
        "transport": "streamable-http",
        "enabled": true
      }
    }
  }
}
```

3. Save, run `openclaw mcp login evolink` for browser OAuth, then `openclaw mcp doctor evolink --probe`. Start a new session, confirm tools are discovered and ask the agent to call `check_balance`.

See [OpenClaw MCP configuration](https://docs.openclaw.ai/tools/mcp) and [configuration-file paths](https://docs.openclaw.ai/gateway/configuration). Let the client manage OAuth; do not manually paste tokens into the file.

## Acceptance scope

Cloud records cover CLI setup, skill discovery and quotes in OpenClaw; protocol checks cover native MCP tool discovery. This does not verify every Gateway deployment, messaging channel, desktop interface or paid-media flow.

Obtain explicit cost approval before generating and deliver originals and charges afterward. See [CLI workflows](/en/mcp/cli-workflows) and [results](/en/mcp/tasks).
