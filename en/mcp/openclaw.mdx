<Steps>
  <Step title="Copy this line and run it on the Gateway machine">
    ```bash
    openclaw mcp add evolink --url https://mcp.evolink.ai/mcp --transport streamable-http --auth oauth && openclaw mcp login evolink
    ```
  </Step>
  <Step title="Open the sign-in link">
    The terminal prints a sign-in link (it doesn't open a browser). Open it, sign in to EvoLink and click **Allow and connect**.
  </Step>
  <Step title="Look for the saved message">
    `MCP OAuth credentials saved for "evolink".` in the terminal means you're done. No restart needed: the next turn can use EvoLink.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="The browser isn't on the Gateway machine">
    The callback can't reach the Gateway. Copy the `code` value from the URL the browser ends up on, then run:

    ```bash
    openclaw mcp login evolink --code <code>
    ```
  </Accordion>
  <Accordion title="Why --transport streamable-http">
    OpenClaw connects to remote servers over SSE by default. EvoLink uses Streamable HTTP, so without this flag the connection fails.
  </Accordion>
  <Accordion title="Check the connection">
    ```bash
    openclaw mcp doctor evolink --probe
    ```
  </Accordion>
  <Accordion title="Edit the config file instead">
    Add an `evolink` entry under `mcp.servers` in `~/.openclaw/openclaw.json`, then run `openclaw mcp login evolink` to sign in:

    ```json
    {
      "mcp": {
        "servers": {
          "evolink": {
            "url": "https://mcp.evolink.ai/mcp",
            "transport": "streamable-http",
            "auth": "oauth"
          }
        }
      }
    }
    ```
  </Accordion>
</AccordionGroup>

<Note>
These steps follow OpenClaw's own documentation; we haven't tested OpenClaw ourselves yet.
</Note>

## Try it

Send this in a chat; it only looks something up and costs nothing:

```text
Use EvoLink to check my account balance.
```

If the assistant calls an EvoLink tool and answers, you're connected. If EvoLink doesn't show up, run `openclaw mcp doctor evolink --probe`. See [Check the connection](/en/mcp/tools#check-the-connection) and [Troubleshooting](/en/mcp/troubleshooting) for more.
