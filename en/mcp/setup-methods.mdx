## Choose a connection method

| Method | Best for | Installation and authentication |
|---|---|---|
| CLI and skill | Codex, Claude Code, Cursor, OpenClaw, Hermes and other agents with terminal access | Install `@evolinkai/cli`, sign in through browser OAuth, install the `evolink-cli` skill |
| Remote MCP | Claude or ChatGPT web, and clients that need native MCP tools | Add `https://mcp.evolink.ai/mcp`, sign in through browser OAuth |
| Local stdio MCP | MCP clients using an API key or allowed local file access | Run `@evolinkai/mcp` on the client machine with a personal API key |

The introduction page has a short setup prompt. The full prompts below add environment checks, skill discovery and free verification. CLI sign-in does not register native MCP; native MCP sign-in does not install the CLI skill.

## 1. Install and sign in

<Tabs>
  <Tab title="CLI and skill">
    Send this entire prompt to the agent that will run commands:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Check Node.js and npm in the current execution environment. Node.js 22 or newer is required. Run `npm install -g @evolinkai/cli`.
2. Run `evolink auth login`. I will sign in to EvoLink and approve in the browser. If no browser opens, give me the sign-in URL.
3. Run `evolink skills install`. To install for this agent only, use the appropriate `--agent` option. Verify that this session can discover and read `evolink-cli`; start a new session if needed.
4. Run `evolink balance --json` for free verification. Tell me when I can get started, or which step failed.
Use EvoLink for media generation by default. Quote each paid task and wait for my explicit confirmation before submitting it.
```

    Each client page has a full prompt with `--agent` already filled in:

    | Client | Skill installation command | Full steps |
    |---|---|---|
    | Codex | `evolink skills install --agent codex` | [Codex](/en/mcp/codex) |
    | Claude Code | `evolink skills install --agent claude-code` | [Claude Code](/en/mcp/claude-code) |
    | Cursor | `evolink skills install --agent cursor` | [Cursor](/en/mcp/cursor) |
    | OpenClaw | `evolink skills install --agent openclaw` | [OpenClaw](/en/mcp/openclaw) |
    | Hermes | `evolink skills install --agent hermes` | [Hermes](/en/mcp/hermes-agent) |
    | Other terminal agents | `evolink skills install` | [CLI](/en/mcp/cli), [other clients](/en/mcp/other-clients) |

    For manual installation, run the three installation/sign-in commands and the balance command in order. For a remote agent, install on its execution host under the same user. See [CLI sign-in](/en/mcp/cli) for SSH callbacks and credential storage.

    Released CLI 0.6.0 also provides one-command free setup. After installing the npm package, run:

```bash
evolink setup --agent codex --json
```

    Replace `codex` with the agent type in the table. This handles sign-in, skill synchronization and free verification; the agent still needs to confirm skill discovery. The four-step prompt above remains supported.
  </Tab>
  <Tab title="Remote OAuth MCP">
    For browser clients, follow [Claude](/en/mcp/claude) or [ChatGPT](/en/mcp/chatgpt). Create a custom connection named `EvoLink`, choose OAuth and Streamable HTTP, and enter this server URL:

```text
https://mcp.evolink.ai/mcp
```

    Agents with configuration-file and command access can use this prompt:

```text
Add EvoLink remote MCP to my current client.
1. Identify the client, version and configuration scope. Use its supported MCP add command; if a file edit is needed, back up the file and preserve other servers.
2. Use server name evolink, URL https://mcp.evolink.ai/mcp, Streamable HTTP and OAuth. Add or update only this entry.
3. I will sign in to EvoLink and approve in the browser. Reload or start a new session as required by the client.
4. Verify that EvoLink tools are available and call check_balance for free verification. Do not generate paid media yet.
```

    Browser conversations have no local configuration file. Follow the client page's buttons and forms instead of asking it to edit files on your computer.
  </Tab>
  <Tab title="Local stdio MCP">
    Requires Node.js 18+. Create a personal API key and supply it through your local secure settings. Use this prompt without putting the key into it:

```text
Set up EvoLink local stdio MCP.
1. Verify stdio support and identify the client's MCP configuration file. Back it up and preserve other servers.
2. Add evolink with command npx and args ["-y", "@evolinkai/mcp@latest"]. I will supply EVOLINK_API_KEY through local secure settings; do not print secrets into the conversation.
3. If I need local uploads, add only the absolute directories I specify to EVOLINK_UPLOAD_ALLOWED_DIRS.
4. Reload the client and call check_balance for free verification. Do not generate paid media yet.
```

    See [local MCP](/en/mcp/local) for JSON configuration, directory limits, environment variables and billing. Local MCP and the CLI are different npm packages.
  </Tab>
</Tabs>

## Edit local configuration manually

<Steps>
  <Step title="Find the active file">
    `~` means the home directory of the user running the client. Remote clients read remote files. If you use a custom configuration directory, use the active path reported by your client.

    | Client | Default configuration location | Entry to merge |
    |---|---|---|
    | Codex | `~/.codex/config.toml`; trusted projects can use `.codex/config.toml` | `[mcp_servers.evolink]` |
    | Claude Code | User: `~/.claude.json`; project: `.mcp.json` | `mcpServers.evolink`; HTTP requires `type: "http"` |
    | Cursor | `~/.cursor/mcp.json`; project: `.cursor/mcp.json` | `mcpServers.evolink` |
    | OpenClaw | `~/.openclaw/openclaw.json`, or custom `OPENCLAW_CONFIG_PATH` | `mcp.servers.evolink` |
    | Hermes | `~/.hermes/config.yaml` | `mcp_servers.evolink` |

    Client pages include the matching snippets and reload instructions. JSON, TOML and YAML snippets are not interchangeable.
  </Step>
  <Step title="Back up and merge the EvoLink entry">
    Keep a local backup before editing. Update an existing `evolink` entry and preserve other servers. The outer objects in JSON examples show structure; do not replace your entire file. Merge into existing TOML tables or YAML root keys instead of defining them twice.
  </Step>
  <Step title="Sign in and reload">
    Use the client's OAuth sign-in flow for remote MCP. For local stdio, the client reads your API key from its secure environment. Save, reload MCP, restart the client or start a new session, then confirm tools are available.
  </Step>
  <Step title="Verify for free first">
    Run `evolink balance --json` for CLI or ask the agent to call `check_balance` for native MCP. Installed files alone do not prove the connection works. Check environment, permissions and callbacks with [troubleshooting](/en/mcp/troubleshooting) if verification fails.
  </Step>
</Steps>

## 2. Connect and start creating

```text
Use EvoLink to create a coffee cup product image on a white background. Check the model and parameters, quote the cost, and wait for my confirmation before generating.
```

Deliver the task ID, original file URL and actual cost when complete. See [CLI workflows](/en/mcp/cli-workflows) and [tasks and results](/en/mcp/tasks) for image, video and audio workflows.
