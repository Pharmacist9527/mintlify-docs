## What a native MCP agent should read

1. Read [MCP overview](/en/mcp/overview) and the client setup page, then configure and authorize the host.
2. Consult [MCP tool reference](/en/mcp/tools) and the actual tool schemas.
3. Optionally install evolink-mcp guidance or a host plugin using [plugin steps](/en/mcp/plugins). Reading skills does not register or authenticate tools.
4. Apply [shared agent rules](/en/cli-mcp/agent-resources#agent-rules), then verify actual calls using [MCP troubleshooting](/en/mcp/billing#faq).

evolink-cli teaches terminal commands; native MCP uses evolink-mcp tool instructions. Verify installation and authentication separately. llms.txt is a documentation index; the MCP endpoint remains https://mcp.evolink.ai/mcp.
