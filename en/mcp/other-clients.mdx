## Terminal execution: unified CLI

Gemini CLI, OpenCode, Copilot CLI and other skill/terminal-capable agents can use the [Quickstart prompt](/en/mcp/quickstart). Use Node.js 22+ and install/login in the agent's actual execution environment.

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
```

Target one skill with `--agent gemini`, `--agent opencode` or `--agent copilot`. Verify discovery of `evolink-cli`, then query models and quotes. Skills do not change host security policy. Gemini quote execution was denied by its host in current acceptance records; installation success does not prove every workflow passes. Preserve budgets and resolve host permissions.

## Native MCP connection

| Setting | Value |
|---|---|
| Name | `EvoLink` or `evolink` |
| URL | `https://mcp.evolink.ai/mcp` |
| Transport | Streamable HTTP, sometimes labeled HTTP |
| Authentication | OAuth discovery/registration or a supported published client identity |
| Client ID / Secret | Normally default; do not enter a platform API key |

Common JSON shape; follow your client's documentation:

```json
{
  "mcpServers": {
    "evolink": {"url": "https://mcp.evolink.ai/mcp"}
  }
}
```

Merge without replacing existing servers. Complete browser sign-in, verify actual `check_balance`, and inspect generation-tool availability.

## Stdio-only clients

Choose [local API-key MCP](/en/mcp/local), or a third-party HTTP bridge following its official instructions. The bridge manages its own credentials and login. Do not delete a shared authentication directory to reset one service. Verify transport, OAuth and media rendering separately for each client.

## Documentation for agents

The [documentation index](https://evolink.ai/docs/llms.txt) provides model articles. `https://evolink.ai/docs/mcp` searches documentation only; it has no generation tools. Use the media server `mcp.evolink.ai/mcp` to generate.
