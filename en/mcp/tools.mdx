## What you can do

| Tool | What it does | Cost |
|---|---|---|
| `search_models` | Find image, video and audio models by type and keywords | Free |
| `get_model` | See a model's parameters and prices | Free |
| `estimate_cost` | Get a quote before generating | Free |
| `generate_image` | Generate images | Charged at the model's price |
| `generate_video` | Generate video | Charged at the model's price |
| `generate_audio` | Generate music, songs or speech | Charged at the model's price |
| `get_task` | Check a task's progress and results | Free |
| `list_tasks` | List recent tasks | Free |
| `check_balance` | See your balance and what MCP has spent | Free |
| `upload_file` | Turn a public link or a small file (up to 1 MB) into a link for generation input | Free |
| `prepare_upload` | Get a one-time upload address for a local file up to 95 MB | Free |
| `get_upload` | Check a one-time upload and get the file's link | Free |

Just ask in plain language, for example "Draw a red apple with z-image-turbo". For models that can be quoted, the assistant quotes the price first and generates after you confirm; image models billed by tokens (such as GPT Image 2) only show the actual cost after generating. A quote is an estimate for the chosen settings; the final charge is set when the task settles.

## Reference images, video and audio

EvoLink MCP runs on EvoLink's servers and can't read file paths on your computer. Give reference files in one of these ways:

- **A public link:** send the assistant a publicly accessible link; it stores the file on EvoLink with `upload_file`.
- **A small file (up to 1 MB):** in Claude Code, Codex and Cursor, the assistant can read the file and pass its content to `upload_file`.
- **A larger local file (up to 95 MB):** the assistant gets a one-time upload address with `prepare_upload`, runs a `curl` command to upload the file, then gets the file's link with `get_upload`. The address works once and expires after 15 minutes; the upload result is kept for one hour and only your account can look it up.

<Note>
Uploading a local file needs an assistant that can run commands: Claude Code, Codex and Cursor can, and may ask you to approve it the first time. Claude on the web and desktop and ChatGPT usually can't run commands and can't get the original of a file you drop into the chat, so use a public link instead.
</Note>

Uploading is free, and uploaded files are deleted after 72 hours. Supported formats:

| Type | Formats |
|---|---|
| Images | JPEG, PNG, GIF, WebP |
| Audio | MP3, WAV, M4A, AAC, FLAC, OGG |
| Video | MP4, MOV, WebM |

## Task progress and results

- **How long it takes:** images usually come back right away; video typically takes 3–5 minutes and music 20–60 seconds. The assistant checks progress for you, so you don't have to watch it.
- **Reuse results:** a result link can go straight into the next request, as a reference image for editing or as the first frame for image-to-video; no need to download and upload it.
- **If you got disconnected** (for example you closed the window), come back and say "Use EvoLink to check my recent tasks". The assistant finds the task with `list_tasks` and follows it with `get_task`.
- **Don't ask the assistant to generate the same task again** to "refresh" progress; that charges again.
- **Result links expire after 24 hours.** Download what you want to keep. Uploaded reference files are kept for 72 hours; that's a separate rule.

## Check the connection

Send your assistant one of these; both only look things up and cost nothing:

```text
Use EvoLink to check my account balance.
```

```text
Use EvoLink to find 3 video models and tell me their prices.
```

If the assistant calls an EvoLink tool and answers, you're connected. The first time, some assistants ask whether to allow the tool; allow it.

If the assistant can't find EvoLink, check the connection:

| Assistant | Where to look |
|---|---|
| Claude web and desktop | EvoLink shows as connected under **Customize → Connectors**, and it's turned on under **+ → Connectors** in the conversation |
| Cursor | `evolink` shows as connected in the MCP settings |
| Claude Code | Type `/mcp`; `evolink` shows as connected |
| Codex | Run `codex mcp list` |
| Hermes Agent | Type `/reload-mcp` in the session |
| OpenClaw | Run `openclaw mcp doctor evolink --probe` |
| ChatGPT | Type `@` in the input; EvoLink is listed |

When a call stops because a limit is reached, the balance is too low or MCP is paused, the assistant tells you why; see [Costs and limits](/en/mcp/billing#common-messages).
