These 12 tools are exposed by the remote browser-OAuth connection. Local stdio MCP may expose a different list or upload behavior; use the actual connected list. JSON examples show tool names and arguments for an MCP client, not platform REST request bodies. Examples do not approve paid execution.

| Group | Tools | Cost |
|---|---|---|
| Models | `search_models`, `get_model` | Free |
| Quotes | `estimate_cost` | Free |
| Generation | `generate_image`, `generate_video`, `generate_audio` | Model pricing |
| Tasks | `get_task`, `list_tasks` | Free |
| Account | `check_balance` | Free |
| Uploads | `upload_file`, `prepare_upload`, `get_upload` | Free |

## search_models

`type`: `image`, `video`, `audio`, `all` (default). Optional `query`: at most 100 characters. `limit`: 1–50, default 20. Returns canonical IDs, aliases, types, starting prices, documentation status and applicable recommendation fields.

```json
{"name":"search_models","arguments":{"type":"video","query":"seedance","limit":5}}
```

Starting prices are not task totals. See [models and parameters](/en/mcp/models).

## get_model

Required `model`: 1–128 characters. Returns input requirements, parameters, ranges, examples and published pricing, with notices for missing information.

```json
{"name":"get_model","arguments":{"model":"z-image-turbo"}}
```

## estimate_cost

Required `model`, optional planned `input` object, optional `media_seconds` greater than 0 and at most 3600. The hint is separate from `input` and is not sent to the model.

```json
{"name":"estimate_cost","arguments":{"model":"z-image-turbo","input":{"prompt":"A cream ceramic coffee cup on a white background"}}}
```

Inspect input validity, estimate status, warnings and balance/limit coverage. Responses can indicate estimated, partial, token-billed, missing-input or unavailable pricing. Incomplete quotes are not guaranteed totals. This tool does not accept `max_cost_usd`; native MCP puts the cap on generation, while CLI accepts it on `estimate --max-cost-usd`. See [billing and caps](/en/mcp/billing).

## generate_image, generate_video, generate_audio

These tools submit paid tasks for their respective media types and share these top-level arguments:

| Argument | Meaning |
|---|---|
| `model` | Required model ID of the matching media type, 1–128 characters |
| `input` | Documented model parameters; do not put `model` or `callback_url` inside |
| `prompt` | Optional shortcut for `input.prompt`, subject to model limits; avoid conflicting duplicates |
| `client_request_id` | Optional idempotency ID: 16–96 letters, digits, `.`, `_`, `-`; reuse only for the same request |
| `max_cost_usd` | Optional pre-submission estimate cap, greater than 0 and at most $10000; not a settlement cap |
| `media_seconds` | Same estimate hint; cannot turn unknown/partial costs into a guaranteed budget |

Inspect input, quote and obtain approval first. Example image arguments:

```json
{"name":"generate_image","arguments":{"model":"z-image-turbo","input":{"prompt":"A cream ceramic coffee cup on a white background"},"client_request_id":"image-coffee-demo-001"}}
```

Retain the returned `task_id` and query progress with task tools. See [images](/en/mcp/images), [video](/en/mcp/video) and [audio](/en/mcp/audio).

## get_task

Required `task_id`. Integer `wait_seconds`: 0–45, default 30; 0 checks immediately. Returns status, progress, result links, charges or errors.

```json
{"name":"get_task","arguments":{"task_id":"TASK_ID_FROM_RESPONSE","wait_seconds":30}}
```

Results usually expire after 24 hours. Query the same task; never regenerate to refresh progress.

## list_tasks

Use `task_ids` (1–50 known IDs) for batch lookup, or omit IDs to filter recent tasks by `type`, `status`, `since` and `limit`. `status`: `processing`, `completed`, `failed`, `cancelled`; processing includes queued tasks. `since`: ISO 8601 or relative `30m`, `2h`, `1d`. `limit`: 1–50, default 20.

```json
{"name":"list_tasks","arguments":{"type":"image","since":"2h","limit":10}}
```

ID mode ignores other filters. Recent tasks cover the whole account, not just your chat. `since` filters the fetched page instead of scanning all history.

## check_balance

No arguments. Returns balance, spending scope and limits. OAuth MCP spending covers connected agents across the account, not one chat.

```json
{"name":"check_balance","arguments":{}}
```

## upload_file

Choose exactly one of `file_url` and `base64_data`. `file_url` must be public HTTPS. Remote OAuth base64 files are limited to 1 MB; raw base64 also needs `mime_type`, while data URLs can include MIME. Optional `file_name` has no folders; optional relative `upload_path` must not contain `..`.

```json
{"name":"upload_file","arguments":{"file_url":"https://example.com/reference.png","file_name":"reference.png"}}
```

Replace the placeholder domain with an accessible file. Remote MCP does not accept `file_path`. Files remain for approximately 72 hours.

## prepare_upload

Required `file_name` including an extension, optional `upload_path`. Returns one-time `upload_url`, `upload_id`, PUT method, command and expiry. Valid for 15 minutes, once, up to 95 MB.

```json
{"name":"prepare_upload","arguments":{"file_name":"reference.mp4"}}
```

Execute PUT where the file can be read. See [uploads](/en/mcp/files).

## get_upload

Required `upload_id`. Returns status for your account's upload and `file_url` when complete. Status records expire after approximately one hour.

```json
{"name":"get_upload","arguments":{"upload_id":"UPLOAD_ID_FROM_RESPONSE"}}
```

## Confirm the connection

Ask the agent for account balance and verify an actual successful `check_balance` call. For CLI setup, run `evolink balance --json`; native MCP tools need not appear in the client. Also verify the matching skill is available. See [troubleshooting](/en/mcp/troubleshooting).

## Task progress and results

Use `get_task` and `list_tasks` to continue existing tasks and deliver original links and actual charges. See [tasks and results](/en/mcp/tasks) for waiting, recovery, previews and CLI downloads.

## Provide reference images, video or audio

Choose public URL, small base64, CLI or one-time upload according to file location. See [uploads and references](/en/mcp/files) and [tasks and results](/en/mcp/tasks).
