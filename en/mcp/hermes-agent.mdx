<Tabs>
  <Tab title="CLI: copy one command">
    <Steps>
      <Step title="Copy and run this line">
        ```bash
        hermes mcp add evolink --url https://mcp.evolink.ai/mcp --auth oauth --connect-timeout 300
        ```
      </Step>
      <Step title="Sign in and approve in the browser">
        Your browser opens the EvoLink sign-in page by itself. Sign in and click **Allow and connect**.
      </Step>
      <Step title="Enable the tools">
        Back in the terminal, press Enter when asked "Enable all … tools?". In a session that's already open, type `/reload-mcp`; no restart needed.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Desktop app: one-click add">
    <Steps>
      <Step title="Click to add">
        Open [Add to Hermes](hermes://mcp/install?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCIsImF1dGgiOiJvYXV0aCJ9). The Hermes desktop app asks you to confirm; confirm to save it.
      </Step>
      <Step title="Authorize">
        Find `evolink` in the desktop app's MCP settings, click **Authorize**, then sign in to EvoLink in your browser and click **Allow and connect**.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<AccordionGroup>
  <Accordion title="Why --auth oauth and --connect-timeout 300">
    `--auth oauth` makes Hermes sign in through the browser; without it, Hermes asks for an API key. `--connect-timeout 300` gives the sign-in five minutes; the default 30 seconds is often too short.
  </Accordion>
  <Accordion title="Over SSH, or no browser on this machine">
    The terminal also prints the authorization link. Open it in the browser on your own computer, sign in and approve, then paste the URL the browser ends up on back into the terminal. Hermes' device-code sign-in (`--flow device`) doesn't work with EvoLink yet.
  </Accordion>
  <Accordion title="Edit the config file instead">
    Add an `evolink` entry under `mcp_servers` in `~/.hermes/config.yaml`, then run `hermes mcp login evolink` to sign in:

    ```yaml
    mcp_servers:
      evolink:
        url: "https://mcp.evolink.ai/mcp"
        auth: oauth
    ```
  </Accordion>
</AccordionGroup>

<Note>
These steps follow Hermes Agent's own documentation; we haven't tested Hermes ourselves yet.
</Note>

## Try it

Send this in a chat; it only looks something up and costs nothing:

```text
Use EvoLink to check my account balance.
```

If the assistant calls an EvoLink tool and answers, you're connected. If EvoLink doesn't show up, type `/reload-mcp` in the session. See [Check the connection](/en/mcp/tools#check-the-connection) and [Troubleshooting](/en/mcp/troubleshooting) for more.
