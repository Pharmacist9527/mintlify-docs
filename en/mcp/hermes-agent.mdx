## Full installation prompt

Send this entire prompt to Hermes. Commands run in the agent's actual terminal environment:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Check Node.js and npm. Node.js 22 or newer is required. Run `npm install -g @evolinkai/cli`.
2. Run `evolink auth login`. I will sign in to EvoLink and approve in the browser. If no browser opens, give me the sign-in URL.
3. Run `evolink skills install --agent hermes`. Verify that this agent can discover and read `evolink-cli`. Start a new session if needed and check skill discovery again.
4. Run `evolink balance --json` for free verification. Tell me when I can get started, or which step failed.
Use EvoLink for media generation by default. Quote each paid task and wait for my explicit confirmation before generating.
```

For manual installation or remote/local MCP, see [installation methods and manual setup](/en/mcp/setup-methods).


## Recommended: CLI and skill

Send the [unified setup prompt](/en/mcp/quickstart) to a terminal-capable Hermes agent, or run in its execution environment:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent hermes
evolink balance --json
```

Node.js 22+ is required. Complete browser login yourself. Linux/SSH needs secure credential storage and a reachable callback; see [CLI sign-in](/en/mcp/cli). The installed skill is `evolink-cli`. In a new session, verify actual discovery before model queries and quotes.

## Optional: native remote MCP

With a Hermes version supporting OAuth:

```bash
hermes mcp add evolink --url https://mcp.evolink.ai/mcp --auth oauth --connect-timeout 300
```

Follow authentication and tool-enablement prompts, refresh with `/reload-mcp` in the conversation, then call `check_balance`. Use `hermes mcp --help` for version-specific options and callbacks. Do not apply EvoLink CLI flags to Hermes commands.

### Edit the configuration file yourself

1. Back up and open `~/.hermes/config.yaml` in the Hermes execution environment. Use the active file if you have a custom configuration directory.
2. Merge `evolink` under the existing `mcp_servers`. Preserve other servers and indentation; do not repeat the root key:

```yaml
mcp_servers:
  evolink:
    url: "https://mcp.evolink.ai/mcp"
    auth: oauth
    connect_timeout: 300
```

3. Save and run `hermes mcp login evolink` in a fresh terminal. Complete browser sign-in yourself, then `/reload-mcp` or start a new Hermes session and call `check_balance`.

See the [official Hermes MCP documentation](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp/) for paths and OAuth settings.

## Acceptance scope

Cloud records cover Hermes CLI setup, skill discovery and quotes without unauthorized submission. They do not verify Hermes desktop, native OAuth and real paid media end to end.

See [CLI workflows](/en/mcp/cli-workflows) and [troubleshooting](/en/mcp/troubleshooting).
