## Choose an upload method

| Source | Recommended method |
|---|---|
| Public HTTPS link | MCP `upload_file`, or direct use if the model supports the URL |
| Local media and a terminal-capable agent | `evolink upload` |
| Small file up to 1 MB | MCP `upload_file` with `base64_data` and `mime_type` |
| Larger local file with native remote MCP | `prepare_upload`, local PUT, then `get_upload` |
| Claude or ChatGPT browser attachment | Verify the agent can retrieve an accessible original; otherwise provide a public link |

Remote MCP cannot read paths such as `/Users/...` or `C:\...`. Internal chat attachment addresses are not public URLs. Only [local stdio MCP](/en/mcp/local) can read local files inside configured allowed directories.

## CLI upload

```bash
evolink upload ./reference.png --json
```

Use the returned `file_url` in the selected model's supported reference field. For a storage folder:

```bash
evolink upload ./clip.mp4 --upload-path references --json
```

If uploading was interrupted or its response was lost, use the retained upload ID:

```bash
evolink uploads get UPLOAD_ID --json
```

Check the status before retrying; never reuse a consumed one-time URL. The CLI handles preparation, PUT and status queries without manual copying of upload tokens.

## One-time upload with native MCP

1. Call `prepare_upload` with `file_name` including its extension, and optional `upload_path`.
2. Run the returned command on the computer that holds the file, or PUT it to the returned `upload_url`.
3. Call `get_upload` with the same `upload_id` for completion and `file_url`.

The URL expires after 15 minutes and works once. The per-file limit is 95 MB. The URL carries upload authorization; do not publish it in screenshots or logs. Status records remain for approximately one hour; the uploaded file remains for approximately 72 hours.

## Supported formats

| Type | Formats |
|---|---|
| Image | JPEG, PNG, GIF, WebP |
| Audio | MP3, WAV, M4A, AAC, FLAC, OGG/Opus |
| Video | MP4, MOV, WebM |

Uploads are free and files are deleted after approximately 72 hours. Upload acceptance does not guarantee model compatibility. Check the model's format, size, pixel, duration and reference-count limits.

## References versus results

Generated result links usually expire after 24 hours; uploaded references remain for approximately 72 hours. Download files to your own storage for longer retention. When supported, unexpired result links can be reused directly as references without another upload.
