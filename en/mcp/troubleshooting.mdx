---

<AccordionGroup>
  <Accordion title="The assistant doesn't show EvoLink's tools">
    Check the connection as described in [Check the connection](/en/mcp/tools#check-the-connection), and sign in again if it says sign-in is needed. Reopen Claude Code, start a new Codex session only if the tools are missing in the current one, or type `/reload-mcp` in Hermes Agent.

    In Claude Code, if the assistant says it has no evolink tools, type `/mcp`, choose `evolink`, select **Authenticate** to sign in again, then restart Claude Code.
  </Accordion>
  <Accordion title="The approval page says the request expired">
    You have 10 minutes from starting the sign-in in your assistant to approving. If it expired, start the sign-in again from the assistant.
  </Accordion>
  <Accordion title="The approval page shows Unverified">
    The assistant registered itself (see [Sign-in and approval](/en/mcp/sign-in#what-the-approval-page-checks)) and wants to send the approval to a website. Approve only if you started this connection yourself.
  </Accordion>
  <Accordion title="Use a different EvoLink account">
    Click **Switch account** on the approval page and approve with the account you want. For an assistant that's already connected, disconnect it first, then connect again.
  </Accordion>
  <Accordion title="Cursor: sign-in fails after clicking Connect">
    Cursor waits for the browser callback on local port 8787. If another program uses that port (for example `wrangler dev`), the sign-in fails. Close that program and click **Connect** again. See [Cursor setup](/en/mcp/cursor).
  </Accordion>
  <Accordion title="Codex: the command isn't recognized, or no browser opens">
    You need Codex 0.77 or later. If no browser opens, run `codex mcp login evolink`. See [Codex setup](/en/mcp/codex).
  </Accordion>
  <Accordion title="Codex: after Cancel on the approval page, the sign-in page opens again">
    Codex retries once by itself when the first authorization does not go through. Click **Cancel** again, or press Ctrl+C in the terminal.
  </Accordion>
  <Accordion title="Hermes Agent: the sign-in times out, or it asks for an API key">
    Include `--auth oauth` and `--connect-timeout 300` in the command. See [Hermes Agent setup](/en/mcp/hermes-agent).
  </Accordion>
  <Accordion title="OpenClaw: it won't connect">
    Include `--transport streamable-http`; OpenClaw's default SSE can't reach EvoLink. See [OpenClaw setup](/en/mcp/openclaw).
  </Accordion>
  <Accordion title="Over SSH, or no browser on this machine">
    In Claude Code use `claude mcp login evolink --no-browser`, in Codex `codex mcp login evolink --no-browser`, then open the printed link in the browser on your own computer. In Hermes Agent paste the URL the browser ends up on back into the terminal; in OpenClaw use `--code`.
  </Accordion>
  <Accordion title="Claude: the connector limit is reached">
    Claude's Free plan can add one custom connector. Remove one you don't use, or upgrade your plan.
  </Accordion>
</AccordionGroup>

## Common messages

When a call stops because a limit is reached, the balance is too low or MCP is paused, the assistant tells you why; see [Costs and limits](/en/mcp/billing#common-messages).

## Contact support

If none of the above helps, email [support@evolink.ai](mailto:support@evolink.ai) or find us on [Discord](https://discord.gg/P9xzmJWndW). These details help us find the problem faster:

- the email address of your EvoLink account;
- which assistant you use, for example Claude Code, Codex or ChatGPT;
- roughly when it happened, and the full error message;
- for a generation problem, the task ID (`task_id`).

Please don't send your API key or password.
