## Full installation prompt

Send this entire prompt to Cursor. Commands run in the agent's actual terminal environment:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Check Node.js and npm. Node.js 22 or newer is required. Run `npm install -g @evolinkai/cli`.
2. Run `evolink auth login`. I will sign in to EvoLink and approve in the browser. If no browser opens, give me the sign-in URL.
3. Run `evolink skills install --agent cursor`. Verify that this agent can discover and read `evolink-cli`. Start a new session if needed and check skill discovery again.
4. Run `evolink balance --json` for free verification. Tell me when I can get started, or which step failed.
Use EvoLink for media generation by default. Quote each paid task and wait for my explicit confirmation before generating.
```

For manual installation or remote/local MCP, see [installation methods and manual setup](/en/mcp/setup-methods).


## Recommended: CLI and skill

Send the [unified setup prompt](/en/mcp/quickstart) to a terminal-capable Cursor Agent, or run:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install --agent cursor
evolink balance --json
```

Use Node.js 22+. Sign in and approve yourself in the browser. Verify Agent discovers `evolink-cli` and can access the installation in its execution environment.

## Optional: native remote MCP

Select [Add to Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9), install and authenticate/connect EvoLink in Cursor's MCP settings.

For manual configuration, merge this service into `~/.cursor/mcp.json` without replacing existing servers:

```json
{
  "mcpServers": {
    "evolink": {"url": "https://mcp.evolink.ai/mcp"}
  }
}
```

Use Streamable HTTP and OAuth. After browser approval, ask Agent to call free `check_balance`. For native MCP instructions, install the [`evolink-mcp` skill](/en/mcp/plugins).

### Edit the configuration file yourself

Use `~/.cursor/mcp.json` globally or `.cursor/mcp.json` in your project. Back up the active file and merge the `evolink` entry into its existing `mcpServers`; do not replace the whole file with the example. Project entries take priority when the same name exists in both scopes.

Save and restart Cursor. Enable EvoLink and complete sign-in in MCP settings, then start a new conversation and call `check_balance`.

## Troubleshooting

CLI and Cursor's native MCP logins are independent. CLI setup does not require an EvoLink entry in MCP settings. Native MCP requires loaded tools. Cloud execution may use a different installation, login or skill environment than your local machine.

See [Cursor's official MCP guide](https://prod.cursor.com/help/customization/mcp) for current UI and capabilities. For gray previews with accessible originals, see [tasks and downloads](/en/mcp/tasks); do not regenerate automatically.
