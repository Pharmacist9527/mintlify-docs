This page covers native MCP in Cursor. The remote service uses Streamable HTTP and browser OAuth without requiring EvoLink CLI. For command and skill execution, use the separate [CLI guide](/en/cli/cursor).

## Connect remote MCP

For native tools, use **Streamable HTTP + OAuth** with this server URL:

```text
https://mcp.evolink.ai/mcp
```

CLI installation is not required. Back up existing configuration, merge only EvoLink, and preserve other services. Choose command-based or manual registration.

<Steps>

<Step title="Add the server to Cursor">

Choose [Add to Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9), allow the browser to open Cursor, review the name and URL, and confirm. Use manual configuration below if the application does not open.

</Step>

<Step title="Enable and authorize the connection">

Open Cursor’s MCP settings, enable EvoLink, and follow browser sign-in and approval. Return to Cursor and inspect its connection and tool list.

</Step>

<Step title="Verify for free in Agent">

Open an Agent conversation with tool permission and send the verification prompt below. Refresh the connection or start a new conversation if tools are missing; check whether project configuration overrides or disables the global entry.

</Step>

</Steps>

Manual configuration uses `~/.cursor/mcp.json` globally or `.cursor/mcp.json` for one project. Merge into the existing `mcpServers` object:

```json
{
  "mcpServers": {
    "evolink": {
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

See [Cursor configuration](https://cursor.com/docs/mcp).

After authorization, send this in the agent chat:

```text
Use EvoLink to check my account balance and search available image models. Do not generate anything yet.
```

**Success:** actual `check_balance` and `search_models` calls return results. Verify these tools in the actual MCP connection.

## Updates, disconnection, and troubleshooting

EvoLink updates the hosted MCP server. Refresh the actual client session after configuration changes. Reauthorize through that client's OAuth action when needed. Disable, sign out, or remove EvoLink in host MCP settings to disconnect; retain other servers.

| Symptom | Action |
|---|---|
| URL added but no tools | Enable the connection, complete authorization, refresh, and check organization policy |
| 401 or authentication required | Reauthorize this MCP connection and retain original task IDs |
| 403 or tool denied | Check host permissions, account/Key status, and network errors |
| Timeout or lost response | Query and recover the original operation instead of regenerating |
| Link-only or gray preview | Open and deliver the original without automatically remaking it |

See [MCP costs, access, and troubleshooting](/en/mcp/billing#faq). Read the [creation workflow](/en/mcp/overview#workflows) before submitting; call shapes are in the [MCP tool reference](/en/mcp/tools).
