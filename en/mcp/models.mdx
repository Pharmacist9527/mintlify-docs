## Discover, then inspect

Use MCP `search_models` for candidates and `get_model` for exact inputs. CLI equivalents:

```bash
evolink models search --type image --query seedream --limit 5 --json
evolink models show doubao-seedream-5.0-pro --json
```

Search by media type and keywords. Discovery handles catalog aliases and common hyphen/dot variations. Submit the returned canonical ID rather than guessing IDs from display names.

## Read the response

| Information | What to do |
|---|---|
| ID, media type and aliases | Choose the matching image, video or audio tool; retain the canonical ID |
| Parameters and examples | Check required fields, allowed values, defaults and combinations |
| Reference inputs | Check image/video/audio support, counts and dimensions |
| Starting price and unit | Identify per-image, per-request, per-second or token billing; this is not your task total |
| Missing parameter or pricing notice | Do not invent inputs or substitute starting prices; read model documentation or select a fully documented model |
| Platform recommendation | A candidate when the user did not choose a model; still check suitability and budget |

The catalog filters against platform model availability and combines parameter and pricing information. Models can be added, removed or changed: query current data. A missing starting price does not mean the platform has no pricing, and missing parameters do not permit arbitrary input.

## Default model selection

Honor the user's model choice, requirements and budget. Otherwise search these platform-preferred families and compare available models:

| Task | Candidate families | Check |
|---|---|---|
| Images, product photos and image editing | GPT Image 2.5 / 2, Seedream 5.0 | References, sizes, count, token billing |
| Video | Seedance 2.5 / 2.0, Wan 3.0 | Text/image/reference input, duration, resolution, audio |
| Music and songs | Suno v6 | Simple/custom mode, lyrics, style and outputs |
| Speech or voiceover | Search suitable speech models | Text field, voice, language and references |

These are not popularity or release-date rankings. Music models are not universal voiceover models. Extensions, editing, layers and upscaling require models suited to those specific tasks.

## Constraints and validation

Input fields differ from prose descriptions. Include `input.duration` only if supported. Sizes may require a particular format, pixel range or multiple. Some audio models make image and audio references mutually exclusive.

Run MCP `estimate_cost` or CLI `evolink estimate` on the exact input and inspect validation problems and billing notes. Validation success is not a guarantee of final cost; read model documentation and warnings too. See [billing and caps](/en/mcp/billing).
