With a command-line agent such as Claude Code or Codex, you don't have to type the commands yourself: copy the prompt below to your agent. It installs the EvoLink skill, adds EvoLink MCP, then has you sign in to EvoLink from your browser. No API key is needed.

## Copy this prompt

```text
Set up EvoLink for me so I can generate images, videos and audio from here.
1. Install the companion skill: run `npx skills add Evolink-AI/mcp-plugin -g -y`.
2. Add the EvoLink MCP server and start the sign-in:
   - Claude Code: run `claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp`, ask me to restart you with `claude --continue`, then call the evolink authenticate tool and give me the sign-in link.
   - Codex: run `codex mcp add evolink --url https://mcp.evolink.ai/mcp`; it opens the sign-in in my browser (if no browser opens, give me the link it prints). Then ask me to restart you with `codex resume --last`.
   - Other command-line agents: add `https://mcp.evolink.ai/mcp` as a remote MCP server (Streamable HTTP) and use OAuth when sign-in is needed.
3. I'll complete the sign-in in the browser.
Once that's done, let me know when it's ready.
```

## What happens next

<Steps>
  <Step title="The agent installs the skill">
    The agent runs `npx skills add Evolink-AI/mcp-plugin -g -y`, which installs the EvoLink skill in `~/.agents/skills/evolink-media`; Claude Code can use it too. The skill teaches the agent to quote first and generate only after you confirm. The first time the agent runs a command, it may ask for your approval.
  </Step>
  <Step title="The agent adds EvoLink and starts the sign-in">
    - **Claude Code**: after adding it, the agent asks you to restart it with `claude --continue`, which keeps the conversation; then it calls the evolink authenticate tool and gives you the sign-in link. You can also type `/mcp`, pick `evolink` and choose **Authenticate**.
    - **Codex**: adding it opens the sign-in page in your browser; if it doesn't open, the agent gives you the link. After signing in, restart Codex with `codex resume --last` to keep the conversation.
  </Step>
  <Step title="Sign in and approve in the browser">
    Sign in to EvoLink and click **Allow and connect**, then go back to your agent.
  </Step>
</Steps>

<Note>
The terminal an agent runs commands in is not interactive, so `claude mcp login` fails there. That is why Claude Code restarts first and then signs in with the authenticate tool.
</Note>

## Run the commands yourself

- For the one-line commands, see [Claude Code](/en/mcp/claude-code) and [Codex](/en/mcp/codex); for other command-line agents, see [Other MCP clients](/en/mcp/other-clients).
- To install only the skill, see [Plugins and skills](/en/mcp/plugins).
- To use your own API key instead of signing in from the browser, see [Local version (API key)](/en/mcp/local).

## Try it

Send this in a chat. It only looks things up and costs nothing:

```text
Use EvoLink to check my account balance.
```

If the assistant calls an EvoLink tool and shows the result, you're connected. See [Check the connection](/en/mcp/tools#check-the-connection) and [Troubleshooting](/en/mcp/troubleshooting) for more.
