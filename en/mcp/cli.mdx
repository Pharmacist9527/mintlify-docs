Claude Code and Codex have their own setup pages: see [Claude Code](/en/mcp/claude-code) and [Codex](/en/mcp/codex). With another command-line agent, you don't have to type the commands yourself: copy the prompt below to your agent. It installs the EvoLink skill, adds EvoLink as a remote MCP server, then has you sign in to EvoLink from your browser. No API key is needed.

## Copy this prompt

```text
Set up EvoLink for me so I can generate images, videos and audio from here.
1. Install the companion skill: run `npx skills add Evolink-AI/mcp-plugin -g -y`.
2. Add `https://mcp.evolink.ai/mcp` as a remote MCP server (Streamable HTTP) named `evolink`, signing in with OAuth.
3. Start the sign-in: I'll sign in to EvoLink in my browser and approve. If no browser opens, give me the sign-in link. If you have to be reopened before you can use it, tell me how.
Once that's done, let me know when it's ready.
```

## What happens next

<Steps>
  <Step title="The agent installs the skill">
    The agent runs `npx skills add Evolink-AI/mcp-plugin -g -y`, which installs the EvoLink skill in `~/.agents/skills/evolink-mcp`. The skill teaches the agent to quote first where a model can be quoted, and to generate only after you confirm. The first time the agent runs a command, it may ask for your approval.
  </Step>
  <Step title="The agent adds EvoLink">
    The agent adds `https://mcp.evolink.ai/mcp` as a remote MCP server named `evolink`, with OAuth for sign-in, using its own command or settings. Each agent does this differently; see [OpenClaw](/en/mcp/openclaw), [Hermes Agent](/en/mcp/hermes-agent) and [Other MCP clients](/en/mcp/other-clients) for examples.
  </Step>
  <Step title="Sign in and approve in the browser">
    Your browser opens the EvoLink sign-in page; if it doesn't, the agent gives you the sign-in link. Sign in and click **Allow and connect**. Some agents have to be reopened before they can use a new server; the agent tells you how.
  </Step>
</Steps>

## Run the commands yourself

- Claude Code and Codex: see their own pages, [Claude Code](/en/mcp/claude-code) and [Codex](/en/mcp/codex).
- Other command-line agents: see [OpenClaw](/en/mcp/openclaw), [Hermes Agent](/en/mcp/hermes-agent) and [Other MCP clients](/en/mcp/other-clients).
- To install only the skill, see [Plugins and skills](/en/mcp/plugins).
- To use your own API key instead of signing in from the browser, see [Local version (API key)](/en/mcp/local).

## Try it

Send this in a chat. It only looks things up and costs nothing:

```text
Use EvoLink to check my account balance.
```

If the assistant calls an EvoLink tool and shows the result, you're connected. See [Check the connection](/en/mcp/tools#check-the-connection) and [Troubleshooting](/en/mcp/troubleshooting) for more.
