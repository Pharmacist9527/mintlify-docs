Prefer not to sign in from the browser, or want your assistant to upload files straight from your computer? Use the local version: the npm package `@evolinkai/mcp` runs on your computer and calls EvoLink with your own API key. It has the same tools for finding models, quotes, generation, tasks, balance and uploads; generation is charged at the model's price and shows under that key.

<Note>
You need Node.js 18 or later. Run `node -v` in your terminal to check.
</Note>

## Local and remote versions compared

| | Remote version (other setup pages) | Local version (this page) |
|---|---|---|
| Where it runs | EvoLink's server `https://mcp.evolink.ai/mcp` | Your computer |
| How it connects | Sign in from the browser and approve, no API key | Your own API key |
| Which key spending shows under | `EvoLink MCP (OAuth)` | The key you give it |
| Uploading local files | See [Reference images, video and audio](/en/mcp/tools#reference-images-video-and-audio) | Reads the folders you allow, up to 100 MB per file |
| Install | Nothing | Node.js 18+ |

## Setup

<Steps>
  <Step title="Create an API key">
    Create a key in [API Keys](https://evolink.ai/dashboard/keys). Keep one just for MCP, so you can set its limits or disable it without affecting your other keys.
  </Step>
  <Step title="Add EvoLink to your client">
    Replace `YOUR_API_KEY` with your key and run the command in your own terminal. Don't paste the key into a chat with your assistant; the key is saved in the client's config on your computer.

    <Tabs>
      <Tab title="Claude Code">
        ```bash
        claude mcp add evolink --scope user -e EVOLINK_API_KEY=YOUR_API_KEY -- npx -y @evolinkai/mcp@latest
        ```
      </Tab>
      <Tab title="Codex">
        ```bash
        codex mcp add evolink --env EVOLINK_API_KEY=YOUR_API_KEY -- npx -y @evolinkai/mcp@latest
        ```
      </Tab>
      <Tab title="Cursor, Claude Desktop and others">
        Add this to the MCP config file, such as `~/.cursor/mcp.json` for Cursor or `claude_desktop_config.json` for Claude Desktop:

        ```json
        {
          "mcpServers": {
            "evolink": {
              "command": "npx",
              "args": ["-y", "@evolinkai/mcp@latest"],
              "env": { "EVOLINK_API_KEY": "YOUR_API_KEY" }
            }
          }
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="Restart your client">
    Restart your client. In Claude Code, `/mcp` should show `evolink` as connected. The first start downloads the package and can take a few seconds.
  </Step>
</Steps>

<Warning>
Added the remote version before? Both are named `evolink`, so remove the remote one first, or you will get two sets of EvoLink tools:

```bash
# Claude Code
claude mcp remove evolink --scope user
# Codex
codex mcp remove evolink
```

If you installed the plugin, run `claude plugin uninstall evolink@evolink` first.
</Warning>

## Upload local files

To let your assistant upload files from your computer, also set the environment variable `EVOLINK_UPLOAD_ALLOWED_DIRS` to the folders it may read:

- Use absolute paths; separate several folders with `:` on macOS and Linux or `;` on Windows.
- It can read only files in those folders, up to 100 MB each. Images (JPEG, PNG, GIF, WebP), audio (MP3, WAV, M4A, AAC, FLAC, OGG) and video (MP4, MOV, WebM) are supported.
- Uploaded files are kept for 72 hours. Without this variable, local files can't be uploaded; use public links instead.

In Claude Code, for example, use this command instead of the one above:

```bash
claude mcp add evolink --scope user -e EVOLINK_API_KEY=YOUR_API_KEY -e EVOLINK_UPLOAD_ALLOWED_DIRS=/Users/you/Pictures -- npx -y @evolinkai/mcp@latest
```

In Codex, add `--env EVOLINK_UPLOAD_ALLOWED_DIRS=…`; in a JSON config, put it under `env`.

## Try it

Send this in a chat. It only looks things up and costs nothing:

```text
Use EvoLink to check my account balance.
```

If the assistant calls an EvoLink tool and shows the result, you're connected.

## Troubleshooting

<AccordionGroup>
  <Accordion title="evolink fails to connect">
    Most often the key is missing or wrong: without a key the program exits as soon as it starts. Also run `node -v` to make sure Node.js 18 or later is installed. Restart your client after fixing it.
  </Accordion>
  <Accordion title="Switch to another key">
    Remove `evolink` first (see the commands above), then run the add command again with the new key.
  </Accordion>
  <Accordion title="Pause or limit spending">
    Set limits on this key in [API Keys](https://evolink.ai/dashboard/keys), or disable it. The local version doesn't create `EvoLink MCP (OAuth)`; all spending shows under the key you give it. See [Costs and limits](/en/mcp/billing) for billing rules.
  </Accordion>
  <Accordion title="Update to a new version">
    The `@latest` in the command makes your client use the newest version every time it starts, so you don't need to update by hand.
  </Accordion>
</AccordionGroup>
