title: "Get Request Cost"
description: "Query status, usage, and actual cost by Request ID for synchronous API calls, primarily to text models"
openapi: /en/api-manual/account-management/get-request-usage.json GET /v1/requests/{request_id}
---

<Note>
This endpoint queries the cost of **synchronous API calls**, primarily to **text models** through Chat Completions, Messages, or Responses.

Use the value of the `X-Request-Id` header from the original response as the Request ID. Wait a moment after the request completes before querying. For asynchronous tasks, use [Get task status](/en/api-manual/task-management/get-task-detail).
</Note>
