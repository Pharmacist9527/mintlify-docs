<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
**Server-side tools** (web search, MCP) are only available on the [Responses API](/en/api-manual/language-series/gpt/responses/responses-reference). The Chat Completions endpoint supports regular `function` tool calling only.
</Note>

<Note>
**GPT-6**: Function calling with `gpt-6-sol` / `gpt-6-luna` requires `reasoning_effort: "none"` in this endpoint. Use the [Responses API](/en/api-manual/language-series/gpt/responses/responses-reference) for function calling with `gpt-6.2-astra` / `gpt-6.2-sol` / `gpt-6-astra`, `gpt-6.1-sol`, or `gpt-6.1-terra`, or for GPT-6 `max` effort.
</Note>
