### Using Grok 4.7

Set `model` to `grok-4.7` and keep the existing `messages` request format. The context window is 500,000 tokens, and the knowledge cutoff is May 2026.

Use the top-level `reasoning_effort` parameter. Reasoning depth: `low` / `medium` / `high` (default) / `xhigh`. Reasoning cannot be disabled. `grok-4.7` and `grok-4.6` support `xhigh`; `grok-4.5` accepts it but treats it as `high`. Reasoning tokens are billed as output tokens.

`prompt_cache_key` provides a stable cache routing hint for requests sharing a prompt prefix; it does not guarantee a cache hit. Check `usage.prompt_tokens_details.cached_tokens` for actual hits. To preserve encrypted reasoning across turns, use the [Responses API](../responses/responses-reference).
