---
title: "Gemini Explicit Context Caching - Delete a cache"
openapi: '/en/api-manual/language-series/gemini/cached-contents/cached-contents.json DELETE /v1beta/cachedContents/{id}'
---

<Note>
Delete the cache immediately; success returns an empty object `{}`. Subsequent references return 404 `CACHE_NOT_FOUND`. Deletion is free, but **storage fees paid on creation are not refunded**.
</Note>

- If not deleted manually, the cache is removed automatically at `expireTime`. Early deletion releases it without a refund.
- For concepts, billing, and error codes, see [Create a cache](/en/api-manual/language-series/gemini/cached-contents/cached-contents-create).
