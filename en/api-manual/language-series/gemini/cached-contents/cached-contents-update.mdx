---
title: "Gemini Explicit Context Caching - Extend or shorten the lifetime"
openapi: '/en/api-manual/language-series/gemini/cached-contents/cached-contents.json PATCH /v1beta/cachedContents/{id}'
---

<Note>
Only the lifetime can be changed, not the content. Provide either `ttl` (a new lifetime starting **now**, such as `"7200s"`) or `expireTime` (a new absolute expiry time; `expire_time` is also accepted). The new expiry must be 60 seconds to 168 hours from now.
</Note>

- Only `ttl` or `expireTime` is accepted. Providing both or other fields such as `contents` or `displayName` returns 400 with the field name.
- **Extending** charges additional storage: added duration (seconds, with durations below 1 second charged as 1 second) × cached tokens × storage rate (per million tokens per hour). **Shortening** does not refund storage fees already charged.
- This is a paid operation: the Key needs model access (the same allowlist as generation), and its current user group's pricing applies. Insufficient balance returns 402 `INSUFFICIENT_QUOTA`.
- Expired or deleted caches cannot be extended; returns 404 `CACHE_NOT_FOUND`.
- When retrying the same extension request after a network timeout, send the same `Idempotency-Key` header to avoid duplicate charges.
- Extension charges can also be found on the dashboard's Logs page using the cache ID.
- For concepts, billing, and error codes, see [Create a cache](/en/api-manual/language-series/gemini/cached-contents/cached-contents-create).
