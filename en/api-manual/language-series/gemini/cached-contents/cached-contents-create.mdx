<Note>
**BaseURL**: The default is `https://direct.evolink.ai`, which offers better support for text models and long connections; `https://api.evolink.ai` is the fallback endpoint.
</Note>

Create a cache for a reusable long prefix (documents, system instructions, or tool definitions). Subsequent generation requests send only the cache name and a new question. Cached tokens are billed at the cache hit rate; storage is charged by token count and duration while the cache exists.

## Supported models

| Family | Models |
|---|---|
| Gemini 3.x Flash | `gemini-3.8-flash`, `gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-3-flash-preview` |
| Gemini 3.x Flash-Lite | `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite-preview` |
| Gemini 3.x Pro | `gemini-3.1-pro-preview`, `gemini-3.1-pro-preview-customtools`, `gemini-3-pro-preview` |

Gemini 4 models do not support explicit caching. Creation returns 400 `EXPLICIT_CACHE_UNSUPPORTED`.

## Explicit and implicit caching

| | Implicit caching (default) | Explicit caching (this page) |
|---|---|---|
| Usage | No changes required; requests with the same prefix may hit automatically | Create a cache, then reference its name in generation requests |
| Cache hits | Not guaranteed | Referencing the cache produces a hit |
| Cache write fee | None | Charged by cached token count |
| Cache storage fee | None | Charged by cached token count × hours |
| Best for | Natural reuse without changes | Many calls using the same long prefix over a period of time |

## Workflow

1. **Create**: `POST /v1beta/cachedContents`, providing the long prefix in at least one of `contents`, `systemInstruction`, or `tools`. Returns the cache `name`.
2. **Reference**: Add `"cachedContent": "<name>"` to the body of `POST /v1beta/models/{model}:generateContent` (`streamGenerateContent` for streaming). Put only the new question in `contents`.
3. **Extend** (optional): To keep using the cache, `PATCH /v1beta/cachedContents/{id}` with a new `ttl` or `expireTime`. Storage is charged for the added duration.
4. **Delete** (optional): `DELETE /v1beta/cachedContents/{id}` when no longer needed. Otherwise, it is removed automatically on expiry. Storage fees already charged are not refunded.

Caches belong to an account: any API Key within that account can reference them (the model must be included if the Key has a model allowlist). Other accounts receive 404 for the same cache name. References and extensions use the pricing of the requesting Key's current user group.

## Reference a cache in generation requests

```bash
curl -X POST "https://direct.evolink.ai/v1beta/models/gemini-3.8-flash:generateContent" \
  -H "Authorization: Bearer $EVOLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "cachedContent": "cachedContents/20261103012026348092000s1oTuB96",
    "contents": [
      { "role": "user", "parts": [{ "text": "What does the manual say about returns?" }] }
    ]
  }'
```

In the response, `usageMetadata.cachedContentTokenCount` is the number of tokens served from cache, billed at the cache hit rate. `promptTokenCount` includes those tokens; the rest is billed at the regular input rate.

```json
{
  "candidates": [
    { "content": { "role": "model", "parts": [{ "text": "Chapter 7 of the manual states..." }] }, "finishReason": "STOP" }
  ],
  "usageMetadata": {
    "promptTokenCount": 7541,
    "cachedContentTokenCount": 7525,
    "candidatesTokenCount": 212,
    "totalTokenCount": 7753
  },
  "modelVersion": "gemini-3.8-flash"
}
```

<Warning>
Generation requests referencing a cache **must not include** `systemInstruction`, `tools`, or `toolConfig`. Set these when creating the cache; including them returns 400. The generation model must match the cache model, or the request returns 400 `CACHE_MODEL_MISMATCH`.
</Warning>

## Complete example (Python)

```python
import requests

BASE = "https://direct.evolink.ai"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json"}

# 1. Create a cache: long document + system instructions, kept for 1 hour
manual = open("manual.txt", encoding="utf-8").read()   # Must meet the model's minimum cache token count
cache = requests.post(f"{BASE}/v1beta/cachedContents", headers=HEADERS, json={
    "model": "models/gemini-3.8-flash",
    "displayName": "product-manual-v3",
    "systemInstruction": {"parts": [{"text": "You are a product manual assistant. Answer only from the manual."}]},
    "contents": [{"role": "user", "parts": [{"text": manual}]}],
    "ttl": "3600s",
}).json()
name = cache["name"]            # cachedContents/<id>
cache_id = name.split("/")[-1]  # <id>
print("cached tokens:", cache["usageMetadata"]["totalTokenCount"], "expire:", cache["expireTime"])

# 2. Reference repeatedly: send only the new question each time
for question in ["What is the return policy?", "How long is the warranty?", "Can I send a product from overseas for repair?"]:
    resp = requests.post(f"{BASE}/v1beta/models/gemini-3.8-flash:generateContent", headers=HEADERS, json={
        "cachedContent": name,
        "contents": [{"role": "user", "parts": [{"text": question}]}],
    }).json()
    print(resp["candidates"][0]["content"]["parts"][0]["text"])
    print("cache hit tokens:", resp["usageMetadata"].get("cachedContentTokenCount", 0))

# 3. Keep using it: retain for 2 hours from now (storage charged for the added duration)
requests.patch(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS, json={"ttl": "7200s"})

# 4. Delete when done (storage fees already charged are not refunded)
requests.delete(f"{BASE}/v1beta/cachedContents/{cache_id}", headers=HEADERS)
```

## Billing

| Item | Billing method |
|---|---|
| Cache write | Cached tokens × write rate, charged on creation. The write rate equals the model's input rate; Pro caches above 200,000 tokens use the long-context rate |
| Cache storage | Cached tokens × lifetime (hours, prorated by seconds) × storage rate (per million tokens per hour), charged upfront for the full lifetime |
| Generation using a cache | `cachedContentTokenCount` uses the cache hit rate; other input and output use regular rates. If `googleSearch` is declared in the cache, each search is charged separately at the search rate |
| Extend lifetime | Storage fee for the added duration; durations below 1 second are charged as 1 second |
| Shorten / delete / expire | Storage fees already charged are not refunded |
| List / get | Free |

- The cached token count is taken from `usageMetadata.totalTokenCount` in the creation response.
- The `<id>` in the cache name is the creation request's ID. Search for it on the dashboard's Logs page to view creation and extension charges (cached tokens, storage duration, and storage fee).
- See [Pricing](https://evolink.ai/pricing) for each model's cache write, cache hit, and storage rates.
- Cost effectiveness: storage is charged by duration, while each cache hit saves input costs. More calls using the same prefix during its lifetime make caching more worthwhile; for only one or two calls, sending the original text is cheaper.

## Limits

- **Lifetime**: Minimum 60 seconds, maximum 168 hours (`604800s`). Provide only one of `ttl` or `expireTime`; omitting both defaults to 1 hour.
- **Content**: Provide at least one of `contents`, `systemInstruction`, or `tools`. The creation request body must not exceed 10 MB, and content must meet the model's minimum token count (for example, 4,096 for `gemini-3.8-flash`); otherwise, returns 400.
- **Fields**: Only the fields documented on this page are accepted. Other fields return 400 with the field name.
- **tools**: Only `googleSearch`, `codeExecution`, and `functionDeclarations` are accepted.
- **Immutable content**: Only the lifetime can be changed after creation. To change the content, create a new cache.
- **Access control**: Creation and extension follow the same IP allowlist, model allowlist, and rate limits as regular generation requests.

## Error codes

Errors use the Gemini native format. `error.details[0].reason` contains the specific reason code:

```json
{
  "error": {
    "code": 404,
    "message": "cached content not found",
    "status": "NOT_FOUND",
    "details": [{ "@type": "type.googleapis.com/google.rpc.ErrorInfo", "reason": "CACHE_NOT_FOUND", "domain": "evolink.ai" }]
  }
}
```

| HTTP | reason | Meaning |
|---|---|---|
| 400 | `INVALID_ARGUMENT` | Invalid parameters: no cacheable content, `ttl` outside 60 seconds–168 hours, both `ttl` and `expireTime` provided, unsupported fields or tools, etc. |
| 400 | `EXPLICIT_CACHE_UNSUPPORTED` | Model does not support explicit caching (Gemini 4 or image models) |
| 400 | `NO_AVAILABLE_CHANNEL` | The current user group cannot create caches for this model |
| 400 | `MODEL_PRICE_ERROR` | Explicit caching for this model is not enabled for the current user group |
| 400 | `CACHE_EXPIRED` | Cache expired during processing or has too little lifetime remaining |
| 400 | `CACHE_MODEL_MISMATCH` | Generation model does not match the cache model |
| 400 | `INVALID_CACHED_CONTENT` | Invalid `cachedContent` format |
| 4xx | `UPSTREAM_ERROR` | Model rejected the content; `message` explains why, commonly content below the minimum cache token count |
| 402 | `INSUFFICIENT_QUOTA` | Insufficient balance for cache write and storage fees |
| 403 | — | The Key cannot access this model, the source IP is not on its allowlist, or the Key's user group is no longer available |
| 404 | `CACHE_NOT_FOUND` | Cache does not exist, has expired, was deleted, or belongs to another account |
| 404 | `EXPLICIT_CACHE_DISABLED` | Explicit caching is not enabled |
| 413 | `CACHE_CONTENT_TOO_LARGE` | Request body exceeds 10 MB |
| 502 | `UPSTREAM_ERROR` | Service temporarily unavailable. This request is not charged; please retry later |
| 503 | `CACHE_CHANNEL_UNAVAILABLE` | Cache temporarily unavailable; please retry later |
| 503 | `INTERNAL` | Service temporarily unavailable; please retry later |
