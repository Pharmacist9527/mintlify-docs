<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
**Explicit context caching**: Create a cache from a long prefix you reuse (long documents, system instructions, tool definitions); later generation requests send only the cache name and the new question. Cached tokens are billed at the cache hit rate. A cache write fee and an hourly storage fee also apply; storage is charged upfront for the full lifetime and is not refunded.
</Note>

<Tip>
**Using a cache**: Add `"cachedContent": "<name>"` to the `generateContent` or `streamGenerateContent` request body and put only the new question in `contents`. Requests that reference a cache cannot include `systemInstruction`, `tools`, or `toolConfig`, and must use the same model as the cache.
</Tip>
