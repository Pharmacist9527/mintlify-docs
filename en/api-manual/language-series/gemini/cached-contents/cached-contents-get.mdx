---
title: "Gemini Explicit Context Caching - Get a cache"
openapi: '/en/api-manual/language-series/gemini/cached-contents/cached-contents.json GET /v1beta/cachedContents/{id}'
---

<Note>
The path `{id}` is the `name` returned on creation without the `cachedContents/` prefix. Returns the model, token count, and creation/update/expiry times, without cached content. Free of charge.
</Note>

- Expired, deleted, missing caches and caches belonging to another account all return 404 `CACHE_NOT_FOUND`.
- For concepts, billing, and error codes, see [Create a cache](/en/api-manual/language-series/gemini/cached-contents/cached-contents-create).
