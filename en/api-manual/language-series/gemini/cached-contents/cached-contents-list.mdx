---
title: "Gemini Explicit Context Caching - List caches"
openapi: '/en/api-manual/language-series/gemini/cached-contents/cached-contents.json GET /v1beta/cachedContents'
---

<Note>
Returns only **unexpired** caches for the current account, owned by account regardless of Key. Expired or deleted caches are excluded. Free of charge.
</Note>

- Ordered by expiry time descending, with the latest expiry first.
- `pageSize` defaults to 50, maximum 200. If the response includes `nextPageToken`, pass it unchanged as `pageToken` in the next request.
- Each item matches the Get a cache response: metadata only, without cached content.
- For concepts, billing, and error codes, see [Create a cache](/en/api-manual/language-series/gemini/cached-contents/cached-contents-create).
