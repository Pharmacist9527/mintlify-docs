<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

Use `POST /v1/responses` and select `kimi-k3.1-pro`, `kimi-k3.1-pro-highspeed`, or `kimi-k3` with `model`. Only `model` and `input` are required.

<Warning>
**Parameter names differ from Chat Completions**: use `input` for input, `max_output_tokens` for the output limit, and `reasoning.effort` for reasoning effort.
</Warning>

## Reading the answer text

The response `output` may include reasoning, answer text, and tool calls. Iterate over the `output_text` content blocks within `type="message"` items; do not assume the first item contains the answer.

Assuming the response JSON has been parsed into `response`, extract the text as follows:

```python
text = "".join(
    part["text"]
    for item in response.get("output", [])
    if item.get("type") == "message"
    for part in item.get("content", [])
    if part.get("type") == "output_text"
)
print(text)
```

<Note>
**Reserve output budget for reasoning**: `max_output_tokens` includes both reasoning and the answer. If `status="incomplete"` and `incomplete_details.reason="max_output_tokens"`, increase the limit. When the budget is exhausted, the response may contain only reasoning items without answer text.
</Note>

For tool calling, web search, image input, and structured output, see the [full reference](/en/api-manual/language-series/kimi/responses/responses-reference).
