<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
**Reasoning is always enabled for Kimi models**. The response `content` usually includes `type="thinking"` blocks, which count toward output tokens. Avoid setting `max_tokens` too low: reasoning may exhaust the output budget before any answer text is produced.
</Note>
