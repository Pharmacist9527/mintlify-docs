<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
**Reasoning is always enabled for Kimi models** and returned in `reasoning_content`. Reasoning tokens count toward output. Avoid setting `max_completion_tokens` too low: reasoning may exhaust the output budget before any answer text is produced.
</Note>
