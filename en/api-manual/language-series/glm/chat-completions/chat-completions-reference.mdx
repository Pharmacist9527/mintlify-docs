<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
Thinking switch. enabled turns thinking on and is the default for all models. `disabled` turns it off only on glm-5.2.

`glm-5.3`, `glm-5.3-flash` and `glm-5.3-flashx` always think. Passing `disabled` retains the default thinking mode; it neither disables thinking nor sets the effort to low. To reduce effort, set reasoning_effort=low. After switching from `glm-5.2` to the 5.3 series, thinking remains enabled and thinking tokens are billed as output even if `thinking.type=disabled` is retained.
</Note>

`reasoning_effort`: Reasoning effort, default max.

**Compatibility rules for `glm-5.3` / `glm-5.3-flash` / `glm-5.3-flashx`**

| Supplied value | Effective thinking level |
| --- | --- |
| `low` / `high` / `max` | Unchanged |
| `xhigh` | `max` |
| `medium` | `high` |
| `minimal` / `none` | `low`; thinking remains enabled |

**`minimal` and `none` do not disable thinking on the 5.3 series.** Thinking tokens are billed as output. Unrecognized values are unchanged and have no compatibility mapping; use the listed values. These mappings do not apply to glm-5.2.

`glm-5.2` supports `max`, `xhigh`, `high`, `medium`, `low`, `minimal` and none. `xhigh` is equivalent to `max`; `medium` / `low` are equivalent to `high`; `minimal` / `none` can disable thinking. `thinking.type=disabled` can also turn it off. Use `max` for complex tasks such as coding.

<Note>
User message content.

- **String**: plain text, supported by every model
- **Content block array**: text and images mixed, **supported only by `glm-5.3-flash` and `glm-5.3-flashx`**

Sending image content blocks to `glm-5.3` or `glm-5.2` returns an error.
</Note>
