<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
Seed enables reasoning by default. In `content`, a `type="thinking"` block precedes the answer and counts toward output tokens. Set `max_tokens` to at least 1024 so reasoning is less likely to exhaust the budget before any answer text is generated.
</Note>
