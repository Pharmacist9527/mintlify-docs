<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
Only `doubao-seed-2-1-lite` accepts audio input. Web search is available via [Responses](/en/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-responses-reference) or [Messages](/en/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-messages-reference) on Seed 2.1 and `doubao-seed-evolving`. Chat Completions does not offer it.
</Note>
