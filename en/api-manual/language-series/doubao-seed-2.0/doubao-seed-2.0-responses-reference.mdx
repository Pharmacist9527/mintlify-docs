<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
Only Seed 2.1 and `doubao-seed-evolving` support web search. Each actual search is billed according to its source. Explicit caching adds a storage charge. See `caching` and `expire_at` for details. Both explicit-cache examples in the request menu omit `expire_at`, so storage is billed for the default three-day lifetime.
</Note>

## Build a cache request that expires in one hour

Run this Python snippet just before sending and use the printed JSON as the request body. Leave `PREVIOUS_RESPONSE_ID` unset for the first request. To continue, set it to the actual `id` returned by the previous request and run the snippet again. Each run calculates a fresh `expire_at`.

```python
import json
import os
import time

body = {
    "model": "doubao-seed-2-1-pro",
    "input": "Product manual: the motor and battery have a two-year warranty. Remember this policy.",
    "caching": {"type": "enabled"},
    "expire_at": int(time.time()) + 3600,
}
previous_id = os.getenv("PREVIOUS_RESPONSE_ID")
if previous_id:
    body["previous_response_id"] = previous_id
    body["input"] = "Which parts are covered by the warranty?"
print(json.dumps(body, ensure_ascii=False))
```
