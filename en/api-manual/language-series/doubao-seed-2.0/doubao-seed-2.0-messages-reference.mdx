<Note>
**BaseURL**: The default BaseURL is `https://direct.evolink.ai`, which has better support for text models and long-lived connections. `https://api.evolink.ai` is the primary endpoint for multimodal services and serves as a fallback address for text models.
</Note>

<Note>
Only Seed 2.1 and `doubao-seed-evolving` support `web_search_20250305`. Messages does not accept audio. For audio input with `doubao-seed-2-1-lite`, use [Chat Completions](/en/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-reference) or [Responses](/en/api-manual/language-series/doubao-seed-2.0/doubao-seed-2.0-responses-reference).
</Note>
