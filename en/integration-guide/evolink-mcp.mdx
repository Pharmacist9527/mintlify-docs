## Overview

EvoLink MCP lets AI assistants use EvoLink's models directly: find models and prices, get a quote before generating images, video and audio, and check task progress and your balance.

- **Server URL:** `https://mcp.evolink.ai/mcp`
- **No API key needed:** the first time, sign in to EvoLink in your browser and approve; the assistant is then connected.
- **Pay as you go:** usage is charged to your EvoLink balance at the same prices as the API. The MCP itself is free.

## One-click add

### Claude web and desktop

<Steps>
  <Step title="Click to add">
    Sign in to claude.ai in your browser, then open [Add EvoLink to Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp). The **Add custom connector** dialog opens with the name and URL filled in; click **Add**.
  </Step>
  <Step title="Connect and sign in to EvoLink">
    Find EvoLink in your connectors and click **Connect**. Your browser opens the EvoLink sign-in page; sign in and click **Allow and connect**.
  </Step>
  <Step title="Turn EvoLink on in a conversation">
    Click **+** in the chat input, choose **Connectors** and turn EvoLink on; typing `/` in the input opens the same menu. The first time Claude calls an EvoLink tool, it asks for permission: choose **Allow once** or **Always allow**.
  </Step>
</Steps>

<Note>
Custom connectors work on Claude's Free, Pro, Max, Team and Enterprise plans; Free can add one. A connector added on the web also works in the desktop and mobile apps.

**Team and Enterprise:** an organization Owner adds it first, with the [admin one-click link](https://claude.ai/admin-settings/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp) or under **Organization settings → Connectors → Add → Custom**. Members then find EvoLink with the **Custom** tag under **Customize → Connectors** and click **Connect**.
</Note>

<Accordion title="If the link doesn't open: add it by hand">
  1. In Claude, open **Customize → Connectors** and click **Add custom connector**.
  2. Enter `EvoLink` as the name and `https://mcp.evolink.ai/mcp` as the URL, then click **Continue**.
  3. For authentication choose **Sign in now**; keep the OAuth client at the default **Use Claude's published identity (Recommended)**, then click **Add**.
  4. Continue with step 2 above: click **Connect** and sign in.

  The authentication settings can't be changed after you add the connector; to change them, delete the connector and add it again.
</Accordion>

### Cursor

<Steps>
  <Step title="Click to add">
    Click [Add to Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9). Your browser opens Cursor, which asks whether to install `evolink`; confirm.
  </Step>
  <Step title="Click Connect to sign in">
    Open Cursor's MCP settings. Next to `evolink` you'll see that it needs login; click **Connect**. Your browser opens the EvoLink sign-in page; sign in and click **Allow and connect**.
  </Step>
  <Step title="Check that it's connected">
    Back in Cursor, `evolink` shows as connected with its tools listed, and you can use it in Agent chats.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="Add it by hand: edit the config file">
    Add an `evolink` entry under `mcpServers` in `~/.cursor/mcp.json` (if the file already lists other servers, add only this entry), save it, then click **Connect** in the MCP settings the same way:

    ```json
    {
      "mcpServers": {
        "evolink": {
          "url": "https://mcp.evolink.ai/mcp"
        }
      }
    }
    ```
  </Accordion>
  <Accordion title="Use the Cursor CLI (agent)">
    Write the `~/.cursor/mcp.json` above first, then run:

    ```bash
    agent mcp login evolink
    ```
  </Accordion>
  <Accordion title="Sign-in fails after clicking Connect">
    Cursor waits for the browser callback on local port 8787. If another program is using that port (for example `wrangler dev`), the sign-in fails. Close that program and click **Connect** again.
  </Accordion>
</AccordionGroup>

## Copy one command

### Claude Code

<Steps>
  <Step title="Copy and run this line">
    Run this line in your terminal, or type `!` in Claude Code's input box and paste it:

    ```bash
    claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp && claude mcp login evolink
    ```

    The first half adds EvoLink to Claude Code (`--scope user` makes it available in every project); the second half starts the sign-in.
  </Step>
  <Step title="Sign in and approve in the browser">
    Your browser opens the EvoLink sign-in page. Sign in, click **Allow and connect**, and wait for the terminal to confirm the sign-in.
  </Step>
  <Step title="Reopen Claude Code">
    Reopen Claude Code and type `/mcp`. When `evolink` shows as connected, it's ready.
  </Step>
</Steps>

<Tip>
If you sign in to Claude Code with your Claude account and have already added the EvoLink connector on claude.ai, Claude Code can use it directly; you don't need this command. Pick one: using both gives you two sets of EvoLink tools.
</Tip>

<AccordionGroup>
  <Accordion title="Want the EvoLink skill too: install the plugin">
    The skill teaches Claude to quote before generating. Enter these two lines in Claude Code (run `/reload-plugins` if asked), then type `/mcp`, choose `evolink` and select **Authenticate**. If you use the plugin, skip the command above.

    ```text
    /plugin marketplace add Evolink-AI/mcp-plugin
    /plugin install evolink@evolink
    ```
  </Accordion>
  <Accordion title="Over SSH, or no browser on this machine">
    Replace the sign-in half with the line below. The terminal prints an authorization link: open it in the browser on your own computer, sign in and approve, then paste the URL the browser ends up on back into the terminal.

    ```bash
    claude mcp login evolink --no-browser
    ```
  </Accordion>
  <Accordion title="Windows PowerShell 5">
    The PowerShell 5 that ships with Windows doesn't support `&&`. Replace it with `;`, or run the two commands on separate lines. PowerShell 7, cmd and WSL can run the line as is.
  </Accordion>
  <Accordion title="Use it in one project only">
    Drop `--scope user` to make EvoLink available only in the current project; use `--scope project` to write it to the project's `.mcp.json` and share it with your team.
  </Accordion>
</AccordionGroup>

### Other clients

Clients that support remote MCP can usually connect with the same URL. When adding it, fill in:

| Field | Value |
|---|---|
| Name | `EvoLink` (or `evolink`) |
| Server URL | `https://mcp.evolink.ai/mcp` |
| Transport | Streamable HTTP (some clients call it HTTP) |
| Authentication | OAuth; leave Client ID and Client Secret empty, the client registers itself |

Many clients use a JSON config file. The two common shapes:

<CodeGroup>
```json mcpServers style
{
  "mcpServers": {
    "evolink": {
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```

```json servers style
{
  "servers": {
    "evolink": {
      "type": "http",
      "url": "https://mcp.evolink.ai/mcp"
    }
  }
}
```
</CodeGroup>

After saving, sign in when the client asks: your browser opens the EvoLink sign-in page; sign in and click **Allow and connect**.

<Accordion title="The client only supports local (stdio) MCP: bridge with mcp-remote">
  The open-source [mcp-remote](https://github.com/geelen/mcp-remote) runs the remote server as a local process. It needs Node.js 18 or later:

  ```json
  {
    "mcpServers": {
      "evolink": {
        "command": "npx",
        "args": ["-y", "mcp-remote@latest", "https://mcp.evolink.ai/mcp", "--transport", "http-only"]
      }
    }
  }
  ```

  The first start opens the browser to sign in to EvoLink; the approval page shows the app as "MCP CLI Proxy". Sign-in data is kept in `~/.mcp-auth`; delete that folder to sign in again. We haven't tested this route ourselves yet.
</Accordion>

## First connection: sign in and approve

<Steps>
  <Step title="Sign in to EvoLink">
    Your browser opens the EvoLink sign-in page. You can sign up there if you don't have an account.
  </Step>
  <Step title="Approve the connection">
    The approval page shows which assistant is asking to connect (for example Claude Code or Codex), what it will be able to do (look up models and prices, run models on your account, stay connected) and which EvoLink account you're signed in with. Check it, then click **Allow and connect**. To use another account, click **Switch account**.
  </Step>
  <Step title="Return to your assistant">
    When the browser says you can go back, the assistant shows EvoLink as connected and you can start.
  </Step>
</Steps>

<Note>
The approval page shows what EvoLink could check about the assistant. Assistants that publish a client metadata document, such as Claude, Claude Code, Codex, ChatGPT and the Hermes Agent CLI, show "Published by" with their website (for example claude.ai or chatgpt.com). Assistants that register themselves when they connect, such as Cursor and OpenClaw, can't have their name checked, but the approval only goes back to an app on your device, so the page adds a note instead of a warning. If a self-registered assistant would send the approval to a website, the page shows "Unverified": continue only if you started the connection yourself.
</Note>

## Check that it's connected

Send your assistant one of these; both only look things up and cost nothing:

```text
Use EvoLink to check my account balance.
```

```text
Use EvoLink to find 3 video models and tell me their prices.
```

If the assistant calls an EvoLink tool and answers, you're connected. The first time, some assistants ask whether to allow the tool; allow it.

If the assistant can't find EvoLink, check the connection:

| Cursor | `evolink` shows as connected in the MCP settings |
| Claude Code | Type `/mcp`; `evolink` shows as connected |
| Codex | Run `codex mcp list` |

## What you can do

| Tool | What it does | Cost |
|---|---|---|
| `search_models` | Find image, video and audio models by type and keywords | Free |
| `get_model` | See a model's parameters and prices | Free |
| `estimate_cost` | Get a quote before generating | Free |
| `generate_image` | Generate images | Charged at the model's price |
| `generate_video` | Generate video | Charged at the model's price |
| `generate_audio` | Generate music, songs or speech | Charged at the model's price |
| `get_task` | Check a task's progress and results | Free |
| `list_tasks` | List recent tasks | Free |
| `check_balance` | See your balance and what MCP has spent | Free |
| `upload_file` | Turn a public link or a small file (up to 1 MB) into a link for generation input | Free |
| `prepare_upload` | Get a one-time upload address for a local file up to 95 MB | Free |
| `get_upload` | Check a one-time upload and get the file's link | Free |

Just ask in plain language, for example "Draw a red apple with z-image-turbo". The assistant quotes the price first and generates after you confirm. Video and audio take a while; the assistant checks progress for you.

### Reference images, video and audio

EvoLink MCP runs on EvoLink's servers and can't read file paths on your computer. Give reference files in one of these ways:

- **A public link:** send the assistant a publicly accessible link.
- **A small file (up to 1 MB):** the assistant can pass the file's content to `upload_file`.
- **A larger local file (up to 95 MB):** the assistant gets a one-time upload address with `prepare_upload`, runs a command to upload the file, then gets the file's link with `get_upload`. The address works once and expires after 15 minutes.

Uploading is free, and uploaded files are kept for 72 hours. Claude Code, Codex and Cursor can run the upload command and may ask you to approve it the first time. Claude on the web and desktop usually can't run commands; use a public link or a small file instead.

## Task progress and results

- **Video and audio** take a while to generate. The assistant checks progress for you, so you don't have to watch it.
- **If you got disconnected** (for example you closed the window), come back and say "Use EvoLink to check my recent tasks". The assistant finds the task with `list_tasks` and follows it with `get_task`.
- **Don't ask the assistant to generate the same task again** to "refresh" progress; that charges again.
- **Result links expire after 24 hours.** Download what you want to keep. Uploaded reference files are kept for 72 hours; that's a separate rule.

## Costs and limits

- Usage is charged to your balance at the same prices as the API. The balance is shared by the API, the web app and MCP.
- After you approve your first connection, [API Keys](https://evolink.ai/dashboard/keys) in the dashboard shows a key named `EvoLink MCP (OAuth)`, marked MCP at the top-right of its name. All assistants connected to your account through MCP share this key. It can't be copied and works only through MCP; create a separate API key if you need one.
- There is no spending limit by default; only your balance applies. Set a total limit, a daily limit or an expiry date on this key to cap MCP spending. Disable it to pause MCP for all assistants; your other keys are not affected.
- Tasks, charges and usage from MCP appear in the dashboard as usual under the key name `EvoLink MCP (OAuth)`.

## Common messages

When one of these happens, the assistant tells you which one it is and what to do:

| Message | Meaning | What to do |
|---|---|---|
| EvoLink MCP spending limit reached | The MCP total limit is used up; this is not your account balance | Raise the limit of `EvoLink MCP (OAuth)` in API Keys |
| EvoLink MCP daily limit reached | The MCP daily limit is used up; it resets at midnight | Wait for the reset or raise the daily limit |
| Your EvoLink account balance is too low | Your balance is not enough | Top up in the dashboard |
| EvoLink MCP is paused for this account | `EvoLink MCP (OAuth)` is disabled | Enable it again in API Keys; no need to reconnect |
| EvoLink MCP key has expired | `EvoLink MCP (OAuth)` passed the expiry date you set | Extend or clear the expiry date in API Keys; no need to reconnect |
| This EvoLink connection was disconnected | The connection ended or expired | Reconnect EvoLink in the assistant |
| EvoLink has temporarily turned off MCP access | EvoLink has turned MCP off for everyone for a while; it isn't your settings | Try again later; switching models, retrying right away or reconnecting won't help |

None of these are charged.

## Disconnect

- **One assistant:** in Claude, disconnect it in the connector settings; in Claude Code run `claude mcp remove evolink` (or `claude plugin uninstall evolink@evolink` if you used the plugin); in Codex run `codex mcp logout evolink`; in Cursor delete `evolink` in the MCP settings; in ChatGPT remove EvoLink on the plugins page; in Hermes Agent or OpenClaw remove `evolink` from `~/.hermes/config.yaml` or `~/.openclaw/openclaw.json`.
- **All assistants at once:** disable `EvoLink MCP (OAuth)` in [API Keys](https://evolink.ai/dashboard/keys). Enable it again to resume right away, without reconnecting.
- **Delete the MCP key:** deleting `EvoLink MCP (OAuth)` in API Keys disconnects every assistant connected through MCP. To use MCP again, reconnect EvoLink in the assistant and approve; a new MCP key is created automatically. To pause MCP instead, disable the key.
