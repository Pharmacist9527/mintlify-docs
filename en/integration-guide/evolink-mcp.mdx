## Overview

EvoLink MCP lets your AI assistant use EvoLink models directly: find models and prices, upload reference files, get a quote, generate images, video and audio, and check task progress and your balance.

- **Server URL:** `https://mcp.evolink.ai/mcp`
- **No API key needed:** the first time, sign in to EvoLink in your browser and approve the connection.
- **Pay as you go:** usage is charged to your EvoLink balance at the same prices as the API. The MCP itself is free.

## Supported clients

| Client | How to add |
|---|---|
| Claude (web and desktop) | One-click add, or a custom connector in Settings |
| Claude Code | One command |
| Codex | One command |
| Cursor | One-click add, or the MCP config file |
| Hermes Agent (not tested yet) | One command |
| OpenClaw (not tested yet) | One command |

Other clients that support remote MCP with OAuth sign-in, such as ChatGPT, can usually connect with the same URL, but we haven't tested each one. See "Other clients" below.

## Connect

<Tabs>
  <Tab title="Claude (web / desktop)">
    Open [Add EvoLink to Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=EvoLink&connectorUrl=https%3A%2F%2Fmcp.evolink.ai%2Fmcp): the name and URL are filled in for you. Click **Add**, then continue with step 3. Or add it by hand:

    1. Open **Settings → Connectors** in Claude and click **Add custom connector**.
    2. Enter `EvoLink` as the name and `https://mcp.evolink.ai/mcp` as the URL, then click **Add**.
    3. Click **Connect**, sign in to EvoLink on the page that opens and approve.

    <Note>
    On Claude's Free plan you can add one custom connector; see Claude's documentation. A connector added on the web also works in the desktop app.
    </Note>
  </Tab>
  <Tab title="Claude Code">
    Copy this line and run it in your terminal (or type `!` in Claude Code's input box, then paste it):

    ```bash
    claude mcp add --transport http --scope user evolink https://mcp.evolink.ai/mcp && claude mcp login evolink
    ```

    Your browser opens the EvoLink sign-in page. Sign in and approve, then reopen Claude Code and it's ready. The first half adds EvoLink (`--scope user` makes it available in every project); the second half signs you in.

    <Note>
    Windows PowerShell 5 doesn't support `&&`. Replace it with `;`, or run the two commands on separate lines.
    </Note>

    **Want the EvoLink skill too?** The skill teaches Claude to quote before generating. Install the plugin instead: enter these two lines in Claude Code (run `/reload-plugins` if asked), then type `/mcp`, choose `evolink` and select **Authenticate**. If you use the plugin, skip the line above.

    ```text
    /plugin marketplace add Evolink-AI/mcp-plugin
    /plugin install evolink@evolink
    ```
  </Tab>
  <Tab title="Codex">
    Copy this line and run it in your terminal:

    ```bash
    codex mcp add evolink --url https://mcp.evolink.ai/mcp
    ```

    Codex opens the EvoLink sign-in page by itself. Sign in and approve; `Successfully logged in.` means you're done. Start a new session to use it.

    <Note>
    Requires Codex 0.77 or later. If the output says "may or may not require login", or no browser opens, run `codex mcp login evolink` (add `--no-browser` over SSH). Don't run login every time: each run asks you to approve again.
    </Note>

    **Prefer editing the config file?** Add these two lines to `~/.codex/config.toml`, then run `codex mcp login evolink` to sign in:

    ```toml
    [mcp_servers.evolink]
    url = "https://mcp.evolink.ai/mcp"
    ```
  </Tab>
  <Tab title="Cursor">
    Click [Add to Cursor](https://cursor.com/install-mcp?name=evolink&config=eyJ1cmwiOiJodHRwczovL21jcC5ldm9saW5rLmFpL21jcCJ9): Cursor opens and asks you to confirm the install. Then find `evolink` in Cursor's MCP settings, click **Connect**, and sign in to EvoLink in your browser and approve.

    Or add it by hand: put this in `~/.cursor/mcp.json`, then click **Connect** the same way.

    ```json
    {
      "mcpServers": {
        "evolink": {
          "url": "https://mcp.evolink.ai/mcp"
        }
      }
    }
    ```

    <Note>
    With the Cursor CLI (`agent`), write the `~/.cursor/mcp.json` above, then run `agent mcp login evolink` to sign in.
    </Note>
  </Tab>
  <Tab title="Hermes Agent">
    Copy this line and run it in your terminal:

    ```bash
    hermes mcp add evolink --url https://mcp.evolink.ai/mcp --auth oauth --connect-timeout 300
    ```

    Your browser opens the EvoLink sign-in page. Sign in and approve. Back in the terminal, press Enter when asked "Enable all … tools?". In a session that is already open, type `/reload-mcp`; no restart needed.

    <Note>
    `--auth oauth` makes Hermes sign in through the browser instead of asking for an API key, and `--connect-timeout 300` gives the sign-in five minutes (the default is 30 seconds). Over SSH without a local browser, paste the URL the browser was redirected to back into the terminal. These steps follow Hermes' own documentation; we haven't tested Hermes ourselves yet.
    </Note>
  </Tab>
  <Tab title="OpenClaw">
    On the machine that runs the OpenClaw Gateway, copy this line and run it:

    ```bash
    openclaw mcp add evolink --url https://mcp.evolink.ai/mcp --transport streamable-http --auth oauth && openclaw mcp login evolink
    ```

    The terminal prints a sign-in link. Open it, sign in to EvoLink and approve; `MCP OAuth credentials saved for "evolink".` means you're done. No restart needed: the next turn can use EvoLink.

    <Note>
    OpenClaw connects to remote servers over SSE by default, so `--transport streamable-http` is required. If your browser isn't on the Gateway machine, the callback can't reach it: copy the `code` value from the URL the browser was redirected to and run `openclaw mcp login evolink --code <code>`. These steps follow OpenClaw's own documentation; we haven't tested OpenClaw ourselves yet.
    </Note>
  </Tab>
  <Tab title="Other clients">
    Clients that support remote MCP with OAuth sign-in, such as ChatGPT, can usually connect with the same URL. We haven't tested each one, so follow the client's own instructions for where to add it.

    1. In the client's MCP or connector settings, add a remote server (Streamable HTTP) with the URL `https://mcp.evolink.ai/mcp`.
    2. When asked to sign in, choose OAuth, then sign in to EvoLink in your browser and approve.
    3. Back in the client, look up a model once; a response means you're connected.
  </Tab>
</Tabs>

## First connection: sign in and approve

<Steps>
  <Step title="Sign in to EvoLink">
    Your browser opens the EvoLink sign-in page. You can sign up there if you don't have an account.
  </Step>
  <Step title="Approve the connection">
    The approval page shows which assistant is asking to connect (for example Claude Code or Codex), what it will be able to do (look up models and prices, run models on your account, stay connected) and which EvoLink account you're signed in with. Check it, then click **Allow and connect**. To use another account, click **Switch account**.
  </Step>
  <Step title="Return to your assistant">
    When the browser says you can go back, the assistant shows EvoLink as connected and you can start.
  </Step>
</Steps>

<Note>
The approval page shows what EvoLink could check about the assistant. Assistants that publish a client metadata document, such as Claude, Claude Code and Codex, show "Published by" with their website (for example claude.ai). Assistants that register themselves when they connect, such as Cursor, can't have their name checked, but the approval only goes back to an app on your device, so the page adds a note instead of a warning. If a self-registered assistant would send the approval to a website, the page shows "Unverified": continue only if you started the connection yourself.
</Note>

## What you can do

| Tool | What it does | Cost |
|---|---|---|
| `search_models` | Find image, video and audio models by type and keywords | Free |
| `get_model` | See a model's parameters and prices | Free |
| `estimate_cost` | Get a quote before generating | Free |
| `generate_image` | Generate images | Charged at the model's price |
| `generate_video` | Generate video | Charged at the model's price |
| `generate_audio` | Generate music, songs or speech | Charged at the model's price |
| `get_task` | Check a task's progress and results | Free |
| `list_tasks` | List recent tasks | Free |
| `check_balance` | See your balance and what MCP has spent | Free |
| `upload_file` | Turn a public link or a small file (up to 1 MB) into a link for generation input | Free |
| `prepare_upload` | Get a one-time upload address for a local file up to 95 MB | Free |
| `get_upload` | Check a one-time upload and get the file's link | Free |

Just ask in plain language, for example "Draw a red apple with z-image-turbo". The assistant quotes the price first and generates after you confirm. Video and audio take a while; the assistant checks progress for you.

### Reference images, video and audio

EvoLink MCP runs on EvoLink's servers and can't read file paths on your computer. Give reference files in one of these ways:

- **A public link:** send the assistant a publicly accessible link.
- **A small file (up to 1 MB):** the assistant can pass the file's content to `upload_file`.
- **A larger local file (up to 95 MB):** the assistant gets a one-time upload address with `prepare_upload`, runs a command to upload the file, then gets the file's link with `get_upload`. The address works once and expires after 15 minutes.

Uploading is free, and uploaded files are kept for 72 hours. Claude Code, Codex and Cursor can run the upload command and may ask you to approve it the first time. Claude on the web and desktop usually can't run commands; use a public link or a small file instead.

## Costs and limits

- Usage is charged to your balance at the same prices as the API. The balance is shared by the API, the web app and MCP.
- After you approve your first connection, [API Keys](https://evolink.ai/dashboard/keys) in the dashboard shows a key named `EvoLink MCP (OAuth)`, marked MCP at the top-right of its name. All assistants connected to your account through MCP share this key. It can't be copied and works only through MCP; create a separate API key if you need one.
- There is no spending limit by default; only your balance applies. Set a total limit, a daily limit or an expiry date on this key to cap MCP spending. Disable it to pause MCP for all assistants; your other keys are not affected.
- Tasks, charges and usage from MCP appear in the dashboard as usual under the key name `EvoLink MCP (OAuth)`.

## Common messages

When one of these happens, the assistant tells you which one it is and what to do:

| Message | Meaning | What to do |
|---|---|---|
| EvoLink MCP spending limit reached | The MCP total limit is used up; this is not your account balance | Raise the limit of `EvoLink MCP (OAuth)` in API Keys |
| EvoLink MCP daily limit reached | The MCP daily limit is used up; it resets at midnight | Wait for the reset or raise the daily limit |
| Your EvoLink account balance is too low | Your balance is not enough | Top up in the dashboard |
| EvoLink MCP is paused for this account | `EvoLink MCP (OAuth)` is disabled | Enable it again in API Keys; no need to reconnect |
| EvoLink MCP key has expired | `EvoLink MCP (OAuth)` passed the expiry date you set | Extend or clear the expiry date in API Keys; no need to reconnect |
| This EvoLink connection was disconnected | The connection ended or expired | Reconnect EvoLink in the assistant |
| EvoLink has temporarily turned off MCP access | EvoLink has turned MCP off for everyone for a while; it isn't your settings | Try again later; switching models, retrying right away or reconnecting won't help |

None of these are charged.

## Disconnect

- **One assistant:** in Claude, disconnect it in the connector settings; in Claude Code run `claude mcp remove evolink` (or `claude plugin uninstall evolink@evolink` if you used the plugin); in Codex run `codex mcp logout evolink`; in Cursor remove `evolink` from the config; in Hermes Agent or OpenClaw remove `evolink` from `~/.hermes/config.yaml` or `~/.openclaw/openclaw.json`.
- **All assistants at once:** disable `EvoLink MCP (OAuth)` in [API Keys](https://evolink.ai/dashboard/keys). Enable it again to resume right away, without reconnecting.
- **Delete the MCP key:** deleting `EvoLink MCP (OAuth)` in API Keys disconnects every assistant connected through MCP. To use MCP again, reconnect EvoLink in the assistant and approve; a new MCP key is created automatically. To pause MCP instead, disable the key.
