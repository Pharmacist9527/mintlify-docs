## Install and manage the CLI skill

This page covers evolink-cli targets, directories, host discovery, and updates. See [shared resources](/en/cli-mcp/agent-resources) for scope, CLI/MCP/plugin concepts, and common rules.

## Install and verify discovery

```bash
evolink skills install
evolink skills status --json
```

Default installation covers supported target directories without installing the agents. To select one host:

```bash
evolink skills install --agent codex
evolink skills status --agent codex --json
evolink doctor --agent codex --json
```

Check current:true and send this in agent chat:

```text
Confirm this session can discover and read evolink-cli. Query balance and models first; do not generate media.
```

assistant_discovery:not_checked means CLI cannot verify discovery on the host's behalf. Refresh skills/open a new session and check command permissions when files exist but are unused. Reading a document alone does not prove account access.

## Supported targets and directories

| --agent | Client | Directory |
|---|---|---|
| codex | Codex | ~/.agents/skills/evolink-cli |
| claude-code | Claude Code | ~/.claude/skills/evolink-cli |
| cursor | Cursor | ~/.agents/skills/evolink-cli |
| openclaw | OpenClaw | ~/.openclaw/skills/evolink-cli |
| hermes | Hermes | ~/.hermes/skills/evolink-cli |
| gemini | Gemini CLI | ~/.agents/skills/evolink-cli |
| opencode | OpenCode | ~/.agents/skills/evolink-cli |
| copilot | GitHub Copilot CLI | ~/.agents/skills/evolink-cli |

Gemini, OpenCode, and Copilot can follow [general five-step installation](/en/cli/setup#cli-install) with their agent value. Install in the actual SSH/WSL/container/Gateway environment. These are installation targets, not guarantees of discovery in every host version. Host policy and skill loading remain host responsibilities.

## Updates and personal modifications

```bash
npm install -g @evolinkai/cli@latest
evolink skills install
evolink skills status --json
```

Synchronize skills after updating CLI and ask the agent to reread them. Personal changes are retained by default. Inspect modified/conflict states first. Use --replace-modified only after deciding to replace personal content; originals are backed up to ~/.evolink-media/skill-backups/. See [skill troubleshooting](/en/cli/billing#skills-discovery).
