EvoLink CLI lets agents with terminal access and terminal users generate images, video, music, and speech, inspect models and parameters, query balance and tasks, upload references, and save originals.

This section describes released **CLI 0.9.0**. It requires Node.js 22+ on macOS, Windows, or Linux. Install under the user and on the machine where the agent executes commands. Media uses **agent/terminal → CLI → platform API**.

## Installation and verification

Send this prompt to an agent with terminal access. It matches the website installation prompt:

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Install the CLI: run `npm install -g @evolinkai/cli`.
2. Sign in: run `evolink auth login`.
3. Install the companion skill: run `evolink skills install`.
4. Verify the connection. Once successful, tell me I can get started.
```

Paste the prompt in chat; commands run in the agent's terminal or your terminal. Complete browser sign-in and permissions yourself. See [installation and sign-in](/en/cli/setup) for detailed steps, success indicators, updates, logout, and SSH callbacks.

The basic manual sequence is:

```bash
npm install -g @evolinkai/cli
evolink auth login
evolink skills install
evolink balance --json
evolink doctor --json
```

Wait for sign-in to complete before continuing. Do not paste the whole block and ignore authorization. Ask the agent to confirm it has read evolink-cli. Balance and diagnostics do not create paid media tasks; begin creation after verification.

## CLI capabilities

| Capability | Usage and guide |
|---|---|
| Environment and access | version, auth, setup, doctor; [installation](/en/cli/setup) |
| Models and parameters | models search/recommend/show/schema, docs search; [reference](/en/cli/reference) |
| Estimation and approval | estimate creates a local quote; generate after approval; [workflow](/en/cli/workflows) |
| Media | Images, video, music, and speech according to model capabilities |
| References | upload local files; uploads get inspects the original receipt |
| Tasks | get/wait, batch, paginated history, and quote-based recovery |
| Original downloads | One/all results, format checks, and batch recovery |
| Account and usage | balance and bounded historical usage, not a complete bill |
| Skills | skills install/status and host discovery checks |

CLI does not provide general text chat, queue cancellation, funding, Key management, automatic editing, or finished-video hosting. Code development and arbitrary file editing are host agent capabilities. Deliver generated originals first; new variants, edits, or regenerations need appropriate approval.

## First creation

```text
Use EvoLink to create a coffee brand advertisement image.
First query available image models, parameters, and cost, then explain the recommendation and output specification.
Submit once after my explicit approval, save the task identifier, and download the original with its reported actual cost.
```

Follow [model → references → estimate → approval → task → download](/en/cli/workflows). Installation is not approval for paid generation. Estimates are not final settlement; see [costs and troubleshooting](/en/cli/billing).

## CLI and MCP

CLI installation includes the executable, shared business modules, and bundled evolink-cli skill. It does not require cloning MCP/plugin repositories or register native MCP. Passport provides OAuth; the operating system stores credentials securely.

CLI and remote MCP sessions are managed separately. Account OAuth currently shares internal Key permissions, limits, and pause state. For Claude/ChatGPT web or native tool invocation, use the [separate MCP section](/en/mcp/overview).
