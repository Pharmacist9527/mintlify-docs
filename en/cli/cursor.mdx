Cursor can execute media tasks through EvoLink CLI. This page covers host environment and skill differences; [installation and sign-in](/en/cli/setup) owns the complete common procedure. For native tools, use the [MCP guide](/en/mcp/cursor) directly.

## Ask your agent to install

Paste the following into the agent conversation. It matches the website prompt. Complete browser sign-in and permission review yourself.

```text
Set up EvoLink so I can generate images, video and audio directly here.
1. Install the CLI: run `npm install -g @evolinkai/cli`.
2. Sign in: run `evolink auth login`.
3. Install the companion skill: run `evolink skills install`.
4. Verify the connection. Once successful, tell me I can get started.
```

## Three steps for this client

<Steps>
  <Step title="Complete common installation and sign-in">
    Install in the workspace execution terminal; Remote SSH, WSL, and containers need their own installation and agent command permission.

    First-time users should open the [five-step guide](/en/cli/setup#cli-install): check Node.js 22+, install CLI, and complete browser sign-in. It includes commands, success indicators, and troubleshooting. If already done, verify:

    ```bash
    evolink --version
    evolink auth status --json
    ```

    Look for a CLI version and authenticated: true. See [installation errors](/en/cli/billing#cli-install), [sign-in errors](/en/cli/billing#login), or [SSH callbacks](/en/cli/setup#ssh-login) for the failed stage.
  </Step>
  <Step title="Synchronize this agent's skill and verify discovery">
    ```bash
    evolink skills install --agent cursor
    evolink skills status --agent cursor --json
    ```

    The directory is ~/.agents/skills/evolink-cli. current: true means files match the CLI. Ask the agent:

    ```text
    Confirm this session can discover and read the evolink-cli skill. Verify access without generating media.
    ```

    assistant_discovery: not_checked still requires host verification. Follow [skill discovery](/en/cli/billing#skills-discovery) if files exist but are unused. Review required execution permissions and preserve personal modifications.
  </Step>
  <Step title="Verify for free before creating media">
    ```bash
    evolink balance --json
    evolink doctor --agent cursor --json
    ```

    Setup is complete when balance returns account data, doctor reports ok, connection_verified, and model_discovery_verified as true, and the agent confirms reading the skill. These queries do not create paid media tasks. Zero balance can still verify connectivity.
  </Step>
</Steps>

### Combined setup for an installed CLI

```bash
evolink setup --agent cursor --json
```

This checks the environment, synchronizes skills, signs in when needed, and verifies access. Look for setup_complete: true; host discovery still needs confirmation. Use phase, steps, error, and recovery to identify failures.

## Update and sign out

After updating the CLI, synchronize the current agent’s skill:

```bash
npm install -g @evolinkai/cli@latest
evolink --version
evolink skills install --agent cursor
evolink skills status --agent cursor --json
```

Local changes are preserved; handle `modified` or `conflict` under [skill troubleshooting](/en/cli/billing#skills-discovery). Run the following only when you want to sign out of the CLI; it is not an installation or update step.

```bash
evolink auth logout
```
